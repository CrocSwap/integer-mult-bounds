\section{A fixed finite scalar alphabet in the interchange transfer}
\label{sec:finite-alphabet-transfer}

The rational-frame interchange interface does not intrinsically require
XOR as its pointwise scalar operation. The following extension concerns
the swap interface only; it does not change the complex phase interface.
All conclusions remain conditional on the upstream stream procedures.

\begin{proposition}
Let $\mathcal A$ be a fixed finite alphabet containing distinct symbols
$0,1$. Suppose a fixed finite circuit on $W$ roles consists of fixed
pointwise maps on symbols in $\mathcal A$ and has, on every input in
$\mathcal A^W$, the complete scalar action of a role permutation $\rho$.
Assign the same rational $m$-by-$m$ matrix to all incidences of each gate.
If
\[
 M_{\mathrm{out}(\rho(w))}-M_{\mathrm{in}(w)}=I_m,
 \qquad s=\sum_e\operatorname{rank}_{\mathbb Q}
 (M_{\mathrm{head}(e)}-M_{\mathrm{tail}(e)})<Wm,
\]
then the upstream power-width interchange proposition holds with these
$m,W,s$ and every rational $\tau\in(0,1)$ satisfying $s/W<m^\tau$.
It acts on bit data as well as arbitrary $\mathcal A$-valued data.
\end{proposition}

\begin{proof}
Use the fixed tape alphabet $\mathcal A$ on the data track. Its symbols
can alternatively be represented by a fixed number of bits per cell;
this changes every scan cost by a fixed factor. For this induction let
$V$ count data entries, so a role stream has exactly $V/W$ entries.
For an original bit array this is its original logical volume. No
conversion factor enters the recursive branching coefficient.

The elementary stream procedures move whole symbols and apply fixed
pointwise maps to aligned symbols. The machine model already permits
fixed finite alphabets and fixed tracks. All counters, descriptors and
address radices remain as in the upstream proof. The prime used for
rational address shears is chosen from their finite rational tables and
is unrelated to any field used to name the data symbols.

Induct simultaneously for all $\mathcal A$-valued arrays. Base-case scans
permute symbols. Recursive matrix-shear calls therefore remain within
the induction hypothesis even when a surrounding gate has produced
symbols other than $0,1$. A common address permutation commutes with
every fixed pointwise map, without any linearity assumption on that map.
Consequently the same frame invariant gives
\[
 f'_{\rho(w)}=\Phi_{M_{\mathrm{out}(\rho(w))}}
             \Phi_{-M_{\mathrm{in}(w)}}f_w=\Phi_{I_m}f_w.
\]
Merging the role streams undoes $\rho$, including on all scratch-role
payload. The two other triangular updates convert this shear into the
desired chunk interchange. The identical recurrence is
\[
 T(V,e)\le\sum_{j=1}^s T(V/W,e/m)+O(V),
\]
with constants depending on the fixed alphabet and circuit. Restricting
initial data to $0,1$ is now legitimate: every completed recursive
interchange restores those data values, while its interior may use other
symbols. No invalid binary encoding or initialized scratch symbol is
assumed.

The arbitrary-width reduction is unchanged as well. Its reserved high
address digits provide at least $W^k$ rows, using only $O(\log e)$ digits
for the fixed $m,W$. Row padding increases volume by less than two, and
radix padding by a fixed factor. Use the symbol $0$ in padded entries;
completed recursive calls are data permutations and therefore preserve
the padded zero rows at their boundaries. Removing those rows and invalid
address ranges consequently returns the original symbol array in the
required order. No bound on the numerical size of $W$ relative to $m$
is added by this reduction.
\end{proof}

In particular one may take $\mathcal A=\mathbb F_p$ for any fixed prime
$p$. A signed exchange $(X,Y)\mapsto(-Y,X)$ is corrected to an unsigned
exchange by negating the physical $X$ bank at its final identity frame.
This is a fixed pointwise map with zero added edge rank. The rational
frames and all rank charges must still be checked; changing the scalar
alphabet by itself supplies no improvement.
