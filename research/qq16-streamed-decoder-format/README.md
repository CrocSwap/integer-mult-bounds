# Independent native-frame and tensor checks for the QQ16 recovery format

PR4109 already establishes the common finite format and producer composition
for PR4015 and its paired successor. This package independently rederives the
PR4015 baseline, binds it to raw native-frame data and ownership, and executes
the actual q=19 negative line on dense one- and two-factor arrays against a
separate translation-convolution oracle. It also reconciles two explicitly
different numeric counting protocols. No new format theorem or priority is
claimed. The domain is the literal **3,813-event, 224-output streamed word**,
including its nine reused output banks, native interiors and private lifetimes.

For every integer tensor depth `lambda >= 1`, put `t=lambda-1`. If all 224
borrowed current X/Y fields have Gaussian-dyadic components in `h Z`, uniformly
bounded in absolute value by `< 2^P h`, the decoder executes exactly with

```
q_decoder = h * 2^(-9-3t),       W_decoder = P+28+6t.
```

Owned output banks are distinct from borrowed inputs and each other. Their
initial contents are discarded only by their literal paid CLEARs. Private F/G
fields are exclusively owned, initialized before use, and cleared to zero
before release. Scalar and native numerical scratch is disjoint and written
before use. The tensor-native, full-cover and functional decoder semantics are
the retained source contracts, not re-established by a capacity calculation.

Composing with the authenticated PR3303 F0 -> B12 format, now let h and P refer
to its **original 704 persistent input fields**, including its dirty helpers;
its eight private fields enter zero. One common format for the producer and
this complete decoder is

```
q_total = h * 2^(-80-22t),       W_total = P+242+44t.
```

This independently checks the consumer arithmetic conclusion: the represented
reference has zero producer and decoder arithmetic error on the declared lattice. It
does not supply an actual caller's input preparation, literal return of the
producer's dirty helper arrays, or a favorable physical/recursive invoice.
No supplier or kappa claim is made.

## Proof of the standalone format

For `z=2^t >= 1`, associate a nonnegative rational polynomial p and integers
g,b with each nonzero field. Maintain

```
|component| <= 2^P h p(z),      component belongs to h*2^(-g-bt) Z.
```

Known zero has an empty polynomial and no grid obligation. Borrowed entries
start with p=1, g=b=0. Owned fields have no usable value until their first
source CLEAR. The following rules apply to arbitrary correlated values:

- ADD adds the two magnitude polynomials and takes the maximum of the two
  grid intercepts and slopes. All literal coefficients are ±1 or ±1/4.
  A signed coefficient product is computed before its destination ADD; the
  copied source, sign change and exact division are included in the bounds.
- A private or owned CLEAR produces exact zero. It does not erase the already
  recorded peak range or grid requirement. No borrowed field may be cleared.
- A signed native coordinate line on x=a+ib and y=c+id has outputs
  `((a+c-e(b-d))+i(b+d+e(a-c)))/2` and
  `((a+c+e(b-d))+i(b+d-e(a-c)))/2`, with e=±1. Pair sums/differences,
  cross numerators and outputs have component bounds 2L, 4L and 2L.
  The final halves refine the grid by one bit.
- Applying this line in all lambda tensor layers gives bounding observations
  `2zp, 4zp, 2zp`, with grid `(g,b+1), (g,b+1), (g+1,b+1)`.
  These bound every intermediate layer: before layer j, the magnitude grows
  by at most `2^(j-1)` and the grid by j-1, where j<=lambda.
- The native basis wrappers are permutations, including the negative line's
  affine offset q. Full-cover maps are owner/payload bijections and preserve
  a component bound uniform over all owners. No owner is silently identified
  with another. Scalars act once on a field, not once per tensor factor.

Source induction through all 3,813 events and **10,336 primitive observations**
gives

```
max p(1) = 171043 < 2^18,   max degree(p) = 3,
max grid intercept = 9,    max grid slope = 3.
```

The range maximum is at event 3797, an ADD. The global maxima are conservative
capacity bounds, not optimal formats or demonstrated reachable extrema.
Nonnegative coefficients give `p(z) <= p(1) z^3`, so every component, product
and native numerator has magnitude `< 2^P h 2^(18+3t)`. In units of the proposed
q_decoder it is an integer of magnitude `< 2^(P+27+6t)`. Signed width
`P+28+6t` therefore suffices. Each right-shift result is on the common lattice,
so its numerator is divisible by the required power of two. Strict bounds
also make negation safe at both signed extremes.

The checker derives the 224 stage/port owner maps from canonical phase data,
checks their complete 73-axis inverses, and verifies all frame transitions.
It checks 114,688 exact signed native basis columns for all 112 labels, including
both signs and the negative affine offset. These are source-bound primitive
checks; the full inverse identity is inherited from PR4015.

## Composing the actual producer entry

PR3303 gives, for the original input h and P,

```
h_D = h * 2^(-71-19t),
|each producer output component| < 2^P h * 2^(143+19t).
```

Thus the decoder's entry parameter may be chosen as
`P_D = P+214+38t`, since the latter magnitude is
`< 2^(P_D) h_D`. Substitute h_D and P_D into the standalone theorem:

```
h_D * 2^(-9-3t) = h * 2^(-80-22t),
P_D + 28 + 6t   = P + 242 + 44t.
```

Execute the producer on this same finer lattice from the beginning; its
previous bounds also fit the enlarged signed width. No boundary rounding or
lossy conversion is needed. Producer current X/Y then enter the decoder
unchanged, and its owned output banks use the same format as its temporary
query sums. For `h=2^-64`, `P=64`, `lambda=1`, one sufficient whole-chain
format is **306-bit signed components on quantum 2^-144**.

Under the inherited exact source semantics, all implemented producer and
decoder arithmetic defects are zero on this input domain, so the corresponding
completed-error allowances are met for any requested beta. Initial real-input
quantization, caller format admission and physical effects are not deleted by
that statement. The new decoder's exact functional identity is its own
predecessor theorem; the older PR2736 numerical theorem is not substituted for it.

## Direct numerical bill

Let `N=2^(73*lambda)` be complex payload coordinates per owner. The protocol
uses a W-bit signed component format throughout. Constant-product terms are
copied, conditionally negated, divided exactly by four when required, and
then added. Each native line pays both basis permutations using a reusable
complex buffer. One Gaussian coordinate line pays 4N real additions,
2N halvings and 4N component copies. Each cover pays 4N conceptual component
transfers separately. The inventory is 2,816 ADDs (1,172 negative, 896 quarter),
416 CLEARs, 224 native lines and 352 maps.

| Decoder reference charge | W-bit operations per N |
|---|---:|
| Product copies | 5,632 |
| Signed negations | 2,344 |
| Exact quarter shifts | 1,792 |
| Destination additions | 5,632 |
| Owned/private clears | 832 |
| Two native permutation wrappers per line | 1,792 |
| Gaussian interiors and copies | 2,240 lambda |
| Final reusable buffer clear | 2 |

There are also twelve final arithmetic-scratch zero writes. Therefore the
decoder reference bill is `(18026+2240 lambda)N+12` numeric operations,
`1408N` cover transfers and `930N+12` numeric words. The latter counts
224 borrowed inputs, 224 outputs, at most sixteen private fields, one complex
permutation/cover buffer and twelve scalar temporaries.

Adding the inherited producer bill without credit for eliminating either
boundary cleanup gives the entire numerical reference:

```
work:     (390348 + 113000 lambda) N + 24 W-bit numeric operations,
covers:   3520 N conceptual component transfers,
storage:  1890 N + 12 W-bit numeric words.
```

The storage bound retains all 704 original persistent producer fields,
including the 480 borrowed helpers; adds 224 recovery outputs; reuses at most
sixteen private fields and one complex buffer. It assumes these logical fields
can be supplied disjointly; it is not a physical placement construction. Code,
address/sign/control work, tape-head motion, representation adapters and
recursive tariffs remain separate costs. No favorable supplier moment follows.

PR4109 uses a different protocol: signed ADD/subtraction is one operation, its
constant term is not separately copied, each monomial allows 2N sign operations,
cover copies are included in the numeric total, and it reports no final buffer
clear. Recounting that convention from the same WORD gives its published
`(12352+2240 lambda)N` baseline. Our unfused convention, with cover transfers
included for comparison, gives `(19434+2240 lambda)N+12`. The difference is
exactly `7082N+12`: 5632N term copies + 2344N explicit negations - 896N
unnecessary sign allowances for these pure-permutation wrappers + 2N+12 final
scratch clearing. Both are constructive upper protocols, not conflicting
minimum-cost claims or a new speedup. The verifier records and independently
recounts both conventions; mixing them would manufacture a false saving.

The primary polynomial interpreter authenticates inputs before parsing. The
separate integer/dyadic recurrence imports no primary or predecessor code and
matches all 10,336 one-layer observations; it explicitly repeats native layers
at depths 1,2,3,8,32 and independently checks the reference bill and composition.
The observed grid guards are 9,12,15,30,102. The all-depth theorem comes from
the preceding induction, not extrapolation from these depths.

Six behavioral groups check 1,250 signed Gaussian pairs, an off-grid half,
an overflowing intermediate with fitting endpoints, the actual source's
ownership/frame mutations, and width/storage substitution. Complete fixed-grid
executions at depths 1,2,8 check all 3,808 changed-field cuts per run on arbitrary
independently chosen complex constants in each borrowed field. Uniformity over
owners and payload coordinates makes these valid source inputs: both signs of
C_q and all cover maps fix constants. The native pair interiors are still
executed and compared against a separate Fraction formula. This is explicitly
a constant-payload control, not a huge-payload execution or a full functional
decoder proof. Independent general primitive checks and induction supply the
capacity guarantee for arbitrary bounded input arrays.

The additional group binds actual event 1707 (`Z10`, negative q=19) to dense
512- and 262,144-coordinate inputs with independent complex components, for
one and two nine-axis tensor factors. Bounded integer pair-first execution
agrees at every endpoint with a separately expanded sum of 2^lambda translated
inputs. The inverse returns the entire input exactly and the source arrays

spectators omitted, not a full O73 owner-cover or whole-decoder dense run.
