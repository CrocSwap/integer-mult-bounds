## Replay offline

From the repository root, with Python 3.12 or 3.13, assertions enabled, the pinned
bit requirements, bash, sha256sum, GNU g++/C++17 and Boost:

```sh
python3 -m pip install -r research/e8-bit-seven-stage/requirements.txt
python3 -B research/e8-bit-signed-validation/verify.py /fresh/output
```

Allow roughly five minutes. The output must be new; inherited shell paths must
not contain whitespace. All dependencies default to sibling packages. Overrides
are `--composition`, `--baseline`, `--bit`, `--bit-parent`, `--complex`, and
`--far`; the last names the unchanged PR378 source package. There is no default
shortcut around fresh component verification.

The package is text only. `signed_source.py` is copied unchanged from PR388's
pinned source archive into the generated output directory before execution.
The original upstream receipt is preserved there; `SIGNED.json` is a portable
view that removes runtime/path metadata and identifies the native word payload.
The raw compressed input is still checked before canonicalization. Every
mathematical field and assertion remains. `SOURCE.json` binds the upstream
script/archive/commit and all 16 files of the frozen composition.
