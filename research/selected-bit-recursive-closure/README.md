# Selected BIT recursive interchange closure

We give a written construction of ordinary binary chunk interchange in
`O(V E^(1-a))` time, with `a=169711/100000000=0.00169711`, in the stated
fixed-tape complete-stream model. We close the weighted-child premise by
proper-width induction, starting from elementary digit interchanges.

We bind the selected MOVE, rank-seven COPY and idle residuals to their actual
full-ring projectors. We use one symbolic ancestor expression across a
complete high packet, provide completed weighted leaves and elementary
header routes, and specify the chronological caller, fresh row reserve and
parking discipline. [PROOF.md](PROOF.md) gives the construction and uniform
time argument. We use a coarse rational point in the existing BIT moment
certificate; we claim no new optimized supplier root.

We contribute this work as Jose Manuel ([jmbarrancoml](https://github.com/jmbarrancoml)),
with substantial OpenAI Codex assistance. We have not obtained independent
human or proof-assistant verification. We leave the selected frontier and
the full multiplication theorem unchanged.

  `mu_1<199/200` and `mu_(1-c)<9999/10000`.

The leaf and header routines accept no opaque child implementation. We keep
independent dense address maps as finite test oracles. The whole selected
machine remains a written algorithm; we do not execute its GL64 payload or
claim that the tests prove the all-size theorem.
