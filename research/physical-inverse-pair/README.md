## Literal four-block theorem

Operators act rightmost first. On the direct sum of 112 arbitrary owner fields let `Q` be the central Gaussian, `D` the product of the eight fresh Gaussian axes, `R=DQ=QD`, and `K=diag(K_i)` the actual PR4933 signed normalizers. Set

```text
C = K^-1 (A tensor I) K,
B = diag(D,D) [[I,-QC],[0,I]],
T = [[I,0],[Q^-1 C^-1,I]],
E = diag(I,C^-1),       O = diag(I,Q^-1 C Q).
```

The raw-dual convention is PR4933's actual X-only Q-squared correction. Each real signed K_i commutes with R, hence C and its inverse commute with R. Consequently literal multiplication gives every block, without commuting C through Q or D separately:

```text
T B = [[D,              -DQ C],
       [Q^-1 C^-1 D,       0]],

O T B E = [[D,        -DQ],
           [DQ^-1,      0]].
```

For the bottom-right block use `Q^-1 C^-1 DQ C = Q^-1 DQ = D`. For the top-right block right-multiplication by C^-1 cancels the final C. For the bottom-left block left-multiplication by `Q^-1 C Q` cancels adjacent `Q Q^-1` and `C C^-1`, giving `Q^-1 D=DQ^-1`. The top-left block stays D. These equations hold on independent arbitrary X and Y, not only on x=0 or a selected source column. The uncorrected pair already cancels its YY block; its YX block is still wrong. A scalar exit C, with the Q conjugation omitted, fails the executable control.
