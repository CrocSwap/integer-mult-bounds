# Finite native-frame implication

Fix the source bytes in SOURCES.json and PR2445's CIRCUIT.json at its pinned
head. Work with 512-dimensional complex address arrays. Distinct public input
registers carry arbitrary independent such arrays. Use the same zero/full
chart and owned private-copy contract as PR1991; no global supplier admission
is assumed or concluded.

## Physical chart binding

The doubled E8 roots reconstruct the ordinary Gram matrix G. The compressed
binary labels pair through the inverse compressed Gram matrix J, not through
the ordinary dot product. The checker independently reconstructs every root,
checks J, checks the recorded J-orthonormal basis, and verifies all 120 squared
root pairings after the resulting map q. It additionally checks q is a
bijection on all 512 binary labels. Thus new frames containing non-root labels
use the same valid linear coordinate map, rather than extrapolating only from
the labels used in the old word.

For a binary subspace W, take the canonical reduced basis after q and the
fixed Clifford chart Gamma_W interpreted by native_verify.py. Canonicalization
is essential: equal subspaces must denote equal physical charts. Merely using
different bases for a common subspace need not justify an unadjusted scalar
contact unless the chart convention is the same.

## Exact transport operators and invoice

For each added edge A to B, compile the operator Gamma_B Gamma_A^-1. The
emitted form consists of Gaussian monomials surrounding one positive child.
Both the compiler's rank and the independent recipe rank must equal
abs(dim B-dim A). All 161 distinct added edges are nested; their 236 uses have
profile 142 H1 + 16 H2 + 18 H6 + 60 H7. Each is absent from the old catalogue,
so no old occurrence count can substitute for the new compilation.

The checker evaluates each recipe without importing the compiler. Equal
conjugation actions on every signed Pauli generator imply that two Clifford
operators differ by a scalar: their quotient commutes with the full matrix
algebra generated by X and Z, whose commutant consists of scalars. Equality
on the nonzero state |0> fixes that scalar. The Gaussian interpreter computes
this column exactly with integer real/imaginary numerators and powers-of-two
denominators. No floating-point comparison or unsigned symplectic-only test
is used. The forward-phase and inverse-phase fault controls demonstrate why
the second condition matters.

For each new edge its reverse operator Gamma_A Gamma_B^-1 is separately
lowered and checked at the same rank. This establishes only a finite native
inverse transport. It does not reverse the whole supplier contract, its
private lifetimes, precision obligations, or all-size construction.

## Full forward induction

Let z contain the 358 independent logical input arrays. At each event every
live public register r has a physical value Gamma_(W_r) a_r z, where a_r is
an exact rational row. Entry adapters establish this invariant on all source
registers. Initial target and dirty-helper charts are ZERO.

For a checked native transport, Gamma_B Gamma_A^-1 changes W_r from A to B
and leaves a_r unchanged. For an ADD at a common physical chart W,
Gamma_W a_r z + c Gamma_W a_s z = Gamma_W(a_r+c a_s)z, since Gamma_W is
complex-linear and c is rational. The checker verifies literal common charts
and performs the row update exactly. It handles owned zero/copy/discard under
the unchanged explicit contract and checks all eight lifetimes close.

Induction over every one of the 4734 events therefore proves the full physical
endpoint for arbitrary input arrays, without enumerating address functions.
The final row comparisons cover all 358 squared coefficients. They show the
identity correction on Y0 and Y1, the original G/2 channel on the remaining
102 targets, and logical restoration of all 150 dirty helpers. All final
frames are checked. The 208 retained entry/exit adapters are rechecked as
complete phase-correct rank-zero operators at the actual source/target roots.

The added scalar shears are exact rational array operations in this finite
model. Their bit/tape implementation, bounded-precision errors, global role
availability and recursive charging are not supplied by this argument. The
702 new boundary rank units are not asserted to be recursive excess cost.
Consequently this native frame certificate closes the named finite gap but
does not establish a complete P104 supplier or a changed exponent.
