## What is admitted

Both words implement a valid local supplier on 632 arbitrary independent persistent
inputs: 224 main fields and 408 helper fields. The owned temporary's entry is also
treated as arbitrary and must be cleared at return. `independent.py` imports no
upstream evaluator or Clifford implementation. It executes the exact rational scalar
word over the free group algebra, checks every chronological frame contact, each
paid width and all 72 shared native maps on every occurrence, and compares every
final input coefficient in both orientations. The result has 632 rows, 744 terms
and no nonempty operator words. The retained scalar records match the original
word exactly. Both meaningful mathematical corruption controls are rejected.

For each helper, the entrance is a proper subspace of its exit. Its output depends
only on its own arbitrary input after the physical endpoint transforms. Its rank
is computed from that actual nested pair. No helper input is initialized or
identified with another provider call's helper.

The exact phase-aware upstream replay is separate evidence: `replay.py` invokes
the original verifier with `-I -O -B` in its authenticated source directory,
places its temporary regeneration copies under `.scratch/`, and checks that the
original source bytes remain unchanged. The original wrapper launches assertion-
enabled child evaluators for both orientations. Its success requires regenerated
word, warp-phase, main-normalizer and paid/helper-phase mathematical payloads to
match exactly, including absolute phases. `REPLAY.json` and the two log files
record the successful result. This package adds no Lean formalization.

## Reproduction and dependencies

From this directory using standard-library Python 3.12 or later:

    python -I -B independent.py
    python -I -B replay.py
    python -I -B check_bundle.py

The independent check takes a few seconds. The exact phase regeneration takes
several minutes. Replay needs writable `.scratch/` and no network, Git object,
solver, Lean installation or external repository path. `capture.py` is only a
source-import aid and requires Git plus the pinned commit object; it is not
needed for a clean-checkout audit replay. Original compressed bytes are pinned,
while regeneration compares decompressed mathematical payloads.
