# Sequential monomial phase production

The retained complex phase pass evaluates its tensor polynomial from decoded
addresses. This package supplies those phase codes with physical binary
counters, a borrowed active-position mask and fixed recipe tables. It then
drives the retained Gaussian coefficient loop without a decoded address or
record count. The actual family 65689 right recipe keeps its absolute phase,
strict-upper quadratic convention and inverse direction.

[PROOF.md](PROOF.md) proves all-size correctness and the complete bound
`32(m+1)(R+b+1)` for initialization, carries and counter cleanup. The producer
stores no full phase table. The source coefficient path contributes `18V`
separately. [phase.py](phase.py) contains the implementation;
[RESULT.json](RESULT.json) records complete source domains and exact checks.

```sh
python3.12 -B scripts/research_package.py --package research/sequential-monomial-phase
```

Both registered isolated, warning-strict normal and optimized modes print
`PASS_SEQUENTIAL_MONOMIAL_PHASE`. The standard library suffices. Evidence
includes 9760 records in 224 generic domains, 524800 actual source phase records,
six 1024-record Gaussian payload cases in both directions, exact coefficient
meter agreement, dirty-prefix independence and six rejecting ABI controls.
The proof supplies the all-size claim; the finite domains corroborate it.

The mask is a supplied physical input, with its scan and return charged.
Its manufacture is not claimed. The demonstrated consumer has one Gaussian
coefficient per record and consumes its owned input. Mixed-width packing,
affine routing, recursive C, complete allocation/stock/precision and native
supplier admission remain open. No full 147-bit production payload, Lean,
Docker, selected cold replay or full-history validation was run. The complete
kappa calculation is unchanged.
