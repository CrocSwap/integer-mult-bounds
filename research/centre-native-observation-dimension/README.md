# Native payload dimension for owner-local centre repairs

**Scoped conditional information theorem, with exact native local premises.**
For the selected calls 0 and 4, a repair using linear observations local to
each old cover owner requires **104d additional complex coordinates per
owner**, where every complete payload space has dimension d. This is sharp
as an abstract information interface. Records holding at most d coordinates
therefore require at least 104 records per owner. This does not price recursive
children, rank mass, native reads or an executable repair.

[PR2461](https://github.com/CrocSwap/integer-mult-bounds/pull/2461) at
`4c674beb8c752c4c2352e4591638807d23215c49` proves 104 additional scalar
coordinates on payload-constant input differences. Its source explicitly
leaves general native operator rank unclaimed. This package supplies the
missing full-payload factorization, rather than multiplying its scalar bound
by 512 without checking the operators. The earlier scalar theorem and routes
are credited and replayed as premises.

The new check audits the **complete forward and backward words**, and proves
that the backward pre-transport queries have only T coefficients, H=R/4, with
all D/helper coefficients zero. Thus the first call's native D and T responses
cannot cancel each other in those queries. Every first-call D-to-T port block
is verified invertible, and the source-to-helper endpoint block is zero. The
112 distinct actual routes then give disjoint output-owner supports for
arbitrary port payloads, yielding rank 112d; the old transcript has rank 8d.
[PROOF.md](PROOF.md) states the exact contract and the sharp reconstruction.

The native local facts are checked on every address column, including phase.
The global interpretation retains an explicit **full-space invertible
local-view/cover contract** on equal finite payload spaces; no physical
73-axis compiler is rebuilt. Tensor spectators and invertible row charts
preserve the proof. A local 512-dimensional example gives an additional
53,248 coordinates. The entire physical 73-axis payload has its own larger d;
this is not a claim that its whole array has only 512 coordinates.

The theorem permits arbitrary cross-owner decoding, including nonlinear
decoding, but the added encoders are linear and local to each old owner's
original 112 source arrays. Initial target/helper dirt is held fixed, not
assumed clean. Every later internal query must be recovered. The original
chronology is fixed and all other source-dependent state is excluded. General
mixed-owner encoders, sequential reads, final-output-only contracts and new
centre mechanisms remain open.

## Reproduce

Python 3.12 or later, standard library only, from the repository root:

```sh
python3 -I -O -B research/centre-native-observation-dimension/verify.py
python3 -I -O -B research/centre-native-observation-dimension/test_integrity.py
python3 -B scripts/research_package.py --package research/centre-native-observation-dimension
```

Expected primary marker:

```text
PASS_NATIVE_OWNER_OBSERVATION_DIMENSION old=8*d later=112*d additional=104*d controls=7
```

Ordinary replay reads and recomputes the entire RESULT.json. `--write NEW_PATH`
creates a new receipt exclusively. SOURCES.json authenticates four runtime
root inputs and six unique full-path archive members; PREDECESSORS.json binds
all five retained predecessor files by SHA-256 and Git blob. All dependencies
are authenticated before their bytes are compiled directly, avoiding stale
bytecode caches. No runtime Git or network access is used.

Seven semantic controls cover a bad backward frame, reversed backward centre,
omitted forward transport, omitted repair coordinate, wrong native global
phase, a constant-preserving but singular endpoint map, and a collapsed-route
positive boundary. They remain active under Python optimization. The last
two specifically show why constant-payload evidence and scalar coefficients
alone do not establish the full native dimension conclusion.

All local arithmetic is exact rational or packed integer Clifford arithmetic.
The common-frame lemma is read and pinned; Lean is not run. The full original
supplier cold replay, physical global compiler, repair implementation and
bill, precision proof and all-size recursion are not run or claimed. The
unchanged centre-phase invoices are recorded for binding only: forward
176 ADD/8 COPY/16 CLEAR/8 rank-eight transports; backward 184 ADD/16 CLEAR/8
rank-eight transports. There is no changed profile to insert into a moment
or ceiling calculation.
