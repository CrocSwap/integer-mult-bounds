Read: B16 (flow/B16.NOTES.md), B33, R40-C, R39-H/C.7, B101, SYN-7 Lemmas 1-2. Run: one numpy rank check (cards/B3R/R.npy, <1 s). Literature (Kempe-Kleinberg-Kumar JCSS 2002; Akrida et al.) from memory, not fetched; only the known statement used (Menger fails for time-respecting vertex-disjoint paths, i.e. a temporal cut can be SMALLER than the max number of disjoint journeys). That is the direction that would help, so it was checked on the actual data.
## Checks
1. Rank is NOT time-independent in the loose sense, but the relevant numbers are (new, verified): for each of the 8 splits by R column j (56|56): rank G_AB = 7, rank G_AA = 7, rank G_BB = 8 (rank G = 8). So the 56|56 split saves one functional only for the cross pairs; the B x B odd pairs (25% of M) still need all 8 functionals, and 59|53 / 24|88 splits are no better for the large block.
2. A temporal 7+1 schedule is algebraically fine (G = sum of 8 rank-1 terms, delivery sequential), so Menger-failure is real here in principle. But the saving is not the simultaneous register count. B16/B15: centres = decoder terms, cst 64 = 8 x beta8, and -1 centre = +22.6% b comes from the per-call decoder mass. A time-shared 8th functional keeps 8 decoder terms (7 + 1 later), so the cst is unchanged. Saving = 0 on the invoice unless the 8th term has beta < 8 (B16's restricted-e8 escape, which this does not supply).
3. Cost side: the second pass needs a second descent epoch for the reused centre. R40-C: centre descent is cheap (one frame-rank step per word) but legal ONLY at the locked barrier node before B; a mid-B epoch is a new skeleton role (escape 2 of R40-C) or reader descents at -5.5% each per call (C.7). B101: a centre read is legal only for t = f_i (frame gate), so the pass-2 centre cannot read the ports at their final frames. Cost >= -5.5%/call per descent against a 0 saving.
4. Lemma 1/2 consequence: the second pass ADDs journeys through already-final port registers (G = U at 79% of ops), so by Lemma 2 it violates necessarily; this is B98c/B99/B100's failure again.
## Verdict
Priced split: saving 0% (cst/decoder terms unchanged, 8 functionals) vs descent cost >= 5.5%/call plus a skeleton change. Ratio undefined/infinite; no GO.
Residual (not killed): the saving appears only if the later rank-1 term can be a RESTRICTED e8 decoder term (beta < 8) on the BB block, i.e. B16's open escape; this card adds that the AA/AB side is rank 7, BB side rank 8, so the restriction would have to live on the B x B block.
TRANSFER: temporal cuts help register-count walls, not per-call decoder-mass walls; cst is charged per functional, so time-sharing buys nothing. BB-block rank 8 (verified) bounds any hyperplane split.
