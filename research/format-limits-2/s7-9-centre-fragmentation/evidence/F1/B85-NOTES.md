# B85: format-level lower bound on target fragmentation. VERDICT: KILL as a tight bound (PROVEN weak bound; skeleton-free bound = 0). ship=false
Tool: b85.py (single process, <2 min; reads B11 coarse.load of ck/jp8; no heavy job). Scope: SPEC + cap geometry (112 ports, cap in F2^9), psi(r)=r ln(73/r), frag = sum psi(steps) - psi(8) = 1342/call shipped (12.0 per target avg).
## Proven (rule-by-rule)
1. SPEC common frame + monotone frames: when operand o is added into t, both are at one frame F; o's frame afterwards contains F; any later direct target reader t' of o needs F inside perp(p_t'). Hence reader j of o (r = k-j+1 readers still pending incl. t) reads at dim <= 9 - rank(ports) <= 8 - ceil(log2 r) (cap: k ports span rank >= ceil(log2 k)+1). Only the LAST reader of o can read at dim 8; at most 2^(8-L) readers of o can read at dim >= L.
2. t's frame is monotone, so t's frame at every read is <= the read's ceiling. If t reads any operand as a non-last reader, its chain has a stop d <= 7 before 8, so frag(t) >= min_d [psi(d)+psi(8-d)] - psi(8) = psi(1)+psi(7)-psi(8) = **3.014 psi** (concave psi: cheapest stop is d=1; the ceiling then does not matter beyond "< 8"). Targets with ALL reads last-reader: frag 0.
3. Per-target statement: L(t) = 3.014 if t shares any direct operand with another target, else 0. Order-free over the direct-read graph of the shipped word (396 operands, 796 pairs; k_o in 1..5, targets read 5-10 operands; k_o max is 5, so every cap ceiling is >= 5): the all-last targets form an independent set in the "shares an operand" graph (degree 1..9, avg 4.9). Found packing 36 (B&B hit its 60 s limit; optimum not proven, so P>=36 and bound <= below).
   Bound: L <= 3.014 x (112 - 36) = 229 psi/call (if P=36 optimal; never above 3.014 x 112 = 338). ck and jp8 identical.
## Numbers
Shipped 1342 psi/call; bound <= 229 (<= 338 worst case); GAP >= 1004..1113 psi/call = 75-83% of target fragmentation; at the SYN-4 rate (1342 psi = +6.68% b, ~0.00498% b/psi) the bound is worth at most +1.1% b, gap up to +5.5% b. This is the same room SYN-4 found (one-jump +6.68%); the bound does not shrink it.
## Why it is loose, and what would close it (the card's kill clause)
- Skeleton-free: a private helper h_t per target (t reads only h_t, as its last reader) gives L = 0. SPEC alone cannot forbid it; the cost reappears as helper climbs (SYN-4: helper and target fragmentation are one currency). A skeleton-free target bound is therefore 0 and cannot be raised without a rule on helpers.
- Rule needed: a JOINT bound over all registers: the operand's frame floor (o's frame at the read contains every earlier reader's read frame; helper reading sources at common frame must climb to it) plus the fixed mass cover (deficit 2560 literal). Each ADD (o,t) forces dim(F) >= dim(span of o's earlier-read frames) and >= t's frame, so one ADD's cost is shared by two chains; a bound needs a global charging argument (per ADD, fragmentation >= f(common-frame rank jump)) not per-target.
- Also not used: actual port ranks (B80 c(o)=9-rank gives higher/lower ceilings but only matters for the L<8 test), floors of d>=2 (would raise 3.014 toward 11), forced extra stops from different operands' incompatible frames (B11: 77.5% transitive).
## Escapes / rescue (kill protocol)
1. Add floors: stop d >= dim of the operands' common frames (needs B76 provenance of each operand's frame) -> per-target bound up to ~11; unproven, would need the joint charging above.
2. Fix the helper count (no private helpers: e.g. R <= shipped 484) and bound targets+helpers together by ADD-charging.
3. Drop common-frame ADD (SPEC, not allowed).
Rescue check: replaced "last reader" by actual-rank ceilings 9-rank(ports of pending readers): readers with k<=5 pending still rank<=5<9, same L<8 test -> same 3.014/not-last result.
Proven vs argued: items 1-3 proven (scope: direct-read graph of ck/jp8, ports as in B11 load); P=36 packing is a found value (not optimal-proven); the 'private helper => 0' point is an argument from SPEC (nothing forbids it), not a built word.
