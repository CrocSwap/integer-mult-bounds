# Join the actual rational reference to ideal periodic compression

**Assumption progress through a source-specific interface theorem. No new
kappa.** The complete multiplication bound remains conditional.

The public Core/halo bridge, group scale ledger and actual remaining diagonal
produce a normalized approximation to a fixed rational Gaussian Reference H.
This package supplies the missing comparison with the **ideal periodic narrow
Gaussian N**, on the same original selected coordinates and holes, through the
final extraction and unchanged restoration exponent gamma.

## Result

The literal source certificate has

    delta = 1-adjacent_upper-5*distant_upper-epsilon.

It therefore also certifies the ideal inverse by
`||N^-1||<=1/(delta+epsilon)`. For one actual normalized group,

    xi = mu * sum_i epsilon_i/(delta_i+epsilon_i),
    mu = 2^(V-K) * product_i delta_i^-1 <= 1.

This pays the actual D diagonal and group normalizers. Across all groups,
the exact reference-versus-ideal contribution on initial radius R0 is at
most `R0 sum xi`, before final `2^gamma` restoration.

The actual `Reference.for_cap` radius/target allocation and actual diagonal
service leave enough room for this term at the **unchanged public Core t and
external q allocation**. The exact finite sufficient gate is

    mu_j * |G_j| * 2^U_j <= 2^42.

The concrete p^100 source normalizers satisfy a stronger bound below one.
Source targets and radii must be bound to the actual caller; a simple source-
first target rule avoids circular dependence on normalizers computed later
from the Reference. That rule can increase a source target by up to U_j over
the minimum Core target; it preserves the stated O(p) envelope, and it is
not a claim that every old frozen Reference already has the required target.
See [the full proof](PROOF.md) for every premise and the restored inequality.

The bounded T64/S61/p3 case executes the complete for_cap constructor and
checks all 4,096 Reference entries against 549 independently enclosed periodic
terms plus an infinite geometric tail. Its original holes are 11,32,53. Two
128-step fixed-grid Neumann diagnostics receive separate exact residual
certificates for H and for the full ideal N. Both solves use one named
64-component complex input x. On that input, the difference of the exact
inverse outputs is at most 2^-158; after D, its declared normalization and
extraction, the difference on that input is at most 2^-169. These are
input-specific bounds, not measurements of inverse operator norms. The old q41/Core target34 rule satisfies the combined conditional
2^-12 target, using a source target of35 and radius2.

This fixture uses the valid small-case bound v=2alpha^2, not the eventual
production v. It admits neither complete Core geometry nor the actual dense
native radius, and executes no physical Core or remaining diagonal. Radius2
checks only the new bridge-radius binding; the larger dense-radius contract
remains an inherited prerequisite. Finite residuals do not prove the universal
theorem; PROOF.md supplies that argument.

Also checked: 216 exact unchanged-budget fixtures and 30 concrete production
normalization gates. Ten controls distinguish underfunded source radius and
target, missing normalization slack, noncontracting diagonals, omitted period
wraps, invented hole coupling, an arbitrary wrapper without the needed slack,
deleted positive diagonal aliases, the wrong D/inverse order, and omitted
resolvent amplification. Four are actual admission rejections; the remaining
six are exact source or mathematical discriminators, not physical failure
injections. A separate lead AI implementation checked 144 rational tensor/
resolvent cases and 162 allocation cases; this is not human or formal-kernel
acceptance.

The first unbounded-fraction oracle attempt was stopped without a result.

## Full costs

The ideal matrix and inverse are proof objects; production never constructs
their dense tables. Source targets remain O(p), original positive weights
retain their O(p^2 log p) setup heights, and actual interval/constructor work
is charged. Full padded volume, dense/halo work, routes, actual diagonal stock,
scalar leaves, restored widths and live backing retain their public invoices.
The T/S<2 source admission is needed before comparing padded and extracted
volume. No same-reference proof converts unpaid setup into online work or
removes a physical service premise.
