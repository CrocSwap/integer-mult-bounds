## Exact parameter change and proof

Let a be the last exponent of the existing seven-step bootstrap, b the
existing certified complex endpoint, and eta=beta=10^-24. The retained
outer engine computes

```text
q = a(1-2 eta),
m = (1-eta)q/(1+q),
kappa_d = (ceil(m 10^d)-1) / 10^d.
```

The integer formula used in the source,
`(ticks.numerator-1)//ticks.denominator`, is exactly the largest integer
strictly below ticks, including when ticks is an integer. This chooses a
strict rational point, rather than rounding the real ceiling upward.

The same engine proves that m is the smallest of all seven workload margins.
The other forty strict constraints are independent of kappa. Every workload
condition is `margin-kappa>0`. Therefore the refined point preserves all
47 conditions whenever `kappa_d<m`, and all underlying invoices and
bootstrap premises are unchanged. This is the retained framework's exact
conditional asymptotic bound, under its inherited assumptions.

Only these three expressions in the frozen runtime assembly are changed:

```text
margin*10**18                         -> margin*10**24
ticks.denominator,10**18)             -> ticks.denominator,10**24)
k+Q(1,10**18)                        -> k+Q(1,10**24)
```

All other source bytes are retained. The specification changes only its
three derived kappa expectations and a portable path to a byte-identical
pivot recipe. The original archive contains an obsolete macOS absolute
path; the verifier copies the same SHA-256-pinned recipe and substitutes a
relative path. No owner, primitive, profile, prefix allowance or invoice
field is changed to obtain a pass.

The full output's only changes are kappa and its decimal, the conservative
kappa and its decimal, their outer slacks, and the two corresponding derived
gain fields. Both supplier moment tables, conservative moment table,
bootstrap lists, template hash, profiles, provider counts, source invoice
digests, deficit derivation, surcharges and model controls agree exactly.
The refined conservative witness is **0.001661960544831580991666**.

This is the last admissible 10^-24 point for these **fixed certified
endpoints, eta/beta and outer recipe**. It is not a real-root optimum, an
architecture-wide ceiling or a finer all-replica optimum theorem. PR942's
published all-T 10^-18 grid result remains valid on its stated grid.
