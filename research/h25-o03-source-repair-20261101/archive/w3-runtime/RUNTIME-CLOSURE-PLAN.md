## Why the historical runtime cannot be promoted

The preserved observer receipt has status STOP, reports `/usr/lib/locale/locale-archive` as an unsealed mapped file at both initial and closing checks, contains no worker result, and records zero reaped-child CPU. This establishes one observed missing dependency. It does not establish that this was the only missing dependency or that any worker/control/serializer/validator ran.

`RUNTIME-PINS-v2.json` calls itself `SOURCE_METADATA_ONLY_NOT_RUNTIME_ADMISSION`. Its 95 declared files, 16 allowed mapped paths, 24 preloads, builtin-zlib premise, selected callable descriptors and historical Python version are source declarations. `ELF-CLOSURE-v2.json` describes 17 files and explicitly makes no RPATH analysis claim; PT_INTERP/DT_NEEDED do not attest actual binding or dynamic loading. The old pin set also carries site-related paths although launch requires `-S`; these must be dispositioned from actual startup/source provenance instead of assumed active. No historical dev/inode/time metadata, consumed marker, ledger balance, deadline or host identity transfers to a new operation.

The old `closure()` checks mapping names against an allowed set and hashes the declared runtime files; it does not itself establish that each mapped device/inode is the same opened and hashed inode. The replacement specification requires mapping device/inode/offset evidence tied to authenticated regular descriptors, not pathname inclusion alone. Before/after checks assume a trusted host without hostile transient mutate-and-restore behavior; they do not prove the absence of that behavior.

Some dependencies are read without remaining mapped: startup bytecode, loader/OpenSSL configuration, locale message catalogues and other native data selected by the actual build. The acquisition specification therefore requires reviewed own-child file-access evidence from before interpreter startup, or an independently accepted source/configuration argument that closes those reads. Python audit events installed after startup and final maps alone cannot establish this. Any tracing tool needs its own pin, ordinary own-child tracing permission, bounded logs and charged overhead; an unavailable permission is a stop, not a reason to omit the dependency.

## Preserve intended locale semantics

The preferred policy retains the historical intended `LC_ALL=C.UTF-8`, `TZ=UTC`, empty outer environment, fixed PATH and isolated interpreter flags. A separately admitted acquisition must authenticate actual locale resolution, the archive if mapped, any separate locale-category files, gconv data/cache and any reached conversion modules, their metadata and bytes, and native libc/loader provenance. Capture actual effective locale/category names, codeset, filesystem encoding/errors, UTF-8 mode and startup coercion settings under the exact launch environment. Locale startup can precede target imports; acquiring only Python's `locale.py` or adding `locale-archive` to a list cannot close this route.

An alternative policy is a separate reviewed version. Examples are forcing the C locale while explicitly selecting Python UTF-8 mode/coercion settings, or selecting a sealed locale directory instead of the host archive. That changes startup locale resolution, libc category behavior and possibly text encodings, filesystem/surrogate behavior, diagnostics and timing punctuation; it can add/remove locale, gconv and environment dependencies. It needs a new source/launcher contract and fresh controls. W3 does not select an alternative or claim its equivalence.

## JSON, integer conversion and provider workspace

Authenticate the actual CPython executable and build, frozen/builtin providers, Python `json` implementation, `_json` native module, scanner/encoder/ASCII-escaping bindings, float representation/formatting and Unicode behavior. The candidate explicitly requires a C encoder. Hashing closure must include the actual SHA implementation and native linkage, including any build/provider-dependent OpenSSL configuration or module route if reachable. gzip reaches zlib decompression/CRC in loader/validator and compression in loader controls. A's built-in-zlib requirement is an old source premise; changing it to an extension provider requires an explicit reviewed source revision.

Decimal input travels through `json.loads`' default integer parser; output travels through C JSON integer representation; diagnostics/effective fingerprints can call `repr` or `str` on integers. Capture initial `sys.get_int_max_str_digits()`, startup digit-limit settings, `sys.int_info`, interpreter flags and relevant build configuration. Review the exact corresponding CPython integer/JSON source and distributor patches. Determine both successful and error paths, thresholds and compiled helper gates. If that build can call `_pylong` or decimal/native decimal support for large input/output, recursively authenticate those sources/providers and their imports, or provide a reviewed source-and-domain proof of unreachability. This is a provider possibility, not an observation that the intended build or authentic H25 reaches a particular helper. The published comparison sources mentioned in the audit are not actual build identity.

Finite warmup maps and a declared input cap do not prove branch closure. Controls deliberately reach wide/unlimited and conversion-error cases (`serialization_controls.py:155`; `frozen_input_controls.py:161`). Any helper preloading must be source-bound and reviewed before effective sealing. The auxiliary-space claim retains an explicit encoder/numeric-provider workspace term until W1 can discharge it for the authenticated build and domain; W3 does not infer workspace bounds from encoded output size.

`-B` suppresses bytecode writes; it does not by itself attest which cached bytecode may be read. Before admission, choose and review either a source-only staging/import mechanism or immutable authenticated bytecode plus source/build provenance. Record loaded origin, cached file identity or frozen authority and effective code under that policy. `-I -S` and an empty environment remain necessary declared startup controls; they do not replace import-custody evidence.

## Timing and acquisition boundary

W4's selected conditional contract is `O03_TIME_V3 ` with exact keys `wall_seconds`, `user_seconds`, `system_seconds`, `kernel_individual_maxrss_kib`, `utility_exit`. The proposed GNU time format uses `%e`, `%U`, `%S`, `%M`, `%x`, but current bytes/version/build and format semantics are unknown. Prefix selection, numeric lexical behavior, locale effects, units and rounding require actual provider source review. An independent launcher receipt binds raw SHA, admission, exact argv/environment/redirections, timed-child identity and corroborated exit/signal/timeout plus reap/accounting facts. `%x` alone is not signal/timeout evidence.

Historical timeout surrounds time and can kill the timer before it writes. Missing/truncated timing remains STOP. GNU time's child interval also excludes some env/timeout/time setup and closing work. Preserve the exact topology, state these endpoints and bill the finite outside work; a tagged record does not turn unknown physical costs into zero. The outer raw/record/report caps and grammar are W4's contract, not observations of a current utility.

`ACQUISITION-PROPOSAL.json` specifies a separate once-only discovery operation, tools, exact permission classes, numeric caps, output/custody contracts and admission fields. It proposes no target/control/authentic decoding or W5 execution. If any actual host identity, tool/source pin, ledger, required permission or cost guard is missing, do not acquire: retain this packet as preparation. Discovery evidence must undergo independent review and an additional frozen-manifest decision before later execution. No final runtime manifest can be written from the information available in this order.

All physical metadata, acquisition, sealing, final publication and unresolved tail costs remain `OPEN_NOT_ZERO`. The historical 94.550533479 policy-seconds record is not a refreshed ledger and grants no allowance. This packet preserves A's failed source/records and changes no original O03 denominator, frontier, scientific receipt or control result.
