Why this proves local substitution: both words are linear extensions of the
same shared-role dependency order. To transform one into the other, move its
first desired occurrence left across the occurrences preceding it. Any such
crossed occurrence must have disjoint logical support, or its shared-role order
would differ. The two complete logical actions commute, so the swap preserves
the exact map on arbitrary inputs. Repeat inductively. Applying this argument
separately in each phase gives the same complete phase map, hence the same state
and frame boundary at every phase cut, including private cleanup. This assumes
the retained complete-primitive semantics; it is not a new native compiler proof.
