# Bounded replay inspections

The touched Python paths contain no recursion. All enumeration is bounded by
256 residues, 120 roots, eight coordinates, 10,795 two-spaces and four affine
sections. The controls stop within 32,385 vector pairs. Every function stays
below 60 formatted physical lines. Acceptance uses explicit exceptions, not
assertions disabled by optimization. Source reads require regular files and
are bounded at 200,000 bytes. Invalid input and return failures propagate.
Controls write only to their own TemporaryDirectory and unlink owned links.
They never change a shared file's permissions.

The only shared writes are short locked Git and semantic-reservation
transactions outside the mathematical replay. Local values own the census,
temporary source copies and receipts. Receipt regeneration requires a new
explicit output path opened exclusively. No hidden solver, network request,
child process or asynchronous work occurs in the direct checkers.

Rule 3 deviation, Python managed allocation. Interpreter and Fraction objects
allocate during replay. Fixed eight-dimensional matrices, bounded byte reads,
10,795 plane keys and 5,440 equality lists of 36 labels bound retained data.
No input can increase those domains. Follow-up: use fixed native arrays only
if this tiny finite replay becomes a measured resource bottleneck.

Rule 8 uses source authentication followed by literal_eval of the sole SIMPLE
assignment. Neither checker executes predecessor functions or imports their
bytecode. Both independently reconstruct the pinned source's root/frame and
leading-one-label formula. Package-local runpy loads the current verify.py
source to share only authentication and explicit exception contracts in the
independent checker. It does not share geometry or census functions. The local
source loader is a bounded dynamic-loading deviation; the path is fixed inside
this package, with no search-path or configurable target. Follow-up: move the
small authentication contract to a plain data reader if package loading grows.

Rule 9 deviation, finite local callback controls. Rejection controls pass
explicit bounded closures to one exception checker. Each is a visible single
source or semantic mutant with no retained mutable state or external authority.
Follow-up: retain this boundary while extending controls.

Rule 10 uses warnings as errors, optimized controls, Ruff when available,
registered metadata/replay and exact committed-byte/export checks. No broad
repository diagnostics or historical suite is changed for this isolated
package. Exact commands and observed results are retained in CHECKS.json.
