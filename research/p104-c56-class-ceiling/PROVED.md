## What is NOT a Lean fact

`hJ : 4166 ≤ J.card` is a hypothesis. Its justification is the external Lagrangian certificate in `certificate/` (computer-certified outside Lean, exact rational arithmetic, two independent checkers). Lean does not model the C = 56 flag class and does not connect `J` to any word. The scope hypotheses of that class are these, and none is proved in Lean:

1. Rank-8 Y-plane rows with C = 56: the 8 chain pairs are one of 8 valid configurations (`certificate/data/f1cfgs.pkl`, exhaustive over 12,870 subsets in the source analysis); numerical rigidity of the row factorisation is quoted, not proved.
2. Monotone frame chains `<z'_k> = F_0 < ... < z_k^perp` with ANY step sizes. (Multi-dimensional steps are dominated by a complete refinement; this was proved in the audit, so it is not a hypothesis, but that proof is not in Lean either.)
3. One piece per gather and one piece per read, per chain: NO split gathers and NO split reads. This is a genuine hypothesis: with split gathers the dual bound fails for multi-chain cells, so 4166 does not follow; only the single-chain bound 1936 survives splits.
4. Plane separation: no second owned plane carries plane-1 X content.

The Lean theorem below is the same ceiling functional as `ceiling_native` with the junk count raised from 1936 to 4166; its other premises (`hcong`, `hdist`, `hspMono`, `hcstMono`, the spF / cst brackets) keep the status they have there.
