# Check paired-diagonal gauges before searching dyadic Borel words

An even denominator does not by itself put a word beyond PR2613's rank
obstruction. This package decides whether all applied matrices become
2-integral in one common analytic basis B=diag(D,D), D=diag(2^a_i).
It returns a checkable integer potential or a negative cycle. This is
complete for that paired-diagonal class, with no arbitrary-lattice claim.

The existing first-order theorem then applies without executing B as a
physical gate: it preserves n_I targets, scalar mixing, block-lower maps,
and every paid rational rank. The change is a usable obstruction filter
for the source's dyadic search handoff, not a new invariant or supplier.

## Evidence and boundaries

[PROOF.md](PROOF.md) gives the decision theorem and exact application to
Sagar Thakrar's PR2613 at `ea9b811636934a4e5a4a81c1b292619ba6d9f2c9`.
The general lattice method is already in eumemic's PR288; the rank
functional and related bounds retain the PR2613/P1 attribution.

The explicit positive word has two data roles, one arbitrary auxiliary,
four dyadic rank-one calls, full lower-Borel updates and free scalar XORs.
Its complete formal endpoint is diag(g,g,J), with g_HD=I and auxiliary
J=diag(2I,I). The gauge (0,1) makes all applied matrices integral, and the
reduced data block has rank four. This is a sharp four-call example with
genuinely dyadic paid and free matrices. The auxiliary is not restored;
its unconstrained output is part of the declared source model.

Three rejected fixtures retain the source half-frame and commutator, and
add an incompatible pair whose members are individually gaugeable. They
produce two negative self loops and one negative two-cycle. A separate
checker reads the original rational entries and validates the certificates
without importing the producer. Independent min-plus closure agrees on
4,352 finite graph controls: 2,022 feasible and 2,330 infeasible.

Controls distinguish invalid shortcuts: unrelated H/D scalings can clear
a half-frame while destroying the unit target; entrywise denominator
clearing can increase the paid rank; an integral even target still fails
unit admission. Source corruption, malformed potentials/cycles, an omitted
restore, receipt mutations and missing evidence are rejected.

The certificate consumes a complete list of applied matrices, including
every inverse actually used. It does not establish a proposed circuit's
endpoint, free/paid classification or physical legality. A negative cycle
means only that no common paired-diagonal gauge exists. It implies neither
a saving nor failure of other lattices or representations. No selected
supplier conversion, physical compiler, native cost or new kappa is claimed.

## Replay and interface

Python3.12, standard library only, from the repository root:

```sh
python3.12 -I -B scripts/research_package.py --package research/paired-diagonal-borel-gauge
python3.12 -I -O -B research/paired-diagonal-borel-gauge/verify.py
```

Default replay is read-only. `verify.py --emit` prints a fresh JSON receipt.
[RESULT.json](RESULT.json) contains all rational matrices, the literal
operation sequence, transformed matrices and certificates. The reusable
Python interfaces are `gauge.solve(m, matrices)` and
`check.check(m, matrices, certificate)`. Their results concern integrality
only; callers must separately supply the model and target premises.
`check.py` imports no producer or predecessor executable.

The exact source READMEs, proof and named scope-control code are retained
as data under `source/`; no predecessor executable is imported. SHA256 and
Git blobs in [SOURCES.json](SOURCES.json) bind those inputs and the retained
PR288 note. Git-free export tests run with an empty PATH and reject source
and receipt corruption. The written finite-graph proof, rather than the
4,352 examples, establishes completeness for arbitrary finite inputs.

Python dynamically allocates exact integers and rational matrices. The
default replay uses widths at most three and one fixed three-role word;
the API's O(mE) graph bound excludes integer bit costs and is not a
fixed-tape implementation claim.

## Revision5 expansion decision

This is a **narrow local analytic interface**, not a family expansion.
The initial revision4 draw was retained; after the checkpoint the branch
advanced to canonical `b4560d9e7216f72b73c5aa940ac099c05e33ccf9` and read
the revision5 family gate. The selected result is unchanged.

The consumer is a source-model candidate search: an admitted unit-target
word cannot save paid rank. The proved obligation is the exact gauge test
and transfer of the existing floor. Complete endpoint equality is required
from that consumer. A physical conversion, routing, hosting, precision and
all-size supplier invoice remain unknown and are not assigned zero cost.
There is no claimed saving to recoup through execution or cleanup.
The decision is **narrow**: finish this certificate/checker and independent
review, then stop. No larger census or general-lattice implementation is
authorized by its local success alone.
