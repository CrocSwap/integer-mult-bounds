# A minimum-decrement divisor for chronological widths

This contribution was produced by Nick Petalas. All integers below are exact.
The recurrence and its separated-flow properties are credited premises from
Jerry Chen / CubeJerry [#7424](https://github.com/CrocSwap/integer-mult-bounds/pull/7424),
head `d622d8c62defa9defeb95741e88b33a120044866`, PROOF.md sections 1–4.
That work extends #7345, codyw912 #4638 and Mihir Srivastava #4507/#5071.
The new step is the additive plateau visit bound and its width divisor.
No predecessor theorem is audited here.

## 1. Boundary and inherited recurrence

Fix positive integer target multiplicities W_k and paid-site multiplicities P_r,
with finite nonempty supports satisfying

```
2 <= k_min <= k <= m <= A,       1 <= r <= r_max < k_min.
```

Each occurrence of a paid site and each chronological path remains distinct.
Let Gamma be the multiplicative semigroup generated by target and paid ranks,
including 1. Write gamma_next for the successor of gamma in Gamma. It exists
because k_min*gamma is in Gamma. For n < A let B_n=1. At n >= A the credited
flow supplies fresh-source multiplicities t_s > 0, their total S=sum_s t_s,
and a nonempty list of individual exit ranks e. Its least replication is

```
a_n = lcm( {B_(n-s)/gcd(B_(n-s),t_s): s<n}
           union {B_e: each individual exit} ),
B_n = S*a_n.
```

Sources with s=n have no complement. A source multiplicity groups only
identical-rank fresh sources, before complement consumption. Equal-rank exits
remain separate chronological cuts: their repetition count never divides B_e.
The construction's source, exit and unit censuses are constant on

```
A*gamma <= n <= A*gamma_next - 1.
```

Every source rank s belongs to Gamma, satisfies s>gamma and s<=A*gamma,
and hence s>=gamma_next. These properties follow from the credited fresh-source
floor s>n/A and the product form of source ranks, evaluated at the plateau's
first rank. Every exit has

```
e <= r_max*k_min^G <= r_max*gamma < A*gamma,
```

where G=floor(log_(k_min) gamma). Thus every paid exit leaves this plateau.
These statements specify the exact application boundary of the theorem.

## 2. New visit bound

Fix a maximum N>=A and an observed plateau gamma<=floor(N/A). Put

```
L_gamma = A*gamma,
U_gamma = min(N, A*gamma_next - 1),
delta_gamma = min{s: t_s>0},
nu_gamma = 1 + floor((U_gamma-L_gamma)/delta_gamma).
```

Consider any directed recursive rank chain starting at a rank <=N. Every edge
strictly decreases its rank, so its visits to one plateau are contiguous. An
edge that remains on that plateau cannot be an exit. It must be a complement
n -> n-s, which decreases rank by at least delta_gamma. If the chain visits
this plateau v times, its first and last such ranks differ by at least
(v-1)*delta_gamma, and by at most U_gamma-L_gamma. Therefore

```
v <= nu_gamma.
```

There is no logarithmic estimate or real-power rounding in this argument.
This visit bound is attained in the numerical recurrence: start at U_gamma
and repeatedly take the positive-count complement with s=delta_gamma until
it leaves the plateau. All intermediate ranks lie in [L_gamma,U_gamma], where
the source census is unchanged. If this process takes another edge while
remaining in the plateau then its child is positive, so that complement exists.
Thus the actual maximum number of visits is exactly nu_gamma.

A useful uniform consequence is

```
nu_gamma <= ceil(A*(gamma_next-gamma)/delta_gamma)
         <= ceil(A - A*gamma/gamma_next)
         <= A-1.
```

The last inequality uses gamma_next<=k_min*gamma<=A*gamma. This also shows
nu_gamma is always smaller than the previous common visit exponent
`tau=A*ceil(log2 k_min)`, which is at least A. Truncating the last plateau
can improve it further. In particular the minimum with the inherited tau,
proposed in the advance claim, equals nu_gamma on this application boundary.

## 3. New all-prime divisor

For any prime p, including a prime absent from the rank alphabet, the LCM
recurrence gives

```
v_p(B_n) <= v_p(S_n) + max_child v_p(B_child).
```

The gcd can only lower a complement child's valuation. Follow a maximizing
child until a base rank is reached. Strict descent makes this finite. The
resulting sum has at most nu_gamma copies of v_p(S(gamma)) on each observed
plateau. The maximizing chain can depend on p; the visit bound holds for all
chains, so no common maximizing chain is needed. Therefore, simultaneously
for every 1<=n<=N,

```
B_n divides Q_new(N) = product_(gamma<=floor(N/A)) S(gamma)^nu_gamma.
```

Moreover

```
Q_new(N) divides Q_old(N) = product_(gamma<=floor(N/A)) S(gamma)^tau.
```

Every exponent is lower. Divisibility is strict whenever at least one observed
plateau has S(gamma)>1. Replacing tau by nu_gamma also tightens the explicit
bit envelope to `log2 B_n <= sum_gamma nu_gamma*log2 S(gamma)`; this does not
assert a lower asymptotic degree or change the width sequence.

The argument is also a self-contained lemma for any integer width recurrence
with the same constant-plateau census, complement steps, below-plateau exits
and unit base widths. Physical native semantics are not needed for that lemma.

## 4. A sharp first-plateau instance

Take targets (2,3), one paid rank-1 site, A>=3 and A<=N<2A. Then gamma=1,
gamma_next=2, t_2=t_3=1, S=2, delta=2 and the individual exit is e=1.
The new divisor is

```
Q_new(N) = 2^(1+floor((N-A)/2)),
Q_old(N) = 2^A.
```

Jerry Chen's #7424 already gives the width formula
`B_n=2^(1+floor((n-A)/2))` on this plateau. We cite that formula as a premise;
it is not the new result. Our divisor attains it exactly at N, so its exponent
cannot be decreased even by one. At A=64, N=127 the upper divisor changes
from 2^64 to the attained 2^32. The source's quadratic explicit-output
obstruction still applies; the smaller divisor does not remove it.

The uniform A-1 visit constant is sharp as well: two target roles of rank A
and one paid rank-1 site have their first plateau [A,A^2-1], with delta=A,
S=2 and exactly A-1 visits. This follows directly by taking successive
rank-A complements. No physical supplier for either toy rule is asserted.

## 5. Evidence and limits

The standard-library checker expands small productive words and paid paths,
then constructs only the exact width recurrence and directed child graph. It
checks the new divisor, its divisibility into the old divisor, actual longest
plateau visits by a separate graph dynamic program, and attaining truncated
plateaus. It imports no predecessor program and runs no predecessor suite.
Finite enumeration corroborates the new theorem; it is not an all-rank proof.

The result assumes the stated separated numerical compiler and its credited
flow. It supplies no actual selected manifest, complete instruction stream,
new batching policy, native realization, owner erasure, precision/tape bound,
analytic recovery or multiplication theorem. All five selected assumptions
remain. Independent human and formal proof-kernel review are unclaimed.
