## 1. Where the single unpaid coordinate comes from

`verify.py` checks on the pinned bytes:

  k = 2,…,8, and 224 of rank 73 = 1 + 8·9. That is 2·V·p = 3,584 main targets, with

- Every arm target 1 + 8k has a paid whole-idle of rank exactly 8k with the same
  multiplicity. The long targets are covered by the 18 native calls.
- The rank-one surplus is `752 = 18·(H_1 - P_1 + V + 2VB) - V`, with H_1 = 3,471,
  P_1 = 5,327 and B = 8.

The extra coordinate in each main target is the central Gaussian line `Q = C_q`, with
`q ∈ F2^9` the port's odd vector (`kappa-hybrid-controller/NATIVE.md` §2). The Laurent
controller has diagonal targets `D·Q^{±1}` (central exponent ±1, PR4470 PROOF §4). The
paid idles carry only the D blocks. In this interface the old #1094 coverage identity
`mass = 72W + 64N` and `ceiling.ceiling(unpaid=…)` do not apply. The replacement
identity is the one above: one central credit per main target.

## 2. The changed contract: substitution Q → Q_a Q_b

Let `q_b` be a fresh spectator axis of every main field and `Q_b = C_{q_b}`. The PR4440
factorization is an identity in the commutative Laurent ring generated by `Q, D_0, …`.
The map `Q ↦ Q_a Q_b` (with `Q_a = C_q`) is a ring homomorphism into a commutative
algebra, because operators on disjoint axes commute. So the substituted word is again an
exact controller, and every main target becomes `D·Q_a^{±1} Q_b^{±1}`. These are **two
unpaid coordinates per main family**, the card's object.

`C_{q_a} C_{q_b}` is a rank-2 Gaussian request (kernel support spans {q_a, q_b}). Its
inverse is `X_{q_a} X_{q_b} C_{q_a} C_{q_b}`, because `C_q^{-1} = X_q C_q`.

The fully charged realizations considered are:

1. **Thin shears.** The 15 query shears per port become rank-2 requests (+1 rank each).
2. **Native contacts by conjugation.** With `Δ = diag(1, Q_b)` on the stage's (X, Y)
   pair,
   `D_s S_y(Q_a^{-1} Q_b^{-1}) = Δ^{-1} (D_s S_y(Q_a^{-1})) Δ` and
   `S_x(-Q_a Q_b) = Δ^{-1} S_x(-Q_a) Δ`.
   So each unchanged native call plus two rank-one `q_b` requests per port realizes the
   substituted native stage.
3. **Optimistic relaxation.** Item 1 with native calls unchanged and free. This is a
   screen, not a realization.

## 3. Credit-rank lemma

Work over the field `K = F(x)[Q_b]/(Q_b^2 - x)`. Here F is the rational function field
in all other symbols, and x stands for the translation `X_{q_b}`. Let `σ` be the
Galois automorphism `Q_b ↦ -Q_b`. It fixes x, so it fixes `X_{q_b} = Q_b^2` and every
`Q_b`-free operator.

**Lemma.** Let `W = F_1 ⋯ F_m` be a program of square matrices over K. Every column is
a physical field, including helpers and copies. Suppose its productive block, between
`σ`-fixed boundary programs, is monomial with entries `u_i Q_b^{e_i}`, where each `u_i` is
`σ`-fixed. Then

    #{i : e_i odd} ≤ Σ_j rank(σ(F_j) - F_j).

*Proof.* `σ(W) - W = Σ_j σ(F_1)⋯σ(F_{j-1}) (σ(F_j) - F_j) F_{j+1}⋯F_m`, so its rank is at
most the right side. A submatrix and a product with fixed invertible boundary matrices do
not increase rank. For the monomial target, `σ(T) - T = Π·diag(((-1)^{e_i} - 1) u_i Q_b^{e_i})`,
whose rank is the number of odd `e_i`. ∎

**Premise (P).** A factor is `σ`-fixed unless it is a paid Gaussian request on one field
whose effective active span contains `q_b`. Scalar operations, copies, adds, routes fixing
`q_b` and the translation `X_{q_b}` are `σ`-fixed. A request on one field is a diagonal
factor, so `rank(σ(F) - F) ≤ 1`. A request inside a native call is counted
individually; the native is a product of its operations.

Under (P), **c credited targets require at least c paid requests containing q_b**. In the
substitution contract, c = 3,584. The 15·112 = 1,680 thin shears supply at most 1,680, so
the native stages must contain at least **1,904 q_b-touching requests** (≈105.8 per
native call). The formal and literal instances in `verify.py` show both cases: the
substituted three-shear word has 3 terms for 2 credits; the gauge realization has 2 terms
for 2 credits, so the bound is tight there. A pure gauge on a diagonal target yields zero
credits.

## 4. Obstruction for incremental full-credit realizations

**Incremental premise (I).** Relative to the selected invoice, the realization keeps
every productive field. It adds `q_b` to targets only, so each main target R becomes R + 1.
It keeps every selected paid request. Each `q_b`-touching request is either an existing
selected request enlarged by `q_b` (rank r → r + 1, at most once per request) or an
additional request of rank ≥ 1. Further costs only add paid work.

Put `g(x) = (x+1)^t - x^t = ∫_x^{x+1} t y^{t-1} dy`. For `0 < t < 1` it is strictly
decreasing, with `g(0) = 1`. An additional request of rank r' costs `r'^t ≥ 1 ≥ g(x)` for
every x ≥ 0.

**Theorem.** Under (P) and (I), if every one of the 3,584 main targets is credited (two
unpaid coordinates per live main family), then `S_new(C) < S(C)` for every `0 < C < 1`.
At C = 0 the gain is exactly repaid at best.

*Proof.* The gain is `Σ_main g(R_i)`. By the lemma, at least 3,584 distinct q_b-touching
requests are charged. Their cost is at least the sum of g over the 3,584 largest selected
paid ranks; additional requests cost at least 1. `verify.py` checks exactly that the
sorted main targets dominate these paid ranks elementwise. The pairs are
145↔72, 73↔64, 65↔64, …, 17↔8 or 5, and every target is larger. Since g is strictly
decreasing, the gain is strictly below the cost. ∎

So the fixed-invoice root of any such realization is strictly below the selected root.
The selected package certifies that `S` decreases through C = 1/20 and is negative beyond
it; this is inherited. `verify.py` also encloses the net change at three points
(selected root: ≤ −2.285).

The conjugation realization is one instance: its rank-one surplus is
`752 + 3584 - 1680 - 4032 = -1376`. It is negative already at C = 0.

## 5. Partial credits: an explicit ceiling

When only a subset of main families gets the second coordinate, dominance can fail. Small
targets (17) can be paired with large idles (72). The verifier rejects that case as a
mutation control. For any credited subset of main targets, of size c,

    S_new(C) ≤ S(C) + max_c [ Σ_{c smallest main targets} g(R) - Σ_{c largest paid ranks} g(r) ].

The second term is computed with outward intervals as a best prefix; 1,568 pairs have
R < r. At the selected root it is at most 3.67. Bisection on a 1e-9 grid certifies that the
right side is negative at **C = 0.003035069**. No partial-credit incremental
realization certifies that saving, a ceiling of +0.49% over the selected root.

This is a pointwise certificate at the stated point; the bisection's other points are
sign checks. Credits on helper targets are outside this scope: they change helper
residual frames, which is the helper-retiming mechanism, not a coverage law.

## 6. What is left open: the native allowance

In the optimistic relaxation (§2.3) the root is enclosed in
`(0.01023582, 0.010235821)`, 3.39× the selected root. So the relaxation passes, and
only the native charge decides the contract. Adding E rank-one paid units keeps a
positive surplus at the selected root's upper end exactly for **E ≤ 1,859**
(103.28 per native call; E = 1,860 fails). The lemma forces at least 1,904 q_b-touching
requests in the native stages. Paying each one as a separate rank-one request
therefore loses; the conjugation contract pays 4,032.

By §4, enlarging the selected native requests does not help either. **The only
route left open under (P) is a redesigned native word on the enlarged central block.**
Its own complete local profile must change, and its moment must beat the selected
`H_t - P_t` after it realizes ≥ 1,904/18 central-q_b contacts per call. No such word
is constructed here.

## 7. Small complete instance

`verify.py` replays:

- **Formal (Laurent polynomials in Q_a, Q_b, D).** The one- and two-central three-shear
  identities; the native and back-shear conjugations; the gauge realization; the
  credit-rank counts; and the diagonal-target zero-credit case.
- **Literal (Gaussian-rational kernels on F2^3, axes q_a, q_b, d).** `C_q^2 = X_q`,
  `C_q^{-1} = X_q C_q` and Fourier ranks 1 and 2. It runs six arbitrary dirty input pairs
  (X, Y) through the substituted swap word and through the conjugated native-shaped
  factor, and compares them with the declared targets.

The literal algebra has `C_q ∈ span{1, X_q}`, so `σ` is not an automorphism there. The
lemma is a statement about the formal Laurent model in which the controller is
factorized; this is recorded as a modelling premise.
