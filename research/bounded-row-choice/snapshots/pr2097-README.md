# Fresh row fibers in the selected stopped cover

**A conditional all-depth address theorem and adversarial audit; no new κ.**
A large enough row reserve and a restored row endpoint are not, by themselves,
enough to justify per-edge bad-class averaging. This package proves the missing
counting implication under the inherited **fresh-field** contract, maps that
contract to the selected bit producer's source, and gives exact counterexamples
when either invocation predictability or complete padded execution is removed.
It does not assert that the selected compiler violates either condition.

## One-padding conditional-fiber theorem

Fix integers `W>=2`, `D>=1`, and a genuine row range `Q>=S=W^D`. Let

```
T = ceil(Q/S),       P = T*S.
```

Pad **once**, from `[Q]` to `[P]`, and execute over the entire padded range.
Euclidean division is a bijection

```
[P] <-> [T] × [W]^D,
x = (((t*W + r_0)*W + r_1)*W + ...)*W + r_(D-1).
```

At depth `j`, the slab `t` and fields `r_0,...,r_(j-1)` are ancestors,
`r_j` is current, and the remaining fields are unused stock. The exact
hypotheses at every invocation boundary are:

1. The decision that this invocation exists, its width, its fixed edge list and
   its weights depend only on its ancestors (and fixed program indices), not on
   current/future row fields or data. An ancestor-dependent union of cylinders
   is allowed. A child selected by a parent's current residue satisfies this
   rule because that field has become a child ancestor.
2. Each current-role route fixes ancestors and unused stock and acts as a
   permutation of `[W]` depending only on ancestors. In particular, no unused
   stock value selects that permutation.
3. Calls have depth at most `D`; a completed child restores its supplied row
   field and preserves ancestor spectators before a sequential sibling uses
   it. The ordinary leaf may borrow internally under its own completed contract.
4. The padded rows are not pruned by the genuine/dummy flag during execution.
   Only a completed row-restoring endpoint restricts back to `[Q]`.

**Conclusion.** Every live invocation domain is a disjoint union of complete
suffix cylinders. On fixing one ancestor prefix, each value of its current
role occurs exactly `W^(D-j-1)` times. Every low type in an equal-fiber
partition of that current role has its stated uniform frequency. There is
no per-recursion padding factor: `Q <= P < Q+S <= 2Q`, with `P<2Q` also when
`Q=S`. The original genuine range is invariant at the completed endpoint.

**Proof.** The root is a full product by Euclidean division. Suppose the claim
holds at a node. Hypothesis 1 selects entire ancestor cylinders, never a
proper subset of the fresh suffix. Hypothesis 2 permutes the current factor
and fixes all later factors, so preserves the full suffix product and its
counting measure. At a child boundary, fixing the parent's current field
merely fixes one more prefix coordinate; every later factor remains complete.
This proves the assertion by induction to depth `D`, including prefix-dependent
stopping and fallback. Hypothesis 3 restores the child row before reuse, so
sequential siblings start with the same product rather than consuming or
multiplying the reserve. The two ordinary-body calls likewise reuse it.
For padding, `ceil(Q/S)<Q/S+1` gives `P<Q+S<=2Q`; if equality `Q=S` is used
in the last comparison, actually `P=Q`. At the completed outer endpoint every
row coordinate is fixed, so the subset `x<Q` is preserved and padding can be
removed. This last argument does **not** assert that `[Q]` was a complete-fiber
execution domain at intermediate cuts. ∎

This is an address-counting proof, not an assumption that arbitrary program
maps preserve a uniform random distribution. There is no random input model.
The volume is counted over complete address fibers, including padded rows.

## Selected low-residue averaging and full unchanged bill

For the selected cover, use

```
W(w) = 28425 * |GL_64(Z/q^w Z)|,
|GL_64(Z/q^w Z)| = |GL_64(F_q)| * q^(4096*(w-1)).
```

Every lift `g0+qG1` of an invertible low matrix is invertible, and an invertible
matrix reduces to an invertible low matrix (determinant is a unit iff its
reduction is nonzero). Thus each low matrix has exactly `q^(4096*(w-1))`
lifts. Right multiplication by an invertible route is a bijection on the
whole group and on low classes, so it preserves this equal-fiber statement.
The role factor `28425` is independent and cancels. These statements hold for
**every eligible prime q and every w>=1**, not just the small test rings.

Fix an odd prime `q>2^80` before choosing input widths, avoiding the fixed
rational denominators and rank witnesses of the selected geometry, as required
by the inherited cover contract. This is what **eligible** means here; the
finite profile alone does not certify that prime-selection contract. Fix any
invocation's ancestor prefix and any one of its edge occurrences. The source's
bad-minor set then has fraction at most `b=2*64^3/q < 10^-16`.
By the theorem, this remains its frequency at the invocation. Sum costs over
edge occurrences and then ancestor prefixes. Linearity of a finite sum, not
independence of bad events, gives the surcharge. There is no need to bound the
probability that *some* edge fails, and no simultaneous union bound. Arbitrary
correlation between the bad sets of two fixed edges is harmless.

With selected histogram `H`, `E=sum_r H_r`, `L=28416` and exponent `a`, retain
exactly the selected conservative charge

```
(1/L) * sum_r H_r*(r/64)^(1-a)
  + (1/10^16) * (32*64^2) * E/L * (1/64)^(1-a).
```

Every good term stays charged; no displaced-good subtraction is taken. One
outer factor `P/Q<2` is a volume constant, **not** a factor inserted into the
characteristic moment at each level. This audit derives neither a new endpoint
nor a new reserve coefficient. The first-stage fit envelope, H2 time bound,

## Two failures that row restoration cannot detect

**Current-field adaptive edge choice.** Over `GL_2(F_q)`, index edge predicates
by the `q+1` projective lines `[v]` and let `B_v={g : first_row(g)·v=0}`.
Every fixed `B_v` has fraction `1/(q+1)`: each nonzero first row has exactly one
kernel line, and invertible change of basis permutes the line fibers. Choose
`v` to be the kernel of the **current** first row. The selected edge is then
bad on every matrix. Identity routing and the identity final row map remain
legal bijections; the sole missing hypothesis is that the edge choice be fixed
before reading that invocation's current role. This is a linear-minor example,
not an arbitrary rare-set oracle. It does not allege such a choice in PR589.

**Skipping dummy rows.** Take `W=3`, `D=2`, `S=9`, `Q=10`, `P=18`. The complete
padded slab `t=1` has three values of `r_0`, each with three values of `r_1`.
In the genuine prefix `[10]`, the cylinder `(t,r_0)=(1,0)` contains only
`r_1=0`. The event `r_1=0` has conditional frequency one rather than one third.
All routes can be identity and the final row map can restore every row. Thus
endpoint restoration justifies **unpadding**, not pruning intermediate
invocations. The package checks these two failures separately.

## Open next questions

1. **Emit the selected all-size field-dependency certificate.** The concrete
   remaining obligation is that every call guard/edge-list/weight read set is
   contained in its ancestor fields and every route fixes unused descendant
   fields. Start from the child-weight formula and the current chart route,
   then annotate the selected emitter's all-size lowering. This is blocked by
   that lowering remaining an inherited contract rather than an emitted
   address-level artifact; stock magnitude and scalar endpoint checks cannot
   substitute for it.
2. **Admit a deliberately adaptive selector only with its new charge.** If a
   changed controller chooses an edge after reading current low residues,
   compute the fiberwise sum of its chosen bad indicators instead of reusing
   the fixed-edge average. Start with a finite partition of low classes. The
   obstacle is a favorable fully paid bound, not the mere existence of a
   row-restoring permutation. This result supplies no such improved selector.
