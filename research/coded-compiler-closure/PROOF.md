
`L(n) <= n^t (1+log2 n)^140` for integer n>=1 under its stated compiler
premises. This is a normalized recursive leaf-count bound, not a full running
time or precision/storage bound. The source induction uses no unknown
multiplicative constant in this particular majorant.

The desired uniform saving is `C-d`, with `d=1/700000000`. On the grid
`H=700000000 j`, the sufficient integer-height comparison is

```

```

j=5866 fails. Exact integer arithmetic establishes both comparisons. The
