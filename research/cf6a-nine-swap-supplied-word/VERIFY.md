# Verification versions and optional enlarged grid

Use the direct or registered commands in README.md. The original portable package has run on Mac CPython 3.9.6 and independently on Linux CPython 3.12.14. INDEPENDENT-REVIEW.json binds the original archive. Scientific engines, verify.py and current run_verification.py are unchanged here.

The original R3 Mac and independent Linux logs remain in the private archive/review workspace. EVIDENCE-SUMMARY.json is a labelled derivative, not a rewritten historical transcript. The no-resource-cap R3 direct runner is retained unchanged.

Optional enlarged-grid replay, not part of the newly executed standard suite:

    python3 -I -B verify.py --mode finite --grid 21233664000

The direct runner imposes no arbitrary Mac resource limits; registered CI has standard repository timeout rules. No constructor regeneration, universal rounded-caller proof or full upstream original-checker success is claimed.

The original R3 VERIFY.md named PASS_SCOPED_SUPPLIED_WORD_AND_INVOICE_CHECKS; the actual unchanged runner emits PASS_ALL_SCOPED_VERIFICATION. This integration corrects that documentation-only marker mismatch.
