# Ten common-map queries with restored mutable sources

**Scoped recursive-interface construction and sharp paired-readout query bound;
no new kappa.** Temporarily mixing five source rows by paid XORs permits all
31 nonzero output patterns using **10 common-map queries, 62 readouts and 12
source XORs**, restoring every source and arbitrary dirty scratch. In the
read-only-source interface, the two PR943 repairs instead use 12 queries/62
readouts or 10 queries/64 readouts. Both earlier repairs are replayed here.

The changed premise is explicit: every source uses the **same exact linear B**,
and source rows may be changed temporarily. The target is
`y_m += A_m B(sum_{j in m} x_j)` over F2. The A_m and B need not commute or be
invertible. Sources and outputs cannot be externally observed during the batch.
All source changes, recursive children, inverses and dispatch are paid.

Ten is the minimum common-map query count when every output is read exactly
twice, even allowing arbitrarily many source shears. A linear-coordinate
normalization reduces the nine-query exclusion to **2,600** point sets in F2^5;
none has full difference cover. A separate integer Walsh-autocorrelation census
agrees with the direct pair-set checker. [PROOF.md](PROOF.md) gives the reduction,
all-size identity, complete price criterion, implementation and limitations.

With five factors per map, the literal recursive word uses **2,016 arbitrary-map
leaf calls plus 12 identity-row XORs**, versus 2,072 leaf calls for either old
repair, with four borrowed dirty rows in each case. Every child inverse and
internal node is included. A declared positive tariff including internal nodes
and root dispatch gives **2,760 versus 2,812** units. This is an abstract complete
price fixture; no favorable physical tariff, practical speedup or supplier
instantiation is claimed. In general the gain requires the fully priced source
XORs and extra root instructions to cost less than the two avoided map calls.

## Open next questions

The useful next task is to identify a real supplier boundary with a common exact
B, temporarily owned source rows and an actual favorable tariff. First locate
two original calls sharing B, check their frame/source-access contract, then
price a single source XOR with all routing, precision and restoration. If source
immutability is mandatory or the price inequality fails, stop that adoption
attempt. No such selected-supplier instance is established here.

The sharp minimum number of source XORs for ten queries is also unproved; twelve
is only an attained count. It matters only if actual map/XOR prices make this
boundary competitive. A small finite synthesis with complete source-basis and
connector states would be a first step; no search-completeness claim is made.
