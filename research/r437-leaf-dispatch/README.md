# R437 root-produced child to leaf: scoped coefficient chronology audit

**A finite source-bound metadata certificate, not complete leaf payload execution.**
Starting with the actual 2048→64 capsule from the PR4732/4741 route, this package
executes the unchanged `Machine.block` at the next rank-2 block. It takes the
below-cutoff leaf branch, generates the actual width-2 leaf trace, and evaluates
all **12 prescribed split/merge coefficient requests** with the unchanged
Callback/`children.coefficient` machinery. Every request creates, checks and
erases an actual second-STEP Program with widths **2048→64→2** and depths 0→1→2.

The packet interpreter is explicitly replaced by a **metadata observer**. The
observer calls the actual coefficient closure supplied by `Machine.block`; it
does not execute atom swaps, signs, split/merge payload loops or the whole
parent node. The source payload is empty. No physical cost, numerical admission,
all-input theorem or new κ is claimed.

## Exact executable boundary

The fixture uses paid R437 D SOURCE87 request 1676 (`MOVE,0,0,22397`), rank 2,
root unit 2, q=7/w=1 and conservative K^7 stock. The original semantic root entry,
root prefix, real binary-Count quotient and `Machine.prepare_child` produce the
2048→64 capsule. The disclosed PR4176 three-power `child_extents` adapter is
used for that predecessor geometry. It preserves the actual eight capsule
ports and returned modulus/width/depth grants.

The exact grants enter `Machine.new_context`. As in PR4741, the first 15
unchanged top-level `Machine.node` AST statements run through the stock guard,
returning coefficient 2, inherited rows R/A and local unused R/A². The original
root source and field/precision are retained. Count normalization changes
padded before/gap/suffix representations while preserving their values/heads.

Then `directory.produce` constructs the complete w1 next directory from the
actual old directory. It has one prefix with two chronological fields. Actual
`Machine.geometry` and `Machine.block` generate a leaf at positions 0,126,
width 2, depth 2. `prepare_child` and internal `call` are forbidden controls at
this boundary; the real block returns false. No extra fresh-row quotient occurs.

The observer consumes the original 18-event trace (enter, eight primitive
events per coordinate, return). Each ADD yields two coefficient visits, labelled
split then merge. This multiplicity is checked against authenticated
`stream.add_pass`: its two top-level calls are `traverse(False)` and
`traverse(True)`; each starts with one `prepare_coefficient()` before any payload
loop. The chronology is for a **successfully completing** primitive pass.
The source validates complete input between traversals, so malformed payload
can abort before merge; the observer does not establish successful payload
execution or remove that guard.

For each request the real `children.extend` appends the second STEP and the real
leaf Callback validates it against both source fields. An observation wrapper
records the resulting root/STEP after the producer returns and observes its
clear; it supplies no decoded value to the algorithm. The inherited root unit 2
and identity preparation pivots give coefficient 2. The negative inverse is
`-2^-1 mod 7 = 3`. Values are `[2,2,3,3,2,2]` for each of coordinates 0 and 1.
The same generated Program bytes occur all 12 times, and every temporary
Program is erased. Each positive coefficient call restores numerical live sets
and borrowed Program/prefix bytes and heads. All five inherited Count values
remain unchanged through leaf dispatch; no general exception-cleanup claim is
made.

Three actual Callback controls reject coordinate 2, a changed generated second
STEP rank, and a changed current-field source code. They are deliberate test
mutations, not alleged producer outputs. RESULT.json records exact values and
errors. The full parent payload, node peel/restoration and complete packet
execution remain outside the tested boundary.
