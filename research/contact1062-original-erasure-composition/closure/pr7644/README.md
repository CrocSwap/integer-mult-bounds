an assertion-enabled POSIX process. The registered application uses local
scratch and runs its native and signed engines sequentially. All original
source and replay inputs are included. No additional checkout is required.

```sh
python3.12 -B scripts/research_package.py --package research/chart1062-original-erasures
```

For a quick replay of the original source inventory and literal edit, run


hash. The complete replay checks the scientific predicates and the final
