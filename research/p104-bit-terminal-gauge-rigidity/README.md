# Prove rigidity of the released-terminal P104 BIT scalar gauges

All 32 idle masks and 38 terminal gauges are free while the existing gate equations and input are fixed.

The anchored equality graph has rank 70, and a separate expanded graph verifies rigidity.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `06070e89f6d64469ae0f81ef59a00493a02bf397232c07f300d9eee88a9e1b17`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run python3 -I -B check.py.
