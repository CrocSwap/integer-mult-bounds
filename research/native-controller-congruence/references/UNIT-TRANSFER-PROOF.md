# Eight-row identity transfers with a full-query source code

The historical complex supplier has a local backward content map
`(x,y,h,c) -> (x-Jy,y,h,0)`, where `J=I-KR`. This construction changes
that map to `(x-y,Gy,h,0)`. It stores the original full centre query in
eight selected source fields. A forward companion gives
`(G^-1x,y+G^-1x,h,0)`.

Each complete word restores all 480 arbitrary helpers. It adds eight
rank-one native children, 16 address maps, and no array field. Its scalar
allowance is 217898 real primitives per array coordinate. The source code
has order six in one fixed chart. The complete supplier and kappa bound
are unchanged: routed composition, source removal, and the full recursive
invoice remain open.

## An ordered-ring construction

Work over a unital ring. All products have the stated order. Let R have
r rows and n columns, and let K have n rows and r columns. Suppose
supplied maps P and L satisfy

```text
RP=I,  LP=0,  LK=I.
```

Set `M=RK`, `J=I-KR`, and

```text
Z=K-P(M-I),  Q=R-L.
```

Then `RZ=LZ=QP=I`, `QZ=0`, and `JZ=-P(M-I)`. Define

```text
G=(I-PL)(I+ZQ)=I+ZQ-PR,
G^-1=(I-ZQ)(I+PL)=I+PL-ZR.
```

Both factors are units: `(PL)^2=(ZQ)^2=0`. Direct multiplication gives

```text
LG=R,  RG=Q,
C=JG-I=-P[R+(M-I)Q].                         (1)
```

Thus C has support only on the support rows of P. No inverse of M or
M-I occurs. The construction does not require M to be scalar or central.

For any source y, put `u=Qy`, `v=Ly`, and `w=y-Pu-Zv`. These give the
direct sum `y=w+Pu+Zv`, with `Qw=Lw=0`. The code fixes w and sends
`(u,v)` to `(-v,u+v)`. Its matrix on the two section images is
`[[0,-I],[I,I]]`. Its cube is minus I there, so `G^6=I` on the full
source. Over the actual dyadic ring and r>0, its order is exactly six.
Positive characteristic can reduce the order.

## The two local words

For the backward word, first add Cy to x, then apply G to y, then run
the retained clean-J backward core. Equation (1) gives

```text
x+Cy-JGy=x-y.
```

The complete map is `(x-y,Gy,h,0)`. The target uses the identity matrix
on all n source fields, not only on a quotient by the selected rows.

For the forward word, run the clean core `(x,y+Jx,h,0)`. At its complete
exit, apply G inverse to x and denote the result by x'. The target is
`y+JGx'=y+x'+Cx'`. Subtract Cx' from the selected target rows. The result
is `(G^-1x,y+G^-1x,h,0)`.

These words are companions, not inverse calls. An inverse of the
backward content map is `(x+G^-1y,G^-1y)`. The emitted calls also clear
owned private inputs; they do not restore those initial values.

## The actual scalar and native interface

The pinned supplier has `K=R^T/4` and `RK=14I`. It uses disjoint sets

```text
A=[0,7,20,27,36,46,57,111],
T=[21,37,47,76,81,87,92,110].
```

Both minors satisfy `R_A R_A^T=R_T R_T^T=4I`. Take
`P=iota_A R_A^-1` and `L=R_T selector_T`. The backward source output
has `Y_T'=R_T^-1 RY`, so it stores the full original query in existing
fields. The physical endpoints remain

```text
X_p: C_p -> FULL,
Y_p: I -> FULL C_p^-1.
```

The backward correction is before every retained entry adapter. Form
each row of CY in owned C0 at I, apply the intrinsic positive C_p to C0,
add it into X_p, and clear C0. This uses one rank-one child on each A
port. The exact input recipes include the scalar phase; a binary
subspace representative alone is insufficient.

Next apply `I+ZQ` to Y with one private accumulator. Read a full row
q_k Y before its scatter by column z_k. Since every `q_i z_k=0`, each
completed scatter preserves every later query. Clear C0 after each row.
Finally apply `I-PL`: the A fields read the disjoint T fields. This last
factor has 32 signed-half ADDs.

For the forward word, every retained core event runs first. At FULL,
apply `I+PL` to X, then the serial inverse of `I+ZQ`. Form each row of
`-CX'` in C0 at FULL. Apply the intrinsic inverse C_p to that copy, add
it into Y_p at `FULL C_p^-1`, and clear C0 back to I. C_p commutes with
FULL in this pinned interface. The certificate gives the exact inverse
line recipe, including its translation and scalar phase.

All 480 helper outputs keep their original native transforms. Helper
restoration in the displayed maps refers to canonical contents. The
source query fields keep their individual native endpoint frames;
clean query contents do not provide free common-frame access.

## Uniqueness and the repair-row bound

Suppose P has exactly r support rows A and `P=iota_A R_A^-1`. Then
`ker J_offA=im Z`. For the reverse inclusion, let `J_offA v=0` and put
`d=v-ZRv`. We have `Rd=0`, so `Jd=d`. Since JZ is supported on A, d is
also supported there. The unit minor R_A then gives d=0.

Every source map F with `J_offA F=I_offA` therefore has the unique form
`F=G+ZB`. Since `GP=Z`, this is `G(I+PB)`. It is invertible exactly when
`I+BP` is a unit. If F must also satisfy `LF=R`, then B=0. Thus G is
unique with both this fixed target support and this full logger.
Also `CZ=-P`, so all r correction directions are required.

For the actual supplier, reduce dyadic coefficients modulo 13. The
identity `RK=14I` gives `RJ=0`, and `RP=I` gives rank R=8. For any source
matrix F, if `C=JF-I`, then `RC=-R`. Thus rank C is at least eight. C
needs at least eight nonzero target rows; their R columns must span the
eight-dimensional query space. The actual A meets this bound.

This lower bound covers identity-target source preparation followed by
target-row correction. It does not bound arbitrary native circuits or
prove a general minimum number of recursive children. It does not need
F to be invertible. Gaussian dyadics also reduce modulo 13 by mapping
i to 5. For coefficients in the dyadic or Gaussian-dyadic group algebra of
cover permutations, augmentation followed by this reduction gives the
same bound with the stated port support. This extension requires that
augmentation; it does not cover a general algebra of phased native
operators.

## A conditional query-transport law

Let charts s and t satisfy the theorem's hypotheses. Let U transport
source fields between them. Suppose their actual selected transport
satisfies `L_t U=V_R L_s`, with its specified mode basis. Since
`R_t G_t^-1=L_t`,

```text
R_t (G_t^-1 U G_s)=V_R R_s.                    (2)
```

Thus the full query transfers without an inverse of `R_t Z_s`. These
source transitions telescope under compatible ordered composition.
If normalized selected values use `R_T^-1`, their transport V_T gives
`V_R=R_T V_T R_T^-1`; these two matrices must not be identified.

Equation (2) has an explicit source-transport premise. It does not
restore the full source, close bank bridges, or make the first and last
gauges equal. Also, `G_s^6=I` at each chart does not give order six for a
product of different charts. The portable checker rejects that inference
and a fixed-chart FBF signed-exchange shortcut.
