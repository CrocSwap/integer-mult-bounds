The immutable assembly is pinned; the replay does not depend on the mutable selected-result file.

Fix a subset S of registers within one of the A/B stages. Let x be the original state and z the replacement state. Maintain the diagonal invariant x_r=d_r z_r, initially d_r=1. When the original has a SCALE q on a selected register r, omit the gate and set d_r<-q d_r. An original ADD x_t<-x_t+q x_s is replaced by z_t<-z_t+(q d_s/d_t) z_s. On an unselected register, an original SCALE is retained; scalar multiplications commute with the diagonal invariant. Thus the invariant holds at every scalar step. At the stage boundary, explicitly scale each register by its nonidentity d_r. The entire stage map then equals the original on arbitrary inputs, including all dirty helper columns. All d_r are nonzero signed powers of two, so all replacement coefficients remain nonzero dyadic rationals.

Climbs are not moved or removed. They do not change the scalar coefficient matrix used in this invariant, but they carry a separate frame obligation. The emitted replay checks the retained frame and containment rules at every gate, including each new boundary scale at that register's actual current frame. Exact equality of all non-scalar event lists additionally fixes the paid climbs, phases, wrappers, and center ordering. This verifies the inherited finite scalar/frame contract; it is not an independent native or physical-frame theorem.

For each elementary matrix G, the backward gate is G^(-T): ADD swaps source and target and negates q; SCALE uses 1/q. If M=G_k...G_1, then M^(-T)=G_k^(-T)...G_1^(-T). Thus gatewise inverse transpose in the same execution order transports stage equality to the opposite orientation. The verifier confirms the original stage pairing, emits the candidate pairing, independently compares all four A/B matrices, and replays the complete backward program.
