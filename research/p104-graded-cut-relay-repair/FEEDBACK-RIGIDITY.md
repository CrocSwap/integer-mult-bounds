# A backward feedback field can change only by a constant

Consider the 27 decreasing-dimension MOVEs in the 111-port #8027 binary graph. Its 630 independent constant binary input fields are sufficient for this obstruction. At one chosen logical MOVE slot let the received bit be any deterministic Boolean function of the full input, and propagate the resulting value through the remaining native local computations and contact graph. Grant each terminal chart its full local history, unlimited memory and arbitrary deterministic decoding. A successful protocol must deliver the original public values on every input. Substitutions at multiple logical slots and altered interior computation belong to a wider class.

**Rigidity theorem.** At each of the 27 slots the only possible received functions on this binary restriction are the original normalized function \(f(x)\) and its complement. Both differ from \(f\) by a globally known constant, which is sufficient for a terminal decoder. In particular, nonlinear data-dependent substitutions and data-dependent terminal recoding cannot bypass this obstruction.

Write \(\delta(x)\) for the discrepancy of the proposed bit. By the linearity of the fixed suffix, each chart’s list of its initial bits and all subsequent incoming bits takes the form \(w(x)+v\delta(x)\), where \(w\) is its native list and \(v\) is the sensitivity of that list to a one-bit error. All of a chart’s local history is determined by this list. One terminal has native desired bit \(q(w)\), a linear function with \(q(v)=1\). Its native list has full row rank, so both \(w\) and \(w+v\) occur for every pair on the translated line. For any input with either native list, the changed list must be one of the two elements of that same pair. The original output bits for the two native lists differ. Recoverability forces each side to occupy exactly one of these two possible observations. Thus \(\delta\) is determined by the native list, and is constant along each pair. This argument permits \(\delta\) to depend a priori on any of the 630 inputs.

Every one of the 27 errors reaches an odd target at **two distinct charts with three native observations each and six jointly independent observations**. Apply the preceding result to both charts. Since every pair of their native triples is attained, a Boolean function simultaneously determined by each triple is constant. Conversely a known constant can be removed by each decoder on its known affected output bits. At clock 10997, for example, charts 532 and 534 witness rigidity through public outputs 118 and 120. Both are the XOR of their three native arrivals, and only their third arrivals are sensitive. Across all 27 sites the complete forward signatures have 55 or 63 affected final charts. The certificate supplies two charts and their masks at every slot.

**Cheaper sources.** Give a prospective source and the original destination their *entire*, freely pooled histories from a second computation in which the chosen receipt has been set to zero. This includes their future arrivals. The altered fixed suffix determines those histories without the missing receipt. For every existing chart whose dimension would make one direct contact strictly cheaper, this stock fails to determine \(f\). The 4,643 source–slot tests even include equal-dimension and geometrically incomparable alternatives. The independent zero-versus-probe input pair in each case fixes the two complete supplied stocks and flips \(f\), ruling out arbitrary encoders of their joint observations. A constant complement cannot change distinguishability. All 27 original senders hold the required value at its native clock, and can also recover it from their complete zeroed history. A previously unused sending chart with no native stock adds no information to this overgrant. Receiving some other independent input at a new chart entails an additional changed contact.

Together with the unconditional lower bound 4,750 on upward grade, this excludes a strictly cheaper single downward sender replacement in the model above while preserving the destination and logical perturbation site. The theorem grants histories to terminal decoders and the proposed producer. Interior nonlinear recoding, a different physical output assignment, or several interacting wire changes would require a new argument.
