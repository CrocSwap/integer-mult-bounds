independent helper inputs**, using 112 existing paid H1 children of the

The 112 copied responses are dependent observations, not additional productive
jobs. Their 112 owned storage fields, 112 copies, 224 initial/terminal clears,

**This is a forward observer ABI, not a complete Gaussian caller or a new κ.**

inputs for them still requires a caller that restores all displaced helpers.
No backward observation interface is asserted.

## Reproduce

Only Python 3.12 and its standard library are required, in a full Git checkout:

```sh
python3 scripts/research_package.py --package research/native-helper-query-bank --check-only
python3.12 scripts/research_package.py --package research/native-helper-query-bank
```

The bounded registered replay runs the verifier normally and with `-O`. Direct
replay is `python3.12 -I -B research/native-helper-query-bank/verify.py`.
It authenticates the source files, regenerates all 632 endpoint rows and 358
first departures, checks the full scalar basis, checks exact signed Clifford
tableaux and absolute phases for all 112 responses and 32 completions, and
rejects four base semantic mutations. A second replay tracks all 632 original
and 225 arbitrary owned inputs through the hoisted schedule, checks all 112
replacement cuts and unchanged paid counts, and rejects two rescheduling
mutations. The observation readout phases are checked separately from their raw
copied rows. It compares parsed receipts without writing. The explicit authoring
option `--write` regenerates `BANK.json` and `HOIST.json`.

replays under Python 3.12.15 on macOS 27.0.1 arm64. The normal and optimized
replays, including the entrance-prologue checks, took 13.20 seconds together.
