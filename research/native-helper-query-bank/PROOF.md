# A forward native paid-history interface on independent helper inputs

## Fixed source and precise scope

Use the center-free forward word in the pinned `CODED-WORDS.json.gz`, with
632 arbitrary independent inputs: 112 X, 112 Y and 408 helpers. Its predecessor
proves, over the rational free-group algebra of the native warp symbols,

    (X,Y,H) -> (X,Y+A X,H),

with the original physical entrance and exit frames. Here
`A=I-MM^T/4`, `M^T M=56I`, is the center-free producer's code. This package does
not change A. The independent helper block and zero helper-to-main blocks are
essential. Our verifier regenerates and checks all 632 endpoint rows against
that identity, rather than trusting a stored prefix registry. It also checks the
6,596-instruction source offset and exact center-deleted source suffix.

The inherited physical rule is: a normalized logical term `a H_j` with native
word W, in physical chart F, acts as

    a F W F_birth(j)^-1 H_j.

The rational coefficient stays outside the lifted address operator. Source
`phase`, `adapter` and `residual_adapter` markers use the authenticated native
physical implementation and the predecessor theorem; they are not newly proved
by the symbolic interpreter. The source has one owned center temporary, cleared
at exit; no persistent owner is erased.

This result concerns the **forward** word only. In particular the raw-dual
backward word, conjugated frames and the main X-only Q-squared correction are
not supplied by reversing the observation list. A future bidirectional caller
must prove those obligations separately.

## The scalar first-departure basis

Let J be the ordered set of 358 helper owners whose initial chart is empty.
Let the other 50 helpers be called hot only to distinguish their nonempty birth
charts; their inputs are also arbitrary and independent.

For each j in J, stop immediately before that owner's first paid climb. Direct
source replay proves:

1. its current chart is empty;
2. its row contains only inputs in J;
3. every native word in that row is empty.

Write that row as `sum_k T[j,k] H_k`, with rows and columns indexed by the same
increasing list J. Thus T is an actual scalar matrix of chronological
first-departure observations; its rows need not occur at one simultaneous cut.
`BANK.json` lists every entry. Exact elimination and both product identities
prove that the entire 358-by-358 matrix is invertible. T has 2,242 nonzero
entries; its inverse has 3,206. This statement includes every cold helper input,
not merely the selected query subspace.

The deterministic elimination uses 2,949 ADDs, 117 SCALEs and 87 swaps. Each swap
is emitted without scratch as

    a += b; b -= a; a += b; b *= -1.

The resulting 3,210 ADDs and 204 nonzero SCALEs implement T^-1 in place.
Reversing them and reciprocating SCALE coefficients implements T. The checker
executes both literal programs on all 358 independent input columns and checks
both inverse identities. These operations preserve all input information; none
uses a productive helper as an erased temporary. The coefficients are fixed
rationals, including odd denominators. This is an ordinary scalar program, not
a claim of free exact division in the eventual integer multiplier.

## The selected common-Q responses

Among the first departures, exactly 198 are already funded H1 children on odd
noncharacteristic lines, and their original helper endpoints have rank nine.
Choose the earliest 112, ordered by the emitted forward event index. Their
helper owners, zero-based event indices in both words, first chart and line q
are in `BANK.json`. Every selected row is an independent row of the full T.

Let Q be the rank-one native Gaussian C gate on the first of the nine axes,
and R the full nine-axis Gaussian. For selected slot s, use the real signed
monomial K_s inherited from the phase-correct normalizer construction, so

    K_s R K_s^-1 = R.

Let E_s be the actual first-departure frame for that slot. Define the monomial
response map

    O_s = Q K_s^-1 E_s^-1.

For every selected slot the verifier proves that K_s and O_s have Fourier rank
zero, compiles them into literal P/D/X/phase-only words, and checks

    O_s E_s K_s = Q

by the signed tableau **and** the complete exact zero-column amplitude. The
latter fixes the absolute phase left undetermined by a tableau. The full
R-commutator is checked by the same exact method. No Gaussian call occurs in
these wrappers. The unselected diagonal entries of D_K are the identity.

The input contract is 358 independent fields ξ, plus the original arbitrary
main and hot-helper fields. Before the source word:

    H_J = T^-1 D_K ξ.

Execute the diagonal K maps, followed by the emitted T^-1 scalar program. The
selected first-departure row is then `(T H_J)_s = K_s ξ_s`. The existing paid
H1 child produces `E_s K_s ξ_s`. Immediately after that actual event, COPY the
field into a distinct owned zero field and apply O_s to that copy. It is exactly
`Q ξ_s`. The persistent native owner continues along its original paid path.
This adds **no Gaussian child and no paid split** to obtain the observation.

In this chronological version, each response becomes available after its listed
event and may be retained until the source word finishes. The following exact
rescheduling makes every response available in an entrance prologue instead.
In both versions, observations are owned copies of existing paid history, not
independent input jobs or extra productive credit.

## An entrance prologue with the same 112 paid children

After the diagonal K maps, but **before** the existing T^-1 scalar program,
the cold coordinates are `w=D_K ξ`. For each selected coordinate s:

1. Initialize a new owned raw field and COPY `w_s` into it.
2. Execute the complete adapted H1 child from the listed source event on that
   field. Its physical value is `E_s w_s`. This is the original child relocated,
   not a second invocation or a bare C gate without its source adapters.
3. COPY its value into the owned observation field and apply the already
   compiled monomial O_s. This gives `Q ξ_s` immediately. Keep the raw field
   `E_s w_s` unchanged for its later replacement cut.

Now execute T^-1 and the source word, omitting the 112 selected child events.
At such an event the original persistent field has chart zero and value

    (T T^-1 w)_s = w_s.

The first-departure proof establishes this identity on every original input;
it contains no main-input coefficient. SWAP that entire physical field with
its stored raw field, **transporting the chart tags with the data**. The
persistent field now has exactly the chart E_s and value E_s w_s that the
omitted original child would have produced. The owned raw slot contains the
old duplicate w_s in chart zero; CLEAR that owned slot. No persistent field is
cleared, and its input information remains in the invertibly transformed
E_s w_s. A whole-field permutation works between these two charts; it is not
the three-ADD common-chart swap used by the scalar basis program.

All other source instructions are unchanged. Induction at the 112 replacement
cuts therefore restores the complete source state, with exactly its original
paid inventory. Completion and return decoding below apply unchanged. All
responses are available after the 112 prologue children, before the original
native operations and even before T^-1. This is an early-query interface, not
a claim that the prologue has zero cost.

The helper arguments are fixed before the prologue and thereafter follow only
the declared basis program and source word. A caller may recode its **main**
entrance values after receiving the responses: the replacement identities hold
for arbitrary main values and have zero main coefficients. Such a recoding
changes the main input to which the producer contract applies. It does not
automatically preserve a caller's original jobs. Later interventions in the
native word, changes to helper arguments, or mutation of held raw fields require
a new integrated proof.

[HOIST.json](HOIST.json) emits an **ordered patch recipe**, not a standalone
instruction stream. After its prologue, insert the existing BANK scalar
T^-1 entrance program. Then replay the pinned forward source in order, replacing
only the listed child events and retaining every intervening source segment.
Afterward apply the unchanged BANK completion and return decoder. The final
observation clears are obligations after the consumer's last use.
The verifier executes that program on all 632 original inputs and 225 arbitrary
owned inputs (the native center, 112 held raw fields and 112 observation fields).
It checks all 112 replacement cuts, every persistent endpoint, unchanged paid
counts, and clearing of every owned input. Observation copies are tracked in
their raw representation; the independent signed-tableau and absolute-phase
identities above verify their O_s readouts. The native word never reads those
copies, so normalizing them immediately cannot affect the replay. Wrong held
arguments and a swap that fails to transport chart tags are rejected.

## Returning every independent helper

At source termination, the old cold-helper target census is

    26 H4 + 6 H8 + 326 H9.

The other 50 helpers have targets `2 H4 + 7 H7 + 41 H8`. Rank means the dimension
increase from that helper's actual birth chart, not just its exit-frame rank.
The hot helpers remain completely unchanged in this package.

The scalar decoder T cannot be applied while different cold fields still carry
different physical Gaussian frames. For every cold owner j of original rank
r<9, append the operator

    C_j = R F_final(j)^-1.

The verifier compiles C_j into a monomial wrapper, one contiguous standard
Gaussian block of rank 9-r, and a monomial wrapper. It checks the exact signed
tableau and phase of the compiled word, and `C_j F_final(j)=R`. The explicit
32 recipes cost **26 H5 plus six H1**, with at most 64 monomial wrapper maps.
The 326 original H9 outputs already equal R H_j. The whole cold bank is now
uniformly `R H_J`.

Apply the literal T program, then the diagonal K_s^-1 maps. Scalar owner maps
commute with the same R on every owner, and K_s commutes with R, so the output is

    D_K^-1 T R T^-1 D_K ξ = R ξ.

Every one of the 358 input coordinates is returned as its independent H9 job.
No original helper information is discarded or replaced by a main input. This
changes the target contract for the cold bank to 358 H9 jobs; it does **not**
claim that the old ordered H4/H8 target list survives the mixing unchanged.
Together with the unmodified hot bank, the new target profile is
`{4:2,7:7,8:41,9:358}`. The added target rank mass and added paid rank mass are
both 136. The main coded endpoint remains exactly the source endpoint, because
its helper-to-main blocks vanish for all original helper values, and all new
exit operations act solely on helpers or owned observation copies.

## Ownership and ordinary work

The source retains its original persistent owners and owned center temporary.
The scalar basis programs operate reversibly in place on all 358 cold fields.
They require no additional basis scratch. The observation interface owns at
most 112 extra fields. Each is initially cleared, receives one COPY after its
specified H1 event, then receives its response monomial map. At an interface
return these fields contain the promised responses and the recipient owns them;
a completed caller must CLEAR them after their last use. The ordinary-work
invoice includes those terminal clears. A demonstration that simply clears all
responses at the end leaves only the independent original jobs, without
turning the observations into productive outputs.

Additional field passes for the chronological version, relative to the pinned
center-free producer:

| Operation | Count |
|---|---:|
| Scalar ADD | 6,420 |
| Scalar SCALE | 408 |
| Diagonal basis monomial maps K and K^-1 | 224 |
| Observation monomial maps | 112 |
| Completion monomial wrapper maps | at most 64 |
| Owned observation COPY | 112 |
| Owned observation initial CLEAR | 112 |
| Owned observation terminal CLEAR | 112 |
| Extra simultaneously owned fields | at most 112 |
| Paid completion children | 26 H5 + 6 H1 |

For the entrance-prologue version, keep the same scalar, monomial and completion
counts. Replace the observation-storage rows by **224 owned COPYs, 448 owned
CLEARs, 112 whole-field SWAPs and at most 224 extra simultaneous fields**. These
totals include observation creation and the recipient's final observation
clears. Each SWAP requires ordinary movement of two complete fields. Thus the
prologue adds 112 copies, 224 clears, 112 swaps and 112 held
fields over the chronological interface, with **zero additional scalar passes
and zero additional Gaussian children**. Copying the selected w coordinates
before T^-1 avoids reconstructing the dense T rows afterward. The source's
original owned center remains separately charged as before.

A monomial field map is the complete emitted P/D/X/phase word, not a single
machine instruction; its indexed movement and phase arithmetic must be priced
using the retained source implementation. Each rational ADD/SCALE must likewise
be implemented at the chosen precision. The lists are fixed finite programs,
so they admit width-independent algebraic suffix bounds: charge each scalar
ADD or SCALE coefficient c the bound `1+|c|`, and each unitary, whole-field SWAP
or owned COPY/CLEAR the bound one in maximum-over-fields Euclidean fiber norm. The finite
product bounds propagation of local rounding errors. This is a local existence
bound, not a complete precision allocation, optimized ordinary-work tariff or
outer multiplication budget. The new Gaussian children also require the source
Gaussian implementation and its normal costs.

## Every positive digit width

For f positive, evaluate the source rational free-group identity at the actual
consistent native operators on the f digit columns, as in the pinned
`CODED-PROOF.md`. The same exact first-departure rows have empty words, hence
the same scalar matrix T. All coefficients remain scalar owner coefficients;
T is **not** raised to a tensor power.

Independently lift each one-column physical word K_s, O_s, E_s, R and C_j to its
columnwise f-fold operator, with spectator coordinates unchanged. Exact
operator composition identities lift under this tensor operation. P and X act
columnwise, diagonal Z4 phases sum over columns, and a one-column global phase
`i^gamma` becomes `i^(f*gamma)`. Keeping that phase unchanged would be wrong.
The signed-tableau plus absolute-phase checks establish the one-column
identities, and the emitted literal words fix this lift unambiguously.

Finally evaluate the same finite scalar owner programs in the algebra of these
lifted address operators. This gives `O_s,f E_s,f K_s,f = Q_f`, and the completed
return identity `D_K,f^-1 T R_f T^-1 D_K,f = R_f` at every f. It never asserts
that tensor powers preserve sums. Thus the ABI is an all-width consequence of
explicit fixed scalar programs and inherited source semantics, not merely a
512-dimensional numerical experiment.

The hoist uses those same evaluated first-departure identities. COPY and SWAP
move complete f-column fields, with their frames, and the relocated child is the
same lifted E_s. Hence the equality at each replacement cut and the source-state
induction hold at every f as well. Neither scalar T nor an owner sum is tensor
powered in this rescheduling argument.

## Evidence boundaries

The registered verifier authenticates every live source file before importing
source code. It regenerates all 632 forward rows and all 358 first departures,
checks the entire scalar basis, emits and checks 112 response words and 32
completion words, and compares the deterministic receipt. It also rejects:
main-input contamination of a claimed helper-only departure; a singular basis;
a phase-only wrong response with the same tableau; and omission of a required
cold-H8 completion. These checks use explicit exceptions and also run under
Python `-O`. The additional hoist replay checks all 857 raw-state input columns,
the 112 matching physical replacement cuts, the unchanged Gaussian inventory,
and the two rescheduling controls described above.

The inherited native physical compiler and multiplication analytic hypotheses
are not independently audited here. No full historical suite, selected cold
replay, hosted CI or formal-kernel acceptance is claimed. A complete caller must
still put the required main arguments into this interface without losing any
independent helper input, establish both directions actually used, clear all
owned observations, and pay storage, precision, ordinary work and the outer
budget. Until then the result is an exact reusable forward paid-history ABI,
not an admitted supplier or a new exponent.
