# Standalone elementary interchange at the raw CRT boundary

This supplies a new encoded binary interchange component with a complete
fixed-role initialization and successful lifecycle, then uses it for all twelve
exchanges in the actual u2/t2/y8/back2 raw compact CRT word. The output remains
196608 binary cells. It is not yet a repaired CRT output or a selected supplier.

The R10 attempt stopped because its q2 dummy binding did not meet the actual
selected constructor, and because the repair parser rejected48-bit packed
strings. Here the selected constructor is absent by construction: five unchanged
low-level source modules, a proved narrow16-role allocator and encoded-width
iteration supply the elementary algorithm directly. No Ordinary/RootSession,
selected catalogue, fake topology/program, patched branch or accepted-record
hash override is used. The original selected guards remain unchanged.

[PROOF.md](PROOF.md) proves the interchange for arbitrary encoded H>=0 and
positive spectator extents. It gives a13-live-role bound inside16 scratch roles,
borrowed preservation, owned output, zero-width identity ownership, reuse and
final marker disposal. All17 owned tapes are physically initialized; no initial
marker or numerical arena is supplied for free. A conservative explicit
source-operation bound is included. Fixed tape count does not bound retained
backing-array length, and this is not a compiled binary instruction tariff.

The fixed actual caller executes F,u+=f(y),F,u-=f(y), including four t-update
and two u-update shuttle pairs, ten physical fiber rotations and fresh current-y
ROM reads. It restores all four dirty-back values at good and bad addresses.
The28 private roles include caller descriptors and rotation buffers. The data
port is consumed/rebuilt through charged copies and returned as the same object;
ROM bytes/head are preserved and all private roles are erased at disposal.

Input/output ABI: numeric LEFT=2 at cell0, then196608 numeric0/1 payload bits in
(u,t,y,back,payloadbit) order, then BLANK=4 tail, head1. Four back records are
contiguous at each of4096 address positions; each record has12 bits in MSB order.
The source ROM is a separate borrowed32-bit tape in the same framing. The actual
fixture is h3/s5/offsets[0,2,4,0] middle layer, target position2. The compiler's
fixed prefixes/cuts are code, while ROM values are read physically at runtime.

The unchanged #5105 parser still accepts only integers0..4095. This package
does not reinterpret four12-bit records as one accepted48-bit symbol and does
not invoke repair. A separate paid four-column interface is needed. ROM
production, current selected/native admission, all-size CRT source amortization,
full E, binary lowering, precision/outer multiplication and new kappa remain
unclaimed. Successful typed-domain ownership does not imply exception rollback.

## Evidence and reproduction

The verifier checks widths0..5,32 independent input columns, repeated calls,
all borrowed/private boundaries and actual mutations of bucket orientation,
prefix progression, erasure, allocation, aliases and ROM control. The full
calibration compares every output bit against the independent source compact
oracle, with every dirty-back value included. One12-bit label pattern is not a
unique naming of all14-bit addresses; the arbitrary-payload result comes from
the written permutation proof, corroborated by the independent-column tests.

Run python3 -B research/standalone-elementary-crt-raw/verify.py --light for small
controls. The registered package hook runs the full normal and optimized
checks, with exact source authentication and a frozen RESULT.json. Explicit
--write-result authors that receipt. Full replays require the shared heavy slot.
See VALIDATION.md for the exact performed commands, environments and limits.
