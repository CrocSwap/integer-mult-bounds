## Reproduce

C++20, Python3.11+ and SymPy1.14.0 are required. Boost and JSON headers are vendored in native/native-deps.zip with their licenses. Install the reference requirements if needed:

    python -m pip install -r references/source527/requirements.txt

Windows (use a short writable temporary path to avoid compiler path limits):

    ./verify.ps1 -Compiler g++ -TempRoot D:/proof/replay

Unix:

    bash verify.sh

By default the wrapper first performs a new immutable eight-stage public replay, then reruns every added native check and compares the exact final certificate. All new mathematical computation is C++; the public verifier is retained unchanged, and Python also performs data export and gzip extraction. Outputs are preserved in a fresh temporary folder, with no cleanup or publishing command. An already completed source-identical public replay may be supplied with -PublicResults PATH or PUBLIC_RESULTS=PATH; the verifier checks its completion and source-manifest binding and still reruns all new native checks. The delivered fresh public and native receipts are evidence of the recorded run, not replacements for the default replay.
