# Reuse reversal banks after a finite rejection

This scoped constructive proof and executable graph add rejection retirement
to Jerry Chen / CubeJerry's [#7427](https://github.com/CrocSwap/integer-mult-bounds/pull/7427).
The contribution was produced by Nick Petalas. No new kappa is claimed.

The new fixed graph uses **26 tapes, 2,145 locations and four symbols**.
After a finite malformed-input rejection it preserves all public contents,
erases private work and returns every head. The same private banks can then
serve a valid reversal. The predecessor's successful reversal and its public
preservation on rejection are cited premises. Their verification is not the
deliverable.

For a source run of T instructions on n tapes with total visited length L,
the new graph costs at most `5T+16L+6n <= 21T+22n`. Here n=13, giving
`21T+286`. The graph records visits on synchronized monitor tapes, clears
each marked private interval and returns to its retained origin marker.
The visited-interval method is classical; the explicit transformer and this
rejection/reuse application are the new contribution. [PROOF.md](PROOF.md)
gives the quantified premises, loop bounds and historical-backing bill.

The source is frozen at `7662d01d827c95d90032579c168cae78aa531f2f`.
Only its two executable files and original notice are retained locally.
[SOURCES.json](SOURCES.json) records their original paths, byte lengths,
Git blob IDs and SHA256 hashes. The verifier authenticates these local
exports before importing them. No pending Git object or network is needed.

it back. All counts enumerate the stated finite fixture sets.

The compiler and checker use managed Python containers. The finite fixture
dimensions and two-million-instruction per-run cap bound replay resources.
The mathematical runtime is the emitted local graph; its scan loops have
the visited-interval bounds proved in PROOF.md.

## Limits and scope

The source program must halt or reject, and its private visited cells and
the additional monitor windows must be blank on entry. The caller must own
and provide those windows. Erasure preserves historical allocation. No
cleanup after interruption or nontermination is promised. This gives time
linear in the finite rejected execution, which can be much larger than the
actual DATA length for excessive descriptors.

Card `formal-interface-lemma`, priority revision 8, changes scope to #7427's
Open next question 4. Base `e54523517d0f03e58352e647c403a5af3e525a57`.
The source-binding orientation command passes at selected #7000; the older
#5599 values in the priorities prose are historical. This package changes no
selected record. It implements no complete native MOVE, physical caller,
common-grid conversion or multiplier. Those integrations, the selected cold
replay, independent human review and formal proof-kernel acceptance are unrun
or unclaimed.
