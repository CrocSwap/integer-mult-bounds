# Implementation bounds and verification decisions

The package owns two Python files and reads one source-authenticated geometry
module. It changes no shared checker or predecessor source. Separate Before
Serializing Shared State keeps research and outputs in the assigned worker
worktree/session directory; short shared Git operations use the orchestration
OS lock. Build the Lever produced the deterministic finite verifier. Prove It
Works required exact receipt comparison, an independently coded subset-span
capacity check and a peer check of the stated mathematical implication.

The new code has no recursion. New functions fit the 60-line review ceiling.
The only proof input is the pinned geometry source; source drift fails before
import. Public numeric helpers reject malformed domains. Explicit exceptions
keep mathematical guards active under optimization. Output creation is
exclusive and failure propagates. Root inventories, reflection images,
subspace counts, witness ranks and counting boundaries have executable guards.

Loop bounds are structural: 120 roots, 112 live lines, 8 simple reflections,
7,140 root pairs, 1,120 orbit queue removals, 8,001 dual pairs per slice,
2,667 accepted dual planes per slice, 80,730 five-label subsets per slice and
3,309,747 source five-flats. Binary vectors have at most nine bits and span
at most 512 values; subset controls use at most eleven generators. The
finite source enumeration and exact 8-dimensional elimination are inherited,
source-pinned and replayed, without editing that predecessor.

Rule 3, fixed allocation, requires a managed-runtime deviation. Python integers,
sets, tuples and library calls allocate during computation. Live inventories
have the bounds above. The independent subset checker retains at most 2,667
five-spaces of 32 nine-bit values each per slice. No concurrent replay or
unbounded stream exists. The source checksum and receipt checks compensate
for shared data construction. Follow-up would use fixed arrays if this finite
research checker acquired a strict memory-limit requirement.

Rule 9, indirect dispatch, requires a bounded standard-library deviation for
argparse, unittest and unittest.mock. Dispatch targets are the eight named
local test methods and explicit CLI action. Direct mathematical calls use
local functions and the one pinned geometry module. Follow-up is to remove
these adapters if a freestanding checker is required.

Rule 10 diagnostics are recorded in CHECKS.json. Python warning-as-error,
optimized controls, Ruff checks and the registered package replay cover the
changed paths. This is a finite research artifact, not a performance claim.
Timing is not used as scientific evidence. The mathematical chamber theorem
and any future physical caller remain explicit unrun obligations.
