# Exact integer-transvection length of every shear power

This contribution was produced by Nick Petalas. Apache-2.0.

For `X(t)=[[1,t],[0,1]]`, `Y(t)=[[1,0],[t,1]]`, and
`B=X(2)Y(2)=[[5,2],[2,1]]`, let each nonzero integer t cost one letter.
Then the exact faithful matrix-word length is

```text
lambda(B^k) = 2k,  for every integer k >= 1.
```

This is a **scoped proof with exact finite corroboration**. unpaidmoon's
[PR4146](https://github.com/CrocSwap/integer-mult-bounds/pull/4146) leaves
`4 <= lambda(B^k) <= 2k` for k >= 2 and explicitly does not claim equality.
The first new instance is `lambda(B^3)=6`. The new proof settles that gap
for all powers, using the classical shortest-division-chain theorem over Z.
The exact two-role moment in the inherited rank-only model is `k*2^(a-1)`.
No physical supplier, complete multiplication theorem or new kappa is claimed.

## Proof and evidence

[PROOF.md](PROOF.md) identifies the classical theorem and its unrestricted
remainder hypothesis. Left removal of any alternating matrix word gives a
division chain from one orientation of the first column. Pell coordinates
give shortest chain lengths 2k and 2k+1 for those two orientations. The
literal word `(X(2)Y(2))^k` attains 2k. Negative and arbitrarily large integer
coefficients are covered by the written argument.

The standalone verifier independently multiplies all 64 attaining words,
compares them with Pell coordinates, validates both least-remainder traces,
and compares literal inverse removals with those traces. It enumerates every
word of length zero through five in the twelve-letter alphabet with
coefficients in `{-3,-2,-1,1,2,3}`, looking for B cubed. This bounded census
corroborates the first new instance; it does not replace the all-integer proof.

Twelve rejection controls damage traces, a target, letter contracts, the
integer-coefficient requirement, or one of the six attaining calls. Two
additional scope checks distinguish the mod-two quotient and the tariff
obtained by expanding coefficients into unit letters. The literal identity
`X(12/5)Y(70)X(2/5)=B^3` shows why rational coefficients are outside the theorem.

`RESULT.json` is generated by the verifier and binds the finite evidence to
the proof, code and metadata hashes. It is compared with exact regeneration
on every ordinary replay. No predecessor verifier is imported or executed.

```sh

/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -W error -O -B research/sl2z-power-length/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/research_package.py --package research/sl2z-power-length
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/check_research_commit.py --package research/sl2z-power-length --check-source-history
```

Other machines may substitute their CPython 3.12 interpreter. To regenerate
the result without overwriting a file:

```sh
python3.12 -W error -B research/sl2z-power-length/verify.py --write /tmp/sl2z-power-result.json
python3.12 -W error -B research/sl2z-power-length/verify.py --certificate /tmp/sl2z-power-result.json
```

## Verification implementation limits

The finite verifier has no recursion or unbounded search queue. Powers stop
at 64, words at length five over twelve letters, and least-remainder inputs
at 1024 bits with at most 1026 divisions. Every function fits within 60
physical lines. Runtime contracts remain active under optimized Python.

Power-of-Ten rule 3 has a managed-runtime deviation in `verify.py`: Python
integers, Fractions, tuples, dictionaries and JSON allocate dynamically.
The finite bounds above cap all live data; the input certificate is capped
at one megabyte. Rule 9 has a Python arithmetic-dispatch deviation, confined
to standard integers and Fractions with direct, visible calls. The control
word is the only Fraction calculation. Exact endpoint and normal/optimized
replays check both paths. A fixed-capacity native implementation would be
needed if allocation or dispatch guarantees became a caller requirement.
Warning-strict replays supply the available runtime diagnostics; no repository
build configuration is changed.

## Open next questions

integer action at a favorable complete tariff? This would determine whether
the exact formal count has any supplier use. Start with the single X(2)
operation and account for the shift, arbitrary dirty data, restoration and

are the blockers. The present theorem closes the word-shortening route for
the stated integer alphabet and does not provide that implementation.
