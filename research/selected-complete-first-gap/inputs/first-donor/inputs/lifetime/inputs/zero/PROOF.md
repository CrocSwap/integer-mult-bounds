premise at a concrete earlier interface: one valid retained old coded field

The complete new graph has4803 locations and43 fixed tapes. Exact source

**Claim.** On the domain below, one input-independent fixed table creates
`^ h 0^V | $`, where h is the exact required six-Gamma header. The old field
and context are bit-for-bit unchanged, their heads return to their original
relative origins, every private body is erased, and the HOME head returns

## 2. Retained old input, geometry and source binding

The descriptor schema is taken literally from canonical
`research/current-coded-gaussian-leaf/vendor/binding/provider.py`:

```

K, G, H, q0, qF, qB, D, f, rho, active_start, back_start,
selected_axes, entry_start, remainder, cutoff.
```

Each nonnegative number is `1^ell 0` followed by ell least-significant-first
binary digits. Zero has one digit; any longer code ends in1. The descriptor
has exactly23 codes followed by physical blank. Let E_old be its entire
physical bit length, including ignored fields and cutoff.

Put a=within_bits, u=active_start and C=outer*rows. Require
outer,rows,f,K,cutoff>0;0<=rho<K;u+9fK<=a. There are N=C2^a address records,
each with r positive complex coefficients. Every real/imaginary component
has b>=2 signed bits, least-significant first, followed by virtual delimiter2.
The exact old physical codewords are000,001,010 for digit0,digit1,delimiter2.
Thus

`record_bits=6r(b+1)`, `row_bits=2^a record_bits`,
`V_old=C2^a6r(b+1)`.

The input quantum is supplied externally; zero below is exact on every
such grid. The constructor does not infer precision admission from p or
silently replace the source's full provider premises. It uses this same
local old-format geometry as the predecessor codec. The original provider's
additional G,H,reservation and caller conditions remain its own.

The output is the established packed shape

`h=Gamma(f)Gamma(r)Gamma(P)Gamma(S)Gamma(b)Gamma(cutoff)`,

## 3. Actual physical symbols and the separate output owner

The retained old hardware uses ZERO=0,ONE=1,LEFT=2,SEP=3,END=4,BASE=5,
BLANK=6. The frozen guide compiler names blank2 and LEFT3 abstractly.
`hardware_code()` applies the fixed injective instruction-label map

`abstract(0,1,blank,LEFT,new_delimiter,new_end) -> (0,1,6,2,3,4)`.

No public cell is rewritten by this translation. The emitted tests and
writes use the actual old LEFT/blank symbols, and old DATA digits remain
physical0/1. Virtual delimiter2 remains its three-bit code010; it is never
confused with the physical LEFT marker2. The verifier executes the translated
table, checks the exact original symbol declarations, and rejects any
instruction writing OLD or CONTEXT.

The new owned HOME uses this physical LEFT as `^`, old SEP as `|`, and old
END as `$`. Its head enters and returns on `^`; OLD, CONTEXT and the40 private
tapes enter/return on their first body cells, immediately right of their
LEFT guards. These conventions are explicit, not an uncharged head shift.
The graph moves HOME right at entry and physically rewinds it back to `^`.

The two input ports, output owner and private owners must be genuinely
disjoint, with valid relative guards and sufficiently large blank private
windows. A fresh output window is blank through F+2; an existing inactive
HOME has an arbitrary binary F-bit body followed by `|$`. These owner/window
grants are an explicit enclosing allocation premise. The controller pays
for every newly written/visited body cell and marker, and its history bound
states the required increment. It does not prove the enclosing allocator
can grant those windows or reaches their origins at zero cost.

The source remains present while this distinct output is created. In
particular `V_old/V=3(b+1)/b>3`, and F additionally contains its new header.
No old-format body can be relabelled as packed DATA or have its capacity
silently shortened. The resulting one-owned-HOME boundary can be consumed
by a correctly placed native service, but it is not itself the complete
B1 bank of productive and owned caller fields. Placement/transport into
that actual bank and its stock bookkeeping remain separate obligations.

## 4. Literal construction and unchanged-source theorem

The reused parser scans and canonically checks all23 old codes. It expands
only the nine needed shape values into unary guides; cutoff is kept as
binary, and irrelevant fields are checked and retired in encoded length.
It reads the first complete old component to infer b, checks b>=2 and
returns the OLD head. It computes
`r=record_bits/[6(b+1)]` by exact unary division, rejecting zero or a
nonintegral quotient. It checks the complete row-size equation, selected
coordinate bounds and rho<K, then physically constructs N,P,S and the six
Gamma values by the frozen unary/binary guide operations.

Copy those Gamma bits into HOME, erasing the private generated-header copy
as it is consumed. Every HOME bit write first checks that the current cell
is binary or blank, so a too-short inactive HOME rejects before overwriting
its right delimiter. No header is supplied from a preexisting Gamma packet,
and no runtime host number chooses a tape position.

Next execute nested unary loops for N records,2r components per record,
and b physical numerical digits per component. Each iteration validates
the entire old three-bit codeword for0 or1 and appends exactly one HOME0.
After b such iterations require codeword010. Rewind the b-guide, then the
2r-guide at each record boundary; finally require the exact old blank
frontier and return OLD to its origin. This validates every later component
against the inferred b, rather than assuming the first component represents
the whole field correctly.

There are exactly N2rb=V emitted DATA zeros. At the resulting HOME frontier,
either append `|$` into the fresh blank window or verify the existing `|$`
of an equal-extent inactive HOME. A longer inactive body still presents a
binary symbol and rejects; a shorter one was stopped by the per-write check.
Return HOME to `^`, erase every private guide/buffer and return its head.

No instruction writes OLD or CONTEXT, on any execution path. On success
their complete contents are unchanged and their explicit rewinds restore
both heads. Protected source/context contents also remain unchanged on
rejection, although failure head/private cleanup is not claimed. A rejected
output is not a live typed packet, and partial inactive-output writes are
not rolled back. Source, context and target aliasing are outside the theorem;
the binder rejects an obvious object alias, while genuine physical separation
remains a premise for external wrappers.

## 5. Why no strided DATA permutation is needed

The complete nonzero codec of the predecessor maps old address order to
`[P] x [2^f]^9 x [S]`, including all spectators. It has9f successive selected
bit extractions. For this INIT, every scientific output numerator is0.
Any permutation of a fixed-length all-zero bit word is that same word.
Likewise reversing each component's bit order preserves zero. Thus the
requested complete packed zero is obtained by writing exactly V zeros,
without routing old source values or reversing their components.

For every positive f and every native target frame U, the linear operator
`T_U^(tensor f) tensor I` sends0 to0. Therefore the generated packet denotes
the required zero on any supplied grid in the source INIT's frame,
independently of the donor's frame and arbitrary source/spectator correlations.
No all-column native implementation theorem is needed just to establish
this zero identity. Nonzero transformations remain separate services.

The cutoff is copied from the actual OLD23 descriptor, not manufactured
from f. In particular this producer does not prove f<=cutoff,2f<=cutoff,
or any policy admitting a later native call. Zero's numerical integrality
and width are trivial, but a later primitive's explicit cutoff guard still
applies. This is a zero-construction lemma, not admission of the full native
operation or of the selected nonleaf recurrence.

## 6. Uniform complete time and historical backing

Use the predecessor's explicit macro bounds:16(ell+1) for copy/erase/rewind,
128(ell+1) for unary doubling/halving,1024(v+encoded_length+1) for canonical
binary-to-unary conversion,128(xy+x+y+1) for unary multiplication, and
256(v+1) for unary-to-binary plus Gamma output. These bounds include all
head returns across the actual formerly occupied length, even after erasure.
The frozen implementation is included for review rather than treated as
a unit-cost arithmetic oracle.

On legal input, all nine unary-expanded old values are at most V_old.
In particular row_bits<=V_old, record_bits<=row_bits, outer,rows<=N,
and K,u,9f<=a<=2^a<=N. Intermediate products are at most a or V_old:
9fK<=a-u, row_bits=record_bits2^a, N=C2^a, P<=N and S<=N.
The inferred b and r also have positive factors inside V_old.

The strict binary prefixes in decoding an integer v sum to less than v;
this proves the stated linear unary conversion rather than v log v work.
In each repeated unary doubling, the successive lengths form a geometric
sum less than twice the final length. The additive loop count is at most a,
also absorbed by V_old. Exact unary division consumes record_bits digits
once; all divisor rewinds together traverse that same number of digits.
Its quotient and final head returns are linear in record_bits as well.
Thus no input integer becomes an uncharged host computation.

There are only a fixed number of these preparation operations. Nine
conversions cost at most9216V_old+1024E_old plus fixed overhead. Four chains
of repeated doubling, the fixed products/sums, inferred-width scan, exact
division, and five unary Gamma outputs add only a fixed multiple of V_old.
Cutoff and unused fields are scanned/copied in encoded length; their
numerical values are never expanded.

In the complete old scan each physical codeword is inspected by a bounded
number of R/W/M/J transitions. Writing one zero and resetting b,2r,N guides
cost O(b) per component,O(r) per record and O(N) at completion. All are
bounded by O(V_old). Header copying, HOME traversal and all private cleanup
are also charged. Counting these fixed loop bodies gives the deliberately
generous complete bound `2^20(V_old+E_old+1)`; no9f routing pass is present.
The graph reads all V_old+E_old source/context bits, so its own running
time is also Omega(V_old+E_old). This lower bound is only for this validated
source-scanning graph, not a general obstruction to a different zero service.

For output capacity, N>=512 and V_old=6Nr(b+1)>=18N. Each of f,r,P,S,b is
at most V_old/18: f<=a<=N, P,S<=N; r<=V_old/18; and
b<=V_old/(6Nr)<=V_old/18. Since a positive Gamma(v) has length at most2v,
the five non-cutoff Gamma codes have total length at most5V_old/9. The
cutoff Gamma has two fewer bits than its own old code, hence length at
most E_old. Also V/V_old=b/[3(b+1)]<1/3. Therefore

`F=E_Gamma+V < 8V_old/9+E_old <= V_old+E_old`.

Every other guide/buffer has length at most V_old+E_old. The41 non-input
banks, their end tests/markers and any new source-frontier visits fit the
conservative increment64(V_old+E_old+3). This counts the output in addition
to the still-present old source/context. Earlier historical extents remain
in history_entry, including erased storage and suspended ancestor backing.
No erasure subtracts them. No rewind visits an ancestor origin: each stops
at its own supplied permanent LEFT.

The CLEAR entry scans all F body cells, writes physical0 at every header
and DATA position, verifies `|$`, and returns HOME to `^`. Its fixed loop
and return use at most16(F+1) transitions. It retains that owner's allocated
home and historical extent; it creates neither productive credit nor
permission to alias a future unrelated lifetime.

## 7. Verification and remaining obligations

The checker uses independent ordinary binary/string formulas for all output
values and a sparse physical tape implementation with read/write/move visit
monitoring. Five complete f=1 packets cover b=2,3,5,22; r=2; two rows;
nontrivial u and spectator factor S; a201-bit cutoff; and an ignored old
descriptor value of bitlength1025. Fresh and correlated inactive target
entries are both exercised. These are local format fixtures, not asserted
to satisfy every stronger selected-root numerical/caller admission premise.
Complete f>1 packets are unrun; the universal theorem is the loop and bound
argument, not extrapolation from these finite cases.

Fifteen controls detect malformed/truncated/extra old data and headers,
inconsistent row size, nonintegral r, zero f, invalid selected geometry,
wrong inactive HOME extents, source/output alias, nonzero initializer writes
and omitted CLEAR writes. Wrong-size target checks preserve its existing
right markers. Every success checks the complete source/context, output,
relative heads, guards, private retirement and earlier history. Static
instruction inspection rules out any OLD/CONTEXT write on any path.

The live output is the intended combined Gamma6/HOME byte boundary. It does
not create a global compiler owner address, allocate a full productive
native arena, reach arbitrary source owners for free, or make a child call.
Actual OLD23-to-current-owner binding, disjoint window grants, full HOME
placement, native/cutoff admission, chronological child returns and the
complete selected fast recurrence remain. The cost of any surrounding
dispatcher scans, transports or child calls is additional.

The progress is removal of the already-packed Gamma donor premise for
zero construction, replaced by the established valid OLD23 source boundary
and an explicit charged separate-output boundary. It supplies no complete
new multiplication coefficient and discharges no foundational assumption
at its full scope. No selected certificate change is proposed.
