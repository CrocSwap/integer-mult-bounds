## 4. Literal delivery, arithmetic and retirement

The new `home_transfer` starts both heads at their origins, moves right
once, and copies or scatters each binary cell until the complete field
separator. It checks the following actual `$`, returns the HOME head, and
returns or erases the working copy. A scatter requires simultaneous work
and HOME separators, so successful return has exactly the original F.
No arithmetic address lookup supplies a position or width.

`bank_transfer` unrolls the fixed five field identities in control states.
It scans all five full fields and their separators in order, selecting only
the specified immutable slot. A gather copies that whole field to work; a
scatter replaces only that field from work. It checks the terminal `$` and
physically rewinds both heads. The remaining four field values are preserved.
This solves B2's actual layout seam: its single HOME ending`|$` is retained
as a separate owner instead of being silently identified with an interior
field of the external bank.

Each SUB gathers the current donor to work3 and owned1526 to work4, calls
the exact signed #7567 SUB, scatters the returned target to HOME2, and
physically erases its source working copy. The donor HOME itself is never
written. `clear_work` scans forward from its returned origin through every
binary body cell and separator, erases them, then returns through the blank
track. Merely calling an erasing rewind at an origin would not retire its
right-hand body; no such shortcut remains in this graph.

The MOVE gathers HOME2 to work3, invokes the unchanged full rank-two adapter
and its115776-location core, then scatters the complete returned packet to
HOME2 and erases the copy. This includes the right phase/map, two actual
positive first-slot C services with paid slot swaps, and the left phase/map.
Original f and all9f address bits remain. Its rank-aware guard compares2f
with the actual encoded cutoff; no host integer performs that comparison.

The consumer gathers HOME2 to work3 and the live receiver1515 to work4,
executes the exact ADD, scatters only external slot4, and erases both work
copies. Owned1526 remains unchanged. The final CLEAR is the exact B2
entry: it writes0 through all F header/DATA cells, verifies`|$`, and returns
the same HOME head. It neither assumes an initially zero body nor attempts
to uncompute the accumulated nonzero vector.

The inherited signed arithmetic performs a full canonical header comparison
and physically decodes w from its fifth Gamma code. It visits every component
with finite carry/borrow control. The MOVE adapter physically splits and
rejoins the six-code header and DATA. All constructors run offline; every
runtime effect is a literal transition. No callback, decoded host packet,
runtime frame interpreter or uncharged integer operation occurs in the table.

Under valid boundary premises, signed overflow, unequal headers and the
MOVE's cutoff/numerical rejections occur before that contact scatters its
target. They preserve the current actual HOME values. Failure private
cleanup/retry is not claimed. A failed INIT may have overwritten part of
the exclusively inactive output. Malformed arbitrary-packet transactionality
is outside the typed success theorem.
