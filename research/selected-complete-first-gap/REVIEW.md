## All-width half-copy and parser proof

For original signed MSB-first bits `b0 ... b(w-1)`, the arithmetic right
shift writes `b0 b0 b1 ... b(w-2)`. Its signed value is
`(B-b(w-1))/2`. The actual graph initially remembers the original sign,
writes the remembered bit, and then remembers each overwritten original
bit. At the end of the physical width guide, the current finite state is
therefore the **original** LSB. Accepting only its zero state is necessary
and sufficient for exact division by two on the unchanged lattice. This
includes the minimum signed input; the quotient always fits the old width.
An odd B plus integral A is half-integral, so odd rejection is mathematically
required by this interface rather than an arbitrary implementation restriction.

The paired parser compares all bits of all six canonical Gamma codes.
Leading zeros are counted physically on L; popping and erasing L controls
the suffix length. Only the fifth code initializes and expands W. Each
`double_plus` performs the actual `n -> 2n+b` copying, erasure and head
return on W/B. The sum of proper binary prefixes is
`sum floor(w/2^k) < w`, while the number of updates is at most w. Thus the
stated conservative `4E+128w+16` setup bound is uniform in both width and
cutoff. The full cutoff code is scanned, but no loop expands its numerical
value. There is no decoded-width host operation in the runtime graph.

Every component moves source, target and width heads together. The target
is only tested and traversed; it is not written by the half-copy. At every
component boundary the whole width guide is rewound. The per-component
bound `4w+8`, the final guide retirement and both operand returns cover
the literal instructions. On the typed complete DATA domain this works for
all coefficients, complex components, columns and spectators, including
correlated arrays. Finite fixtures below corroborate this induction; they
are not the universal argument.

## Independent complete-cost derivation

A fixed m-field scan pays one entry, `mF+m+1` forward transitions,
`mF+m+2` bank-return transitions and `F+2` work-return transitions. Hence
each gather/scatter costs exactly `(2m+1)F+2m+6`, or `7F+12` for bank44.
The separate execution measures the two-gather subtotal `14F+24` and
the scatter/clear/return subtotal `9F+17` on every successful fixture.
Together these are `23F+41` per new contact.

Two unchanged ADD calls plus the new half-copy each fit `4096(F+1)`.
The new overhead is consequently bounded by

`3*4096(F+1) + 2*(23F+41) = 12334F+12370`.

The two inherited return redirects still cost one transition each, so no
hidden boundary transition is dropped. Adding the predecessor's explicit
bill gives the stated conservative whole-prefix envelope

`2^20(V_old+E_old+1) + 2^24(fV+E+1) + 32768(F+1) + 128`.

The primitive history bound follows from two F-sized work fields, two
width-sized guides and one E-sized counter; `8(F+2)` safely covers a single
invocation. Three such calls, the new three-field bank traversal and the
work windows fit the additional `128(F+2)` allowance even if charged again.
Together with the predecessor's allowance this proves

`DeltaK <= 64(V_old+E_old+3) + 4096(F+2)`.

These are monotone visited-cell unions. Erasure refunds no history. Initial
banks, inactive reservations, old source backing and all older history are
already entry resources. Creating those resources, acquiring real live
source packets and transporting them to this interface remain caller costs.

`independent_check.py` imports the compiler to obtain the graph but uses a
new sparse simultaneous-transition interpreter, a separate canonical Gamma
encoder and independent integer arithmetic. It never imports the author's
CPU, verifier, fixture builders or arithmetic oracle. Its normal and
optimized executions produce identical receipts.

Six complete arithmetic packet cases have 1,024 signed components each:
widths2,3,5,9,17, plus width3 with a cutoff of bit-length2049. Their two new

checked. The two arithmetic entries are deliberately tested at their
internal seams, skipping the unchanged native stage. These are not claimed

Eight small adversarial controls include returning skipped-first-ADD,
returning wrong-source-equal-to-old212, and returning logical-right-shift

wrong public arithmetic endpoint. Other controls reject a last-component

and a short DATA hole. Failure cleanup is not required or assumed.

One additional bounded joined failure trace begins at the post-INIT
arithmetic entry and executes the original MOVE until rejection, for
536,257 total transitions. It puts -32 at native129, packed address258,
real component516. The independent closed source formula has maximum

The observed public212 update remains committed, bank43 donor stays
unchanged, and the later ADD/SUB are not reached. This directly guards
against an endpoint-only numerical premise and a whole-prefix rollback claim.

The author's separate full positive graph replay is not labelled independent
