# Complete source backing at the real ADD coefficient boundary

This package closes PR2923's missing actual-callback backing composition for
PR2697's `Consumer.apply` → `stream_runner.action` → `add_pass`. It binds the
unchanged Consumer coefficient closure and both its adapter and child branches.
The written bound counts extent preparation, full payload buckets/output,
Counter/Natural tapes, warm numerical slots/templates and all serialized callback
records at the same chronological cuts. The default source Tape factory and
canonical successful semantic contracts remain explicit.

A child coefficient requires more than four continuation tapes: the parent
Callback's four empty tapes and an owned extended Program coexist with the leaf
Callback. The proof charges this Program through its last reference, even after
clearing. It also includes the fresh empty Fields tape created and immediately
replaced by the real Consumer closure. No callback-private count allowance is
left uninstantiated; the closed source dependency inventory gives zero.

[PROOF.md](PROOF.md) gives the explicit upper bound `K0+A`, with K0 all entry
backing once by identity. Numerical high water stays charged after callbacks.
The bound is not asserted sharp. It counts source arrays, not Python object heap
capacity, physical tape placement or a whole recursive reserve.

The finite checker executes the real dimension64 source coefficient twice per
complete81-bit component ADD, cold and with40000/64 retained numerical slots,
and exercises a real child request. An independent address permutation checks
the complete Boolean endpoint. Source `compile_plan`/`trace` and `Layout.extents`
separately bind the actual final-width64 geometry: the real packet is9^128 bits,
which is not materialized. The component is never claimed to execute that packet
or establish actual selected-catalogue membership.

The predecessor's final-width256 coefficient fixture fails Consumer.apply's
64..127 entry condition. The new credited recipe uses root64*64^depth and its
canonical index width; frozen runtime sources are unchanged. All source inputs
are authenticated before compilation. The unchanged nested coefficient AST is
bound with its complete original lexical environment. This is source refinement,
not an execution of the entire Consumer.apply setup.

Checks reject a four-stack-only child ledger, an omitted extended Program and a
one-cell-short complete observer quota. They verify borrowed bytes/heads and
ownership, release of all new nonoutput arrays, and unchanged typed receipts
under normal and optimized Python. The quota is an accounting observer, not a
physical allocation limit. See RESULT.json for the exact regenerated measurements.

Reproduce with Python3.12 and the standard library:

```sh
python3.12 -Werror -B scripts/research_package.py --package research/selected-add-complete-backing
```

The universal result is the written conditional proof; finite replay does not
prove general semantic success. No full GL64 payload, physical reuse/movement,
H2/P3/outer admission, selected frontier change, new kappa, kernel verification
or independent human review is claimed.
