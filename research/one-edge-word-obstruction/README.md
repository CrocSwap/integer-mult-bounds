# Four-projector words at three exponent relations

At every finite length, a full diagonal word on the PR7749 alphabet with
all four types, nonzero labels and at most three saturated relations must
cancel both fresh-type totals. Its only targets are ([u],[u],1,1).
The complete rank-power tariff cannot improve for 0<t<=1. Six calls are
the sharp minimum for a nonzero complete-alphabet diagonal word.

Read [PROOF.md](PROOF.md), [RESULT.json](RESULT.json),
[verify.py](verify.py), [SOURCE-PINS.json](SOURCE-PINS.json) and
[CREDITS.md](CREDITS.md). The proof gives necessary and sufficient
chronology and exact-total conditions. It does not transfer geometric
image dimension into productive targets.

Run from the repository root with Python 3.12 and the standard library:

```sh
python3.12 -B scripts/research_package.py --package research/one-edge-word-obstruction
```

Both modes print `PASS_ONE_EDGE_WORD_OBSTRUCTION`. The source geometry
checker runs unchanged. No physical supplier, new kappa or selected-frontier
change follows. All five framework assumptions remain.
