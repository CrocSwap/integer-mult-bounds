# Native dirty-arena relocation with bounded addresses

Status: an informal universal sufficient theorem with an explicit machine construction. No new κ and no fresh Lean proof are claimed.

## Theorem

Let p be a native Lax13 word-RAM program at word width w. Let A ≥ 1. Assume every direct memory operand in p is below A. Consider any execution of T steps in which every indirect address actually used is below A. Arithmetic values may occupy the full range [0,2^w); only addresses need the bound A. Choose an arena origin b with b+A+2 ≤ 2^w. There is a mechanically constructed relocated program p_b, running at the same word width, that reproduces the source input/output and all active source cells at addresses b+i, uses at most 3T+1 instructions to reach the corresponding state, and leaves every address outside [b,b+A+2) untouched. Initial memory outside the embedded active source cells is arbitrary. Only the two cells b+A and b+A+1 are added scratch. No copy of the arena and no initialization of its dirty exterior is needed. The fixed program p_b depends on b, but the same construction works for every permitted b.

## Construction

Reserve a base cell c = b+A and pointer scratch s = b+A+1. Begin with SET c b. Replace each source instruction by a block of exactly three instructions, padding unused slots with SET s 0. Every direct operand i is replaced by b+i. Arithmetic, SET literals, READ and WRITE retain their values unchanged. In particular data literals are not confused with addresses and are never blindly shifted.

For LOAD a z use ADD s c (b+z), then LOAD (b+a) s, then padding. For STORE z a use ADD s c (b+z), then STORE s (b+a), then padding. Thus logical pointer values remain exactly their original values, and the origin is added only at the point of dereference. A source JUMP l becomes two padding instructions followed by JUMP (1+3l). A source JZERO z l becomes two padding instructions followed by JZERO (b+z) (1+3l). A source HALT becomes two padding instructions followed by HALT. The initial origin setup is at program counter 0; source counter j corresponds to counter 1+3j. Program counters are natural numbers, not data addresses, in the Lax13 model. Reaching the first out-of-range source counter corresponds to the first out-of-range translated counter and halts as well.

## Proof

After setup, relate each source cell i < A to target cell b+i, and source counter j to 1+3j. The base cell holds b; input and output lists agree. All translated direct operands are below b+A. At each dereference, the source pointer z is below A by hypothesis, so b+z < b+A ≤ 2^w; the address addition is exact. Its scratch cell cannot alias any source cell. The LOAD or STORE therefore reads or writes precisely the related cell. Arithmetic instructions have identical operands and the same modulus 2^w, so identical results even when intermediate mathematical values overflow a word. Branches inspect identical words and jump to related counters. READ and WRITE observe identical tapes. Padding touches only scratch. Induction on the source execution proves the relation after each completed block and equality of external input/output. Each source step uses at most three target steps, plus the single setup instruction. Every target write is to a related active cell or one of the two scratch cells, establishing the arbitrary-exterior frame property. The conclusion concerns completed source steps; native HALT is observed at the corresponding final block instruction and preserves genuine halt.

## Why this is directly useful here

The arbitrary dirty helper values in a supplier remain literal data at their existing arena locations. Their values need not be moved or cleaned merely to install an addressing convention. Independent supplier arenas can be relocated and composed provided the caller chooses disjoint owned scratch and respects each actual address bound. This avoids a false inference from the clean initial-state theorem compileProgram_runsTo to a dirty hosted run. The existing Problem 1.8 local theorem compile_correct already begins with an arbitrary representing native state; its Represents predicate constrains only declared scalar cells and valid array entries. Expression-block Reaches.frame gives the corresponding explicit scratch discipline. The present native wrapper supplies a separate constructive arena embedding and frame theorem.

This does not prove a complete recursive ownership schedule or an improved multiplication exponent. It eliminates memory copying for this specific offset adapter with an explicit constant instruction cost. No source-memory bound can be omitted: full-word arithmetic values are allowed, but actual pointer values must fit the selected arena. An arbitrary global memory permutation does not preserve pointer arithmetic without such a dereference adapter.
