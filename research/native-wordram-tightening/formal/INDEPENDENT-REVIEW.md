## DIV-free Newton lowering reviewed separately

For nonzero d < 2^w, choose d' = d*2^s in [2^(w-1),2^w), a = d'/2^w, B = 2^(4w), A = d'*2^(3w). The integer iteration X' = floor((2B^2 X-A X^2)/B^2), starting X = B, is downward-rounded reciprocal Newton. Its invariants are 1 <= X/B <= 1/a and 0 <= e = 1-aX/B <= 1/2. It satisfies e_next <= e^2+1/B. Comparing with the exact sequence a_j = 2^(-2^j), both terms stay at most 1/2, so the squaring map is 1-Lipschitz on the interval and e_j <= a_j+j/B. For k = ceil(log2(4w)), e_k <= (k+1)*2^(-4w) <= 2^(-2w). Therefore t = floor(n*2^s*X/2^(5w)) is floor((n/d)*(1-e)); it underestimates floor(n/d) by at most one. Test n-t*d >= d for the unique possible correction. All subtraction numerators are nonnegative and all temporaries have O(w) bits; the full-word product is lowered using half-word products to a fixed number of native limbs. Zero divisor and finitely many tiny widths need explicit base cases.

Model boundary: the actual Lax13 instruction set has primitive left shift only; its published right shift uses division. The DIV-free strengthening explicitly targets a standard Word RAM with both logical shifts primitive, rather than claiming the same Lax13 machine with DIV deleted; this model boundary is retained in the root proof. Normalization can find the leading bit in O(log w) comparisons and shifts. Word-width discovery may be paid once at setup. All online divisions can then be replaced by O(log w) such native operations; this adds a polylog(p) factor absorbed by the existing strict exponent margins. This is classical reciprocal division reused constructively, not a new reciprocal algorithm.
