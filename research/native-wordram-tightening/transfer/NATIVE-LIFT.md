## Explicit universal parameter choice

Put c=3/32 and Q=min(q_C,c). For rational 0<kappa<Q, set

    q=(kappa+Q)/2,
    stop=(q_C-q)/(2q_C),
    delta=min(1/100, (q-kappa)/(4(q+1)), (c-q)/16),
    epsilon=1-delta,  beta=1-3delta,
    r=delta/10,  layout=delta/100,
    xi=epsilon(1+q)-c+layout.

All quantities are fixed before n grows. The source provider can be stopped at the required interior exponent because

    q_C(1-stop)-q = (q_C-q)/2 > 0.

Here stop is the harmless strict loss used by the provider recurrence/base policy; it is not a license to omit paid exits or owned work. The finite provider lowering is unchanged. Only the dimension, grouping and cap parameters in the actual native caller vary.

## All interface guards, with universal proofs

We have 0<delta<=1/100 and 0<q<c<1/3. Thus beta>=97/100>0, beta<epsilon<1, and r>0. The global gamma guard is

    1-epsilon-r = 9delta/10 > 0.

The full-coordinate group key has size

    K=O(p^(beta+1-epsilon)+p^beta log p),

where beta+1-epsilon=1-2delta<1. Hence K=o(p), and explicitly enumerating the actual coefficient/address/classification functions on every K-bit key costs n^o(1). It is important that the key includes coarse coordinates, not only a local membership header. The separate retained membership guard is

    1-beta-2(1-epsilon)=delta>0.

    xi > 99/100 - 3/32 > 1/2.

The cap lies below the axis exponent because

    epsilon-xi = c-epsilon*q-layout
                >= c-q-delta/100 > 0;

indeed delta<=(c-q)/16. The actual chirp/conditioning guard simplifies exactly to

    1-(beta+2xi-2+r)
      = 2(c-q) + delta(122/25+2q) > 0.

Thus the group guard bits remain o(p). This explicitly preserves the two potentially restrictive analytic inequalities while allowing q up to c. Fixed polynomial setup remains polynomial(s_i,p)=n^o(1), and all online coefficients remain O(p) bits under the retained conditioning bounds.

For the first row, delta <= (q-kappa)/(4(q+1)) implies delta*q < (q-kappa)/4. Its saving exceeds kappa by more than 3(q-kappa)/4. This proves all nine strict comparisons without numerical optimization.

The fused Gaussian row uses the actual shallow tensor circuits; unfused O(Td) Gaussian evaluation does not satisfy this theorem. The record-product row uses global O(p)-bit words on r coefficients; switching to a fresh O(log(rp))-bit local machine would invalidate its tariff. Per-call gathers and restoration are charged in their calls, and extra group scans have their own row. No recurring pass is silently assigned a one-time cost.

Every polylog(p) factor is absorbed by the fixed positive margins just proved. Native preparation is n^o(1), below the claimed work bound. The retained recovery theorem then gives exact packed integer multiplication. This completes the sufficient assembly argument.

## Meaning of the 3/32 endpoint

This theorem establishes the open range below min(q_C,3/32). It does not establish equality at either endpoint. The number 3/32 comes from this caller's cap inequality xi<epsilon and its conservative boundary matrix-multiplication certificate. It is not a universal lower bound or impossibility theorem about Word RAM multiplication, suppliers, matrix multiplication or alternate Gaussian geometries.

In particular a correctly admitted complex-only supplier with q_C near 0.0156 would transfer through this native caller without needing to improve a BIT supplier. But PR #4629's finite endpoint-chart and full provider obligations must be independently settled before such a numerical consequence may be reported. The checker includes a 0.0156 arithmetic example only; it is not evidence admitting that provider.
