# Eight causal cuts raise the ordinary BIT saving to 0.00385896149

Eight edits remove a rank-one transfer and a rank-three transfer for each rank-four helper given up. Each edit changes when a different sender receives its data. The unchanged caller runs the resulting binary word 36 times. Its full signed price crosses between 0.00385896184247 and 0.00385896184248. Two finite ordinary stages raise the selected BIT saving from 0.00385248 to **0.00385896149**. The proof uses the five assumptions of the selected multiplication framework.
