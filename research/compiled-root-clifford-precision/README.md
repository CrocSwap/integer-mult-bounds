# Current compiler: an exact grid from unfinished context depth

For the ideal recursively substituted current complex uniform template, this
package derives an explicit common binary grid from the **unfinished raw
caller contexts**, while charging a Clifford denominator on the complete root
selected factor only once. It joins the published current single-caller
precision result to the actual chronological product and integer compiler,
without assuming that compiler's precision closure conclusion. **No new κ.**

After the separately paid root preprocessing, let d>=1 be the complete root
selected dimension, p the incoming fractional grid and each real/imaginary
component have magnitude<2^h. The sufficient explicit format is

    F=p+d fractional bits,
    W=p+h+2*d+3 signed bits per component,
    W+6 numerator temporary bits.

The proof uses the current chronological power1024 and H=65807000000000,
N=2^H. Combining #4586's credited fractional rank descent with actual class
and raw-caller depth gives K_star=1024*145^1024*(H+1)^2. This coefficient
has7455 bits and is checked exactly; N is never constructed. The compact
inequality32*K_star<2^8299<N absorbs the unfinished-context debt into the
displayed linear format. Increasing the fractional grid is accompanied by
the recomputed signed width above, not an unfunded precision conversion.

Earlier #2287/#2390/#4359 already proved an O(p) common format. The new
result is this explicit current compiler/ordinary-root precision implication
and its source-derived context bound, not that asymptotic existence claim.
