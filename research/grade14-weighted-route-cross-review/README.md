proves full low/high inverse return. Independent productive endpoints allow

The common weight needs **route invariance** for algebraic commutation.
#7837's ancestor-only restriction is sufficient. The new positive control
also checks a genuinely fresh-dependent invariant weight built from det(g)
for the determinant-one test routes. All actual port maps have determinant
-1, so functions of det(g)^2 commute with those maps, though not automatically
with subsequent compiler matchers. This refinement supplies no new descriptor,
cost or full runtime claim and leaves the source theorem unchanged.
