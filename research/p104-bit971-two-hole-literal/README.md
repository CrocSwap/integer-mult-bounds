# Compile the literal two-hole BIT control and identify the erasure bill

This is a destructive-INIT/CLEAR symbolic interpreter and explicit first dirty-retirement witness. It does not certify physical reversible erasure, a third omission, finite transfer or a new κ.

A 679-owner literal program with 2,872 paid transfers, original 971 kept, and 968/1564 omitted passes both 679×679 public maps and protected 3553. Each orientation has 3,551 dirty retirements. The full BIT change is approximately −35.276054260872 at K and −35.276054075089 at near.

Observed validation. The archived owner VERIFY.log reports successful source inventory, both primitive orientations and owner/clock charts, regenerated full invoices, a damaged input rejection and the first erasure witness.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `c8435ab383c9062932c8d289ebadc13257621f955f42ff0113d39f06921d4d14`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run the extracted README.md commands.
