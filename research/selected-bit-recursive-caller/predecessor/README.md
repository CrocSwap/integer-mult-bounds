# Complete selected BIT node for 64 <= n < 128

We construct the first internal selected BIT node from actual source packets
and completed below64 leaves. We include the original-weight remainder peel,
fresh-row decoding, the complete local/idle/bridge/exchange caller, an
independent external gap and return to the original row order.

In [PROOF.md](PROOF.md) we prove the scoped stream refinement under the pinned
predecessor contracts: arbitrary dirty payloads return with weighted reversal
F_A, unchanged row/spectator coordinates and cleared owned work. Under the
retained root coupling we construct a complete `C_q V(n+w)` time bound.
We leave numerical reserve admission, larger recursion and full transfer open.
We claim no new exponent or formal-kernel verification.

The caller completes the handoff from
[PR2569](https://github.com/CrocSwap/integer-mult-bounds/pull/2569) and the
conditional whole-call staging interface in
[PR2475](https://github.com/CrocSwap/integer-mult-bounds/pull/2475).
We preserve PR2234's full 28278-request vocabulary, the selected logical
denominator W=28416 and compatible unused-row factor 9475. We use a common
view after local routing and the native family chart for idle requests.

Within a local invocation we scatter repeated-family roles into the latest
family state. We finish one common low before gathering the next. Both
requirements matter: repeated faulty sweeps can cancel at the final endpoint,
so we check the first sweep and retain separate lost-update witnesses.
