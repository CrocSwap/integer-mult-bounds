# Saturated frames with a different legal tie order

The scalar producer is the unchanged frozen PR117 DAG. Its support identities,
root scatter, /21 decoder, carrier matching and complete role word are unchanged.
The bit supplier and all inherited stopped-product, analytic and fixed-tape
interfaces are unchanged. This is a conditional finite witness, not a proof of
those all-size interfaces.

For each eligible role, the starting candidate is the nondegenerate part already
accepted by the inherited candidate filter. PR114/120 saturated placement intersects
it with incompatible target-chain frames. If an intersection is degenerate, symmetric
binary elimination splits off norm-one lines or alternating dot-one planes; these
blocks are mutually orthogonal and nondegenerate. The residual radical is discarded.
Containments are checked again after every extraction. Every operation decreases
dimension or terminates, so placement terminates with a nondegenerate subspace of
the first owner and of every reached target hyperplane. The placed frames are nested
on each target. The accepted schedule therefore satisfies the same inherited
frame hypotheses regardless of candidate priority or tie order.

The exact rational primary priority is 2^dimension / reached_targets^2, followed
by dimension. This package changes only the final tie order to a shuffled sorted
candidate list with Python Random seed 1. The frozen complete profile and independent
replay verify the resulting finite witness. A 16-seed search selected this order;
no global or local optimality is claimed. Randomness is a search device, not an
assumption of the bound. Seed selection does not relax any verifier assertion.

The unchanged expanded readouts contain coefficients as large as 55/42. The PR118
unit-shear decomposition and charge are retained: 55/42 = 1 + 13/42, each piece
at the same frame. For an off-diagonal elementary matrix E, E^2=0, hence
(I+aE)(I+bE)=I+(a+b)E; inverse order and signs restore exact dirty values.
There is no additional frame transition between pieces, while every scalar
addition is paid. The exact independent audit checks each coefficient, literal
forward/reflected frame incidence, dependency cut and complete child histogram.
The precision/row bridge recomputes the conservative scalar cost and all 47
constraints and seven margins. The next complex and kappa grid points fail.
