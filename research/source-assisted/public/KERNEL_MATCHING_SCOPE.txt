2. Why smaller recipient dimensions are always preferable

Let h=22, m=66, and 0<a<1. Set f(r)=m^a r^(1-a)-r, with f(0)=0.
Replacing a rank3 retirement and a dimension-v birth by one handoff
changes the three-core excess by the positive saving

  w_a(v) = 3 [ f(h-3) + f(v) - f(v-3) ].

For v>3,

  w_a'(v) = 3 [ f'(v) - f'(v-3) ] < 0,

because f is strictly concave. Thus recipient weights decrease strictly
with dimension for EVERY 0<a<1; no exponent-specific weight tuning is
needed. All 706 donors can be matched, so the physical count R=11,056,
W=13,696, and deficit1,320 stay fixed while comparing full matchings.

3. Prefix rank certificate

The recipient subsets that can be matched injectively to donors form a
transversal matroid. Process recipients by increasing dimension and use
an augmenting path whenever the current recipient can be added while
keeping every previously accepted recipient. Matroid greedy attains the
rank of every dimension prefix simultaneously.

The implementation does not ask the reader to trust that optimization
claim as a black box. For every k from0 through19 the JSON receipt gives
both a matching in the graph restricted to recipient dimension<=k and
a vertex cover of exactly the same cardinality. The checker verifies
the matching's distinct endpoints and every eligible edge's coverage.
These are direct lower and upper certificates for the prefix maximum.
It then checks that the final selected matching attains every maximum.

The rank at k=5 equals that at4, at k=18 equals that at17, and ranks
below4 are zero. The selected recipient histogram is

  13:13, 14:115, 15:35, 16:14, 17:13, 19:80.

For any other full matching, summation by parts expresses the difference
in total saving as a sum of nonnegative prefix-count differences times
the positive gaps w_a(k)-w_a(k+1). Hence this selected matching maximizes
the excess saving for every 0<a<1 on this fixed graph. It also maximizes
the resulting local characteristic root, because W and the deficit are
unchanged. Matchings within equal-dimension ties need not be unique.

5. Scope of the optimality statement

The local lift formula b=max(0,t+d-r-n), or its source-control quotient
version, is separately minimal for each FIXED local boundary problem.
This matching certificate closes kernel-only reuse for those fixed
minimal completions. It does not prove a global optimum over other
frames, query modules, phase cuts, source-control opportunities, output
schedules, boundary bases carrying different requests, nonzero-fresh
complement routing, or different multiplication constructions. It also
does not replace the physical/affine cleanup and all-size bridge proofs.

  python public/kernel_matching_prefix.py \
    --witness decision/aligned_parity_purified_flow.result.witness.json \
    --profile decision/aligned_parity_purified_flow.result.json \

the same three paths. Defaults point to the selected witness/profile and
public/kernel_matching_prefix.json. The default mode requires the input
matching to attain every prefix maximum. The optional --optimize mode is
only for producing an explicitly unselected proposal from another input.
