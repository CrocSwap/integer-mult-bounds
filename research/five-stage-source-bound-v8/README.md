Use Python 3.11 or newer with assertions enabled and SymPy 1.14.0. Install requirements.txt into an environment outside this package if necessary. Verification itself uses no network access.

From this directory, run:

The command checks Python, SymPy and every package/source hash first. The output directory must be new and outside the package. Failed outputs are preserved. For preflight only, use `python3 -B verify.py --preflight-only`.
