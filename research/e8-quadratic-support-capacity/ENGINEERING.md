# Code scope and verification

The package adds one bounded mathematical replay, a separate reconstruction
and behavioral controls. The only executable input is the existing pinned
geometry module. The selected construction and frozen predecessors are
unchanged. Separate Before Serializing Shared State led to this owned
package/branch/cache and short shared Git locks. Prove It Works led to
actual live-label binding, explicit attaining supports, sign counterexamples
and a read-only Git-free export. The investigation playbook governed the
proof-dependency audit; the user explicitly authorized the resulting package.

Power of Ten inspection covers all three new Python files and the imported
geometry entry `root_data()`. The latter uses bounded eight-dimensional
rational elimination and 120 root lines. Other geometry routines, including
its large censuses, are not called.

1. Control flow uses finite loops, direct functions and structured exceptions.
   No recursive call path is introduced. Files and temporary directories use
   context managers. A failed check raises without publishing a result.
2. The ambient cube has256 vectors; polarization checks256 squared pairs.
   Root reconstruction has120lines,8coordinates,112live bindings. Witness
   directions have at most5generators and32points. Branch enumeration has
   two dimensions and at most3polar ranks. Tests cover35small planes and
   16offsets. The source inventory is exactly3rows and each file<=100000bytes.
   Registered commands each have a30second timeout. No unbounded search runs.
3. Python/Fraction allocate dynamically. This is a managed-runtime deviation,
   bounded by those fixed collection sizes and source limits. There is no
   service/steady-state loop. Resources leave scope on failure or completion.
4. Every new function is below60physical lines after formatting. The largest
   functions authenticate one manifest or check one evidence receipt.
5. Executable `require` contracts stay active under optimization. They check
   polarization, label bijection, source identity, exact witnesses and radical
   bounds. Tests include invalid inputs, file drift and an opposite-sign model.
6. Mutation stays in local fixed-size structures. No shared output or global
   registry is modified. A requested receipt must be outside the checkout and
   is opened exclusively. Default replay only reads committed evidence.
7. File sizes, source hashes/Git blobs, exact inventory, rank arguments and
   receipt equality are checked. The supported input is a trusted published
   source set. Matching a self-replaced manifest alone is not authentication
   of its provenance; registered Git pins and reviewed/exported bytes supply
   that binding. A receipt write checks its returned character count.
8. One deliberate metaprogramming deviation executes a compiled, bounded,
   hash-authenticated fixed geometry source. It uses precisely the verified
   raw bytes and cannot read a preexisting bytecode cache. This retains the
   source convention without copying or editing a frozen predecessor. There
   is no user-provided module selector or generated code. Follow-up imports
   are standard-library fractions, itertools and math.
9. Calls are direct except the single pinned geometry module entry. The
   independent implementation imports no primary or predecessor executable.
   Tests call both implementations explicitly and patch only local test state.
10. Registered replay runs warnings as errors. Ruff E,F,B,UP,SIM diagnostics,
    formatting and warnings-as-errors compilation were run on touched code.
    Broader repository linter configuration is outside this isolated package.

The written character-sum proof is not proof-kernel formalization. The old
global flat censuses, shortening proofs, selected cold replay, Lean and Docker
are unrun. No runtime speedup measurement is claimed.
