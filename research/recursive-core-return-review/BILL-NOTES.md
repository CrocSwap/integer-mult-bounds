# Handwritten support for the deliberately coarse core bill

This supplements, rather than edits, the frozen `CORE-PROOF-DRAFT.md`. It is a static handwritten accounting argument for the current fixed two-site core at source head `e4e52d6ba2c805fa78bb57778c3b7bbc064edba5`. No code, table constructor, interpreter, checker, numerical script or kernel was run. Source author-side theorem/check exposure is retained. The count below is an upper bound on **aggregate helper categories**, not an independently regenerated emitted-table census or a claimed exact optimized transition total.

Two wording qualifications apply to the assembled review. CALL moves the readonly unary-depth head right; RETURN moves it left. Omitting either restoration/movement may break the invariant, but there are not two decrements. Also, the core assumes valid prepared physical LEFT/BASE delimiters and encoded entry packets. It does not manufacture those outer delimiters or pay their unspecified production. `K_entry` is a retained-space term; adding it to a space inequality does not silently pay for entry preparation in time.

## Premise boundary and logical tables

Let K=max(16,L+11), e_b=bitlength(b), V=L*A*R at the current node. Retain the isolated shape/router/machine contracts and their numeric envelopes as premises. In particular this note does **not** independently reprove the complete original1000V producer/consumer bill or94V router induction.

There are at most two mapped shape calls per internal node, safely allowed1000V logical transitions each, including their promised local preparation/retirement. Split plus merge use at most188V logical transitions under the retained94V contracts. Every old instruction is lowered through the actual codec by at most32 physical transitions, including its fixed control transfer. Hence these logical tables consume at most

`32*(2000+188)*V = 70,016*V`.

Some retirements are also allowed in the raw estimate below; double charging is safe. A leaf uses no shape call. None of these quantities prices a Gaussian/BIT leaf, numerical ancestor descriptor or a different final template.

## A conservative participating-extent bound

All data-bearing local packets, unary guides, headers, grants and temporary return packets have logical length at most V on the valid source domain; in particular at an internal node H*R<=V/L^2 and A>=L*H. A complete encoded packet includes its two logical markers and may materialize one extra logical BLANK on a movement boundary. With its physical delimiter, a conservative per-payload span is `3*(V+2)+3+1 <=8V` because V>=L>=2. Empty payload roles use less. Summing over K payload roles therefore bounds their current participating spans by8KV.

The newly written control frame has one tag and one unary-offset terminator per payload, a unary offset no greater than that payload's participating span, plus a separator, at most one phase bit and frame markers. Its length is at most `8KV+2K+4 <=10KV`. This is the current frame, not the whole older control stack. Push scans only the local parent segments; pop scans the current control record and the just-exposed parent segments. The final previous-top scan traverses the blanked current record to its immediately preceding END/BASE; it does not scan every older frame.

The four relays hold only full selected packets or headers, each bounded by the same8V allowance. Phase, global H/width/depth positions and finite endpoint checks use another fixed number of such extents. Thus **100KV** is a generous bound for the aggregate participating local/control/relay positions of one node/edge event, including constant markers. This is a source-domain extent argument, not a maximum inferred from an author fixture. Root width setup is charged separately below. Inaccessible prefixes are excluded from scans because the valid local delimiters stop them; they remain in K_entry for space.

Shared node housekeeping—aggregate postmerge bank/work retirement, root marker/head checks, root H retirement and final halt—and the fixed leaf head setup/return can be covered by fewer than eight further groups. Assigning them conservatively to the per-site allowance still leaves fewer than64 groups. The leaf's data loop is charged separately, not hidden as one constant-time group. The source's two-site allowance of64 groups per site therefore has room for endpoint checks and source-label bookkeeping without claiming an exact PC count.

Each raw loop step performs only a fixed branch/write/unit move/jump sequence; the displayed helpers use fewer than128 physical transitions per participating scanned position including terminal checks, and at most four scans/rewinds of their participating aggregate extent. The K-wide push/pop loops count local and control traversal in that extent. The conservative raw bound is therefore

`2*64*4*128*(100KV) = 6,553,600*K*V`.

This bound intentionally overpays constants. It is not a claim that every helper makes exactly four passes or that every physical position costs128 steps. Counting one full tape extent K times after already summing K extents would add an unnecessary second K; treating the K-wide loops as constant-size data would omit work. The aggregate formulation avoids both errors.

## Leaf, root and width costs

For a leaf, each selected-bank bit follows one codec branch, one codec write, one codec move and one goto. Charging each of these by32 gives at most128 physical transitions per logical bit, plus its terminal code branch and the raw body-head returns. Its bank has V/L bits. A loose256V allowance covers this loop and its fixed endpoint/return work; this is negligible compared with the displayed C_time slack. Split/merge and raw nonroot return are still charged as above.

Root BASE/END detection, the root control-head return, H retirement and halt also have the actual scan/marker costs included in the raw extent allowance. A root at d=0 has no artificial CALL, pop or depth decrement; it nevertheless has a real leaf loop, merge, H retirement and final halt. The root source/A/R/width/depth preservation premise is not a zero-cost erasure premise for H.

For once-only H generation, the multiplier's carry is a compiled state in0..b-1. One binary input digit uses a branch, write, move and goto; carry drain and complete rewind add O(ell(b)) and O(current bitlength) work. The maximum H bitlength over the w-1 products is at most e_b*w+1. Summing all products, the retained width converter and cleanup gives a conservative logical estimate O((e_b+1)*w^2); source bound `(100+20e_b)*w^2` is loose for these concrete loops. Codec factor32 and raw coded-guide retirement remain explicit. Since `w^2<=2*b^(w-1)=2H<=2V0`, this setup is O((e_b+1)*V0), not repeated at every node. A bound of `100,000*(e_b+1)*V0` is already generous for the displayed digit, rewind, conversion and cleanup paths, and fits well within the source's10^8 coefficient. This does not audit natural-root A/R generation, which is a separate program.

Combining raw, logical, leaf/root and width allowances fits

`C_time=10^8*(K+e_b+1)`.

The large margin is deliberate: the dominant raw coefficient is6,553,600K, whereas the source allows100,000,000K; logical and leaf terms are below one million per V, and the once-only width allowance is below100,000(e_b+1)V0. No exact optimal constant, compiler table size or measured runtime follows.

## Retained-space assembly

One active local frame, its current control record and relays fit the100KV participating-extent allowance above. Root width/H guides and their coded cleanup have O((e_b+1)V0) extent. Sequential sibling calls return to the same first blank suffix with the same shape-dependent lengths and restored heads; they do not append a new backing block per completed sibling. However every visited physical000 cell, frame delimiter, saved-head mark and later-erased cell remains charged.

Thus the source's conservative

`C_space=1000*(K+e_b+1)`

covers the local frame/record allowance and global setup with a large constant margin. It yields `K_entry+C_space*sum_(j=0..d)V0/L^j`, strictly below `K_entry+2*C_space*V0` for finite d and L>=2. Time instead uses the actual two-child occurrence sum `V0*sum_(j=0..d)(2/L)^j`, plus once-only width setup. L=2 retains its depth factor in time; maximum backing still has the geometric active-chain bound. Neither inequality discharges preparation time, physical stock/precision, actual final-template branching, ancestor weights, BIT/Gaussian semantics or any selected framework assumption.
