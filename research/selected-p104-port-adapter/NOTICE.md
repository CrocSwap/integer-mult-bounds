This package uses the E8 root-line and frame-pair model from DreamingOfClouds' PR717 and the exact frame-pair decoder construction from themilkman216's PR968, via the pinned repository verifier listed in SOURCES.json. The selected 112-port input is the retained local word identified by the current selected record and its source manifest. No predecessor source file is copied into this package.

The P104 frame decoder and its COPY-rank proof remain attributed to those predecessors. The new contribution is the exact GL(9,2) adapter from the selected word's port labels, the mapped eight-port deletion and the entrywise reindexed decoder witness.
