# A positive native C tensor leaf as one literal tape program

**Scoped numerical/interface lemma. No new kappa; all five selected global
assumptions remain.** Prepared for Jerry Chen / @CubeJerry with substantial
OpenAI assistance.

One fixed 6,826-location, 29-tape graph executes the positive rank-one central
child of actual #7000 MOVE24472, `["MOVE",415,3,99,false]`. The scalar factor
is `C=[[1+i,1-i],[1-i,1+i]]/2`; for column width f it executes the entire
`C^(tensor f)`. Rank one does not mean f=1.

The supplied entry is the packed `[P]x[2^f]^9x[S]` field of the published
literal native phase component, with r common-grid Gaussian coefficients
per address, w signed MSB bits per component, and six Gamma values
`f,r,P,S,w,cutoff`. Its first five fields agree with that phase ABI; its
opaque-tail contract preserves the added cutoff. The old 23-field coded
descriptor conversion and strided packing remain supplied caller work.

## Result and complete bill

The program generates all f axis strides, splits complete suffix blocks,
executes exact four-input Gaussian rows, checks parity and final signed fit,
restores MSB order and merges full arrays. Two persistent private field banks
alternate. DATA commits on its original owner only after every axis succeeds.

For `N=PSr2^(9f)`, `V=2Nw` and header length E:

`T<=65536(fV+E+1)`, private history `<=K_entry+64(V+E+1)`.

Metadata, source access/return, every axis, full staging, installation, resets
and erasure are included. Cutoff stays binary, so a huge threshold costs its
encoded length. All heads/private bodies/guards return on success. Erased
history remains charged, and smaller clean calls scan only current shapes.

The accepted numerical domain requires integral w-bit outputs at every axis.
Final-image fit is insufficient: real f=2 fibre `[1,0,0,1]` has final image
`[0,1,1,0]`, but its first axis is half-integral and must reject. Named arithmetic
and finite width/cutoff/cardinality failures preserve public DATA. Failure
private cleanup/retry is not claimed, unlike the stronger structured #6967
lifecycle.

## Contribution and predecessor boundary

#3091 already supplies the C identities, tensor reserve, physical axis method
and direct O(fV) tariff. #6967 binds its structured implementation to the old
current-coded interface; subsequent rounded/cutoff wrappers leave literal
numerical lowering open. This package adds a fixed local-symbol graph,
generated geometry, same-owner staging and retained-history proof at the

positive normalization. Its two surrounding monomials, full old codec,
complete MOVE, enclosing compiler and nonleaf speed remain outside the claim.

## Reproduce

With Python 3.10+ from this directory:

```sh
python -I -W error -B bind_source.py
python -I -W error -B check.py
python -I -W error -B check_big.py
```

Add `-O` for optimized Python. `check_big.py` also requires a C++17 compiler
named `c++`; it compiles the included table interpreter in a temporary folder.
No downloaded library is needed. C++ interprets the same literal table; it is
test infrastructure, not an additional machine-model operation.

Eleven exact source/blob pins and wrong-rank/inverse-C controls protect the
source gate. Seven complete m=9,f=1 Python successes use 6,201,327 transitions;
six malformed/arithmetic packets preserve DATA. Three grow/shrink/regrow calls
retain the same 29 owners and private history 42,093.

The complete **actual m=9,f=2** execution has 262,144 addresses, 2,621,440 bits
and 704,382,528 literal transitions. A direct tensor-row polynomial oracle
agrees, with every header/head/private/exterior check passing. A first-axis-only
mutant retires correctly but fails that oracle. The complete endpoint-only
fibre above rejects with zero DATA writes. The C++ interpreter also matches
the original interpreter's exact f=1 count. This local f=2 packet uses cutoff
2; it is not a globally certified selected-producer witness.
