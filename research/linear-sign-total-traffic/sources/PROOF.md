# Executable all-size selected BIT caller and complete logical reserve

This package extends the selected first-range caller of [PR2697](https://github.com/CrocSwap/integer-mult-bounds/pull/2697), by Jose Manuel (`jmbarrancoml`), to every internal width n>=64. It implements the previously missing whole-packet recursive call and return, with an independent fresh-row coordinate, exact projected spectators and separate numerical frame banks. It also replaces the inherited digit-pass address sign by a linear-traffic sign, which is necessary when the fallback normal form is repeated over arbitrarily many columns.

The result is a scoped construction and source-level proof. It supports the executable baseline p=1 and a complete logical live-symbol reserve under the stated root coupling. It does **not** establish the selected native H2 saving `a=384599/10^10`, a fixed-physical-tape compiler, the outer borrowing wrapper, the complex supplier, or a complete multiplication theorem. The selected frontier is unchanged.

`predecessor/` preserves the PR2697 package at exact head `a53fdf4bcbe33c6732f0bec1badc8c023380f9d1`; [PREDECESSOR.json](PREDECESSOR.json) gives its author and byte pins. The selected finite operators, normal forms, chronological guards and generated-weight grammar remain attributed to that package and its [source notice](predecessor/NOTICE.md). The compatible stock comes from [PR2234](https://github.com/CrocSwap/integer-mult-bounds/pull/2234), `d047ef86fbc5b1614d3d8e2b8d3441413beab73f`, retained in [selected-bit-local-ring-sweeps](../selected-bit-local-ring-sweeps/PROOF.md). The earlier [written recursive closure](../selected-bit-recursive-closure/PROOF.md) supplies the paid profile and moment estimates; the present contribution implements and audits the missing all-size caller boundary.

## 1. Complete input and endpoint contract

Fix an odd prime q, precision w>=1, atom radix A=q^w, m=64, W=28416, P=28425,

    N = |GL_64(F_q)|,  H = q^(4096(w-1)),
    K = lcm(W,P) N H = 269241600 N H,
    D(n) = 0                              for n<64,
    D(n) = 1+D(42 floor(n/64))             for n>=64.

At a node of width n>=64, use fresh-row count R=t K^D(n), t>=1. The complete input order is

    [C physical frozen-prefix ordinals][R fresh rows]
    [B][head A^n][G][tail A^n][S].

C,B,G,S are arbitrary positive complete extents. Frozen prefixes may repeat and carry arbitrary correlations in their Boolean payload; equal field values do not identify their physical ordinals. The incoming diagonal unit a_i is generated by the source-bound encoded program. It reads the frozen prefix and encoded coordinate i only. It cannot inspect fresh family/low/high/unused-row coordinates, body addresses or spectator values.

The required address endpoint on each frozen prefix is

    head_i' = a_i tail_(n-1-i),
    tail_(n-1-i)' = a_i^(-1) head_i,        0<=i<n,

with every row and spectator coordinate preserved pointwise. The runtime returns the Boolean pullback of this address permutation. Source, input directory and input program are preserved, and the owned output and caller heads are reset. Owned payload intermediates and live numerical words close; logical frame banks are released. This last statement does not assert sequential erasure of their permanent template/LEFT cells on physical tapes.

The split is R=WNHU with

    U = t*9475*K^(D(n)-1),
    269241600/28416 = 9475.

The implementation passes `child_stock=U` and `child_before=B` independently through `Driver` and `Consumer`. Their product U*B remains convenient for primitive scans but cannot replace U in the child input contract. The node checks the compatible 9475 quotient; the all-size theorem requires the displayed full root stock, which is stronger than merely passing that local check.

## 2. Remainder and projected child geometry

Write f=floor(n/64)>=1 and delta=n-64f, 0<=delta<64. `peel.events` handles the delta pairs with original head coordinates 64f+i and absolute tail coordinates 2n-1-(64f+i), using the original frozen incoming coefficient at 64f+i. It appends no fictitious current field. The remaining logical core has 128f atoms and embedding

    phi(p)=p                 for p<64f,
    phi(p)=p+2delta          for p>=64f.

Its middle spectator is the ordered product `[peeled head A^delta][G][peeled tail A^delta]`. This mixed-radix regrouping is injective, so preserving it restores each original coordinate rather than only its product size.

For a child let a=phi(first), b=phi(second), c=width. The runtime checks c>0, a+c<=b, b+c<=2n, that each complete chunk lies in one original bank, and that mapping each final atom agrees with a+c-1 and b+c-1. These last checks rule out a chunk crossing the embedding discontinuity.

The complete selected packet can then be read, without moving any payload, as

    [C H frozen prefixes][U][B'][A^c child head][G'][A^c child tail][S'],

where

    B' = B*A^a             * (G if a>=n else 1),
    G' = A^(b-a-c)         * (G if a<n<=b else 1),
    S' = S*A^(2n-b-c)      * (G if b+c<=n else 1).

Exactly one factor receives G. These formulas preserve coordinate order, including old peeled coordinates; they are stronger than a volume equality. `layout.child_extents` implements them with encoded comparisons and cardinality tapes.

| Trace case | Logical first | Logical second | c | G location |
| --- | --- | --- | --- | --- |
| good rank r, 1<=r<=42 | 0 | (128-r)f | rf | middle |
| pair/unit across banks i<64<=k | if | kf | f | middle |
| pair/unit inside head i<k<64 | if | kf | f | suffix |
| pair/unit inside tail 64<=i<k | if | kf | f | before |
| head half-reset on k<64 | kf | (k+1)f-d | d=floor(f/2)>0 | suffix |
| tail half-reset on k>=64 | kf | (k+1)f-d | d=floor(f/2)>0 | before |

A half-reset retains the central A^(f-2d) spectator, including the middle atom for odd f. For f=1 it is omitted. In the good case B'=B, G'=G*A^((128-2r)f+2delta), S'=S. Every selected child satisfies the bank and contiguity checks.

## 3. Program extension, ordinal preservation and completed return

For c<64, `trace.child` keeps the completed eight-primitive weighted leaf. For c>=64 it yields ENTER, INVOKE, RETURN with the same encoded boundary. `packet_engine` checks the parent identity, source code, child kind, field, orientation, half flag, positions, width and depth, and permits exactly one INVOKE between matched boundaries. Primitive events are forbidden inside an unresolved internal child.

On INVOKE, `recursive_call.child_call` constructs one source-bound child Request and calls the inherited `children.extend` once. It appends the parent source/rank/field/orientation/half and exact parent/child sizes. `Callback.step` verifies the exact rf, f or floor(f/2) formula and strict contraction. The new descriptor depends on the unchanged parent program and fixed low-class branch, never on a selected numerical high field. Reading the first directory prefix validates the encoded context; it does not choose the branch or replace the complete directory by that representative.

The child receives the full current directory of C H physical prefixes, with h+1 frozen fields, and the whole selected packet. The call lies outside the prefix loop. No high-prefix value or repeated frozen prefix is deduplicated. The child's own `produce` appends its new field after those h+1 ancestors. Its incoming weight grammar has exactly the old fields and cannot read that new field. Ancestor field ordinals and their original source codes remain authenticated by the inherited callback.

`Frame` creates separate residue/index arenas, copies encoded words and program symbols without runtime integer decoding, and constructs the child's `SelectedNode`. The scheduler uses an explicit generator stack, so Python call-stack depth does not impose an upper width limit. A single shared fixed-capacity arena would not suffice for arbitrarily many suspended parents.

`node.selected_topology` retains one source topology on the shared fixed-q
Catalogue. The inherited recipe/call caches are therefore bounded by source
labels and low classes, rather than by the number of completed child invocations.
This sharing is necessary for the one-time compilation allowance F_q below.

After the child returns an owned output, the engine clears its previous owned current packet and resumes the exact saved parent trace. The input source remains preserved. Family scatter always merges into the latest family state, including earlier returned roles. Private COPY retains the copied source for its literal lifetime; ERASE still checks the inherited chronological equality guard. The generated child preserves every spectator, including unused U, so it cannot invalidate those guards.

## 4. Termination, compatible stock and endpoint induction

Every child has positive c<=42f<=21n/32<n. D is monotone; D(c)<=D(n)-1. Hence K^D(c) divides U. After j internal dispatches the fresh row count is

    t*9475^j*K^(D(root)-j).

If an actual child has less depth than the largest possible branch, the extra power of K simply increases its positive row multiplier. All routes and body operations treat these rows as complete spectators. Split followed by merge restores their original mixed-radix ordinal pointwise; spare stock is neither discarded nor zeroed.

Strong induction on n proves the endpoint and ordinal contract together. The base consists of the inherited completed leaf operations. At an internal node substitute the inductively completed children into the pinned good/fallback normal forms, then into the chronological local words and global hosting schedule of PR2234/2697. The selected full-ring coefficients and source bindings are unchanged. The delta peeled pairs are disjoint from the embedded core and use the same original frozen weights; their composition completes all n pairs. Directory and program validation closes the field-scope contract on each return.

The compatible lcm stock is deliberate. The smaller live-only divisor from [PR2420](https://github.com/CrocSwap/integer-mult-bounds/pull/2420), `c0b8224f4331dfc4a4b115bd728b0bbee437fbed`, changes caller premises and is not silently substituted here.

## 5. Linear address sign and the actual baseline recurrence

This section restricts the endpoint contract to the selected admissible fixed prime q>=2^80 and the root-coupled precision/history domain stated in section 6. The endpoint construction itself applies to odd source-admissible primes, but the displayed epsilon and imported moment gaps are not asserted for all odd primes.

The inherited sign uses w digit passes. A fallback has signs in every column, so retaining that implementation would introduce an f*w local factor. `linear_sign.sign_address` repairs this concrete all-size issue. On `[before][A][suffix]`, copy the zero slice; move by charged unit head steps to the last nonzero suffix slice; copy each nonzero slice forward while visiting their starts in reverse order; then advance to the next outer row. This implements x->-x modulo A, preserves the source and resets both heads. Total source-head movements, including rewind, are at most 6V. Counter initialization and decrement remain explicit and have the inherited amortized linear scan charge. Thus all f signs cost O(fV).

Adapter ADDs have O_q(V) complete-fibre cost after their numeric preparation is charged to the associated complete fibres. There are O_q(f) adapters. Peel has at most 63 pairs and costs O_q(wV). Owner routes and ordinary leaf atom swaps still use O_q(wV) implementations. The current code therefore has the **p=1 baseline**, not a general p=1-a<1 primitive contract.

For completeness, the preparation absorption is an asymptotic source argument, not a measured finite invoice. Fixed-size ring arithmetic is polynomial in L,I,h. A pair expression branches at most twice per ancestor, giving at most 2^h times a fixed polynomial. Under the root coupling 2^(h+1)<=8e² and e<=w^(10000/17), this is a fixed polynomial in w. Its ratio to the complete target-fibre factor q^w has a finite supremum over w>=1. Old/current directory and frame setup costs have the same type of polynomial absorption. Spectator count initialization is charged to its scan; arbitrary spectator sizes stay in canonical count tapes. For independently chosen widths/history, retain those preparation terms explicitly.

The source-bound paid profile is

    (H_1,H_2,H_3,H_4,H_5,H_6,H_7,H_42)
      = (381024, 400416, 22752, 26880, 29376, 17376, 26784, 288).

Here T(n,w) denotes a uniform normalized upper bound over admissible descendant
contexts with the original root e and its coupling retained. Atom precision w
is fixed for the entire recursion; it is not recomputed from a child's n.
The time unit is charged logical Tape reads, writes and unit head movements,
with the stated preparation absorption. It is neither Python wall-clock time
nor a bound for the still-unimplemented fixed-physical-tape lowering.

A bad class has at most 3*(127+254+16256)=49911 main/half child calls. This is below the inherited 32*64² allowance. Their widths are at most f. For each paid request, the retained nonzero-minor argument bounds the bad fraction by 2*64^3/q: the minor union bound is conditioned on GL64, whose density is greater than one half. At the lower allowed boundary, 2*64^3*10^16 < 2^80, so the same epsilon=10^-16 is valid uniformly for every allowed prime. There is no union over all request labels. With F=32*64²*sum H_r=118606528512, the normalized stopped recurrence is

    T(n,w) <= Cw                                             (0<n<64),
    T(n,w) <= sum_r (H_r/W) T(r f,w)
              + epsilon F/W * max_(1<=j<=f) T(j,w)
              + C(n+w)                                     (n>=64).

C depends on fixed q and the pinned source, not original e, spectator values or a suspended parent's contents. The retained moment receipts give

    mu_1 = 2874298095721977/2890625000000000 <199/200,
    mu_(1-c0) <9999/10000,     c0=17/10000,
    mu_t = [sum H_r(r/64)^t + epsilon F(1/64)^t]/W.

Induction using the monotone proposed bound, not an assumed monotonicity of measured runtime, gives

    T(n,w) <=200Cn +10000Cn^(1-c0)w.

This imports the existing moment evidence; it is not a new moment certificate. It supplies the baseline recurrence of the actual completed caller. Obtaining the selected H2 saving requires stronger implementations of every named route/leaf primitive, and their full numerical billing. Replacing only a leaf callback is insufficient.

## 6. Complete reserve domain and statement

The byte-exact proof exports are authenticated in [EVIDENCE.json](EVIDENCE.json), with author and source-path attribution in [evidence/NOTICE.md](evidence/NOTICE.md). The local storage inputs are [PR2731](https://github.com/CrocSwap/integer-mult-bounds/pull/2731), the [residual lifetime proof](evidence/pr2731-README.md) giving 3v+3r at `46c0c3554608a1096816ad668c755d3b5b7a8c0b`; [PR2708](https://github.com/CrocSwap/integer-mult-bounds/pull/2708), the [routing/key lifetime proof](evidence/pr2708-README.md) at `2982489cc00a17bd1c7ee1e206e975eda9bcb64d`; and [PR2688](https://github.com/CrocSwap/integer-mult-bounds/pull/2688), the [directory storage proof](evidence/pr2688-PROOF.md) at `1b9e1ed8793ffdde3c4b115641f0e644a9289923`. These sharp component results are predecessor work. The new reserve combines them with the all-size code's actual suspended-parent, numerical and control lifetimes.

The space unit below is one live logical tape symbol, including LEFT/RIGHT/record delimiters. Cleared storage is reusable. This is not a Python heap bound. Observers that retain histories and external meter histories are checker instrumentation and are excluded.

Put W=28416, N=|GL_64(F_q)|, H=q^(4096(w-1)), A=q^w, and

    K = 269241600 N H = lcm(28416, 28425) N H.

Use distinct notation A for the atom radix; the constant 269241600 is the row-stock multiplier, not the atom radix. Let D(n)=0 for n<64 and D(n)=1+D(42 floor(n/64)) otherwise. A root with fresh-row count t K^D(e), t a positive integer, has sufficient stock on every branch. The algorithm invokes an internal child only for its actual width at least 64; smaller children use the completed eight-primitive leaf.

Assume q is one fixed prime at least 2^80, the source-bound selected catalogue has 28278 requests, the residue and root-index words have their canonical minimal widths, and the generated history satisfies

    w = ceil(e^(17/10000)),  n <= e,
    2^(h+1) <= 8e²,  17(h+1) <= 20051w.

The last inequality may instead be checked directly for the supplied initial history and every descendant. For a history generated from the original root, the global chronological level is never reset at a unit child and h+1<=D(e)<=2 log2(e) at every internal node. The inequality follows from max_(x>=1) log2(x)/x^(17/10000)=1/((17/10000)*exp(1)*log(2)); the rounded constant 20051/17 is conservative. Arbitrarily padded residue/index contexts or an unrelated large supplied history are outside this simplified constant bound; the explicit ledger below still charges their actual widths and lengths.

For this reserve statement, supply root residue and index arenas of capacity 2^24, matching the child banks constructed by `Frame`. For the runtime inventory described below, all simultaneously live logical symbols, including borrowed input and suspended parents, are less than

    11 V_root + F_q.

F_q is the one-time finite source/compiler table storage for the fixed q and selected catalogue. It is independent of e,w,h and every runtime high residue. It can instead be part of the fixed machine description. If charged as work storage, the bound is `(11 + F_q/q²) V_root`, since V_root>=q². This is an explicit separation of compilation from execution, not an unpriced runtime numerical component.

A uniform four-bit encoding suffices for the record alphabet, whose largest symbol is RETURN=13. Thus the corresponding encoded live contents occupy less than 44 V_root+4F_q bits. This is a storage encoding observation. Scheduling and scanning those contents on a fixed number of physical tapes, with a proved time bound, remains a separate compiler obligation.

### Active packet volumes and suspended parents

At one node write its input order as

    [C prefixes][R fresh rows][B][A^n head][G][A^n tail][S],
    R = W N H U,
    V = C R B G S A^(2n).

After the fresh-row split, every selected low-class packet has exactly

    v = C H U B G S A^(2n) = V/(WN).

`layout.child_extents` keeps U as the independent fresh-row factor. It moves each spectator interval into exactly one of B',G',S', including the old external gap once. The child's complete input is the same v-bit packet, not merely its two visible chunks. Its current directory is inherited with C H physical prefixes, and its old current field is frozen exactly once. Consequently, along the single active recursion chain,

    V_j = V_root/(WN)^j.

This identity is the reason parent families may be retained: their costs form a geometric series. Charging every suspended parent as another V_root would be a different, weaker accounting.

The row quotient is U=t*9475*K^(D-1) at a node whose supplied stock is t*K^D. Indeed 269241600/28416=9475. A shorter actual child uses fewer than D-1 levels and treats the remaining K power as a positive stock multiplier. No discarded or hidden U factor is allowed in this argument.

The scheduler retains only one active chain. `recursive_call.Frame` gives each internal child separate residue and index arenas of capacity 2^24. The parent arena remains parked and counted. The parent clears the temporary extended program and temporary first prefix before yielding; `packet_engine` clears an obsolete current packet after each returned child; `node` clears peeled and family copies on return. These lifetime rules are necessary to the geometric accounting. `Frame.close` erases live numerical words and the program, but permanent arena templates and erased-slot LEFT markers are released with the logical frame bank; it does not implement a sequential physical blank-return procedure for them.

### Local payload and routing-key allowance

A deliberately coarse 8V allowance at a node covers its own payload and routing keys, including the copies it retains while a descendant is active. This is not a sharp first-range peak result.

* Source, peeled source and all split families together occupy at most 3V. Merge occupies at most 4V. Peel's completed primitive pipeline is at most 6V: source/current/partial output plus at most three complete local-fibre copies; local fibres partition the complete current packet.
* The selected local call has 661 ordinary roles and at most one private role. PR2731 bounds a completed local residual by 3v+3r, borrowed input included, where r is one physical-prefix fibre. PR2708 bounds the route by 2v+3H(r+J) for w>1, with a smaller w=1 bound, and J=4096(L+1) for actual residue width L. Gather/scatter creates at most one additional native family copy Nv=V/W.
* With J<=r, every local phase is bounded by 3V+680v+V/W. The slack 680 includes all 662 role packets, the source/current/copy retained at an invocation, and the residual or route's active local copies. This quantity is below 4V even using N>=1 and W=28416. At an invocation no partially assembled primitive output exists: `packet_engine` yields before beginning the next prefix loop.
* A new child's own payload is charged in its own8v term. Retained parent references do not create a second physical copy; counting them twice would only increase this conservative allowance.

Under the hypotheses J<=r follows from r>=A² and L<=bw+2, with b=ceil(log2q). Namely J<=4096(b+3)w<=q^(2w), using b+3<=q, w<=q^(w-1), and 4096<=q. Actual internal packets have a much larger A^(2n) factor, n>=64.

Thus all payload and keys on the active chain cost at most

    8 sum_j V_j <= 8 WN/(WN-1) V_root.

### Explicit metadata ledger before absorption

Let L be residue width, I root-index width, Q source-code width, and h the frozen history length at the node. Write ell(V)=1+floor(log2V). Canonical count tapes use at most ell(V)+4 symbols including a leading margin and delimiters. All cardinalities generated at an admissible internal node are at most V: this includes H, fresh-row quotients, prefix counts, projected spectator extents, powers of A and their intermediate nonnegative products. The required root stock ensures H<=V even for the deepest internal frame.

A serialized field occupies exactly

    f = Q + 4096(L+1) + 2

symbols. A complete produced directory has

    Delta = 1 + C H (h+1) f

symbols; the old directory and any one copied prefix are no larger. This includes physical multiplicities, source labels, word delimiters, record delimiters and LEFT. The root input directory is a supplied input of this exact canonical form, not free metadata.

The exact program size at history length h is

    P_h = 2I + L + 6 + h(Q+2I+90).

This follows directly from `records.Program`: a ROOT tag, two index words, one residue word and one record delimiter, then h STEP records with six finite fields (one Q-bit and five 16-bit), two index words, and a record delimiter; each encoded word carries WORD_END, and the whole tape carries LEFT.

The following intentionally inflated ledger covers one frame:

    E(V,h,L,I,Q) =
      (2^24+1)(L+I+4)                    two Word arenas and their templates
      + 8 P_(h+1)                       original/extended/copied programs
      + 16(h+3)(2I+L+8)                 pending/value stacks and pop reversals
      + 2^20(ell(V)+4)                  Count/Counter tapes and saved continuations
      + 2^32(Q+1)                       finite labels, form records, role bindings
      + q² + 2^20.                      bucket and other LEFT markers

In addition charge 32Delta for coexisting old/current directories and temporary raw-prefix/field copies. The current implementation needs far fewer than 32; this covers directory construction (old+output+saved prefix), one consumer directory and prefix, the child-extension prefix and an inherited borrowed directory, with slack. A child directory is charged to that child's associated complete packet; it is never charged against an isolated header or a single atom.

Therefore a pre-absorption bound is

    F_q + sum_(active j) [8V_j + 32Delta_j + E(V_j,h_j,L,I,Q)].

This formula is also the appropriate form when widths are padded or a supplied history does not satisfy the root-coupled bounds. An arbitrary supplied byte string is not automatically a canonical Program or directory: successful execution checks exact depth, fields and prefix count. If a host separately retains unrelated input files or instrumentation, their actual sizes must be added. No reserve theorem can absorb an arbitrarily large unrelated supplied string into V.

### Source inventory supporting the constants

The arena capacity is a source bound, not an inference from a finite test. Every matrix is at most 128 by 256. At most64 such matrices, 2^19 other Word-vector entries, and 1024 scalar/index temporaries suffice:

    64*(128*256) + 2^19 + 1024 < 2^22 < 2^24.

`Matrices.prepare` retains the input high matrix with raw/common/projector intermediates, fewer than eight full matrices. `good_form` has at its late peak projector, left, right, li, ri, lp, a0, b, cross; its early a has been freed. Its row/column scalar lists total at most 4032 entries and at most 64 pivots. `fallback_form` retains a 128-square matrix, at most 16256 shear scalars, and 128 diagonal entries. A retained Page form may coexist with one ancestor matrix preparation by `Callback.weight`; there is no matrix per ancestor. `weight` uses explicit sequential pending/value stacks. Route decoration and directory odometers are separate phases and fit within the same inflated 64-matrix bound. Euclid/divmod/multiply loops free scalar temporaries on every iteration; fewer than 32 nested arithmetic temporaries are needed, covered by 1024.

The callback evaluator has arity at most two and decreases the chronological level at every VALUE expansion. At most two pending records per level, one retained completed value per level, and a constant number of pop/reverse records exist. Allowing two Callback objects and both reverse tapes gives the stated 16(h+3)(2I+L+8) bound. The evaluator recomputes ancestor forms; it does not retain an exponentially large evaluation tree.

The Count/Counter allowance 2^20 is deliberately much larger than the fixed source-call inventory. There are five node input-count copies, three derived stock/fibre counts, layout extent triples, context.highs, the driver's row count, directory expected/emitted/outer counters, and the bounded nested primitive counters. Count.product has factor/scan/result and one add copy. These loops process one entry at a time; they do not append a counter per processed row, prefix, digit, matrix entry or operation. The only unbounded nesting is the separately charged recursive frame chain or serialized callback stack. Saved generator continuations have a fixed number of references, labels and encoded word/tape positions per nonrecursive source activation; the same 2^20 allowance covers a conservative serialization. This is a storage inventory, not an implementation of such a continuation compiler.

Finite fallback permutation snapshots have at most 16256 records of 128 labels. Two simultaneously relevant forms and all 661 role bindings, loop labels and trace metadata fit far below 2^32(Q+1). Fixed-q chart/source/low-class plan caches are instead in F_q: they are independent of input precision and must not silently be called runtime-free Python memory. The atom digit-swap has at most q² bucket LEFT markers; fresh families, role buffers, count tapes and stack tapes fit the additional 2^20 markers. Arena LEFT/RIGHT markers were already counted in arena cells.

### Root-coupled absorption, with explicit inequalities

For minimal widths and the selected vocabulary,

    L <= bw+2,  I <=591w,  h+1 <=1180w,  Q <=4096b+16.

The source-code bound uses 2*28278*N<2^16 q^4096, including both physical views. The index bound follows from the canonical root word I<=log2e+2 and w>=e^(17/10000); for x>=1, log2x/x^(17/10000)<=1/((17/10000)*exp(1)*log(2))<313, so591 is conservative. The displayed history bound is the retained checked root-coupled condition, rounded upward.

Substituting these bounds into the ledger gives, with considerable slack,

    E <= 2^48(b+597)w² + 2^20(ell(V)+4) + q².

Here 8P_(h+1) and the callback stacks are quadratic in w; the arena is linear in w; finite form labels are bounded by 2^45(b+1); and all constant LEFT markers are included. More explicitly, replacing L by (b+2)w and h+1 by 1180w, the non-count/non-q² part has nonnegative coefficients and degree at most two in w. It is at most (83066202501+17592241506793*b)w², which is less than 2^48(b+597)w² coefficientwise. Thus the displayed envelope is an exact conservative inequality, not a finite-size extrapolation.

Every complete active packet has V>=q^(2w); internal frames in fact have V>=q^(128w). For integer w>=1, w²<=4^(w-1), and q²>=4. Also b+597<=q for q>=2^80. Therefore

    2^48(b+597)w² / V <= 2^48/q <= 2^-32.

For V>=16, ell(V)+4<=16 sqrt(V), so

    2^20(ell(V)+4)/V <= 2^24/q^w <= 2^-56.

Finally q²/V<=1. Hence E<2V. PR2688, with the same minimal vocabulary and history assumptions, gives Delta<2^-130 V for a complete associated packet, so 32Delta<2^-125V. It follows that

    8V +32Delta +E < (10+2^-125)V,

and summing the geometric series yields

    (10+2^-125) WN/(WN-1) V_root <11V_root.

This proves the claimed full logical live-symbol reserve, including numerical words and suspended parents. It does not reuse the historical 14-field parking reserve or claim that the existing source has implemented that sharper physical layout.

## 7. Explicit stock coefficient and capacity boundary

Since N<q^4096 and 269241600<q,

    log_q K <4096w+1.

A sufficient borrowed q-ary row exponent is exactly

    k(e,w) = ceil(D(e) log_q K),

as a row-capacity bound. To embed an arbitrary q^k row range in the compatible format, the retained written construction pads to ceil(q^k/K^D(e))*K^D(e), a factor below two. The actual runtime here accepts a compatible tK^D(e) fresh-row count; it does not implement that outer padding/borrowing wrapper. Merely having q^k rows without the required divisibility is not the same input contract.

Using 42/64=21/32<2^(-1/2) gives D(e)<=2 log2e for e>=64. Consequently

    k <= 2(4096w+1)log2e+1 <=8195w log2e.

With w=ceil(e^(17/10000))<=2e^(17/10000), this also gives

    k <=16390 e^(17/10000) log2e.

These deliberately rounded constants are derived from the new 269241600 row stock. A sharper coefficient can be obtained from log2(32/21), but no historical 6748 coefficient is assumed. Storage closure and stock feasibility do not price the actual numerical execution time; that remains governed by the actual callback and routing implementation rather than a free-operation model.
