# Replay independent BIT idle tags and price the extra field volume

Gives an exact m=3 two-tag direct-sum and arbitrary dirty stock replay for the nominated paired idle.

The two tags use two full field volumes and tie the original 2H(7) under volume-linear billing. An explicit ternary tag uses three volumes or four with the exhibited dirty-auxiliary repair.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `61faa4db1aa15df5f4d42419fa0e55ff3de9cad488197099db4b89978b8d28a4`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run `python3 -I -B replay.py`.
