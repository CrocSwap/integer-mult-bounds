```text
(2/m)^(1-a) + (7/m)^(1-a) > (9/m)^(1-a).
```

## Reproduce

CPython 3.12, standard library only; no network, Git checkout, optional optimizer or GPU is needed for the direct replay:

```sh
python -I -O -B research/p104-coalesced-private-reuse-audit/verify.py
```

The package may also be copied anywhere and run by its absolute path. Inputs unpack to temporary storage. Source hashes are checked before execution and again afterward; the default command only reads package files and compares the recomputed receipt with RESULT.json.

In a repository checkout, the registered check is:

```sh
python -B scripts/research_package.py --package research/p104-coalesced-private-reuse-audit
```

Expected marker: `PASS_P104_COALESCED_PRIVATE_REUSE`, with 735 columns, 339 preserved frame changes, five rejecting semantic controls and native=True. The native checker additionally rejects an incorrect global phase in each variant.

The registered replay deliberately uses `-O`, matching the predecessor: acceptance is enforced by explicit failures in the successor and the retained independent native interpreter, not by the compiler's internal assertions. A second source-only replay without `-O` also passes, with those compiler assertions enabled. [VALIDATION.json](VALIDATION.json) records both commands, timings and payload hashes.

The five successor controls omit a direct contact, change its nonzero coefficient, reverse the private descent order, retain the obsolete dirty compensation, or omit private initialization. A schema error alone is not substituted for the contact/dirty endpoint checks.

## Scope and remaining obligations

This establishes a finite forward composition and a strictly improved bill under the same conditional owner-window model. It does not admit a changed global emitter, backward supplier, route/wrapper proof, recursive precision/reserve bound, all-size lifting, or the full multiplication theorem. No full selected cold replay or hosted-CI success is claimed.

The unchanged widths establish applicability of the same **conditional packing invoice**, not a new proof of its physical schedule assumptions. The released-helper variant has no concrete hosting improvement claim. These distinctions matter because the existing complete conditional invoice still misses the selected result.
