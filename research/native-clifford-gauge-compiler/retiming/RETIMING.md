# All-input compensated scalar retiming

Let x and y be distinct fields in a module over a commutative ring. An interval starts with x ← x + a y. During the remainder of the interval, no other field may read x, every change to x must be an additive update with a distinct source, and every change to y must have the form y ← y + b z with z different from x and y. Operations on other fields may be arbitrary, need not commute, and may read y.

Delete the first instruction. After each update y ← y + b z, insert x ← x − a b z. At the interval end, append x ← x + a y. This constructs an exactly equivalent interval for every input and every module dimension.

Proof: all fields except x have identical trajectories because none reads x. The difference between rewritten and original x is initially −a y. Every original additive update to x preserves this difference. An update to y changes −a y by −a b z, precisely the inserted compensation. Operations on other fields preserve the invariant. The final addition a y makes the difference zero. No cancellation, invertibility, genericity, or probabilistic assumption is used.

If a legal physical realization thereby replaces consecutive positive paid ranks u and v by one rank u + v, preserves every other paid call and productive target, and the merged Gaussian is admitted, then its paid moment decreases strictly by u^θ + v^θ − (u + v)^θ for 0 < θ < 1. This follows from strict concavity. The physical contact/ownership assumptions must be checked; the abstract identity alone supplies no improved supplier or κ. No improvement to the current complete invoice is claimed.

Run `python3 -I -B retiming_verify.py` and `python3 -I -O -B retiming_verify.py`. The standard-library checker compares every independent input column in 80 exact examples, including noncommuting operators on other fields and reads of y. It rejects 80 wrong-sign compensations and a forbidden observable-read case, and exhibits an actual failed identity when that read restriction is omitted. This finite replay supports the implementation; the module argument above proves all dimensions.
