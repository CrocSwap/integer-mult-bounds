# Selected BIT child caller and complete numerical phase envelope

At a child coefficient callback in unchanged PR2697 `Consumer.apply`, the
caller owns exactly **18 additional index Words for a good plan and 19 for a
fallback plan**, and no additional residue Words, above **all** apply-entry
residents. Fallback retains its zero half-width Word. Combining this with
Arham Tahir's PR2796 child lifecycle gives conditional child-action bounds of
`(20494 residues,40 indices)` and `(20494,41)`.

The remaining non-ADD/return phases fit inside that allowance. With the credited
adapter and prefix lemmas, the complete successful first-range call has the
conditional occupied-numerical-content bound

```
(L_R+1)*r + (L_I+1)*i + max(37672*r+34*i, 20494*r+41*i).
```

Here `L_R,L_I` count every live entry Word; `r,i` include each RIGHT delimiter.
The two permanent arena templates are included by the `+1` terms. This finishes
the numerical-phase handoff from [PR2821](https://github.com/CrocSwap/integer-mult-bounds/pull/2821).
It is a conditional source-level component theorem, not total physical reserve,
whole supplier admission or a new kappa. No sharpness is claimed for the
composed envelope.

```sh
python3.12 -I -B scripts/research_package.py --package research/selected-child-caller-lifetime
```

The primary probe enters actual `Consumer.apply`, initializes/validates its
directory/program, and runs the complete source trace and packet-engine child

nonzero unrelated entry residents. It checks every ADD event's live inventory;

`Layout.extents` and `action` with two restored callback samples. Serialized
movement, payload traversal and coefficient arithmetic are explicitly abstracted
in this probe. Source-level fixture metadata is not selected catalogue admission.

Ten separate primitive fixtures execute **complete** Boolean atom swaps and
address signs over F3, Z/9, Z/27, F5 and Z/25, with nontrivial spectator extents.
An integer permutation oracle checks every output bit, while every allocation
is budgeted and numerical entry values/heads/ownership are restored. They attain
the exact six-residue peak. This is actual small primitive execution, not a
full selected GL64 Boolean run.

The independent trace census covers good ranks1..42 and a synthetic fallback
