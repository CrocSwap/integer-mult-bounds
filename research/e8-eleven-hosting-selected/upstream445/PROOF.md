## Three-level halving and row stock

Two levels fail: 78²=6,084 ≤ 2×56²=6,272. Three levels succeed:
78³=474,552 > 2×56³=351,232. The one-level moment is strictly below one; its
third power is also below one. Floors can only reduce descendant widths.

The coarse q^(m²+1) enumeration estimate would give complete row coefficient
3×6,085+9,909+252=28,416, exceeding 20,161. We instead count actual orthogonal
cover elements using the following elementary bound, valid for every odd q.

Diagonalize a nondegenerate symmetric form in dimension d. For a specified
nonzero norm, fixing d−1 coordinates leaves a nonzero-coefficient quadratic in
the last coordinate, with at most two roots. Thus there are at most 2q^(d−1)
choices for a vector of that norm. Its orthogonal complement is nondegenerate.
Successively choosing the images of a diagonal orthogonal basis therefore gives

```
|O_m(q)| ≤ ∏(d=1..m) 2q^(d−1) = 2^m q^(m(m−1)/2) < q^(m(m+1)/2),  q ≥ 3.
```

For m=78 the cover exponent is 3,081. Physical stock is 9,609 families, including
nine private-centre reserves, and 9,609 < 3^9 ≤ q^9. Thus the physical row divisor
is strictly below q^3090. The inherited restored-row argument uses this divisor
once per recursion depth, reusing restored rows for sequential operations; its
statement is preserved verbatim in `proof/INHERITED-ROW-DIVISOR.tex`. Three-level
halving gives complete coefficient

```
3×3,090 + 9,909 + 252 = 19,431 < 20,161.
```

This changes only the bound on actual stock. Finite routing-time charges still
use the larger m² parameter. No faster group enumeration or new compiler
interface is assumed. `row_bound.py` checks the exponents and strict margins and
rejects false two-level halving and an overflowing row reserve. Its finite checks
support the arithmetic; the induction above proves the bound uniformly in q.
The complex row coefficient remains 15,443. Both fit the retained 20,161 bound,
so the existing outer degree gap 10^6 − (51/25)×20,161 remains unchanged.
