## Why this is an exact separation

Use `0` and `1` for the sides of a predicate P. There are 104 ports q. For
this witness, each has a unique x-plane `X_q`, and one or two assigned
compatible y-planes `Y_qj` as generated by the frozen integer matching. The
400 field paths are

```
L_q -> X_q  -> top           (one or two copies)
bot -> Y_qj -> H_q           (one or two copies)
```

where `L_q=span(q)` and `H_q=ker(q)`. In addition there is one bank in each
direction between top and each of two flag planes `b1,b2`. The witness has
D=R=14 and X=D+R=28. The source `UniHSC7113.hsc7113` establishes that, for a
legal #7113 word's folded graph, the designated `Ehi`/`Elo` rows pair fields
of the **same** label. For D labels these are respectively X2/Y2 and Y/X;
for non-D labels X/Y and Y/X. Generic `HSContract` only asserts an
injective partner and does not by itself identify an arbitrary graph's
pairing with these labels. The exact result below concerns the #7113
pairing and the particular fixed witness, not arbitrary `HSContract`
instances.

For any path A -> C -> B, in both directions its bank-crossing count minus
its field-crossing count is `1` when A and B lie on the same side but C
lies on the other; otherwise it is `0`. The four flag banks add one surplus
in each direction for each `b_i` on the opposite side from top.

If `P(top)=P(bot)`, no designated x/y pair can have both x endpoints on one
side and both y endpoints on the other, and path telescoping makes the
violation nonpositive. Complementing P exchanges the two directions and
preserves the violation. Hence it suffices to take `P(top)=1, P(bot)=0`.
Put `l_q=P(L_q)`, `t_q=1-P(H_q)`, and `w_q=1` for a non-D port or `2` for
a D port. The mandatory excess in **each** direction is

```
E(P) = sum_q l_q t_q.
```

For fixed plane sides, the common bank-minus-field surplus is

```
S(P) = sum_q [w_q l_q (1-P(X_q)) + t_q sum_j P(Y_qj)]
       + (1-P(b1)) + (1-P(b2)).
```

Since the port lines and hyperplanes are distinct actual charts, their
Boolean choices are independent. For each q, independently maximizing
`l*t - a*l - b*t` over bits `l,t`, with nonnegative integer
`a=w_q(1-P(X_q))`, `b=sum_j P(Y_qj)`, gives 1 exactly if `a=b=0`, and 0
otherwise. The two extra flag planes are distinct from every intermediate
plane, so they can both be set to 1 without affecting anything else.
Consequently the maximal violation is the maximum number of q for which

```
P(X_q)=1 and P(Y_qj)=0 for every assigned y-plane j.
```

Construct an undirected conflict graph on the 104 labels: add q--r if a
`Y_qj` equals `X_r`. The checked x-planes are unique; every y-plane is an
x-plane, with no self-loop. The simultaneously qualifying labels are
precisely the independent sets of this graph, up to the choice of the
remaining plane sides. The checked graph has 124 edges and maximum degree 4.

The optimality proof is an independently checkable combinatorial
certificate: `CERT_EDGES` and `CERT_CYCLES` in `separate.py` partition all
104 vertices into 28 edges and four odd cycles of lengths 13, 11, 11, 13.
An independent set meets them in at most

```
28 + floor(13/2) + floor(11/2) + floor(11/2) + floor(13/2) = 50.
```

The script also constructs a 50-vertex independent set and checks the
actual 804-bank and 400-field counts. It independently computes the same
optimum using an exact recursive independent-set solver (405 memoized
states). No floating point or solver-status assumption is used for either
the upper or the lower certificate. Exhaustive toy checks compare the
recursion with brute force on every graph of up to five vertices and verify
the path and endpoint Boolean identities.

## Inequalities and limits

For the maximizing predicate P, the pair-cut lemma `BankFitHS.dir_extras`
requires outgoing banks ≥ 50 and incoming banks ≥ 264 for the **concrete**
#7113 D/B assignment; other helper fields would only increase the field
crossing requirements. The number 214 is `2 * (200 - 93)` because the 50
selected labels carry 93 x-field copies and 93 y-field copies. This is a
necessary condition of a full banked graph with those endpoint data, not a
construction of one.

With the same 104 labels but only `DCount=96`, without fixing which eight
are non-D, at least 46 of the 54 unselected labels are D. The 54 unselected
labels therefore produce at least 200 incoming field crossings, so the
same fixed predicate still requires at least **250 incoming banks** and
**50 outgoing banks**. This is a paper application of the pinned directed
cut lemma; it has not been added to Lean or kernel-replayed here.

If one holds the 400 fields and all 804 witness banks fixed and only
**appends** nested banks, this particular cut alone requires at least 50
new banks in each direction. Every nontrivial nested chart transition has
absolute dimension change ≥1. Thus any such append-only repair has at least
100 additional banks and X ≥ 28+100 = **128**. This append-only bound is
not a bound on a redesigned witness, on unrestricted networks, or on legal
words. It neither proves nor disproves `hJ`, the aggregate D+R ≥ 112
premise, and gives no invoice crossing `hV` or κ result.
