# Short words on actual tapes

This controller implements the finite calculations in the label, geometry, factor and repair routines. Its costs include memory travel. It never stores a physical address or the entire module index in one word.

Use `m>=4096`, `b=128 bitlength(m)`, `M=m^32`. An unsigned word has `b` bits. One marked memory tape has `M` consecutive `b`-bit words, each followed by a delimiter. At most 128 register and temporary tapes have marked left origins and right ends. Home is the first low-order bit. Finite labels, jumps and register names are part of the finite control. Each of the fixed routines calls the primitives below, reusing these tapes. Counters from larger unbounded ranges have a different, separately priced physical interface.

The instructions are copy, constants 0 and 1, comparison, bitwise operations, add, subtract, multiply, unsigned division with remainder, binary shifts, branch and indexed word load/store. Addresses and intermediate finite values in the routines are less than `2^b`. To read a bank word, copy its index to a temporary word. Test and decrement with at most `6(b+2)` transitions per record including both returns. Skip the marked record in `b+1` more transitions. At the selected word copy or overwrite, then return to the unique memory origin. Even serializing head motion this costs at most `16(M+1)(b+2)`. Register sweeps for copy, compare, Boolean operations, add and subtract take at most `8(b+2)` each. A shift by at most `b` places is a repeated single shift or a two-head copy with countdown, bounded by `8(b+2)^2`.

Schoolbook multiplication has at most `b` rounds, each reading one multiplier bit, optionally adding, and shifting the working word. Long division has at most `b` rounds, each shifting the partial remainder, inserting an input bit, comparing, conditionally subtracting, and writing the quotient bit. Use a `b+1`-bit temporary. Even locating each current bit from home uses at most `64(b+2)^2` transitions per round. These algorithms give a common bound `128(M+1)(b+2)^3` per instruction including serial head returns. The work tapes start and finish at their origins, including both data-bank and control-register heads.

Given binary `m`, write 128 marks per input bit, count to initialize `b`, and install the fixed register end marks. Five squarings produce `M`; write and mark the `M` words using a short binary countdown and return to the origin. Initialization, all marker writes and returns fit `512(M+1)(b+2)^3`. For `m>=4096`, `b+2<=m`, so each instruction and initialization separately cost at most `m^37`. All memory, registers and temporarily visited boundaries occupy fewer than `m^34` cells. The finite number of control states is independent of input. Long-term use through recursive calls requires the caller’s arena or parking rule.

### An exact indexed access on nonempty occupied memory

The [four-tape rule tables](https://github.com/CubeJerry/integer-mult-bounds/blob/a2a17b61d943676c757e0bbfaef3f4fae03ab8e5/research/moonshot-overhead-program/sessions/2026-11-26-S008/compiler-short-word.py) implement both `load` and `store` with 14 states per mode. Memory consists of `M>=1` original occupied `b`-bit records with delimiters, and the index and value tapes each hold an independent `b`-bit word. All are low-order digit first. Let `0<=i<M`, `i<2^b`. A fresh copy of the index is decremented until it vanishes. A successful decrement of positive `v` changes its low zero run to ones and its first one to zero, homes the temporary tape, then advances the bank across one full slot. At zero the unsuccessful decrement turns all `b` zeros into ones; the backwards pass erases them all before copying the selected slot. Store preserves its source word and every unselected slot. Both modes preserve the original address and restore all four entry positions.

The total, including installing/clearing private home markers, is exactly

    T(i,b) = i(2b+7) − 2 popcount(i) + 8b + 16
    visited(i,b) = i(b+1) + 4b + 8.

Copying the index and resetting its two heads costs `3b+5`. A successful decrement and slot skip cost `b+4+2ν₂(v)`; summing the valuations gives `i−popcount(i)`. The failed decrement and erasure cost `2b+2`. Copying the selected word and returning memory and value to home costs `i(b+1)+3b+5`. Opening and closing cost four. The visited intervals run from the private marker at −1 through the terminal positions at `i(b+1)+b` on memory and `b` on each of the three registers. In particular the load/store bound used above holds for arbitrary implicitly stored numerical values and for displaced selections deep in the original bank. The 1,332 traced accesses cover both modes, full carry chains, independent data and retained occupied memory. This is a numerical and executable check of the indexed-memory primitive. The larger arithmetic and programme-level bounds in this note remain written estimates.

### A source-level proof for an indexed seek

[compiler-controller.lean](https://github.com/CubeJerry/integer-mult-bounds/blob/a2a17b61d943676c757e0bbfaef3f4fae03ab8e5/research/moonshot-overhead-program/sessions/2026-11-26-S008/compiler-controller.lean) proves a second implementation of the seek portion in the literal `OAI.Computability.IntegerMultiplication.TMModel.TM.advance` semantics. Its input is an occupied bank of delimited `b`-bit records, an independent index tape with `i` unary marks followed by a delimiter, and arbitrary initial absolute positions `p,c`. Its theorem makes no assumption about any bank cell at or after the selected slot. The rule has three states, two tapes and a finite alphabet. The theorem `S008.Compiler.indexed_seek` derives exactly `i(b+2)+1` actual deterministic transitions to heads `p+i(b+1), c+i`, with both entire tape functions preserved. A record can contain arbitrary independent bits. The theorem `indexed_seek_halts` proves the reached state has no outgoing transition.

To select this implementation inside an access macro, copy the input's little-endian index in reverse with its zero padding to a most-significant-first scratch word, then use the physical [binary-to-unary port](node-streams.md). Padded to exactly `b` digits its cost is `11i−6 popcount(i)+12b+3`, since a leading zero contributes the same per-bit dispatch as the later digits. Put the terminal delimiter after the `i` unary marks by one round trip along them, run the proved seek, then copy the chosen word, return to the bank origin, erase the unary index and home all scratch. Each ancillary tour crosses at most `i(b+1)+b+2` cells on the data bank, `i+2` on a unary bank and `b+2` on each word bank. Even allowing 32 such tours and the conversion separately gives total time at most `128(M+1)(b+2)` and at most `4M+16(b+2)` additional controller cells. Both fit the existing `m^37` time and `m^34` space budgets. The 14-state exact formula above describes the binary decrement implementation.

The source proof was kernel-checked with Lean 4.34.1 and the unmodified OpenAI source at commit `3344da59991ed94f9ba711217b29c1d760badfa6`. Running `lean compiler-controller.lean` with its source dependencies on `LEAN_PATH` reports only `propext, Quot.sound` for `indexed_seek` and `propext` for `indexed_seek_halts`. The complete access, multiplication/division routines and adaptive dispatcher retain their written clock proofs.
