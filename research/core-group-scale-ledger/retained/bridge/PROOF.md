## 1. Exact missing interface and inherited statements

The new bridge implements their codec, normalization and owned-return join.

## 3. Whole-grid numerical theorem

Let the actual input x have component-l1 radius
`max_r(|Re x_r|+|Im x_r|)<=R`, with components on grid 2^-q. Then
`||x||_2<=R sqrt(T)`. A sufficient **complete-field** Core input radius is 2^r,
where `r=ceil(log2 R)+ceil(n/2)`. A per-context radius cannot replace it at a
global dense call. The Core's own larger internal radii remain required.

Let P>=q be the resulting common fractional width and w its actual field
carrier. The admitted Core must satisfy

`||C_hat(x)-C x||_2 <= 2^(-t-1)`,

where `C=direct_sum_c tensor_i H_i[C_i,C_i]^-1`, in original coordinates. This
is its existing contract on actual rounded states, not an ideal-state radius
argument. Put U=sum_i u_i and a_total=2^U. The bridge returns

`z=Q_q(C_hat(x)/a_total)`,

where Q_q truncates both components toward zero. Since component-l1 <= sqrt(2)
times complex modulus and coordinate modulus <= whole-field Euclidean norm,
the normalized section defect is strictly bounded by

`E_core = 2^(-t-U) + 2^(1-q)`.                            (1)

There is no sqrt(T) factor at this output conversion; it belongs in the input
radius. The sqrt(2) factor is necessary: components (3/10,4/10) have norm2=1/2
but component-l1=7/10. Equation (1) uses a safe rational factor-two majorant.

Each normalized principal section has infinity norm at most one. Thus the
unnormalized Core's result after dividing by a_total has each component of
magnitude strictly below R+1 for t>=0. For integer R, external component width
`d=q+R.bit_length()+1` suffices. Truncation does not increase magnitude, and
the codec still checks overflow literally. The actual Core source requires
t>=1, a stronger admissible instance.

Let `lambda_i=rho_i^J_i/(a_i delta_i)`. The inherited kept-row locality
difference is at most 2 lambda_i. Tensor telescoping against normalized rows
of norm <=1 gives

`E_keep <= E_core + 2R sum_i lambda_i`.                   (2)

The actual rounded source-bound halo recurrence separately gives

`E_halo <= sum_i[((2W_i+1)R+2)2^-q/delta_i + R lambda_i]`. (3)

Both compare with `B=tensor_i(H_i^-1/a_i)` at the same original x. Kept and
discarded coordinates partition the output, so

`||splice(x)-B x||_* <= max(E_keep,E_halo)`.               (4)

This consumes the global Core error directly; it does not assume an
inapplicable per-axis rounded-Core radius induction. A next group needs radius
at least R+max(E_keep,E_halo); 2R suffices if that error <=R. Undoing the
normalization multiplies the error by 2^U and must be funded by the outer caller.
If rho_i=0 then lambda_i=0. Identity holes require no new definition: they remain
rows of the same original matrix in both source owners.

## 4. Literal format conversion and one final normalization

Each external component is a sign followed by d-1 big-endian magnitude bits;
negative zero is inadmissible. Its value is X/2^q. A native component consists
of w little-endian two's-complement bits and denotes Y/2^P. Assume
`P>=q` and `w>=d+P-q`. Thus every admitted external carrier, including its
largest signed magnitude, fits the native carrier after the exact lift.

`Codec.prepare_input` writes P-q low zero bits, reverses the magnitude, and
forms complement-plus-one if negative, extending the sign through the remaining
high bits. It writes precisely the integer `Y=X*2^(P-q)`. The source is traversed
sequentially and restored to its canonical left position. Its complex-record
order is unchanged. Conversion is exact, so it adds no input numerical defect.

For a returned native numerator Y, `return_component` reads precisely w bits,
retains the final sign bit, and forms |Y| by complement-plus-one when needed.
The unsigned absolute buffer has w places and therefore also holds the most
negative native input's magnitude 2^(w-1). Let `D=P+U-q`. It discards the first
D low *magnitude* bits, copies the next d-1 bits, and rejects any remaining
nonzero high bit. It emits the sign only when the retained magnitude is nonzero.
The resulting external numerator is exactly

`sign(Y) floor(|Y|/2^D)`.

Consequently it implements Q_q(Y/2^(P+U)) including D>=w, negative values,
and rounded zero. An arithmetic right shift of a negative signed numerator
would instead round downward and is not this operation. No native precision
bits, normalizer bits, or external-grid drop are omitted. Each component error
is strictly below 2^-q; adding the real and imaginary errors gives (1)'s final
rounding term. The input-dependent branches retain only signs, bits, carry,
and an any-nonzero flag. Every moving loop is clocked by a tape delimiter or
one of five input-independent unary format tapes. They do not decode a field
word, coordinate, precision, or number of records into a host integer.

The unchanged external stream clocks `prepare_return`: each original record
requires exactly two native components and then a '#'. After its final record
the native tape must be blank. Truncation, overlong output, malformed bits and
overflow are detected before output commitment. Input-independent construction
and the explicit setup verifier are separate from this finite-control body.

## 5. Ownership, transaction order and retained backing

The sequence is the inherited `transport.gather()`, this bound Core call, then
the inherited halo consumer and unique-key return merge. Gather must have
completed and set the transport phase to `saved` before `BoundCore.run` admits
the call. The original external field remains unchanged while the native input
is copied, the actual source-bound Core runs, and the entire normalized external
return is formed in a protected owner. The native callee has no port to the
saved halo copy. The bound ports are those of actual `OriginalCore`; the small
physical witness uses the separately labelled packed `CompleteCore` boundary.
No arbitrary numeric callback establishes the source theorem. The source
preparation admission requires these bound ports to be the actual outputs of
`build_numeric`/`prepare_banks` and `PreparedRoutes` for the family just checked;
the generic `BoundCore` protocol does not independently reconstruct that source
certificate from arbitrary Python objects. Its test double exercises lifecycle
only and is never substituted into the numerical theorem.

After complete validation, the bridge consumes the callee's protected native
return and sequentially copies its own complete normalized return into the
transport field. It then sets phase `core`. Native source/control heads and
borrowed contents obey the callee's existing restoration contract. The bridge's
own failure paths erase its pending buffers and, if the callee has a pending
return, consume that return. A failure before the commit preserves the original
external stream. This is an algorithmic failure contract, not fault tolerance
for a physical interruption during the final copy.

There are five unary format roles, three reusable component roles, one protected
external-field role and one native-input role: ten new roles, independent of
record count, contexts, axes and groups. The native input marker is armed once
per call and erased once; the explicit `input_armed` state makes cleanup
idempotent without scanning left of an already erased delimiter. Formats may
be rebuilt only while idle, in those same five roles. Payload cleanup visits
live words; every visited blank remains in the retained-space account.

## 6. Complete additional invoice

Put `F=d+w+(P-q)+(P+U-q)+1`. For T complex records, the new online codec and
transaction work, including forward/reverse component scans, unary-clock
rewinds, source restoration, protected external output, the final full-field
copy, native-input erasure and all component erasure, is `O(TF)`. Each component
scan traverses at most its word length and each full-field pass traverses at
most its complete encoded volume. No component invokes a full-field rescan.
There is no extra dense scan for each selected axis. Setup of the fixed unary
formats is `O(F polylog(F+2))` by ordinary binary-to-unary control construction;
the literal fixture setup has its emitted cells metered. If a caller supplies
already prepared control tapes their production cost is still included once.
Both tape alphabets are fixed finite alphabets and use the same bounded-step
binary simulation convention as the retained source programs.

The inherited complete native-Core charge is added unchanged. Its numerical
plan uses the enlarged global input radius from Section 3, so the inherited
charges use the resulting actual P, w, coefficient accuracies and setup heights.
The inherited complete first-face charge is also added unchanged, including
all source production, full archive scans, common-b copy volume, key sorting,
returns, source restoration and erasure. The bridge cannot replace either bill
by its own O(TF) tariff.

`match_sources` is an input-independent certificate validator, not a free
oracle or an online numerical operation. It traverses every one of K complete
context rows and every active axis, validates the actual source partitions and
checks archive parameters. All exact-reference entry formation, source seals,
matrices, interior validation and catalogue data remain paid. Its repeated
partition validation has the same uniform per-context source envelope already
required by the complete-Core preparation; a constant number of additional
validations changes only its constant. If that source envelope is not proved
for the admitted instance, it must remain a separate setup cost.

The added retained space is `O(T(d+w)+F)` plus any larger historical extent
present at entry. This includes both whole-field buffers, every format and
component scratch role, and blank backing. Reusing a smaller format does not
release the previous maximum extent. The callee, existing transport, saved
copy, original archive and every source cache retain their separate space
invoices.

For the exact conservative family of the frozen Core, n, q, P, w and log R
are O(p) and `g=Theta(p^(39/40))`. Require the uniform bound `a_i<=p^C`
for a constant C independent of the group, context and axis, equivalently
`u_i=O(log p)` with a uniform implied constant. The retained gap premise
`delta_i>=1/(16p^2)` permits the least dyadic `a_i>=delta_i^-1` to satisfy
`a_i<32p^2`. A caller using a larger normalizer must separately retain the
stated uniform polynomial bound. It gives `U=O(g log p)=o(p)`, so F=O(p).
With V=Theta(Tp), the new payload bill is
O(V) per balanced group and `O(V d_outer/g)` over the same actual group cover.
The complete source-match setup costs at most
`K 2^(O(ell_original)) poly(p)` under the inherited **uniform** preparation
envelope; `ell_original=O(p^(1-epsilon))` and `1-epsilon<39/40` absorb this as
o(V) using `T=K L^g`. The standalone halo archive production remains separately
paid. Neither an omitted K, a cross-context cache, a final undersized group nor
free large original-weight precision is used in that substitution.

This compatibility statement is conditional on precisely that conservative
source family and its native admissions. It does not admit the selected best

## 7. Evidence, scope and remaining obligations

`verify_codec.py` uses the actual two retained Tape classes, prohibits online
Tape construction and diagnostic decoding, and compares with an independent
integer oracle. It checks 3,936 signed/grid cases, 160 native extreme cases and
34 rejection/detection controls, including omitted normalization and failures
after the actual callee protocol has taken ownership. Its
transaction-protocol test double is explicitly not a numerical Core proof.
`verify_binding.py` uses two actual immutable References, 16 admitted original
partitions, a real halo archive and every one of 512 original coordinates.
Its controls distinguish swapped axes, incorrect origins, omitted contexts,
foreign/reinstantiated source objects, normalization mismatch, global-volume
underallocation and the complex norm conversion. The source gap chosen for
this fixture funds an explicit next-group radius; this is still no claim that
its admitted finite interiors prove the production carve.

`verify_actual_core.py` executes the real retained packed two-record Core:
three native dense calls containing 189 events, one native inverse-boundary
call and one native forward-boundary call. Its original Q is coupled and
nonidentity, while its scalar dense interior A is exactly 1. It uses the same
frozen source ports, then exact codec conversion
and final dyadic normalization. An independent direct rational 2-by-2 inverse
checks the source endpoint, and snapshots check restoration of every borrowed
source/control tape. This witness ran in about 311 seconds. Its fixture is
K=1, g=1, L=2 at one original window and is **not** a full first-face geometry
execution. No extrapolation of that finite run establishes all-size source
production, the induction hypotheses, or the complete costs.
