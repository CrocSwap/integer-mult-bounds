# Verification design and bounded deviations

The falsifiable predicate is that all three fixed coefficient policies preserve
each macro, its source and zero scratch, while fitting common D=7/W=P+20.
The workload is all 9,992 ordinary prelude/A macros in each pinned provider and
orientation. Three policies are the complete declared attempt set. All checks
are exact, so numerical noise is zero. A passing capacity certificate does not
extend to an excluded adapter, bit operation or consumer.

Build the Lever led to the retained every-microstate verifier. Prove It Works
led to fresh native source compilation, an integer interpreter, endpoint-correct
overflow controls and comparison with the committed receipt. The source
generator and normalized propagation are reused; no complete independent
supplier verification is claimed.

## Power of Ten inspection

1. New code has structured loops, branches and exceptions, with no recursion.
   Temporary output directories use a context manager. Explicit external
   outputs are intentionally retained for diagnostics and owned by the caller.
2. Native streams are checked at at most 30,000 events before traversal.
   There are 632 fields, at most 4,096 row atoms, 32 scalar templates, 32
   instructions per template, three policies and two providers/orientations.
   Frame validation is bounded by 1,124 frames, rank nine and 256 warps.
   Frozen subprocesses have 90-second timeouts. VERIFY bounds the whole replay.
3. Python and Fraction allocate during execution. See the deviation below.
4. New functions fit within 60 physical lines after formatting. Chronological
   traversal, per-macro verification and capacity-report assembly have separate
   responsibilities. CHECKS records the final measured maximum.
5. Executable require checks remain active under -O. They enforce exact
   division, prefix equality, macro/source/scratch endpoints, recipe counts,
   common capacity and source hashes. No external validation uses assert.
6. Row dictionaries and recipe caches belong to one stage traversal. Integer
   rows are local to one macro. The two tiny global limits are immutable.
   The retained parent import path is installed only after source authentication.
7. Arithmetic and process results are checked, including source writes and
   file inventories. The CLI requires a fresh output outside the checkout.
   Failure raises and preserves explicit diagnostics. Automatic temp output is
   removed on success or exception.
8. There is no eval, reflection or generated executable code. The literal
   instruction alphabet has six fixed operation kinds.
9. New arithmetic calls are direct, with shallow row access. Standard unittest
   discovery uses its bounded set of twelve methods. Frozen source generators
   retain their original internal interfaces and notices.
10. Python warnings are errors. New Python files pass Ruff correctness,
    import, simplification and formatting checks. The package manifest supplies
    repeated exact replay and optimized controls. Shared repository tooling and
    frozen predecessor coding styles are unchanged.

## Deviations and limits

Rule 3, fixed memory. Python dictionaries, arbitrary integers and Fraction
require allocation during this finite exact verifier. The preceding enforced
event/row/template/instruction bounds limit live state. At most one macro's
32 changed rows are retained by the new integer comparison; source streams and
templates persist for one stage. Runtime/library allocator internals are not
instrumented. Replay and all limit/failure controls check this bounded path.
If a future package accepts larger arbitrary streams, it must supply new input
and resource limits before reusing this evaluator.

Frozen code. The retained compiler, Clifford kernel and source propagation
include historical styles and assertions. They are immutable research inputs,
not rewritten dependencies. The compiler subprocesses explicitly drop inherited
optimization and use fresh bytecode directories. Source authentication and
native expected receipts constrain their use. Their full implementation and
all-size correctness are inherited proof obligations, not newly verified here.

Direct `-B` calls can still read preexisting bytecode. Registered replay gives
the verifier a private cache namespace, and frozen compiler subprocesses use
another fresh namespace. Claims about source execution rely on that registered
route. No new global environment or cache policy is introduced.
