# Validation

`verify.py` checks the explicit four-signed-swap C5 word as an exact integer
permutation, the three workspace rotations and output rotation prices, each
41-ADD child map, the shortest-path recurrence, and every one of the 3,125
five-child phase paths. It emits the five- and ten-child schedules and compares
full dirty integer matrices for the optimized, eager, separate-call and joint
call echoes. All 35 basis columns of the root map are checked.

Negative controls reject a noncanonical terminal phase, an omitted final frame
transition and a missing copied-source restoration. Complete invoices include
all forward and inverse child calls, phase changes and source copies. The
prefix row-L1 peaks are recorded to expose the precision limitation.

`make selected-record-check` checks that the accepted record remains intact;
it is not a replay of the selected supplier. No selected cold replay or
supplier-specific precision/tape admission is claimed. The registered Python
3.12 replay is unavailable in this environment; the direct checker runs with
the installed Python 3.14 interpreter.
