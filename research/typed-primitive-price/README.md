# The typed quotient costs more than its direct main primitives

**No new K.** Under the exact A/B interface supplied by PR4654, the native
word's recursive paid moment is strictly greater than a direct implementation
of the same main operator and all independent helper jobs, for every
`0<=C<1`. Its surcharge is at least **8 * 7^(-C)** per invocation.

Read [PROOF.md](PROOF.md). A direct main implementation needs 224 rank-seven
jobs and 112 rank-one jobs; all 408 helper jobs are also paid. Four exact
Laurent identities cover both types in both orientations. Every sign,
inverse power and helper normalizer is retained. This is a comparison of
recursive prices; fixed routing, scalar, ownership and native admission
obligations are stated separately.

The direct helper implementation includes rank-nine jobs, so it does not
retain the native word's rank-eight child cap. Its use in a compiler needs
new rank/tail checks, or a caller that removes neutral fresh helper jobs
from both target and paid lists. Local price dominance alone is not admission.
