# A physically realized mixed seven-axis quotient supplier

Prepared for Dugongue with substantial OpenAI Codex assistance. Apache-2.0.

## Sufficient constructive statement

Starting with the credited kernel-153 complex quotient word, there is an explicit replacement of its 72 shared native address maps and explicit monomial input/output normalizers on every main port such that:

- Every actual shared native warp has rank zero and an exact monomial realization, including its absolute phase and inverse-transpose orientation.
- The complete local paid profile is unchanged:

      P={1:2177,2:424,3:389,4:147,5:50,8:8}.

- All 408 arbitrary independent helpers retain their actual whole-job target census:

      H={3:2,6:7,7:47,8:139,9:213}.

- Of the 112 independent main pairs, exactly 56 realize

      F_A=D S_y(Q⁻¹),

  and exactly 56 realize

      F_B=diag(D,QD) S_y(Q⁻¹).

Here D is the Gaussian transform on seven fresh address axes, Q is the Gaussian transform on a separate central axis, and the ninth axis is a spectator. In the field ordering X=roles 0 through 111 and Y=roles 112 through 223, the extra central Q in type B acts on Y, the target of the forward shear. The backward interface is the inverse transpose of the corresponding forward matrix. These statements hold at every digit-column fiber width f, with D and Q replaced by their f-column counterparts.

This is a sufficient typed local interface. It establishes neither the old common rank-eight interface nor a completed improved multiplication bound. Its main purpose is to give a controller an actual proved operator to consume, instead of pricing changed output charts as though they were unchanged.

## 1. Repair all shared native maps constructively

Let H₈ denote the image of the nine-dimensional ambient under the kernel-153 quotient. Before spectator padding it is the coordinate eight-plane. Every native operator has a shared contract H₈→H₈ and one additional equal-dimensional pair A→B. Twelve operators also have a nonzero line a→b. In the submitted finite word the line belongs to A if and only if b belongs to B. These incidences are checked explicitly, not inferred from dimensions alone.

For a two-subspace contract, choose bases of A and B and extend each to H₈. Mapping corresponding basis vectors gives an invertible map on H₈. For a line plus subspace, put a and b first in their respective bases if they belong to A and B; otherwise first choose bases of A and B, then append a and b. Extend both lists to bases of H₈. Map the corresponding bases, and fix the unused ninth coordinate. This constructs one invertible G for every operator, satisfying all occurrences of that operator simultaneously. Negative occurrences use its inverse.

Use the native monomial K_G specified by the retained source. Every actual physical warp is

      C_input.adjoint().then(K_G).then(C_output),

or uses K_G⁻¹ for a negative occurrence. The canonical-frame Lagrangian formula implies its Fourier rank is zero whenever G maps the input subspace onto the output subspace. The exact Clifford lowering constructs the monomial and checks its tableau and absolute phase. Shared-map consistency is essential: separately choosing a map at each occurrence would not preserve the arbitrary-input symbolic identity.

The exact emitted word passes both retained literal interpreters on all 632 arbitrary-input fields in both orientations. Therefore replacing the shared operators preserves the source's formal all-column identity, with no initialized-helper assumption. All 180 actual warp classes were freshly lowered in both orientations and had exact rank zero, including absolute phases. No Fourier call is hidden inside a supposed free warp. The eight paid center operations and every helper-final repadding call are included in P.

## 2. The exact two-field endpoint before normalization

At every main pair, X starts in the central line c and ends in H₈. Y starts at ground and ends in a subspace A. Writing C_H, C_c and C_A for the exact canonical frame operators, the forward physical block matrix is

          [ C_H C_c⁻¹       0 ]
      M = [ C_A C_c⁻¹     C_A ].

There are precisely two cases:

- Type A: dim A=7, A⊂H₈, and c∉A, so A⊕c=H₈.
- Type B: A=H₈.

Both cases occur 56 times. These are properties of the literal source frames, independently checked for each port. The distinction is why a uniform common rank-eight replacement was invalid.

## 3. Explicit monomial normalizers

Choose standard central axis e₀ and standard seven-plane E=span(e₁,…,e₇). Put Q=C_e₀ and D=C_E. They act on disjoint axes, so they commute.

In type A, choose an invertible binary map G sending e₀ to c and E to A. It consequently sends span(e₀,E) to H₈. In type B, choose G sending e₀ to c and span(e₀,E) to H₈. Extend it on the spectator coordinate. Let N=K_G, an explicit native monomial. Define

      T_Y=D               in type A,
      T_Y=QD              in type B,

      M_Y=N,
      M_X=C_c N Q⁻¹,
      O_X=D Q N⁻¹ C_H⁻¹,
      O_Y=T_Y N⁻¹ C_A⁻¹.

All products use ordinary matrix multiplication, with the rightmost factor applied first.

Each of the four M_X,M_Y,O_X,O_Y is monomial. To see this without assuming an oracle, use

      L_U=C_U(L₀)={(x,z):x∈U, x+z∈U⊥}.

The monomial K_G sends L_U to L_GU. Every canonical frame is involutory at the symplectic level. Therefore M_X sends L₀ to L₀ because N sends L_e₀ to L_c. Likewise O_X sends L₀ to L₀ because N sends L_span(e₀,E) to L_H₈. In type A, O_Y is monomial because N sends L_E to L_A; in type B use L_span(e₀,E) instead. A Clifford preserving L₀ is monomial. Exact lowering resolves its affine permutation, quadratic phase and absolute scalar phase.

Direct multiplication, without approximation, gives

      O_X (C_H C_c⁻¹) M_X = D,
      O_Y C_A M_Y          = T_Y,
      O_Y (C_A C_c⁻¹) M_X = T_Y Q⁻¹.

Thus diag(O_X,O_Y) M diag(M_X,M_Y) is exactly F_A or F_B as claimed. No independently chosen column is credited twice; the wrappers act on the original two independent main inputs and their actual outputs. Helpers remain independent and unchanged by these external main-only wrappers.

The monomial wrappers are explicit finite nonrecursive operations. They must be counted in any subsequent finite-template route/scalar allowance; they are not zero-cost machine instructions. Their degree, coordinate dimension and coefficients are fixed, so they contribute fixed linear per-record work under the native lowering. All their phases have modulus one, so the wrappers do not introduce a growing conditioning loss.

## 4. Inverse transpose and every fiber width

The actual backward source word uses the inverse-transpose logical identity and the corresponding conjugated frame operators. If F=O M N is the forward identity, then

      F⁻ᵀ=O⁻ᵀ M⁻ᵀ N⁻ᵀ.

The inverse transpose of a monomial is monomial. Hence the normalized backward type is exactly F_A⁻ᵀ or F_B⁻ᵀ, rather than an independently guessed orientation. The extra central Q is on physical Y before taking this dual; its exponent changes sign under inverse transpose.

For fiber width f, tensor each ADDRESS-OPERATOR block identity f times. For example, from O_X A_X M_X=D one obtains O_X^(⊗f) A_X^(⊗f) M_X^(⊗f)=D^(⊗f). Apply the same argument separately to the Y diagonal and the off-diagonal coefficient. This preserves the two-field block shape and scalar coefficient 1. It does not tensor the entire 2×2 field matrix, which would create additional field rows. Monomial tensor powers remain explicit monomials, and the chronological arbitrary-input identity at every fiber width follows from the independent free-group-algebra argument below.

## 5. A universal free-group-algebra evaluation proof

The logical endpoint is not inferred by tensoring a numerical one-column field matrix. The retained literal interpreter computes a stronger symbolic identity.

Let F be the free group on 72 named generators g₁,…,g₇₂ and R=Q[F] its group algebra. A row is a finitely supported map from pairs (initial field, reduced group word) to rational coefficients. Initialize each of the 632 persistent fields as its own basis vector. The owned C field is also represented symbolically until it is explicitly cleared. Process every record as follows:

- A native warp with signed operator i multiplies each coefficient on the LEFT by g_|i| or its inverse. The implementation prepends the signed symbol and removes it only when it cancels the adjacent inverse symbol.
- ADD and SCALE perform exact rational module arithmetic. COPY duplicates the source expression only into permitted owned storage. CLEAR sets only permitted owned storage to zero.
- A paid frame change is the identity on logical values; its physical conjugating frame operators are accounted separately. Phase and adapter markers do not modify the logical row.

These are precisely module operations in the free R-module on the initial field symbols. Induction on the record index therefore proves that the interpreter's row is the corresponding formal logical expression, before any native operator has been assigned a numerical matrix. In particular, no relation such as commutation, finite order, dimension, a chosen binary G map, or a one-column coincidence is used.

At termination, the checked forward rows are X_i↦X_i, Y_i↦Y_i+X_i and h_j↦h_j; the backward rows are X_i↦X_i−Y_i, Y_i↦Y_i and h_j↦h_j. Every surviving coefficient has the EMPTY group word. The owned C row is zero. The fresh receipt records 632 persistent rows, 744 exact terms and zero nonempty group words in each orientation. Changing one occurrence to a new unshared generator produces a nonzero endpoint difference and is explicitly rejected.

Now take any vector space V over Q or C and assign ANY invertible linear operator T_i∈GL(V) to each shared generator. Send a reduced word to the ordered product of those operators and extend Q-linearly. This is a well-defined algebra homomorphism R→End(V): the only reduction used, g_i g_i⁻¹=1, is valid because T_i is invertible. Extending it componentwise to module rows sends every step of the formal computation to the actual vector-valued operation. Hence the final formal identity proves the same endpoint for arbitrary independent V-valued inputs.

Apply this evaluation independently at every fiber width f, assigning the explicitly constructed shared K_G,f and their inverses. The same operator must be used at every occurrence of its name; this is why the simultaneous shared-map construction in section 1 was required. The 72 new maps satisfy that condition. The backward interpreter uses a separately named set of generators, so the result also applies to the inverse-transpose assignments. This proves the changed word's universal logical all-fiber endpoint directly. The only tensor arguments needed are for individual frame/normalizer operator identities, where tensor powers do preserve composition; no assertion that tensor powers preserve sums is made.

This evaluation theorem is completely separate from a contraction or a complete multiplication algorithm. It proves the arbitrary-input operator identity and does not supply a favorable paid invoice by itself.

## 6. Controller relevance and paid obligations

The type-B identity has a useful exact rewriting:

      diag(1,Q) S_y(Q⁻¹)=S_y(1) diag(1,Q).

Also Q² is monomial. This permits central-parity row gauges that can change whether a query coefficient requires a rank-one Gaussian call. It does not make all queries free: an ADD across different central gauges can itself require a paid rank-one call. A complete controller must charge every such bridge and derive its final central target parities from the actual diagonal operator. The seven-axis target ranks cannot be priced with the old eight-axis invoice.

The receipt intentionally states only a typed local supplier. A full contraction, compiler, native caller and larger κ must be proved using the resulting complete paid and productive profiles.
