# Verification contract

## General claims and finite evidence

`PROOF.md` proves the stabilizer and pairing isomorphism symbolically.
The checker exercises those statements, checks rejection boundaries, and
verifies the exact relation between the two actual #6824/#6835 gauges.
A finite certificate is not used as a substitute for the general proof.

The executable suite:

1. Authenticates all ten retained inputs by SHA-256, Git blob hash and
   byte count; authenticates the native JSON payload against the digest
   published in #6824. The pinned #6835 modules are compiled from their
   verified source bytes, bypassing Python bytecode caches.
2. Checks the torsor in a small example with nonempty J, I, H and M,
   dyadic inverse conditions, and illegal-support/rational-only controls.
3. Checks complete small PURE modules with Gram `[0]`, `[3]`, `[4]`, a
   direct-sum Gram `diag(4,3)`, and the Bézout ideal generated by `[3,5]`.
   Unit capacity is computed by exact determinantal ideals over Z[1/2].
4. Checks unchanged physical read/write witnesses after a nontrivial
   right gauge, simultaneous Gram transport, and an independent fresh
   input endpoint defect. Rejects omitted row purity, omitted unit
   pairing, insufficient physical bank and nondyadic rational witnesses.
5. Rejects extrapolation to noninvariant labelled helper subsets, including
   a triangular gauge preserving helper columns but not dual helper rows.
6. Keeps private state rows in a rectangular example. Accepts and
   transports a two-sided prefix/suffix split witness that is not PURE;
   rejects the false PURE claim obtained by dropping the private copy.
7. Replays two legal small frame words with the same total middle matrix
   and identical MOVE lists. Exact Laurent-polynomial chart replay checks
   their equal endpoint, while a complete helper class changes cut
   capacity from one to zero after an intermediate mixing and separation.
8. Checks the integral completion Γ=((3,1),(5,2)) and verifies the retained
   greedy constructor rejects its N=(3,5) column. This tests the documented
   incompleteness of that algorithm, not the existence theorem.
9. Reconstructs the native original and alternate hub maps. Independently
   computes B and its inverse, checks their H support, and checks the
   new public endpoint with a separate sparse replay. Classifies complete
   equal-boundary helper blocks and verifies all are preserved.
10. At three deterministically selected native cuts, checks both directions
    of prefix transport on all 772 public rows and 29 private slots. Also
    checks every pre-CLEAR private row and its zero/nonzero status. It
    records 32 nonzero rows and one zero row under the inherited reset
    semantics; it does not assert a zero-before-CLEAR precondition.

## Recorded commands

Run from the repository root:

```sh
python3 -I -B research/p104-hub-gauge-invariance/verify.py
python3 -I -O -B research/p104-hub-gauge-invariance/verify.py
python3 scripts/research_package.py --package research/p104-hub-gauge-invariance --check-only
python3 scripts/research_package.py --package research/p104-hub-gauge-invariance
```

Python 3.12.14 was used. The full direct run takes approximately seven
seconds in the author environment. `RESULTS.json` records exact counts,
source digest, selected cuts and rejection labels. Normal and optimized
runs must have identical semantic results; elapsed time can differ.

## Not run or not established

There is no native symbolic productive-job census, source-wide dyadic
Smith computation, price improvement, complete #6833 caller replay,
selected supplier cold replay, compiler validation, or outer theorem
validation. No claim is made about all broader endpoint-correct
retirements when the suffix has a kernel. No cost bound on alternative
basis realizations is supplied. The inherited native all-width,
owned-erasure, compiler closure, precision/tape and analytic recovery
assumptions remain.

Overlap review was targeted: the parent investigation cached all 789 open
PR titles/bodies and identified #6835/#6827 for this question; the relevant
#5599 predecessor proof was read and retained. The closed archive survey
was partial. This is not a claim that every historical package was read.
