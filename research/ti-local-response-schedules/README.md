## Reproduce

Requirements: Python3.11+ (unoptimized), a little-endian machine, C++17 g++ and Boost headers. nlohmann JSON and pinned mathematical source inputs are bundled. Run from any working directory, with a fresh output directory outside this package:

    python -B verify.py --output ../local-response-replay --cxx g++ --boost-include /path/to/boost/include

Default verification freshly regenerates the inherited base, both reordered words, the37-gauge layer, the10-helper transport, the actual complex supplier and the final banks/finite/47-clause assembly. It compiles native tools from pinned sources and executes mutation controls. The base replay is the majority of runtime and may take tens of minutes on a slower machine. Nothing is downloaded and nothing is published.

An optional `--reuse-base-output PATH` accepts only the exact previously completed base replay whose output, certificate and binary SHA-256 digests are listed in REUSE-BASE.json. This is explicitly authenticated reuse, not fresh source compilation of the inherited base. All extension tools and the actual PR304 admission are still freshly compiled and rerun.
