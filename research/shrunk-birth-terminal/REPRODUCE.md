# Reproduce the selected composition

From the repository root, run:

```sh
make verify-shrunk-terminal
```

This uses Python's standard library. It verifies the frozen source closure, losslessly decompresses the exact selected inputs, reproduces the entire geometry from pinned source and recorded legal moves, compares it directly with every mathematical field of the actual selected input fixture, reconstructs the complete physical word, checks both orientations over Q, compares the complete paid profile and scalar bill, recomputes both exact arithmetic enclosures and all transfer inequalities, runs 18 arithmetic adverse controls, audits independent birth/terminal accounting, and checks the unchanged Lean input/generator/compile provenance. All reconstruction writes occur in a new temporary directory; frozen inputs and certificates remain unchanged. The geometry replay is a selected witness replay, not a rerun of the heuristic optimization.

The complete repository check required before publication is:

```sh
make -j1 verify
```

Historical compiler groups need a C++17 compiler and Boost headers. CI uses Ubuntu; the exported local verification receipt records the macOS compiler adapter and environment. The selected group itself requires no compiler, external package, network request, downloaded model or account credential.

Fresh formal compilation uses the repository's pinned Lean 4.21.0 and Mathlib configuration:

```sh
make formal-historical-verify
```

The `formal/lean/KappaCheck/ShrunkBirthTerminal.lean` module is byte-identical to the separately compiled 240-theorem companion. The formal target builds all integrated modules and checks every listed theorem's axiom dependencies. It permits only `propext`, `Classical.choice` and `Quot.sound`. `audit_lean.py` reproduces the generated source from its saved input and links all mathematical values to the selected exact certificate; that check is not itself a fresh Lean compilation.

The authoritative current certificate is `certificate.json`. `arithmetic/certificate.json` and `audit/independent-prepackage-certificate.json` preserve the independent witnesses before the descriptive scalar-count correction. The exact equivalence and original byte hashes are recorded in `audit/lean-portable-equivalence.json` and `audit/scalar-metadata-correction.json`. No bound, physical word, paid histogram, scalar charge or Lean theorem changed during that correction.

For a fresh optional receipt outside the frozen package:

```sh
python3 research/shrunk-birth-terminal/verify.py --output build/shrunk-birth-terminal-verification.json
```

`SOURCE.json` binds all portable construction, exact arithmetic, saved inputs, original references, Lean sources and repository integration. `selected/INPUTS.json` binds both the stored compressed bytes and the original uncompressed input bytes. The full word comparison uses the decompressed canonical payload, avoiding platform-specific gzip-header differences; the supplied archived file also has its own exact SHA256. Assertions must be enabled. Timing and RSS belong only to diagnostic receipts; the mathematical certificate forbids floating-point values recursively.
