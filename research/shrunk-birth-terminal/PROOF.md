## Dirty-slot reuse and terminal elimination

A birth recipient has no earlier active use. Its donor has finished all active uses in the center phase and has a nondegenerate endpoint frame A contained in the recipient's nondegenerate birth frame F. The explicit birth compensation read cancels the donor's current dirty value, including any correlations and earlier source signals. The subsequent recipient operations use that same physical slot. Cleanup reverses the actual chronological sequence of source and workspace events. All 2,108 donors and recipients are distinct and no eliminated terminal is a donor or recipient.

For e=dim(A) and s=dim(F), the complete paid reuse comparison replaces the two old widths `h-e` and `m-h+s` by the new residual width `s-e`, while removing one physical auxiliary role. Adding a dummy width-m child to the new side conserves mass. The padded new packet majorizes the old packet. For a strictly concave power, this improves the unnormalized feasibility slack; normalized-moment improvement is asserted only at an already feasible exponent. The stored word and profile, not a role-count approximation, determine the final moment.

Each selected terminal u has exact ordinary readout coefficient alpha=+/-1/2 on one target, never controls an auxiliary update, is untouched in the center phase, and has only late updates. If its initial dirty value is z_u, then

    -alpha*z_u + alpha*(z_u + sum_j a_j(t_j))
      = sum_j alpha*a_j(t_j).

The compiler removes u and redirects each update at its original index to that target, using the same source value and the same gate frame. It retains target promotions even when the corresponding old terminal read is omitted. Targets never control workspace operations. One selected terminal per target ensures that simultaneous rewrites have disjoint target-front packets. The actual reverse cleanup includes only the retained workspace and source operations.

The selected first incoming frame, final old target front and initial terminal frame coincide: sigma=M=F0. With h=24 and m=576, the general padded comparison is

    old: [m-h+sigma, 1, F0-sigma, h-1-M]
    new: [m, F0-M, 0, 0].

All entries are nonnegative and masses agree. Complete-profile reconstruction checks the sum of these packets and every integer concavity hinge from 1 through 576. The detailed terminal proof and its assumptions are in [TERMINAL-PROOF.md](TERMINAL-PROOF.md). Deleting an aliased birth recipient is expressly forbidden; the joint optimizer instead chooses between its real donor edge and its terminal edge.
