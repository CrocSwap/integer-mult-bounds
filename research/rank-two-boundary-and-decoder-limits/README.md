# Rank-two native and decoder limits on the path to κ = .01

We tested whether a second protected direction could improve the signed recursive
invoice of a fixed BIT native word. The frozen-boundary obstruction, the two
propagation screens and the 45-port caller cost check all held up in the
replay included here. The experiments also give an exact local source worth
retaining for a redesigned caller.

## What the checks establish

- **Frozen neighbors.** On the 27,818-event six-helper-handoff word, exact
  rational nullspaces give zero initial extension and zero terminal shrink
  dimension on all 111 ports. The calculation takes the same-chart ADD
  components between MOVE and CLEAR events into account. It holds with the
  adjacent frame subspaces fixed.
- **Propagating the frame changes.** The saved profiles contain 6,993
  single-seed cases and 8,040 selected paired or collective cases. Every
  profile worsens the native helper-minus-paid moment at κ = .005, .006
  and .01, with no independent main-output credit. At .01 the best deltas
  are about −51.4191 and −36.0921 respectively. The paired census used up
  to twelve leading seeds per direction for pair tests and one simultaneous
  seed set. The published replay rechecks every saved price with integer
  interval arithmetic. It does not regenerate the propagation census.
- **A source that passes locally.** Fused boundary bridges protected 45
  planes simultaneously. The retained normalized source receipt covers
  775 arbitrary input and scratch columns. The separate audit covers the
  rational frames, ownership and nested-query identities. Paid rank mass
  stays 5,129, with a small increase in the concave moment. Physical BIT
  phases, address semantics and arbitrary tensor width are still open.
- **Its existing caller tariff fails.** The old four-factor main path has
  off-diagonal rank at most `2+6+6+6=20`. For block matrices,
  `B(MN)=A(M)B(N)+B(M)D(N)`, so the bound follows by rank subadditivity.
  The declared target tariff grants the other main outputs, pure centers and
  helpers and charges no decoder. It still has signed margin below
  −154.532 at κ = .005 and below −283.109 at κ = .01. This applies to the
  declared target tariff and that factored path. A different allocation or
  caller remains open.

There is no new conditional κ claim here. In particular the historical
rank-two and free-shear screens were conditional budgets for unbuilt
constructions. The five inherited framework assumptions and the matching
complex/BIT, physical, precision and outer obligations remain.

## Reproduce

From this directory, run `python3 -B verify.py` using Python 3.10 or newer.
The checker verifies the public evidence hashes, regenerates the exact
111-port nullspaces from the normalized word and frame data, reprices all
15,033 saved profiles at the three specified thresholds, and recomputes
the 45-port tariff signs. It works without a network or solver. Historical
checks on the emitted 45-port word are preserved as receipts. The standalone
replay here covers its tariff and does not rerun that full word.

[Evidence provenance](evidence/provenance.json) records original source
hashes, the exact retained frames and word, and the projection used to
package the saved price inputs. [Follow-up](FOLLOW-UP.md) records the later
connected-caller and decoder checks separately.

## Open next questions

1. Can a revised native path keep rank-seven diagonals while protecting a
   second direction? Start by changing one ADD component and checking all
   affected helper endpoints and the actual paid profile.
2. Can a different productive caller use the protected planes without the
   rank-20 factored path? Start with exact forward and reverse endpoint
   checks and price the whole proposed target bank before adding a decoder.
3. Can one paid transport carry the required repair over multiple cuts
   without increasing its rank or changing another output? Keep all
   arbitrary owners, and charge finite phase, scalar and cleanup work.
