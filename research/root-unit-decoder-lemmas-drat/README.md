# DRAT certificates for the D5 T = 3 closure of `research/root-unit-decoder-lemmas`

`research/root-unit-decoder-lemmas` (PR1590, merged) records one SAT result as RECORDED, because the 1.71 GB DRAT proof was not shipped:

> no exact three-total decoder on D5 has all block ranks ≤ 4

This package makes that proof publicly downloadable and gives a one-command replay. It changes no claim and no file of the merged package.

**The proofs** are release assets, too large for a repository file: [DreamingOfClouds/integer-mult-bounds release `d5-t3-drat-v1`](https://github.com/DreamingOfClouds/integer-mult-bounds/releases/tag/d5-t3-drat-v1). They are pinned by `SHA256SUMS`.

| asset | size | content |
|---|---|---|
| `d5_zr.cnf` | 667,739 B | the D5 caps-(4,4,4) CNF; sha256 equals the digest pinned and regenerated by the merged package (`f5e75d3b…7796`) |
| `d5_core.drat.zst` | 108,888,323 B | the core-trimmed proof (drat-trim `-l`), 895 MB uncompressed, independently re-checked: `s VERIFIED` |
| `d5_full.drat.zst` | 316,624,324 B | the original kissat 4.0.4 `--no-binary` proof, 1,710,338,687 B uncompressed (sha256 `1b0e28b8…faf3`, as stated in the merged README) |

## Replay

```sh
bash research/root-unit-decoder-lemmas-drat/fetch_and_check.sh /tmp/d5drat            # quick: download + sha256 + CNF pin (~1 min)
FULL=1 bash research/root-unit-decoder-lemmas-drat/fetch_and_check.sh /tmp/d5drat     # + build drat-trim (pinned commit 2e3b2dc0) and check the core proof (~3-6 min)
FULL=2 bash research/root-unit-decoder-lemmas-drat/fetch_and_check.sh /tmp/d5drat     # + the original 1.71 GB proof (~20-25 min, ~2 GB disk)
```

- **Requirements:** curl, zstd, and shasum or sha256sum. `FULL` also needs git, make and a C compiler.
- **Recorded run:** macOS arm64, `FULL=1`. The output was `PASS` on all hashes, the CNF pin and `s VERIFIED` (drat-trim 178 s).

## Scope

This certifies only that the CNF is unsatisfiable. That the CNF encodes the decoder question is the subject of the merged package's encoding audit, `evidence/D5-AUDIT.md`. Theorem C costs and the window arithmetic are inherited unchanged.
