# Independent review of the cache path and tree proof

Verdict: accept the fixed-path module criterion and the one-output scalar
merge-tree bound as a scoped appendix. This is a new independent proof
review of the existing text. It does not change the historical receipts.
The reviewer read the workspace PR-DESCRIPTION-STANDARD.md.

For a path with a supplied exact transition T_V T_U^-1, a transition changes
the physical frame and preserves the logical row. Each scalar read adds a
permitted-ring multiple of its snapshot row. Induction proves necessity of
the module condition. The coefficients of any module representation give
the sequence of ADDs and prove sufficiency for the stated fixed schedule.
Owned clearable cache fields, the supplied native recipes, and the declared
read times are premises. This does not clear an arbitrary borrowed field
without an account of its old contents.

The endpoint term dE is valid only while those rows retain their recorded
values. Completing all eight cleanups before the first X repair provides
that invariant. The telescoping rank cost is a conditional identity for
edges that have the stated cost; it is not an existence proof for a path.

The tree induction is correct for every finite rooted tree. At a k-child
node, the child costs plus incoming edges give
k*dim(U_v)-sum_j dim(I_j). Each I_j lies inside U_v. Subadditivity of
codimension bounds this below by dim(U_v)-dim(intersection_j I_j).
A snapshot at an internal node can be treated as an extra zero-length leaf.
Scalar cancellation cannot add a source port outside the union of leaf
supports. Every such support lies in I_root perpendicular.

The 511 line certificates imply that a nonzero query row can annihilate
only one binary line. On each of the eight special normal lines, the
excluded-column matrix has a one-dimensional left kernel generated by one
row of R. Two distinct such rows are independent because R R^T=56I.
Thus two independent annihilator lines are impossible. The rank cost is
at least 9-1=8. The factor eight for eight outputs requires disjoint paid
trees. A shared subexpression cannot be charged again by this proof.

The source support checker was read and rerun in fresh copies in normal
Python and with -O. Both complete output files match the retained receipt
byte for byte. It checks 12,271 rows, 16,687 intervals, 104,088 nonzero port
incidences, all 1,002 proper actual frame minors, and all 511 line minors.
It selects minor columns modulo a prime, then evaluates each determinant
over the rationals. Its conclusions therefore do not rely on a failed
finite-field search. The full snapshot producer is not rerun here; the
parent query package retains and replays that separate source audit.

The older exploratory path screen is not needed for either accepted proof.
The shared-network formulation and cut inequality are sound, but the parent
package already gives their broader independent review and exact global
42 certificate. The tree bound remains useful because it applies to one
nonzero output and distinguishes separate output trees from shared DAGs.
No current selected source, native cache construction, owner schedule,
precision claim, or complete supplier price is admitted by this appendix.
