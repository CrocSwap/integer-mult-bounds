## Whole-call replacement lemma

For helper role j, let E_j be the old physical input view and let O_j be
the old physical output view. Include all address permutations, exact
monomial phases, and complete-job wrappers in these maps. Suppose the
old local endpoint operator is F_j. The old global helper job is

    H_j = O_j F_j E_j.                              (1)

Suppose a new complete invocation has the following physical endpoint:

    data_out = A(data_in),
    helper_out_j = F_j helper_in_j.                 (2)

There is no data-to-helper, helper-to-data, or cross-helper term in (2).
All inputs can be arbitrary and correlated. Apply the same E_j and O_j
to the new invocation. Equation (2) gives exactly H_j on each old helper.
Thus the new invocation satisfies the same helper interface as the old
one. This is equality of physical operators on arbitrary arrays, not
equality of names for logical frames.

In particular, a helper can enter with an inherited exterior O that
differs from the active-data exterior P. An interpretation through
Delta=P^-1 O changes the logical mode coordinate. In (2), every
off-diagonal mode block is zero. The input and output coordinate changes
then cancel. No Delta or Delta^-1 is executed. The helper can be used as
data in a later call: its complete physical state at this call boundary
is exactly the state required by its old native history.

The injected-query concern has a direct answer. In the literal local
word, an injected query is acted on by the same F_j as the old helper
input. Its cancellation must be proved by the complete physical word.
If it is proved there, conjugating that complete word by E_j and O_j
does not change a zero coefficient into a nonzero coefficient. One
must not replace that check by a query identity in a fresh logical mode
coordinate.
