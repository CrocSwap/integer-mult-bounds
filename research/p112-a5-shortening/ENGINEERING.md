committed exact receipt. Prove It Works requires actual input reconstruction,
failure controls and committed-source replay, rather than treating the displayed
inequality as sufficient evidence. Unslop shaped the written scope and credit.

The arithmetic is deterministic and has no statistical measurement noise; no
runtime speedup or benchmark result is claimed. The general certified support

Every new production function is shorter than sixty physical lines. All
acceptance contracts use explicit exceptions and remain enabled under Python
optimization. Sources and the empty local `vendor/__init__.py` package boundary
are authenticated before geometry imports. JSON and source
files have explicit byte limits and fixed inventories. Values then pass through
local immutable tuples or bounded lists; no runtime-selected module names occur.

Mathematical loops have fixed domains: 120 roots, 112 live coordinates, 9 binary
coordinates, 8 rational coordinates, 5 star-extension levels and at most 240 signed
roots per level. The retained flat census visits 3,309,747 five-flats and 788,035
six-flats while storing only 113 histogram bins. The historical transcription

four-subsets and 81 bin assignments for each of two capacities. The unchanged
original filter has 24 output rows and a 45-second child timeout. Registered
commands have 90-second bounds and run sequentially.

The CLI permits only a new external receipt file, opened exclusively. Failure
propagates; the original historical child must succeed with the complete expected
24-row output, retained in the receipt. Tests create their own temporary exports
under TMPDIR and remove them.
Making disposable copies writable supports tests from read-only source exports
without changing any source input. No extra checkout is used.

Power of Ten inspections found no new recursion, unbounded retry, generated code
or hidden mutable singleton. The retained geometry remains byte-identical. The
following runtime constraints have bounded deviations:

- Rule 3, fixed allocation. Python, Fraction and unittest allocate at runtime.
  All production live collections are bounded by the domains above; the flat
  census does not retain all subspaces. JSON input files have a 200 KB byte cap.
  Native fixed-capacity arrays are a follow-up only if the domain is expanded.
- Rules 8/9, runtime dispatch. Ordinary Python imports and the test mocks use
  runtime dispatch. Production module targets are fixed, retained geometry is
  authenticated before import, and tests use mocks only for child failure,
  timeout and incomplete-output rejection. No user-supplied code is evaluated.
- Rule 10, diagnostics. Python has no strict native compiler equivalent.
  Warnings-as-errors replay, optimized controls, source compilation and available
  Ruff checks cover new code. Frozen retained code is not reformatted. A global
  lint or compiler-policy migration would be outside this isolated proof task.

These deviations remain confined to this package and its retained geometry.
Changing the domains or import contract requires rechecking their compensating
controls. No historical supplier cold replay, Lean or Docker build is needed
for this result, which changes no selected construction.
