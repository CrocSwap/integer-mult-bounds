# Implementation scope and checks

The kept change is one isolated opt-in package. It contains a written affine
cover transfer and a source-bound application to one P112 profile. It changes
no shared verifier, canonical input, priority or selected-result record.

## Engineering decisions

Build the Lever shaped `cover_transfer.py`: the reviewer can rerun every
four-cube subset and all affine hyperplane controls. Prove It Works shaped the
receipt and source-byte checks: the registered runner executes the actual
retained geometric and weighted statements used by this caller.

The initial exploratory five-flat census also reached 141, but the structural
cover proof makes that new census unnecessary. Its code and temporary outputs
are omitted. The final result reuses the predecessor's stated rank-four cover
contract through a new rank-five transfer.

## Power of Ten inspection

1. New paths have structured branches and finite loops, with no recursion.
   I/O failures and failed contracts propagate. Temporary test files use scoped
   cleanup. The only subprocess runs an authenticated fixed predecessor.
2. `cover` scans at most sixteen points, fifteen normals and three differences.
   Binary elimination uses at most sixteen rows and five bits. The exhaustive
   transfer visits exactly 65,536 masks and thirty hyperplanes per mask.
   Profile enumeration has four lengths, at most 2,002 weight multisets for
   each length, six distance levels and eight basis packings. The predecessor
   subprocess has a 120-second timeout. Registered commands have finite bounds.
3. Python allocates during operation. See the managed-runtime deviation below.
4. Each new function has at most thirty physical lines, including comments and
   blanks. Frozen predecessor functions retain their original layout.
5. `require` checks support, rank, inventory, source, receipt and coverage
   invariants even under `python -O`. The tests exercise invalid values and the
   sharp thirteen-point failure boundary.
6. New mutable state is local to the computation. Module values are immutable
   paths, tuples, or read-only-by-convention tables. No concurrent writers share
   research outputs; fresh receipts require an absent external destination.
7. Files are bounded to two megabytes, ordinary regular files and exact hashes.
   Missing data, linked data, source changes, receipt changes and predecessor
   failures reject. No proof-relevant subprocess result is ignored.
8. New code uses no dynamic evaluation or generated source. Test framework hooks
   and scoped mocks have the standard unittest lifecycle.
9. New data access is shallow. The only dynamic test calls are bounded unittest
   dispatch and scoped mocks; production imports name exact retained modules.
10. Verification runs warnings as errors, compilation, applicable Ruff rules,
    source/pin checks and behavioral tests. CHECKS.json records actual commands.
    Frozen sources are byte-authenticated rather than reformatted by lint.

## Managed-runtime and frozen-source deviations

Rule 3, fixed allocation. Python, Fraction, JSON and itertools allocate during
replay. Replacing them would exceed this mathematical package's scope. Inputs
are fixed to eight root coordinates, nine binary bits and at most two megabytes
per file. The largest enumerations stream their masks instead of retaining all
3,309,747 flats. The new transfer keeps only thirty planes and a finite histogram.
The inherited graph has 58 vertices and at most 40,000 traversal states; its
root/frame queues have explicit capacity checks. Registered replay and boundary
controls verify these limits. A native fixed-allocation verifier would require
separate implementation and equivalence review.

Rules 4/8/9/10, frozen sources and test framework. The retained modules include
unused predecessor application helpers and their original formatting. Their
exact bytes preserve attribution and bind the statements being reused; this
package does not edit them to satisfy local style rules. New code does not call
the unrelated applications. Unittest supplies bounded test dispatch, class hooks
and two scoped path mocks. Ruff is applied to new Python sources; warnings-as-
errors compilation and authenticated replay include the retained sources. A
future shared-library extraction must carry its own equivalence and source-
binding review. No assertion is disabled to pass verification.

These checks corroborate the finite premises. They are not independent human
review, proof-kernel verification of the Weyl-chamber theorem, or a proof of
full C5 or multiplication.
