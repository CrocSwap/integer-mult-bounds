# Credit and exact source reuse

Prepared for commdata2338 (@commdata2338), with substantial OpenAI Codex assistance.
New code, proof and documentation use the repository's Apache-2.0 license.

Jose Manuel (@jmbarrancoml) supplied PR2234's selected provider, chronological
expressions, low-class macroplans and recursive-closure proposal, and PR2310's
iterative evaluator, prepared-table tests and uniform-control argument. Those
are the principal predecessors. Their used source files and both original
notices are copied byte for byte, with original paths, exact commits, Git blobs
and SHA256 values in `SOURCES.json`. No predecessor source is edited here.

The vendored normal-form and descriptor lineage retains source527 and the
OpenAI framework, Ross Richardson's PR2159 fallback algebra, this account's
PR2160 good normal form and PR2188 mixed descriptors, and Jose Manuel's
PR2171/2195/2207 stream continuations. Their algorithms and the diagonal
covariance argument are reused and attributed; this contribution supplies
the joined table adapter, a scoped interface proof and independent local
matrix checks.

The selected source lineage includes DreamingOfClouds' PR589 on eumemic's
PR555 base, alephnan's retained PR1627 hosting/provider checks, Dugongue,
Rohan Arun, Zhihao Chen and the remaining contributors identified in the
retained source notices. Gareth Davidson's PR2289/2295 recurrence/moment
formalizations motivate the uniform physical-charge handoff but are not
built or claimed proved by this package. PR1379's tape parking result is
context and is not reproduced here.

All reported checks are author-run. Independent human review, formal proof,
complete physical realization and adoption of either pending predecessor
remain separate obligations.
