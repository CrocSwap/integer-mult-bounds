## Result and exact scope

[PROOF.md](PROOF.md) gives a joint construction for the selected #7000/#7001 raw
words at canonical base `e54523517d0f03e58352e647c403a5af3e525a57`. Its proposed
conclusion retains the selected complete saving
`kappa=363005817/100000000000=.00363005817` under `owned_erasure`,
`precision_tape` and `analytic_recovery`, supplying the source instances of
`native_all_columns` and `compiler` together.

The point is the quantifier order. First prove the raw all-column denotation
with *formal* positive queries. Next generate and freeze the finite
single-grade instruction list, without evaluating a query. Choose the binary
prime after its full rational matcher catalogue. Finally implement execution
by the lexicographic measure **(completed ordinary stage, active width)**.
Same-stage numerical children decrease width; ordinary movement calls a
previously completed stage. The elementary stage requires no fast supplier.
This is stronger than combining two conditional implications in a cycle.

The compiler receives arbitrary complete fields. Every discarded target has
its own zero-owned input and no productive credit. Its paid queries remain in
the invoice even when their current value is zero. The proof keeps nonzero raw
private clears under `owned_erasure`; an endpoint-zero argument does not pay
allocation or erase.

## Reproduction and provenance

This directory is a standalone source export. Run its authenticated entry
point with standard-library Python 3.11 or newer:

```sh
python3 -I -W error -B research/selected-native-compiler-closure/verify.py
python3 -I -W error -O -B research/selected-native-compiler-closure/verify.py
```

Before running either engine, `verify.py` verifies the SHA256 and Git blob
identity of every vendored input. It also rejects a changed-byte control for
each. The imported compiler modules are executed from source bytes, so an
unrelated `.pyc` cannot replace the checked input. Use `verify.py`, rather
than directly running an engine, for a source-authenticated replay.

[ORIGINS.json](ORIGINS.json) records each exact source, head, Git blob and
SHA256. Its `input` entries authenticate the working bytes in this export;
its `reference` entries are frozen proof citations, not dynamically fetched
or reauthenticated by the finite replay. [VERIFY.json](VERIFY.json) records
the bounded commands; [evidence/verification.txt](evidence/verification.txt)
contains the fresh result. Publication metadata and the selected certificate
are not altered by this child package.
