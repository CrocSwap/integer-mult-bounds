# Exact simultaneous butterflies on a complete field

`c_dispatch.py` runs simultaneous normalized butterflies on an actual complete tape of signed Gaussian words. No FFT, dense matrix, or product oracle supplies payloads. The controller uses one binary address primitive. For disjoint pairs `(s,t)`, it must apply `out[t] = in[t] XOR in[s]` to all pairs at once, leave every other address bit fixed, retain each opaque record, and restore its work. Each complete outer row has the same permutation. The literal implementation performs one sequential four-bucket split and merge per pair. A growing-family time saving requires the stronger bound for this same permutation stated below.

## A word whose all-column semantics can be checked

Use the repository's two-dimensional operator `C = ((1+i)I+(1-i)X)/2`, its normalized `H0`, and `S = diag(1,i)`. The upstream source gives `H0 = b S C S` with `b=(1-i)/2`. [Upstream operators](https://github.com/CrocSwap/integer-mult-bounds/blob/e54523517d0f03e58352e647c403a5af3e525a57/research/atlas-frontier-applications/applications/metric/primary/05-layers.tex)

A candidate fixes `N>=2`, `W>=2` productive registers, `Z>=0` owned registers, and a finite chronological instruction list. ADD and SUB have a specified source. HALF, CLEAR, NEG, and scalar `i` act on a specified register. A column gate applies one of global phase `i`, X, S, CZ, or CNOT, or one paid one-coordinate C to the declared register and base coordinates. At column multiplicity `f`, a column gate is the tensor power of its base action. For example, the global column phase acts by `i^f`. The scalar `i` acts once. Independent productive rows enter arbitrarily. Private rows enter zero and are cleared on exit. No private row receives productive credit.

For each ordered productive source and destination, expand its formal output into a finite sum `sum_A c[A] A^(tensor f)`. Each `A` is the product of the one-column matrices on one path. All `c[A]` are Gaussian dyadics independent of `f`. This description follows by instruction induction. A scalar gate adds or scales dictionaries. A column gate left-multiplies every key by its own base matrix. Different paths with the same matrix use one common key. The row-major binary address order at general `f` differs from the column-major tensor order by one common permutation on both sides. This permutation is the same for every term and the target. Complete spectators tensor with the identity.

Exact coefficient comparison is both sufficient and necessary for all `f>=1`. All keys are nonzero matrices. For any finite distinct set of keys, choose a complex linear functional `L` which is nonzero on each key and on every difference. Such a functional exists because finitely many proper hyperplanes cannot cover a vector space over an infinite field. Apply `L^(tensor f)` to a vanishing difference for `f=1,...,m`, where `m` is the number of keys. The resulting power matrix has determinant equal, up to sign, to the product of the nonzero `L(A)` and their distinct pairwise differences. Thus every coefficient vanishes. This includes keys differing only by a global phase. Cancellation at one column does not establish their equality. `finite_c_word.py` stores exact integer matrices with a common dyadic denominator and uses exact rational scalars. It accepts precisely the productive identity `I_W tensor C^(tensor N)` in this grammar. It also checks `P^500 < W^500 N^499` with integers, where `P` counts every paid operation, including calls on private registers.

## Physical recursion, rows and restoration

Let `h` be the number of requested coordinates in an `n`-bit address. Sort the requests and send them to consecutive low bits. Extend the partial bijection to its support union and fix its complement. Factor each cycle into the involutions `j -> -j` and `j -> 1-j`. Each involution is one disjoint matching of ordinary bit swaps, implemented by three disjoint XOR banks. At most `2h` positions move. Reverse the two matchings at exit. For the present geometry `h=O(p^.997)` and `n=Theta(p)`. No complete neighborhoods of width `O(log p)` are moved at this entry. All unselected labels remain available as data, never as prescribed zeroes.

At depth `d=floor(log_N h)` reserve `u=ceil(log2(W^d))` real, most significant, unselected address bits as a row prefix. After the initial permutation these are disjoint from the low `h` active bits whenever `h+u<=n`. If they do not fit, the program runs the entire requested C layer literally. Since `W,N` are fixed and `h=o(n)`, this exception is bounded along the stated family. The original `R=2^u` rows are padded to the next multiple of `W^d`, less than `2R`. Every row contains all `2^(n-u)` addresses and all data. Intermediate owners may mix arbitrary rows. Exact final productive independence returns padded rows to zero, which the exit scan explicitly checks. No padding is added in descendants.

At width `e=Nf+r`, execute the `r<N` individual C kernels on the remaining coordinates. Split the complete row prefix cyclically into disjoint groups of `W` productive registers. Each contains `R/W` complete rows through the current full address. Allocate and zero every declared owned register. Execute each scalar, phase, flip or CNOT operation. Exactly one register enters each paid rank-`f` recursive call. The other complete slots are pushed in reverse record order onto one sequential parking tape. The restored slots are popped in the reverse slot order and forward record order. Each call reduces the live child data volume by a factor `W`. Stack data is bounded by a geometric series times the root volume. At most a fixed number depending on this finite word of payload tapes are live at once. The remaining depth descriptors have polynomial size in `p` and are push/pop records. Restore the original row order and erase the owned buffers. This works for unrelated, correlated and zero input rows equally.

Column flips invert the order of a contiguous `f`-bit slice using two full block reversals that preserve its lower suffix. A column phase, S, or CZ costs a sequential record pass and `O(n)` bit operations on each index. A column CNOT gives one XOR bank on two disjoint contiguous slices of exactly `f` bits. All other address bits, row prefixes and nonzero coefficients are spectators.

## Exact arithmetic

On entry the C wrapper receives integer numerators at a known binary grid. The literal branch applies `2C` on each selected bit, so for rank `h` it returns exactly the numerator of `2^h C^(tensor h)` on the input numerators. A local complex numerator can grow by at most four in maximum-component norm. The returned signed width `initial_width+2h+3` covers the entire direct branch.

The recursive program executes unscaled `C` on a common grid. Set `J=len(ops)`, `B=J+N+1`, and lift the input exactly by `G=8B(h+1)` binary places. A completed C call on `f` bits incurs at most `f` denominator bits, and increases maximum-component log norm by at most `f`: a single C has absolute real-coordinate row sum two. HALF and a scalar sum cost at most one denominator bit or one magnitude bit. Within an active node the completed tail and preceding raw operations therefore cost at most `N+J+J floor(e/N)` in either height before a child. Inside a child, add its own bound, once. The sum over the path is bounded by `(N+J)(1+log_N h)+2Jh < G`. This uses the exact semantic result for every *completed* smaller call; the induction hypothesis establishes both its exact return and its internal headroom. The stored component width is `out_width+2G+4`, buying both the fractional lift and the temporary magnitude. Every HALF and every individual C division checks exact divisibility. At the root `C^(tensor h)` has denominator dividing `2^h`; dropping `G-h` exact low bits yields the required integer numerator. Since `h=O(p^.997)`, the fixed factor multiplying `h` still gives external working width `O(p)`.

Two address-dependent `S` phase passes and the exact scalar `b^h` turn the C numerator into normalized `H0^(tensor h)`. If `h=2k+e`, rotate by `(-i)^k`, multiply by `1-i` when `e=1`, and divide by `2^(h+k+e)`, once, toward zero. The first `h` bits in this denominator compensate the native integer-numerator representation. The synthetic FFT's initial `log2 M` fraction lift makes all of these normalized H drops exact before its last scalar projection.
