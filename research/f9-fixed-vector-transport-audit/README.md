# F9 fixed-vector premise versus full-frame transport

**Audit, no new κ.** On the pinned F9 word, every canonical `K_G` fixes the
computational zero vector. The full-frame transport `F† K_G F` does so for
8 of the 72 classes and moves `|0>` for the other 64.

The selected conditional exponent stays `781451/250000000`.

## Scope and evidence

Task `joint-query-controller`, scope **refined**. The card's first experiment
says to audit PR5745's active-mode delivery claim before another free-injection
search. PR5823 later closed the immutable all-rank floor and left this
common-fixed-vector premise open. This package decides that premise for the
word PR5720 names. It does not change the query demand or construct a caller.

[PROOF.md](PROOF.md) states the two operators, the general `K_G|0> = |0>`
lemma, and the 8/64 transport census. [RESULT.json](RESULT.json) lists every
class. The eight classes that fix `|0>` with phase `+1` are operators
2, 16, 17, 41, 44, 61, 62 and 64. Operator 1 is sent to address 48, matching
the predecessor monomial recipe for the same columns.

The scalar observer in PR5745 leaves rational coefficients unchanged at a
warp. That step agrees with `K_G` on `|0>` and does not agree with the
full-frame transport, except on those eight classes. PR5823's `8H8` floor
still depends on the fixed-vector reading. It is not a theorem about
`F† K_G F`.

## Limits

The lemma is the matrix element on `|0>` only. Nonzero addresses, moving
charts, feedback-dependent payloads and a changed native word remain outside
it. No compiler, caller, precision or outer admission is claimed. The
predecessor kernel already recorded that these `K_G` fix `|0>` and stored
monomial recipes; this check uses the separate quadratic engine and binds
the F9 member hash named by PR5720.

## Open next questions

* Can one of the eight transports that fix `|0>` be used by a legal caller
  without paying a new `H8`? First price that one class, including its
  frame change, restoration and target debit, against the removed centre
  job. The fixed-vector identity alone does not supply that invoice.
* For a nonzero common address, which of the 72 classes still have matrix
  element `1`? Evaluate `K_G` on one nonzero basis vector before treating
  the scalar observer as exact for that address. This package only treats
  `|0>`.
