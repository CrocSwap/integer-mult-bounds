## Theorem (cut count)
Let W pass AL (run(), no --main) on the 112-port geometry (odd weight ports p_t in F2^9, h=9), and assume H-CUT: every op of W['cut'] is `add target<-q` with q in W['centers'], and no centre is a target register. Let K = the centre registers read in the cut. Then |K| >= mu, the minimum rank of a real 112x112 X with X[t,u]=delta_tu on Odd={(t,u): p_t.p_u odd}. mu >= omega = max set of ports with pairwise ODD inner product. For the 112 ports omega = 8 (exhaustive, clique.py), so |K| >= 8: at least 8 registers sit at their locked centre frames at one instant (start of B, AL:131). Tight: shipped words have |K|=8, rank(F-F0)=8. Corollary: the assert len(centers)==8 (code/audit_allcold.py:75, emit_allcold.py:41) is forced, not a choice.
## Proof (lemmas)
L0 (what AL requires): rows v+t of the whole program on source columns = I (endpoint identity :106-112, forward). Cleanup ops cannot touch targets (:143: end[target]=perp(p_t), dim 8 != full). Precondition ops act on targets only; compensation is helper->target (:92-94): neither carries source content (checked).
L1 (monotone everywhere): cur[] is assigned only at :117,:120 (start) and :125 (climb, which needs contained(cur,U), :122). The centre loop :130-136 changes only the local U (billing); cur[q] stays the centre frame. So frames never fall, even at centres (this corrects "descent" wording of B134/B164: it is a pricing step, not a frame fall).
L2 (path lemma): every A/B/tail op climbs BOTH registers to its e[-1] (:31,:138,:141). So a time-respecting directed path u=r0->...->v+t through framed ops gives cur_end(v+t) contains <p_u> (start :117). End cap :115,:142 forces cur_end(v+t) inside perp(p_t). Hence <p_u> in perp(p_t), i.e. (t,u) even. 
L3 (F0 odd-free): let F0 = rows v+t, source cols of the program with W['cut'] deleted. F0[t,u] != 0 needs such a framed path (matrix-product expansion). So F0 = 0 on Odd.
L4 (rank): cut ops only add centre values into targets, never read targets, so the cut block is I+N, N = sum_{q in K} n_q e_q^T (N^2=0). Then F - F0 = X_post N X_pre = sum_q (X_post n_q)(e_q^T X_pre): rank <= |K|.
L5 (count): X := F-F0 equals F=I on Odd (L0, L3), so |K| >= rank X >= mu. A set I of pairwise-odd ports gives X[I,I] = Id, so rank X >= |I|; omega = 8.
Side lemma (checked): frame of centre q contains p_u for every u in the support of q's A-row (L2), so a centre's frame >= span of its sources' ports.

## Scope, caveats, corrections
1. H-CUT is NOT enforced by AL: cut ops get no frame check (AL:82 concatenates them, :132 only reads dest/src for `served`). A cut op `add target<-nonCentre` is frame-free. H-CUT comes from the emitters (B101: c82 assert) and the 8-centre asserts above. Any verifier that let a cut read other registers would still need >= 8 frame-free read sources: the proof gives rank(F-F0) <= #frame-free ops in general (telescoping, one rank-1 term per op).
2. One cut section/one time: AL has a single 'cut' (:82,:126-137); "every time cut" of the card reduces to that instant. A different verifier with several descent epochs is outside the theorem (bound becomes #free ops >= 8, grouped by register version only in a slab).
3. The card's premise is imprecise: rank(M o Odd) = 112 (M = B3R/M.npy, rank 112; M != I-RR^T/2 exactly), so "odd part of M has rank 8" is false as stated; also M is the A,B,cut-order replay (B3 replay.py), while in AL order A,cut,B the target-source map is I. The right rank object is the minimum-rank COMPLETION of the odd-position constraints (clique bound), not a Hadamard-masked rank. Also G_ut odd <-> port pair EVEN (diag G=2, diag ports odd).
4. mu >= omega only; mu = 8 follows from omega=8 plus the shipped words (|K|=8). Valid for these ports (all three words have the same port set up to the same labels).
5. Does not price anything: B106 (cst per functional) and R40-C/B134/B164 pricing stay as is; this gives the count, which they used as ARGUED. B14/B27 (decoder terms) are separate (decoder n>=9 via B109).
