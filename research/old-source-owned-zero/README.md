validates the whole old body, and emits a **separate owned HOME** containing

writes; every successful head and private guide is restored.

and complete old context length E_old, it satisfies

```
T <= 2^20 (V_old + E_old + 1),
history_after <= history_entry + 64(V_old + E_old + 3).
```

The general codec's selected-bit permutations are unnecessary for zero:
every complete address permutation, component reversal and linear native

start as a fresh blank owned window or as an arbitrary correlated inactive

The literal table is translated to the actual old hardware symbols at
compile time: old LEFT remains 2 and blank remains 6. No public marker or
codeword is rewritten. HOME returns on its LEFT guard, while OLD, CONTEXT
and the private heads return to their first body cells.
