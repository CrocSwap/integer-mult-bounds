New work is Apache-2.0. Exact retained sources preserve their original notices.

The selected #7000 source, its application and predecessor native/Clifford
contributors supply the actual event and operator decomposition. The published
literal-native-quadratic-phase package supplies the exact current recipe
binding and five-Gamma/raw packed ABI. The published literal-row-reversal
package supplies the unchanged literal record-reversal graph, classical
two-stack implementation and exact cost/history theorem. The phase lineage
supplies the retained Gamma/unary helpers, and #7349 supplies the finite
machine grammar and builder. The earlier serial monomial descriptor iterator
is a distinct predecessor, not a solved numerical join on this ABI.

This package contributes literal collapsed-descriptor production and the
actual fixed-graph join for one source-bound post-matrix translation. It does
not claim the source recipe, tensor translation identity, reversal algorithm,
or classical unary/binary conversion as new. Independent AI review, where
recorded, is not human or formal-kernel acceptance.
