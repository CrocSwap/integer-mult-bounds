## 2. Geometry, positive direction and absolute phase

The unchanged first-slot leaf applies positive C to all f bits of slot0
using the original nine-slot geometry. Replacing its header f by rho*f
would change its volume to2^(9rho*f); it would not select rho slots from
the2^(9f) body. This construction never passes such a changed header.

For fixed i>0, the three-CNOT word
`(0<-0 xor i),(i<-i xor0),(0<-0 xor i)` exchanges slots0 and i. The
unchanged generic `cnot_columns(target,control)` applies each gate to all
corresponding f columns. Its inherited proof covers any distinct fixed
pair in0..8. The word sends (a,b) to (b,a), preserving other coordinates,
and has no Gaussian phase. Write this permutation Si. Exactly `Si C0 Si=Ci`.

Chronologically the program executes joint guard,C0, then Si,C0,Si for
i=1..rho-1, then commit/retirement. The Ci act on disjoint bits and commute.
This is positive C on all rho*f requested axes, including the factor1/2
and absolute phase. It is not projective equality. Every factor uses the
original header for full prefix/middle/suffix/component strides; all P/S,
c coefficients and inactive native bits remain complete spectators. The
all-f tensor statement follows from these individual coordinate operators,
not by tensor-powering a register scalar sum.

## 3. Literal rank-times-f guard

Let n be f's bit length, `q=ceil(log2(rho))`, with q=0 at rho1. Prefix FBIN
with q zero digits before the unchanged Gamma parser appends f's canonical
n MSB-first bits. The same parser retains original unary F and n marks on
FLEN. The public header is read-only throughout.

Clear FLEN and scan FBIN from its low end. Fixed carry a in0..rho-1 on
digit b writes `(rho*b+a) mod2` and changes to `floor((rho*b+a)/2)`.
Induction on processed low digits proves multiplication. Every new carry
stays in0..rho-1. Since rho<=2^q and f<2^n, the product fits n+q positions.
The carry at the original left marker is therefore zero. A nonzero carry
there rejects; no left guard or opaque neighbor is overwritten/crossed.

Skip/erase leading product zeros; copy the positive canonical suffix to
PREFIX while rebuilding FLEN and erasing old FBIN. Return FBIN across its
now blank body and move PREFIX back into it, erasing PREFIX. FBIN/FLEN now
hold canonical rho*f and its length at the original origins. The product
has n..n+q digits, so at most q leading zeros are skipped. Unary F remains f.
The loops are literal fixed-state operations; no host decoding occurs.

Decode c,P,S,w using the inherited parser. Read cutoff only as binary
digits/length. The retained length-first and lexicographic comparison now
tests rho*f<=cutoff, clears its binary guides, and returns. Restore HEADER
with its trace; clear all other guides and local markers. In particular,
an arbitrarily large encoded cutoff is charged by E, never its numeric value.
