## Summary

Add a literal fixed-rank positive central service for every construction-time
native rank `rho=1..9` and arbitrary encoded column count `f` in the existing
Gamma6/HOME ABI. The wrapper preserves the original `f` header and complete
nine-slot geometry, and checks the joint guard `rho*f <= cutoff`.

Each actual C prefix must remain integral on the supplied common grid and fit
signed width `w`; final fit alone is not an entry promise. The package states a
simple sufficient input reserve and the complete direct-leaf bill, including
incremental history and the separate HOME adapter charge.
