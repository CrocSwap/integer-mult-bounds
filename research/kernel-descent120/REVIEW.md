# Independent checks and reproducibility

The package verifier regenerates the pinned upstream source, compiles eight native C++ checkers and executes the exact published retiming stage. It does not accept stored PASS receipts as evidence without execution. Frozen witnesses are sufficient for reproduction; stochastic discovery is not rerun.

The transform checks every local input column forward and inverse. A separate arbitrary-precision chronological checker verifies actual frames, source ownership and COPY lifetimes. A separate prefix checker verifies every selected response relation. The bank checker constructs exact charts and enumerates the entire120-replica assignment. The five-stage checker covers every global input column. The finite invoice recounts actual costs and the old price engine regresses the pinned PR249 endpoint. The final fixed-prime engine independently recomputes that full invoice and uses two exact moment enclosures.

Expected mathematical receipts and both pre-retiming and final word hashes are pinned. Runtime durations and local output path fields are excluded from semantic receipt comparison; mathematical values are not. The final certificate binds the immutable package manifest and records whether upstream regeneration occurred. Default replay regenerates it; snapshots-only explicitly records weaker provenance.

Earlier development tests also rejected one-unit underbilling of selectors, primitive coefficient and rank mass. Omitted basis operations, inverse basis operations, global bridges and individual bank blocks are nonvacuous negative controls in the actual checkers. Tests and finite checks do not prove the retained public all-size interfaces.

The packaged retiming stage differs from pinned PR263 only by caching each exact rational canonical frame key once instead of recomputing it twice. The selected representative remains the smallest sorted frame ID for that key. All source-span, Gram, chronological and histogram checks remain active. Its full output must match the receipts and word obtained from the unchanged original stage.
