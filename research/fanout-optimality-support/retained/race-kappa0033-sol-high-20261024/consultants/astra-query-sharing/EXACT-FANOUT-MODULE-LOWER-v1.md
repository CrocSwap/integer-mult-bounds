For the supplied program n=25, with the nine source coordinates embedded in the declared stage axes. Up to the fixed address-layout permutation, every whole field at width f belongs to V tensor-powered f times.

The ordinary address gates are the fixed source columnwise unit monomials: binary P maps, X translations, Z4 diagonal-polynomial D gates, and per-column fourth-root phases. They generate a finite group G. One may conservatively enlarge G to all computational-basis monomial matrices on V with fourth-root entries; that group is still finite and contains every allowed source ordinary address gate. This enlargement does not turn a nonmonomial operator into a monomial operator.

All other ordinary operations are K-linear whole-field ADDs, COPYs, uniform exterior scalar multiplications, and CLEARs. Coefficients and the finite straight-line program are fixed independently of f. The program may use arbitrary fixed numbers of known-zero or arbitrary-dirty owned fields; may overwrite, copy, clear, reuse or preserve intermediates; and may feed earlier paid outputs into later paid inputs. Arbitrary positive-rank Gaussian field calls are permitted, each applying one invertible fixed one-column operator lifted columnwise to ONE whole field of the declared capacity. Ordinary pre/post maps and an unchanged copy of the input do not create an additional paid output row.

## 2. Faithfulness of the all-width tensor family

For h in H, write [h] for a BASIS ELEMENT of the formal group algebra K[H]. Define

```text
Phi_f([h]) = h tensor-powered f times,
Phi_f(sum_h c_h [h]) = sum_h c_h (h tensor-powered f times).
```

The scalar c_h is exterior and applied once. Each Phi_f is a K-algebra homomorphism, because tensor powers preserve operator products. The combined map over all positive f is injective on K[H].

Proof: take distinct nonzero matrices h_1,...,h_t and suppose

```text
sum_j c_j h_j^(tensor f) = 0  for every f>=1.
```

Since K is infinite, choose a K-linear functional ell on End(V) such that the values `lambda_j=ell(h_j)` are nonzero and pairwise distinct. The excluded choices form only finitely many proper hyperplanes. Apply ell tensor-powered f times to the operator identity. For f=1,...,t this gives

```text
sum_j c_j lambda_j^f = 0.
```

The matrix of these equations has determinant, up to sign,

```text
(product_j lambda_j) (product_{a<b}(lambda_b-lambda_a)),
```

which is nonzero. Hence every c_j=0. This proves injectivity. No finiteness of H is required; each group-algebra element has finite support.

The source address layout may conjugate every tensor-powered operator by the same fixed layout permutation at width f. That does not change the proof. The declared stage embedding adds identity spectator factors and likewise preserves it.

This is the crucial distinction from the width-one matrix algebra. At width1, `q=aI+bX` is a valid matrix equality. It is NOT the group-algebra identity `[q]=a[I]+b[X]`: at width f the left side becomes q^(tensor f), whereas the right side remains `a I^(tensor f)+b X^(tensor f)`. A two-term width-one expansion cannot be substituted into a fixed all-width program.

Likewise `[iI]` and `i[I]` are different group-algebra elements. Their evaluations are respectively `i^f I` and `i I`. The source phase prescription is exactly the first for a phase gate, while exterior scalar multiplication is exactly the second. Using the actual width-one matrix span instead of formal K[G] would collapse these distinctions and invalidate the proposed lower bound.

Because the target equality holds on all independent original fields, it gives a separate operator equality for every input column at every f. The injectivity lemma therefore promotes each such equality to an equality in K[H], component by component.

## 3. One paid field call adds at most one ordinary module generator

Set `R=K[G]` as a formal group algebra. Its K-dimension is the finite positive integer |G|. Let N count all independent initial input coordinates, including arbitrary owned dirt if present. Known-zero owned fields have row0 and need no new input coordinate.

Represent every field at every point of the fixed program by a row in `K[H]^N`. Initially the independent rows are the coordinate vectors e_1,...,e_N. Define the conceptual history module to retain ALL initial rows and ALL paid output rows, even after their physical fields have been overwritten or cleared.

Before any paid call, ordinary operations keep each current row in the left R-module

```text
I = R e_1 + ... + R e_N = R^N.
```

After k paid calls, let t_1,...,t_k be their actual output rows and define

```text
M_k = I + R t_1 + ... + R t_k.
```

Every current field row belongs to M_k. This is an induction over the actual chronology:

- an ordinary address gate left-multiplies a current row by an element of G;
- ADD and exterior SCALE form R-linear combinations;
- COPY repeats an existing row;
- CLEAR replaces a row by0;
- the next Gaussian applies its H element to its actual current input row and creates one new row t_(k+1), which is then adjoined.

The input of a later Gaussian may contain any earlier paid outputs. No one-layer assumption is made. Keeping overwritten rows only enlarges the history module, making this a valid upper bound on what the physical program can access.

There is a surjective K-linear map `R^(N+k) -> M_k`, sending the standard generators to the initial and paid-output rows. Thus

```text
dim_K M_k <= (N+k) |G|.
```

This inequality does not require R to be a division ring or an integral domain. In particular, zero divisors and ordinary projector combinations are allowed.

## 4. The targets require C additional free copies of R

At the final time m, each required target row and each initial background row lie in M_m. Subtracting the ordinary initial background conceptually shows that every f_i lies in M_m. This is a containment argument, not an extra physical operation or a promise that erased data can be recovered for free.

First remove the shared right normalizers mathematically. Right-multiply the h_j coordinate of every row by Km_j^-1, and leave other coordinates unchanged. This is an invertible LEFT R-linear map on the ambient row space, since left multiplication commutes with this coordinatewise right multiplication. It sends I to I because Km_j is in G. It sends the required rows to

```text
f_i_tilde = [A_i] M[i,:] / 2
```

on their eight h columns. Thus the common right-diagonal Km factor cannot alter the dimension comparison. This step is not an assumption that a paid operator commutes with Km.

For a class with representative a, write `A_i=g_i a`, with g_i in G. Multiplication by the unit [g_i]^-1 and the exterior factor2 shows that its required row module is generated by

```text
[a] M[i,:],  i in that class.
```

Let v_1,...,v_r be any rational basis of those scalar rows. They also have rank r over K, since extending scalars from Q to Q(i) does not change the rank of a rational matrix. The class module is generated by `[a]v_1,...,[a]v_r` and is FREE of rank r over R.

To prove freeness without ignoring zero divisors, suppose

```text
sum_l r_l [a] v_l = 0,    r_l in R.
```

The r-by8 scalar matrix with rows v_l has a right inverse over K. Multiply the eight coordinate equations by that scalar right inverse. Scalar coefficients are central, so this gives `r_l [a]=0` for every l. Right multiplication by the group element [a] is invertible in K[H], hence every r_l=0. This proves injectivity of the map `R^r -> K[H]^N` and therefore K-dimension `r |G|` for this class contribution.

For distinct classes, the possible group-basis supports of their coefficients are disjoint sets G a. Consequently their row submodules form a direct sum. Each is also disjoint from I, whose coefficients are supported in G itself, because every A_i is nonordinary. The common right normalization above is what makes this support separation simultaneous in all eight input coordinates.

It follows that M_m contains an internal direct sum isomorphic, as a left R-module, to

```text
R^N  direct-sum  (direct-sum_alpha R^(r_alpha)),
```

and hence

```text
dim_K M_m >= (N+C) |G|.
```

Combining the lower and upper dimensions gives

```text
(N+C)|G| <= dim_K M_m <= (N+m)|G|,
therefore m >= C.
```

Arbitrary dirty owned entries do not provide a loophole: including them increases N on BOTH sides, and N cancels. Arbitrarily many fixed known-zero scratch fields add no independent initial rows. COPY/CLEAR and noninvertible ordinary projectors likewise add no paid generator. Zero divisors cannot pack the required FREE class modules into fewer generators because the finite K-dimension comparison remains valid.

## 5. Source-specific conclusion and exact limits

Under Sections1–4, every fixed finite exact program implementing this full arbitrary-input `y += q^-1 W_s h` requires at least C paid Gaussian whole-field calls. These calls may form arbitrarily many layers and may use earlier outputs through ordinary feedback. If only central H1 queries are permitted, this is at least C H1 calls. If higher-rank Gaussian field calls are also permitted, it remains a bound on their total NUMBER at the same whole-field capacity; no weighted invoice is inferred here.

The root receipt binds C=112 for the exact112-row source. Subject to independent acceptance of this proof,112 is therefore the optimal Gaussian FIELD-CALL count in this fixed standalone grammar, matched by the emitted112-H1 upper construction. This does not optimize its ordinary work, scratch, precision, transport or source/compiler constants.

The following boundaries are essential:

1. **Fixed columnwise ordinary gates.** G must be finite. The actual P/X/Z4-D/per-column-phase grammar has this property. A different ordinary model with unrestricted address operations coupling fiber columns, non-root per-column scalings, or an infinite ordinary group requires a different argument. Finite dimension is used explicitly.
2. **Fixed finite program and exterior coefficients.** The same finite word and the same exterior K coefficients must establish the target for every positive f. A width-dependent or width-growing program is not covered by the tensor-family injection as used here. Nor are approximation schemes, nonlinear/data-dependent operations or anti-linear operations outside the stated K-linear grammar.
3. **All original inputs independent.** Restricting h or y to a special image, imposing a relation between fields, changing the target background to a nonordinary one, or requesting only selected original columns changes the target module. The arbitrary whole-field interface is part of the theorem.
4. **No free nonordinary initial observations.** If a caller starts this cut with a correctly versioned qh, a Gaussian cache, a native observation, or another correlated nonordinary row, the initial module is not merely R^N. The proof must then bound the new dimension gained beyond that actual initial module. It gives no automatic additional112-call lower bound at such a cut.
5. **Fixed whole-field capacity.** A paid call returns one new transformed row on the declared common field space. Packing original fields into a larger address geometry, changing capacities, splitting field domains, or obtaining multiple independent transformed outputs from one charged call changes this model and its invoice.
6. **Central scalar source matrix and common right factors.** The source factorization `A_i M[i,j] Km_j/2` is used essentially. Arbitrary operator-valued coefficients or row-dependent right factors do not receive this class-rank conclusion without a new proof.
7. **Exact phases and lift.** A per-column phase is a group element, not an exterior scalar; rational M coefficients are exterior, not tensor-powered. Projective cosets or an impulse-only source test do not establish the required decomposition.

In particular, this theorem must NOT be transferred directly to the global120 termination problem, a complete coupled caller, a noisy-helper construction, or a stream with previously paid observations. It also proves no unconditional arithmetic or multiplication lower bound. Those tasks may have different initial nonordinary modules, field geometries, targets or allowed operations.
