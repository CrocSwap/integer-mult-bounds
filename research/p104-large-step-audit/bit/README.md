# Nine BIT cache promotions fail under the fixed chart trace

The nine descending owned fields 770–778 cannot become independent productive
outputs by adding linear repair confined to chart 0 while preserving the
original chart trace and all operations at other charts. This includes a joint
change of basis among the nine new inputs and repair interleaved with the old
word. It is a scoped negative result and supplies no new κ.

The standalone audit uses one immutable scientific input and Python 3.10+ with
the standard library. It imports no predecessor checker and needs no Git or
network access. Its default run is read-only and checks both the source hash
and every field of the hash-pinned expected receipt.

```sh
python3.12 -I -B audit.py
python3.12 -O -I -B audit.py
```

The script resolves inputs relative to its own file, so either command also
works when invoked by absolute path from another directory. A passing run
prints `PASS_INDEPENDENT_REVERSE_DUAL_FIXED_HISTORY_SCREEN` in its JSON receipt.

The reverse calculation propagates 39,848 observation functionals and obtains
nine explicit right-kernel witnesses. Separate XOR checks and a concrete
forward execution verify these witnesses without trusting the elimination
rank. Positive controls grant one joint new-input combination or all nine
independent inputs; negative controls reject a changed witness and corrupt
source bytes. [PROOF.md](PROOF.md) gives the argument and its limits.

The symbolic credit `36 * 9 * 7^(1-C)` is hypothetical. This component does not
replay the signed caller, certify a revised paid invoice, grant new targets,
or establish the complete conditional multiplier. Changes to another chart,
address maps, nonzero-chart operations, or the input/output contract remain
outside the result. The separately authored implementation is model-run audit
evidence, not independent human or formal-kernel review.
