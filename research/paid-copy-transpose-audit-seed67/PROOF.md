# Full-map transpose and paid count

Write column-vector states on n scalar registers and one private work register. For a primitive with matrix A, the reverse-mode full linear transpose is A^T, whether or not A is invertible. If a chronological stream is A_1,...,A_k, its matrix is A_k...A_1, so its transpose is A_1^T...A_k^T. Therefore the transposed chronological stream is A_k^T,...,A_1^T.

For a distinct-register overwrite C_(t<-s), only row t changes from the identity: it becomes e_s^T. The transposed map sends s to s+t and t to zero, leaving all other coordinates unchanged. ADD(s,t) followed by CLEAR(t) implements it. Reversing these two operations erases the value that must be accumulated. Copying s from t is a different rank-one map. A single listed primitive can change only one output row, whereas C^T changes two; hence no one-primitive realization exists in the listed vocabulary without auxiliary registers. All 15 zero/one-primitive programs on two registers with distinct binary operands are independently replayed as a finite certificate, and the two-primitive witness is checked on both input columns. Allowing self-COPY adds only the identity already covered by the zero-length case; self-ADD/SUBTRACT coincide with DOUBLE/CLEAR.

Every other primitive has a one-primitive transpose: add/subtract reverses its directed edge, and clear/double/halve/negate is diagonal and self-transpose. Thus literal gate-by-gate expansion has length k plus the number of COPYs. This is an exact count for this specified transformation only. Subsequence fusion or a fresh lowering may do better.

Each pinned lowered ADD has full boundary (x,w) -> (E x,0), for arbitrary w, while each SCALE has boundary (x,w) -> (D x,w). There is at least one ADD in the cleanup. Their composition is (x,w) -> (M x,0), i.e. diag(M,0). Transposing yields diag(M^T,0). Reversing the macro order and swapping ADD operands (retaining coefficients and diagonal SCALEs) gives M^T. Lowering those macros by PR696 once again clears arbitrary work and thus has the same full matrix. Each macro's lowering length is unchanged by swapping ADD operands, so this direct lowering has the forward count.

The certificate verifies these equations as exact rational matrices on all 705 input coordinates. Its independent macro-column oracle reconstructs the full scalar M, while the primitive interpreter checks erasure of the arbitrary private input and its zero output. A deliberate extra work-to-target ADD passes every clean-work scalar-input column but fails the full dirty-input map, demonstrating why the work column cannot be dropped.

The cleanup contains 4,191 unit-cost COPY primitives. Accordingly 26,541 + 4,191 = 30,732 real primitives in its literal transpose; direct transposed-macro lowering remains 26,541. Applying the real-coefficient construction separately to real and imaginary components doubles these counts. This proof neither transposes physical Clifford recipes nor infers a prefix bound or global invoice.
