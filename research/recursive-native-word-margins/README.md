# Minimal word margins through the physical recursive caller

The recursive native caller inherits finite-word arithmetic guards even
when enough register slots are available. This package proves that its
actual root producer's minimal templates remain sufficient through the
historical dimension-64, rank-at-most-42 caller: complete body geometry,
generated child histories, high routing, leaf records and exact parent
restoration. **No new κ.**

For root body width `n0 >= 64` and modulus `M = q^w`, the unchanged
`PhysicalArena.prepare` produces index width `bitlength(n0)+1` and residue
width `bitlength(M)+1`. On the explicitly admitted source and record domain,
every finite prefix before an unrelated failure satisfies the numerical
width guards in the two native working banks and matching ingress words.
In particular, every fixed-word divisor there has a zero high bit. Ordinary's
separate high/tail preparation rings retain their own maxima and are outside
this native-width conclusion. No successful capacity-unlimited execution
is assumed.

The proof distinguishes two values that simple residue-only bounds miss.
The complete body endpoint can be `2*n0`, while the terminal route mask is
`2^(L-1)` and can exceed `M`. Both fit their templates; neither enters a
fixed-word division. The original external gap changes separate cardinality
tapes, not atom-coordinate word sizes.

## Assumptions and limitations

The theorem concerns the admitted unbounded-integer semantic domain of the
pinned historical caller, not arbitrary malformed records. It inherits
canonical residues, valid source classes, chronological parent/child
histories, ordered primitive coordinates, correct ownership and record
grammar. It does not assume the width guards that it proves. Other errors,
capacity shortages, rejected source classes or interrupted execution remain
possible. No transactional cleanup after a rejected call is claimed.

The finite record witness uses actual selected catalogue labels and
source-generated common-low data, with zero high fields; it is not a full
GL64 Boolean payload. The reduced high-route witness has dimension one.
Neither fixture substitutes for the written all-size proof or admits the
selected CrocSwap/integer-mult-bounds#6030 supplier. No multiplication-bound
improvement, independent human review or formal-kernel acceptance is claimed.
