# Locate every expanded compiler leaf and its persistent source or owned field

**Scoped compiler-emission theorem; no new kappa.** This package joins the
published source/occurrence codecs to the evaluated smaller-rank library.
Given any ordinal in the fully expanded compiler's rank-one paid-leaf
projection, it returns the exact chronological smaller-call path, canonical
base axis, and original source-row or owned-bank identity. The inverse
recovers the ordinal. It also resolves every input port of a whole nested
call to its persistent caller field, preserving return order.

The new weighted suffix table compresses chronological exit counts by
`(depth,paid-rank product)`, with bottom weights from each actual smaller
program. Equal-rank paths still receive distinct chronological intervals.
Upward source/exit port translation composes through rank descent; encountering
an already existing parent's owned bank retains its original namespace.

This is an emitted **leaf projection**, not the complete scalar/phase/adapter
word. The actual selected native manifest and winning huge library are not
materialized. Whole-job adapters, payload gathering/return, numerical child
correctness, initialization/erasure and fixed-tape payload costs remain
separate obligations. The selected conditional kappa remains 0.00363005817,
and all five foundational assumptions remain.

## Why chronological identity matters

With one rank-two productive role x and two paid rank-one sites on x, two
distinct exit leaves visit the **same physical source row**. Their cut keys
are `(0,)` and `(1,)`, and their leaf ordinals differ. A map keyed only by
physical owner or rank loses an instruction. The new inverse retains the
full cut and call path. Nonaliasing is proved for the input ports of **one
whole invocation**, never globally across all leaves.

## Exact scope and cost

The written [proof](PROOF.md) covers every separated fixed finite rule and
every supplied valid rank library, including an ambient cap A larger than
all target ranks. The unchanged default library generator from #7345 is used
only in its A=max(target rank) specialization. Its sharper width bound is
not transferred to the larger-A case.

After paying for the N-row input library, node-local setup and indexed leaf
queries have deterministic polynomial bounds in log N and actual supplied
integer bit lengths, for fixed rank alphabets. Every source bucket rebuild,
large replica quotient, path copy and retained table is charged. A separate
serialized-table simulation charges full scans, cursor returns and erasure;
it grants no free random access or payload move.

## Reproduction and verification

Python 3.12 and the standard library, from the repository root:

```sh
python3 -I -W error -B research/chronological-leaf-owner-index/verify.py
python3 -I -O -W error -B research/chronological-leaf-owner-index/verify.py
```

Expected status: `PASS_CHRONOLOGICAL_LEAF_OWNER_INDEX`. Default replay compares
the complete fresh evidence with `VALIDATION.json`; `--write` is an explicit
authoring option. Frozen source bytes are authenticated before use.

The separate literal oracle imports no production source codec, owner
resolver or suffix DP. It materializes classes, matches actual ordered
parent/child slot lists, then fully expands all smaller calls. The checks
compare **4,102 leaves**, **2,970 whole calls**, and **3,746 child input ports**
over 78 ranks, including 1,183 owned-field leaves and 106 complement batches
crossing replica boundaries. Fifteen failure controls cover lost site
multiplicity, merged cuts/replicas, lost owned namespaces, wrong totals,
return identities and invalid ports.

A separate direct base-eight/last-owned-site oracle checks queries into
**68,719,476,736 chronological cuts**, represented by 13 suffix-count states
and 12 source-count states. Another queried library has 4,729,570,560,000
replicas, 94,591,411,200,000 source rows and 5,158,340,373,946,848 leaves.
Those instances are not expanded or asserted to be realizable native
suppliers. The universal result comes from the proof, not these finite sizes.
