Each selected block is replaced by one equal-volume child from the first source span to the last target span, with rank equal to block length. Retain the exact original normalized read increments in their old charts at their literal clocks, and retain the clocks and coframe endpoints of every other paid MOVE. Grant arbitrary linear coframed operations, free caching, and free restoration. The obstruction can apply even if every scalar contact is recomputed by a different owner.

## Temporal support

Index an independent input by its arbitrary complete field. For each span store the set of input fields on which a value in that span may depend. Seed the sets with the literal initial charts, retain all labels with equal span as aliases, and persist all learned dependencies indefinitely. Scalar ADD, COPY, SCALE, zero initialization and erasure cannot introduce a dependence from outside the span's current set. A MOVE with fixed source and target takes a linear map of a value in its source span, so at that clock union the source set into the target set. Grant any independent coordinate in the source even when the actual carrier has no copy of it. This is an induction on the old paid clocks. Monomial address and phase differences within an equal span are also granted free.

Fix an original intermediate read between adjacent ascents \(a,b\) of its owner. A block crossing this gap consumes both \(a,b\). Any disjoint chosen block consumes neither. Remove the old paid edges \(a,b\); keep every other old paid edge, even when the actual fusion would have deleted it. Form all hypothetical same-owner fused arcs. Omit an occurrence if it contains exactly one of \(a,b\). Retain every other occurrence at all times, even when its actual move would be scheduled later, its original blocks overlap, or only one of several alternatives can run. Identical endpoint arcs remain if at least one occurrence remains. All possible legal new arcs are covered by this overgrant. They strictly ascend the span lattice. Close the dependency sets under the timeless arcs at initialization and after every old paid clock. A needed independent input absent immediately before the original read is impossible to supply in that chart under any fusion layout crossing the gap. The exact original read contribution is a nonzero rational multiple of its original normalized source row. Its support follows from the exact normalized replay. This proof is about preserving a live read contribution. Terminal cancellation, changing the prescribed read chart or clock, moving another paid clock, or replacing the native external input contract changes the question.
