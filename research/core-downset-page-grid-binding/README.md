## Reproduce

Run `python3.12 -B scripts/research_package.py --package
research/core-downset-page-grid-binding` from the repository root. Direct
normal or optimized execution of verify.py works in the official Git-free
export. Standard library only; declared timeout 300 seconds. Do not run
concurrently with another heavy scientific replay. `--record` deliberately
regenerates the package receipt; ordinary invocation only compares it.

The checker independently reconstructs grid floors, exact inverse-page
identities and rounded page errors. It applies original reference factors
to each actual stage input, checks raw Euclidean entrance radii, and checks
the final narrow residual/gap or broad direct product. It does not import
or run the predecessor scientific verifier. The source's own execute guards
remain active. Controls use an actual old allocator's incompatible final
request, an altered prepared page, a changed reference and an omitted
actual upper coupling. The inherited theorem is not proved by these finite
checks, and this is AI-assisted review rather than human or kernel acceptance.
