The new history theorem is relevant because physical free-slot names enter

per-role historical backing. No host queue sorting/reset is an implementation.

There is a further source fact needed to make the result useful: **successful

Therefore changed-core payloads do not themselves prevent native action
cancellation. Their mathematical endpoint correctness remains #4166's separate

inherited admission and on the history theorem's proved boundary, not on a
new assumption that two unrelated upper bounds are equal.

## Payload-oblivious action proof

Partition runtime information into (i) descriptor/address/control words and
(ii) fixed-width coefficient payload bits. Compare two successful admitted
executions with identical type-(i) information and possibly different type-(ii)
bits. Relate each live role by its logical purpose, equal length and equal head;
payload bodies may differ. Native arena roles use the history theorem's slot
relation. The following source cases preserve this relation and equal R/W/M:

1. `machine.py` selects node/leaf, source events, groups, owners, recipes,
   target/rank and descendants from encoded descriptors and finite bindings.
   `shape`, `prepare_child`, Count arithmetic and header production do not
   inspect coefficient values. `copy_symbols`, transfer, clear, bank gather
   and scatter stop at structural BLANK boundaries and copy bits opaquely.
   All complete packet lengths are fixed by the shared descriptors.
2. `signed_linear.linear_word` executes one fixed-width iteration per component
   bit. Carries and emitted digits may differ but source read/step and target
   append schedules do not. The payload-dependent parity/headroom branches
   reject; on the successful domain both comparisons continue along the same
   tape-action schedule. Extension loops have fixed lengths. The same holds
   for `scalar_words.shifted`, zero/copy and restoration checks. A failed
   numerical admission is outside this successful-execution theorem.
3. `signed_phase.scan` computes the unit phase from `plan.decode(index)`, the
   finite recipe and descriptors. It does **not** compute phase from payload.
   Real/imaginary choices and negation directions consequently agree. Every
   component is read and emitted at its fixed width. The minimum-negative
   rejection can vary in truth only outside the paired successful domain.
4. `compact_streams.rotate`, digit gates and `repair` route records by encoded
   coordinate states. Exceptional flags, hole bits and stable-radix keys are
   produced from the loop index and `Control` arithmetic. They are not payload
   bit predicates. Thus data-dependent-looking key branches have identical
   keys, lengths and routes in the comparison; record contents remain opaque.
5. Binary padding/restriction and Ordinary's fitted/fallback selection use
   descriptor widths. Native `stream.copy_blocks`, `bitstream` and the outer
   ordinary wrapper copy payload bits without using them to select addresses
   or arithmetic branches. Numerical Ring values in these routines are
   address/loop/coefficient words derived from descriptors and finite source
   constants. They are not decoded coefficient-payload values. The native
   dispatcher and parked directory refine the same address operation word;
   allocation/slot-codec effects are the separate history theorem.
6. Successful return restores borrowed bytes and heads and clears the same
   structural extents. Recursion is well-founded under the inherited source
   contraction/stock theorem. Induct on the completed C call tree: related
   child descriptors and fixed source bindings give equal successful action
   counts, including descendants once. Marker and root-context differences
   must be kept explicitly; the claim does not identify embedded and external
   contexts.

No argument above equates Python wall time or arbitrary finite-control cost.
Carry branches, short-circuit predicates and finite slot selectors may have
separate compiler charges. Source R/W/M equality follows because their payload
branches perform the same measured tape operations on the successful domain.
The read-only structural controls in `comparison.check_sources` are regression
checks, not a substitute for this source-case proof.

For the actual complex construction, `CompactEngine.__init__` closes its fresh
Ordinary with `native.finish(False)` and erases its output marker. Its first
call therefore already enters the successful closed interface required by the
history theorem. Direct standalone fresh `Ordinary` and warm `Ordinary` still
have different entry rearm work. Controller first-use/marker corrections, if
using a steady-state child price, belong in the explicit startup term; the
allocator theorem is not permission to omit them.

## Actual Ordinary invocation sites and fitted branch

The original scalar and Gaussian leaf engines make no Ordinary invocation.
The path is `MonomialEngine.compact_gate -> CompactEngine.complete_row ->
swap -> Binary.run -> Ordinary.run`. For a monomial with `f` columns,
`r` actual outer rows and an affine recipe containing `e` early/constant gates
and `l` late gates, the exact number of Ordinary invocations is

    J(f,r,e,l) = 0                         if f=1,
                r (4e+12l)                if f>1.

The reference Compact word emits four swaps for an early/constant gate and
twelve for a late gate. For f>1 all swap fields have width `(f-1)G>0`.
For f=1 the monomial uses `single_column_rows`, bypassing Compact entirely.
`Compact.calls['ordinary']` counts attempted Binary swaps, including width-zero
ones in other scopes; it is not an unconditional Ordinary-call census.

Binary computes `d_q = min {d : q^d >= 2^((f-1)G)}` through encoded operations.
Ordinary's `select(d_q,q,profile)` determines fitted/fallback by its encoded
atom width, borrowed row stock and body tests. A q=2 or f=1 fixture cannot be
called fitted evidence merely because it uses the same class names. The
package's separate fixture records actual branch and completed fitted roots.

A reset policy, if later proposed, must sum J over **every** monomial in root,
service and all C descendants, adding exact first-use policies and costs. Root
callback multiplicities510662/511014 are not this sum. The present route adds
no reset and no per-invocation reset cost.

experiment from tracking hundreds of thousands of unrelated engine histories

new/removed nonchild word at one admitted reduced geometry, checked against
actual executions and then generalized only where the source recurrence
