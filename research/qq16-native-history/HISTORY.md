# Reachable native histories and the fitted discriminator

The retained implementation is Jose Manuel's PR2899 `Ordinary`, `PhysicalArena`,
`RootSession` and `BankParking`, reached through the unchanged #4167 authenticated
source closure. `runtime.cold()` verifies the retained archives and canonical
inputs before `fitted_fixture` imports the source's fixture compiler. No queue is
assigned, permuted or sorted to manufacture either execution history.

## Exact reduced admission

`check_engine.fixture_engine()` compiles the source's declared two-dimensional
nested toy grammar with radix 2, register capacity 128 and the explicitly
fixture-only index floor 64. The fitted plan is the original source plan:

| Field | Value |
|---|---:|
| Original radix width | 5 |
| Atom width | 1 |
| Depth | 1 |
| Required stock | 6 |
| High rows | 8 |
| Borrowed digit count | 3 |
| Body rank | 2 |
| Remainder | 0 |
| Prefix / gap / suffix | 1 / 1 / 1 |
| Original packet | 1,024 bits |
| Each of two padded native roots | 1,536 bits |

The public source `execute_plan` hook supports declared small grammars. It calls
actual `Ordinary.fitted`, including both actual physical `RootSession.run` calls,
the physical numerical implementation, wrapper return and disposal. This smallest
fitted case has native child-call count zero: its body rank 2 produces children
below the declared cutoff. Actual bank-codec frames and nested parking are tested
separately by the mechanism evidence; they are not claimed from this fixture.
It does not call the elementary branch and does not replace the endpoint with a
double. This is **not** admission under the default production `select` profile,
the selected large-prime catalogue, or a production O73 payload. The quantified
context theorem has its own source argument; these finite executions test the
same relevant machinery at reduced admitted geometry.

The nonconstant packet uses address-dependent bits, including multiple address
shifts. The fixture checks every returned bit against the independent explicit
interchange permutation and checks both padded native endpoints. Payload and
all four encoded descriptors retain their bytes and heads. `last_fitted` and the
two actual observer callbacks provide branch receipts. The initial independent
source replay additionally checked all 1,024 input-column provenance masks;
that expensive oracle is not repeated by the registered discriminator.

## Legal warm histories

The left engine completes the source fallback for width 1, consumes its protected
output, then executes the fitted target. The right engine completes width 2 with
a nontrivial gap, executes a fitted call on a different nonconstant packet,
consumes its output, completes another fallback with nontrivial prefix and
suffix, then executes exactly the left target payload and descriptors. Thus the
right stream is fitted/fallback/fitted and its native register queues were changed
by a successful genuine fitted invocation. Both target entries are warm closed
boundaries, avoiding a cold-versus-rearm comparison.

The first, cheaper experiment used only the two different fallback histories.
They produced distinct `banks[0].available` orders and equal fitted action triples
`(79543744, 23380814, 82873286)`. That result did not test different native
`runtime.arena`/`runtime.indices` histories and is not substituted for the stronger
registered experiment. The registered test explicitly rejects a pair unless at
least one of these runtime queues differs at target entry.

## Observations and charge boundary

`state_model.snapshot` records all four outer arenas and the two runtime arenas:
free order, live slots, initialized flag, each stable slot identifier, template,
heads, meaningful content and per-role retained backing. It also records both
scratch lease inventories, outer scope state, output, dictionary-codec state,
heads and symbols. The fixture observes real numerical allocations and the first
two completed parking frames, including their encoded slot fields when frames occur. The fitted rank-2
case records an empty frame list rather than implying that it parked a child. Host snapshots,
digests and allocation observers are checker tools; none is a reset, predicate or
free operation in the proposed machine construction.

The measured interval begins immediately before `Ordinary.execute_plan` or
`Ordinary.run` and ends at its successful protected-output return. It includes
rearm, plan construction, numerical templates, both fitted roots, all descendants,
wrapper transfer and successful engine cleanup. Input/descriptor loading is
outside both matched calls. Post-return test consumption and borrowed-fixture
retirement are outside the interval. Every preallocated source `Tape` is counted
once, including all numerical roles. Both the dictionary codec's direct counters
and its interpreter counters are also counted once. Arena aggregate counters are
not added again to their underlying tapes. No elapsed-time result is treated as
an action theorem.

The independently written lifecycle guard validates each consumed return and
checks per-slot historical backing monotonicity. It does not infer absence of
escaped Python references: sole ownership and no escaped numerical residents are
explicit caller obligations. Physical `Word` handles lack a generation check;
the stronger `ScratchPool.Lease` guarantee must not be imported into that API.

Finite equality is reported as observed equality only. It proves neither full
history independence nor payload obliviousness. The source theorem and whole-root
comparison must supply those claims separately.

## Open next questions

The default selected catalogue and large-prime admission remain inherited. A
production-parameter execution is not claimed. If a future codec uses variable
slot widths, slot-dependent movement or data-dependent scan lengths, this fixture
must be supplemented and the context theorem rederived before reuse.

The stronger completed-history discriminator returned the same action triple for
both identical target inputs and for the different nonconstant fitted payload.
Five queues differed at the identical-target entries: `banks[0]`, `banks[1]`,
`banks[3]`, `runtime.arena` and `runtime.indices`. `banks[2]` remained unused because
this source plan has zero remainder; it was still inventoried and checked. Runtime
residue and index allocations numbered 253,608 and 27,560 respectively in each
fitted invocation. These are observation counts, not added action charges.

## Separate reached native recursive call

`native_nested.run_cut()` uses the original source `ToyBinding`, mode-1 root
coordinate projectors and mode-0 children at width 4, 36 root rows and 9,216
nonconstant bits. It reaches the first actual `Machine.call`, executes the
width-2 child, and checks its complete reversed-interchange endpoint from the
observed encoded shape. The actual parent PC advances 3 to 4. All saved numerical
objects return at their original physical slots with their bytes and heads;
all parked parent stream roles other than the changed current result and cleared
header are restored. The outer borrowed input survives.

This cut performed one child call and one return, 13 residuals and 486 completed
macros. The actual parent frame contained 123,520 dictionary-codec symbols;
62 codec commands were executed. Reads/writes/unit moves through the returned
cut were `(41224159, 12308582, 42422092)`. An explicit disposal at this successful
primitive boundary uses source `close_frame`, `RootSession.finish(0)` and owned
marker erasure. Its separate observed invoice is `(83113, 41365, 83170)`.
The check requires every engine tape to be blank with head one afterward.
This disposal is **not** completion of the remaining parent root program and is
not a theorem about arbitrary interrupted macros. The other eleven root calls
are not executed by this bounded test. The independent child-endpoint and all-role
retirement guards are part of the final registered replay.

The fitted payload recipe is
`((address*13) ^ (address>>3) ^ (address>>7) ^ seed) & 1`.
It varies with address and hence with the row/field decomposition. Changing the
seed in this recipe changes only its low bit; the distinct fitted payload control
is therefore a nonconstant complement, not an independent arbitrary-data family.
Neither this control nor the nested fixture enlarges the quantified domain by
itself. The source proof carries any arbitrary successful-payload quantifier.

Dictionary-codec current blankness is kept separate from historical backing.
The final fixture continuously observes both direct codec head moves and the
literal two-tape interpreter steps from the first invocation, retains per-tape
minimum and maximum visited positions across generations, and includes those
bounds in its snapshots. These observations do not reclaim storage after erasure
and do not add host memory as a claimed machine action.
