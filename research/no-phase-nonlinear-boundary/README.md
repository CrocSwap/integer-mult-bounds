# The exact nonlinear boundary of the abelian no-phase reduction

This contribution was produced by Nick Petalas. Apache-2.0.

**Scoped proof with finite corroboration. No new κ.** Let `V = C^(F_2^m)`,
`m >= 1`, and let `X_v e_x = e_(x+v)`. Put

```
a = (1+i)/2, b = (1-i)/2, C_v = a I + b X_v,
A = the group generated by the C_v for v != 0.
```

For an address permutation `p`, write `P e_x = e_p(x)`. Then

```
P A P^-1 = A  if and only if  p(x) = Mx + t for some invertible binary M.
```

Moreover, if `p` is nonlinear, **no abelian group containing `A` is normalized
by `P`**. Thus enlarging the abelian call group cannot extend the same
semidirect-product reduction to a nonlinear address permutation. Even the subgroup generated by `A` and `P A P^-1` is already nonabelian.

The exhaustive three-bit census accepts exactly 1,344 of 40,320 permutations.
It supplies a noncommutation witness for each of the other 38,976. Three bits
is the first dimension with a nonlinear permutation: all two one-bit and all
24 two-bit permutations are affine. The written theorem covers every `m`;
the census covers only `m = 1,2,3`.

## Proof

### 1. The call group contains all translations and lies in the convolution algebra

Since `a^2+b^2=0` and `2ab=1`,

```
C_v^2 = X_v,   C_v^4 = I.
```

Every `C_v` is a polynomial in translations, so these calls commute and
`A` is abelian. In particular, `A` contains the translation group
`T = {X_v : v in F_2^m}` and lies in its convolution algebra

```
L = { sum_v k_v X_v : k_v in C }.
```

If an element of `L` is a literal permutation matrix, it is a translation.
Indeed, its column at `y` is the translate by `y` of its column at zero.
The latter must have exactly one coefficient equal to one and all others
zero. Therefore

```
L intersect {address permutation matrices} = T,
and consequently A intersect {address permutation matrices} = T.
```

### 2. Normalizing the call group forces an affine permutation

Suppose `P A P^-1 = A`. Every `P X_v P^-1` is both a permutation matrix and
an element of `A`, hence is a translation `X_phi(v)`. This defines an
invertible additive map `phi` on `F_2^m`, because conjugation preserves
products and is injective on `T`. Thus `phi(v)=Mv` for some invertible binary
matrix `M`. Evaluating `P X_v P^-1 = X_(Mv)` at the address `p(0)` gives

```
p(v) = p(0) + Mv.
```

Conversely, if `p(x)=Mx+t`, then `P X_v P^-1=X_(Mv)` and
`P C_v P^-1=C_(Mv)`. The nonzero directions are permuted bijectively, so
`P A P^-1=A`. This proves both directions.

Translations themselves are already free elements of `A`. An affine map is
`X_t` followed by its linear map. The existing linear-map reduction can
therefore absorb its translation part without a new call group.

### 3. An abelian enlargement cannot repair a nonlinear permutation

Let `B` be an abelian group of invertible operators with `A <= B` and
`P B P^-1=B`. For every `v`, set `Q_v=P X_v P^-1`. Then `Q_v` belongs to
`B` and commutes with every translation, since `T <= A <= B`.

A permutation `q` commuting with every translation satisfies
`q(x+v)=q(x)+v`. Taking `x=0` proves `q(v)=q(0)+v`, so it is itself a
translation. Applying this to every `Q_v` makes `P` normalize `T`, and the
argument in section 2 makes `p` affine. This contradicts nonlinearity.

Equivalently, for every nonlinear `p`, there are `v,w` with

```
[P X_v P^-1, X_w] != I.
```

The same obstruction is present among the call roots. If
`P C_v P^-1` and `C_w` commuted, their squares would commute; those squares
are exactly the two displayed translations. This also proves that
`<A, P A P^-1>` is nonabelian. No assumption about how a proposed larger
abelian group is represented was used.

### 4. The first nonlinear witness

Use three-bit addresses `(x0,x1,x2)` and the Toffoli permutation

```
p(x0,x1,x2) = (x0,x1,x2+x0*x1).
```

It is an involution. With `Q=P X_e0 P^-1`, direct substitution gives

```
Q(x0,x1,x2) = (x0+1,x1,x2+x1),
Q X_e1 Q^-1 X_e1^-1 = X_e2 != I.
```

The verifier checks this as a permutation identity. Separately it constructs
`2 C_v` as eight-by-eight Gaussian-integer matrices, checks all seven
identities `(2 C_v)^2=4 X_v`, and verifies that the literal matrices
`P C_e0 P^-1` and `C_e1` do not commute.

The obstruction persists under tensor powers of these permutation operators:
a nontrivial permutation remains nontrivial on any positive tensor power.
The theorem already concerns the one-column group required by the cited
reduction. No inference from a finite-width test to a full multiplication
algorithm is made.

## Verification design

All enumeration is bounded by the three-bit domain: at most 40,320
permutations, seven directions, three basis shifts and eight addresses per
witness search. Affine generation stores at most 1,344 eight-entry tuples.
Matrices have eight rows and columns. Functions are below 60 physical lines;
there is no recursion, generated code or external mathematical dependency.

Python's managed allocation is a deviation from literal allocation-free
operation. Its scope is this finite verifier; fixed domain bounds limit live
collections, and permutations are streamed. The file-hash report reads only
the five fixed package files, whose sizes are fixed by the committed artifact.
The normal/optimized registered runs with warnings treated as errors are the
diagnostics. No separate static type checker is a declared dependency.
