# Prove a scoped P104 event-attribution criterion and exhibit a strict separator

Central multi-stage projectors give global mask attribution. A non-tight n8/k6 Q=0 word with six HOSTs separates local from global strict attribution.

The separator has all local strict matchings, a global mask match, and no global strict match in five exhaustive cases.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.
