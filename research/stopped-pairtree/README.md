## Reproduce

Requires Python 3.11 or newer and a C++17 compiler. All Python checks use the
standard library.

```sh
python3 research/stopped-pairtree/verify.py
```

The default verifier checks all source pins and writes only temporary files.
`--record` additionally writes `verification.log` and `validation.json`, never
mathematical inputs. `CXX` can select a compatible compiler.

The gate regenerates the original PR104 and PR107 complex producers and
their exact certificates, then generates the new graph and every selected
carrier edge. It checks the original matching diagnostic and reproduces the
selected integer-weighted matching byte for byte. The unchanged coarse h23
bit producer and ordinary leaf are inherited, source-pinned inputs; their
rank/exponent moments, stopping calculation and row stock are rechecked.

An independent parser verifies **all 4,096,576 signed scalar coefficients**,
all actual binary frame Gram ranks and inclusions, and **all 7,194 matching
edges**, including order, unchanged operands and uniqueness. The literal
program audit checks the corresponding role operations and frame paths.
Separate finite matrix/atom-ring/wrapper controls check the new interface's
algebra. The paid recurrence, exact moments, adjacent-grid exclusions,
three-factor bridge, 47 inequalities and seven margins have independent
arithmetic checks and ten corruption controls.
