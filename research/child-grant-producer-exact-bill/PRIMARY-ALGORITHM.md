# Sparse interpreter plan and independence boundary

Status: code written, not executed, imported, compiled or scientifically
trialled by its author. Root alone seals and schedules the first run. No oracle
code, data or outputs were read. Three frozen metadata hashes are literal code
constants; the complete thirteen-file core manifest must authenticate before
the shared emitter is imported. Source programs and original notices remain
byte-identical inputs.

The emitter is the shared candidate constructor. It authenticates the four
original modules and invokes only the exact full `producer.build(L)` for the
four frozen templates. This is not independent construction. The primary
execution method is independently authored sparse dictionaries, with absent
coordinates representing BLANK and explicit integer heads on nine tapes. It
does not execute source Machine/Tape, router build, linked_split, delivered
consumer, codec or predecessor checker suites.

Every finite instruction row is structurally checked, including strict integer
tape/symbol/PC fields, branch uniqueness, unit moves and successor bounds.
Dispatch charges one step for branch/write/move/goto/reject/HALT; a successful
HALT is included. Each tape's visit set starts at its initial head. Branch and
write add the current head; moves add both endpoints. Space is the sum of the
nine distinct visited-coordinate counts, never the number of nonblank cells.
Sentinel cells do not inflate visited space unless actually reached.

The fixture encodes A,H,R as positive canonical LSB-first packets with LEFT0
and RIGHT after the highest ONE, on tapes0,1,2 with heads1. Six owned tapes
start blank at0 with heads0. All nine carry MARK at-1 and UNIT at8192. No runtime
division/multiplication supplies output grants: host q=A/(L*H) and K=H*R are
endpoint expectations used only after actual literal execution.

For each of261 frozen valid cases, the engine checks complete input cells and
heads, complete canonical quotient/product outputs and heads1, and complete
scratch5..8 maps equal to their untouched guards with heads0. Thus any scratch
marker, overlooked remote write, input damage or guard change fails. It records
all heads, visited min/max/count triples, steps and the SHA256 of the complete
canonical nine-tape endpoint. Endpoint hash input is nine objects containing
each head and its sorted nonblank coordinate/symbol pairs, without a terminal
newline. Actual table hashes likewise use compact sorted-key ASCII JSON.

Primary also checks each actual step count against the independently supplied
written accounting expression:

    c(A)+c(H)+c(R)+C(q)+C(K)+12A+11H+R+6K+4qL+2q+46,
    c(x)=24x-7 popcount(x)+15 bit_length(x)+12,
    C(x)=13x-7 popcount(x)+5 bit_length(x).

This exact-expression test is additional primary evidence; it is not the
independence claim or a formula inferred from test rows. Actual steps must also
obey60(A+H+R+K), and actual visited space10(A+H+R+K). The common small witness
is actual L2,A2,H1,R1 producing1,1 in291 charged steps and30 visited cells.
These are predeclared expected checks, not results until root executes.

Ten controls execute the same engine or strict parser. Four actual emitted
table mutations change the first quotient ONE write to ZERO, first product ONE
write to ZERO, final WORK BLANK write to LEFT and final input-A positive return
move to a negative move. They must finish and fail the intended output, scratch
or input endpoint test. Three malformed raw fixtures—nondivisible A, a padded
high ZERO and occupied WORK origin—execute without a host-domain precheck and
must reach a dedicated source reject row with its exact expected reason.
No rollback on rejected inputs is promised. Duplicate JSON keys, float/nonfinite
tokens and Boolean proof integers are specifically rejected. Controls do not
count arbitrary exceptions as success.

Normal default mode regenerates the entire actual certificate and compares all
canonical fields of retained CERTIFICATE.json; --certificate PATH exercises an
actual alternate retained packet. --emit PATH explicitly writes the complete
regenerated packet. Incoming packets have strict exact schemas, integer types,
case order, table rows, SHA256 forms, bounds, witness fields and Boolean control
types before whole comparison. There are no assert-based acceptance gates, so
optimized mode preserves every check.

Forecast: under180 seconds and128MiB per complete execution on managed Python
3.12, not measured yet. The case grid and boundary fixtures are immutable. A
one-million-step per-case safety cap bounds an accidental corrupt-table loop.
First failures, if any, remain preserved; no post-first adjustment is implicit.
