# Mixed targets need only finitely many dirty registers

A successful `k`-call word in the formal abelian bit model can be restricted to
at most `k-d+s` scalar roles, where `d` is the rational span dimension of its
paid frames and `s` is that of its target frames. The restriction preserves
every paid frame, call order, rank-one scalar idempotence and diagonal target.
It retains arbitrary dirty inputs on the remaining extra roles.

For three arbitrary invertible rational 3-by-3 targets in eight calls,
**at most four dirty roles suffice**. More precisely:

| Paid-frame span `d` | Maximum total roles | Maximum dirty roles |
|---:|---:|---:|
| 4 | 7 | 4 |
| 5 | 6 | 3 |
| 6 | 5 | 2 |

The other span dimensions are excluded by the retained low-span and
at-most-one-relation results. Thus searching unbounded dirty workspace is
unnecessary for this specific eight-call question. This does not produce a
successful word or rule one out. No supplier, physical storage saving or new
kappa is claimed.

## Proof

Work over `F2[H]`, where `H` is the subgroup generated by the finitely many
nonzero rational paid frames `A_j`. Every frame has rational rank one. A paid
factor is `I + ([A_j]-1)N_j`, with `N_j` a binary rank-one idempotent on `R`
scalar roles. Assume the full formal endpoint is
`diag([C_1],...,[C_W],1,...,1)`, with all `C_i != 0`. Equality includes every
input column, so the extra roles are dirty and restored, not clean ancillas.
Free scalar basis changes are allowed; arbitrary free address maps are not.

### The scalar span bound

The group `H` is free abelian of rank `d = dim_Q span{A_j}`. Each nonzero
endpoint coefficient occurs at a subset sum, so every `C_i` belongs to `H`.
Let `V = H/2H`, let `a_j` and `c_i` denote the corresponding classes, and set
`q = dim_F2 span{c_i}`. First-order augmentation gives

```text
sum_j a_j tensor N_j = sum_i c_i tensor E_ii.
```

The `a_j` span the `d`-dimensional binary space `V`. Every functional on `V`
annihilating all `c_i` therefore supplies a relation among the `N_j`, and the
map from such functionals into `F2^k` is injective. There are `d-q` independent
relations. Consequently

```text
dim_F2 S <= k-d+q,   where S = span_F2{N_j}.
```

This generalizes the identical-target tensor step in Tuafo's retained
[proof, section 4](../bit-identical-three-targets-dirty/PROOF.md).
It uses the actual generated lattice `H`. Reducing rational matrix entries
modulo two would be invalid, including for half-integral frames.

For a lattice-free upper bound, put `K = sum_i Z C_i`. It is a free subgroup
of rank `s = dim_Q span{C_i}`. The map `K -> H/2H` factors through `K/2K`,
so `q <= s`. This remains true when some target classes vanish or when
`K` is not saturated in `H`. Hence `dim S <= k-d+s`.

### Constructive restriction

Choose a basis of `S` from actual paid projectors. Each basis projector has a
one-dimensional image. The space `U = sum_j im(N_j)` is spanned by these
basis images, so

```text
dim U <= dim S <= k-d+q <= k-d+s.
```

Every `N_j` maps the entire register space into `U`, making `U` invariant.
The image of every coefficient of product-minus-identity lies in `U`.
For each distinct nonzero target frame `C`, the coefficient at `[C]` is the
coordinate projector onto all roles with that frame. Therefore `U` contains
the full `W`-dimensional active coordinate space, even when targets coincide.

Let `D` be the original dirty coordinate space. Because `U` contains all active
coordinate axes, it splits as their direct sum with `U intersect D`. Start a
basis with the active axes, then append a basis of `U intersect D`. This detail
matters: an arbitrary complement can mix active and dirty coordinates and
need not leave the restricted endpoint diagonal.

Restrict each `N_j` to `U`. It remains rank one and idempotent. Its nonzero
image vector belongs to `U` and is fixed by `N_j`, so its rank cannot vanish
on restriction. Restriction commutes with multiplication on an invariant
space, proving equality of every formal coefficient of the reduced word.
The endpoint is the same active diagonal target and identity on the appended
dirty basis vectors. No paid address or call is added or removed.

This is an existence-preserving restriction of the word, not a claim that
each original gate equals the reduced gate direct-summed with identity.
Original intermediate gates can read discarded dirt. Full dirty restoration
is required at the endpoint before the reduction applies.

### Eight-call application

For `m=3`, `W=3`, `k=8`, the target-frame span satisfies `s <= 3`. The retained
[low-span argument](../bit-dirty-auxiliary-registers/README.md#3-low-span-for-any-register-count)
excludes `d <= 3`. The retained arbitrary-register
[one-relation theorem](../bit-dirty-auxiliary-registers/README.md#2-disjoint-subsets-with-at-most-one-relation-for-any-register-count)
excludes `d >= 7`. For the remaining `d=4,5,6`, the bound `R <= 11-d` gives
the table above. These inputs are cited, not independently reproved by the
finite replay here. Padding a shorter positive-length word by splitting a
nonzero frame into two half frames reduces a shorter-word existence question
to eight calls without changing its target or rational frame span.

## Evidence and reproduction

```sh
python3.12 -I -B scripts/research_package.py --package research/bit-mixed-target-register-compression
python3 -I -O -B research/bit-mixed-target-register-compression/verify.py
```

The constructive checker computes the actual image space, a basis adapted to
the active and dirty coordinates, and every restricted projector. It compares
the full formal endpoints using exact rational address tuples. A separately
implemented vector-propagation oracle checks every original input column and
every restricted basis column; it does not multiply formal matrices.

Six fixtures include different invertible 3-by-3 targets, half-integral paid
frames, dependent projectors, cancelling dirty calls that mix active and dirty
coordinates, target classes that vanish in `H/2H`, and the empty word. A
noncommuting roundtrip also reads dirt outside the restricted image space,
then restores every input column. One fixture attains `dim U = k-d+s = 6`
with three rank-one targets and three dirty roles. It is **not** an eight-call
full-rank construction. `RESULT.json` stores
the constructive bases and reduced projectors, not only counts.

The replay also checks every word of length at most three on two roles and
at most two on three roles, using respectively six and 28 scalar idempotents
and the two rational addresses `E11` and `E11/2`. Every diagonal-monomial
endpoint is compressed and compared with the vector oracle. Ten rejection
controls cover invalid calls, off-diagonal endpoints, a noninvariant space,
dependent basis vectors and dimension limits. The separate behavioral tests
exercise relocated normal and optimized execution and corrupt actual receipts.
Checks do not use Python assertions or floating point.

The universal statement is a written linear-algebra proof, not an inference
from these bounded fixtures. No formal proof kernel, complete predecessor
computer-assisted replay, native compiler, hosting, precision/tape, all-size
supplier or multiplication-theorem check is supplied.

## Open next questions

Can three different invertible targets use eight calls in any of the reduced
`d=4,5,6` domains? A first step is to choose one exact frame multiset and
relation lattice, pass the existing rational rank-cut and determinant screens,
then search its bounded scalar-role domain. The remaining obstacle is the
formal endpoint identity and a favorable complete native bill, not unbounded
dirty register count. This package does not justify a larger search before
that budget and candidate screen.

## Implementation limits

The checker is a bounded research verifier, not an untrusted-input service.
Fixtures have at most 12 roles and 12 calls, at most 4096 address subset sums,
and at most 4096 binary coordinates. Census alphabets and horizons are fixed.
There is no recursion, external process, network access or inherited-code
execution in `verify.py`. Python runtime allocation is a Power of Ten rule 3
deviation; live collections are bounded by these enforced dimensions. Static
checks and behavioral replay constrain that deviation. Revisit capacity limits
before exposing arbitrary external fixture input, rather than expanding them
silently. Tests and rejection controls use bounded callback dispatch, a rule 9
deviation with fixed local targets. The tests also use one local Python
subprocess target with explicit timeouts and temporary-directory cleanup.
