# A full-address trace obstruction at every residual phase cut

This is a source-bound finite operator result and a written conjugacy argument.
It is conditional on the inherited completed-child eight-stream projection.
It is not a full native supplier verification or a new multiplication exponent.

## 1. The mechanism and its favorable recursive budget

Fix the retained PR3148 T740 allocation, owner replica zero and port zero.
Let `N=2^73`. The eight data streams are arbitrary complex vectors of length N.
Move the binary axis 16 from residual child 10 to child 12, changing their ranks
`48,48 -> 47,49`. Every hosted prefix, other residual, interaction, separate
translation, call order, target and normalization stays fixed.

For `p=1-a` and `0<a<1`, strict concavity gives

```
(47/73)^p + (49/73)^p < 2(48/73)^p.
```

The residual rank mass remains96. Holding the complete remaining invoice and
stock fixed therefore gives a favorable recursive-child direction. The question
is whether replacing one already scheduled residual phase can absorb the changed
operator, avoiding an extra repair child. No paid implementation of that repair
is assumed. The screen grants its chart, inverse, source access, frame/routing,
movement, precision, helper/stock and restoration costs zero. A passing screen
would still need those charges and a legal implementation.

PR3275 excludes reciprocal charts preserving each Fourier character, even with
an arbitrary middle eigenvalue function. Here the charts may mix **all addresses
and streams**, while the middle operation is an actual pure native tensor phase.
These two domains are incomparable: this proof does not keep the predecessor's
arbitrary middle phase function. In particular, the original separate
`translation_after` events remain outside the replacement and fixed.

## 2. Complete replacement contract

At one of the twenty residual cuts, write the altered surrounding word as
`W=B_j G_j A_j`, in first-applied-right convention. The exact unchanged target is
`T(x)=i^popcount(x) I_8` in Fourier coordinates. Any required replacement is
uniquely

```
R_j = B_j^-1 T A_j^-1.
```

Let `C=((1+i)I+(1-i)X)/2`, where X exchanges the two binary coordinates.
Then C has eigenvalues1,i, `C^2=X`, and `C^4=I`. A rank-r native phase on one
length-N stream is, up to its coordinate basis,

```
Q_r = C^tensor r tensor I_(N/2^r),      0 <= r <= 73,
Q_0 = I_N.
```

Grant **any** rank in this range, either orientation epsilon=+1/-1 and **any
nonzero scalar** lambda, rather than just the site's charged native rank and
fourth-root phase. Also grant any number d of arbitrary dirty spectator
coordinates, all required to be restored. The proposed identity is

```
R_j direct_sum I_d = E^-1 D E,
D = I_(7N+d) direct_sum (lambda Q_r^epsilon),
E in GL_(8N+d)(K),
```

over any characteristic-zero coefficient field K containing i. E may mix
streams, addresses, different Fourier characters and the dirty spectators. It
need not be unitary, monomial or local. Every entrance coordinate is independent;
there is no clean subspace promise or allowed spectator garbage. The active
child still acts on exactly N coordinates: enlarging its active volume changes
this contract and its cost.

## 3. Necessary trace identities

For every r>0,

```
tr(Q_r^2) = tr(X^tensor r) * (N/2^r) = 0,
tr((Q_r^-1)^2) = 0.
```

Equivalently, in the Fourier basis its square is the sign of a nonzero binary
character, whose complete sum is zero. This is independent of the native axes
as long as the r axes are independent. Hence **every positive-rank candidate**,
with any nonzero lambda and either direction, has

```
tr(D^2) = 7N+d.
```

For r=0, put `t1=tr(R_j)` and `t2=tr(R_j^2)`. Similarity would force

```
t1 = 7N + lambda N,
t2 = 7N + lambda^2 N,
(t1-7N)^2 = N(t2-7N).
```

The d spectator identities have cancelled from both equations. This r=0 case
is essential: a phase i on an identity stream has squared trace6N, so squared
trace alone would leave that loophole. Similarity preserves both traces even
when E mixes all Fourier characters.

## 4. Exact full-address traces of the required cuts

Let `gamma=2^-24`. The literal cut calculation gives:

| Residual sites | Count | tr(R_j)/N | tr(R_j^2)/N |
|---|---:|---:|---:|
| 0,1,2,3,5,7,9,11,16,17,18,19 | 12 | 7 | 6 |
| 4,6,14,15 | 4 | (13+i)/2 | 5 |
| 8,13 | 2 | 6+gamma | 5 |
| 10 | 1 | 13/2+gamma-i/2 | 6 |
| 12 | 1 | 13/2+gamma+i/2 | 6 |

Thus no positive rank can work at any site: neither5N nor6N equals7N.
For rank0, the normalized discrepancy
`g_j=(t1/N-7)^2-(t2/N-7)` is respectively

```
1;
2-i/2;
2+(gamma-1)^2;
1+gamma^2-gamma+i(1/2-gamma);
1+gamma^2-gamma-i(1/2-gamma).
```

Every one is nonzero. This excludes a rank-zero scalar at every site too,
including an arbitrary nonzero scalar rather than only the four unit phases.
Consequently **no one of the twenty cuts admits the displayed replacement**,
for any r, epsilon, lambda, d or E in the stated domain.

### Why these are complete address sums

The program has 141 elementary phases/shears/signed exchanges. Each scalar matrix
entry is represented as an integer combination of functions `i^q(x)`, where

```
q(x) = sum_i a_i x_i + 2 sum_(i<k) b_ik x_i x_k  (mod4),
a_i in Z/4, b_ik in F2.
```

For a binary mask v,
`parity(v.x) = sum_(i in v) x_i - 2 sum_(i<k in v) x_i x_k (mod4)`.
This identity is exact: every higher multilinear coefficient is divisible by4.
It transcribes every native phase, including separate translations, without
sampling addresses. The unchanged complete baseline reduces formally to T on
all eight columns for every one of the 2^73 characters.

The cut computation starts with `W^-1 T` and conjugates it by each successive
prefix A. At the literal phase gate g it records

```
g A W^-1 T A^-1 = B^-1 T A^-1.
```

This uses the target's scalar form in each character and retains the full
chronological inverses. It is an equality of the actual symbolic matrices,
not an inference from ranks. The resulting matrices have 8–12 phase terms;
their squared traces each have only 2–3 terms. In fact every nonconstant
squared-trace term is a nonzero ordinary signed binary character, so its sum
is zero and the constant coefficients5/6 give the second column directly.

For the first traces, the primary checker exactly sums quadratic phases by
one-variable and paired-variable elimination. When a variable has odd linear
coefficient alpha, summing it multiplies by `1+i^alpha` and adds
`-alpha*parity(neighbors.x)` to the remaining phase. With only even coefficients,
eliminating a pair with a nonzero quadratic edge gives
`sum_(u,v) (-1)^(uv+uA+vB)=2(-1)^(AB)`. Isolated even variables give zero or two.
These identities evaluate a finite complete sum; they do not extrapolate from
small dimensions. RESULT.json retains each phase, coefficient and exact sum.

The independent checker uses separately transcribed Gaussian-integer events,
cut inverses and phase representation. It also factors the small interaction
components and sums those components directly, independently of elimination.
The primary makes 200 finite cut comparisons against the authenticated canonical
interpreter: all eight input columns at all twenty cuts and ten characters.
The independent checker instead compares its own numeric and symbolic cuts at
those ten characters, checks complete symbolic cut completion and the baseline,
and imports no canonical operator routine. These finite checks test transcription;
the all-address trace result comes from the symbolic sums.

## 5. Scope controls and boundaries

Each checker accepts its own legal permutation conjugacy mixing different
characters. The primary checks all 32 columns of a native C1 on a four-address
stream among eight streams; the independent checker checks all eight columns
of a two-stream, four-address native C2 fixture. Each has a required fiber with
a rank-two defect, so the controls prevent silently reimposing PR3275's
character-preserving condition. Exact quadratic-sum controls cover all 549
forms through three variables, and 15 nonzero four-bit parity forms.

An address-dependent monomial **iZ_v** on one active stream has trace0 and
square trace -N, for nonzero v. With seven identity streams its trace pair is
`(7N,6N)`, the first row's pair above. It is **outside** the pure
`lambda Q_r^epsilon` alphabet. That spectral compatibility is a boundary control,
not an exact cut realization, a priced chart, or a supplier construction.
Changing the middle child's address-dependent phase or separate translation,
paying nonreciprocal adapters, rewriting multiple sites, changing the active
volume or allowing spectator garbage all require different contracts.

This finite result tests owner0/port0 and this transfer only. The eight-stream
projection assumes the retained completed-child/frame/hosting interpretation;
helper-only bank/family events are not re-proved as a full physical controller.
The result does not exclude all idle-axis changes, every address-mixing repair,
an enlarged child alphabet or every cost-structure mechanism. It supplies no
changed supplier, selected frontier, all-size compiler proof or new kappa.
