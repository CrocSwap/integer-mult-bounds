## Independent expected endpoint and dense literal runtime

The retained index-mask expectation is correct for the full natural-root shapes. For an original index x, it identifies a=floor(x/(L*R)), low=floor(x/R) mod L and r=x mod R. At an internal node only low0/1 recurse; otherwise the bit is unchanged forever. Deleting low produces child index a*R+r with dimensions A/(L*H),H*R and equal full bank volume A*R. Thus the fresh high coordinate remains inside enlarged child R. At a leaf the bit flips exactly when its final low is0. Inverse merge restores the original global index, so this computes the correct output XOR mask without recursively transforming vectors. It differs from the primary's recursive split/call/complement/merge implementation.

The expectation and observer decode are host-side verification only; no decoded integer, product, branch or expected bit is supplied to the literal program. Entry A/R/H are actually absent. Initialisation supplies only source/T/R_body/width/depth plus the exact prepared markers/guards. Distinct T2/R_body3 in the zero-depth case makes the wrong-input wire meaningful.

The dense byte-array runtime separately tracks support and visits. Initial support does not imply visits; branch/write visit the scanned position, movement visits both ends, and goto/halt/reject do not visit data. Every instruction including HALT is charged. Default branches and write/move fallthrough match the literal machine. Cleared cells leave live support but remain visited. The backing field unions initial support with actual visits, rather than counting only final nonblank cells.

Every write attempt includes the corrected `head>prefix` predicate, original source packet/guards, entire T/R_body/width/depth readonly roles, and phase-specific header guards. Generated A/R are writable during preparation/cleanup but their actual canonical root packet positions become readonly across the core; child suffixes remain writable. Entire H becomes readonly after actual prefix_start and remains so until actual old root_done, before H retirement. These flags are independent assertions only and cannot alter a program decision. The earlier S5 negative-prefix defect is not repeated.

## Five actual controls and precise exception qualification

Mutations check the actual source PC/row predicates before modifying the literal instructions: restore the old node-entry jump, bypass actual depth rewind, bypass actual dummy retirement, restore the old final HALT, or remap actual T operands to R_body within the prefix. All then run the same dispatcher, phase checks, observer and full endpoint/ownership logic. The actual frozen receipt reports all five `accepted:false` with the deliberately broad `failure_gate:semantic_rejected`.

The implementation catches only its dedicated Semantic class for those outcomes. Actual runtime PC/step bounds, DenseTape get/visit address bounds, malformed instructions, parsing and constructor/authentication failures are hard ValueError/RuntimeError/OSError paths and cannot count as control passes. This claim should not be overstated as “every observer bound is hard”: the legacy decoder uses Semantic for malformed/unterminated marked-packet conditions, including its missing-marker boundary check, while its explicit packet-length exhaustion is a hard RuntimeError. These are distinct from program-execution address/step caps. The broad receipt does not identify a unique narrow diagnostic or prove which Semantic predicate fired for each case; no such stronger diagnostic claim is justified without a separate reason receipt.

The negative controls exercise actual generated-state/depth/dummy/cleanup/input-wire obligations, rather than hard-coded result flags. In particular final full-state equality precedes missing root events for the cleanup fault; raw dummy residue is part of the handoff comparison; and T-versus-body has unequal source values. Generic exceptions are not accepted. I found no classification issue that requires a code change for these fixed actual controls.
