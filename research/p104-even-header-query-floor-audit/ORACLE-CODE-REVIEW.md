## Column-rank method and actual rank traces

column_rank builds an incremental column-space basis rather than using
primary's row-elimination implementation. A stored basis vector is normalized
to1 at its first nonzero row and has zeros above that pivot. Sorted pivot
reduction cannot revive an earlier pivot entry, since later pivot vectors have
zeros above their pivots. A remaining nonzero vector adds an independent new
column direction; a zero remainder is in the prior span. New pivots can occur
before older pivots without breaking this invariant. The basis cardinality is
therefore the exact ordinary Q(i) rank.
