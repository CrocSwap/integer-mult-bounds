## Faithful expression representation

Let G be the finite subgroup generated by the actual binary orthogonal owner
maps. For `g in G` and `a in F2^73`, the affine view acts on arbitrary arrays as

```
M(g,a) f(d,z_1,...,z_lambda)
  = f(d g,z_1+d a,...,z_lambda+d a),    lambda >= 1.
M(g,a) M(h,b) = M(g h,a+g b).
```

An expression is a finite rational sum of symbols `(input array, g, a)`.
The checker multiplies matrices over F2 and shifts by this semidirect law,
collecting exactly equal symbols. A zero expression is therefore a universal
operator identity, for arbitrary arrays and every positive tensor power.

Conversely distinct `(g,a)` evaluate at `d=I` and every `z_i=0` at distinct
array addresses `(g,a,...,a)`. For a nonzero expression, select one nonzero
coefficient and set only that input array's value at that address to one.
All other input values are zero. The output residual at `(I,0,...,0)` is
exactly that coefficient. This gives an independently inspectable concrete
counterexample from each `negative_controls` entry in RESULT.json. No regular
cover enumeration or numerical rank estimate is needed.

The logical chart in the inherited QQ16 formulas is `D=M(rho,0)`. Physical
alignment is `A=M(rho,delta)`, and the native boundary gauges relate them by
`A T = T_common D`. They cannot be substituted for one another in a logical
decoder. This audit inherits that bridge identity; it does not re-prove it.

```

```

