# Independent review of the fixed-reader query

The forward query is correct for all three declared D25 pairs. The
literal query restores all 112 source fields. It preserves each arbitrary
target baseline and all 416 outside fields. Its price is 11,168 real
scalar primitives and 2,064 monomial map calls. It uses no native child
and no extra field.

The sixteen positive H8 carrier phase identities and the retained path
conditions pass independent checks. These results do not verify an
integrated native reuse word. The complete supplier, map price, child
hosting, and recursive precision remain separate.

The separate typed inverse-adjoint lemma is correct. This review also
emits its late query in memory and checks its exact map on all 640
arbitrary input columns. This is a check of the late query, not a complete
native backward service.

## The algebra needs no inverse response

Let P select the coordinates that J inserts, so \(PJ=I\). This P is
an operator; in the actual coordinate notation it is \(J^{\mathsf T}\).
Let

\[
L_tJ=I,\quad B_t=L_t-P,\quad
C_t=I+JB_t,\quad E_t=I+A_tL_t.
\]

Then \(B_tJ=0\), so \(C_t^{-1}=I-JB_t\). Direct ordered
multiplication gives

\[
E_tC_t^{-1}=I-JB_t+A_tP.
\]

For a normalized old reader \(L_sJ=I\), put \(B_s=L_s-P\) and
\(M=L_sE_tJ\). It follows that

\[
L_sE_tC_t^{-1}=B_s-B_t+MP.
\]

The six steps in the producer follow:

1. Add \(B_sX\) to the selected target bank.
2. Add \(PX\) to that bank.
3. Apply \(C_t\) to X.
4. Subtract the new \(PX\) from that bank.
5. Add \(MPX\) to that bank.
6. Apply \(C_t^{-1}\) to X.

Steps 2 and 4 add \(-B_tX_{\rm initial}\). Step 5 adds
\(ML_tX_{\rm initial}\). Their sum with step 1 is
\(L_sE_tX_{\rm initial}\). The target baseline has coefficient I at
the endpoint. This argument does not commute operators at two stages.

Neither \(E_t[P,P]=0\) nor invertibility of \(E_t\) is needed for this
identity. The former is a property of the actual inexpensive middle
query. It is not a hypothesis of the general factorization.

`GENERAL-READER.md` records a separate extension to an arbitrary old
reader. It replaces the two copies by a paid map \(W=L_sJ\).
The actual invoice in this review applies only to \(W=I\).

The checker reconstructs all 336 D25 routes from the native q values
and the actual orthogonal chart rule. It checks the canonical Z4
phase identities with a separate coefficient representation. The
canonical operator model itself is inherited from the source supplier
and the earlier formation and D25 reviews.

The checked reader/service pairs are \((0,1),(0,2),(1,2)\). In each
case the physical level before service t is \(t-1\). The label s
identifies a retained reader. Thus \((0,2)\) assumes that reader \(L_0\)
was carried through stage one. It does not mean a physical jump from
level zero to stage two.

At the adjacent entry, a selected FULL target becomes its positive
intrinsic line \(Q_p\), with the common exterior retained. An ordinary
hole target becomes I with the same exterior. The checker verifies
448 source/target FULL-to-Q identities and 224 hole-to-I identities
over all ports. It also verifies 672 past/current FULL view identities.
Omission of the positive intrinsic line gives a different phase.

Each carrier uses eight orthogonal axes perpendicular to its actual
q, plus an explicit output translation. The full phase polynomial is
that of \(F_9Q_p^{-1}\), with no constant phase. All sixteen carriers
pass. The opposite intrinsic sign fails.

For a term of \(L_sE_t\), the route is

\[
\rho_{s,p}\rho_{s,j}\rho_{t,j}\rho_{t,r}.
\]

The independent multiplication retains this exact order. It combines
terms only if both the input field and the complete route agree.
There are 3,808 terms per pair. Restriction to the selected source
fields gives 696 terms. The first two pairs use 216 distinct middle
routes; the last pair uses 696.

Every route A is orthogonal and fixes all uncompleted axes. At the
completed level t, its actual view is

\[
\Psi_t(A)=F_{9+8t}P_AF_{9+8t}^{-1}
         =X_{\delta_A}P_A.
\]

The checker verifies the entire Z4 difference polynomial and the
inverse translation \(A^{-1}\delta_A\). The map is a single owner and
payload map: the owner read is \(h\mapsto hA\), and the payload map
expresses that source chart in the target chart.

The review expands the complete literal query. It applies each old
view, code view, temporary source map, scalar gate, and restoration map
in order. Its matrix is compared with the direct \(L_sE_t\) product on

Here the row sum also gives the sharp physical sup norm on the
regular cover. Each coefficient is attached to an input field and a

signs that attain the row sum. This statement uses the regular cover.
It does not assert sharpness on a quotient cover.

The bounds concern complete emitted gates. They do not bound the

child, or a recursive caller. They do not supply a complete precision
certificate.

## The typed inverse-adjoint

Let \(Q_P\) be the positive intrinsic line on the selected target
fields, with I on the other target fields. Let \(H_R\) be the inverse
intrinsic line on the ordinary target fields, with I on the selected
fields. Put

\[
F_{\rm in}=\operatorname{diag}(Q,Q_P),\qquad
F_{\rm out}=\operatorname{diag}(F,FH_R),\qquad A=C_sE_t.
\]

The exterior factors and cover views belong to these unitary frames.
For an integrated forward word, the physical operator is

\[
U=F_{\rm out}
\begin{bmatrix}I&0\\A&I\end{bmatrix}F_{\rm in}^{-1}.
\]

For a chronological word \(U=G_n\cdots G_1\), its inverse-adjoint is
\(G_n^{-*}\cdots G_1^{-*}\). Thus the chronological gate order stays
the same. Unitary native and monomial gates stay the same. An ADD
\(b\leftarrow b+ca\) becomes \(a\leftarrow a-\overline c b\), and a
real unit SCALE becomes its reciprocal. Therefore

\[
U^{-*}=F_{\rm out}
\begin{bmatrix}I&-E_t^*C_s^*\\0&I\end{bmatrix}
F_{\rm in}^{-1}.
\]

This is an adjoint response, not a reciprocal response. It retains
the selected \(Q_P\) input type.

The late dual query is checked independently by this gate transform.
It implements \(X\leftarrow X-E_t^*L_s^*Y_P\), retains every selected
Y baseline at its endpoint, and leaves ordinary Y and outside fields
unchanged. Its maps have the same order, and it reads only the FULL
selected Y fields. The complete route in each adjoint coefficient is
the inverse of the forward route. The price is unchanged. The
different prefix bounds are computed separately.

This proves the conditional circuit lemma and the emitted late query.
It does not replace the missing integrated native forward and backward
replays. It also does not provide a controller that accepts these
boundary types.
