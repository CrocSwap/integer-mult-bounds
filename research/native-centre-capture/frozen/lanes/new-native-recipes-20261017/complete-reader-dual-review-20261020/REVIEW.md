## Why the same chronological maps implement the dual

For a complete physical map \(W=OMA^{-1}\), with unitary input
frame A and output frame O,

\[
W^{-*}=OM^{-*}A^{-1}.
\]

Thus the inverse-adjoint keeps the direction of physical stage
progress. It does not exchange the DATA entry and exit views.

For a chronological gate list \(g_1,\ldots,g_n\), the physical
operator is \(g_n\cdots g_1\). The inverse-adjoint is

has the same order. A unitary native child or physical monomial
