# A restored-source query for the routed involution

The actual dyadic row involution permits a shorter fixed-reader service.
At the completed FULL cut, apply the current involution to X, query
the past reader from X, and apply the involution again. The last step
restores every source field. The target can have an arbitrary baseline.

The emitted query has 8,440 real scalar primitives, 672 monomial maps,
and no native child or extra field. With the existing carrier prefix,
the complete typed forward service has 14,896 real scalar primitives
and native rank 1,792. This result does not close a backward caller,
the helper host, or the full supplier.

## The reversible-source query lemma

Let X be a complete source bank. Let Y be a distinct target bank.
Let T be a unit on X, and let L be a reader from X to Y. Assume that
the following three operations are admitted at their actual frames:

1. Apply T to X.
2. Add LX to Y.
3. Apply \(T^{-1}\) to X.

On arbitrary independent x and y, this word gives

\[
(x,y)\longmapsto (x,y+LTx).
\tag{1}
\]

The first operation gives \(Tx\). The second adds \(LTx\) to the
unchanged target baseline. The last restores x. No condition on
\(LJ\), no zero source, and no zero target is needed. In particular,
the selected target records need not be a separate owned workspace.

If the three words restore their own borrowed fields, the complete
word restores them as well. The price is
\(a(T)+c(L)+a(T^{-1})\), with the actual view and storage costs included.
If both source words cost at most a, this is at most \(2a+c(L)\).
The lemma does not make T or L admissible at a new frame.

Several target readers can be used between steps 1 and 3 if each
reader preserves X and the other target baselines. In that case the
two source transformations are shared. This is an algebraic extension;
this packet emits one sixteen-row reader.

## The actual current source unit

The source is the controller lane's 112-port physical row involution A.
The emitter pins its exact matrix and its 3,276-scalar common-frame
word. It checks both the complete word and \(A^2=I\).

The pivot set P has sixteen ports. Its complement R has 96 ports.
The source response E and A have exactly the same R rows:

\[
A[R,*]=E[R,*].
\tag{2}
\]

Thus the frozen carrier prefix for E remains a valid carrier prefix
for A. It emits the ordinary increment \((A_tx)_R\), leaves the selected
records independent, and completes all X and selected Y fields to
FULL. No native transfer or native phase recipe is changed.

Let \(A_t\) be the current routed operator. Let \(L_s\) be the retained
past reader. Use (1) with \(T=A_t=T^{-1}\) and \(L=L_s\).
The result is the required selected increment \(L_sA_tx\).

This argument does not replace \(A_t\) by a scalar matrix in the
global chart. It does not commute the reader through the response.
The map \(L_sA_t\) has 3,824 actual owner paths in each checked case.
The implementation does not enumerate those paths as separate ADDs.

## Literal current and past views

The three checked pairs are
\((s,t)=(0,1),(0,2),(1,2)\). The physical input level is always \(t-1\).
The label s identifies the carried reader, not that physical level.

At the completed level t, the current A word has this order:

1. Apply the literal current FULL view to each of the 112 X fields.
2. Execute the pinned 3,276-scalar A word.
3. Undo those 112 views.

The word therefore uses 224 map calls and has the exact global action
\(A_t\). The emitter checks every view's complete Z4 phase polynomial.
Each route is orthogonal and fixes every uncompleted axis.
The current view arrays equal the current DATA exit arrays in the
frozen dispatcher.

For the old reader, write \(L_s=J^{\mathsf T}+B_s\). Use the old FULL
views on 96 ordinary X fields and sixteen selected Y fields. Run
the 1,760-scalar complement reader and undo its views. This costs
224 maps. Then make the sixteen same-port selected copies, at a
cost of 128 scalar primitives and no further map.

All maps act only on FULL fields. The ordinary Y hole fields are
neither read nor changed by this late query. The second A word uses
the same current views and the same scalar word as the first.

The exact order is:

```text
current A on X
past B_s complement query into Y_P
sixteen selected copies into Y_P
current A on X
```

The two current A words restore X as a complete routed operator.
They do not restore X by identifying different owner paths.

## The complete typed forward service

Use the frozen carrier prefix before the query. It has 2,406 events
and the profile

```text
1392 H1 + 64 H2 + 48 H3 + 16 H8.
```

Its native rank is 1,792, and it has 1,520 native children. Its
scalar price is 6,456. All 416 arbitrary helper fields are restored.
The existing native phase checks and the current DATA phase checks
remain unchanged.

Let \(F_\ell\) be FULL on the first \(9+8\ell\) axes, and put
\(G_R=\operatorname{diag}(I_P,q_R)\). For independent target records w,
the complete service is

\[
(F_{t-1}x,\ F_{t-1}G_Rw)
\longmapsto
(F_tx,\ F_tG_R(w+D_{s,t}x)),
\tag{3}
\]

where

\[
(D_{s,t})_P=L_sA_t,\qquad
(D_{s,t})_R=(A_t)_R.
\]

If \(w=C_sy\), the selected records after the service are
\(L_s(y+A_tx)\). Thus the reader from stage s is retained.

The native cover sweep and all DATA exits precede the late query.
The program contains both native provider prefixes, all actual stage
view records, and all six provider/pair invocations. It preserves
the whole-cover barrier in the previous dispatcher.

The query invoice is:

| Part | Real scalar primitives | Maps |
| --- | ---: | ---: |
| First current A | 3,276 | 224 |
| Past complement reader | 1,760 | 224 |
| Selected copies | 128 | 0 |
| Second current A | 3,276 | 224 |
| Total | 8,440 | 672 |

Adding the carrier prefix gives 14,896 scalar primitives. A conservative
bound for this word is 4,384 monomial calls: 448 DATA calls, 224 local
endpoint adapters, at most 3,040 native side maps, and 672 query maps.
This is a call count, not a finite real-operation price for those maps.
Helper acquisition, recursive parking, and the outer caller remain
separate.

The exact query row-sum maximum at the emitted gate boundaries is
202, and its binary denominator height is at most two. These values
hold for all three pairs. The bound also holds after the complete
carrier prefix. It does not cover internal arithmetic in a lowered
ADD, a native child, or a recursive caller.

## Checks, scope, and credit

The emitter uses exact rational coefficients and the pinned route
algebra engine. It checks all 640 formal input columns of the joined
prefix and query. Each coefficient retains its input field and its
complete \(O(25,2)\) owner route. It compares the result with the
direct \(L_sA_t\) product. Every X field, ordinary Y field, and helper
has the required endpoint.

Omitting the second A word fails. Replacing the past reader by the
current reader also fails. Both controls fail for every checked pair.

Run `emit_query.py --output <new-directory>` with normal Python and
with `python3 -O`. The payloads and receipts must be byte equal.
The emitter rejects an existing output directory.

The reversible-source argument supplies the selected query. It does
not prove that the complete response \(D_{s,t}\) is reciprocal or
stage independent. A backward service, the complete controller,
raw output restoration, recursive hosting, and a final exponent
remain open.
