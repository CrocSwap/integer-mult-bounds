This package preserves a source-bound written obstruction for the released
[two-FULL/one-query construction target](https://github.com/CrocSwap/integer-mult-bounds/discussions/4930#discussioncomment-19143357).
Within **fixed finite columnwise monomial-Clifford plus scalar-owner programs**,
no all-width invertible `t0` satisfies the four declared free-membership
conditions. The proof gives zero `t0` at every sufficiently large width; it
allows exceptional small widths. It does not classify every physically FREE
program. No successful controller, complete caller or new κ is supplied.

The independent review passes the corrected argument, including the essential
transported class `Ht = D3 H0 D3^-1`. It does not replace this class by `H0`.
See the unchanged [proof](evidence/proof/PROOF.md),

scalar owner sums are applied once, rather than tensoring an owner sum.

```sh

python3 -I -O -W error -B research/released-operator-clifford-ceiling/verify.py
python3 -B scripts/research_package.py --package research/released-operator-clifford-ceiling --check-only
```

author source/flag checker and conditional budget engine. It compares the full
regenerated receipts byte-for-byte. The budget loader mirrors the original
logical inventory path in private scratch and changes only `HERE`/`STOCK`;
`__file__`, scientific functions and all output fields remain unchanged.
No path-field canonicalization or edited receipt is used.

The source checker verifies the exact A polynomial, zero diagonal, 112 distinct
source directions, 52 nonzeros per row/column and orthogonal G maps. Its actual
17-axis binary witness demonstrates that a transported letter may send
`e_q` to `e_q + e_w`, preserve the correct three flags, and fail the untransported
`Lq` condition. Five source/flag and five invoice controls reject. The former
is **binary symplectic support only**: it does not verify absolute phase,
all-width theorem logic, every physical source endpoint or a native supplier.
The written proof and independent review supply the mathematical argument;
