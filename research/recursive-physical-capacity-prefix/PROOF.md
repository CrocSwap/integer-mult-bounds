## 4. Actual recursive park and restore

prepare_child verifies source/parent,builds the complete projected extents,calls
the actual child-program producer,and copies the three grants. Its finally
clauses close temporary producers/counts. The trace closes and close_geometry
frees eight indices before call. The parent then owns3R/2I plus grants1R/2I.

RoleParking moves streams only. BankParking.park keeps exactly the three grant
labels and serializes/frees every other live slot. It allocates no numerical
Word. new_context therefore starts from grants alone at every depth. Parents
remain encoded on the parking tape, not live in the numerical banks.

close_frame frees the child's numerical work and requires both banks empty
before restoration. _restore_word checks the exact original label is free,
moves it to the top of available,and calls zero. That request necessarily uses
an existing slot rather than its fresh-inventory branch. The original Word
object/slot is restored, not a same-valued replacement. The parked frame has
the parent's3R/2I because grants were excluded. restore_context makes aliases
only. The child result stays on a protected stream through both restores.

Induction on any finite well-bracketed execution prefix establishes the cut
invariant without assuming the complete call tree terminates. The next macro's
actual boundary check establishes its resident set. If a separate ownership or
semantic guard fails,the theorem stops there rather than assuming success.

## 5. First-failure argument and backing

PhysicalArena preallocates C fixed Word roles. Allocation removes an erased
slot from available and adds it to live; free reverses that transition. Warm
reuse/free-order changes preserve the partition and identities. Suppose a
first inventory-rejecting zero occurs before any noncapacity error. A nonempty
free list skips the guard. Otherwise all C slots are live,so pending demand is
C+1,contradicting the bound when C dominates the displayed budget. Restore
additionally has the exact-specific-free-slot argument above. No unlimited
successful reference execution is needed.

Erased use is not removed from backing. Fixed Word identities,templates,
visited cells and LEFT/RIGHT margins persist. A numerical-inventory bound does
not by itself imply the physical action/space tariff or erase the ancestor
stack. Those separate premises remain.
