# Actual compiler switches through a complete physical H boundary

This package connects the retained tensor compiler's **actual emitted global
H/sign/H/half switches** to the complete physical T74 caller from
CrocSwap/integer-mult-bounds#3627. It derives selected bit positions from the
source emitter, keeps every original coarse label, executes the nonconstant
product sign diagonal in the restored caller frame, and returns the complete
route on the original address axes. The exact raw-H adapter includes real
low-zero insertion, the backend's normalized H0 return, signed width changes
and an exact division that restores the input width after every switch.

**No new κ.** This is a scoped source-relative compiler and precision-tape
composition result. It uses the older physical backend and its domain, retains
its native/hosting/refinement premises, and does not admit the selected #6030
supplier or discharge all five assumptions. It executes the forward Beneš
routing prefix of `local_layer`, including its true adjacent nonconstant
diagonals; the central general complex gate word is an explicit remaining
obligation.

## Exact statement and complete budget

For `g` original axes, with `m` low local bits per axis, let
`n` be the total binary address width, `N=2^m`, `L=2^(n-gm)`,
`V=2wCr2^n`, and `P_*=w+g`. The input is the complete `C` by `2^n`
rectangle with `r` signed Gaussian coefficients per address, `w` bits per
component, on an external `p`-grid with `0<=p<=w`.

For fixed comparison constants, the rate theorem requires
`n=Theta(P_*)`, `g=O(w)`, `m=O(log P_*)`,
`gm<=floor(P_*^.997)` and `log(r+1)=O(P_*)`. Its complete time is

    O(S_prepare
      + Vm[g^.99827101 log P_* + (g+1)^tau (log P_*)^(1+tau) + 1]
      + V(gm+1)^tau (log P_*)^(1+tau)),
    tau = 332353/332929,
    S_prepare = O(LgN^2(P_*+2)^7 + poly(P_*+log(C+1)+log(r+1))).

The last execution term pays one initial and one final physical gather, whose
listed support is at most `2gm`. The separate preparation term pays all L
coarse-label tables and the actual local compiler work. It is absorbed, for
example, when `g=Theta(P_*^beta)` for fixed `0<beta<.997` and
`m=O(log P_*)`; it is retained explicitly for small g. No per-microbox invocation
is assigned the whole-field backend tariff.

[PROOF.md](PROOF.md) gives the source-event derivation, grid identity, exact
switch reset, internal stock alternative, distinct router/root reservations,
full preparation allowance, occupied-space bound and retained-backing caveat.
The endpoint proof is universal under its stated source premises. The finite
replays do not prove those premises.
