# Physical whole sparse-union router

This package implements the **entire encoded sparse-union window around the
first narrow inverse service** of CrocSwap/integer-mult-bounds#6908. Starting
from one delivered complete dense context and its same-Reference coefficient
catalogue, it physically produces #4583 membership/ordinal headers, executes
all #4327 union rounds, exposes complete non-dyadic E-lines, calls the unchanged
numerical service, restores order and returns a protected dense frame.

**No new κ.** The selected #6030 bound and its five retained assumptions are
unchanged. This is a source-bound component theorem and executable implementation,
not completion of the Gaussian, FFT/CRT or integer-multiplication supplier.

Prepared for **@CubeJerry**, with substantial OpenAI assistance. Canonical base:
`7c49fe32c55de02c2c873655c804b16e4c3fef0a`. Exact numerical dependency:
`9c6078ff36ae2110e6cc30ff69a9addbf5a47bf2` (#6908). See [NOTICE.md](NOTICE.md),
[SOURCES.json](SOURCES.json) and [DEPENDENCIES.json](DEPENDENCIES.json).

## What becomes concrete

#4327 already proves the record schedule and its head-travel bound. #4583
already supplies the header schema and capacity bound. #6908 already implements
the numerical first inverse window and proves rounded flag-class chronology.
Its retained integration still performs the surrounding scheduling in host
Python. This package replaces that host boundary with physical tape operations;
none of those predecessor results is claimed again.

| Boundary | Implementation supplied here |
| --- | --- |
| Source carving | Exact unchanged canonical `carve` and `Core.partition` bodies, bound to original Reference coordinates; separately charged setup |
| Membership and ordinal production | Sequential merge of the source-generated E list with `[0,L)`; dense tape catalogue; no supplied host membership function |
| Dense headers | Carrying tape odometer and three raw field scans; exact #4583 format |
| Round selection | Encoded flag/count scan selecting the next active axis |
| Axis grouping | Stable bitwise radix scans with locally delimited inversion logs |
| Non-dyadic line exposure | Encoded balanced-range tree and raw-prefix comparisons; no suffix-length counter or host tree |
| Numerical payload | The unchanged #6908 `UnionInverseWindow`, using its actual prepared pages and seven-product child |
| Restoration and dense return | Inverse zip/radix passes, local keep/final stacks, fresh source-header checks, protected same-context dense output |
| Ownership | Fixed pools/roles, suspended parent scope during numerical calls, complete borrowed restoration and explicit consumption |

The online machine has no variable-size Python record array, sorting primitive,
decoded long key or host payload callback. Python observation counters do not
schedule work. Its 256 short-metadata scratch roles and 27 named buffers are
fixed independently of the input dimensions; the numerical descendants retain
their own fixed inventories. Constructor sealing and no-decoding guards are
active during the executions.

The key engineering point is that lengths such as `L^g`, the live round size,
a radix prefix length and a suffix-row length **never become arithmetic
operands**. End markers and local decision stacks replace them. Arithmetic
operands remain short fields bounded by polynomial expressions in the local
side, block, grid and group dimensions. This avoids charging a polynomial in
`log(L^g)` on every bit when that is not a polylogarithm of the production
precision.

## Source relation and scope

The input is at the first sparse inverse boundary, after the prior dense
interior action. Its complete binary context contains the immutable Reference,
original window/coarse origins, admitted partitions, grid/carrier/block choices
and spectators. The data frame and coefficient bank must have exactly the same
full key. The key is compared and returned directly, never replaced by a hash.
This is a typed source contract: it does not cryptographically prove the meaning
of arbitrary user-supplied page bits.

The retained `source_window.make_window` produces E from every original nonzero
boundary/interior incident coupling, and J from the complete interior complement.
It supplies the same original shear and Schur factors used by physical page
preparation. The new canonical-carve adapter produces interiors from actual
original phase cells and holes. The online membership producer then consumes
that serialized list. These are distinct stages with separate prices.

The numerical map is the precise inherited deterministic rounded version of

\[
 T_f(u)_{J_f}=F_f^{-1}(u_{J_f}-C_{0,f}u_{I_f}),\qquad
 T_f(u)_{E_f\setminus J_f}=u_{E_f\setminus J_f}.
\]

The machine passes **current** values to each complete E-line. Rounded maps
need not commute. The inherited flag-class proof identifies the result with
the full increasing-axis rounded schedule; no exact tensor matrix is substituted
for that rounded oracle. Source/radius/error/carrier premises remain those of
#6908 [NUMERICS.md](retained/inverse_window/NUMERICS.md).

This theorem concerns a **delivered complete context**. Global delivery, its
retained stock, incoming dense-stage error and grid conversion, other inverse
stages, broad forward maps, core/halo assembly and final recovery remain outside
this window. The separately proved existing halo/tail geometry is not reproved
here. A full literal production source-setup pipeline also remains a separate
join; its sequential algorithm and full invoice are explicit here.

## Full invoice

The all-size argument is [PROOF.md](PROOF.md). Write `D=L^g`, `U` for the number
of points with at least one exposed coordinate, and

\[
 S=\sum_x |F(x)|=\sum_f |E_f|L^{g-1},\quad
 H=2+2g\lceil\log_2 L\rceil+g+2\lceil\log_2(g+1)\rceil,\quad B=H+2w.
\]

Let C be the complete serialized context/catalogue length, M the actual dense
membership-catalogue length, R the executed rounds, and
`ell=1+ceil(log2(L+g+w+b_max+P+2))`. The new transport time is

\[
 O\!\left(\left[DB+SB(1+\log g+\log\max(1,a_{\max}))
                  +M+(R+1)C+1\right]\ell^5\right).
\]

The dense DB term remains separate from sparse S movement. Complete catalogue
scans are retained even for unused axes. No source setup, long header, partial
row, complex-column ceiling, protected return or erased backing is free.

For each actual nonempty `(round,axis)` stream of m complete lines, the unchanged
child makes exactly

\[
 \bigl[2(2\lceil a/b\rceil-1)+2(2\lceil n/b\rceil-1)\bigr]
       \lceil2m/b\rceil
\]

matrix calls. Their exact arithmetic and movement invoice is added, with all
ceilings. The complete scoped time is **source/page preparation + bank
serialization + whole transport + numerical calls**. Caller delivery and other
stages are further additions.

The new transport backing is `O(q+DB+C_max+ell^2)`, plus the child's complete
retained bound and all borrowed/setup/cache storage. This uses `S<=gU<=UH` and
`Ut<=UB`, so it needs no extra sparsity inequality. Across repeated calls each
fixed role retains its historical maximum visited span; erased space does not
disappear from the account.

A conditional corollary pays fresh source preparation within each delivered
complete context. If `g=Theta(p^beta)`, `L=p^Theta(1)`, original-coordinate scale
`O(p^(1-epsilon))`, `beta>1-epsilon`, and the stated source-description bounds
hold uniformly over its at most g axis keys, then preparation and complete
catalogue traversal are `o(Dw)`. The proof compares their logarithms. This does
not supply missing contexts or automatically extend to the caller's separate
sparse tails. The generic invoice remains valid without that corollary.

## Executable evidence

The finite evidence is deliberately split by what was actually executed.

- `verify_transport.py` runs eight cases using a physical endpoint-NAND line
  service and a separately written dense oracle. The cases include empty E,
  heterogeneous and noncontiguous E, non-dyadic 3/5-row exposures, six rounds,
  signed payloads and a 4,097-bit context. Wrong axis order, stale values and a
  dropped axis are distinguished. Ten failure controls cover malformed source
  counts/masks/E lists, truncation, context mismatch, corrupted return headers,
  a wrong zip chunk and failure after a completed child return. The same owner
  recovers and is reused.
- `independent_flat_oracle.py` is the separate root reviewer's seven-case check.
  It imports no author fixture encoder or expected-value oracle; its reference
  uses flat arithmetic strides. It checks full outputs, exact incidences and
  complete lines, signed values, reuse, borrowed views and historical cleanup.
- `review/a_review_union.py` is the separate worker A review. Its independently
  written sparse hardware checks local block retirement without reading an
  older 65,537-bit block, raw contexts with Count arithmetic disabled, and long
  coordinate prefixes whose leased Count backing stays short. A deliberately
  wrong raw-prefix-to-Count conversion is distinguished.
- `verify_carve.py` runs the exact canonical carve and partition bodies. One
  L40 source admission has two nonempty interiors, E28/J24 and inactive
  coordinates. A separate L90 geometry case crosses two original holes and
  three phases while retaining three interiors. These are source/geometry
  checks, not physical numerical replays.
- `verify_source.py` actually serializes the same-Reference factors, executes
  physical `prepare_pages`, copies those actual pages into the bank and calls
  the complete physical router with the unchanged numerical child. Its exact
  full-grid oracle rebuilds the source factors independently. The admitted4
  fixture uses g2/L4/E4/J2/b4; the extended sparse8 fixture uses
  g2/L8/E6/J4/b2 and multiple flag classes. These explicitly admitted interior
  partitions are not outputs of the conservative production carve.

Receipts retain primitive read/write/unit-move counts, precise source and output
hashes, complete-line/incidence counts, numerical scalar products and written
backing. They do not substitute measured finite values for the proof. Action
counters delimit the reported physical stages; external Reference generation,
fixture encoding and reusable owner initialization are covered by the separate
setup/initialization invoice rather than silently attributed to online calls.
`retained_cells` denotes written bytearray backing; the proof counts historical
visited extents, including blank lookahead and caller movement.

## Reproduction

Use Python 3.12 and the standard library. All canonical inputs and unchanged
pending-predecessor modules are authenticated by Git blob ID and SHA256 before
execution. Retained pending modules are included in this package; replay does
not depend on their commits being present in a local object cache. The canonical
input archives remain unchanged and are declared explicitly in VERIFY.json.

The bounded registered replay runs the transport, independent flat oracle,
independent local-scan hardware, canonical carve and admitted4 numerical fixture, in isolated fresh Python
namespaces. Its normal and optimized runs keep explicit rejection checks active:

```sh
python3 -B scripts/research_package.py --package research/physical-union-router --check-only
python3 -B scripts/research_package.py --package research/physical-union-router
```

Direct individual commands are also supported:

```sh
python3 -I -B research/physical-union-router/verify_transport.py
python3 -I -O -B research/physical-union-router/verify_transport.py
python3 -I -B research/physical-union-router/independent_flat_oracle.py
python3 -I -B research/physical-union-router/verify_carve.py
python3 -I -B research/physical-union-router/verify_source.py --case admitted4
```

The larger source run has a separate long replay because its actual rational
page preparation can exceed the generic command's 600-second limit:

```sh
python3 -I -B research/physical-union-router/verify_source.py --case sparse8
python3 -I -O -B research/physical-union-router/verify_source.py --case sparse8
```

`--write-result` deliberately regenerates an individual stable receipt; ordinary
commands compare with the committed receipt. Timing is excluded from equality.
The registered launcher supplies fresh bytecode caches; the package wrapper
also isolates each child interpreter's cache. Direct individual replay should
likewise use a fresh `-X pycache_prefix=...` when untrusted ambient bytecode is a
concern. See [TASK.json](TASK.json) for the exact frozen assignment and next steps.
