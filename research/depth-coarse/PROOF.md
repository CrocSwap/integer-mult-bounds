# Local algebra and inherited proof boundary

Let Gi,Gj be disjoint groups of vertices, each of size 1 or 2. Every edge value
e(a,b) has support disjoint from all other edge values in this coarse sum.
The coarse edge is

    Cij = sum_{a in Gi, b in Gj} e(a,b).

It can be emitted as either

    sum_{b in Gj} (sum_{a in Gi} e(a,b))       [columns]
    sum_{a in Gi} (sum_{b in Gj} e(a,b))       [rows].

Both are finite distributive regroupings of precisely the same partition.
Every nontrivial addition has disjoint support; singleton/empty summands are
handled by the inherited total routine. Each intermediate core and cover is
computed from its actual support. The resulting common-point exclusion graph
therefore retains its weighted total and all single/pair exclusion identities.

The row/column choice is fixed at each internal weighted-exclusion construction
level before compilation. There are eight choices at levels 0–2; deeper levels
use columns. This is a
finite grammar, not a data-dependent runtime choice. The PR71 grouping vector
[1,1,2], singleton/pair partition and strict contraction are unchanged, so its
weighted induction and termination proof apply to either regrouping. The
global-pair anchor remains a permutation of points other than each common point.

Reassociation can share nodes with the existing strip DAG and can alter
carrier matching/retirement. Thus fewer scalar additions do not prove fewer
physical roles or a better exponent. The selected word is recompiled in full,
with every paid XOR, frame raise, source, copy, endpoint and dirty-state cleanup.
No actual price is replaced by the discovery heuristic. The full paid profile
is constructed as in PR71: data and endpoint copies, replicated actual axis
profiles, exteriors and data growth. It satisfies

    W = 2N + 2300 R23 + 1771 R25,
    sum_t t n_t = 575 W - 1846900,
    0 < t <= 529 < 575.

The normalized characteristic is

    M(a) = sum_t n_t t/(575 W) exp(a log(575/t)).

Inherited independent rational logarithm/Taylor bounds prove a strict accepted
upper moment and strict rejected lower moment at adjacent saving grid points.
The complete frozen PR #71 and #75 profiles are also lower-bounded above 1 at
the selected saving; comparing width alone is insufficient. The inherited
balanced assembly is rerun for all 47 strict inequalities, seven margins and
the adjacent kappa-grid rejection, retaining backoff 10^-12 and the unchanged
complex saving 717/10^7.

The literal verifier explicitly reconstructs the entire ordered scatter list
from the exact output inventory and compares it with the word. Canceling extra
scatter operations therefore cannot pass merely because their net scalar map
is zero. This binding follows PR64's verification precedent. All port/role
indices are range-checked before inherited replay, so negative Python indices
cannot masquerade as legitimate source/dirty roles. Every input, target and
dirty basis coordinate is replayed in both orientations, and actual frame
transitions and exact fixed-basis/CRT profiles are regenerated.

These are finite algebra, word and arithmetic claims. The ambient framed lift,
all-size row/remainder compiler, scalar overhead, tape/routing simulation,
prime/setup/recovery and analytic multiplication transfer remain inherited
dependencies. This local proof does not remove those hypotheses or establish
global optimality of the finite search.
