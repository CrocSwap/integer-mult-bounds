the newly proved old-coded entrance and return bridges. A single fixed
12,829-instruction graph uses 70 tape owners, with no host-side arithmetic
or output substitution at either continuation. It returns the exact
central result to the original old-coded owner and restores all private
bodies, heads and guards under the explicit all-prefix numeric domain.

**Classification:** scoped implementation and composition theorem;
enabling progress on the physical `precision_tape` / `native_all_columns`
interface. **No new kappa. No foundational assumption discharged.**

indices, spectators, common quantum and absolute phase preserved. For

```
T <= 2^24 (f V_old + E + 1)
K_after <= K_entry + 128 (V_old + E + 1).
```

Both directions of the old codec, all 18f address passes, literal header
parsing, the actual f C axes, source access, staging, original-owner

conservative constants follow from the pinned complete program bounds and
the proved six-Gamma header bound. Erasure never refunds historical cells.
The unchanged graph retains a Theta(f V_old+E) direct-order cost; it does
not establish an accelerated nonleaf tariff.

complete stock and cutoff derivation, failure-time cleanup/retry, recursive

the central C action, not a complete selected MOVE or a multiplication
