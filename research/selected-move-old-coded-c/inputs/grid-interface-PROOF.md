## 2. Every lowered Gaussian prefix stays on the common grid

Let C_j be the positive Gaussian on the j-th selected bit. Between the
right monomial and the left monomial, every completed axis prefix has form

    C_(j_k) ... C_(j_1) R sum c U x
      = sum c (C_(j_k) ... C_(j_1) R U) x.

Each parenthesized operator is another Gaussian-dyadic Clifford on the
same n-bit root. Multiplication by these unitary native factors changes
neither the exterior coefficients nor their denominator/mass budgets.
The argument works for any axis order and any subset prefix, not merely
the final product. Monomial prefix gates have the same property.

Use the retained complete-root Clifford row theorem: entry denominators
divide 2^ceil(n/2), and a row has Euclidean norm 1. Thus every such prefix
component requires at most

    p+ceil(n/2)+178t fractional bits,

and its magnitude is strictly below the selected majorant with exponent

    h+ceil((n+1)/2)+161t+1.

Since 356t<n, one has 178t<n/2. Integer rounding gives
ceil(n/2)+178t<=n, and the magnitude exponent is at most h+n+2.
Consequently every ideal prefix is exactly on grid2^-(p+n), and its stored
integer components have absolute value strictly below 2^(w-1). Both signed
endpoints are safe; the most-negative two's-complement boundary is excluded.

The literal program forms each four-summand numerator exactly in w+2 bits,
then checks parity and the signed fit of its half. The two sides of each
Gaussian pair at the next axis are precisely the ideal next-prefix values.
They are integral on the common quantum and fit w bits by the bound above.
Therefore all parity and signed-fit checks succeed. The available w+26
temporary allowance dominates its w+2 numerator requirement.

Induction over the finite f axis loops proves agreement with the ideal
prefixes. During a partially written field each consumed component is an
old or a new bounded component; there is no external consumer before the
literal macro returns. The six-Gamma leaf needs no runtime proof oracle or
additional divisibility precheck. It need not satisfy the stronger optional
input-divisibility criterion 2^ceil(f/2); the actual correlated-prefix domain
is enough. Existing 1125 entrance/exit scaling remains charged once per native
invocation and is not repeated for this child.

This fills a numerical provider-precondition seam. The common-root Clifford
bound, source envelopes and depth condition are credited retained results;
the deduction must not be called a new tensor/Kronecker theorem. In particular
it does not assume that the leaf is already numerically exact to establish

## 4. Minimal paid packing adapter at the older physical boundary

The older coded raw interface has C_rows=outer*rows, a within-row address
bits, native selected positions

    p_(i,j) = u+(if+j)K+rho,
    0<=i<9, 0<=j<f,

counted from the left. Write b for the stored component width, distinct from
the root input magnitude parameter h in sections 1-2. A faithful bridge in
this corollary has b=w=p+h+2n+3. It stores r coefficients with b-bit real and imaginary
components, LSB first, a delimiter after each component, and three physical
bits per virtual symbol. Its complete public length is

    V_old = C_rows 2^a 6r(b+1).

A precise complete packing bijection is: preserve the first u address bits;
then gather the 9f selected bits, slot by slot; then append all remaining
address bits in their original order. No spectator coordinate is discarded.
In each new f-bit chunk the gathered order is MSB first. Thus new bit j has
the old column index f-1-j. This reverses the column labels uniformly in all
nine slots, which commutes with the tensor of identical native factors. The
inverse permutation is required on return; no payload relabeling is free.

Choose the literal parameters

    P=C_rows*2^u,  S=2^(a-u-9f),  w=b,

retaining r and the numerical quantum. Decode the old three-bit symbols,
remove delimiters, reverse each component to MSB order and apply the complete
address permutation. The required new volume is

    V_packed = 2 C_rows 2^a r b,
    V_old/V_packed = 3(b+1)/b >3.

This immediately refutes a header-only drop-in adapter on the unchanged old
physical DATA word. The literal leaf's clone expects exactly V_packed bits
and a blank; the old word still has physical bits there. Its cardinality
guard rejects before numerical execution. Changing the descriptor width to
make lengths match would change the coefficient arithmetic interpretation.
This is a concrete interface obstruction, not a counterexample to the
selected conditional theorem or to a correctly implemented bridge.

A correct bridge owes physical source access, complete codec conversion,
component orientation, all selected and spectator address transport, the
six Gamma values with actual cutoff, one common quantum and width, genuinely
separate bank ownership, head returns and inverse conversion to the original
owner. In the explicit separate packed-bank model it has worst-case payload
work at least Omega(V_old+V_packed): arbitrary last input coefficients force
the old source head to visit its far data end, and the new full field has
to be materialized. In particular E-only descriptor work cannot pay it.
This lower bound does not preclude an admissible linear or fast ordinary
bridge; no such complete upper tariff is proved here. Reentry retains the
absolute per-role history union, not merely current field sizes.
