# Active query feedback restores a missing coefficient, with high-rank coupling

Two changed inputs to already-paid queries recover the first original input's
missing rank-nine Gaussian coefficient in the PR4948 physical p2 caller.
The complete output remains coupled to two other arbitrary input banks.
**No autonomous new job, profitable complete caller or higher kappa is supplied.**

Save the first FULL's Y output h. Add h to the second query's old input;
then add C1 Q^2 times that query response to the final query's old input.
All FULLs, the IDLE, three paid queries and 816 independent helper jobs stay
charged. The new response path gives exactly D1 Q^-1 on the first original
input. It escapes the unchanged-input premise of the passive grade result.

The same output has second-input coefficient
`Q^-1 C1 Q (I-Q) D1`, which is nonzero at every positive width. At digit
width f its ordinary complex rank on the 112-owner, 17-axis ambient bank is
`112 * 2^(16f) * (2^f - sum_{k=0 mod 4} binomial(f,k))`.
The fraction of the bank dimension tends to 3/4. This measures coupling;
it is not a recursive-call lower bound. The [proof](PROOF.md) gives the
complete four-input row, all-width argument, exact recipe and ordinary bill.

The exact bounded synthesis tests 8,281 feedback policies in a declared
universal operator algebra, retaining only one of the four required jobs
in every case. This rejects that finite formal synthesis domain. It is
**not** a physical impossibility result: additional source relations, other
feedback inputs and larger decoder grammars are untested.

## Reproduce

Python 3.12, standard library only, from the repository root:

```sh
python3.12 -B scripts/research_package.py --package research/coded-active-feedback
python3.12 -I -O -W error -B research/coded-active-feedback/verify.py
```

The registered normal command replays every full-search policy and rank
(about three minutes on the author's machine). The optimized command checks
the complete component row, rank counts through width 64, positive/negative
controls and 196 direct span certificates on a smaller 49-policy pilot.
Both authenticate four inherited source inputs. All guards remain active
under optimization; no scientific module is loaded from a bytecode cache.
Default verification writes only private temporary outputs. `--write` is
the explicit RESULT.json authoring option.

`SEARCH.json.gz` is a compressed mathematical receipt. Replay compares its
parsed JSON with the regenerated receipt, including every case. Compression
container bytes are not a cross-platform mathematical equality condition.
[RESULT.json](RESULT.json) records the canonical payload digest.
