## Exact job types and arbitrary-input return

Let X contain c=120 arbitrary fields and Z contain r=8 arbitrary fields,
each with V=2^(d f) coefficients. The authenticated query rows give

```
B=R^t/2, C=R/2, CB=14I,
U=[-B;12I], W=[C,I], WU=-2I,
T=I+UW, T^2=I.
```

This is the retained round5 dyadic completion of the native clean-J
response, not a newly claimed supplier. Every old source byte used here is
copied and hashed in `SOURCE-MANIFEST.json`. Let Q_f be the block diagonal
of the actual port Gaussian queries, including the selected-port queries
of the eight auxiliary fields. Define two new *requests*:

```
Row_f: (x,z) -> (x, z + W Q_f x),
Col_f: (x,z) -> (x + Q_f^-1 U z, z).
```

The input on every field is arbitrary. Their chronological composition

```
Row_f, Col_f, Row_f, Col_f
```

returns exactly

```
(Q_f^-1 T Q_f x, -z).
```

Negating z restores it, so the eight dirty fields supply no productive
credit and need no zero-input promise. This is an exact producer/consumer
identity for a changed coupled job. It is not a complete cheap producer:
the price of Row_f and Col_f remains part of the request.

`QueryProducer.lean` proves the reflection identity, all-input four-shear
return, conjugation by any additive equivalence, and both split identities.
The five freshly compiled reports use only `propext` and `Quot.sound`.
No native Gaussian price, tape bound or multiplication theorem is inferred
from this additive algebra.

## Honest paid implementations and all-f recurrence

The direct Row_f implementation takes each source field in turn, copies
it to one owned zero stream, performs its actual rank-f query, scatters
its column of W to the eight target fields, and erases the owned stream.
The source remains unchanged. For Col_f, form each row of U z in that
stream, perform the corresponding inverse rank-f query, add to its target
source field and erase the stream. Complex inverses include the actual
Pauli normalization. The owned stream is returned zero, never credited.
All scalar gathering/scattering, copies, initialization, erasure and
inverse normalizers remain real work.

Even though there are only 112 distinct query directions, there are 120
heads in each direct factorization. For every equal-direction group the
rank of its W columns (respectively U rows) gives its independent direct
heads. The exact group-rank sum is 120 for both jobs: the eight duplicated
selected directions have two independent components. This is a verified
invoice for this algorithm, **not a lower bound on all new algorithms**.

Writing G_d(b) for the cost per coefficient of an ordinary rank-b Gaussian
in the same ambient payload, and P_d(f), C_d(f) for the corresponding row
and column costs, the direct bounds are

```
P_d(f), C_d(f) <= 120 G_d(f) + scalar/copy/erase work.
```

For every f=a+b, the actual tensor queries factor Q_f=Q_a Q_b. Apply Q_b
to all c source fields, use Row_a on each of the 2^(d b) spectator slices,
then apply Q_b^-1 to every source field. This returns x and gives precisely
Row_f. The column construction has the same conjugation, with the inverse
operator in the correct reversed order. Thus before normalization the
complete split bill is

```
T_Row(d,f) <= 2^(d b) T_Row(d,a) + 2c V G_d(b) + Route_d(f,a,b)
             + scalar/precision/owned work,
```

and likewise for Col. The b=0 and a=0 cases use the corresponding identity
query; the width-zero job is an ordinary scalar shear. The active-column
row view or any required gather must be supplied by the physical compiler;
`Route_d` is charged explicitly, not called a free transpose. Under the
round7 same-rho compact selected-control admission it has its full
`O(V((d f log p)^tau+1))` charge. That machine lemma is not re-proved here.
Even granting that routing bound, the normalized recurrence

```
p(f) <= p(a) + 240 g(b) + routing/scalar work
```

does not supply an eight-row recursive price. Balanced splitting gives a
multiple of the existing Gaussian cost; it does not bootstrap a new
contraction. The four-shear direct bill is 480 rank-f heads per reflection,
while sharing the original Q_f/Q_f^-1 around a whole coupled product uses
240. Therefore this exact identity is not applied as a profitable repair.

For the actual rows, ||W||_infinity<=29 and ||U||_infinity<=12. The crude
exact Gaussian envelope ||Q_f||_infinity,||Q_f^-1||_infinity<=2^f gives a
four-shear prefix bound `152100*2^(4f)`. This exposes at least the additional
4f+18 magnitude guard bits for that implementation. Full rounding-error
propagation and the inherited bit/tape reservation induction remain open;
an algebraic dirty return does not establish a rounded dirty return.

## New star-interaction closure test

For stage s let U_s and W_s be the actual owner-route transports and put
E_s=(I-T_s)/2=-U_s W_s/2. A scalar Temperley--Lieb relation would require

```
W_s U_t W_t U_s = 4 lambda I.
```

All linear routes fix address zero, which forces lambda=1. At actual f=1,
input query row 0/address 1 gives output row 0/address 1 coefficient 152,
rather than 4, for both stages (0,1) and (1,2). Thus this proposed scalar
closure cannot make the stage-dependent products a finite recursive color
family. This does not exclude a noncentral operator algebra, a changed
completion or a genuinely different owner protocol. The source-bound
counterexamples are in `STAR-RELATIONS.json`.
