# Check ownership and scope

The test authoring gate was read before the new checks were added. Each
group below protects a mathematical or package contract. No production
hook, changed dispatcher, or runtime monkey patch was added for a check.

| Owner | Contract and credible defect | Separate evidence |
| --- | --- | --- |
| `pins` | The proof applies to the retained word and source dependencies. A transport or word edit can invalidate that proof. | SHA256 and Git blob pins; AST comparison permits only the new admission, helper, and two read-once validation edits. Numerical faults are also tested without this binding check. |
| `budget_checks` | Fractional, integer, preparation, and feedback inequalities must hold. A missing factor, wrong beta exponent, or omitted inverse-preimage term can understate a width. | Separate count recurrence, Euler-phi formula, and exponent inequalities. Package faults reduce the local exponent and inverse guard and must fail at these checks. |
| `admission_checks` | Every induced exponent is between `2^k` and the original cycle length. Prepared powers must be exactly zero at the claimed cutoff. | Exact geometry enumeration, real and complex powers, rational non-dyadic margins, and all-length threshold inequalities. A false cutoff is rejected by actual nonzero coefficient output. |
| `zero_subtrees` | The dirty tail must have the exact addition endpoint and a depth-independent magnitude bound. Endpoint equality alone is insufficient. | Actual `solve` calls with five further structural levels, both signs, two root phases, arbitrary dirty data, and peak-value observation. |
| `leaf_checks` | Signed source-only accuracy, exact restoration, target dependence, and the unchanged tape bill must hold. A wrong restoration or expansion can break them. | A separate geometric inverse, unmodified PR985 output comparison, actual tape meters, and two target-dependent increments. |
| `deep_admission` | A finite case beyond the old length gate must execute correctly. The new formula alone is insufficient evidence. | Full `L=5741` word, a residual bound from the Neumann inverse, exact cancellation, and complete movement count. The old public API rejects the same dimensions and width. |
| `kernel_cases` | Tighter budgets must support the actual dirty word. A missing inner shift or wrong inverse order can corrupt output or restoration. | All ten original factor fixtures, a dense expanded-polynomial oracle, both signs from fresh states, both inverse orders, odd lowest bits, integer guards, and two physical tape heads. |
| `uniform_kernel_cases` | The stated uniform widths must admit actual coefficient preparation and execution, not only an integer formula. | Roots are rounded to the prescribed factor width. Exact interval coefficient bounds, stable margins, norm hypotheses, dense output, and restoration are checked. |
| `run_counted` | Literal array accesses must equal the charged reads and writes. Duplicate validation reads were present in the predecessor. | An array observer counts actual indexed accesses independently. It rejects the retained original and a duplicate-read mutation. |
| `test_package` | The result must run without a checkout or writable source. It must detect source drift and preserve an existing output file. | Twelve faults, a full read-only relocated replay in a path with spaces, and exact receipt regeneration. |

PR985's full original package remains byte-exact. Its power cases are
reused because the powering implementation is unchanged and extinction
depends on its norm bound. The new leaf cases own the changed admission
and signed-error transfer. The new suite does not replay unrelated
frontier or compiler packages. The selected-record checks protect the
unchanged current frontier separately.

The written proofs supply the all-size arguments. Finite cases cannot
replace the return-time induction, zero-subtree induction, common-operator
theorem, or inherited analytic and preparation hypotheses.
