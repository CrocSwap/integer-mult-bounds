# Payload involutions split a sector-3 joint space

Prepared by unpaidmoon with substantial Cursor Grok assistance. Apache-2.0.

For the historical 8-by-112 centre query, the degree-881 payload involutions
that fix Bell block `c=3` are `X_3` and `Z_{508}`. Both lie outside the
signed-permutation group classified for this block. On the explicit
commuting pair from that classification, `X_3` splits the trivial
`(+1,+1)` joint space of dimension 216 into `B_3`-invariant subspaces of
dimensions **84** (eigenvalue `+1`) and **132** (eigenvalue `-1`).
`Z_{508}` splits the same space into dimensions **108 and 108**. The
intersections of that 216-space with the four degree-881 sectors have
dimensions **42, 42, 66, and 66**.

The selected conditional kappa stays `781451/250000000`. [PROOF.md](PROOF.md)
separates the trace-formula proof from the facts that are not claimed.

## Result

The live input is the query pinned in [SOURCES.json](SOURCES.json), SHA256
`5c6c51fbffc07a683e922f17532fd90262ae9e23cc3560a696002073dd234ef3`.
`X_3` translates addresses by 3. `Z_{508}` is the diagonal character of
`3 xor 511`. They commute with each other, with `B_3`, and with the
order-64 group generated by the explicit pair

    u = (0 2)(4 6) with minus signs on coordinates 0 and 2,
    v = (0 4)(2 6) with minus signs on coordinates 0 and 4,

together with the order-16 sign group that is positive on the even
coordinates. The joint dimensions of that pair match the published c=3
table, including `216^4` on the trivial character.

`X_3` has trace `-48` on the trivial `(+1,+1)` space. Its `+1` eigenspace
there has dimension 84 and its `-1` eigenspace has dimension 132. The same
trace formula gives both eigenvalues on every other joint space of this
pair. The address trace of `Z_{508}`, and of the product, is 0 on each of
the 64 group elements, so every joint trace of those two operators is 0
and each joint space is split in half. Inside the 216-space, the
intersections with the four degree-881 sectors are 42, 42, 66, and 66, for
`(s,t)` equal to `(+1,0)`, `(+1,1)`, `(-1,0)`, and `(-1,1)`. Summing those
intersections over every character and every joint eigenvalue rebuilds the
four 1024-dimensional sectors.

This is a proof. The address counts are exhaustive on a set of 512
elements, once by enumeration and once by an affine solve, and the two
counts agree. It is not a stopped search and not a claim that every
operator outside the signed-permutation group splits these spaces.

## Scope

Catalogue card `formal-interface-lemma` asks for a formal interface binding.
The live question is open question 2 of
[PR #6965](https://github.com/CrocSwap/integer-mult-bounds/pull/6965),
recorded in discussion comment
[19507308](https://github.com/CrocSwap/integer-mult-bounds/discussions/1166#discussioncomment-19507308).
The predecessor classifies signed permutations only. This package starts
from the payload involutions named in Krzysztof Wojt's degree-881
certificate and tests the ones whose block is sector 3.

It does not redo that signed-permutation census, and it does not compute a
characteristic polynomial. The 16-dimensional weight-4 calculation left
open by #6965 stays open; the trace table here only records that each
8-dimensional weight-4 joint space meets the four sectors in dimension 2.
The 216-dimensional `c=1` polynomial is a different block.

for kappa `781451/250000000`.

## Reproduce

From the repository root, with CPython 3.12 and the standard library:

```sh
python3 -B -W error research/c3-payload-sector3-split/verify.py
python3 -B -O research/c3-payload-sector3-split/verify.py
python3 -B scripts/research_package.py --package research/c3-payload-sector3-split --check-only
```

The direct marker is `PASS_C3_PAYLOAD_SECTOR3_SPLIT`. Acceptance uses
explicit checks, so `-O` does not skip them. The run rebuilds the 64
symmetries from the query, checks commutation on every port and every
address, and evaluates the joint trace formula. On the measured host that
takes about five seconds. Rejection controls are a translation by 1, an
address character other than 508, a truncated sign average, the identity
trace on the same 216-space, and a coordinate transposition. No Lean,
Docker, degree-881 coefficient replay, or selected cold replay was run.
