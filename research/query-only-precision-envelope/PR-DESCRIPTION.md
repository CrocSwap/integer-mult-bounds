## What changed and why

The published 3,095-event QUERY-only caller removed the proposed QSELF
opcode, but its exact endpoint identity did not establish intermediate
precision or admit rounded child returns. This package supplies a
source-specific prefix/suffix envelope for that caller with every source
cut of its 18 current 71,144-event native calls included.

Under explicitly retained complete-fibre unitary, total primitive error
and compiler contracts, the exact rational certificate gives
M_ctx<2^355, Sigma_ctx<2^576 and Gamma_ctx<2^337. Current source/threshold
checks imply the conditional format F=p+D, W=p+h+2D+3 for D>=19, five extra
fractional bits below 19, and W+26 temporary bits. Every arbitrary helper
input and incoming native-call defect is included. The proof retains the
wrapper's D-dependent admission cost.

It also locates an exact-service obstruction in the actual source:
MOVE37476 on register697, followed without another access to that field by
SCALE37480 at -2/3. A permitted one-grid child defect is nondivisible at
every F. This is an abstract contract countermodel, not a claim that the
retained MOVE implementation produces that error. The unchanged exact
scalar table physically rejects the example before public writes.
