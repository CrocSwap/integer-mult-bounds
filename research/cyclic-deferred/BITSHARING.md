# Shared completed bit cores

The input is the immutable minimal-V scalar schedule included by an664 in
PR128, built on Swapnil Jain's round-seven word. The standalone bit package
reconstructs the physical event word from that pinned schedule, checks actual
V chronology and frame geometry, and replays every formal source/dirty column
in both directions. It does not claim to regenerate an unpublished optimizer
that originally selected the minimal-V schedule.

For h=23 use the inherited bilinear form H=9I-J. A triple indicator t has
H-norm 18. Its exact rank-one projector is

    P_t = t (3 t^T - 1^T) / 6.

Distinct triple projectors annihilate each other when the triples meet in
exactly one point. For an original role with gauge projector P_sigma, a
completed core has residual D_E with

    E = (I-P_sigma) tensor P_t,
    D_E = [[I-E,E],[E,I-E]].

The reflected orientation transposes the tensor factors. If E and F annihilate
each other, direct block multiplication gives D_E D_F = D_(E+F). The same
identity holds for arbitrary physical scratch and spectators; it does not
require clean or independently distributed dirty inputs. The signed logical
word individually restores its original auxiliary coordinates before the
framing residual is applied.

The exported witness is checked independently for complete triple coverage,
pairwise H-orthogonality, exact projector idempotence and self-adjointness.
No optimality claim for arbitrary constructions is needed.
