# Completed-core scratch sharing

Under the inherited PR104/PR117 interfaces, this finite construction certifies

\[
T(n)=O\!\left(n(\log n)^{1-\kappa}\right),\qquad
\kappa=\frac{12310001053253}{10^{17}}=0.00012310001053253>2^{-13}.
\]

The contribution shares complex scratch banks **between completed cores**
whose outer triple labels are binary-orthogonal. An explicit partition of all
2024 triples into 83 groups of 24 and four groups of eight reduces the
allocation to 13,187,822 original streams. Every internal operation is retained,
and each partial group pays an explicit signed complement transform for every
shared role. The complex supplier is PR117's regenerated all-disjoint producer
with 28,705 roles. The bit supplier is the included improved deferred word
with its stopped opposite-bank compiler.

The result is conditional. [PROOF.md](PROOF.md) gives the composition, actual
phase signs, new allocation and precision argument. [certificate.json](certificate.json)
contains the complete exact profile, moment bounds, three row reserves and
all 47 strict constraints plus seven saving margins. No unconditional
multiplication theorem or full expanded Gaussian tape-word execution is claimed.

## Verify

From the repository root:

```sh
python3 research/completed-core-sharing/verify.py
```

Requirements: Python 3.10+, a C++17 compiler available as `c++`, and a POSIX
environment. Only the standard library and local pinned sources are used.
The verifier does not install packages or access the network. Do not use `-O`.

The default command verifies every frozen input hash, then uses a temporary
copy for all generated files. It regenerates the PR117 complex producer and
legal carrier matching; checks the final bit frame geometry; replays all
1,076,483 literal events on all 32,408 formal columns forward and reflected;
and compares decompressed event bytes to the saved word. It reconstructs the
87-group partition and checks its actual phases, explicit signed complement
bases, complete child list, opposite-bank algebra and signed core transfer.
The public PR117 frame ledger alone omits scalar signs; the included separate
source-to-target and inverse-word proof supplies the required scalar linkage.

All arithmetic bounds are rational. A separate 64-term/degree12 interval
calculation checks the accepted 50-term/degree8 arithmetic. No floating root
is a proof input. Corruption controls reject a coverage-preserving
nonorthogonal group swap, a missing bit scatter, an omitted paid child and
the next kappa grid point. Submitted files remain read-only; gzip timestamps
and elapsed timings are not treated as mathematical data.

## Profile and scope

The exact complex saving is 0.0001231305483517511358. The coarse bit saving
is 0.0001245362098479795607; the stopped ordinary wrapper gives
0.0001244501335381315811393. The assembly uses beta=10^-6, eta=10^-16 and
the original-prefix margins. Maximum children 528 and 529 require halving
degrees 367 and 9. All three row reserves are included: degree 22000 exceeds
the required exponent by 20773/25. PR117's scalar count is retained in
G=2,401,613,632 and its conservative semantic guard.

The proof consumes the transparent individually restored dirty core, paid
copied-center/bit adapters, stopped ordinary-leaf interface, semantic precision,
ordered-affine streaming, analytic/prime setup and exact recovery contracts.
The verifier regenerates PR117's complex producer; its separate bit producer
is not used. The full Gaussian compiler is supported by the stated operator
proof and inherited interfaces. Full repository verification is a separate
command; this script is the focused contribution check.
