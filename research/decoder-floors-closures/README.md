### 2.1 Tools (PROVEN)

**Lemma G (PUNCT5 §2).** Call `s ∈ K` *good* if the live lines orthogonal to `s` span `s^⊥`. Then every `N` in the `N`-space of `M` satisfies `N r_s = λ_s r_s` with `λ_s = M_ss/|r_s|² ≠ 0`. *Proof.* `r_tᵀ N r_s = 0` for live `t ⊥ s`, so `N r_s ⊥ s^⊥`, so `N r_s ∈ Q r_s`, and `r_sᵀ N r_s = M_ss ≠ 0`. ∎ If the good lines span `Q⁸`, `rank N = 8` and every decoder has `m ≥ 8` terms. Good lines fail to span iff they lie in one rank-7 flat `F*` (8 `W`-types).

**Restriction Lemma (PUNCTTHEORY §1).** For `K′ ⊆ K` with orthogonal projection `π` onto `span K′`, `x′_j = π x_j`, `y′_j = π y_j` is a decoder of `K′` with `rank B[R_j ∩ K′, A_j ∩ K′] ≤ rank B[R_j, A_j]`, so `cost(K) ≥ cost` of the restricted decoder; merging proportional `x′`'s (or `y′`'s) does not increase cost; an orthogonal live `k`-set in `K′` forces `≥ k` terms. ∎

**Merging-template bound (PUNCT5 §3).** For pairwise non-parallel `x`'s whose `d ≥ 2` sides are rank-7 flats, `Σ_x d ≤ m + β` with bracket `β = Σ_{sides with d ≥ 2}(d − 1)`; same for `y`; hence `cost ≥ 9m − 2(m + β) = 7m − 2β` for every `m ≥ rank N`; `m = 8` is the worst case. Valid while every `d ≥ 2` side is a rank-7 flat (rank-6 flats need `≥ 48` punctures for `d = 2`), i.e. `p ≤ 47`. Arithmetic (CHECKED, `c1`): `β ≤ ⌊(55 − (need − 1))/2⌋ = 8` for `p = 45, 46, 47`, so `7m − 16 ≥ 40 ≥ need(p)`.

**Monotonicity in `P` (PUNCT5 §RUNS2, PUNCT-MID §1).** `P` enters the Lemma-G-failure CNF only through `|S| ≤ P` and the option filter `|e| ≤ P` (options inclusion-minimal); a model at `P′ < P` with option `e` yields one at `P` with a minimal `e′ ⊆ e`. So UNSAT at `P` covers every `p ≤ P`.
