# Two-image prefixes cannot be isolated with returned dirty helpers

**An all-width completed-interface obstruction; no new κ.**

The original and phase-repaired two-image block-3 prefixes are invertible
and have useful exact rank properties. This contribution proves a different
boundary: neither can be a standalone output on one arbitrary input while
every arbitrary dirty helper is returned unchanged, in the fixed uniform
linear word model below. An explicit triangular dirty-target port remains
available and is not contradicted.

The source prefixes are

`F_f = C_f(U_f+2V_f)C_f`, `F'_f = C_f(P_f+2Q_f)C_f`,

where each base letter is tensorized before mixing. [PROOF.md](PROOF.md)
pins the actual bit maps and phase repair. Their common determinant profile is

`|det F_f| = |det F'_f| = 3^((8^f+4^f+2*2^f)/4) * 5^((8^f-4^f)/4)`.

Every completed uniform word with fixed register mixing, tensor powers of
fixed invertible base address matrices, and any unitary paid operations
has **affine normalized log determinant** in f. The source profiles violate
that invariant at widths one, two and three:

`D_3 D_1^64 / D_2^16 = 3^52/5^16 != 1`.

Thus adding more unitary calls or more returned dirty banks cannot implement
that isolated interface. Independent unitary helper outputs cannot absorb
the missing volume either. This proof even grants arbitrary fixed invertible
base address letters; the source engine permits fewer free operations.

The written proof also classifies **every fixed complex pair of nonzero
mixing coefficients** for these source permutations. Replacing 1 and 2 by
alpha and beta cannot repair this completed contract: singular ratios fail
invertibility, and all other genuine two-image mixtures have a nonaffine
profile. Single-image cases remain available. This is not a claim about
arbitrary pairs of address permutations.

The conclusion does not exclude clean initialized workspace, omitted or
nonunitary compensating outputs, width-dependent mixing, nonlinear routines,
a different global continuation, or the general five-in-fourteen problem.
Dugongue's existing two-input triangular port keeps F'_f off diagonal and
unitary maps on both diagonal channels; its determinant has absolute value
one. It supplies dependent information rather than the isolated target
considered here. No source construction or selected frontier is changed.
