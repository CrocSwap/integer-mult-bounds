# Exact sources and verification

[PROVENANCE.json](PROVENANCE.json) records the exact Git blobs and SHA-256
pins for the signed caller and directed tariff, the #7357 generated price
receipt, and exact source references for the physical application.
[LOCAL-PINS.json](LOCAL-PINS.json) authenticates package-relative inputs,
engines and receipts. The exact uncompressed #7113 caller SHA-256 is
`255d89f38cd45e38e5770f559bc43dc217e989032359768cdc7e8cdfd64b47bc`.
The package contains one compressed caller and expands it to one shared
clean replay path. The #7334 independent admission and complete signed
readback are fixed comparator inputs.

The primary exact rational prefix runner used CPython 3.12.14 and took
0.16 s. The independent interval runner took 0.04 s. Both exhausted all
nine keys under the 20-second cap and checked all 36 old endpoint columns.
The relocated replays took 0.16 s and 0.06 s and matched their exact
receipts. The physical character certificate took 0.05 s using the same
nine keys and the independent interval witnesses. Controls include
reciprocal prefix scaling, row-only and column-only shears, a signed J
inverse, and a cancelled swapped pair. The replay rejects a changed byte
in the price and caller before endpoint output.

The independent physical test counts the target stage occurrences,
checks the one-axis C eigenvalues exactly and materializes a nonzero
physical difference at b_j=−1 for each pair. A new chart, all-body
Laurent candidate, ordinary realization, precision/tape and complete
outer replay were unnecessary after exclusion. Hosted checks remain
separate from these local results.
