# Concrete routes from the theorems to a better complete contract

The actionable unit is a constructed word, recovered map or certified budget. A future κ improvement requires its **complete** caller invoice and uniform outer interface to improve. The routes below identify actual inputs, delivered objects, payment and the first useful application. They are research recipes justified by the numbered sufficient results, not claims that the current multiplier already meets every premise.

## 1. A changed helper word with a proved arbitrary-dirt response

Start from the literal `A`, `compensation`, `cleanup`, `start_extra`, `helper_final`, `warps` and `cut` fields of the pinned PR #2857 words, rather than from their rank histogram. Extract their exact response columns and source footprints. N003–N020 emit kernel charts fixing declared protected helpers; N094–N096 compute the actual effect of staged insertions, including the ordered two-insertion cross term. N097 supplies a source borrow along a verified dirty-response kernel. N099 tests every declared input/dirt column and N100 emits the compensated forward/cleanup word.

The deliverable to the next worker is a literal changed word, its complete response matrix, a proof of restored inputs and an expanded scalar/native transition ledger. A006 prices favorable and unfavorable width changes together; A008/A009 permit safe price/exponent intervals; A001 composes genuinely disjoint gains. A positive complete saving then has a quantified adapter allowance by A002–A005 and a symbolic exponent interval by A011–A018. No gain follows merely from deleting a compensation column: chart creation, inverse cleanup, source reads and frame transitions remain paid. The existing #2857 quartet is credited background, not a new instance of this route.

## 2. A consumer that repairs its actual order, or avoids repeated physical work

Use the real PR #2850 emitter/invoice and #2859 literal consumer permutation. P006/P058 derive its actual crossing phase, and P012–P019 turn that phase into finite returned-bank circuits. P091 realizes a caller-fixed correction physically, with rank charts, full operand volume and wrappers. P092 provides a completely corrected aggregate producer, not the predecessor's invalid uncorrected aggregate shortcut. P056 constructs a specific encoded assignment beyond the restricted one-bit-per-column model, with its increased controls charged.

There is also a guaranteed finite improvement independent of a speculative new caller: P080 changes each two-cell butterfly's output order to high-address then low-address after both outputs are computed. For N cells and address stride h=2ᵃ, the total return-to-zero travel drops by exactly Nh while additions, halvings, accesses and eight private real slots remain. P073 can further remove only genuine inter-record returns; P078 licenses record reordering only with disjoint supports. These are alternative emitted schedules; a frozen predecessor invoice is not silently edited.

If a real unobserved common-chart region contains several closed Q jobs, P100 replaces it by the actual phase-sum controller, with two rank-r C children and all charts paid. P098 similarly compiles a monomial wrapper run into one table, counting both its LN generation and execution. The next worker should return the changed literal emitter, full endpoint identity, new prefix grid/range bounds and actual movement/control ledger. A035–A040/A091–A095 allocate deterministic precision; A019/A056 admit only improvements surviving every integration charge. Existing all-size unit-shear #2776 and whole-word grid #2772 remain separate credited components.

## 3. A usable tensor certificate, rather than bare orbit existence

The input is an actual labelled bilinear coefficient table or a supplied finite query certificate. T006/T038 verify or recover the complete table with charged probes; T030 returns an actual common-label matching from normalized coefficients; T033–T040 construct frames, ratio maps and a decoder from explicit finite data. T081–T090 supply recovery algorithms only for their declared restricted transporter instances. No theorem assumes that arbitrary tensor isomorphism has an efficient recovery oracle, or that TI = TI_SL has been proved.

Then choose an explicit transformation: T001/T002 fuse queries while modifying the decoder; T014 aligns a tree of actual label frames; T026 prices tensor-power adapters by fibres; T041–T050 perform scalar descent with actual maps. T051–T060/T071–T080 recover exact coefficient responses from sampled or border certificates, counting interpolation, jets, roots, denominators and reconstruction. T091–T100 provide concrete matrix/convolution/residue/NTT arithmetic children with label and bit costs.

The output is a certificate with recovered maps, finite operation/bit/workspace bounds, source embedding and a complete decoder. It is a **changed tensor/block-query consumer**; the existing native C operation is linear and cannot be replaced by bilinear rank arithmetic alone. A real compatible source realization and paid native/physical adapter are required. N021–N030 can implement an explicitly factored linear response, and P088 can implement a specified binary phase matrix, but neither supplies a universal conversion from an arbitrary bilinear certificate. Evaluate the resulting actual profile through A007/A010/A024/A032/A059, keeping exact live normalization and full operand volume.

## 4. Preserve a strict reserve through precision, resources and uniform execution

Take the actual complete profile and concrete error/source bounds produced by a construction. A033–A040 and A071–A080/A091–A095 give deterministic magnitude, coupled-error, quotient and exact-output budgets; shared error symbols may cancel only when their reuse is real. A030/A086–A090 allocate fraction fields under the actual price/shared-field constraints. A063–A065 control half-rank parity and dyadic grids; they complement T064's general denominator ledger. A096/A097 output explicit scratch/recursive-space schedules, and A098 supplies a bit-growth bound for a fixed dyadic word across logarithmic depth.

For a typed recurrence, construct a positive weight certificate by A052–A055, rationalize it using A060, and charge every returning adapter with A056. A041–A049/A051/A057 then prove bounds from the actual implementation recurrences; A066–A070 retain finite bootstrap and outer losses. A100 assembles only a fully specified uniform implementation. Use the existing all-size logical caller #2753 and current storage successor map to identify the actual physical/H2/outer boundary, rather than rebuilding or ignoring that caller.
