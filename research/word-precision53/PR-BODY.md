amplification bound. Tracking each array's chronological dependencies reduces
the sufficient shared coarse/working precision from 86/145 to 69/112 bits at
margin 1/2, and from 151/291 to 117/226 bits at margin 1/16, for the complete
12-stage forward/inverse word and 40 target bits. The rounded leaf, source
restoration and all execution calls remain unchanged.

The package gives the standard componentwise-majorant proof specialized to
this interface, exact pins and an immutable selected snapshot, 20 actual source
fixture replays with exact restoration, 144 dense oracle prefix comparisons,
an independent 4,680-word / 279,616-corner check, and 13 mathematical/package
controls. All three commands in the README pass under isolated optimized
Python 3.14.5; relocation in a path with spaces passes.

These are sufficient numerical budgets, not a measured speedup, arbitrary
dirty-bit restoration, fixed-tape invoice, supplier admission or new kappa.
The source's clean low-bit capacity, phase/coefficient preparation and compiler
obligations remain. Only `research/word-precision53/` is added. Credit Chafik
Boukhalfa's source implementation and composition proof, Ali Romman's inverse
