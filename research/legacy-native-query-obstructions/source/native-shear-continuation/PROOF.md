# A coloop obstruction for native words

Work over Mat_r(F2[G]). Let each query be
H_i = I + a_i b_i^T (g_i - 1), with b_i^T a_i = 1.
Assume the complete endpoint is z I_r on arbitrary DATA input.

Suppose a_i is outside the binary span of all other query images.
Choose a binary row l with l a_i = 1 and l a_j = 0 for j != i.
Use the suffix form of the product difference:

    H_1 ... H_k - I = sum_i (H_i - I) H_(i+1) ... H_k.

This identity uses chronological factors in the written left-to-right
order. Left multiplication by l removes every term except i. Thus

    (z - 1) l = (g_i - 1) F

for a finite row F over F2[G]. Set H = <g_i>. For each set Hx, sum
the group coefficients of each entry. Left multiplication by g_i
permutes Hx, so every entry of (g_i - 1) F has sum zero on Hx.
At least one entry of l is one. If z is outside H, the terms 1 and z
lie in different sets Hx. That entry of (z - 1) l has nonzero sum
on each of those two sets. This is a contradiction.

The sets Hx are orbits under left multiplication by H. In standard
coset terms, they are right cosets. The proof does not need z to be
central. A transpose argument gives the same obstruction for a query
covector outside the span of the other query covectors.

The idempotent hypothesis gives a stronger result: a coloop forces
g_i = z. Put U = span_(F2){a_j: j != i}. Every other query and its
inverse preserve the extension of U to F2[G] and induce identity on
the quotient. The endpoint z I_r preserves this space. Isolate the
i-th query by multiplication by the other inverse factors. This query
must also preserve U. Its action on the nonzero quotient class of a_i
is multiplication by g_i, because b_i^T a_i = 1. The endpoint acts
on that class by z. A binary functional with l(a_i)=1 and l(U)=0
therefore gives g_i = z in the group algebra.

For a nonidentity rational rank-one ADDRESS update in dimension m >= 2,
the fixed subspace has dimension m - 1. Every power fixes that subspace.
The map -I_m fixes no nonzero rational vector. Hence -I_m is outside
the cyclic subgroup generated by that update. Every successful word
with this endpoint therefore has no image or covector coloop.

# Four negative plane queries and one positive query

There are three complete productive DATA roles and plane endpoint -I2.
Apply the determinant-sign homomorphism to dual numbers
R = F2[e]/(e^2): a negative determinant maps to 1+e, and a positive
determinant maps to 1. A negative query maps to I+e N_i. Since the
endpoint has positive determinant, the word gives

    sum_(negative i) N_i = 0.

Write the four negative projectors as N_i = a_i b_i^T. If A has those
four image columns and B has those four covector rows, then AB = 0.
Binary field ranks give rank(A) + rank(B) <= 4.

All five query images must span the three DATA roles. Otherwise a
nonzero row that kills every image would stay fixed through the word,
contrary to the nonidentity complete endpoint. The covectors must also
span the three roles, by the transpose argument.

One positive query can add at most one dimension to each span. Thus
rank(A) >= 2 and rank(B) >= 2. The rank inequality forces both ranks
to equal two. The sole positive image is outside the span of all four
negative images. It is a coloop, contrary to the preceding lemma.

This excludes every four-negative, one-positive five-query plane word
on three complete productive roles. No common Gram matrix or finite
ADDRESS subgroup is assumed. This argument does not yet exclude the
two-negative, three-positive or all-positive five-query cases.

# Target subset ranks

Expand a k-query word into its 2^k selected and unselected branches.
A selected query contributes N_i g_i. An unselected query contributes
I-N_i. Every branch with a nonempty selected set has binary scalar
coefficient rank at most one. Thus an r-role coefficient at a nonidentity
ADDRESS endpoint requires at least r branches at that endpoint.

There is a stronger bound. Fix the last selected query i. All branches
in that class have image in the same line: it is the image a_i after
the fixed trailing unselected factors I-N_j. The sum of that class
therefore has rank at most one. The endpoint coefficient rank is at
most the number of distinct last selected query indices in its branches.
The first selected indices give the same bound for covectors. Three
complete roles therefore need at least three distinct first selected
indices and at least three distinct last selected indices. These are
necessary ADDRESS support conditions. They do not certify a DATA word.

# Scope

These statements are native word obstructions. They give no new word,
supplier, integer-multiplication lower bound, or kappa gain. Interspersed
free binary DATA changes must first be absorbed into effective projectors.
The helper extension is proved and audited separately in
independent-audit/HELPER-AUDIT.md. No external theorem or
global novelty claim is used. AI assistance was used in this proof.
