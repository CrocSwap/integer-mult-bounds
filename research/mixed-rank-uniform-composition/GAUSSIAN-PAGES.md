# Physical coefficient producer and its integer checks

[The coefficient generator](gaussian_pages.py) computes the one-axis narrow band H, broad band U and scalar recovery diagonal on the inputs p, P, r, t and W from the grouped construction. Here r is the odd source length, t the dyadic target length, P the working precision, and W the signed physical cutoff. The output contains integer numerators at common denominator 2^P. It uses no host exponential or root table to produce these words. [The page check](check_gaussian_pages.py) contains the independent numerical comparison.

For a target row v, visit all signed offsets −W through W. Write v+offset = q+kt with 0 ≤ q < t. Test the interval [r(2q−1)/(2t),r(2q+1)/(2t)) for its first nonnegative integer j. A hit gives the original column j with q=floor(tj/r+1/2). Set b=tj−rq and z=r·offset+b. For a selected source, the broad coefficient is exp(−π z²/(t² α²))/α. For a selected target with q different from v, the narrow coefficient is exp(−π α²(z²−b²)/r²). Each exponent here is nonpositive. The image at the same address has exactly one narrow diagonal, including at a hole. The broad operator sends each unselected input column to itself, while selected columns may contribute to every target row. The signed occurrence number k stays with the returned coefficient. Zero numerators add zero on all paths. The recovery factor at a selected q is exp(π α² b²/r²), and is one elsewhere. These are precisely the unnormalized entries of U,H,D in [the grouped proof](GROUPED-GAUSSIAN.md). The required public factors are U/a* and D H⁻¹/a*, with original-source insertion and extraction as described there. There is no implicit Fourier or normalization factor in the emitted pages.

The integer width selection uses α=ceil(sqrt(ceil(log₂(16p)))). The private evaluator bounds π by Machin's identity and alternating arctangent terms. It halves a nonnegative argument until it is at most 1/2, bounds the alternating exponential terms on an integer grid, and squares the interval with outward endpoints. The reciprocal of a positive interval gives a recovery factor. For negative exponents, if 3 z ≥ (P+3)·denominator then exp(−π z/denominator) is already less than 2^(−P−3), so zero is a certified lower numerator. Otherwise it emits a downward grid value after an integer check shows that the upper endpoint is at most two public grid units above that value. It refines the private grid if necessary. Thus an exact grid equality never requires a transcendental comparison. Library decimal computations occur only in the independent test.

The numerical precision used privately stays polynomial in p. In the negative case the cutoff bounds the unreduced argument by O(P); the positive recovery argument is O(log p). Repeated squaring has O(log P) stages. On [0,1] it multiplies an absolute interval width by at most two per stage. The alternating series, π enclosure and elementary rational multiplications introduce polynomially many private-grid units. Inverting exp(−O(log p)) can amplify this width by only a polynomial in p. Consequently P+O(log p) private bits above the binary point suffice eventually. Integer coordinates have O(log t) bits, and the reduction uses their exact signed differences. Every coefficient can therefore be computed in poly(p) fixed-tape bit operations. The complete one-axis setup can stream one row at a time. The integer row test sums encoded |(I−H)·2^P| and checks both Lean hypotheses before admitting a page. Its total across all axes and signed offsets is O(d t_max W poly(p))=2^o(p). The width selection and real row-gap proof give eventual admission. Global coefficient archives are individually sublinear. Only polynomial-size local tables travel into the grouped kernels. The Python implementation illustrates the row generator on arbitrary integer parameters. Its bounded caches are optional, and none of its Python indexing or host arithmetic supplies the fixed-tape movement proof.

`python3 check_gaussian_pages.py` exercises every row and column of two fine source axes at the same base precision p=6 and at external coefficient precision P=36. The exact interval requirement (1−1/(2p²))t < r ≤ (1−1/(4p²))t holds for both 1013/1024 and 2029/2048. Their target widths differ by one. It checks all narrow integer row guards, all recovery-diagonal enclosures, identity hole columns, selected contributions at holes, both signed wrap directions, finite broad row and column sums, and independent high-precision entries including addresses where the encoded coefficient is zero. The comparison uses 82-decimal-digit arithmetic with π obtained by a separate arithmetic-geometric mean iteration. An additional 3/4 control retains separate nonzero occurrences mapping to the same slot. It checks the signed occurrence stream on a short period. At p=6, row 32767 of the inadmissibly close 65535-to-65536 map fails the required inverse margin. The same row admission function used by the product probe rejects it. These are local coefficient and acceptance tests. They do not imitate the much larger all-size geometry or execute integer multiplication.
