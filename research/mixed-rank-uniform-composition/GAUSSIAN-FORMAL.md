# Formal meaning of the Gaussian and synthetic checks

Lean 4.34.1 with its bundled Std kernel-checks HaloRadius.lean, RationalInverse.lean and SyntheticBridge.lean. The files use ordinary signed integers and finite lists. They do not use an external numerical oracle.

## From the fixed physical band to HaloRadius

For public numerical precision P let D=2^P, let H be the generated dyadic narrow band including the exact identity hole rows, and let E=I-H. For a signed integer lift of a physical target row i, give the Lean row a list of pairs (D E(i,j), j). The index j includes the appropriate signed periodic lift of its occurrence and all spectator coordinates. The argument admits zero coefficients and arbitrary signed coefficients. The sum of their absolute integers is the encoded row mass. The row-gap proof gives mass/D <= 1-1/B where B=16p0² and p0 is the geometric precision. Here a is the single dyadic normalizer a*=2^ceil(log2(p0^100)), with a>=B. Thus the two required integer checks hold:

    D + B·mass <= B·D,     D + a·mass <= a·D.

The first bounds convergence and the second bounds the actual nonlinear iterate. Input words x and all iterates z are signed Gaussian numerators at common denominator D. The literal update in the shrinking reference takes a fixed x at each sweep, forms x/a+E z, then truncates real and imaginary parts toward zero after the sum. On the integer numerators this is exactly

    tdiv(D·x + a·sum_j (D E_ij) z_j, a·D),

component by component. Since H itself already uses the same grid, the consumer's extra coefficient truncation is exact. The separately proved difference from the ideal, untruncated Gaussian is still required and is included in GROUPED-GAUSSIAN.md. Using rounded higher-precision input coefficients would require adding the predecessor's coefficient perturbation allowance. [Physical recurrence](https://github.com/CrocSwap/integer-mult-bounds/blob/e54523517d0f03e58352e647c403a5af3e525a57/research/shrinking-reference-halo/PROOF.md#L88-L120)

* updateBound, eachIteration and everyAxis prove that the actual component-l1 radius remains at most the original bound, throughout any number of iterations and sequential axes.
* finiteNeumannError bounds the difference between actual and exact finite Neumann iteration, at every integer input and iteration count k, by 2B units of the input grid (the Lean inequality clears the common denominator (aD)^k). It derives the two-component truncation residual using signed division/remainder and the original band update.
* spectralNumeratorError bounds the final difference after any list of axes by e+2B·length grid units, with initial discrepancy e. It proves linearity and contraction for the exact finite polynomial, and it reanchors the numerical error at the actual input to each rounded axis. It does not assume linearity or nonexpansiveness of a truncated map.
* geometricTail proves that a rational fixed point y/s of the normalized inverse differs from the k-term polynomial by at most (max_i |y_i|/s)·(m/D)^k in input-grid units, where m bounds encoded row mass and the norm is maximum component-l1. The exact equation in Fixed is precisely aH(y/s)=x. Existence of this rational fixed point follows outside Lean by strictly dominant H, finite rational elimination and arbitrary rational input. Its size is at most the input's radius because a delta>=1. Thus k=16p0^4 gives exp(-p0²) as in the written proof.
* completeInverseError composes the actual rounded updates, the exact finite-polynomial contraction, and the geometric tail into one all-axis error estimate against the actual normalized inverse equations. Choose a common mathematical denominator S for the finite family of exact rational intermediate values. It is absent from the running machine. Take m=max_i mass(row_i), a row-gap reciprocal bound B, and one grid unit for each residual tail. On the geometric parameter family, (m/D)^J<=exp(-p0²) and the incoming numerical component-l1 magnitude is at most a constant times D=2^P, so one grid unit eventually suffices on all axes. With input discrepancy e the formal result gives e+(2B+1)·(#axes) units for the whole exact inverse trajectory before the separate D(j) diagonal. This conclusion includes numerical error at the actual incoming argument, coefficient-exact Horner and every finite truncation. It is not only a list of single-axis certificates.
* physicalCone is the exact integer containment for a signed offset in [-W,W] when a lifted interval is reduced by W at each end. savedRectangle explicitly uses the fact that the incoming zeroth iterate is zero, so a J-step update needs only (J-1)W input neighbors. It proves equality of *both* the actual rounded and the exact finite iterations on the target, when given the same physical band rows and original values on that cone. Source fields may differ off the saved rectangle. The permitted period lifts are unique because L+2(J-1)W<t_i eventually.
* disjointSplice proves the maximum of the two errors for disjoint kept and discarded outputs with the same scale and denominator. In the application the keep predicate requires all active coordinates to lie away from their core boundaries. The first failed coordinate and its side determine the physical return key. Actual sorting, unique-key checks and movement are the written/source proofs in GROUPED-GAUSSIAN.md.

Every printed theorem in HaloRadius uses a subset of propext, Classical.choice and Quot.sound. The operator norm calculation for the actual exponential coefficients, complex Toeplitz accretivity, Gaussian Poisson identity, prime theorem, dense five-factor core, and finite-tape movement costs remain outside these kernel theorems. RationalInverse.lean proves existence and uniqueness of the exact mathematical solution. The tape machine uses only its finite Horner sweeps.

## Existence, uniqueness and the complete numerical error

RationalInverse.lean imports HaloRadius.lean. Give every coordinate of a full finite rectangle any enumeration by `Fin n`. Lifted occurrences from a signed periodic band can repeat the same coordinate. The dense integer entry is the sum of all its occurrence weights. `physicalSum` identifies its row action with the actual list recurrence. `entryNorm` bounds its absolute row sum by the original term list mass. These definitions include the true zero bands on holes and all signed aliases.

`schurDominant` proves that fraction-free elimination of a positive diagonal pivot preserves strict row dominance of the remaining integer matrix. `solve` uses this fact to solve every integer right-hand side with a positive common rational denominator. In `physicalDominant` the matrix is exactly D I minus the collected integer entries of E. The generated row inequality gives strict dominance. `inverseExists` combines the real and imaginary integer solutions and the normalizer a. `inverseContraction` proves that every solution has actual component-l1 radius at most its input radius, by using a coordinate with maximum radius. `uniqueStep` cross-multiplies any two candidate solutions and proves that their difference is zero. The construction extends through every axis, with a common rational denominator for the reference only. `uniqueTrajectory` gives equality of results at different denominators. These dense mathematical witnesses never enter the fast machine.

The geometric tail is also checked without a transcendental inequality. If D+B m ≤ B D for the maximum row mass m, `halfInOneBlock` proves 2 m^B ≤ D^B by using the first two terms of (m+(D−m))^B. `poweredTail` gives 2^h m^J ≤ D^J for J ≥ B h. Set B=16p₀², h=p₀² and J=16p₀⁴. For all sufficiently large p₀ the input grid numerators have radius at most 2^(p₀²) because P=Cp₀ for a fixed C. `fineGaussianInverse` then proves existence and uniqueness of the exact normalized inverse output of any such list of physical bands, and bounds the full rounded computation by (32p₀²+1) times the number of axes, in units of its working grid. Its premises are the two integer row inequalities, the input bound and the executed sweep counts. The written estimates for the coefficients generated by the physical narrow Gaussian prove these integer row inequalities. No assumption of a given inverse, exact trajectory or finite-tail estimate remains in this theorem. The comparison with the untruncated transcendental Gaussian and the independent dense/core splice are still the written bounds.

To check the local import, run the following in the package directory with `lean` from Lean 4.34.1 on PATH. The generated .olean is a local build output. The printed conclusion for `fineGaussianInverse` lists only `propext`, `Classical.choice` and `Quot.sound`.

```sh
lean -o HaloRadius.olean HaloRadius.lean
LEAN_PATH=. lean RationalInverse.lean
lean SyntheticBridge.lean
```

## From the P104 endpoint to a synthetic butterfly

SyntheticBridge represents signed Gaussian numerators and defines the two C entries by multiplication by 1+i or 1-i, each with denominator two. D's selected bit contributes the exact quarter-turn i. The external b=(1-i)/2 has its own denominator two per slot. The numerator of the actual operator b^h D C^tensor(h) D therefore has common denominator 4^h. clearedCharacter proves that the resulting numerator equals 2^h times the usual +/- Hadamard character in every row and column and at every size h. The resulting coefficient is the signed 2^-h. anyInputs sums this equality on arbitrary Gaussian numerators. Both depend only on propext, Classical.choice and Quot.sound. The native compiler's proof of the C^tensor(h) endpoint and the physical-grid implementation of that computation are separate from this scalar/phase theorem.
