# Exact finite exclusion

Let the cleanup be an indexed sequence O_0,...,O_(m-1). For every ordered pair (a,b), collect every index i with O_i = ADD(a,b,q_i). A target-unread corridor is two such endpoints i<j for which there is no k in (i,j) with O_k = ADD(c,a,r). The tested optimization class additionally prohibits scaling a and originally bounded updates to b. Those extra restrictions can only shrink this set.

The forward census lists all combinations of indices in each ordered-pair bucket. It computes R(i,j) = {k : i<k<j and O_k explicitly reads a}. Thus a nonempty R(i,j) certifies that this endpoint pair is outside the class, independently of its coefficients. The pinned word has 6,574 ADDs, 6,463 buckets, maximum multiplicity two, and 111 pairs. RESULT.json gives the minimum, maximum and cardinality of R(i,j) for each. The verifier recomputes the full certificate, and all 111 sets are nonempty. These exhaust every possible endpoint pair; no length or state cap remains.

For the separate backward algorithm, the epoch of register a counts explicit reads of a encountered so far while scanning in reverse. Two occurrences of the same (a,b) have the same destination epoch exactly when no explicit read of a lies strictly between them (the frozen word has a != b). The latest remembered read while scanning backwards is the first read in forward order. The independent algorithm checks both absence of same-epoch repetitions and agreement of these witnesses. The frozen multiplicity-two check makes its adjacent-occurrence enumeration equal the full pair census.

The class has useful positive members. If b is unchanged inside a target-unread, unscaled-a corridor, combine its endpoints into a += (q+p)*b. If the sole source change is b += r*c, remove the first endpoint, retain that source update, insert a += -q*r*c immediately after it, and use a += (q+p)*b at the last endpoint. The discrepancy removed at the first endpoint is q times the old b; after the correction and final update, its net contribution is q times old b plus p times new b, exactly as before. No other output can observe the intermediate discrepancy because a is never explicitly read. Other additive writes to a preserve the discrepancy. Zero coefficients are omitted and every emitted update is paid.

The verifier plants three strictly cheaper cases, evaluates both sequences on every rational basis column, and requires the backward oracle to detect their unread corridor. Conversely, a += b; c += a; a -= b cannot be replaced by c += a: input (a,b,c)=(0,1,0) yields (0,1,1) originally and (0,1,0) after invalid cancellation. This explains the restriction without asserting that every read prohibits every more general rewrite.

All facts here concern the fixed literal macro stream. Neither the argument nor the certificate is a global cleanup lower bound or a proof about arbitrary commuting, refactoring, or introducing additional wires.
