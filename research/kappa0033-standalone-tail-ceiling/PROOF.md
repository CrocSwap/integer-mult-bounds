# A ceiling for one declared standalone eight-H17 completion

This is a theorem about explicit moment profiles and a declared cost grammar. It
uses no physical program as a public hypothesis. The local resource whose budget
motivated these parameters remains a separately hashed, unadmitted local source;
its unreleased words, operations and 14-input derivation are excluded.

Put `t=1−C`, `f_C(r)=r^t` for positive integer r, and define

```
P = 6611 H1 + 1236 H2 + 1530 H3 + 381 H4 + 120 H5 + 8 H8,
H = 84 H4 + 21 H7 + 117 H8 + 954 H9,
T = H + 240 H25.
```

The notation `n Hr` means n complete rank-r jobs in a scalar moment sum. All 240
H25 targets are an **unearned optimistic upper allowance**. This definition neither
constructs those targets nor admits a physical/native/ordinary/precision/compiler
or outer implementation.

Assume a completion independently pays eight positive whole H17 jobs, with no new
productive credit for them. It may also pay any additional nonnegative work,
lose targets or impose any reserve `rho>=0`. More generally let P' dominate P
coefficientwise and T' be coefficientwise no greater than T. Its necessary moment
margin is bounded above by

```
(1-rho) T'(t) - P'(t) - 8*17^t <= T(t)-P(t)-8*17^t = A(t).
```

All moment terms are positive, so these dominations preserve the inequality. The
eight-H17 cost is an explicit protocol premise. There is no assertion that every
cache advance or decoder must pay it. Fused/reused operations, new observations,
changed encodings and changed profiles remain outside this premise.

**Theorem.** For every `.0033<=C<1`, `A(1−C)<0`. Consequently every completion
satisfying these profile bounds and the eight independently paid H17 premise
fails its necessary strict moment test throughout that interval.

## 2. Elementary anchor cost

The first three binomial terms give

```
(17/16)^100 = (1+1/16)^100
 > 1 + 100/16 + 4950/256 = 6806/256 > 17.
```

The first inequality is strict because omitted terms are positive. Hence
`17^99>16^100`, and `17^(99/100)>16`. At every `0<=C<=1/100`,
`17^(1−C)>=17^(99/100)>16`. Both numerical anchors lie in this range. In particular
at C0 the eight declared tails cost more than 128. Therefore

```
A(1−C0) < 43−128 = −85 < 0.
```

The inequality `8*17^(1−C)>128` is used only at these small-C anchors. It is not
claimed for all C<1. The next argument supplies the entire stated saving interval.

## 3. Exact scalar regrouping and full-domain extension

Cancel common paid and target ranks:

```
R(t)=T(t)-P(t)
 =240*25^t+954*9^t+109*8^t+21*7^t
  -120*5^t-297*4^t-1530*3^t-1236*2^t-6611.
```

With `A(t)=R(t)-8*17^t`, normalize by the positive factor `6^t`:

```
A(t)/6^t
 =8[(25/6)^t-(17/6)^t]+232(25/6)^t
  +954(9/6)^t+109(8/6)^t+21(7/6)^t
  -120(5/6)^t-297(4/6)^t-1530(3/6)^t
  -1236(2/6)^t-6611(1/6)^t.
```

The checker verifies the regrouping by exact integer coefficient dictionaries.
The pairing of eight H25 terms with eight H17 costs is algebraic grouping only.
It does not match physical targets, establish a fusion identity or earn credit.

For fixed t>0 define `phi_t(r)=(r/6)^t log(r/6)`. On r>6,

```
d phi_t(r)/dr = (r/6)^t [1+t log(r/6)]/r > 0.
```

Consequently the t derivative of `(25/6)^t-(17/6)^t` is strictly positive. Every
other positive term has base above one, while each subtracted term has base
below one. All of their t derivatives are strictly positive. Thus `A(t)/6^t`
is strictly increasing on `0<t<1`.

Let `t0=1−C0`. For `0<t<=t0`,

```
A(t)/6^t <= A(t0)/6^t0 < 0,
```

so `A(t)<0`. This proves the theorem for every `.0033<=C<1`. It uses a separate
analytic monotonicity proof, not interpolation or a numerical sweep. Reserves,
additional paid work and lost targets only lower the possible margin.

## 4. Additional-paid variants and limits

Eight additional H1 charges change either anchor budget by exactly −8 because
`1^t=1`; no new power evaluation is required. Such a bill dominates P, so the same
interval theorem applies. This observation does not identify or admit any newly
released physical word. Conversely a genuinely cheaper base bill, extra targets,
fusion that avoids the eight separately paid jobs, or another grammar changes the
premise and requires a new complete account.

At the two small-C anchors, even three independently billed H17 jobs cost more
than 48 against a budget below 43. Thus at most two are a necessary quota before
any other decoder cost. This is only a budget quota, not a claim that two suffice
or an information/rank lower bound.

There is no universal κ/circuit barrier, rank-minimality result, impossibility of
free fusion, complete decoder, target admission, compiler/precision/stock/outer
result, selected-record change, independent human approval or formal-kernel proof.
The user's goal of an achieved conditional κ>=.0033 remains open.
