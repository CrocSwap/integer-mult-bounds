## 1. Exact question, prior work and claim

at width one. `check_a6.py`/`a6lib.py` add owned-rise and sampled width-two

method as new. The missing implication addressed here is the literal
connection from **this** word's typed raw MOVE occurrences and exact frame
convention to the completed current coded, once-rounded physical provider.

For every one of the 6,323 raw MOVE occurrences, let `a,b` be its actual
current/return frame indices, `r=|dim(b)-dim(a)|`, and `T_b T_a^-1` its
width-one operator. The binder produces the actual owner and an authenticated

with positive `f<=t`, the exported `RoundedMove` satisfies the preceding
whole-MOVE theorem for

    U = (T_b T_a^-1)^(tensor f),

with all spectators, rows, coefficients and absolute phase retained. Public
input components may be arbitrary signed h-bit grid integers. It returns
exactly the componentwise once-rounded `R_Delta(Ux)` if the final h-bit
result fits, and rejects true final overflow before public commit. All source,
disjointness, valid-return and physical-provider premises remain explicit.

This is a raw local occurrence provider. It does not replace an expanded

and owned-ascent policy are not adopted as global framework theorems here.

## 2. Source convention is established before portability

The retained #6936 `native.py` implements precisely:

    chart(i) = canonical_frame(9, frames[i])
    lower_child(chart(a).adjoint().then(chart(b)))

`adjoint(frame(a)) + frame(b)`. Thus `T_a^-1` acts first and `T_b` second.
`a6lib.py` separately defines that same `T_b T_a^-1` convention from dense
permutation/phase tables, and uses the positive normalized Gaussian

    C = ((1+i)I+(1-i)X)/2.

The actual upstream retained compiler and verifier are byte-identical to

`166841a037f069249f6f7f6dedb89248812f59e2` and
`2c209dfa9cfade3bc20ac5fc9d876b433a147f8c`. This is an exact source join,
not an inference from similar labels. For all 1,095 frames, the replay also
checks literal equality of the independently generated canonical chronological
circuits, including the rank-zero and rank-nine endpoints.

The positive Gaussian, monomial sign convention and adjoint order therefore
agree with the preceding runtime. The source explicitly treats a width-one
global phase `i^p` as `i^(pf)` across f columns. The retained serialized
monomial implementation applies a genuine width-one call for each column,
which realizes that power. No copied width-one phase integer is installed on

## 4. Complete finite recipe family and absolute phase

For each of the 2,961 actual directed pairs, the retained compiler supplies
`L C^r R`. The new finite-family receipt checks all 18 signed Pauli images
and a complete, exactly normalized 512-position zero column against the
actual source circuit, using the predecessor's independently written
integer checker. This arithmetic does not use the compiler's tableau or
zero-state routines to compute the expected certificate.

The credited certificate lemma is: if two unitary operators have identical
conjugations on every X and Z generator, their quotient commutes with all
Z and is diagonal, then commutes with all X and is scalar. Equality on a
nonzero column fixes that scalar. It therefore determines the complete
width-one operator, including global phase; it is not only a basis-zero test.
The checker also recovers Fourier rank independently from the X parts of
the transformed Z generators and compares it with the actual dimension
difference.

For every factor, explicit shape checks validate nine binary matrix rows,
invertibility, symmetric quadratic data, diagonal/linear parity, offset
range and phase residues. The actual unchanged physical `Recipe` constructor
is invoked for both sides of every chart. Hence a formally equal but
unadmitted literal cannot silently enter the runtime. The remaining generic
recipe-to-physical-gates proof is a retained premise, not reproved by these
finite constructor checks.

Meaningful controls show both halves of the certificate are necessary:
adding a global phase passes Pauli-only comparison but fails the column;
adding input Z passes the zero column but fails Pauli comparison. A wrong
rank is rejected. Separate controls reject wrong word, owner, source hash,
Boolean aliases, truncated/reversed chronology, public/owned alias,
missing CLEAR and a wrong current frame.
