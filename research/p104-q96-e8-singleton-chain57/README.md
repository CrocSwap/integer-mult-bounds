# Prove the sharp 57-ascent bound for the Q96 E8 singleton-gauge chain family

Covers the fixed E8 basis, one singleton-output gauge, arbitrary nonzero real combinations, pair order and row rescaling.

A rational nine-epoch eight-lifetime execution attains 57. The signed-tail error and Q5 chain-versus-decoder distinction are separately checked.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `1241ed8cc50ea4395593d456dab1293cb0a588796cb76c34082fde014491c41b`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run python3 -B verify.py --census.
