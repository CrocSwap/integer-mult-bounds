# Verification scope

The four lane tests are independent standard-library programs and use exact finite fields, integers or rational real/imaginary pairs. All important checks use explicit exceptions and run under Python optimization. Expected JSON is compared structurally, not accepted merely because a program prints PASS. The immutable #4688 engine is checked by SHA-256 before importing it. The hook comparison checks six actual candidate words on all eight frozen cuts, with exact Gaussian-integer ranks. Its stored timings describe one replay and are not a research-throughput benchmark.

Root checks 27 port identities, nine arbitrary-baseline translations, nine wrong-adjoint controls, four character-decoded arrays and the full nine-query union. Quantum checks 720 exact symplectic classes, 16,384 phase tests, 3,072 quadratic-phase compositions and owned/borrowed controls. RAM checks the actual prefix in three fields, 485,088 lazy butterflies, 256 TFT roundtrips, 69,904 packed additions and 192 signed CRT products. Algebra verifies its displayed group identities, actual coordinate actions, explicit inverse, scalar specialization controls, width parity repair, tensor padding, exact moment inequalities and norm-aware guard calculations. See each EXPECTED.json for the generated receipt.

Positive all-input statements are proved in the four reviews. Finite tests supplement those proofs and check concrete implementations. Randomized floating rank estimates, smoke tests, and source indexing are not treated as proof certificates. No new κ follows from these local checks. No native end-to-end multiplication runtime, Lean kernel audit or hosted Linux CI was performed.

The public manifest inventories every package file except itself. The root verifier checks this inventory and every file hash before executing bounded subprocesses. A hash manifest establishes transport integrity, not mathematical truth. Publication checks also inspect Git author/committer, frozen commit bytes, explicit file layout, short staging paths and release hashes. Successful local checks do not guarantee a later authenticated network upload.

The separate anchor compiler replay checks 192 width-two basis-call identities, 64 canonical-target identities, six width-three arbitrary-complex call identities, two canonical targets and four zero-owner cases. It tests the forward compiler proved in algebra/ANCHOR-EXTERNALIZATION.md. It does not prove that an unrelated eight-bank controller can be compressed into one larger paid call.
