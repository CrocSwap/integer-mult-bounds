## Which hypotheses still matter?

PR1194's D contract requires source-free additions at the common zero frame,
no COPY/ERASE, recursive child, allocation or frame-change event inside D,
complete restoration of dirty helper and target bases, and its retained H1
restriction on target feedback. The continuation still needs H1/H3/H4/H5 and
the separately checked raw `J=I`. The chronological argument substitutes only
the equal-value, equal-frame prefix before an identical continuation; its
virtual D is not executed or charged.

Thus the original syntactic failures and the successful replacement contract
can coexist. Likewise PR1311's stored `hosted_admission: false` records **that
package's scope**. PR1806 subsequently supplies the missing finite hosted
invoice for the identical candidate. It explicitly leaves acceptance of the
replacement interface and inherited physical/all-size premises separate.
Neither record is made false by the later work.

A proposal that changes the frame, reads sources, permits target feedback or
changes the continuation must identify the corresponding missing implication.
PR1194 alone does not certify such a proposal. A scalar addition saving also
does not improve the recursive moment: the local rank mass remains 5,129,
and PR1806 retains PR589's complete bit profile and saving.
