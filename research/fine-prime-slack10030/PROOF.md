# Finer endpoint with fixed positive slacks

The physical supplier and paid rank profile are unchanged from PR1800 at its pinned head. This package re-certifies that profile's moment root on the same 10^-10000 rational grid certified in PR1928. The input source specification is preserved byte for byte as inputs/SOURCE-SPEC.json. The derived SPEC differs only in expected.complex_lower. The unchanged independent PR1982 checker proves M(B)<1<M(B+10^-10000), using outward integer rounding and explicit series tails. The new ledger directly encloses its own interior b and rejects B+10^-10000 using that same checked interval kernel; these two calls are not claimed as independent algorithms. M is strictly increasing because every child rank lies strictly between zero and the parent dimension. No floating-point root finder is used by verification.

Write h=10^-10030, b=B-h, q=B-2h, a=B-3h/2, delta=2h, epsilon=1-delta, beta=1-3delta, r0=slack=h, stop=10^-10036 and zeta=10^-10032. As in PR1800 and PR1828, c=3/32 and xi=epsilon*(1+q)-c+slack. The source-axis absorption gap is delta-r0=h>0; the membership gap is delta>0; the Gaussian gap is delta*(1-2q)>0; the effective-router gap is h/2>0. The stopping condition stop*b<h/2 is checked exactly. The remaining inherited inequalities and nine cost powers are regenerated as exact rationals with 17 rejecting controls.

K=floor(epsilon*q*10^10070)/10^10070-10^-10042. Both independently implemented balance calculations must agree on this exact rational. K must strictly exceed the exact PR1928 rational pinned in inputs/LEADER1928.json (and the earlier PR1839/1875 comparison points). Decimal displays play no role in comparison.

The full replay checks the immutable PR1800 dependency, all inherited outer replays and complete supplier admission. The actual assembly must match the preserved original specification and exactly the re-certified profile, dimension, live count and bit endpoint. The endpoint certificate binds that same profile to the new derived specification; it does not rely on changing an old receipt's number. The original native admission's lower endpoint is a weaker valid endpoint, not an upper ceiling.

All slacks are fixed positive constants. The predecessor's eventual polynomial and polylogarithmic absorption arguments therefore transfer with a potentially larger unspecified cutoff if those written arguments are valid. No limit point epsilon=1, uniform cutoff as h tends to zero, new physical supplier, or practical speedup is claimed. All inherited compiler, hosting, online precision, fixed-tape, source-prime, locality, recovery, interchange and analytic hypotheses remain. Finite replay does not prove those all-size hypotheses.
