and physical-family constraints. It does not assert attainability or bound
changed supplier constructions.

**not the best reported candidate**. During final overlap review,

release and hosted CI are distinct from our source-premise inspection; we have
not rerun its complete admission. Its portable fresh-native cold tail remains
unexecuted according to that source. The independently reproducible all-T

## Reproduction

With Python 3.12 and `numpy==2.5.4`, from the repository root:

```sh
python3.12 -B scripts/research_package.py --package research/staged-644-660-owner-successor
```

The single registered command has a 600-second bound. It performs fresh owner
construction, complete independent audit, three exact moment methods, all 63
modern strict inequalities and 17 controls, all 47 bootstrap inequalities and
four controls, the original four integer-primal controls, six journal controls,
five independent local owner-predicate controls, and the exhaustive dual.
The optimized-parent replay took 85.5 seconds on the author's Mac.
The recorded full-release binding is checked against that fresh arithmetic.
See [VALIDATION.md](VALIDATION.md).

Direct Git-free replay of a committed export uses:

```sh
python3.12 -O -B research/staged-644-660-owner-successor/verify.py --repo . --out /tmp/fresh-owner-successor
```

The output must be fresh and outside the package. The wrapper retains an
unoptimized child for inherited assertion-based validators and uses a private
bytecode namespace. Complete decompressed literal payloads, not regenerated
gzip streams, are the semantic admission gate. Immutable archived source bytes
retain both SHA256 and original Git blob identities; Git export reads disable
replacement refs. See [VENDOR.json](VENDOR.json) and [ADAPTATIONS.json](ADAPTATIONS.json).

The long [reproduce.py](reproduce.py) wrapper retains the original source/native
preparation and full admission. It requires the historical Git objects named
in the archived predecessor FETCH.txt. It is separate from the bounded command;
its end-to-end cold tail has not been run. Authenticated source
and native-cache reuse in the completed actual release is explicitly different
from a fresh cold native run.

## Scope and inherited premises

scaling/concavity proof, not a formal-kernel theorem. Conditional transfer still
requires uniform all-size scalar/COPY/CLEAR/zero-allocation costs, a consistent
whole-call physical hosting and common source-label model, paid mutable-source
access and restoration, all private scratch and continuations, source-bound
native/phase/idle/controller invoices, internal rounding and precision bounds,
a finite-tape realization, retained bootstrap time, the PR559 recurrence and
correction/recovery hypotheses, analytic outer transfer, and the unchanged
joint BIT H1–H5 endpoint. The full profile includes every local and idle child;
physical stock 663549 must not replace live stock 663040 in the moment.
