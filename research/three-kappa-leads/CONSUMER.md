## Exact proof and controls

For any nonzero scalar c and delta !=0, a shear `A(h,d)=(h,d+c h)` fails to commute with translating h alone:

`A (X_delta ⊕ I) - (X_delta ⊕ I) A` has target block `c(X_delta-I)`.

This is an all-input linear identity. For the first actual coefficient1/4, every one of the 512 address basis vectors gives a discrepancy. We include nonzero target dirt. Complex linearity covers imaginary as well as real inputs; no clean-workspace hypothesis is used at this consumer cut.

The replay grants an optimistic same unchanged scratch value through ALL23 translations, applies one bound scalar consumer per block to independent target arrays, and checks that final scratch translation is zero. The first output remains wrong in all512 basis cases. Thus final scratch restoration alone is an insufficient acceptance check even in this more favorable sharing model. These23 hypothetical splices are a boundary counterexample, not a source/native construction.

Positive control: translating BOTH source and target before an ADD and undoing target translation afterwards gives the correct dirty output. Its target frame changes/restoration must be implemented and priced. A fresh source reloaded into reused scratch is a separate negative control: translations on different values do not cancel merely because storage or an address pointer is reused.
