`adapt_native.py:adapt(rootwork, roundroot)` is a prepared adaptation of #7622's pinned full native runner, not a qualification result. It was AST-parsed only; no adapter, candidate, scientific source, or native engine was executed. Original #7622 head is `fb03f3a4bbc288fe264f5ce708364ddcbb7245d2`; current #7623 head is `2ee2f0b61f7d123e8862482b966699cca578be6d`. Root controls all freezes, guarded source execution, caps, receipt validation and the one native attempt.

The application first performs the old #7620 prepare, then copies to `frozen-composition`: `7620-WORD.json.gz`, `7620-NATIVE.json`, `7620-INVOICE.json`; `7621-WORD.json.gz`, `7621-EDITS.json`; `7623-WORD.json.gz`, `7623-EDITS.json`, `7623-PAIRS.json`, `7623-INVOICE.json`, `7623-NEW-CERTS.json`; and `CONTACT7623-MANIFEST.json`, `CONTACT7623-PRICE.json`. Current package copies are compared byte-for-byte against authenticated input trees. The 7620 runner's SHA and 208 CRLFs are checked; every code anchor has an exact occurrence count and before/after SHA. It compiles the generated runner before writing. The 7620 reconstruction and its original native result are separately checked; 7620 → 7621 → 7623 is rebuilt from literal edit lists, preserving all metadata; then exactly ten authenticated manifest edits and complete origin/reverse maps reconstruct the candidate. No #7623 published complete native result is assumed.

The completed first-gate `RESULT.json` must have its provisional status and all required output hashes; candidate compressed/canonical hashes, manifest and candidate invoice hashes are discovered from that completed receipt chain, never historical candidate constants. Candidate identity, exact and price bindings, current source gzip/canonical hash, 77,277 → 77,271 events, 1501/68 fields, 180 INIT/CLEARs and 47 owned MOVEs are checked. Root's independently authenticated freeze must bind the first-gate RESULT, this adapter, source input trees, launcher, all gate outputs and run ID. The adapter ledger records first-gate result, original/adapted runner, pair manifest and source/candidate hashes and patch counts.

The complete physical pair set is the union of all 964 unique #7623 pinned pairs, #7481-versus-#7623 affected route pairs, #7481-versus-candidate affected route pairs, and source-versus-candidate splice route pairs. The adapted runner computes fresh 7620 inventory to check the old receipt, plus fresh #7623 and candidate native inventories. Unequal `context_c` refuses and requires explicit common-context review; no implicit cprec cap.
