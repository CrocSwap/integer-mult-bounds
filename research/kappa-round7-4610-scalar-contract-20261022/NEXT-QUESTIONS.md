# What this result leaves open

The fixed-rank system is rigid even when owned-only contact freezes are removed.
Allowing exactly one physical phase-rank defect yields only independent helper
boundary pre/postprocessing, which cannot improve the moment at any rank.

The next useful phase search must allow multiple defects together. A concrete
tractable family, already motivated by Dugongue's PR4654 phase-cut grammar, is
binary switching of a fixed ambient rank-one form at each actual contact
component. Charge paid and formerly monomial warp rank increases literally,
retain fixed main/owned boundaries, and compare the complete helper reward.
Enumerating every nonzero nine-bit ambient covector gives 511 global energy
problems. This is distinct from the single-edge result and can pool phase
changes across several helpers. One-endpoint-fixed modes have unary helper
rewards; allowing both endpoints to switch introduces interactions that must
be treated with their actual sign rather than silently called submodular.

A promising energy must still emit literal columnwise Clifford circuits,
normalize every actual helper job, preserve all arbitrary main/helper inputs,
restore owned storage, and pass the whole invoice, compiler and outer/Lean
gates. Other exits are changed scalar words, shared native G maps, subspaces,
main/adapter interfaces, or a new controller. No useful instance is assumed to
exist, and the one-edge obstruction is not a theorem about those larger spaces.
