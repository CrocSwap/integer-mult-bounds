# Rank-one phase-flow optimization by a minimum cut

Prepared for Dugongue with substantial OpenAI Codex assistance. Apache-2.0.

This is a constructive extension of PHASE-FORM-GRAMMAR.md. It preserves the old subspaces, scalar chronological word, fixed logical native maps and exact main ABI. It permits and pays additional Gaussian children when a formerly monomial physical warp becomes nonmonomial.

## Binary gauges

Fix a nonzero ambient functional l on F2^n. At a contact node v with subspace U_v choose s_v in {0,1} and form

    b_v(x,u)=s_v (l·x)(l·u),     x,u in U_v.

An actual gauge is F_v=C_(U_v) D_(s_v ll^T), with the same inverse-image convention as the phase-form grammar. A scalar contact has one common gauge for all roles it touches. Fix all main endpoints to s=0. Initially also fix owned-center/non-G adapter boundaries to s=0, so those frozen instructions remain unchanged. Fix one endpoint of every helper to zero; allow its opposite endpoint to vary. Both choices, all helper entrances fixed or all helper exits fixed, are valid separate search problems.

## Every physical edge has an exact rank invoice

For an original paid edge U→V with I=U intersection V, its old rank is r=dimU+dimV-2dimI. The two rank-one forms restricted to I agree when both switches agree, so the added rank is one exactly when switches differ and l is nonzero on I. Its complete child cost at exponent t is (r+added_rank)^t, not an unpriced phase correction.

For a fixed logical native warp K_G, the retained subspaces satisfy GU=V. The transported source form is the rank-one functional G^-T l restricted to V; the target form is l restricted to V. Write these restricted functionals as a and b. The physical operator is

    F_target K_G F_source^-1.

Its Gaussian rank is exactly rank(s_source a a^T + s_target b b^T), hence one of 0,1,2. If a and b are equal nonzero, the rank table for switches (00,10,01,11) is (0,1,1,0). If they are distinct nonzero, the table is (0,1,1,2). If one vanishes, the table is (0,0,1,1) or (0,1,0,1); if both vanish every entry is zero. These cases are decided by exact binary linear algebra.

The physical warp is emitted as its actual exact Clifford circuit. The retained Clifford normal form factors it into two explicit monomial adapters and one rank-one or rank-two Gaussian call, or only a monomial when the rank is zero. Thus a switch cannot make a formerly free native warp expensive without that expense appearing in the paid profile. All adapters, owned work and absolute phases remain covered by their explicit native construction and replay, rather than treated as cost-free semantic labels.

## The binary edge costs are submodular

Let f(r)=r^t for fixed 0<t<1, with f(0)=0. For each original paid rank r, charge the incremental cost f(r+added_rank)-f(r); the original invoice remains as a constant. For a formerly monomial warp use r=0.

If two active restricted rank-one forms are distinct, the nontrivial cost table is

    c00=0, c10=c01=f(r+1)-f(r),
    c11=f(r+2)-f(r).

Concavity gives c00+c11<=c10+c01. Equal forms have c11=0 and satisfy this inequality too; zero restrictions are unary costs. Therefore every edge cost is a submodular binary function.

For completeness any table satisfying c00+c11<=c10+c01 has the exact decomposition

    c(s,t)=c00 + A s + B t + C |s-t|,
    C=(c10+c01-c00-c11)/2 >= 0,
    A=c10-c00-C,  B=c01-c00-C.

Thus C is a nonnegative cut-edge capacity, and A,B are unary contributions. Negative unaries are represented by a nonnegative terminal capacity plus a constant. There is no sign ambiguity or appeal to a floating optimization status in this reduction.

## Productive rewards remain unary

Suppose a helper has nested source/end subspaces U⊂V and original productive rank g=dimV-dimU. One endpoint switch is fixed zero. The relative helper's extra rank is s times rank((l|U)⊗²), hence zero or one. Its productive-moment reward is the unary quantity

    s * ((g+1)^t-g^t)

when l is nonzero on U, and zero otherwise. The reward must be multiplied by every actual controller occurrence of that independent helper. Every helper remains a distinct arbitrary input and its true new Gaussian job is normalized explicitly.

Consequently total added paid cost minus total added productive reward is a binary submodular energy and is reducible to an s–t minimum cut. The all-zero assignment is feasible with energy zero. Any negative-energy cut gives a strictly improved complete moment at exponent t. This conclusion requires the actual graph multiplicities, owned-center charges and controller invoice; it is not a local gain that can be added across overlapping windows.

## Exact arithmetic and discovery

At rational t the weights are algebraic powers, not generally rational numbers. A portable discovery implementation may solve min-cut problems for rational enclosures/approximations of these coefficients, then evaluate every selected cut with the retained outward-rational power engine. Only a strictly certified negative true energy is a mathematical improvement. Approximate optimality alone is not an exact ceiling. Because the graph has finitely many cuts, any strictly profitable true cut is eventually detected by sufficiently fine rational approximations; a bounded search that finds none gives no universal obstruction.

All n-bit nonzero functionals l can be enumerated at the fixed local dimension n=9. This is 511 distinct rank-one phase families, not a claim to search arbitrary symmetric phases, simultaneous moving subspaces, or all native algorithms.

## All-input semantic assembly and finite compiler

The new physical edge for every old logical operation M is F_next M F_prev^-1. Adjacent gauges cancel exactly. At scalar contacts the same F acts on each operand, so the original scalar opcode and coefficient are retained. Main gauges are frozen to their original values. In the mode with all helper entrances frozen, the initial gauge is unchanged on every field, so every main endpoint is immediately unchanged on every arbitrary input. In the mode with varying helper entrances, additionally use the retained independent-helper direct-sum contract: the old global endpoint has zero blocks from helper inputs to main outputs. The original all-column certificate must check those zero blocks explicitly. Right-multiplying independent helper input blocks then cannot affect a main output. Thus both declared modes preserve the actual main ABI; freezing main gauges alone would not suffice for an arbitrary globally coupled operator. Helper endpoints change to the actual relative Gaussian/Clifford operators indicated by their gauges; they are not validated against an automatically redefined main contract.

The original chronological word order is unchanged. Each new Gaussian child finishes before the suspended parent resumes. The exact normal form provides whole-job monomial adapters, so the retained direct mixed-target compiler can treat the additional rank-one/rank-two paid jobs and increased helper ranks as actual canonical Gaussian jobs. Owned erasure is not inferred from the moment: frozen owned instructions and their original all-column proof remain explicit. Actual all-column and absolute-phase replay must validate the emitted witness and helper normalizers.

For every digit-column lift width f, tensor the actual one-column Clifford factorization independently over all f columns. Operator identities tensorize, active paid ranks multiply by f, and the helper rank gain becomes f. Identity spectators add no rank. This supplies an all-fiber algebraic extension of an admitted candidate; it is not a new unknown adapter hypothesis.

After a negative cut is emitted and verified, the entire changed target/paid histograms must pass the critical-root mirror, funded majorant, finite uniform-word absorption, precision and native outer assembly checks. No new kappa follows from a min-cut objective alone. This theorem gives a sufficient exact candidate-generation and lowering mechanism; it does not assert a useful cut has been observed in the current word.

## Extension: an arbitrary fixed symmetric ambient form

The minimum-cut reduction is not restricted to rank-one Q=ll^T. Fix ANY symmetric ambient Q and choose b_v=s_v Q restricted to U_v. On a paid edge I=U intersection V, the extra rank is zero for equal switches and rank(Q|I) for unequal switches. Its incremental paid cost is a nonnegative Potts cut weight f(r+rank(Q|I))-f(r).

For a formerly monomial logical warp G, pull both forms back to its source U. Put A=Q|U, B=(G^T Q G)|U, a=rankA, b=rankB and c=rank(A+B). The four paid costs are (0,f(a),f(b),f(c)). Rank subadditivity gives c<=a+b, and the increasing subadditive function f(k)=k^t gives f(c)<=f(a+b)<=f(a)+f(b). Thus this table is submodular too. A helper with one endpoint fixed has unary reward f(g+rank(Q|I))-f(g). All earlier source/normalizer/owned/main-ABI obligations remain unchanged. The actual diagonal Clifford D_Q is explicit and its phases must be carried literally.

Consequently any chosen symmetric Q, including alternating rank-two and high-rank forms, supplies another exact min-cut discovery problem. Searching finitely many Q is bounded evidence; it does not exclude a useful form among the other 2^(n(n+1)/2) possibilities.
