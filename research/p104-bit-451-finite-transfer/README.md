# Quantify the near-trial BIT margin needed with the 451-factor transfer

Reprices the fixed complete BIT and rational profiles for a target strictly above 0.003879929046155, with the retained 451-factor losses and seven-stage selector.

The raw trial must be strictly above 0.0038799290488400000004497 for that selector. The old BIT profile has an exact deficit; conditional stock depth is separately bounded once the finite product ledger is provided.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `ba0da8a26530cf2dfee0dde11930c0553b1873b46658555ac265faf91e2e1eee`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run `python3 -I -B self_test.py` and `python3 -I -B replay.py`.
