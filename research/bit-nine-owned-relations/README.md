# Nine owned BIT helper relations

This conditional construction raises the ordinary BIT saving from
**0.0034363538396 to 0.0034441226396** at matched compiler and cover
parameters. It admits the strict endpoint **0.00344412**. The complete
multiplication kappa does not increase: the complex supplier still binds.

The reverse PR589 word has nine COPY values that are linear forms of its
initial full-frame fields. Own one helper for each independent form and
set all nine forms to zero. This removes nine rank-one transitions and
nine rank-seven COPY jobs per local call. It also removes nine rank-eight
productive helper targets. All 652 retained inputs remain independent.
The ten owned fields, including the old COPY centre, accept arbitrary
entry data and finish at zero.

[PROOF.md](PROOF.md) gives the local boundary argument, the physical
involution that permits use at all eighteen full calls, the tensor lift,
and the complete cost. [RESULT.json](RESULT.json) contains the exact
receipt. [WORD.json.gz](WORD.json.gz) contains the emitted program.
[SOURCES.json](SOURCES.json) pins all thirteen live inputs at base
`d277c97824e50782da6adbc486ca3c76c8fc687e`. The selected record in that
manifest is historical provenance. This package does not change it.

The complete p16/a7 controller has 57,231 paid jobs and 11,292 productive
fields. Its change is minus 162 rank-one jobs, minus 162 rank-seven jobs,
and minus 162 rank-eight targets. Its rank surplus remains 753. The raw
moment crossing lies strictly between 0.003472070044 and 0.003472070045.
The complete scalar and route allowance remains below 10^9.

## Reproduce

Use CPython 3.12 and its standard library. From the repository root:

```sh
python3.12 -B scripts/research_package.py --package research/bit-nine-owned-relations
python3.12 -O -B research/bit-nine-owned-relations/verify.py
```

The verifier prints:

```text
PASS_BIT_NINE_OWNED_RELATIONS_00344412_NO_NEW_MULTIPLICATION_KAPPA
```

It authenticates every live source, rebuilds the word, checks all symbolic
input rows, and replays each of the 662 input columns with separate
Boolean state. It checks rational projectors and all 111 port charts,
the literal controller, all targets and paid jobs, two exact moment
engines, the compiler tail, the cover loss, the ordinary BIT conversion,
and the unchanged outer arithmetic. It rejects missing entry or exit
clears, a changed relation, a nonzero free transition, a missing target
debit, and the old word at the new saving.

## Scope

The native all-column, owned-erasure, compiler, precision/tape, and
analytic-recovery premises remain conditional. The source delayed-cover
argument supplies the common weight and recursive interface. The finite
checks do not materialize the full GL cover, the winning uniform word,
or the complete integer multiplier. No Lean or proof-kernel check is
included. The outer arithmetic consumes the pinned PR5398 receipt; it
does not replay that complex construction. No global optimum is claimed.

## Open next questions

A further BIT gain needs a new relation space after all nine COPY jobs
are removed. Check active claims first, then charge each lost target
against the full word. The current full-history searches supply no such
additional gain. A complete multiplication gain needs a cheaper complex
supplier with a complete caller and cost. This package supplies neither.
[TASK.json](TASK.json) records the scope and these limits.
