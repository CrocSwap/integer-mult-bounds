**Scoped source-wide proof; no higher kappa.** In the retained round-three
scalar chronology, every positive prelude 47–58 must still send its original
main input vector to vector 45. Releasing all native maps and helper endpoints
does not free those first image lines. Even widening the first prelude input
cannot change this conclusion under the monotone contact contract.

The certificate follows ordinary persistent scalar paths to eight fixed main
Y output hyperplanes. Their independent normals have common kernel <45>.
Every warp is cut from the containment graph: no map, helper endpoint, owned
frame or inverse-map equation is used to obtain these paths. There are 96
explicit paths and 996 consecutive-contact links per orientation.
[PROOF.md](PROOF.md) states the exact implication and its hypotheses.

This does **not** force the three later prelude contacts or inverse occurrence
to remain at one-dimensional frames. Their possible growth is a distinct
remaining construction question. It also does not prove a global moment
ceiling or admit a new supplier. Canonical main at this contribution's base
selects conditional kappa .00302015; later separate conditional numerical

## Reproduce

From the repository root, using Python 3.12+ and its standard library:

```sh
python3 -I -W error -B research/prelude-line-forcing/verify.py
python3 -B scripts/research_package.py --package research/prelude-line-forcing
python3 -B scripts/check_research_commit.py --package research/prelude-line-forcing --check-source-history
```

The registered replay runs ordinary and optimized Python, authenticates the
exact compressed and decompressed source, checks every path against both event
streams, checks all output bases/normals, rejects seven certificate/source
corruptions and evaluates all 512 vectors independently against the normals.
No optimizer, predecessor constructor, Clifford decoder, Lean, Docker or
historical selected replay is required. This is an author-checked written
proof with finite source certificates, not independent human or kernel review.

CERTIFICATE.json stores the actual scalar event IDs after omitting `climb`
events, with each path's persistent owners and final main output. Native
warps remain present in this indexing. A link can never skip a scalar contact
or cross a warp on its named role. The certificate uses no assertion-based
acceptance checks, so optimized Python preserves all tests.
