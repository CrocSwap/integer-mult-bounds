# The twelve first prelude images are forced by main output paths

Prepared by Cinna Davis with substantial OpenAI Codex assistance; Apache-2.0.

The scientific input is Cao Yifan/intqwq's round-three word, canonical payload
`cfcd36b40326d7a5815e1db5313444379b3fb756b27d5201c561574c085cc0dd`.
This is a scoped construction constraint, not a multiplication theorem or a
new conditional kappa. All vector spaces below are over F2 in nine axes.

## Retained hypotheses and optimistic relaxation

Retain the chronological scalar opcodes and their persistent operand roles.
Every scalar has one common actual frame subspace on all its operands.
Between consecutive scalar contacts on a persistent role, in the absence of a
native warp, allow any sequence of ascending subspace transports. Thus the
earlier contact subspace is contained in the later one. This is the retained
monotone contact contract, not a claim about arbitrary Gaussian programs.

Keep the main X entrance lines and the main Y exit subspaces fixed. No helper
entrance or exit is fixed in the argument. No owned-center frame, adapter
marker, paid rank, late-map input or capacity is used. At **every** native warp,
including all positive and inverse preludes, sever the containment graph. No
containment edge crosses a native warp and no matrix G is used to generate a
path. This relaxes simultaneous native-map consistency rather than proving it.

An edge joins consecutive scalar contacts on the same persistent role without
an intervening warp. The final contact on a main Y role has an edge to that
role's fixed exit. A path certifies repeated subspace containment. Changing
another field's frames does not invalidate an existing path under the stated
chronology and ascending-contact hypotheses.

## Source certificate

For each operation j=47,...,58, let p_j be its positive one-line prelude on
main X role r_j and let s_j be the immediately following scalar ADD. The source
has no earlier native warp on r_j. Its entrance is the nonzero line <a_j>.

CERTIFICATE.json gives eight directed paths from s_j to eight main Y exits.
The exact verifier checks every link against the two original event streams,
with the persistent owner of that link recorded. There are 96 paths and 996
links per orientation. These are literal chronological contact incidences,
not transitive edges accepted by a construction optimizer.

Each selected exit is an eight-dimensional hyperplane. Its stored nonzero
normal is checked against the actual source basis. The eight normals are
independent and their common kernel is exactly {0,45}. Consequently every
legal new common subspace F_j at s_j satisfies

    F_j <= intersection(eight fixed main exits) = <45>.             (1)

The checks of the two directions are separate, although their operand sets
and stored witness paths agree. Independent direct evaluation of all 512
vectors corroborates the kernel calculation. Removing any one of the eight
normal constraints leaves four vectors, so the selected constraints are
independent; this does not assert a minimum path cut or an optimal endpoint
modification.

## Forced image, including attempted prelude widening

Let U_j be a proposed new input subspace immediately before p_j, and suppose
the logical native map G_j remains an invertible binary address map. The fixed
main entrance and absence of an earlier warp imply <a_j> <= U_j. A legal
transported native prelude has output G_j(U_j). Any subsequent ascending
transport before its first ADD gives

    0 != G_j(U_j) <= F_j <= <45>.

Invertibility forces dim U_j=1, U_j=<a_j>, G_j(U_j)=F_j=<45>, and G_j(a_j)=45.
This proves the original first input/image line contract for all twelve
operators even if all other native matrices and all helper boundaries are
allowed to change. An attempted wider **first** prelude input also fails under
these hypotheses. The all-subspace conclusion follows from the written
containment argument; no floating solver optimum is used.

The result constrains the first positive prelude and its first scalar contact.
It does not force the three later contact spaces to stay one-dimensional.
In particular their inverse-prelude input can grow, and its transported output
can grow too. Giving the inverse occurrence a different higher-dimensional
contract, while using the same G_j, is outside a model that repeats one fixed
line pair. The proof does not exclude that changed paid itinerary.

## What the result does not establish

The first prelude line is not a free parameter of this retained scalar graph
and main ABI. This does not establish optimality of its remaining contacts,
helper charts or maps, nor turn a floating fixed-prelude result into an exact
ceiling. Nonascending contacts, a changed scalar graph/order, changed main
interfaces, additional warps, a non-address native operator, or a changed
inverse-prelude contract need their own physical construction and complete
bill. No moment, supplier admission, compiler, precision, stock, BIT or outer
claim follows from this certificate.
