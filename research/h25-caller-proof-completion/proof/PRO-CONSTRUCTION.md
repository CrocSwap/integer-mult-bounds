\[

[Actual supervisor owner](https://github.com/CrocSwap/integer-mult-bounds/blob/1479ccf2ec0bc29b7bf741a2d613d79e1f9ec19e/research/h25-original-refusal-repair/snapshots/implementation/source/fresh_supervisor.py.txt)

The observer’s complete finite protocol is

```text
RESERVED → OBSERVER_BORN → TRACEE_STOPPED → EXEC_OBSERVED
→ TRACING → EXIT_EVENT → WAITED → EOF_COMPLETE
→ READBACK_COMPLETE → QUALIFIED
```

Any failure moves monotonically to failed or uncertain retirement.

1. Reserve the attempt, native error slots, byte/event capacities, descriptors, temporary paths, deadline, and cleanup tail before acquisition.
2. Fork exactly one tracee. The child closes unrelated descriptors, establishes ordinary stdin and two pipe writers, verifies its resource profile, calls `PTRACE_TRACEME`, stops, and then performs the exact exec.
3. Install exit-kill and exec/exit/fork/vfork/clone/syscall tracing at the genuine stop. Use `PTRACE_GET_SYSCALL_INFO`. Reject alternate ABI, unexpected descendants, a second exec, or non-protocol signal delivery.
4. At stdout/stderr `write` or `writev` entry, copy bounded bytes while the sole task is stopped. Require the full requested count at syscall exit. Short writes, restart, errors, missing exits, and capacity exhaustion invalidate the report.
5. Drain both pipes concurrently while tracing. Reject replacement/export of their writer descriptors and unsupported output mechanisms.
6. Continue through exit handlers and final FILE cleanup. An exit event is not a terminal wait.
7. Require actual terminal wait, both EOFs, once-only known descriptor retirement, complete guardian retirement, and independent parent readback. The successful-write snapshots, drained bytes, retained bytes, and parsed report must agree.

The observer records actual native errno events. It does not invent Python exception objects. Parent-local failures retain their genuine original objects and tracebacks.

### Why this closes the formatting-before-write gap

The selected GCC query paths use fixed narrow formats, with at most three `%s` arguments in the relevant configuration diagnostic. Under an actually verified hard AS ceiling of 256 MiB,

\[
3\cdot268{,}435{,}456+k < \mathrm{INT\_MAX}
\]

for their fixed literal contribution \(k\). The selected calls have no wide, positional, grouping, dynamic-precision, `%n`, or registered custom-format conversion. The selected C locale semantics retain the fixed message formats.

Ordinary fresh FILE state supplies the format, write, and orientation preconditions. If FILE buffer allocation fails, glibc `_IO_doallocbuf` falls back to its one-byte short buffer. Output then reaches the monitored write path. The observer traces registered exit processing and `_IO_cleanup`, not just return from `main`. Thus a zero exit and syntactically plausible prefix cannot conceal an accepted silent formatting or flush failure. [glibc FILE allocation fallback](https://github.com/bminor/glibc/blob/ef321e23c20eebc6d6fb4044425c00e6df27b05f/libio/genops.c), [glibc exit finalisation](https://github.com/bminor/glibc/blob/ef321e23c20eebc6d6fb4044425c00e6df27b05f/stdlib/exit.c)

Give each query its own registered administrative TMPDIR and retain its creation/deletion/finalisation costs. Alpha-renaming is permitted only for source-proved temporary-name fields. Preserve every original non-temporary argv byte and implement the inverse of GCC’s actual quoting loop, rather than applying shell interpretation.

For the linker script, select the source-derived internal shared-script branch. The inspected generator closure produces literal script text without active `%` directives or injected input files. An external-script branch cannot use this proof’s unchecked `fread` assumption; it requires an independent complete owning read instead.
