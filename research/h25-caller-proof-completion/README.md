# Compiler-input preservation and owned property-query observations

This contribution connects a conditional compiler/view preservation argument to the actual candidate caller source. The caller authenticates selected compiler inputs, obtains bounded property reports through an owned observer, verifies their transport and lifetime, and reobserves the inputs before the private-view launch. The unchanged scientific caller and its original equality contract remain the reference.

The candidate source and its conditional argument received separate AI source review. This archive does **not** establish current-host eligibility, installed-image equivalence, complete baseline/candidate execution, output equality, a speedup, or a new multiplication bound. The fresh baseline transfer and complete comparison executor are still unimplemented in the candidate controller. No runtime role contracts or execution permission are issued by this package.

## What changed

- The actual loader, constructor, supervisor and strict receiver now join the genuine parent association to a separate PropertyQuery child role. A JSON flag or detached report cannot grant this authority.
- The native observer records bounded write/writev entry bytes and returned counts, drains both pipes, distinguishes a non-returning terminal syscall from an observed return, follows final cleanup, retires the writer and retains independently readable evidence. Early native errors retain their first-error position.
- Compiler selection covers the literal configured GCC paths, three independent compiler origins, five build plans, shared linker scripts, explicit plugin and complete selected input closure. Relative bare linker operands use the actual script directory, original working directory and ordered prefixes; `-l` lookup keeps its separate rule.
- The private-view entry preserves the already-read-only HERE, `/tmp` and `/var/tmp` object relations. It refuses unsupported premises instead of changing the host to establish them.
- Both immutable scientific stage maps retain all 196 original members with their exact bytes and modes. Historical failed snapshots and corrections remain available in the archive.

The proof statement is conditional. For every original context c and eligible environment E in the explicit class D, it asserts

    T1(E) and T2(E) and F(E,c)
      imply O_original(P,E,c) =_original O_original(V(P),E,c).

P and V(P) use the **same patched Ubuntu GCC/binutils subject**. This does not compare patched tools with pristine upstream tools. T1 is the original source/native/primitive association; T2 is the controller and ownership contract; F contains the concrete input, object, query and currentness joins. The original observation projection is unchanged.

D explicitly uses Linux 6.12, native LP64 x86-64 semantics and the additional security, filesystem and configuration premises in [the preservation argument](proof/PRESERVATION-v1.md). Those premises require separate qualification. A necessary release/architecture screen on this workstation returned `7.0.0-42-generic x86_64`, outside that proved class. This result puts full execution on hold; it does not prove universal incompatibility of newer kernels.

## Layout and integrity

This is an inert source archive and handoff, not a registered executable research replay. Source snapshots under `readable/` have a `.txt` suffix to discourage accidental imports. Original paths in metadata are provenance labels and are not dereferenced by the integrity checker.

- [SOURCE-MAP.json](SOURCE-MAP.json) maps every retained original path, extent, SHA-256 and mode to a content-addressed regular tar member. Identical bytes and modes share one member; mandatory original occurrences remain separate rows.
- `source-snapshot.tar.gz.partNNN` are ordered 512 KiB parts of one deterministic gzip/tar stream. The map gives every part and the full stream digest.
- [readable/implementation/](readable/implementation/) contains exact text copies of the actual owning source and its final manifests and profiles.
- [proof/PRESERVATION-v1.md](proof/PRESERVATION-v1.md), [proof/QUERY-FORMAT-MATRIX-v1.md](proof/QUERY-FORMAT-MATRIX-v1.md) and [proof/PRO-CONSTRUCTION.md](proof/PRO-CONSTRUCTION.md) retain the argument, per-report formatting analysis and complete Pro construction. Earlier provisional status wording is preserved as historical evidence; the final review and explicit boundary below give the accepted scope.
- [evidence/CANDIDATE-SOURCE-REVIEW.json](evidence/CANDIDATE-SOURCE-REVIEW.json) and [evidence/SOURCE-BOUNDARY.json](evidence/SOURCE-BOUNDARY.json) distinguish candidate-source acceptance from the missing comparison owner and later execution obligations.
- [evidence/](evidence/) retains raw control outputs, warning logs, timings and exact result records. Failed and superseded source is archived without being adopted.
- [source/UBUNTU-SOURCE-BUNDLE-v1.json](source/UBUNTU-SOURCE-BUNDLE-v1.json) is the already published ordered Ubuntu patch/source packet. Selected third-party sources and license texts are under `third-party/` and `licenses/`.

From this directory, the passive command is:

```sh
python3 -I -B verify_integrity.py
```

It streams and hashes the newly created archive and readable copies. It never extracts files, imports candidate code or runs native/scientific work. The guarded validation receipt records the exact executed command and its narrower isolated-Python options. This archive preserves the current assembled tuple and named proof inputs, not every predecessor's entire source history or a portable executable installation. Historical absolute-path imports, external issued authority, generated toolchain configuration and operating contracts remain external dependencies. The map and retained source identify them; missing runtime prerequisites cannot be replaced by archive metadata.

## Verification actually performed

The connected-source operation completed ten guarded steps with known zero waits: 27 new parent controls in normal Python, the same 27 in optimized Python, 11 loader cases, 38 query-owner cases, three native-owner compilations without running their mains, and 23 literal native mock cases. Its recorded guard-process wall time was 4.97 seconds. A subsequent distinct regression operation passed eight new library-context cases in each Python mode in 0.91 seconds; it did not rerun the old suites. These are finite source controls, not executions of the original campaign.

Compiler warnings are retained: entry 5, observer 5 and mock harness 5 misleading-indentation warnings; guardian 14 warnings including format truncation. Successful compilation is not native-image qualification. No real property query or original scientific invocation was executed.

The final source review checks the actual graph, both 196-member stage maps, original helper/context coverage, lifecycle and error-order contracts, and the conditional preservation argument. It is an independent AI review, not a human endorsement or proof-kernel certificate. [NEXT.md](NEXT.md) gives the remaining original obligations.
