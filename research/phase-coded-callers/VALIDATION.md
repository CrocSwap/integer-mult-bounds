# Replay contract

The package replay uses Python 3.11 or later and the standard library.
It runs one child process at a time with numerical thread counts set to
one. Each child gets a fresh private copy of the frozen repository layout.
The copies are removed after each job. Files produced by old scripts
beside their source paths therefore remain inside the private copy.
No source-workspace path, Git operation, or network call is needed.

The default command runs these seven jobs twice, once in normal Python
and once with `-O`. Each child also uses `-I -B`.

| Job | Fresh decisive work | Inherited limit |
| --- | --- | --- |
| local | Regenerate both providers and all three local orientations; check 640 independent inputs and 416 unchanged helpers; reproduce the complete local payload | Spatial native kernels and endpoint adapters remain exact pinned records; no dense native recompilation |
| triple | Independent phase engine; 224 endpoint columns; 1,344 phase identities; all three FULL shears; terminal profiles; negative entry/type controls | Local provider proof and generic native contracts remain premises |
| chain | The actual nine routes; 3,584 boundary and 1,008 shear-view identities; entry/exit omission controls | General-width view proof and common-q recursive consumer are distinct |
| geometry | Reconstruct the actual matrices, 512 character sectors, exact spectrum and odd-power witness | All-width extension uses the retained proof |
| translation | Literal signed T/T inverse shear words, all sixteen live inputs and C0, completed views, exact invoices | Exchange uses exact three-shear composition and the proved inverse; odd-grid theorem is inherited |
| inplace | Nine formal columns; 1,024 mode inverse orders; 32,768 kernel coefficients; 144 Walsh blocks; 64 completed views; exact invoices | Apply MAP-COST-CORRECTION; no general O(V) map lowering |
| closure | Bind the final corrected receipt; reconstruct 12,544 literal affine paths; verify both sets of 896 witnesses | General-T theorem and regular-cover step require the retained proofs; no native decoder replay |

Each input is checked against SOURCES.json before and after the replay.
Compressed inputs also have their decompressed payload hashes checked
when that hash is recorded. All 50 direct entrypoints remain in the
closure. The checker inputs use the historical pins; packaging base
b58ad9ef4d4e861b0eaa5dba41742bdc072dca51 does not replace those pins.

The translation-service reviewer originally resolves five absolute
paths from its frozen receipt. The portable copy resolves those same
paths under the copied repository root. All five expected hashes are
unchanged. PORTABLE-ADAPTATION.json and PORTABLE-ADAPTATION.patch bind
and show the complete change. The adaptation does not change an import
or an imported module.

The output comparison retains every JSON field. It checks generated
output hashes before comparison. It then replaces only the source and
copied repository path prefixes with one marker. For generated artifacts
whose byte hash changes only because of such paths, it compares the
complete normalized artifact and replaces the validated hash by the
artifact's canonical hash. For the adapted translation checker, it
first verifies the actual portable self-hash, then maps that hash to
the original checker hash in the expected receipt. No cost, status,
source hash, matrix, program event, or mathematical field is omitted.
REPLAY.json records byte equality and canonical equality separately.

The final status is `PASS_PHASE_CODED_CALLERS`. The `--only` and `--mode`
options permit one named job or one Python mode. Such a restricted run
is not the full packaging check. The receipt records both options.

The output comparison preserves the historical receipts. It does not
endorse the withdrawn O(V) map statement or the service review's missing
record-count factor. PROOF.md states both qualifications.

The replay does not compile every inherited Clifford kernel, rerun all
historical campaign probes, prove a global owner lease, lower every
packed map, construct the recursive common-q consumer, or recompute the
complete kappa value. The full proofs, exact source contracts, and
independent reviews remain necessary for the all-width claims.

The fixed-code appendix has its own unmodified runner, source manifest,
exact graph receipt, proof review, and ANNEX-MANIFEST.json. It runs in
normal and optimized Python and compares complete receipt bytes. The
main seven-job replay does not invoke it. Run the second command in
README.md to include it. Its separate review was prepared by the
reciprocal-publication-review agent; no human review is claimed.
