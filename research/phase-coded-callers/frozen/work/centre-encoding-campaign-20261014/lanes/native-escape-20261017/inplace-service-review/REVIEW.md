## Why the finite mode proof applies at every width

At tensor width f, let g_j flip coordinate j in every copy, for j=0,...,8.
Let ell_j read coordinate j in the first copy. Then ell_j(g_k)=delta_jk.
The subgroup generated by the nine g_j has size 512 for every positive
f. Its action by translations is free. Each orbit has a unique element
whose nine first-copy bits are zero.

On each orbit the literal W is the normalized 512-point Walsh matrix.
It sends translation by g_delta to the diagonal sign
(-1)^(chi dot delta). This proves

```text
W T W^-1 = diag_chi(T_chi),
W^-1 diag_chi(T_chi^-1) W = T^-1.
```

The argument concerns one nine-generator translation group. It does not
treat T as a tensor power of an eight-by-eight matrix. The all-width
claim therefore follows from the free-orbit decomposition and the 512
exact matrix checks.

## Direct stream implementation and a sharper map bound

The marked-counter implementation is valid in the pinned fixed-tape
model. Place nine marks on a fixed extra track of the existing address
counter. A finite 512-state register holds their values. Every carry
that flips a marked bit updates that state. For N consecutive records,
the total counter-head travel is O(N+p), including initialization and
returns, where p is the address width. This follows by summing the
O(1+N/2^j) visits to each bit. A selector lookup uses that finite state
and does not rescan the full address.

For each conditional instruction, scan every source and target record.
The inactive case leaves the target unchanged and still traverses both
streams. The active case uses the retained exact arithmetic scan. A
record reversal can use O(w) temporary bits for a guarded width w; it
does not require another field array. The marked counter uses O(p)
bits. Thus the conditional arithmetic has its stated arithmetic charge
plus O(N+p) control work per real pass. The finite mode selectors remain
fixed when f increases.

The 144 Walsh translations have a stronger bound than an arbitrary
packed basis map. In the retained column layout, g_j complements one
entire f-bit chart coordinate. On that address field it is exactly

```text
y -> -1-y modulo 2^f.
```

Collapse the other fields into one prefix and one suffix. The retained
ordered-affine stream lemma applies with the fixed unit -1 and fixed
offset -1. Each such complement has O(V) cost, including descriptor
work, tape returns, and cleanup. No packed row-addition exponent is
needed for these 144 maps. The sixteen outer views still use their
inherited route implementation. Work tapes used by the map backend
remain part of that backend; the one-C0 statement counts numeric owner
roles, not an absence of all machine work tapes.

The checker verifies the literal finite word. The counter bound,
ordered-affine implementation, and orbit proof are source-based
mathematical arguments. This review does not execute a full Turing
machine trace for arbitrary widths.

## Reusable consequence and remaining construction work

The mechanism applies to any fixed-rank group of independent binary
translations with explicit dual address selectors. If a fixed matrix
convolution has invertible rational character matrices, its inverse
can be compiled in place: use the normalized Walsh word, finite
pointwise matrix words, and the inverse Walsh word. One scratch field
suffices. Integer Smith factors and one common denominator give a
uniform grid at the mode output. The finite word can be large, but its
length does not grow with tensor width when the translation rank is
fixed. This statement counts each declared translation as an operation;
it does not give a linear stream bound for arbitrary generator layouts.
Each new application must still supply the matrix factors,
coefficient bounds, denominator contract, and legal physical views.

section is

```text

A_query K_plus = B Q_U^2 D T^-1 = I.
```

word. This removes a centre-storage obligation. It does not make the

complete physical decoder remain separate obligations. No complete
supplier moment, native saving, or kappa value is claimed.
