## Independent matrix construction

Write the original response as \(E=I+UV\). Let P be the actual
sixteen selected ports, and let R be their 96-port complement.
The selected column minor \(V_P\) has determinant 16. It is a
dyadic unit. Keep \(U_R\), and set

\[
\widetilde U_P=V_P^{-1}(-2I-V_RU_R),
\qquad
A=I+\widetilde U V.
\]

The construction gives \(V\widetilde U=-2I\). Hence

\[
A^2=I+\widetilde U(2I+V\widetilde U)V=I.
\]

The checker constructs this matrix before it reads the emitted
response for comparison. All 96 ordinary rows agree with E, and
all sixteen selected rows differ from E. The actual normalized
reader is \(L=V_P^{-1}V\), and \(LA=-L\).

The full 3,276-scalar `common_frame_words.A` is replayed from the
112-column identity matrix. Its result is exactly A. Its targets
and sources are existing X fields. It uses no extra field and no
odd division.

The source identity \(A^2=I\) does not imply that A is symmetric
or unitary. It does not make \(C_sA_t\) self-inverse, reciprocal,
or independent of the stage.

The unchanged carrier prefix has the profile

\[

\]

primitives. Its ordinary output rows remain valid because
\(A[R,*]=E[R,*]\). Its selected records are independent.
All 416 helper values are restored under the inherited helper
supply contract.

Let \(G_R=\operatorname{diag}(I_P,q_R)\). Let \(F_\ell\) denote
FULL on the first \(9+8\ell\) axes. Define

\[
(D_{s,t})_P=L_sA_t,\qquad
(D_{s,t})_R=(A_t)_R.
\]

The complete forward data service is

\[
(F_{t-1}x,F_{t-1}G_Rw)
\longmapsto
(F_tx,F_tG_R(w+D_{s,t}x)).
\]

The target w is arbitrary. If \(w=C_sy\), the selected output
records are \(L_s(y+A_tx)\). The same reader is retained.
The checker composes the exact routed query with the full
prefix and verifies all 640 input columns for all six
provider/pair invocations.

The complete scalar count is \(6456+8440=14896\).
The monomial call bound is

\[
448+224+3040+672=4384.
\]

These terms count DATA entry/exit maps, local endpoint adapters,
native side maps, and query maps. This is a map-call count. It
does not price the finite implementation of a map. Identity
maps remain counted where the literal word calls them.

The native prefix's exact content coefficient bound is 22,
with binary denominator height one. The late query's exact
coefficient row-sum maximum is 202, with height two. These

The query maximum is attained at an emitted boundary. Its
witness has 266 coefficients of magnitude \(1/2\), another

At these late boundaries the regular cover gives a sharp

sharpness for a quotient cover. It does not cover primitive

The checker also transforms each late scalar ADD to its negative
transpose and each SCALE to its reciprocal. It keeps chronology.

This is the gatewise inverse-adjoint word.

\[
