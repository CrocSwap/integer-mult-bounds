**The actual W45 exit does not meet the 112-H1 premise.** Each of its
56 proposed pair ratios has Fourier rank two. The required common W_R
has rank four. Preparing or removing W_R is not free. A lower bound of
four applies only to one common Clifford which makes these pair ratios
monomial, not to an arbitrary joint decoder.

The growing-frame rank formula is `8 + ((a+j-b) mod 2)`. For frame
transport with `j=0`, alternating types use rank nine at each transition.
For an inserted odd source phase with `j=1`, different input/output
types instead give rank eight. The frame-only schedule has total rank
81 per mode and endpoint rank 73. It is not an odd-source caller invoice.
The endpoint adapters do not restore contents changed by a controller.

This growing family differs from the doubled global lift in
[PR #1719](https://github.com/CrocSwap/integer-mult-bounds/pull/1719),
whose ambient dimension is 146. That result is comparison material,
not an input to this annex. [RELATED-WORK.json](RELATED-WORK.json) pins
the retained historical description and reviewed commit.
