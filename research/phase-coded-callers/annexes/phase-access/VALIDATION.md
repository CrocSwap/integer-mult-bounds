# Validation scope

The runner verifies every byte count and SHA256 in SOURCES.json before
and after execution. It checks decompressed hashes when recorded.
Each old checker runs in a separate private repository copy. Scripts
which write beside themselves therefore cannot change frozen inputs.
All three checkers run normally and with `-O`, using `-I -B` and one
worker. Every complete receipt must match its frozen counterpart byte
for byte. No receipt field is normalized or omitted.

The dyadic checker rejects omission of the selected negative-difference
update. It records a witness that separates K from its transpose, and
checks that K has nonzero off-diagonal entries. The actual W45 ratios
provide a direct failure of the proposed cheaper frame premise. The
rational proof retains the noncommuting counterexample to an unjustified
negative-alignment implication. These controls have different scopes.
The all-width results are not inferred from a bounded matrix sample.

The Walsh checker imports only basis and route arithmetic from the
unchanged verify_bridge_operators.py. It does not call that module's
archive/Git-loading function. All used route and kernel operations are
local. The rational checker imports a pinned earlier independent matrix
helper; the dyadic peer imports no producer or compiler. The runner
changes no import or source code.

[REPLAY.json](REPLAY.json) records the six packaging runs. The accepted
298-file core is outside this annex's replay and remains unchanged;
[CORE-BINDING.json](CORE-BINDING.json) records its manifest. The annex's
own manifest excludes only itself. The related PR1719 metadata is
comparison evidence and is not a mathematical replay input.

This replay does not emit full native phase records for either capture,
prepare or remove W_R, validate new ambient cover routes, restore changed
centre contents, construct a routed owner schedule, price all packed
maps, prove the physical phase grid, or calculate a new complete kappa.
