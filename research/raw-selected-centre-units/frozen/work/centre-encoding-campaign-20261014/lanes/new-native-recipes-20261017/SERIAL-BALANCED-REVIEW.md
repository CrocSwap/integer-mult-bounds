## Independent exact calculation

The checker imports no producer emitter or replay code. It uses the
small exact algebra routines in the pinned check_raw_selected.py from
this review lane. It does not execute that file's old-provider checks.

Each retained core is checked by reverse transpose accumulation over
free invertible warp generators. The check covers 731 columns: 632
live fields, eight owned fields, and 91 private zero buffers. Only
adjacent inverse generators cancel. All nontrivial warp words cancel,
and the result is exactly

    forward:  (x,y,h) -> (x,y+Jx,h),
    backward: (x,y,h) -> (x-Jy,y,h).

The reverse proof holds for arbitrary invertible generator substitutions.
The forward implementation uses the standard warp recipes. The backward
implementation uses the separately checked literal conjugate recipes.
No equality between those two physical recipe tables is assumed.

A separate forward ledger checks every scalar frame, native transition,
signed canonical warp class, and endpoint adapter. Every private buffer
is allocated once, used only while live, and returned at FULL with zero
content. Every retained word is exactly the current CLEAN-J-PROGRAMS
array for its provider and orientation.

The boundary operations are then applied to this full core operator.
This calculation uses a free group of the distinct port-line symbols
Qp. It does not move Q through a dense matrix. It replays the literal
physical exchanges as three ADDs and a negative SCALE at each selected
port. It does not substitute logical exchanges.

All 640 arbitrary input columns of each complete local word agree with
the claimed map. All 408 logical helpers restore under the inherited
native residual-wrapper contract. All eight owned outputs are zero.
The 91 private zero-buffer contracts close. A separate ordered inverse
check recovers all 632 live inputs from the two data banks and helpers.

The new factors touch only the relevant data bank and owned C0. Their

## Actual geometry and endpoint equations

The checker reads R from the new source core and checks RR^T=56I.
Set K=R^T/4 and J=I-KR. Let S be the selected ports and U the other
ports. For k complete selected minors, the actual matrix gives

    R_S K_S=kI,    R_U K_U=(14-k)I.

The two cases are k=1 and k=5. Set lambda=14-k and

    H=J_UU,
    H^-1=I-K_U R_U/(lambda-1).

The independent expected-map calculation uses the more general centre
matrix T=R_S K_S-13I. It obtains T^-1 by exact elimination and checks
both inverse orders. It then uses H^-1=I+K_U T^-1 R_U. It does not
copy the producer's row-factor formula as its expected operation.

Write the data inputs as x=(a,u), y=(b,v), and put q=Q_S^-1. The
balanced backward map is

    X_S'=q b-J_SS Q_S a-J_SU v,
    X_U'=H^-1 u-v-H^-1 J_US Q_S a,
    Y_S'=Q_S a,    Y_U'=v.

For the diagonal-borrowed variant, put c=R_S Q_S a+R_U u. Its map is

    X_S'=q b-Q_S a-K_S c/(lambda-1),
    X_U'=u-v-K_U c/(lambda-1),
    Y_S'=Q_S a,    Y_U'=v.

The balanced forward map is

    X_S'=a+q J_SS q b+q J_SU u,    X_U'=u,
    Y_S'=b,
    Y_U'=H(u+v)+J_US q b.

These equations retain the order of every Q factor. Both backward
variants have physical selected Y equal to F times the original selected
X data. That productive output retains information that cannot be
recovered from X alone in the eight-port case.

The complete two-bank maps are units in their stated coefficient ring.
The eight-port fused original-X response alone has an eight-dimensional
kernel. Exact division by three does not remove that kernel. A decoder
that requires the inverse of this X response cannot use that assumption.
