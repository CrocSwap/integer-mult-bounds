# TCCharge.lean: CORE's PURE-HOLDER RULE (ℓ/μ charge certificate), r13/r14
No sorry. ~6 s, 1.7 GB. Axioms [propext, Classical.choice, Quot.sound] for all theorems below.

**Model.** TokenCancel ops on rows in initial coordinates, columns = `Reg` (Fintype). `vec μ s r = Σ_c row_r[c] μ_c` (μ-charge of register r). `lin`/`konst`: a step acts on charges as `vstep = lin + konst` (konst only for births). `linRun l2` = linear part of the later program; `resp = linRun l2 e_u`.

**Theorems.**
- `vec_step`, `vec_run`, `vrun_add`: charges evolve by an affine program independent of the row data.
- `insertion_charge`, `insertion_rows` (EXACT, no first-order approximation): inserting `u += d·s'` between `l1` and `l2` changes final row[r][col] by `d · row_{s'}(t)[col] · resp_r` (the paper's "d · resp(t,u) ⊗ X(t)").
- `charge_single`: if only column h changes, `Δ_h · μ_h = d · λ · (X_{s'}(t)·μ)` with `λ = ℓ·resp` and `Δ_h` the change of ℓ's reading of column h.
- `pure_holder_rule`: if `μ_h = 1` and ℓ's reading of column h changes, then `λ ≠ 0` (receiver ℓ-live) and `X_{s'}(t)·μ ≠ 0`. So when μ is orthogonal to every ℓ-live-receiver-co-present state, no single insertable op changes ℓ's reading of column h; a pure holder `X = a e_h` has `X·μ = a`, so only a pure holder (or a mixed state with μ-charge) can break the certificate.
- `ins_invariant`, `column_pinned`, `neutral_add`, `neutral_scale`: for ANY number of insertions, each μ-neutral at its moment in the modified run (`InsAt`), every register's μ-charge is unchanged; with `μ_h = 1` an h-confined change is therefore zero (stronger than the ℓ-pairing).

**FINDING (paper statement needs strengthening).** r13 §3 says the rank-one charge "covers every first-order insertion, all ADD/SCALE combos across windows". With the stated hypothesis (μ ⊥ states co-present with an ℓ-live receiver, ℓ-liveness read off the BASE program) this is true for a single insertion (`pure_holder_rule`) but FALSE for combinations: `ce_base, ce_one, ce_two, ce_both, ce_confined, ce_weak_hyp` give a concrete 3-register word over ℚ. `g` (INIT zero at A), `h` (pure e_h at A), `u2` (at B, ℓ = e_{u2}), μ = e_h. ins1 `g += h`: g is not ℓ-live (λ = 0), harmless alone. ins2 `u2 += g` after `g` moves to B: μ ⊥ g in the base word, harmless alone. Together u2 receives e_h: ℓ's reading of column h changes 0 → 1 and the change is confined to column h. Cause: the first insertion makes `g` ℓ-live and μ-charged in the modified program (relay). Corrected statements: (a) single insertion only (`pure_holder_rule`); or (b) the strong hypothesis `μ ⊥ X_s` at every inserted source in the modified run (`ins_invariant`, `column_pinned`); or (c) recompute ℓ-liveness and orthogonality in the modified program after each insertion (not formalized). This matters for r14 §3(a): a clone `g += 1*h` fails (ii) when `g` was born (row e_g + e_h), but an INIT-zero relay would be pure e_h; check whether such registers exist in the word.
