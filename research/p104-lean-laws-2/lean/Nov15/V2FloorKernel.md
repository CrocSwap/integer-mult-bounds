# V2FloorKernel: kernel-only V2-FLOOR lower bound (exact small X + hyperplane cover)

## Result
- `v2floor_joint_kernel` (V2FloorKernel_j.lean): every plan E (strict containments of subspaces of F₂⁹, dims 1..8,
  priced by `wcut θ`, θ = 79793/2^20) realising all 2,625 pairs of pairs.txt (`Reach E (Lsub (LBj p)) (Usub (UHj p))`)
  costs ≥ 987754236107 / 2^30 = 919.9178 (JB units).
- `v2floor_beta_kernel` (V2FloorKernel_b.lean): θ = 1, realising the 1,822 forced pairs (D_beta) ⇒ ≥ 941971821916 / 2^30
  = 877.2796.
- Kernel-only: every data check is `decide +kernel`; no native_decide / Lean.ofReduceBool / implemented_by; no sorry.
- Certificates: a hyperplane-cover dual ("t2s0" cover) found outside Lean and checked by an independent C program (not shipped).
  The Lean check re-derives every row itself; it does not trust flagcert_*.txt.

## The cover (no line flags; FS = 0)
- edge X<Y with a = dim X ≥ 3: any hyperplane H = h^⊥ ⊇ X (`exists_hyperplane`); row (h, a, b) over the pairs with
  L ⊆ H, dim L ≤ a. All 511 h are checked.
- a = 2: X = span{l, w}, l = first basis mask of a served pair's L, w any mask (`plane_decomp`); the kernel enumerates
  every l with a line-table entry and every w < 512 (≈ 26k planes), and recomputes the exact-X row from the line table.
- a = 1: X = span{l}.
- Rows use the τ form of the Gaussian top-M rule (`tau_bound`): Σ_U (W_U − τ_dim U) + Σ_d Mt b d · τ_d, sound for any τ
  (E rows compute τ = Mt-th largest in the kernel; F rows read τ from the certificate). Needs the COUNT LEMMA.

## Files (Nov15/)
- V2FloorKernelLemmas: masks ↔ vectors, parity checks decide `Usub` membership, span of two masks, hyperplane existence,
  dimensions from biorthogonal witnesses, **count lemma `count_le'`**: #{U ⊇ Y, dim U = d} ≤ [9−b, d−b]₂ (double counting
  (U, v), v ∈ U \ Y, induction on d − b). V2FloorCount.gaussian_count restates it (the old sorry stub is replaced).
- V2FloorKernelTau: `tau_bound` + list/finset bridges. V2FloorKernelCheck: Bool checkers + data formats.
- V2FloorKernelSound: `kernel_intFeasible` (checks ⇒ IntFeasible) and `kernel_floor` (⇒ the floor via floor_F2).
  Group injectivity uses probe signatures (19 / 8 probe masks); equal subspaces give equal signatures.
- V2FloorKernelCost: T(a,b) ≤ 2^30·w_θ for θ = 79793/2^20 (log bounds of V2FloorCost); β reuses T_beta.
- Data: V2FloorKernelData_{j,b} (generated by scripts that are not shipped; the generator also emulated every Lean
  row in Python: 0 violations, min slack 2,231 / 1,488 units of 2^-30, matching an independent C flag check).
- Checks: V2FloorKernelBase*_{j,b}, V2FloorKernelE_{j,b}_<l>_{a,b}, V2FloorKernelF_{j,b}_<h> (generated by wchunks.py);
  each declaration is a separate kernel run (kernel memory is per declaration; files ≤ 3.5 GB).
- Final: V2FloorKernel_{j,b}. Build: one `lean -o` per file in dependency order (sequential, one olean per file).
