# Minimum support of the retained gather row code

The independently checked finite chamber reduction sends any nonzero real
query to a vector with nonnegative simple-root pairings. If a pairing other
than the unique 57-support fundamental ray is positive, the full query
support contains a fundamental support of size at least 78. Removing eight
ports leaves at least 70.

Otherwise, only the 57-support pairing is positive. The query is a positive
multiple of that fundamental weight. Twice that weight is a literal root.
Simple reflections permute roots, so the original query is a multiple of a
root direction. All 120 root directions have full support 57. They meet the
removed coordinate axes in one or four nonzero inner products. Their
retained supports have size 56 or 53.

Thus every nonzero query in the retained real gather row code has support
at least 53, and a four-support root direction attains 53. A nonzero complex
query contains the support of a nonzero real or imaginary part, so the same
minimum applies to the complex row code.

The statement uses the current Gram gather row space. Query rows outside
that space, including rows in redundant decompositions, are outside this
bound. No higher generalized Hamming weight is claimed.
