the numerical values of constants that PR1673's own text and audits declare free, each needing only to be strictly positive:

| constant | PR1673 | here | why free (PR1673 source) | exact dκ |

| backoff after truncation | 1e-11 | 1e-17 | "fixed logarithmic factors absorbed by strict gaps" (note; OUTER-AUDIT) | +1.0000e-11 |
| layout (boundary) slack s0 | 1e-5 | 1e-12 | "positive boundary slack" (CAPPED-INTERIORS) | +2.8121e-11 |
| r0 (spare logarithm power) | 1e-6 | 1e-12 | only eventual u=α²≤p^r0 (OUTER-AUDIT) | +2.8121e-12 |

| decimal floor | 1e-18 | 1e-30 | rounding grid only | +9e-19 |

Total gain over kappa 0.001677201606748643: +1.40647e-10 (κ = 0.001677201747396342691754270404; the limit of all slacks → 0 is +1.40658e-10).
The binding rows are unchanged: main transform = fused Gaussian (balanced by construction) and the capped boundary row (saving + s0);
all 45 (Strassen) and 47 (matrix) strict inequalities and the 5/6 rejecting controls are regenerated by `check_ledger.py`; `independent_check.py`
re-derives the balance independently. The remaining loss b − κ = 2.55e-6 is the structural factor ε = 0.99848 set by the boundary constant
c = 3/32 (ω < 45/16); it is not a slack.

(0.001677201747396342691754270404) is the baseline of the omega table.
