## Response and physical contracts

Let E be the actual physical response and J its physical diagonal
metric. The checker confirms both inverse orders, the exact
inverse-transpose matrix, and

```text
E^-T = J E J^-1.
```

The physical metric has 80 entries 1, sixteen entries -1/2, and
sixteen entries -1/4. Thus J and its inverse are dyadic units.
The actual pair basis gives zero mode diagonal for both E and E^-T.

With Q the positive portwise line, q=Q^-1, and F the common
nine-axis advance, the direct contracts are

| Word | Input | Output |
|---|---|---|
| forward E | (Qx,y) | (Fx,Fq(y+Ex)) |
| backward transpose E | (Qx,y) | (F(x-E^T y),Fq y) |
| forward inverse adjoint E | (Qx,y) | (Fx,Fq(y+E^-T x)) |
| backward inverse E | (Qx,y) | (F(x-E^-1 y),Fq y) |

All factors keep this order. In particular, the response matrix is
not moved through the field-dependent Q.

For each direct forward word, the checker takes the accepted source
transfer positions and obtains the new coefficient from H E H^-1
or H E^-T H^-1. It removes exactly the zero transfers. All other
scalar events and all native events retain their exact source bytes.
The complete resulting event lists equal the emitted lists.

## Literal inverse adjoint

For a chronological word G1,...,Gn, the physical operator is
M=Gn...G1. Its inverse adjoint is

```text
M^-* = Gn^-* ... G1^-*.
```

Thus the chronological order stays fixed. A real ADD(t,s,c)
becomes ADD(s,t,-c), and a real SCALE(c) becomes SCALE(1/c).
Each native unitary and each endpoint monomial is unchanged,
including its phase.

The checker compares both complete backward event lists with this
literal transformation. It does not merely check their expected
cross blocks. At each transposed ADD, the two fields still have the
same ordered frame. Scalar instructions do not change a frame, so
the unchanged native chronology gives the same full frame ledger.

The endpoint adapters are also unitary and unchanged. If

```text
M = diag(F,Fq) S_E diag(q,I),
```

then the same two endpoint factors occur in M^-*. The content shear
changes from `(x,y+Ex)` to `(x-E^T y,y)`. Applying the same argument
to the E^-T forward word gives `(x-E^-1 y,y)`. This proves the
physical table without an extra chart transition.

## Metric wrappers

The forward metric wrapper applies J^-1 to both input banks,
runs the forward E word, then applies J to both output banks.
Its cross block is J E J^-1=E^-T.

The backward metric wrapper applies J to both input banks,
runs the backward transpose word, then applies J^-1 to both
output banks. Its cross block is

```text
-J^-1 E^T J = -E^-1.
```

J is a scalar diagonal on physical fields. It therefore commutes
with every field's spatial operator even when different fields have
different frames. This is not an assumption that J commutes with E.

The checker verifies every prefix and suffix scale, its actual
field, and its actual input or output frame. It verifies that the
whole core between those scales is unchanged. Scales on distinct
fields can occur in different orders; the exact per-field action
is checked. Each wrapper contains 128 added complex-field SCALE
instructions, with a cost of 640 real scalar primitives. A
one-bank metric price would omit the baseline restoration in
the other bank.
