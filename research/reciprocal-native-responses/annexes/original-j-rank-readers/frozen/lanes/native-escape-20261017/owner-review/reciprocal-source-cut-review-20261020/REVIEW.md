## Ordered local and routed operators

The independent reconstruction gives

```text
E=P R,    E^-1=R P,    P^2=R^2=I,
R=I+U ell,             ell U=-2 I16.
```

Physical P has 160 nonzero entries and is not monomial. Its selected
anchor rows are identity rows. These facts do not permit P to commute
through the port-dependent Q.

Use the pinned native contracts

```text
(Qx,y) -> (F x,F q(y+E x)),
(Qx,y) -> (F(x-E^-1 y),F q y).
```

Pre-multiply current-I Y by P. Post-multiply raw FULL X by P. The first
contract then gives logical outputs `P x,P(y+R x)`. The second gives
`P(x-R y),P y`, because `E^-1 P=R`. Thus the common-P forward and
backward shears have the stated order. Each P acts where all fields
have a common body frame. No q factor crosses P, R, U, or ell.

Define the routed reader by

```text
ell_s = Gamma_c,s ell Gamma_s,
```

where Gamma_c,s uses the actual sixteen anchor routes. Let

```text
t=y+R0 x,
w=x-(P0^-1 R1 P0)t.
```

After F0, the logical banks are `P0 x,P0 t`. After B1, they are
`P1 P0 w,P1 P0 t`. The raw X argument at F2 is therefore `P1 P0 w`.
The independent free-operator calculation obtains

```text
c0=ell0 x,
c1=ell1 P0 t,
c2=ell2 P1 P0 w.
```

Only adjacent equal P_s factors cancel in this calculation. A check
rejects the replacement of `P0^-1 R1 P0` by R1. This is an ordered
operator proof on arbitrary x and y, not a numerical matrix sample.

## Literal frame return at each cut

The D25 record stores the entry shift before rho and the exit shift
after rho. Thus

```text
V_in=P_rho T_delta0=T_(rho delta0) P_rho.
```

The checker uses this convention. It verifies 1,792 exact phase
identities: eight identities for each of 112 ports at each fresh stage.
These include both entry types, both exit types, the inverse entry,
and the literal inverse orders. All 336 routes also have the required
port labels, orthogonality, involution, and fixed own line.

The identities that determine the records are

```text
V_in,s Fprev       = Fext,s Q Gamma_s,
V_in,s Fprev q     = Fext,s Gamma_s,
V_out,s Fnext      = Fnext Gamma_s,
V_in,s^-1 Fext,s   = Fprev q Gamma_s.
```

At F0, read raw FULL X after the complete native service and before
post-P0. The source is F9 x. A same-frame accumulator receives F9 c0.

At B1, read current-I Y before pre-P1 and before the native service.
The incoming global source is F9 q P0 t. The entry view gives the body
source `Fext,1 Gamma_1 P0 t`. A same-frame accumulator receives
`Fext,1 ell Gamma_1 P0 t`. Its inverse entry view returns

```text
F9 q_anchor Gamma_c,1 ell Gamma_1 P0 t = F9 q_anchor c1.
```

This is a hole record. It is not FULL. The independent checker rejects
the proposed FULL return at all sixteen anchors of both fresh stages.

At F2, read raw FULL X after the complete native service and before
post-P2. Its body value is `F25 Gamma_2 P1 P0 w`. The centre FULL exit
returns `F25 Gamma_c,2 ell Gamma_2 P1 P0 w=F25 c2`.

The accumulated P factors are in the current source values. None of
these three reads requires a separate old-chart query. This fact does
not give an accumulator its required frame or owner lease.

## Conditional scalar operation and price

The physical ell has eight rows of length ten and eight rows of length
seven. It has 90 negative and 46 positive unit entries on 96 source
ports. The conditional reader applies 136 complex ADDs.

The independent body replay uses all 112 arbitrary source columns and
all sixteen arbitrary accumulator columns. It proves

```text
(source,acc) -> (source,acc+ell source).
```

Every source value is unchanged. Every accumulator retains its old
value. The local prefix row one-norm is at most eleven, and this bound
is attained. The word has integer coefficients and introduces no
binary or odd coefficient denominator.

The pinned scalar tariff prices a complex signed-unit ADD at eight
real units. One reader therefore costs 136*8=1,088 units. Three reader
formations cost 3,264 units if all required typed accumulators are
supplied. These prices exclude accumulator views, preparation, storage,
transport, leases, and a later erase. An immediate inverse ADD word
works only while its source is unchanged; it does not prove late erase.
