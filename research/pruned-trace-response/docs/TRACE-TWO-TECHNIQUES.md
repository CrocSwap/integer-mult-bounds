## 1. Ordered-product transport across a certified trace

Let an F2 state have arbitrary initial coordinates. A transvection T(t,s) changes coordinate t by adding coordinate s, with t != s. Two such gates commute if neither destination is the other's source. This follows by expanding both two-step coordinate updates; the cross terms are precisely the two excluded incidences. Therefore a gate can cross a whole interval when this condition holds against every interval gate. No values, clean-input assumptions or hidden cancellation oracle are used.

A frame-labelled transport is sufficient when the relocated gate frame contains both operand predecessor spaces and is contained in both successor spaces. Exact rational row reduction tests these inclusions in the physical frame representation. ## 2. A critical-pair completion that removes an existing correction

For distinct coordinates i,j,k over F2, consider the chronological sequence

    i += j; i += k; j += k.

Its result is identical on every input to

    j += k; i += j.

Indeed the original output is (i+j+k,j+k,k); so is the replacement. In matrix notation this is the elementary Steinberg chain commutator, with the existing i+=k gate cancelling the correction required to exchange the noncommuting i+=j and j+=k gates. The correction commutes with both other gates. This differs from a trace exchange, because the two principal gates do not commute and a gate is removed.

For nonadjacent occurrences, first transport the later principal gate through an explicitly commuting interval and transport the correction through its explicitly commuting interval. Only then apply the local identity. Reassign the two remaining gate frames using the same predecessor/successor sufficient condition, and regenerate literal inverse cleanup. This proves a full arbitrary-dirt operator identity; no observability quotient is required in this second step.
