# Implementation and evidence boundaries

Separate Before Serializing Shared State led to a new package and one owned
branch, status file, claim and cache directory. Only Git metadata operations
use the shared OS lock. No peer artifact is written. Prove It Works led to
the exact caller/source map, complete original-cell differential check and
committed-byte/export checks recorded in CHECKS.json.

The falsifiable predicate is the mixed 5,5,6 theorem plus historical caller
transfer in PROOF.md. The generic card's first working example was run and
passed, but its supplier packing ceiling is only context for this side result.
No favorable physical invoice or supplier admission is inferred.

The Power of Ten inspection found no recursion in new code. Root generation
is bounded by 120 roots,112 live coordinates and 8 simple roots. Fiber code
has 128 possible seven-bit vectors,127 nonzero functionals and 2,667 distinct
two-dimensional annihilators per fiber. Plane enumeration has 7,140 pairs
and 1,120 A2 planes. The historical differential check has 7,546 multisets,
at most 10 pieces and 16 bin assignments for four small pieces. Source reads
are bounded at 2 MB, with fixed local manifest inventories. Output creation is
exclusive and resource scopes close on every exit. Mathematical guards are
explicit exceptions and remain active under optimization.

Rule 3 deviation: CPython and Fraction allocate during computation. Fixed
dimensions and collection sizes bound live state. Source input size guards
bound allocation at the file boundary. No solver, dynamic evaluation,
recursive traversal, background process or network call occurs in replay.
The inherited geometry and frozen historical program are unchanged; their
managed allocations have the same finite domain bounds. A native fixed-memory
rewrite is warranted only if a concrete resource constraint requires it.

Rule 9 deviation: the test harness imports the frozen original bk 2 b module
after selecting its fixed vendor directory. Its top-level table has exactly
24 cells. The primary imports one authenticated geometry module from a fixed
declared input path. Both are finite, visible targets. A registered replay
uses the repository's fresh bytecode namespace; direct export checks use
fresh source trees. No inherited bytecode is included in the export.

Rule 10: strict Ruff E/F/B/I/UP/C4/SIM checks and formatting apply to both new
Python files. Frozen vendor code is retained byte for byte. Global tooling
configuration is outside this package. Registered warnings-as-errors replay
and optimized behavioral checks supply recurring diagnostics. Test code
checks the original compiler-free user entry point, mathematical rejection
boundaries and inherited source capacities. No TypeScript/JavaScript is touched.

Every new function is inspected for size and responsibility; the geometry
receipt contains one bounded reconstruction pipeline. CHECKS.json records
function sizes and any remaining one-page exception. Existing global flat
censuses are deliberately inherited, not silently recertified here.
