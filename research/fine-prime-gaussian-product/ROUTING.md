# Permuting the coefficient and Gaussian image streams

Write the physical moduli as s[0], …, s[d−1], with physical axis 0 fastest. The triangular converter orders its logical source factors in reverse. It sends integer exponent k to the physical coordinate y[i] = k / ∏(s[j], j>i) mod s[i]. Division is by a unit. The map is additive, is injective by pairwise coprimality, and has equal domain and codomain sizes. Thus it transports cyclic convolution to tensor convolution. Inverse conversion uses precisely the same map. PR4024 gives the triangular shift decomposition. PR4100 uses the prefix product with a different labeling of the fastest physical axis. The product proof only requires the explicit additive isomorphism above.

In logical order put P[i]=∏(s[j], j<i). The ordinary coefficient k has digits a[i] with k=∑a[i]P[i]. To form its image, rotate coordinate i by the prefix sum ∑a[j]P[j]/P[i] mod s[i], j<i. Run i in descending order. The controlling prefix is still original. Ascending order with the opposite shift recovers the digits. On the padded rectangle a bad prefix disables its rotation. Valid prefixes rotate only the first s[i] positions. Each invalid target tail remains in place. The full forward and inverse therefore preserve the globally valid box and its complement, including arbitrary dirty tail data. Both CRT compact restrictions check that every removed payload is zero. The input to the whole converter is borrowed. Head restoration, separate owned full banks, erasures and output copies are part of the program.

## Address-bit permutation

The compiled wiring reverses order of coordinate fields and preserves order of bits within each field. The two reflections j↦−j and j↦1−j on every permutation cycle compose to give j↦j+1. Each reflection is a product of disjoint binary-address bit exchanges. Partition each matching into batches of at most h edges, then execute three directed XORs per batch. For controls c and targets z, write D=(-1)^(c·z). If H denotes the unnormalized Walsh matrix on the selected target bits, the bit exchange service first forms 2^h times the incoming integer records, applies H/2^h, reads D, and applies H/2^h again. Summing over the middle address gives the coefficient of an input with the unique index z⊕c. All divisions reach integers. The high word can grow by O(h) bits before the completed step. Use the selected grouped service on precisely the target bits in a whole complete global rectangle. Control and spectator bits remain present. If the supplied service has cost O(V h^(1−q) polylog p), at most O(p/h+1) batches give O(V p h^(−q) polylog p) for the whole wiring. For h=Θ(p^.997) and the rate q=.001737 from the C word and the ordinary rectangle there is strict room below the outer power .998269… . The weaker #4100 q=.001730979… does not by itself give that strict room for this router at this h.

For a CZ phase store the p-bit binary address as one small record per bit, with a separate sequential page of mate positions. Flipping bit j changes parity by the current mate bit. A ripple can flip both endpoints, so update parity before each individual bit changes. Each toggle moves the address head by O(p) bit cells in the worst case. The mate page costs O(log p) bits per consumed index and rewind. Across all T addresses there are fewer than 2T bit toggles. Thus even arbitrary far-apart paired positions cost O(T p+T log p)=O(V) per CZ pass. The mate page is set up once per layer in polynomial time. Each emitted sign operates on a full two-component word. Exchanging arbitrary pairs by this construction uses linear scans between grouped calls.

## Nonlinear rotations and interval masks

For fixed i, there are B_i=∏(t[j],j<i) prefix rows. Their remaining suffix has length u=∏(t[j],j>i). Read the modulus, bit radix, and modular coefficient for each prefix digit from a sequential table. Rewinding it plus digit extraction, modular arithmetic and row extent preparation costs poly(p) per prefix. B_i≤T/t_min. In each row copy in order the intervals [cut,s[i]), [0,cut), [s[i],t[i]), each with the complete u-record suffix. The two repositionings and all copying travel O(t[i]u) records, including any zero-length interval. For arithmetic prefix work, total cost per converter is O(d T poly(p)/t_min)=o(V) since t_min = 2^Θ(p^.003) is eventually larger than every fixed polynomial in p. The nonlinear scans cost O(d V). Splitting the three conversions into two direct and one opposite direction changes only the constant. Reuse a fixed number of long scratch tapes. Geometry costs polynomial(p). Include the selected grouped child's actual space separately.

For the ordinary rectangular mask accept digit x when x<s. For the Gaussian mask let q(j)=floor(tj/s+1/2). At target x, test its unique candidate j=floor(sx/t+1/2) and require j<s and q(j)=x. This recognizes exactly the occupied target positions because |s q(j)/t−j|≤s/(2t)<1/2. A carry-updated count of bad digits recognizes the tensor product. Each changed digit reads its actual source and target sizes from a parameter tape, updates a separate digit and validity bit, and restores the lower cursors. At most 2T digit changes occur. Every operation acts on O(ell)-bit coordinates, so its schoolbook arithmetic costs O(T ell²), which is O(V) for ell=Θ(p^.003). Scatter fills all other positions with zero. Original-coordinate extraction consumes every target record and returns the indicated positions in the original order. Gaussian extraction permits dirty holes after a physical opposite transform. The CRT crop independently rejects nonzero invalid padding.

## Sparse Gaussian rows

`sparse_tapes.py` uses the bordered factors and stability argument in `SCHUR.md`. Its multiplication reads cyclic source windows in increasing order. Adjacent rows move O(w) target records, except at the circular seam where O(w) rows can each cross a complete line. This still costs O(a(w+1)) for a rows. The forward bordered solve keeps the last w row partial sums on their own tape. The backward solve keeps the solved far border and the solved near core on two distinct tapes. Reading the border in every core row therefore costs O(w), including each rewind. The forward intermediate goes from ascending write to descending read. Every dyadic coefficient and reciprocal is read in the serialized order of its page for every complete line. A separate physical bit counter charges the coefficient page import, all rewinds and erasures. Every real-by-complex product uses two signed word products, after which it drops bits toward zero. Every result and sum must fit the declared component width. The producer gives O(p) external precision plus an explicit per-axis guard. One line costs O(a(w+1)(M(p)+p)) bit operations including all physical memory movement. The sparse line and independent baseline return to the original global index order before they are added.
