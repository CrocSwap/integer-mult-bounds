exact finite replay, source pins and failure controls. The changed card scope
is recorded in TASK.json. This is a local theorem, not supplier admission.

## Power of Ten inspection

New code has structured control flow and no recursion. Every enumeration has
an explicit finite domain: 120 roots, 2,025 frames, 30,000 frame-search steps, 120 root
generators, 58 mixed vertices, 40,000 retained clique states, nine-bit flat equations,
at most 150 candidate supports per inventory and 1,698,750 union triples. The
predecessor subprocess has a 120-second deadline; registered commands have
180-second deadlines. Exhausted capacities raise ValueError. No solver runs
concurrently with another artifact generator.

Rule 3 deviation, managed Python allocation: integer arithmetic, Fraction,
Counter and bounded containers allocate dynamically. A fixed-allocation
runtime would require replacing the standard-library exact arithmetic and
rewriting frozen dependencies. Scope is one bounded finite replay process.
The enforced domains above bound live collections; flat enumeration streams
its 6,619,494 spaces rather than retaining them. Candidate sets contain at most
150 masks each. Fractions are eight-dimensional. This is not a fixed-byte heap
proof or inspection of CPython internals. CHECKS.json records actual checks;
a runtime port would need its own allocation and stack validation.

New functions stay below 60 physical lines and keep one responsibility each.
Meaningful require guards protect source pins, geometric invariants, complete
counts, domain bounds and the final strict inequality. They remain active
under `-O`. Mutable state is local to enumerations. Calls propagate failures;
subprocess status and stderr are checked. Output is external and exclusive.
There is no eval, code generation or dynamic import selection.

Rule 9 deviation, unittest dispatch: the standard unittest runner discovers
fourteen fixed test methods. Its targets and lifetime are confined to the
registered test process. Production mathematical calls are direct. The
alternative would replace the repository's normal test framework without
changing the proof; a framework change must preserve every control.

Retained vendor files are byte-pinned predecessor inputs, not reformatted or
rewritten for style. Their import graph is acyclic for the invoked paths and
their finite loops are bounded. Unused b=8 predecessor entry points remain in
the unchanged source archive and are not called. This preserves source identity;
the copied code is not represented as a new independent implementation.

Rule 10 diagnostics run with warnings as errors and focused Ruff checks for
new Python paths. Shared CI configuration and historical packages are unchanged.
Unavailable proof-kernel and independent human review are explicit limits,
not checks reported as passing.
