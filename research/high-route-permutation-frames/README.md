# Carry field permutations through selected BIT routes

PR2915 restores field order around every reversed ADD, paying two complete
ordinary-interchange calls each time. This opt-in compiler carries the
permutation through later affine factors and restores it at the end. It
emits ordinary source-compatible factor words; the physical executor stays
unchanged. The exact permutation invariant is in [PROOF.md](PROOF.md).

For the actual selected registry and retained occurrence multiplicities,
the complete entrance/return invoice falls from **409,100,288 to
287,858,688 B1 calls**, a **29.64% reduction**. The census covers all
1,123 chart types, both orientations and 64 row copies. These are finite
route-invoice counts, not executed selected GL64 payloads or a new recursive
child profile. The selected kappa remains 0.001672660197076918.

The compiler charges the final permutation and the extra setup from explicit
swaps. It accepts a candidate only if native calls strictly decrease and the
complete setup/adapter upper-bound coefficient does not increase. Under the
same-domain uniform native tariff and the pinned, pending PR3301 traffic
proof, the whole local bound is therefore no larger for every admitted
width. This compares complete upper bounds, not unknown actual native times.
Fewer calls alone is insufficient: a rejection control shows seven calls
falling to five while the paid setup/adapter coefficient rises.

## Scope and evidence

actual old and new registries also compile every matrix at the identity low
class for q=3, checking all low/carry endpoints and unchanged scalar bills.
The source proof covers arbitrary legal low classes. Six complete physical
baseline/optimized fixture pairs check 8,407 independent input columns,
arbitrary Boolean contents, complete spectators, borrowed sources, owned

Each Tape read, write or unit move is counted once between complete route
entry and return. Every native interval is included and separately reported.
Fixture setup and final returned-output disposal are outside these measured
intervals. No weaker exactness or cleanup check is used for the optimized
case. [RESULT.json](RESULT.json) binds the full typed receipts;
[CATALOGUE.jsonl](CATALOGUE.jsonl) gives every chart's calls and paid setup delta.

## Reproduce

From the repository root with standard-library CPython 3.12:

```sh
python3.12 -B scripts/research_package.py --package research/high-route-permutation-frames
```

Expected: all four `PASS_HIGH_ROUTE_FRAMES_*` suites and successful registered
replay. Normal exact-map/physical checks and optimized rejection controls are
included. [VALIDATION.md](VALIDATION.md) records the actual final execution.

In an authenticated PR2915 source namespace, use
`frames.optimize_registry(registry)` after `selected_registry(catalogue)`.
It returns a separately validated registry with the same chart keys. Pass
that registry to the unchanged StagePool/Adapter construction. There is no
production monkeypatch, lazy runtime wire renaming, or change to the selected
geometry. `scheduled_registry` is an optional class factory used by the small
fixture harness. Runtime numerical decoding and new physical allocation
remain prohibited by the inherited fixture guards.
