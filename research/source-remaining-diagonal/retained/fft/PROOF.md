## 3. Exact numerical substitution

For every admitted signed multiplication, the actual component magnitudes
are below 2^u at the supplied positive width. Negative signed extrema do
not violate this: a width-u two's-complement magnitude is at most 2^(u-1).
The FftWord return is the same padded unsigned bit string that the prior
WordProduct contract supplies. The retained Arithmetic consumes that string
and sets the sign to the original XOR of operand signs. Its exact signed
result is consequently identical, including zero and aliased squaring.

The complex service uses four such products followed by exact signed sums:

```
real = ac-bd;    imaginary = ad+bc.
```

Only after those full numerators exist does the unchanged Full `product`
method perform its temporary-width checks and one componentwise toward-zero
division by 2^F. Output-width checks and signed serialization are unchanged.
There is no new coefficient or data error at this replacement boundary.

Induct over the chronological physical Full program. At entrance the same
input-radius squares, accumulator and comparisons give the same admission.
The lift is unchanged. At a D event every rounded suffix and data product
is identical by the exact scalar argument; the same pages are scanned and
the same state is emitted. At an H event the input bits, metadata and
boundary are unchanged, so its inherited contract supplies the same raw-H
result and frame. Thus every completed stage has the same state and the
same final protected output as the published global rounded Full execution.

The complete source tensor error, prefix bound, data/coefficient precision,
temporary headroom and stored-inverse consequence are therefore inherited
without reducing any width or moving any rounding. This is an exact
replacement argument, not a numerical-continuity estimate for separately
rounded trajectories.

The FFT branch used here satisfies the retained numerical audit domain.
For u above any fixed cutoff K>=2, CrocSwap/integer-mult-bounds#3787 chooses beta=ceil(log2 u),
q=ceil(u/beta), minimal r=2^ell>=2q and p0=2beta+ell. Hence p0>=2 and

## 4. Complete scalar and global invoice

The fixed production cutoff is **4096**. The constructor may compile another
fixed K>=2, but this theorem fixes K independently of input width. Allowing
an input-dependent cutoff to grow with u is outside the stated uniform
fast bound. Every retained base leaf within WordProduct remains 16.

For u>K, CrocSwap/integer-mult-bounds#3787 includes the complete unamortized RingProduct setup:

```
O(r(ell+1)p0^(8/5) + r p0^3 + p0^3),
```

plus packing, fit checks, exact carries, full return copying and cleanup.
Since r=O(u/log u) and p0,ell=O(log u), this is
`F(u)=O(u log^2(u+2))`. Its finitely many widths u<=K satisfy the same
asymptotic bound with a constant depending on fixed K. The signed wrapper
and complete complex sums/truncations add O(u), so they preserve this rate.
No twiddle table is assumed free, shared across scalar calls, or precomputed
by a multiplication oracle. The sharper setup expression in CrocSwap/integer-mult-bounds#5110 is
consistent with, but unnecessary for, this asymptotic substitution.

Retain the published notation: T=K_label N^g=2^n complete Gaussian records;
H,D are actual global event counts; W0 is incoming component width; W is
the common data word width; U=max(W,W_d,W_c,W_t). The complete bill is

```
S_Full + S_encode + S_constructor
  + O(T F(W0+n+1) + T U
      + D T (F(U)+U)
      + poly(n + log(U+2) + log(H+D+2)))
  + H C_H(n,W+g,g).                                      (1)
```

The radius term includes all 2T physical squares and the exact accumulator,
whose safe width is O(W0+n). For every D event the retained geometric
suffix expansion uses fewer than 2T coefficient complex products and T
data products. Each includes four scalar calls, exact sums, one rounding,
copies, rewinds and disposal. Its encoded per-label cardinality cost is
already included by the predecessor's geometric bound; it has not become
a free random-access table. H's complete bill includes its lift, routing,
stock, return and exact sign-only shrink.

S_Full includes actual source construction, validation, exact coefficient
heights and conversion to all F-grid pages. S_encode includes complete
page/metadata serialization; S_constructor includes both the retained
native owner and the new fixed scalar/port inventory. None is absorbed
without the predecessor's stated source-size and growing-group hypotheses.

In the previously stated family U,W0,n=O(p), W=Theta(p), V=Theta(Tp),
equation (1)'s scalar/admission term becomes

```
O((D+1) V log^2(p+2)).                                  (2)
```

For actual synchronized Full words D/H=(8m+3)/(8m+2)<=11/10. Under the
retained complete H tariff, the H contribution is

```
O(H V [g^alpha log p + (g+1)^eta (log p)^(1+eta)]),
alpha=99827101/100000000,   eta=332353/332929.             (3)
```

For any fixed 0<beta<.997 and g=Theta(p^beta), (2) is subordinate to (3)
up to the same paid Full depth. The former condition
`beta*alpha > log2(3)-1` is no longer required. For constant or more slowly
growing g, keep the complete sum; this does not assert uniform absorption
of every logarithmic factor. The native domain n=Theta(P), g<=P^.997,
P=W+g, and any initial whole-field gather remain required. In particular
gm<=P^.997 follows eventually only under the stated strict exponent and
m=O(log p). This is a source-rate consequence, not outer admission or κ.
