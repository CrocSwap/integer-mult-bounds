A minimal export contained this package and precisely the declared live input
files, with no `.git`. All source files were chmod 0444 and directories 0555.
Direct commands were launched from unrelated `/tmp`, with `-I -O -B`, and
compared the existing receipts without regeneration. The primary passed in
57.959 seconds and the boundary checker in 16.336 seconds. The corrected
independent command passed in 25.446 seconds. Changing the recorded helper

The generic metadata launcher itself needs Git provenance; this export tests
the mathematical commands, not an undocumented Git-free metadata mode.

Changing one byte of the credited local audit in that export caused the
primary to fail with `source SHA256` before compiling it. The original bytes
were restored. Native phase controls detect omitted entry/exit correction,
unrouted entry translations and the wrong inverse-Y sign; the primary catches
an actual global-phase adapter fault and a wrong common-frame event. Other
controls omit B1/bridges, reverse a backward sign or inject a live helper.
Support-control failure means the sufficient zero-demand premise fails; it
is not advertised as a full mutated native terminal counterexample.

Default verification is read-only. Receipt generation is an explicit
`--write NEW_PATH` mode that refuses existing destinations. All generated
receipts were inspected; only this new package is in the contribution diff.
Private prompts, session logs and reviewer working notes stay outside Git.
