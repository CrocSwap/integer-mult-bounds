`["MOVE",415,3,99,false]`. Its offset 1 flips output coordinate zero **after
the source linear matrix**. In the packed `[P] x [2^f]^9 x [S]` order this
is the slow coordinate a0, so the produced lengths are

`P'=P`, `R=2^f`, `B=2*S*r*w*2^(8f)`.

phase, central child, full native invocation and selected caller/owner/format
