## Clean replay

From the repository root with CPython 3.12 and assertions enabled:

```sh
python3.12 -B scripts/research_package.py --package research/bit-terminal-main-bank-stock
```

The checker authenticates the exact native word, invoice and directed interval
arithmetic from canonical #7001 paths. It reconstructs terminal ownership and
all coefficient classes. A separate projective-normal enumeration and
marked-pivot elimination checks every class. No external data, prior run state
or extra Python packages are required.
