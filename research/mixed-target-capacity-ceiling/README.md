each. The best permitted target relaxation is

```

```

P includes both native FULL profiles, the 112 H1 query bank, and all helper
complements `94 H1+14 H2+56 H5`. Completed lower-rank helpers are not credited
a second time. Scratch/query fields earn no arbitrary-input productive reward.

