## Two certificate methods

The forward engine keeps q as a formal residue class and all 18 D variables
as formal monomials, with exact Gaussian rational input coefficients.
The backward engine uses output covectors, transposed gate propagation,
separate integer-dyadic arithmetic, and four exact q characters while still
keeping every D formal. Injectivity of those four characters supplies the
universal q identity. It does not import the forward implementation.

The 27 meaningful failure controls include missing/changed QSELF, unrelated
input contamination, repeated D factors, q periods two and eight, total-Q
LAMBDA phase, omitted return translation, omitted inverse basis, ownership
and lifetime faults, understated paid rank and a helper/main alias. Several
critical algebra controls also fail in the separate backward engine.

A proposed forward-for-inverse basis mutation was initially expected to fail.
It did not: all 96 actual stored bases are involutions. That substitution is
equivalent and is recorded as an accepted equivalence, not counted among the
27 rejected negative controls. Omitting the inverse map altogether is the
meaningful failing control. This is an audit of control validity, not an
implementation defect or evidence of a mathematical obstruction.
