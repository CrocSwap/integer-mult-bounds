# E-free caller certificate and owned QSELF lowering

**No new κ. Conditional caller/compiler-interface progress.** Prepared for
**@CubeJerry**, with substantial OpenAI assistance. Apache-2.0.

DreamingOfClouds' [#6937](https://github.com/CrocSwap/integer-mult-bounds/pull/6937)
supplies an E-free two-chain root and caller, but its new QSELF instruction
is outside the retained public QUERY alphabet. This package gives that exact
caller a reproducible operator certificate, constructs typed expansions of
both QSELF sites in the existing owned-bank lifecycle, and checks the source and cost change
against [#6936](https://github.com/CrocSwap/integer-mult-bounds/pull/6936).

## Results

- The exact 2,991-event, 76-field caller is diagonal over
  `Q(i)[q,D_1,...,D_18]/(q^4-1)`, with all D variables formal and all input
  fields independent. The forward certificate peaks at 2,713 monomials.
  A separate reverse-covector engine uses integer dyadics and all four exact
  q characters, still retaining every D variable formally.
- Event 457 on A role 0 and event 575 on A role 19 each have 96 instances.
  Each expands to INIT, COPY, query-in, PAID(1), query-out, SWAP, CLEAR through
  unchanged lifecycle IR classes. One outer query bank is reused; it has no
  productive credit. The canonical ownership contract explicitly permits
  the correlated copied value and erasure after the completed child returns.
  This is a relative typed-IR expansion: this package does not install a
  service registry for the new `qself6937` tokens. The old source-specific
  binders are not implicitly extended by accepting these IR opcodes.
- Two nine-axis maps and the Q² return translation implement Q^-1 with its
  exact absolute phase for every positive tensor-column count. Complete
  field shape, grid, signed range and all physical providers remain declared
  interface obligations. The prototype never uses a Python Gaussian callback
  as evidence of tape execution.
- The complete profiles lose 192 targets and 192 paid calls, all at rank one.
  Thus the moment polynomial is unchanged for every κ; surplus remains 1520.
  The new complete counts are 23,050 productive fields and 117,846 paid calls.
  Under the inherited scalar/routing conventions, including an explicit
  extra 24,576-unit lifecycle charge, the conservative double-recharged raw
  bill is 811,461,936, below 10⁹ by 188,538,064.
- The standalone copied-bank/SWAP scan remainder has a separately derived
  physical bound. The unchanged INIT, COPY and CLEAR routines are metered on
  84 cases with widths 1 through 129, mixed component widths and dirty backing.
  Twenty-seven meaningful algebra/source/phase/ownership/invoice controls
  reject. A proposed forward-for-inverse basis mutation is correctly classified
  as equivalent because all 96 stored bases happen to be involutions.

See [PROOF.md](PROOF.md) for the quantified theorem, exact operation semantics,
all-column identity, physical scan calculation, stock, error propagation and
the limited formal determinant obstruction. [RESULT.json](RESULT.json) stores
the complete replay receipts; [QSELF-PATCH.json](QSELF-PATCH.json) stores all
192 source-bound IR expansions. That patch is a template artifact, not a
claim that the full physical caller has been executed.

## Reproduction

Python 3.12 standard library; no network, external executable, install or Git
history is needed for the four package checks:

```sh
python3 -I -B research/p104-qself-owned-lowering/verify.py --suite formal
python3 -I -B research/p104-qself-owned-lowering/verify.py --suite closure
python3 -I -B research/p104-qself-owned-lowering/verify.py --suite invoice
python3 -I -B research/p104-qself-owned-lowering/verify.py --suite controls
```

Expected markers are `PASS_QSELF_OWNED_FORMAL`, `PASS_QSELF_OWNED_CLOSURE`,
`PASS_QSELF_OWNED_INVOICE`, and `PASS_QSELF_OWNED_CONTROLS`. VERIFY.json registers
all four in normal and optimized Python; the checks do not use removable
assert statements. In a canonical checkout, validate and run all registered
gates with:

```sh
python3 -B scripts/research_package.py --package research/p104-qself-owned-lowering
```

`--regenerate` is an explicit developer command which rewrites RESULT.json and
QSELF-PATCH.json; ordinary verification writes neither file. The source inputs
are finite fixed templates, not samples over an unexplored search domain.

## Limitations

This is a conditional algebraic and typed-template composition theorem. The
full caller requires commuting operators and Q⁴=I. The local bank substitution
alone works for arbitrary completed A. All five selected framework assumptions
remain: native_all_columns, owned_erasure, compiler, precision_tape and
analytic_recovery. #6936's native/A6, odd-scalar exact-return and BIT premises
remain too. No complete rounded multiplier, physical fullcaller run or selected
supplier admission is asserted. The full numerical new bill uses inherited
scalar/pass rates, which are explicitly distinct from the metered physical
scan bound. An exact representation does not guarantee each Gaussian return
has the required finite signed width or grid.
The exact token-to-provider/table registry and concrete header export remain
unfinished; the typed patch is not a literal executable physical dispatcher.
