# Independent bucketed construction and skeptical review

The finite scalar/frame constructions pass independent replay. This directory also closes the concrete bucketed-fixture gap: `bucketed.py` emits **complete K plus compensation** words with one dirty helper for each incident `(source port, target label bucket)`. Every selected bucket includes every actual port in that label fiber. Broadcast coefficients are recomputed separately for every member; a bucket is not assumed to have a uniform scalar coefficient.

Prepared with OpenAI Codex assistance, Apache-2.0. The geometry and integer operator features are inherited from Dominik Scholz's PR606. The explicit private-center opcode stream is the new package's `k_encoder/network.py`; this independent layer does not claim to have invented those features or the private-copy interface.

## Reproduction

From the repository root with NumPy-capable Python:

```sh
python3 -O -B research/h6-compensation-network/independent/bucketed.py
python3 -O -B research/h6-compensation-network/independent/routes.py
```

All independent checks use explicit exceptions and remain enabled with `-O`. Outputs remain in this directory. The gzip fixtures are deterministic expanded opcode payloads, with uncompressed hashes in `RESULT.json`.

## Full bucket schema and scope

The independent recount checks all 14,670 labels and every saved cap-span witness against fresh actual addresses. It recovers 227,312,640 bucket helpers and 480,337,920 weighted target entries. Consequently:

- Compensation ADDs: `2*edges+2*helpers = 1,415,301,120`.
- Helper climbs: `3*helpers = 681,937,920`; data climbs: 61,920.
- Compensation plus data events: **2,097,300,960**.
- Helper transition rank: 3,864,314,880; compensation plus data transition rank: 3,865,305,600.

These are verified compressed-schema counts. The full billion-event stream was **not executed or materialized**. At review time `k_encoder/event_records` still defines the larger per-edge fallback, so its full composed count must not be presented as the smaller bucketed count. The stored bucketed fixtures here provide the concrete smaller-route evidence. K adds its separately counted ADDs, ordinary-center climbs and paid private episodes; none is included for free in the compensation-only schema.

The cap antichain argument in `FULL-MASK-SCREEN.json` is sound for its stated complete-target-mask, per-source ordinary-lane architecture: all incident source labels span each target cap, and distinct rank-16 caps cannot occur on one increasing helper chain. It does not constrain alternative factorizations, shared mixed channels, private copies, or different target flags.
