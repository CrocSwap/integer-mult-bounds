## 2. Domain, zero-frame covariance and common-format boundary

Write

`h=Gamma(f)Gamma(r)Gamma(P)Gamma(S)Gamma(w)Gamma(c)`,
`E=|h|`, `V=2PSr 2^(9f) w`, and `F=E+V`,

with all six integers positive. A valid packet is h followed by exactly V
binary scientific DATA bits. Components are signed w-bit two's-complement
numerators on a supplied common grid. The initializer works for w=1 as well
as every larger width; the inherited signed ADD/SUB domain requires w>=2.
Gamma6 does not itself encode the grid, frame or lifetime state.

Assume a live donor supplies a valid packet, and a physically distinct,
exclusively inactive owned home has the same F-bit binary extent. Every
initial target bit may depend arbitrarily on donor DATA, other homes or
ancestor state. Inactive means no live/public semantic obligation requires
those old target contents to be restored. This is a stronger transformer
domain than fresh B1 raw0^F reservation, not authority to overwrite live
borrowed dirty inputs. Private scratch still has the ordinary blank-entry
contract; historical backing and opaque exteriors remain charged.

**Zero-frame covariance lemma.** For every native frame U, positive column
count f and complete spectator factor, the linear map
`T_U^(tensor f) tensor I` sends0 to0. Consequently the DATA string0^V is
the exact scientific zero in every such frame on the supplied grid. A header
copied from a same-format donor in any other frame produces a legitimate
zero in the target's source INIT frame. No donor-to-target MOVE is required:
there is no donor scientific value being transported.

Proof: each output coordinate of a linear map is a sum of coefficients
times zero, hence zero; tensor products and spectator identities are still
linear. The signed zero numerator fits every positive width and is integral
on every grid. This argument does not assume a missing uniform tape
implementation of the native map. It proves only this zero case. Nonzero
ADD/SUB contacts still require their exact equal current frames.

**What supplies equal format?** The selected #7000 review, section2, acts on
all nine native slots with complete spectators at every f; section5 gives
one common numerical grid and component width through descendants. The raw
native word changes frame labels, not that complete scientific factor.
The imported literal Gamma6 boundary additionally supplies f,r,P,S,w,c and
the already packed view for that invocation. Under that explicit boundary,
all owners share h, E and V even when their frames have different ranks.
The frame table's nine-coordinate alphabet is checked independently of the
packet oracle. The word itself contains no Gamma6 root producer or cutoff
policy, so this package does not infer those from frame IDs or from equal F.
In particular equal total length alone does not prove equal header fields.

The initializer copies the donor's actual header, including its c. It makes
no later native-cutoff admission claim; the actual rank-two primitive still
requires2f<=c and its interior representability conditions. No numerical
value is decoded just to initialize zero. A caller wishing to change any
format field needs a separate producer, not this header-copy theorem.

## 4. Literal graph and all-parameter correctness

`init.primitive` emits a finite graph independent of every input parameter.
HOME is tape0, donor tape1, target tape2, and unary prefix guide tape3. Rules
test current cells, write current cells and move each head by at most one
cell. Python selects six header states offline; runtime has no host integer
decoder, indexed payload operation or numerical Word oracle.

For each Gamma code, append one guide1 per prefix zero, copying each zero
to target regardless of its previous0/1 value. At the first donor1, write
target1 and move the guide left. Each remaining guide1 is erased and permits
exactly one suffix bit to be copied donor-to-target. Reaching the guide's
permanent `^` completes the code and moves guide to its first blank cell.
Repeat this fixed pattern exactly six times.

If a code has a prefix zeros, an induction on its prefix scan gives exactly
a guide digits; an induction on popping gives exactly a copied suffix bits.
The guide is blank at the next code boundary. Thus precisely the six-code
header h is copied and both operands reach the first DATA bit. The graph
has never written a donor cell. This holds for every positive code value,
including cutoffs with arbitrarily long encodings.

The following scan ignores every donor DATA value, overwrites every matching
target DATA bit with0, and requires simultaneous outside delimiters. It
therefore writes exactly V zero DATA bits on the supplied valid common-F
domain. Rewinding both operands and the guide restores every head to its
permanent origin, with private guide blank. The result is exactly h||0^V,
independent of old target contents and arbitrary correlations.

A malformed/incomplete header or mismatched boundary cannot return through
this graph's successful path. Before return B1 has not scattered the private
working copy, so rejection at an already-reserved entry leaves HOME values
unchanged. Failed private cleanup/retry is not claimed. Reservation already
performed before a failed call is still real work and real retained storage.
The graph is a transformer on valid declared scientific packets; it is not
a validator that recomputes V or discovers external chart/grid metadata.

The CLEAR graph writes0 at every one of the F working-body cells, including
all header and DATA cells, and returns the operand head. B1 scatters that
complete body to the same permanent owned home, then erases the duplicate.
The result0^F is a retired raw body, not a live Gamma packet. No algebraic
zero inference or partial-capacity erasure substitutes for this scan.

## 5. Complete time and retained-history bill

Let A be the sum of the six Gamma prefix-zero counts, so E=2A+6. With local
working copies and all heads at their permanent origins, the initializer
uses exactly

`1 + (3A+12) + (V+1) + 2(F+2) + 2`
`= 3A+V+2F+20 <= 4F+8`

transitions. The terms pay entry, all six header/guide loops, every DATA
overwrite and final delimiter test, both complete-field head returns, and
guide return. Simultaneous unit moves on finitely many fixed tapes count
as one transition in the inherited multitape model. Arbitrary old target
bits do not alter this count. CLEAR uses exactly2F+4 transitions.

For R services, K permanent homes, B initial productive homes and b<=2
operand tapes, retain the independently supplied B1 dispatcher bound

`16(R+1)(K+b+1)(F+2)`.

Add4F+8 per INIT,2F+4 per CLEAR, and every other actual primitive/child bill.
B1's term pays raw reservation, complete HOME scans, full duplicate copies,
scatter, duplicate erasure, and all head returns. Included cold tests begin
with only productive homes and actually execute reserve; raw zeros do not
appear for free. Dirty-inactive tests start from an already existing charged
body, making no claim to allocate dirty storage for free.

For a sequence of these services on four tapes, fresh HOME extension visits
at most(K-B)(F+1) new cells. Each of the two operand tapes and the shared
reservation/prefix guide visits at most F+1 positive cells. Consequently

`history_final <= history_entry + (K-B+3)(F+2) + 8`

is a conservative complete historical increment bound. Entry history
includes earlier erased visits and all extant productive/ancestor storage.
Erasure never refunds that history. The tests deliberately retain a larger
previous private extent. Add each arithmetic/native service's own retained
increment; six tapes suffice for the included signed-primitive composition.
The bound is local and does not replace selected root-volume accounting.

All successful private windows are blank and all heads return to their B
origins, so another admitted B1 service may follow directly. The graphs make

## 7. Evidence, negative controls and independence

`python3 -I -W error -B verify.py` executes the literal graph against an
independent ordinary binary-string/two's-complement result oracle. The nine
complete-packet cases include positive widths1,2,3,17; nontrivial r/P/S;
a cutoff with bitlength2049; and a complete f=2 field. Four additional
inactive-body cases use all ones, a donor copy, its complement, and a lone
last-cell1. Exact primitive transition totals are compared to the derived
formula, not merely to another interpreter run. All donor/body bits,
parked values, heads, private windows, permanent markers, exteriors and
retained histories are checked.

Source controls reject forged INIT/frame/index bindings, an inactive donor,
aliasing and overwriting a live owned lifetime; a wrong nonzero scalar frame
also fails. The differently framed valid header donor1349 is a **positive**
control, preventing a false same-frame restriction. Machine controls reject
an incomplete six-code header and duplicate physical operand identities.
A mutated CLEAR clears only its first cell while returning a full binary
body and clean scratch; the full-body oracle detects its residual contents.
This distinguishes actual capacity erasure from merely passing the ABI.

The finite corpus corroborates the universal prefix/scan proof; it is not
the proof for every parameter. The source audit is static liveness/typing,
not numerical scientific execution. The inherited interpreter's code is
frozen. A rerun with Python -O ensures assertions are not required gates,
but is regression testing, not a second independent proof. No independence
claim is made for every inherited arithmetic/native kernel.
