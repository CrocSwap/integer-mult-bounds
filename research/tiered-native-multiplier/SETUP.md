## Observed host installation

Each process restored the authenticated source, installed the complete fixed program, built all recipes delivered by that multiplier, checked the installed dimensions and common K7 digest, then removed its private temporary directory. The comparison uses ToikY's extended multiplier and the complete two-tier candidate. CPU includes the process and its children. Peak resident bytes refer to the compiler process.
