# Exclude positive BIT gains on all 968 protected adjacent component pairs

All 968 fixed-incidence paid-adjacent pairs are covered, even with arbitrary rational subspaces of Q⁸ for both changed components.

Of 12,889 exterior-feasible rank pairs, 1,283 tie, 11,556 are negative and 50 have positive relaxed prices. All 50 fail two exact coupled-geometry tests.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `1954d2346d83d18a058d6d67134fd1a8c7055206e38bbff37458bf73abd14adb`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run `python3 -I -B verify.py` and `python3 -I -B arbitrary.py`.
