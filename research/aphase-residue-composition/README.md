## Reproduce

Use Python3.12 or later. The bounded finite replay uses the standard library:

```sh
python3.12 -B scripts/research_package.py --package research/aphase-residue-composition
```

This regenerates the relay, replays exact source adapters, runs independent
owner/moment and event/word checks with rejection controls, and verifies both
packing caps. It does not replace the complete admission command.

The complete command needs numpy1.26.4, scipy1.15.3, sympy1.14.0 and mpmath1.3.0
(the recorded environment uses Python3.12.15). Run from the repository root,
with a new output directory outside the source packages:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 \
python3.12 -B research/aphase-residue-composition/reproduce.py \
  --source research/gmx-t74-borrow43-handoff \
  --work /tmp/aphase-relay-fresh --jobs 24
```

The tested default command runs four fresh native chains, the retained16-stage parent
admission and the complete candidate release. It preserves the five new P53
dirty-A rejection controls for each provider. `--prepared-native PATH` is an
explicit alternative: it authenticates the entire source-bound cache, all four
successful native chains, and all16 distinct successful retained parent stages.
The wrapper propagates deterministic LF output to descendants and preserves
all scientific acceptance predicates.

`build_adapter.py` derives the admission/native adapters from pinned PR2848
transport code, while retaining the PR2843 per-shard temporary-file repair.
`build_wrapper.py --basis derivation/H23-reproduce.py --out /tmp/reproduce.py`
reconstructs the wrapper from its archived hardened basis. The archived basis
is historical code, not the entry point for this package. The exact adapter
preimages and unchanged auditor algorithms are independently reviewable in
`AUDITOR-DERIVATION.json` and `derivation/`.
