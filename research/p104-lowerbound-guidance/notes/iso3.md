## 1. Isotropic-pair lemma, any e [P]
Setting as DEN4. Digits: a_k^i (from w), b_k^j (from 2^e v). A(x) = [D(a_k(x)) E_k]_k and B(x) = [F_k D(b_k(x))]_k, with E_k F_k = Q[D_k,S_k].
Then P(x) = A(x)B(x) = sum_l x^l P_l.
Let alpha = rank_F2 A0 = rank [D(a_k) Q[:,S_k]]_k, and beta = rank_F2 B0 = rank [Q[D_k,:] D(b_k)]_k.
- (a) A0 B0 = G00 = 0 for e >= 1, so C >= alpha + beta (Sylvester).
- (b) Let W_e = 2^-e sum_k D(w^_k) Q D(v^_k) mod 2, where w^ and v^ are any lifts of w, 2^e v mod 2^e.
  - The truncated sum is ≡ 0 mod 2^e on cells, and W_e ≡ I + G_{0e} + G_{e0} entrywise.
  - Proof: wv ≡ w^v^ + 2^e(a^0 b^e + a^e b^0) mod 2^(e+1).
- (c) For x in leftker A0 and y in rightker B0: x^T y = x^T W_e y, because x^T A0 = 0 and B0 y = 0 kill both G-terms.
  - Every block Q[x∘a_k, y∘b_k] is even. The blocks Q[x∘a_k, ·] have even columns on S_k, and the blocks Q[·, y∘b_k] have even rows on D_k.
  - So W_e restricted there is a tau_{2^e} form of weighted even blocks.
- (d) Hence C >= alpha + beta >= n - rank(W_e | leftker A0 x rightker B0).
  - e = 1: W_1 = X, which is D56(a)-(c), before the Rado relaxation.
  - Also alpha + beta >= rank(I + W_e) (from (b)).
- Gauges: unit gauges do not change alpha or beta. 2-power row/port shifts (w_k(t) -> 2^(s_k+c_t) w, v -> 2^(e-s_k-c_t) v, all 2-integral) do change them, and the max over shifts is valid.
- [C, asserted in ilib.iso] The kernel identity (c) and the inequalities were checked exactly on HS64-D8 and the E7 decoders.

## 2. Sylvester-length family [P]
- S_l: l·C >= rk T_l(A) + rk T_l(B) - rk T_l(P) for every l >= 1. Here T_l is the upper block-Toeplitz matrix of the first l coefficients.
- Proof: over R_l = F2[x]/x^l, len(im A) + len(im B) <= len(R_l^C) + len(im AB), which is Sylvester for finite-length modules.
  The length of the image of M equals rank_F2 T_l(M). Right-multiplying by the block-constant diag(F_k), which has full row rank, keeps the ranks. ∎
- Level-l kernel identity: if x(t)^T A ≡ 0 and B y(t) ≡ 0 mod t^l, then x^T P y ≡ 0 mod t^(2l).
  - For 2l > e, the t^e coefficient gives x_0^T y_0 = sum_{q<e, i+j=e-q} x_i^T K_q y_j + x_0^T K_e y_0.
  - That is the identity form written in carries on polynomial kernels: the deeper isotropic pairs.
- For l <= e+1, rk T_l(P) involves only identity-forced coefficients (K's and I+K_e). In that range S_l and DEN4's Toeplitz T_{l+1} are "identity-level".

## 3. The counterexample to the l = 1 route [P from exact data; cex_hs.py]
- Delta is built with gram_rows_B on HS64 using U = F0·R. F0 is the D8 frame and R is unimodular; hs_kind1.pkl is regenerated by t4.py.
- It is exact (check_decoder = 0) and has 8 rows with C = 62.
- Six rows (0,1,4,5,6,7) have full support, v2(w) ≡ 1, v2(v) ≡ -5 and price 8 each. Rows 2 and 3 have v2(w) in {2,3}, v2(v) = -4, and r2 + r3 = 14.
- Proof that alpha + beta <= 30 in every 2-adic gauge (s, c, e):
  - Let σ- and σ+ be the min and max shifts over the six rows. Legality forces c_t in [-1-σ-, e-5-σ+].
  - Six-row a-digits occur only for rows with s = σ- and only at ports with c_t = -1-σ-. All these rows share the same pattern and the full column set, so together they contribute <= rank Q = 8. Likewise for b.
  - For row 2 or 3: an a-digit needs s_k <= σ- - 1, and a b-digit needs s_k >= σ+ + 1. These are incompatible, so each of these rows feeds one side only.
  - Total: <= 8 + 8 + r2 + r3 = 30. Unit gauges change nothing. ∎ (hill-climb max: 22-27.)
- Mechanism: rows that share their digit-0 label structure are counted once by alpha but pay separately in C. Only higher digits (l >= 2) see them.
- On Delta itself, the bounds S_3 = 45, S_4 = 55 and Toeplitz T_5 = 41 (gauge) all clear 38.
- E7: an optimal-cost frame decoder (e7f_3_2.pkl, C = 49) has hill-climb S1 = 37 < 41.
  - The rigorous enumerator exacts1.py is too slow at R = 2, m = 7 in Python (killed). This E7 claim is [C search] only.

## 5. What it means / next
- The D56-type route (digit-0 kernels plus tau-rank) is dead for PORTWALL at h = 8 and h = 7. This is not a matter of slack: the bound itself drops below threshold on legitimate decoders.
  Any proof must use the level-l >= 2 polynomial kernels (§2), where repeated rows separate.
- Escape routes:
  - (1) Bound the carry form on Toeplitz kernels at l = 2: dims 2n - rkT2(A) and 2n - rkT2(B), identity via K1 = X0 and K2.
  - (2) A normal-form lemma: merge or split rows with equal digit-0 structure without raising the forced bound.
  - (3) Prove T_{e+1} >= threshold directly. The gauge-max Toeplitz never fell below threshold in any test.
- Unsearched: general-model (non-Gram) quarter decoders via mod-8 Gibbs moves. Every family tested here is Gram class.
