## Gaps / remarks on LINEAR.md
1. Cauchy-Binet step: sound on paper (det(CA) = sum_I det C_I det A_I, M_I = A_I C_I), but it is the only non-formalised input of Theorem B besides data; the abstract Lean theorem needs only an 8-subset I with M_I invertible.
2. "alternating L with LM strictly upper": the L obtained is N = Z A^-1 (A = rows alpha_j); that N is symmetric AND has zero diagonal comes from the quadric sum alpha_j zeta_j vanishing identically on F2^n incl. its LINEAR part (x_i^2 = x_i). So the input must be "P0 (deg<=2, zero constant, 36-dim incl. linear forms) is injective on the labels", not just "no extra quadric with nonzero quad part". LINEAR.md states P0 injective, but the diagonal use is not spelled out.
3. Bm (the symplectic form) must be INVERTIBLE as well as symmetric: Omega^(n) = 0 needs beta_i = Bm p_i to span. Used implicitly in LINEAR.md.
4. The proof never needs the "transversal rank of R_t" definition or the quad-part projection as a rank inequality: the independence of the chosen rows of Yhat is proved directly (HInj => a linear relation among rows gives sum lambda_t gamma_t ^ delta_t = 0). Z-side is the same lemma for the swapped data (alpha' = Bm p, p' = Bm^-1 alpha, M' = M^T).
5. Only the 8 rows of I must be parity-linear; other rows are unconstrained (stronger than "linear decoder").
6. hdec is the EXACT integer identity (as in Doubling.lean), not only mod 4.
7. Sizes: the abstract theorem needs C(n,2) <= #ports (28 <= 104).
