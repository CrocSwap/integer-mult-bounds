1 [P] SIGNED-GRAM NORMAL FORM. Let V_t = I + A_t B_t^T (A_t, B_t are n x 2), let G = B^T A (2k x 2k) and H = (I - G_low)^{-1}. Then V_k..V_1 = I + A H B^T. So prod = -I <=> A H B^T = -2I_n. Write W = I + G_diag + G_up, so G = W - H^{-1}; then GHG = -2G <=> (WH)^2 = I. Define C = WH. C+I = K H and C-I = G H, where
   K := 2I + G_diag + G_up - G_low.
   With n = 2k-2: prod V = -I  <=>  rank K <= 2 and rank G <= n. (Proof: rank X + rank(I-X) = dim forces X idempotent; A H B^T = -2I forces rank A = rank B = n.)
   lambda != -1 makes the diagonal blocks K_tt = 2I + B_t^T A_t invertible (their eigenvalues are 1+lambda). Since rank K = 2, EVERY block K_st is invertible and K_st = P_s Q_t^T.
   Gauge form: there are block bases in which G = Etil*diag(A_t + I) - 2I, with Etil_st = +I for s<=t and -I for s>t, A_t ~ V_t|U_t, and A_k...A_1 = (-1)^{k+1} I_2. The (2k-2)-dim product law has become a 2x2 product law plus a support-rank factorisation G = sum_r b_r a_r^T, with b_r and a_r supported on the blocks of M_r. The 2x2 partial products are the obstruction law's 2-dim block.

2 [P] CROSS. Take disjoint stage sets X, Y. G_XY = (signs)*P_X Q_Y^T has rank 2*rank(E_XY), where E_XY = order-sign matrix. rank E_XY = min(#X-runs, #Y-runs) = cyclic alternations c ([C] 8828 labelings k<=8, 0 mismatches; det of the c x c staircase = 2^{c-1}, so char != 2 is needed). Each role adds rank <= 1 to G_XY. So:
   #{r : M_r meets X and Y} >= 2c.   For c=1 this is pair coverage >= 2, from the product alone.
   DYADIC_J (type row, every call order). Sum CROSS over the dyadic tree (class j mod 2^l split into its two lifts mod 2^{l+1}, l=0..J). A role's total count = #distinct residues of M_r mod 2^{J+1} minus 1 (the branching nodes of a binary tree):
   sum_r (min(D_r, 2^{J+1}) - 1) >= R_J(k) = sum_{l<=J} sum_{j<2^l} 2 floor(m_lj/2)   (k64: 128,192,256,320,384,384).
   The dyadic tree is optimal among tree families: each level asks for at most k.
3 [P] PIECE-CROSS (piece-sensitive). Multi pieces q with p_q ⊇ X have x_q in N_X = {x supported on E(X): B_t^T x = 0 for t in X}. They are biorthogonal, hence independent. This gives #Q_X <= |E(X)| - rank{b_r[X] : r in E(X)}, and the rank is >= 2c - #{r ⊉ X meeting X and Y}. So
   sum_r c_r >= 2c,   where c_r = 1[M_r ⊇ X and X is not inside one multi piece of r] + 1[M_r ⊉ X, meets X, meets Y].
   Roles that hold X inside one multi piece count ZERO. This is the only place pieces enter.
