## 1. Network doubling lemma
Setting: NetW in integral gauge. Labels q_p, charts b_k ⊆ a_k, drop d_k, D = Σd_k. Bars mean mod 2, primes mean the second bit (G = Ḡ + 2G', etc.).
- N̄ = (I − H̄)^{-1} mod 2. Content r̄ = N̄F̄ (rows k). Reverse content ū = ḠN̄ (columns k).
- L(b^⊥) = {t : q_t ∈ b^⊥}, L(a) = {p : q_p ∈ a}.

(M) MASTER FORM [P]. For any F2 vectors y_k, y'_k ⊆ L(b_k^⊥) and f_k, f'_k ⊆ L(a_k):
  D ≥ rank_F2 [[(y N̄ f')∘Q, (y N̄ f)∘Q], [(y' N̄ f')∘Q, (y' N̄ f)∘Q]].
- Proof: this is the F2 tensor potential (RS / NT §1, D ≥ rank_F2(Q∘M) for F2-networks) applied to the PORT-DOUBLED network.
  - The doubled network has ports p ⊔ p', the same labels and charts, F ← [f' | f], G ← [y ; y'], and the same H̄.
  - Its F and G are chart-legal, and the relay rule is unchanged. ∎
- Half-integer networks have M̄∘Q = 0. Taking y' = Ḡ, f' = F̄ makes the lower-left block 0, so:
  **D ≥ ρ_B^net + ρ_A^net**, where
  - ρ_B^net = max_y rank (y N̄ F̄)∘Q = Rado rank of R_t = span{r̄_k∘Q_t : q_t ∈ b_k^⊥};
  - ρ_A^net = max_f rank (Ḡ N̄ f)∘Q = Rado rank of R'_p = span{ū_k∘Q_p : q_p ∈ a_k}.
- Decoder corollary [P]. A decoder row of price r is a relay-free node with chart a = span S + U, b = (span S ∩ span D^⊥) + U, for any U ⊆ span D^⊥ (drop = r).
  - So C ≥ ρ_B^ch + ρ_A^ch, with y_k ⊆ L(b_k^⊥) ⊇ D_k and z_k ⊆ L(a_k) ⊇ S_k.
  - This strengthens ORBITLP §3. It gives DOUBLE56 a WEAKER target: ρ^ch ≥ ρ. E8 stays at 28 + 28 (forced).

(T) TORSION FORM [P]. Work over R = F2[ε]/ε², with G^R = Ḡ + εy, F^R = F̄ + εf, H^R = H̄ + εh'. Here h' sits on legal edges, y ⊆ L(b^⊥), f ⊆ L(a).
- U := R-span{χ_v ⊙ ρ_k : v ∈ b_k^⊥} is generated by D elements (NG step 3 over R).
- Every row of M^R∘Q lies in U. When M̄∘Q = 0, the rows are ε·L_t.
- Rank–nullity: dim(U ∩ εF2^n) ≤ dim span{ḡ_i} + dim ker = D.
- Hence D ≥ rank((y N̄F̄ + Ḡ N̄ h' N̄F̄ + Ḡ N̄ f)∘Q). With (y, f, h') = (G', F', H'), N4's identity gives **D ≥ rank_F2(I + X_walk)**. This halves N4's 2D. ∎
- O-form [P]. X_walk ⊆ (odd-read rows) × (odd-gather columns), so D ≥ 104 − |O| + rank(I+X)[O,O].
  - SPLIT networks (no port both odd-read and odd-gathered) have **D ≥ 104**.
  - D ≤ 55 needs |O| ≥ 49.
- (M) and (T) are incomparable for networks. For decoders, (M) implies (T).
  - [C] (T) > (M) is seen (h=4: rank(I+X) = 5 > ρ_B + ρ_A = 3, D = 7).
  - [C] Adding h' to the SUM form is FALSE (nd3: 4 violations). Scalar-2 relays break the F2 span (control EPS in nd1).

Checks [C, exact F2; ρ via Rado with random GF(2^16), a rigorous lower bound]:
- nd1, legal nets h = 3, 4, 5, 3600 instances: master 0 violations.
  - Controls: EPS (h' through the doubled F2 span) 23/70/135 violations; free y 70–752; relay rule dropped 92.
- nd2/nd2b, half-type nets (F̄ chosen in a kernel so M̄∘Q = 0), about 2000 instances, with and without H':
  - SUM 0 violations, tight in about 25% of cases;
  - the HC identity B = X + Y + Z_F' + Z_H' holds in all cases;
  - rank(I+X) ≤ D: 0 violations.
- nd3: TORS 0 violations; the illegal-edge control has 97 violations.
- RELAY instance (h=5, D=4, μ4 = 7 > 6) [C exhaustive]:
  - M̄∘Q ≠ 0 (rank 4), so only the block form applies; its max = 4 = D, so it survives;
  - ρ_B^net = ρ_A^net = 4.

## 2. Reduction to a decoder-side statement
- [P] Relay-free networks: (M) is the chart-closed DOUBLE56 verbatim.
- [P] With relays: ρ_B^net ≥ ρ_B(W) and ρ_A^net ≥ ρ_A(W*). Here:
  - W = forward walk decoder, rows (G_{:,k}, (NF)_k);
  - W* = backward walk decoder, rows ((GN)_{:,k}, F_k).
  Both are genuine mod-4 decoders with the SAME full M mod 4. So D ≥ ρ_B(W) + ρ_A(W*).
- [C] Neither of them realises the network on its own:
  - relay instance: ρ_A(W) = 5 > ρ_A^net = 4, and ρ_B(W*) = 6 > 4;
  - fuzz: ρ_A(W) + ρ_B(W) > D in dozens of cases (e.g. 10 + 0 vs D = 7).
  So DOUBLE56 applied to either one yields nothing about D.
- [P] The two-decoder statement SAME-M ("ρ_B(Δ) + ρ_A(Δ') ≥ 56 whenever W V^T ≡ W' V'^T mod 4") is FALSE, chart-closed or not.
  - Counterexample: M = 2I = Σ e_t(2e_t)^T = Σ (2e_t)e_t^T, giving ρ_B = 0 and ρ_A = 0.
  - A scalar-2-relay network realises exactly this pair. There, (T) gives 104 and (M) with chart closure gives 104.
  - So one-sided half walls (min ρ_B ≥ 28) are also false.
- [C] On the E8 same-M orbit (90 skewed U, samem2.log): min ρ_B = 33 and min ρ_A = 34 away from E8 (28/28). No asymmetric drop was found.
- CONCLUSION: the exact network statement is
  NET-D56: max(ρ_B^net + ρ_A^net, rank(I + X_walk)) ≥ 56 for half-integer P104 networks.
  - It is network-native: a pair of Rado families (b_k, r̄_k) / (a_k, ū_k), linked only by Σ ḡ_k r̄_k^T = Σ ū_k F̄_k^T = M̄ and the (T) identity.
  - DOUBLE56 transfers ONLY if its proof uses nothing beyond:
    (i) the chart-closed families;
    (ii) M̄∘Q = 0;
    (iii) Y + Z_F' + Z_H' = I + X, with Z_H' paid via torsion, not via the sum.
