# Source credit

Prepared by Ali Romman (@aliromman) with substantial OpenAI Codex assistance.
New code and prose are Apache-2.0. ORIGINS.json pins all retained input bytes.

Clear1nsight's [PR #7697](https://github.com/CrocSwap/integer-mult-bounds/pull/7697)
supplies the fixed graph, grid figures and physical model:
[pinned proof](https://github.com/Clear1nsight/integer-mult-bounds/blob/f55fc1434436ffa1c6d064a29fc56812044b3157/research/p104-banked-chart595-split/PHYSICAL.md).
Its notice is retained and preserves Ali Romman's helper bases and banked
pivots, SYLforge's caller, DreamingOfClouds and Rohan Arun's native/caller
lineage, and Jerry Chen's selected framework application.

Ali Romman's [PR #7701](https://github.com/CrocSwap/integer-mult-bounds/pull/7701),
[pinned proof](https://github.com/aliromman/integer-mult-bounds/blob/cd3819c70c6417bc1d3cc138294d973c58735229/research/chart595-factor-seven-audit/PROOF.md),
supplies the complete literal-product trace and independent grid audit. Its
receipt is retained for a byte-bound row-vector comparison. The predecessor
[PR #7680](https://github.com/CrocSwap/integer-mult-bounds/pull/7680) supplied
the earlier product/snapshot method. No source verifier is imported.

Common-denominator accumulation, shift/add multiplication and long division
are classical. Nick Petalas (@petalas) used them for once-rounded Gaussian
gates in [PR #6429](https://github.com/CrocSwap/integer-mult-bounds/pull/6429),
[pinned proof](https://github.com/petalas/integer-mult-bounds/blob/08f0609cc997da02944cf5517eba1aa954665050/research/integer-rounded-gate/PROOF.md).
That proof was read. Its kernel is not copied, and its rounding and width
contract is not transferred to this graph.

Wentao Li (@VictorLiwentao), with credit to Wronskode, supplied integer-row
verification work in [PR #2409](https://github.com/CrocSwap/integer-mult-bounds/pull/2409).
That is related verifier engineering, not this exact row provider. No
performance result from that work is claimed here.

The contribution is the source-specific exact row contract, coefficient
census, W+20 proof, runtime kernel and complete scalar comparison. It is not
an independent human review or formal-kernel proof.
