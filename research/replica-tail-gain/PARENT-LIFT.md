# Explicit arbitrary-replica dedicated parent extension

This is a construction of the source envelope needed for a changed-T candidate. It is not an admitted improved multiplier or a new native phase proof. Full literal hosted-owner, finite invoice, analytic and outer admission remain necessary.

Fix any positive T and any ordered partition q_0+...+q_(G-1)=T with 1<=q_g<=8. Number replicas consecutively within these groups; write r=b_g+lane, 0<=lane<q_g. Keep the authenticated nine-stage, four-pair, 73-dimensional source recipe and all local programs, phase recipes, windows, orientations, bridges and terminal translations literally unchanged.

For every data role of replica r, substitute family 896*r+local_family. Allocate nine separate 504-family helper banks per group, with helper h of stage s in family 896*T+4536*g+504*s+h. Thus no two helper roles or data roles share a family within an invocation. Share only the inherited restored private streams: eight centres, 504 tableau families and two coefficient families. This gives data=896*T, source bank=4536*G, parent live=896*T+4536*G and physical=live+514. Each source call has all 224 data and 504 dedicated helper roles, for exactly9*T complete calls.

For a helper of residual width w, use the exact source lane route: residual axes lane*w through (lane+1)*w-1; when w<9 use the unchanged source spectators8*w through8*w+9-w-1 and the unchanged paid normalization wrappers. These spectators fit because8*w+9-w=7*w+9<=72 for w<=9. Their dirty values are restored inside each complete source invocation, so sharing spectator coordinates with a later lane or with the later complement introduces no observation or phase change. Width-nine helpers use the original route[2,lane]. All actual route lists are checked against pinned full-group source calls.

The used residual coordinate blocks are pairwise disjoint. Together with the explicit complement q_g*w through72 they partition the complete orthogonal73-coordinate basis exactly. Apply that complement once after all complete calls in its bank, at rank73-q_g*w. This is the same orthogonal direct-sum factorization used by the authenticated five-lane source group; varying q changes only the coordinate partition, not its local program or phase recipe. Every bank complement, family correction and private reserve is retained and charged. Some conservative source complements can exceed48; this envelope is an overcharge/controller reference, not the final hosted recursive profile. Final hosted maximum-child and halving tests remain separate.

For an asynchronous order, require its call set to be exactly{0,...,8}x{0,...,T-1} and each replica's stage projection to be0,...,8. Expand each stage into its literal contiguous source event block. Each replica then projects to all source events0,...,29, in order, and the two global events30,31 follow all replicas. Every bridge and final signed data correction is retained. Consequently the data endpoint and phase contracts are unchanged on each replica, since operations on different data replicas are disjoint and shared private work is restored before reuse. This is an explicit extension argument using the same checked source identities, not an assumption of a new gadget.

The script compares all proof-relevant fields of the frozen actual T74 parent, including every owner list, complement, phase/program payload, private interval and source event, with the general construction using its actual [8,8,8,8,5] twice grouping and its exact call order. They are equal; only the version label and helper-route explanatory string differ. Receipts parent-T80-02/RESULT.json and parent-T94-01/RESULT.json bind source/template hashes. Parent idle child COUNT is2016*T; its rank mass is48384*T, a distinct quantity. The complete dedicated helper charge is9*T*504, and all4536*G bank complements remain charged.

The owned adapter lift_parent.py accepts --package, --owners and --out; it reads only the source package and exact reconstructor outputs. It rechecks the actual helper inventory, source-event schedule, strict physical windows, literal source family/copy, each width, no same-call family reuse, no residual overlap, compact prefixes, complete profile and deficit320*T before writing PLAN/SPEC and a receipt. Native phase replay is provided separately by the root's fresh hash-bound unchanged source admission. Old or stale root-level owner artifacts are deliberately rejected when they disagree with current provider widths; use the reconstructor outputs.
