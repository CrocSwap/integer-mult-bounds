## Contribution and source restrictions

Prove that all 40,320 vertex orders of a selected three-axis
physical Gaussian tensor retain full ordinary Stein displacement
rank under a stated Cp-bit factor-table error contract.

The theorem requires `p>=2^20`, a common dyadic target `t>=p^72`,
and one source prime in each narrow interval defined by

```
abs(2p^2(t/s_l-1)-eta_(pi(l))) <= 2^-26,
eta=(33,47,62)/64.
```

It does not claim this margin for arbitrary separated-prime triples.
The conditions imply the original fine-prime guards and have both
exact finite Proth witnesses and a qualified eventual existence
proof at the retained source scale.

## Proof and resulting behavior

Complete symmetry reduction gives 3,360 classes. Exact truncated
lower-degree algebra and Taylor bounds establish an all-order
common-lower determinant margin `D=2^-18 exp(-8a)`.
The physical lower-entry difference, inverse conditioning, matched
periodic aliases and further table error are paid explicitly.

Every order of the selected rounded tensor has displacement
singular value at least `2^-22D`; its exact inverse has margin
`2^-50D`. Sufficient further periodic-factor accuracy is
`ceil(379+72log2 p)` fractional bits, so `p` bits suffice in
the stated range. No physical phase or chirp is removed.
