# Selected BIT fixed routes as sequential stream programs

We compile the selected BIT producer's **999 data route types and 124 hosted
route types** into exact rational column words. We give a carry-aware stream
lowering for those words, count its ordinary interchange calls, and verify
payload movement on bounded complete packets. For hosted residuals, we choose
a completion that exchanges only the two coordinate-set differences: one axis
swap for local-overlap slots and eight for exterior slots.

This closes the fixed-header routing reduction under the completed ordinary
interchange and complete GL high-fiber premises in [PROOF.md](PROOF.md). We
retain the data-dependent recursive compiler, weighted calls, correlated-helper
domain bridge and COPY lifetime obligations. We claim no new supplier or
exponent. The selected result remains conditional.

## Scope and predecessor work

Nick Petalas gives the selected port 8 row-index carry lowering in
[PR2140](https://github.com/CrocSwap/integer-mult-bounds/pull/2140), head
`7ec858702da04d02748a5c05d439f602741a869a`, and requests physical routing.
We extend that handoff to the retained route catalogue, move opaque payload
bits through sequential passes, and supply the ordinary-call invoice.

The authors of the retained [upstream stream lemma](../../upstream/build/sections/02-streams.tex)
already prove the generic ordered-affine method. In the retained
[three-stage BIT proof](../five-stage-source527-banks/proof/three-stage-cover-bit.tex),
the authors also give a generic high-field routing bound. We instantiate those methods; we do not
claim a new generic routing theorem. In [PR442's hosting proof](../idle-axis-hosting/PROOF.md#2-hosting-lemma), DaysSky permits
any isometry with the required residual subspace image. We use that freedom
to choose the smaller support completion.

We follow the selected assembly's citation of PR589's tuned 111-port,
439-helper word. We bind the nine-stage, 32-replica template with 28,425
physical roles, 28,416 live roles and 126,432 hosted helper occurrences.
We check each owner against its
retained stage, replica, physical family and idle-child slot. The current
scalar program, owner assignment and selected frontier stay unchanged.

## Result and evidence

The compiler counts the following abstract primitives for one forward
right action. Its inverse uses the same upper bounds. Here a doubling/halving
count expands powers of two into repeated unit steps; the simulator can
combine those steps into one fixed-multiplier pass.

| Quantity | Data routes | Hosted routes |
|---|---:|---:|
| Distinct route types |999|124|
| Occurrences in the retained template |63,936|126,432|
| Maximum ordinary calls per action |3,520|1,664|
| Ordinary calls, one action per occurrence |128,352,256|76,197,888|
| Doublings/halvings, one action per occurrence |206,438,400|15,728,640|
| Negations, one action per occurrence |8,912,896|1,671,168|
| Controlled shifts, one action per occurrence |143,097,856|19,845,120|
| Constant shifts, one action per occurrence |23,429,120|5,025,792|
| Finite low-class permutations |2,999,808|1,277,760|

These counts describe one header action per owner occurrence. A caller must
charge its actual number of route entries and exits. We do not present this
census as the complete supplier's running time or recurrence profile.

We check exact rational factor products and residual subspace images for
the compiled catalogue. The full canonical IR has SHA256
`63d467f79e7e13fffd1f3de277dd5c6372cdac87f3fcd24b36a69149d300f81f`.
We also reproduce a separate all-111-port data census, SHA256
`03e87cbec874fcc453fb6e1ef6330c90bccf08d1216a37c069633b1893b7e1ab`.

We check 288 additions and 90 scalings. In the addition cases we move
2,957,760 payload bits, including nonzero carries, both field
orders and nontrivial middle/suffix spectators. The complete packet checks
enumerate GL2(F3) and GL2(F5) low classes, move whole high packets between
them, and include width one. We reject omitted carries, carries read from
the updated low class, a wrong hosted-factor order and an omitted support
swap. We use a charged exact oracle for the inherited ordinary interchange;
we do not implement that kernel here.

`Meter` counts payload reads, writes and head moves. Its linear regression
does not count Python arithmetic, scratch erasure or all final head resets.
The proof charges those operations using local counters and extra linear
scans. Finite payload tests support the implementation; they do not replace
the all-width argument.

## Reproduce

Use Python 3.12 and the standard library, from the repository root:

```sh
python3.12 scripts/research_package.py --package research/selected-bit-stream-routes
```

For direct replay or the complete column IR:

```sh
python3 -I -B research/selected-bit-stream-routes/verify.py
python3 -I -B research/selected-bit-stream-routes/verify.py --emit-catalog
```

We authenticate proof-relevant inputs before compiling. The command reads
the compressed source as frozen evidence and checks the decoded template
hash against its retained receipt. It writes no repository artifacts.
