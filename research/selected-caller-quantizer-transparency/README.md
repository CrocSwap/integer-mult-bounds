# Deterministic quantizer transparency for the current selected caller

For the exact current CrocSwap/integer-mult-bounds#6030 complete caller, one
declared fixed grid makes deterministic rounding an identity at every source
scalar/native return and every completed direct elementary C stage. The result
covers all 18 forward local invocations, all 16 reverse interfaces, whole
idles, actual contacts, arbitrary helpers, thin queries and scalar-product
temporaries. **No new κ.** The selected-rate recursive child's internal
precision, physical owned reset and complete tape tariff remain open premises.

For integer `f>=1`, `p,h>=0`, input real and imaginary components on `2^-p Z`
with magnitude strictly below `2^h`, the sufficient format is

\[
F=p+\left\lceil145f/2\right\rceil+4,\qquad
W=p+h+145f+20.
\]

Here F counts fractional bits and W is the signed width **of each real or
imaginary component**. A complex payload has two such components, plus its
actual framing. Six further signed temporary bits suffice for the specified
numerator-first arithmetic. These bounds are not asserted to be sharp.
The theorem permits any finite number of spectator coordinates and arbitrary
correlations between spectators and columns.
