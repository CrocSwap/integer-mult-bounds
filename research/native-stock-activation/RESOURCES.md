## Six genuine stages

For current ordinary width $e$ trits let $\rho=1/250$, $\eta=97/25000$ and $D=2+\lceil\log_N\lceil e/w\rceil\rceil$. The previous width was $w_o=\lceil e^\rho\rceil$. The new width is $w=\max(R_i,\lceil e^\rho\rceil)$ with $R_1=1$ and $R_i=E_{i-1}+1$. Split into $\min(\lceil w^{3/100}\rceil,\lfloor w/R_i\rfloor)$ consecutive components, balanced within one digit. A complete ordinary power uses $W^D$ rows for $W=B|\mathrm{GL}_N(\mathbb F_3)|\,3^{N^2(u-1)}$. In each suspended descent a genuine high coordinate remains live. All new component widths are positive. The largest one satisfies $u\ge R_i$, ensuring that both $u-1$ and $w$ activate the preceding complete stage. The implemented trit-to-trit earlier handoff needs no additional radix conversion. Both binary endpoint conversions and their full temporary buffers remain in the outer bill.

## Other costs and the finite control

The number of true coordinates remains $\Theta(n/p)$ throughout each complete transform. Both persistent Gaussian fields, the input and its returned product require linear backing. Private synthesis changes from a dense first root with at least $2^{131072s^3}$ scalar entries to a complete time and space upper bound of $2^{2^{20}(s+1)^2}$ with $s=\lceil\log_2(p+2)\rceil\ge512$. The wrapped source compiler, lookup-table traffic, numerical precision, changing root passes and cleanup are included. The first positive axis alone moves from input length $2575826973\cdot2^{2575826941}+1$ to $18508\cdot2^{18493}+1$ bits. Neither count implies a native six-stage call. The global dyadic record count $T=2^L$ still depends on the same input length. Large $s$ continues to make a single private square matrix astronomical.
