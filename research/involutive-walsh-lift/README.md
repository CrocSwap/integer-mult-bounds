# Involutive Walsh lift of the selected complex supplier

The historical selected complex supplier admits an exact change to
Walsh frames. Two copies of each coordinate, with a Gaussian unit
normalization, make every frame and source port phase an involution.
The lift preserves arbitrary array inputs, complete borrowed-helper
jobs, and all normalized recursive rank ratios. Its complete finite
invoice fits the retained constants for the unchanged scalar word.

This is an enabling theorem. It gives the complementary centre factors
`I+Q` and `I-Q` an exact zero product on every actual routed chart.
It does not complete a cheaper centre encoder or improve the complete
kappa calculation. Decoder access, changed-word cost, and mode hosting
remain open. The selected frontier is unchanged.

Read the [proof and invoice](PROOF.md), the
[native operator proof](NATIVE-PROOF.md), the
[global supplier binding](GLOBAL-WALSH.md), and the
[centre application](CENTRE-APPLICATION.md). The exact inputs are in

## Result and scope

For an old rank-r Walsh frame H_V, the new frame is

    Gamma_V = i^-r (H_V tensor H_V),   Gamma_V^2 = I.

The new ambient dimension is 146. An old child of rank r has rank 2r.
The array family count, owner assignment, invocation order, and cover
group order are unchanged. The cover is the diagonal image of the old
group, not the full group in dimension 146. The all-size parameter can
be any positive integer. Arrays need not be separable tensors.

The complete paid profile is

    {2:349604, 4:60192, 6:62585, 8:20448,
     10:11808, 14:7, 16:1152, 96:4866}.

The productive family count is 14336. The rank mass is 2082816 and the
rank deficit is 10240. All ratios r/m are unchanged, so the pure complex
moment is unchanged for every exponent. The bit supplier is unchanged.
The complete new scalar prefix is at most 433 bits within the retained
512-bit allocation. The local primitive bound is 80209797991582, which
is less than the retained 2^48 bound. The proof gives the full map count,
router, precision, tape, and physical-row charges.

The theorem uses the inherited all-size native, compiler, whole-call
hosting, precision, fixed-tape, and analytic recurrence interfaces.
The finite replay does not prove the full multiplication theorem or
execute an all-size multiplication program. It emits exact local native
factors and a source-bound global operator schedule. It does not flatten
the global schedule into a complete instruction tape or modify the old
admission executable.

## Reproduce

Use Python 3.10 or later and Git. No third-party Python package is needed.
The repository must contain the pinned source commit. Run from its root:

```sh
python3 -I -B research/involutive-walsh-lift/verify.py
```

The final line is:

```text
PASS_INVOLUTIVE_WALSH_LIFT_PACKAGE
```

The command runs one check at a time and writes to `evidence/`. Source
assertions must be enabled; do not use `-O`. To keep a fresh replay in
another directory, pass `--out PATH`. To read the pinned Git objects
from another checkout, pass `--repo PATH`. The driver verifies every
source archive, consumed member, and direct source hash in the manifest.
It then runs these stages in order:

| Stage | Purpose |
| --- | --- |
| `generate_walsh.py` | Emit exact frame adapters, native factors, complete helper normalizers, and the doubled factors. |
| `review_native.py` | Check full local operators, scalar phases, common-frame access, arbitrary inputs, and helper restoration without the emitter. |
| `review_doubled.py` | Check every emitted tensor factor, coordinate gather, scalar phase, and source event's doubled rank. |
| `global_walsh.py` | Emit the actual selected charts, helper jobs, idle suffixes, bridges, and terminal binding. |
| `review_global.py` | Rebuild the whole history with explicit axis sets and an independent scalar controller. |
| `verify_invoice.py` | Reproduce the old bill, compute both finite dilation bills, and compare two exact rational moment engines. |
| `review_invoice.py` | Derive the new bill as exact differences from the old bill without importing its producer. |

Each stage also accepts `--repo` and `--out`. The driver checks the
cross-stage receipt hashes and binds the complete global profile to the
invoice. Generated gzip artifacts are compared by their decompressed
UTF-8 payload hashes. Container bytes are not proof data.

The native review covers 1004 full frame adapters, 2896 full child
operators, 224 endpoint adapters, 36 complete helper normalizers, and
all 712 scalar input columns in both orientations. The global review
covers all 144 calls, 69120 complete helper jobs, 7526 idle suffixes,
and 14336 productive endpoints. Exact negative controls include a
missing global phase, the singular physical formula for an even line,
an incorrect helper route direction, a missing helper job, an incorrect
bridge sign, and stale terminal and cover translations. The fourfold
comparison fails the retained 48-bit local guard; the twofold lift
passes all reported finite guards.

Independent review here means separate mathematical derivation and
separate checker code by other research agents. It is not independent
human review. Receipts state their exact coverage and omitted checks.

## Open next questions

decoder in [CENTRE-APPLICATION.md](CENTRE-APPLICATION.md). Its exact
cross-stage annihilation now holds at all tensor sizes. First lower
the source-to-mode query and mode-to-data injection at their actual

access to arbitrary borrowed modes.

A second target is complete mode hosting through the changed controller.
First place one full mode cohort in the selected schedule and prove its
entry, exit, and restoration contract. The present unchanged-word owner
lift does not supply this new cohort or pay for it.

A third target is a changed-word finite invoice and supplier comparison.
It must include every new query, injection, scalar gate, wrapper,
recursive child, and restoration step. A favorable hypothetical rank
budget does not establish this result.
