# Ordinary BIT retained-space closure

**Scoped written construction and source-bound counterexample; no new kappa.**
The pinned copied-center ordinary BIT helper admits a source-faithful
reusable-origin realization with retained backing `K_entry + C V` for one call,
and `K_entry + C max_i V_i` for completed histories. This includes erased cells.
The history-free reading `K V_current` is false: actual q=3 digit buckets retain
3^(2e-2) cells after erasure and a later volume-nine call.

[PROOF.md](PROOF.md) derives local extents from actual elementary/ordered stream
procedures, complete-row old recursion and one bounded root padding. It uses
#5814's segment/bridge construction without assuming recursive children already
own or clear their work. This is a new constructive schedule for the pinned
source descriptions, not certification of the full existing Python or final
production machine.

The result supplies old ordinary-helper, fixed cover-route and stopped weighted
leaf space premises. For #5829, local `K V_j` must mean generated relative
extent/arena capacity, with historical backing bounded globally. V is bit
volume; record-count volume U requires the explicit factor r(p), so the
geometric bound is K_entry+C_T r(p) U_root L/(L-1). All markers, coded blanks
and descriptors remain charged. The new schedule may increase fixed ordinary
constants; preserving a conditional asymptotic exponent does not automatically
certify an existing finite numerical tariff or admission ceiling. Bad-class
recursive children, final native macros, generated evaluator implementation,
final-template lifetimes and actual dispatcher binding remain separate.
Compact repair has bound `O(V + M A + poly(A))`, reduced to `O(V)` only in its
stated record regime. All five selected framework assumptions remain; selected
