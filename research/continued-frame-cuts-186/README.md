# Continued physical-frame cuts on PR186

This package refines PR186's actual complex operation frames and replays its
complete supplier/assembly with the new word. The scalar graph, aliases,
read deadlines, 46 terminal sinks and bank-bit construction are inherited.
The exact conditional exponent and counts are generated in [RESULTS.md](RESULTS.md).

```sh
python3 -B research/continued-frame-cuts-186/verify.py
```

Python 3.11+ and its standard library suffice. The command verifies the
immutable PR186 upload and source archive, replays its entire complex/bit
certificate, checks the changed complex plan on every rational column in
both shear directions, reconstructs every terminal action and positive
child, and recomputes the exact paid moment and full balanced assembly.
No network, solver, unpinned producer or development cache is used.

Only the final explicit frames enter the proof. Discovery uses coordinated
intersections and joins, including one-dimensional lines and hyperplanes,
selected by integer-capacity binary cuts. A move may change many different
current frames together. The exact checker, not the numerical objective or
min-cut optimality, determines admission. See [PROOF.md](PROOF.md).

The original scalar/group/router/precision/row reserves remain charged.
The inherited all-size compiler and analytic interfaces remain conditional;
this is neither an unconditional multiplication theorem nor a runtime claim.
The selected main certificate is unchanged. Normal verification is read-only;
`--write` is authoring mode and still runs every check.

The complete PR186 construction and its lineage remain credited in [NOTICE](NOTICE).
This contribution supplies a further checked frame plan, exact aggregate
reproduction and a certificate-generated report. No global optimum is claimed.
