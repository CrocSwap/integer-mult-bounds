# Proof of the scoped retiming boundary

This is a written finite argument with an exhaustive exact checker, not a
formal-kernel certificate or a full multiplication theorem.

## 1. The transported operator

Write an addition as `E = I + e_t e_s^T`, acting on column register states.
Let `M = G_(i-1)…G_c` be the original scalar segment between cut c and E.
Replacing E by `M^-1 E M` at c preserves the complete A map. Within the first
experiment's interval no intervening gate reads or scales t, so `M e_t=e_t`.
Thus the replacement is `I + e_t v^T`, where `v^T=e_s^T M` and `v_t=0`.

The row is unique because the scalar segment is invertible and all live
registers are independent inputs. Pulling across `x_a += q x_b` performs
`v_b += q v_a`; pulling across `x_a *= q` performs `v_a *= q`. Zero coefficients
are removed exactly using Fractions. Each nonzero `v_r` contributes the literal
addition `x_t += v_r x_r`. These additions commute algebraically, but their
frame costs may depend on order; all orders must therefore be covered.

## 2. An order-independent early-cut obstruction

Ignore every given non-prelude A frame and remove E. Propagate the smallest
possible entrance frames forward: an addition replaces both incident frames
by their subspace join; a scale retains its register frame. Let `L_r(c)` be
these lower bounds at cut c. Independently propagate the eight prescribed
centre-frame ceilings backward by intersection along each shared gate. Let
`U_r(c)` be the resulting upper bounds. B and endpoint constraints are not
needed for this rejection test, so their omission only enlarges the domain.

If `v_r != 0`, the literal replacement addition involving r must share a frame
with t. The target's frame there contains `L_t(c)` in every ordering, and the
source frame must remain inside `U_r(c)`. Therefore

```text
L_t(c) ⊆ U_r(c)
```

is necessary. A single vector in the set difference is an explicit witness
against **every** source-addition order and every A-frame assignment. The
checker uses enumerated subsets of F₂⁹, independently of the basis routines
used by the inherited auditor and the frame optimizer.

For the four pinned additions, every cut before the table's boundary has such
a witness. Every later cut is realized by a representative verified below.
The census records a deterministic hash of every exact row and rejection or
representative assignment, including the immediately preceding-cut witness.
No sampled positions are omitted.

If a cut crosses a gate disjoint from t and every nonzero source in v, the row
is unchanged and the inserted additions commute past that gate without changing
any register's event chain. The full frame-assignment optimization is therefore
identical. Otherwise a new representative is retained. This partitions all
7,106 surviving cuts into ten classes per provider, with twelve source orders.

## 3. Exhaustive cost optimization of the survivors

Each scalar A gate has a frame node shared by its incident registers. Consecutive
nodes on each register form directed monotonicity edges. The prelude/entrance
frames are fixed. The first post-A scalar touch bounds the last A frame from
above; a first warp and each centre/target boundary pin the actual preceding
node exactly. No unrecorded climb into an exact pin is allowed. All subsequent
B/restore operations and endpoint frames remain fixed.

Forward joins and backward meets give necessary bounds `lo_i ≤ F_i ≤ hi_i`.
Every subspace in each interval is explicitly generated by closure under
adjoining each vector of `hi_i`. All tuples satisfying the edge inclusions and
fixed nodes are exactly the permitted frame assignments. The chosen witnesses
also pass the complete inherited frame checker and the independent set invoice.

An edge with dimension increase d costs one `H_d(b)` (zero for d=0); repeated
register edges carry their integer multiplicity. Edges into the first post-A
touch are included. The rest of the local profile is a fixed nonnegative vector.
The checker verifies this constant against the full invoice separately for the
baseline and every changed word, so the objective omits no variable child.

`optimize.py` eliminates frame variables one at a time. A factor table records
the rank-count vector for each surviving assignment of its neighboring nodes;
all values of the eliminated node are enumerated. This standard finite
min-sum recurrence is exhaustive by induction on the eliminated variables.
The elimination order affects runtime only. Largest produced table: 80 entries;
224 or 225 free nodes in each representative.

Each comparison of distinct cost vectors is certified uniformly over the stated
b interval using rational lower/upper enclosures for every `H_r(b)`; H_r is
increasing there. Signed combinations use the appropriate outward endpoints.
An ambiguous comparison fails the verification. Equal vectors are exact
symbolic ties. The inherited `root.py` bounds logarithms by the atanh series
with a geometric tail and exponentials by a positive Taylor series with a
geometric tail; its immutable source is pinned. Bounds are then rounded outward
to denominator 10⁴⁰. Across the 24 representative runs, 104,648 strict comparisons
and 33,024 symbolic ties are checked; the smallest strict gap is greater than
0.0009056 in these H units. These counts exclude the additional baseline runs.

Every optimum equals `{1:2434,2:632,3:286,4:104,5:26,8:8}`. Since inventory and
the surrounding assembly are fixed, this family supplies no smaller local bill.
No statement is made about price intervals outside the one checked here.

## 4. Earlier multi-target transport and its limitation

Before an accumulator reader, use the full identity

```text
M^-1 E M = I + u v^T,
u = M^-1 e_t,  v^T = e_s^T M,  v^T u = 0.
```

Pull u backward by `G^-1` and v by G, checking the nilpotence identity at every
cut. An off-diagonal entry `u_a v_b != 0` means that the replacement scalar
circuit's output a depends on its independent input b. Some directed scalar
information path from b to a is necessary in **any** factorization. Frames are
monotone, and each scalar edge shares its endpoints' frame, hence necessarily

```text
L_b(c) ⊆ U_a(c).
```

This remains necessary with auxiliary scalar registers: an auxiliary path
cannot remove containment along the path. Cancellations cannot create a
nonzero matrix entry without a path. No extra warps or changed surrounding
scalar word are admitted by this argument.

For each provider, this directed test rejects 7,078 earlier cuts, with a nonzero
matrix coefficient and a vector witness recorded in the census. Four cuts
remain unresolved: 1851 for sources94/62 and 1856 for sources63/61. A necessary
test passing is not a construction or a cost certificate. In particular we do
**not** claim an arbitrary-scalar-factorization optimum at those cuts, or at
later cuts outside the first experiment's direct-addition family.

## 5. Semantic and accounting checks

The retained exact auditor executes each baseline and each optimized
representative forward and dual in the free-operator algebra on all 632 live
inputs. The whole A map is preserved, and the precondition, compensation, cut,
B and restore lists remain unchanged. The inverse-reverse cleanup is regenerated
with exactly the 86 inherited private buffers. The full target endpoint,
restored-helper rows/columns, and return of zero buffers are checked.

This validates finite scalar/operator identities and accounting. It does not
re-run native Clifford realization, global owner admission, precision/tape,
outer assembly or the inherited all-size compiler arguments.
