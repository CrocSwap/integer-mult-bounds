# Optimistic mixed-cost allowance at one fixed exponent

This proposition assumes exactly the frozen model P/T and rank tariff
`h_r=r^(1-C*)`, where `C*=330007/100000000` and `rho=1/1000000000`.
All 256 new mode targets and preservation of the old main targets are optimistic
grants. Nothing here constructs, admits or prices an unknown physical decoder.

Let P(C*) and T(C*) be the moments of `fixed_paid` and `optimistic_targets` in
the immutable accepted receipt. Let an actual proposed completion add a
nonnegative paid histogram a and lose a target subhistogram l of T. Set

```
A = sum_r a_r*h_r,     L = sum_r l_r*h_r,
B = (1-rho)*T(C*) - P(C*).
```

For this unchanged pricing and consumer boundary, the strict reserve-adjusted
raw mixed moment is equivalent to

```
P(C*)+A < (1-rho)*(T(C*)-L)
iff A+(1-rho)*L < B.
```

This is elementary rearrangement. All additions and target losses must be
included. The optimistic calculation sets a=l=0 for pricing only; physical
future costs and losses are unknown, not proved zero. A genuine paid deletion,
new target, donation, changed geometry or changed tariff lies outside this
additions/losses contract and requires a new full ledger. Ordinary/precision/
compiler work requires its own source-bound accounting; passing this scalar
inequality alone does not close those obligations or fund κ.

The independent rational interval screen encloses P and T with outward bounds
and independently cross-checks the signed-coefficient expression for B. Its
actual receipt proves

```

```

The raw rho=0 margin is separately enclosed between

For any future completion, a certified upper bound on `A+(1-rho)L` below the

bound for B rejects this gate. Overlapping enclosures remain unresolved. Neither
case proves any missing physical premise.

## Isolated integer quotas

For a single additional paid rank r, tariff c=h_r>0, an integer n satisfies the
strict gate exactly when `n*c<B`. With exact B/c its largest allowed nonnegative
integer is `ceil(B/c)-1` when B>0. Given B in [b0,b1] and c in [c0,c1], the screen
uses `ceil(b0/c1)-1` as a guaranteed maximum and `ceil(b1/c0)-1` as a possible
maximum, capped below by zero. When these agree the integer quota is resolved.

For target loss alone use c=(1-rho)h_r and then cap the count by the actual
optimistic target inventory at that rank. An absent rank has inventory-capped
loss quota zero, however large its tariff-only allowance. These bounds say
nothing about physical ownership or whether the lost field is replaceable.

All rows spend the same B. They cannot be added: the paid H1-only maximum is
916, while B<917; adding any further H1 already violates the gate. Nor can a
916-H1 choice be combined with even one H8, since the certified H8 tariff is
greater than 7 and B<917. Separate table maxima are alternatives, not a mixed
construction. A true mixed choice must be substituted into the one inequality.
