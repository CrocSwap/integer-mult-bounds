## Actual termination condition and one next boundary to solve

For a proved diagonal T_A=q^eD_A with D_A B=bar(B)D_A,

therefore q B^-1 q^-1, which remains q-conjugated. After canonical q² output
normalization the code also changes by that ordinary conjugation; the
missing input word does not become ordinary merely because e is printed+1.
No even-q absorption case occurs in the old main endpoint chart.
