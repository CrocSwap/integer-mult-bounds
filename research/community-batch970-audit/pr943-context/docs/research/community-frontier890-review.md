with the dedicated banks, not silently charged as a permitted selected child.

and row coefficient 16469 < 20161.

## Integration corrections and limits

- **PR886:** the submitted enumeration used floating-point moment differences.
  Integration replaces comparison decisions with outward rational intervals
  from the pinned base-two engine, verifies every chosen component minimum,
  and adds the Hadamard minor bound justifying modular versus rational rank.
  Both optima and the degraded positive control still pass. The statement
  remains about closed live-line frames and fixed COPY boundaries, not all
  rational frame assignments.
- **PR881:** the submitted CRT height bound used inflated floating-point
  magnitudes. The integrated checker uses exact integer numerator bounds with
  dyadic denominator alignment. The same X4/U8 positives, six new mutations
  and 36 contributed U8 mutations pass. This supports the finite exact map;
  it does not independently replay the physical tape implementation.
- **PR894:** the margin is less than half a tick above κ, so nearest rounding
  selects κ. Upward rounding selects the rejected successor. The original
  arithmetic and four mutation controls pass; the contrary prose/comment is
  corrected. Original submitted text is retained in the audit snapshots.
- **PR812 and historical audits:** contextual selection references are frozen
  to their actual checkpoint bytes rather than silently repinned to the new
  result. All original spectrum values are unchanged; only the contextual
  adapter's implementation digest changes. Other new PR799-specific audits
  reference the byte-identical frontier799 checkpoint.
- **PR851:** the original patch would alter hash-pinned historical bindings
  and its old selected record. Its mathematical admission check is composed
  externally, preserving the historic proofs and current selection. PR847's
  parallel implementation/tests are retained; standard commands use #865's
  stricter superset. None of these checks authenticates execution merely from
  possession of internally consistent files.
