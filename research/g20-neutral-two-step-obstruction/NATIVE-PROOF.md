## Exact source and geometry

The current source vendor's uncompressed `FRAMES.json` is byte-identical to the
older package's decompressed `FRAMES.json.gz`, with SHA256
`0d99fc6b8f45c03dfba5252a03dd9e7fe23be3a7593dfe15368e34da6629a654`.
The gzip file is only 12,472 bytes; the unrelated large flow certificate is
neither needed nor used. `NATIVE-SOURCE-TRACE.json` in the independent geometry review
pins the actual current integration chain and native predicate.

For a frame of dimension d, the rational B rows span its d-dimensional space,
and A spans its orthogonal complement. All 645 spaces are distinct. For a
lower-dimensional frame U and higher-dimensional frame V, the actual native
predicate admits a query precisely when

    1 <= r = dim(V) - dim(U) <= 7,  and  B_U A_V^T = 0.

It permits both directions. It excludes rank-zero and rank-eight queries;
identical-frame operations are identity skips, not zero-rank queries. The
exact graph contains 26,312 unordered proper nested pairs, hence 52,624 directed
edges. Every one of the 2,369 retained source routes is an admitted edge with
its original rank. The graph is connected: there are 415,380 reachable ordered
pairs of distinct frames, compared with only 23,560 under retained directed
route closure.

For completeness, arbitrary paths preserve the inherited endpoint map even
when dimensions decrease. In the current rational representation let R extract
the eight paired differences, let L embed antisymmetric pairs, and let P be
an orthogonal projector. Then `RL=2I` and the frame involution is
`M_P=I-LPR`, so `M_P^2=I`. If P projects onto a subspace of Q, then

    M_Q M_P = M_P M_Q = I - L(Q-P)R.

The native residual uses the projector difference in either query direction.
Thus an admitted edge s→t implements `M_t M_s`, and consecutive frame
involutions cancel along any finite path. The result is `M_final M_initial`.
No monotone-dimension assumption or commutation of unrelated projectors is
needed. This uses the inherited rational/native frame interpretation; it does
not reprove its all-size modular, precision or ordinary-work obligations.

## All-path lower bound without numerical tariffs

Assign each native edge its positive integer rank. For each origin a compute
integer shortest total-rank distances `d(a,b)` on the complete graph. The
verifier independently checks the defining lower-bound witness:

    d(a,a)=0,  d(a,v) <= d(a,u) + rank(u,v)  for every admitted edge u→v.

Iterating along any finite path from a to b gives `d(a,b) <= sum_i r_i`.
Strictly descending tight predecessor edges give an upper witness and certify
that the computed distances are exact, although the lower-bound theorem only
needs the displayed inequalities. Distinct vertices have positive distance;
the diameter is eight. Every direct native edge of rank r has distance r.

For positive x,y and `0<t<1`, put `s=x/(x+y)`. Since `s^t>s` and
`(1-s)^t>1-s`, one has `x^t+y^t>(x+y)^t`. Induction and monotonicity give

    sum_i r_i^t >= (sum_i r_i)^t >= d(a,b)^t.

Accordingly replace each paid requested transition by one optimistic term
`H_d=d^t`. This does **not** posit an unimplemented rank-d primitive: d may be
eight even though rank-eight native queries are excluded. Every actual route
still pays each admitted edge. This relaxation is valid for arbitrary path
lengths, repeated vertices and backtracking, not a bounded-length search.

A nonzero normalized row stays nonzero under an invertible frame move, and a
zero row stays zero. Hence route choice does not alter the scalar emitter's
zero decisions. The implementation skips both requested routes when the ADD
source is zero; a zero destination's route is free; an owned None header may
initialize only when whole-zero; every public final frame is restored and
owned final rows must be zero. These rules are retained exactly.

## Exhaustive interval and invoice certificate

The pinned source contains 11,930 scalar records on 685 formal roles. Exhaustive
enumeration visits all 2,787 equal-ADD pairs. Exactly 517 encounter a reversed
ADD first; no pair's first obstruction is an operand erasure. The remaining
2,270 eligible intervals include 2,268 with one through 33 corrections and the
two zero-contact intervals `(5846,5852)` and `(7339,7340)` in zero-based scalar
indices. Every rewritten scalar program is checked on all 685 independent
formal input columns, including arbitrary dirty public inputs and inaccessible
owned input columns, before its whole chronological invoice is assembled.

`NATIVE-ONE-STEP.json.gz` records all intervals and their exact signed rank
invoices. Unlike the retained-route graph, every interval is emittable in the
enlarged native graph. The outcome is:

| Lower invoice change | Eligible intervals |
|---|---:|
| Strictly positive for every `0<t<1` | 2,248 |
| Zero, attained by original direct paid routes | 22 |

There are 211 distinct signed shapes. Each carries a small, independently
checkable partition certificate. After cancelling equal ranks, view positive
rank occurrences and negative rank occurrences as multisets. Partition some
positive occurrences into nonempty blocks, one block for every negative
occurrence q, with block sum at least q; retain every unused positive
occurrence as a leftover. The verifier checks exact multiset coverage with
no reuse or omission. For each block B,

    sum_(r in B) r^t >= (sum_(r in B) r)^t >= q^t.

The inequality is strict if a block has two or more members, its sum exceeds
q, or any positive leftover exists. Every nonzero signed shape satisfies at
least one strict condition. This proves all signs without floating-point
powers, numerical roots or an assumed value of the ordinary BIT exponent.

For each of the 22 zero invoices, every paid requested transition is in the
original retained direct table. Choosing those original edges attains each
collapsed term; any zero-payload route remains uncharged. Consequently the
zero lower change is attained and the minimum is exactly zero. The complete
22-recipe list is exported for the separately enumerated neutral-first,
second-conjugation investigation; this proposition itself has depth one.

## Verification, scope and remaining obligations

The primary code uses integer scalar rows, rational geometry and integer graph
arithmetic. All source hashes are checked before enumeration; default execution
compares the complete typed receipt, including every interval, shape and
partition. Normal execution and `python -O` are both required. Controls cover
public final billing, whole-zero source and destination cases, dirty owned
initialization/teardown, illegal rank-zero/rank-eight edges, and malformed
partition certificates.

A separate implementation derives rational RREF kernels from B instead of
using supplied A as its inclusion oracle, constructs all native edges,
computes all distances by bucket relaxation, and checks distance potentials
and tight predecessors. Its complete 645×645 distance matrix equals the
primary Dijkstra matrix entry for entry. A separate multiset checker validates
all 211 partition shapes. These independent checks do not claim an independent
re-enumeration of the 2,270 scalar candidates.

The theorem fixes the source word, outer transvections, correction frames,
entrance/exit contracts and target inventory. Ordinary scalar allowances are
not optimized, and a positive paid-query reduction would still need full
ordinary/native/caller accounting. No complete caller, recursive interface,
compiler, precision/tape cost or selected cold replay is re-established here.
New catalogue frames, moved correction frames, different rewrite identities,
and arbitrary-depth rewrite closure remain open. All five inherited selected
frontier assumptions remain unchanged.
