# Prove exact P104 BIT receipt prices with free original history

At all 2,874 MOVE clocks, freeze the original scalar and prior tape and allow arbitrary deterministic local functions of free original chart history. No strictly cheaper directly nested donor receipts preserve that scalar.

Two historical-union replays return one exception among 1,498 nontrivial moves. Packet 2944 needs 56 different grade-one donor charts using that grade alone, and all affordable cases fail. Both original signed callers and corrupted candidate controls replay.
