# Prove the sharp four-drop cut for two six-dimensional P104 depositors

Nine gathers of dimensions 7,7, and seven at least eight; eight depositors including two dimension-six inputs and six at least eight.

Arbitrary depositor relays are allowed. The first-depositor reduction yields T≥4 and D≥56+E+B, with exact D=56 and relay controls.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run the extracted README commands.
