# Close the current CRT source's raw arithmetic interface

Every raw arithmetic call of the exact admitted current CRT numerical
producer now has a literal implementation. This package adds comparison,
addition and subtraction to the previously verified division substitution,
including aliased doubling, finite carry/borrow returns and actual owner
binding. The original source controllers and Word lifecycle remain retained.
**No new kappa**, selected certificate change or complete compiler theorem.
All five foundational assumptions remain.

The graph has1,304,162 fixed R/W/M/J/H locations and68 physical roles. Its
first336,150 instructions, all old entry addresses and all setters are the
unchanged B10 divider. New entries classify aliases from encoded six-bit
handles, construct fresh result Words directly, preserve inputs, return all
heads and erase all four selector frames. Returning result Words remain
live until the retained actual caller erases them.

## Result and complete boundary

For width P>=4, every new simple call including four paid setters costs at
most401P+1073 literal instructions. Let J count divisions and H the other
raw calls in one current invocation, excluding nested calls inside the old
divider. Let m/t count left/right records, v valid right coordinates and E
the total Euclidean iterations. The exact source gives

    J = 3m + 2t + v + 2E <= (P-2)(4P+5),
    H <= (6P+3)E + m(10P+7) + t(8P+6)
      <= (P-2)(12P²+22P+10).

One invocation at width P pays the two J/H terms below; add89 if it starts
a selector lifetime. The following is a per-invocation upper bound:

    89 + J(930P²+1395P+14322) + H(401P+1073)
      < 2^16(P+2)^4

for the complete new raw arithmetic subset. Across invocations, sum the
terms using each actual width and pay ACQUIRE once per actual lifetime.

## Reproduce

Run the primary commands from this package directory:

```sh
python -I -W error -B source_check.py
python -I -W error -B test_core.py
python -I -W error -B verify_source.py
```

Add `-O` for the three optimized registered commands. All scripts are
read-only and use the standard library. Normal and optimized receipts are
byte-identical. The complete eight-entry registered suite (twelve checks) also includes the
two complementary independent reviews. From the repository root run
`python3 -B scripts/research_package.py --package research/all-current-crt-arithmetic`.

- The static gate authenticates85 retained source objects, all16 raw call
  sites per exact producer,167232 dispatch paths, every new relocation and
  the complete unchanged divider prefix. Fallback and wrong-port mutations
  are rejected.
- The primary primitive check covers840 packets through P257, including
  all ordered four-bit pairs and aliases, old history1025, exact counts,
  malformed domains and returning finite-flag corruption.
- Actual full nonleaf source and padded source/payload roundtrips execute
  1135 comparisons,1510 additions,107 subtractions and192 divisions, with
  1258 aliased simple calls, in22,179,316 literal instructions. All old raw
  providers and the obsolete shift provider are unavailable during these
  executions. There are zero positive fallbacks. Exact source outputs,
  owner relations, histories and outermost-only meter subtraction pass.

The source-only83-role and source/payload100-role harnesses remain separate.
The payload boundary retains fixed13-bit codewords with arbitrary12-bit
payload. A source-only whole traversal does not establish a whole payload
transform. Independent review assets identify their separate evidence.
