## 5. Complete raw-call bound and separate cost vector

Let m,t be record counts and v<=t the count of valid right coordinates.
Let e_i be the inverse's Euclidean loop length on record i. Each left
record uses three outer remainders, each right record two plus its valid
canonical reduction. Every Euclidean iteration uses one raw division and
one qmod remainder. Thus the exact un-faulted count is

J=3m+2t+v+2*sum_i e_i.

The existing source descent proof gives e_i<=2P+1. Every modulus>=2 and
complete product<2^(P-1), so m+t<=P-2. Hence

J <=(m+t)(4P+5) <=(P-2)(4P+5).

B10 gives exact logical division length
18P²+36P+458+(12P+9)popcount(floor(N/D)). Numerical reads expand to30
literal instructions, writes/moves to31. Four descriptor setters cost124;
one ACQUIRE costs89. Therefore all raw divisions in one invocation cost

T_div <=89+J*(930P²+1395P+14322) <2^15(P+2)^4.

Across several invocations use the corresponding sum with their actual
P_j,J_j and a single ACQUIRE for each shared descriptor-owner lifetime.
Q/R retirement occurs in the retained numerical continuation and is paid
there; the separate literal RETIRE entry is not redundantly executed.

The full cost vector also keeps source-field access, encoded entry/frame
preparation, all remaining arithmetic/controller work, output serialization,
source commit/retirement, unchanged header/key instructions, payload actions,
radix instructions and physical grant/acquisition. A large source prefix
is never bounded by a small node's P for free. Fixed metadata is invoiced
as256+32I+16400J bounded source-control units for I invocations and J raw
calls, plus A_grant, exactly as the declared retained B10 tariff. The
eight-action half test disappears; no such query remains. These metadata
units and allocation are separate from literal bit/symbol instruction units.

The meter join is exact: new HostedWord operations charge arena.meter,
not backing Port meters; new descriptor actions charge marker Tape meters.
Remove their measured overlaps once from the raw source/marker totals and
include their literal instructions once. The bounded replay separately
meters the original divmod on the unchanged source. For the same workload,
new residual source actions equal old residual source actions minus all
old raw-division actions. Residual marker work equals the unchanged value
at that encoded height; it is not universally14 (the fixtures at heights

speedup or new kappa is inferred by adding unlike provider units.

History is a union on actual owners. Each numerical Word retains its own

## 6. Evidence and limits

The source/payload replay uses three independent actual fixtures with4,8
and16 fixed13-bit record codewords, arbitrary12-bit opaque payload fields,
different Euclidean lengths, invalid/padded coordinates and different
allocation states. It exercises inverse nonleaf nodes. A further complete
Endpoint.run source roundtrip executes nonleaf groups in both directions,
committing every actual node before proceeding. Each producer's output is
checked by a direct integer CRT/current-coordinate oracle; complete source
and payload outputs are compared with the unchanged source and restore
their original physical data on the inverse.

During each actual replaced execution the original raw-divmod method is
an unavailable sentinel. Every reached call executes the literal graph;
any fallback is an error. Observers only record states and verify direct
integer equalities. Old-source division counterfactuals run afterward on
separate snapshots, establishing the local64-slot boundary bijection for
every call without supplying work to the running source. The universal
composition is the induction above, not an extrapolation from these cases.
Out-of-scope and foreign-arena controls reject before any graph instruction;
a deliberate actual-call fallback mutation triggers the sentinel.

The universal statement concerns the emitted graph plus the stated source
substitution, not the Python watchdog or observational receipt arrays.
Watchdogs may stop larger bounded checks; transcripts and integer oracles
are verifier instrumentation. Other numerical providers, finite metadata
representation, grant acquisition and complete source/radix compilation
remain open. All five full foundational assumptions remain, and the
selected complete multiplication bound and kappa are unchanged.
