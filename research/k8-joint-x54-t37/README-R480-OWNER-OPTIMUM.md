# R480 owner optimum and an attaining construction

The frozen seven-slot k8 word has a complete owner construction with
`kappa = 0.001674097969905390`. An exact supporting inequality proves that
no positive replica count can give a larger complex root for this word and
its whole-helper capacity inventory. The construction attains the bound at
37 replicas. Both endpoints of the certified root interval give the same
maximum grid value under the fixed outer recipe.

This is a conditional construction and a scoped optimum theorem. It does
not prove the full integer-multiplication theorem or a practical speed gain.
It does not change the selected result.

Run from a checkout at the exact base, with this package added:

```sh
python3 -B research/r480-owner-optimum/check.py --work /tmp/r480-owner-check
```

Use a new output directory. No network access, solver, or third-party Python
package is needed. The expected final line is:

```text

```

two rational moment engines, all 47 outer inequalities, 18 certificate CLI
