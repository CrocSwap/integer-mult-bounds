# PR4610 coupled recursion: Pauli gate and actual frame palettes

Cao Yifan; substantial OpenAI Codex assistance. Apache-2.0.

**TL;DR:** The global Pauli pair adapter cannot by itself make the round5
coupled lift's inner-hole contacts common under the retained owner routes.
The actual-frame test passes, and Lean checks the extracted coefficient
obstruction. This is a scoped negative result, with no new kappa or recursive
supplier. The completed actual-operator census and mixed frame palettes below
also produce no improving assignment at the tested weighted moment.

## The actual boundary being tested

The frozen round5 primitive is the 120-port involution

```text
T = [[I-BC,-B],[12C,13I]],    CB=14I,    T^2=I.
```

It has an exact arbitrary-input native word and retains all independent helper
endpoints. Its unconverted local rank deficit is zero. Converting its sixteen
auxiliaries to ordinary ports costs sixteen paid H1 jobs and sixteen target
rank units, giving deficit 32. These are already counted in the frozen caller
receipt, rather than being new savings here.

For a chronological coupled product M, the negative bank requires `Q^-1 M Q`.
Its inner T contacts occur at the Gaussian target minus the per-port q line.
The old terminal-target contact does not establish the inner-hole contact.

The new test allows a separate global Pauli power `S(P_i)^k_i` at each port,
where `P_i=Q_i^2` is translation by q_i in every one of f columns, and
`S(P)=(I+P)/2+i(I-P)/2`. The retained owner route fixes its own q_i.

## Exact obstruction, including all f>=2

The actual first normals are `q_0=11` and `q_1=19`. Both contain axis 0;
q_0 contains axis 3 and q_1 does not. The checker first authenticates the
actual target, owner route and affine phase correction. After this correction
the positive target is the same at every port, so it cancels when comparing
inner-hole frames. The residual at port i is

```text
-sum_(column j) C_(q_i in column j) + k_i C_(q_i repeated in every column).
```

Use the first two columns. Comparing ports 0 and 1, the binary polar
coefficient within one column on axes `(0,3)` is `1+k_0 mod 2`. The polar
coefficient between axis 3 in those two columns is `k_0 mod 2`. Port 1
contributes zero to both. A common frame would force both coefficients to
vanish, which is impossible. Translation changes only an even linear phase;
a scalar global phase also cannot change either coefficient.

This argument applies for **every f>=2**, since later columns can be fixed
to zero. For f=1, `S(P_i)=Q_i` and it cancels the hole: all 1,320 actual
port/stage/interval contacts are positive controls. The finite replay also
checks all sixteen power pairs at f=2,3,4,8 for eleven interval/stage choices,
giving **704** exact full-Z4 polynomial checks. Every failure has an explicit
pair of frequency axes whose second phase difference is two modulo four.

There is a stronger sector statement. Let any invertible function of the
global Pauli be `a+bP`, with sector values `A=a+b` and `B=a-b`. On the two
axis-3 bits at port 0, `Q_0^-1(a+bP_0)` has values

```text
(A, -iB, -iB, -A).
```

Port 1 is independent of both bits. Translation can multiply the two single-bit
entries by signs s and t, and the double-bit entry by st. If s=t, the last
entry would force `-A=A`; if s differs from t, the two single-bit equations
force `A=-A`. Both contradict A nonzero. Thus an arbitrary invertible
Pauli-sector pair gauge also fails this retained common-contact repair.

[PauliHole.lean](PauliHole.lean) proves the incompatible binary coefficients
and this arbitrary-complex sector implication. Its two fresh axiom reports
contain only the standard allowed axioms. Python separately binds the source
normals and actual transported frames to those algebraic premises; this is
not a Lean native-word, tape or recursive-supplier theorem.

This does not exclude non-diagonal coupled adapters, changed native/owner
words, whole-frame block realification, a new recursive job alphabet or a
paid joint-query compiler. In particular the separate whole-frame Phi
candidate is not the line-Pauli contact repair rejected above.

## Complete adapter charge and remaining invoice

The emitted pair program uses four complex ADDs, four signed-power-of-two
SCALEs and one i phase. Exact dyadic calculation gives component-l1 prefix
bound **4**, final bound **2**, and one extra fractional bit. A 120-field
bank performs 120 such field adapters. Its strided implementation pays
`O(V((e log p)^tau+1))` per use, including compact movement, exceptional-set
repair, owned work initialization/erasure and restoration. It is not free,
does not have an asserted O(V) bound, and earns no productive job credit.

The adapter fails the exact contact gate even if all that overhead is granted
zero. It therefore supplies no replacement for the frozen individual Q heads.
The retained p1/p2 ledgers remain only conditional ledgers: their surpluses
before those heads are 144/320 and after the 240/480 H1 heads are -96/-160.
No strict fully paid recursive moment or changed Gaussian supplier follows.

## Whole-frame block realification and mixed palettes

This is a different changed object from the line-Pauli repair. For an actual
canonical frame `F=K C_r K^-1`, the whole-frame square is an actual Hermitian
Pauli `P=F^2`, including its Z part and phase. The checker derives K from the
native chart, authenticates all eighteen Pauli generators of F squared, and
checks its absolute phase on all 512 amplitudes of the zero basis state.
It never replaces the actual frame by a raw binary `B B^t` shear.

For each odd block size ell in {1,3}, define
`Phi(F^tensor ell)=S((F^tensor ell)^2) F^tensor ell`. Its symplectic rank is
computed in the actual chart. Every old paid climb and center is counted,
and every native warp is repriced as the actual product
`E_out K_native E_in^-1`. The helper reward is the rank of its complete
changed endpoint product. The unconditional census gives:

|---|---:|---:|---:|---:|---:|
| selected112 | 1 | 9592 | 3155 | 1792 | 4645 |
| selected112 | 3 | 20246 | 10097 | 5376 | 4773 |
| coupled120 | 1 | 9695 | 2974 | 1920 | 4801 |
| coupled120 | 3 | 19881 | 9288 | 5792 | 4801 |

There are 75 broken native warp occurrences in selected112 and 100 in
coupled120, each costing rank two for either block size. Even granting all
those broken warps zero cost leaves positive deficits. The coupled main
column is an optimistic changed coupled endpoint rank; the census alone
does not give an ordinary independent-job interface for it.

The next screen chooses gauges separately at the **1,067 actual scalar
contact components** of selected112. ADD and COPY impose a common exact
frame choice. Owned center fields and actual main invocation endpoints
retain their old gauge. Deferred adapter records remain inert, following
the literal native replay; their position is not a physical frame change.
The script rejects a suspended-helper residual adapter rather than dropping
its cost. The selected word contains none. The strict case also fixes every
helper endpoint. The helper-free case optimistically admits a different
independent endpoint job, whose whole endpoint Fourier rank is still charged
as its reward; its all-f job type and external semantics remain unproved.

The binary palette is `{F,Phi(F)}`. Exact integer mincut returns the all-old
assignment for strict and helper-free boundaries at both ell values, with
deficits 64 and 192. Integer rank optimality is not a kappa ceiling, so a
separate search minimizes the actual concave weight `rank^(1-kappa)` at
`kappa=0.00302177581`. Rational logarithm and alternating-exponential
intervals enclose every rank weight, and candidates are replayed with those
intervals. The weighted binary interaction graph has 171 sign frustrations;
HiGHS consequently solves its binary product formulation instead of a
mincut.

The four-option palette inserts a chart square-root gate on mask v:

```text
A_v = K C_v C_r K^-1,
v in {0, first active unit, last active unit, all active axes}.
```

For ell=3 the chart axes are the union of the three actual nine-axis blocks,
not a contiguous first-3r segment. The same component, ownership and endpoint
constraints apply. Every table entry uses its actual native warp body.
Both weighted binary and four-option searches return all-old assignments
in all four strict/helper-free, ell=1/3 cases, with exactly zero profile
delta and rational moment-gain interval `[0,0]`. The solver reports floating
MIP optimality; this is finite numerical solver evidence, not a formal
optimality certificate or a barrier to other phase masks, words or interfaces.

The four-option receipt independently rebuilds all chosen native products
before accepting serialized costs. Its controls reject a changed fixed
endpoint and a one-unit price mutation. A literal circuit check covers one
actual frame of every represented rank. Another exact control shows why a
symplectic involution cannot be used as a literal inverse: the first-unit
full-frame option squares to a nontrivial Pauli translation, whereas its
actual adjoint round trip is identity. Absolute phases of an admitted full
supplier, compiler norms, reservation restoration and the recursive all-f
proof are not supplied by a rank screen.

For any future all-f use, write `f=ell*b+t`, `0<=t<ell`. Block changes act
on b blocks and retain the old frame on the t residual columns. A paid edge
would have child width `r_new*b+r_old*t`; a broken old rank-zero warp has
width `r_new*b`. The same rule applies to actual endpoint ranks. Gathering
these axes requires a charged fixed-block movement circuit, and backward
use must complex-conjugate the actual forward circuit. Neither residual
columns nor movement are free credits in these finite screens.
