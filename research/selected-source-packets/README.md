# Canonical selected source packets

We supply the physical source boundary that PR2501's residual interpreter
assumed: canonical raw-prefix directories, matching low-class gather/scatter,
complete owner/common header routes and common-view coefficient binding.
We connect these operations to a transported COPY/ADD/ERASE interval.

The owner route computes destination high keys with binary arithmetic and
orders complete fibres through two sequential buckets. We include low-digit
carries and arbitrary fixed admissible rational charts. After routing g to
d=g sigma, we prepare the residual from d with chart I. Reusing the owner
chart would apply sigma twice; we give an actual selected MOVE counterexample.

[PROOF.md](PROOF.md) proves the quantified source/layout refinement and charges
the directory and route work. Under complete body fibres and the retained
root coupling, we obtain O_q(V) directory work and O_q(wV) routing. We include
live directories in parking volume; earlier literal parking constants need
corresponding directory terms.

We incorporated ywz65's [PR2590 cost correction](https://github.com/CrocSwap/integer-mult-bounds/pull/2590):
the unchanged exponent-reconstruction loops add a cubic setup term in w.
We retain the final directory-volume bound under its stated input contract
and the payload-volume implication under the original root coupling.

## Evidence and scope

We execute these complete finite domains:

- All 48 GL2(F3) and 11,232 GL3(F3) low matrices, checking lexicographic rank/unrank
  against independent enumeration. We also check six GL64 ordinals. A full
  28,278-request vocabulary would need 6,507 source-code bits at q=3.
- Raw directories with repeated frozen tuples, empty prefixes, and the selected
  m=64/w=1 boundary. We preserve old field order and physical multiplicity.
- Complete GL2 high cubes at widths 1, 2, 3, including 6,561 high matrices at width 3.
  We check each route's bit origins, inverse return, carries and erased work.
- A complete two-dimensional COPY lifetime across 56 physical families,
  435,456 input bits and 55 XORs. We check dirty inputs, unselected low packets,
  source preservation, private cleanup and one shared residual/child invocation.
- One complete owner-route/directory/residual chain with 81 GL2 high matrices
  and 531,441 Boolean bits. We check each output bit's origin, frozen/current
  fields and one child entry/return across the packet.

For actual selected sources, we check 36,864 high-key entries across nine
64-dimensional header cases, the exact 57-event COPY511 interval, all 128
columns of its residual address operator, and concrete adapter/serialized-child
consumer sites. COPY511 at identity low header uses the fallback branch with
16,517 child calls. With fifteen adversarial controls, we reject code, view,
chart, directory and decoding faults; we check cardinalities through 529 bits.

The complete Boolean tests use the two-dimensional model. The selected tests
cover source/address operations and consumer junctions. We have not executed
the selected GL64 Boolean family domain, the full global schedule or a larger
recursive child. We retain PR2501's below-64 child guard, the selected frontier
and the remaining formal proof obligations. We claim no new exponent.

## Reproduction

Use Python 3.12 and the standard library from the repository root:

```sh
python3.12 scripts/research_package.py --package research/selected-source-packets --check-only
python3.12 scripts/research_package.py --package research/selected-source-packets
```

We register a source suite, the complete high-packet chain and the adversarial
suite under optimized Python, with 400/600/100-second timeouts. We do not repeat
the full packet under `-O`. We developed the package with CPython 3.12.13 on
macOS arm64. `RESULT.json` retains deterministic receipts; each verification
checks source pins before imports and compares the receipt. Inspect one with:

```sh
python3.12 -I -B research/selected-source-packets/verify.py --suite source --emit
python3.12 -I -B research/selected-source-packets/verify.py --suite packet --emit
python3.12 -I -O -B research/selected-source-packets/verify.py --suite controls --emit
```
