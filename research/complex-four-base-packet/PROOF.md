# Source-derived data-climb stream adapter

This is a scoped all-width proof for the implemented data-climb address/phase interface, calibrated at one actual event. It does not complete the assigned FOUR/base class. All source files are pinned at canonical base `4c0a359d88f22f05189d51f48387750b801a45d4`; the selected conditional kappa is unchanged.

## The actual caller

The exact native canonical word has 632 live registers. Extracting the unchanged `bw_emit.py` function definitions and calling `emit(back)` emits 22,808 events in the forward orientation. Both orientations put the first rank-3 climb at index 8814: `['climb','A',57,310,255,3]`. The frames are `[448,38,21,11]` and `[256,128,64,35,16,11,5]`. `bw_phases.py` lowers precisely `T_310.adjoint().then(T_255)`. The first actual `gauge44-four` dispatch is tick 1665, stage 3, replica 73; the controller selects backward at stage 3. The climb direction is unchanged in the backward emitter. Its scalar gates are dualized; conjugating this climb again would change the source semantics.

Register 57 is X port 57, whose actual q is 56. Stage 3 uses pair 1, hence its physical family is `896*73 + 112*(2*1+0) + 57 = 65689`. The source template specifies the physical cover class `g=d*rho(q,stage)`. `rho` is obtained by executing the actual source definitions in `research/e8-signed-prefix/code/data_phases.py`, not by accepting a supplied host chart. The concrete common cover d exchanges bits 0 and 1 and fixes the other 71 bits; it is a nonidentity member of O(73,2). The implementation checks orthogonality and invertibility, derives g as the physical cover-row label. The actual relative frame is rho(U), so its address chart in common coordinates is g*rho=d, since rho is an involution. The implementation stores cover-row labels and native address charts separately. Treating g itself as the native address chart is rejected by an independent source-route control. The source `stage_frame(q,3,"H")` supplies the nine transported basis axes; after the physical-cover action these equal exactly the columns of d, independently binding the implementation chart to the owning route semantics. Cover matrices remain exact labels; no cover enumeration or conversion to a guessed cover ordinal is performed.

The native compiler returns a right monomial with offset 426 and global phase 1, and a left monomial with offset 0 and global phase 0. The source recipe means `D(Q,alpha)`, then `P_G`, then `X_b`, then multiplication by `i^phase`. Thus a basis address x goes to `Gx xor b` with exponent `phase + sum alpha_i*x_i + 2*sum_(i<j) Q_ij*x_i*x_j (mod4)`. `adapter.mono` implements exactly that order. Neglecting offset 426 or phase 1 changes the actual tensor endpoint at f=2; the verifier checks both failures.

The separate stage-entry and stage-exit translations are 57 and 939524097 on both data sides. They are returned as source metadata. They are applied once at the whole invocation boundary by its caller; this interior climb must not insert them again. This package does not implement the whole invocation boundary.

## Uniform construction on a complete packet

Fix any integer f>=1 and 0<=t<=72, put e=73f+t, and fix positive remaining row stock Z. A complete packet consists of `[Z] x {0,1}^e x S`, where S includes the full compact, prefix, suffix and dirty fields. The coefficient at each address is arbitrary, including arbitrary correlations between all these fields. A chosen family and physical cover g are return labels. For a legal parent stock R=W*Gamma*Z, this packet has exactly 1/(W*Gamma) of the parent records. No row or spectator factor is divided again.

Write the e-bit address in f consecutive 73-bit columns followed by t remainder bits. The coordinate view sends each physical column x_j to d^-1*x_j. Apply the actual nine-bit right monomial on its low nine coordinates, fixing the other 64 coordinates. Sum its Z4 phase over columns. In particular, the scalar global phase becomes f times the source phase and the offset repeats in every column; it is not inserted only once.

Gather the first r bits of each transformed column into one rf-bit child field in column order. Concatenate the other (73-r)f bits into an inactive field and carry the t-bit remainder separately. Carry Z and every S field literally. `pack` and `unprepare` implement inverse address/phase maps. They preserve `rf + (73-r)f + t = e` bits, so no assumption about independent coefficient values or zero spectators is used.

`execute` presents that complete tagged stream to exactly one abstract recursive child implementing C tensor rf independently on every fixed remaining-field value. It then restores column order, applies the left monomial on each low nine-bit part, and returns through d. The physical family, physical/common cover and return-site descriptor are unchanged. It does not execute f separate rank-r children. The child is an explicit abstract interface, not a newly implemented physical primitive.

If the source scalar recipe is `T_new*T_old^-1 = L (C tensor r) R`, then tensor functoriality yields `(T_new*T_old^-1) tensor f = (L tensor f) (C tensor rf) (R tensor f)` after the explicit bit regrouping. Conjugating both sides by the complete coordinate view d=g*rho proves the emitted endpoint. This is the actual source's individual operator recipe, not a tensorization of a sum of operators. The per-column address bijections, phase formula and spectator identity give an all-f proof for this implemented interface. The scalar compiler identity is inherited from its exact source contract and checked again for the concrete fixture; finite tests are not an all-recipe compiler proof.

## Stream order and physical boundary

The implementation emits address-tagged records in the order induced by its input stream. It supplies a constructive address/phase transducer and one child invocation; it does not implement physical sorting, fixed-tape compact permutations, full row padding, origin-relative tape scans or the price of those operations. Those costs do not follow from the volume identity. The child contract accepts the complete tagged rectangle and must preserve every inactive field. The three endpoint tests use basis records as a finite linear-operator oracle, not as evidence that the complete 2^147 payload was materialized.

## Why the helper class is still open

The local inventory contains 3548 climbs: 1189 data climbs and 2359 helper climbs, using 3055 distinct directed edges. Full re-lowering and native replay were deliberately not performed. The first helper climb occurs earlier, at event 8469: `['climb','A',540,0,134,1]`. It is original register 546, compact helper 316. A streaming extraction of the actual owner fill gives row `[1665,316,230,14,77,23]`: owner replica 230, child 14, port 77, offset 23. Its actual family is 206381, its residual width is nine, and its selected host axes are 2^64 through 2^72. These are not the current data replica's d*rho view. Extending the data formula to reg 540 would instead produce family 66172, an exact wrong-owner binding.

`request` therefore rejects helper registers rather than silently applying the data route. `HELPER-HANDOFF.json` records the source-bound witness. This is a demonstrated necessary ABI difference and an implementation limit, not an impossibility theorem or a defect in the predecessor construction. A helper adapter must derive its family and hosted axes from the fill, retain a complete compatible complementary view, and include the actual pre/post residual wrappers when present throughout the same invocation. The first width-nine case needs only its explicit host permutation, but completing it alone would not cover helpers with proper residual widths and nontrivial wrappers. No such general helper implementation is supplied here.

Rank-zero monomial-only events, center events, residual requests, other providers, and complete all-dispatch/helper coverage remain unimplemented. The data request builder is parameterized, but only the stated first source event and its finite calibration are newly exercised. No complete FOUR/base adapter or N(iii) discharge is claimed.
