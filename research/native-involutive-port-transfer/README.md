# An involutive port transfer on the current native source

This package develops the eight-repair source-reflection mechanism of Rohan Arun’s PR #1931 and Ali Romman’s PR #1862 for the current native producer. The prior port matrix A has eigenvalues 1 and -13. A supported rank-eight repair instead produces an exact involution F, avoiding an assumed inverse with denominator 13. The forward word accepts all 632 arbitrary inputs and preserves all 408 helper jobs and the original charts. Its paid profile is {1:2209, 2:412, 3:510, 4:127, 5:40}: eight rank-8 centers are replaced by eight rank-1 repairs. The selected repair ports are [0, 7, 20, 23, 86, 93, 108, 111]. Read [PROOF.md](PROOF.md) for the explicit physical word and checked scope. A physical raw dual is not emitted or claimed. The separately emitted source-mutating variant returns X′ = FX and Y′ = Y + X′ for the same paid profile.

**No improved κ or complete multiplier is established.** Distinct fresh stages carry different routed codes. Their involutions do not automatically cancel, and a profitable complete caller remains unproved.

The supplemental coefficient theorem retains A as an unchanged principal block and completes it with eight auxiliary coordinates to an involution C. Its literal three-shear implementation uses 1,344 dyadic ADDs and 8 negations, with no odd denominator. This second construction requires a common chart; no free adapter between the actual native charts is asserted.
