## What the checks establish

The complete original source Clifford circuit is evaluated independently on
all 512 basis columns and all 262,144 matrix coefficient positions, including
absolute phase and exact half denominators. This oracle does not use the
lowered right/C/left sequence to compute the expected complete output.
The literal three-factor map is then compared with that independent oracle
on all 512 columns. Four phase/direction/coordinate/missing-exit mutants are
rejected both by the complete matrix comparison and the full packet oracle.

Small registered checks cover source corruption, typed source-token/rank/owner
mismatches, obvious aliases, exact administrative cost and whole-input rollback,
an unstaged countercontrol, shrinking reuse with retained backing, and an
independent primitive hardware cross-check. The arithmetic factors themselves
retain their predecessor proofs and verification rather than being called new.

The minimum source-complete numerical packet on this published local interface
has 4,096 records. Its required two front H-bit reservations and one back
H-bit reservation imply at least 12 address bits at native rank nine. A
512/1024-record fixture would violate the published admission guards. The
H=G=K=1 local test descriptor is explicitly smaller than the enclosing producer
allocation; no complete selected caller is executed.

The complete 4,096-record entrance and positive leaf traces passed, joined by
exact complete intermediate bytes. Their completed prefix costs 3,627,001,877
literal actions, including the initial complete-field transfer. A separate

The first uninterrupted packet was interrupted at the ten-minute research

## Reproduction

Python 3.12 and its standard library suffice. No network, external source
archive, host payload callback or decoded numerical oracle is used by a
runtime provider. From the repository root:

```sh
python3 -B scripts/research_package.py --package research/current-coded-atomic-move
```

The bounded source/interface runner prints
`PASS_CURRENT_CODED_ATOMIC_MOVE_SOURCE_AND_WRAPPER`; the package launcher
prints `PASS_REGISTERED_RESEARCH_PACKAGE`. These markers refer to precisely
the checks declared in `VERIFY.json`, not an unregistered interrupted run.
`PASS_CURRENT_CODED_ATOMIC_MOVE_RECORDED_SLICES` checks consistency and
integrity of the saved partial traces, with five corruption controls; it does
not physically re-execute them.
The separate full-factor commands and their completed coverage are listed in
`VERIFICATION.md`.

The algorithm remains a structured fixed-control source refinement, not a
literal `Controller.execute_table` export. Atomicity is for the inherited
named arithmetic failures on otherwise valid source/header/input contracts;
it excludes arbitrary malformed late output and physical interruption.
