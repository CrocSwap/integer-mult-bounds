# P104 endpoint stops cannot evade the relay floor

The 208-lifetime monotone correction floor survives every nested refinement
of the original G/Q/D helper transports, with arbitrary read-only contacts
at the new stops. This changes the fixed-path premise in the actual-helper
read audit. It answers the part of that handoff that inserts frames inside
existing jumps while retaining all original operations and endpoints.

There are exactly 52 possible new target-endpoint contacts across 32 of the
362 original helper transports. They reach 31 of the 104 target endpoints.
Every contact is on a D helper and has its source projection in the root
code K. The predecessor already grants all of K for free at every frame.
Thus none of these new contacts supplies the missing local information.
The 208 floor itself is credited to the prior relay and quotient proofs;
the new result is its extension to these changed paths.

## Exact domain

Retain the frozen 4,058-event P104 word, its 104 X sources, 104 additive
Y targets, 72 G/Q/D dirty helpers and eight private C lifetimes. Replace
any original G/Q/D transport V -> W by any finite strictly increasing
chain V < V1 < ... < W. Insert any read-only contacts at these stops.
Keep every original scalar event, copy, erase, source/target path and
private descent, in its original order. No new update can write an
original X/G/Q/D/C register. Targets remain unread and receive additive
writes only. The original helper's logical value is constant within each
refined transport. Different choices can be combined wherever nestedness
permits; the theorem is not limited to one stop or one helper.

Added correction helpers obey the predecessor model: arbitrary finite
equal-frame linear mixing and relays, rational input-independent scalars,
increasing frame paths, independent initial dirt, and free code inputs.
Each initialization starts a lifetime. Dirty restoration is relaxed for
the lower bound. The statement concerns lifetimes, not simultaneous stock
or recursive excess rank. Changing original captures, retiming original
operations, new descents, target feedback, or a path outside an original
transport interval is outside this theorem.

The exact identity R R^T=104 I gives the membership test for a source row z:

```text
alpha = z R^T / 104
z belongs to K exactly when z = alpha R.
```

## Extension of the arrival proof

For a frame V, put U(V)=span_Q{e_s : source label q_s lies in V}. The pinned
actual-helper audit proves that every original register at V supplies only
K+U(V), including its unfinished captures. Its private descents carry K.
At an inserted frame Z between V and W, the unchanged logical row is still
in K+U(V), hence in K+U(Z). Thus every original read still preserves the
quotient invariant for new correction helpers.

The old proof used absence of original-helper endpoint contacts. That
literal premise becomes false after refinement. Replace it with the new
complete census: every newly possible original-helper row at an endpoint
H lies in K. All original source and private paths remain unchanged. Thus
original endpoint reads still have zero local component in U(H).

The inherited finite certificates give K intersect U(H)={0} for each of
the 104 endpoints. They also show that, after granting every proper earlier
target-frame contribution for free, the still-required source labels span
the eight-dimensional H. At most one new helper arrival from a proper
V < H could supply local support only in V. Code inputs and all new
original-helper endpoint reads have zero local component. They cannot
complete the spanning set of required labels. Therefore each endpoint
still needs two distinct new helper lifetimes. The 104 hyperplanes are
incomparable, so one increasing lifetime cannot serve two of them. The
lower bound remains 2*104=208 for every finite refinement in the domain.

The verifier reruns all 2,458 source-decomposition states and all 104
geometry/minor certificates through the pinned predecessor checker and
compares them with its retained receipt. That checker and its theorem are
explicit dependencies. The new integer replay and normal enumeration use
different representations; this is not independent human acceptance.

## Local cost and limits

Each stop preserves the dimension-gap rank mass r=(r-1)+1. It does not
preserve a concave recursive tariff. For any 0<p<1 and common width m,

```text
((r-1)/m)^p + (1/m)^p - (r/m)^p > 0,  r in {3,4}.
```

Indeed, x^p has strictly decreasing positive derivative. Its increment
from r-1 to r is smaller than its increment from 0 to 1. The displayed
difference is therefore positive. This is the standard tariff comparison,
not a complete physical invoice. Different tariffs require separate prices.
No full native phase lowering or physical array execution is supplied.
Logical composition follows the chart identity, but the actual child
recipes, storage, head motion and read/disposal work remain paid obligations.

No new correction circuit, universal P104 obstruction, selected supplier,
all-size multiplication theorem or new kappa is claimed. The selected
60403/20000000 and every frozen source stay unchanged. The result rules out
this specific rank-mass-preserving attempt to use endpoint stops as a new
information source. A useful successor must change an excluded premise.
