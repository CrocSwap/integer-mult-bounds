This review uses head `0b2e2537b368a0cade07ce3f71452ea018ebe394`. The authenticated producer, compiled directly from source bytes into a fresh module, reconstructs both complete decoded words exactly without mutating either input. The adjacent JSON binds the source receipt, words and executed checks.

For each ordered quartet, the raw-dirt transformation is the invertible triangular map S taking (z₀,z₁,z₂,z₃) to (z₀,z₁+z₀,z₂−z₀,z₃+z₂−z₀). Its first column is (1,1,−1,−1). The actual compensation block annihilates that column. The staged A word realizes A_old S, so the required compensation orientation is C S, not C S⁻¹. The independent replay checks this on all 704 formal rows, with arbitrary independent dirty values and noncommuting warp symbols. It also checks the full inverse cleanup and forward/dual endpoints, with all 72 private buffers zero. This establishes the stated free-operator identity, without assuming a dirty input is zero.

The paid frame recount changes the four quartet leaders by H₁ − H₂ each and their four third members by 2 H₁ − H₂ each. Thus the complete local change from PR #2833 is 12 H₁ − 8 H₂, including the inverse cleanup convention. The literal producer adds 20 A primitives and 20 inverse primitives; compensation removes 28 and adds 28. No extra helper, port, warp or private buffer is omitted from this account. Compared with PR #2853, the paid change is −8 H₁ + 4 H₂. It has zero rank mass and is strictly negative at every 0 < p < 1 because 2ᵖ < 2.

Both full ordered 408-helper width lists agree exactly with PR #2853. Direct comparison of both words finds differences only in A, compensation, report and cleanup. In particular start_extra, all boundary frames, target levels, centres, ports, B, warps, restored/removed helpers and wrappers agree. Therefore an owner exchange or relay whose proof uses the unchanged source windows and ordered widths remains an admissible allocation transformation. Its idle invoice must still be recounted for its actual fill, and its local invoice must use the new profile. This is compatibility of sufficient interfaces, not permission to add independently quoted numerical gains.

The intermediate A frame paths and cleanup do change. Reusing the previous native receipts or hosted chart materialization would be unsound; both changed native chains and their hosting charts must be regenerated. The exact free-symbol audit does not establish Clifford/Gaussian phase identities, scalar/tape bounds or the whole outer claim. The final complete admission remains separate. No new unitarity premise is inferred merely from invertibility of S.

Three actual corruptions were rejected for their intended predicates: a compensation sign error, a missing inverse gate and an uncharged profile count. Optimized Python mode is rejected before input access. All 97 authenticated core source files agree with their pinned hashes before and after this review.

This review avoids that path by compiling the authenticated producer bytes and invoking the standalone checker directly. A new integration should retain the same source-byte execution safeguard; this caution does not invalidate the independently checked word contents.
