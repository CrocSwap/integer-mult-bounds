# Segment-relative PR2250 tape boundary

This package supplies a scoped locality refinement of the retained PR2250 `Tape` interface and a nested payload suspension adapter with a Python control-stack oracle. The unchanged `compact.execute`, `rotate`, `digit_permutation`, `stable_radix`, `repair` and `monomial.phase_pass` run through local views of fixed physical tapes. Rewind and erase then touch only the current segment, and two nested invocations restore the exact parked parent bytes and head offsets. This is an implementation/refinement result, not a complete FOUR/base caller or multiplication theorem.

The changed premise is explicit: PR5041 identified that parked-volume bounds do not provide local time, while the literal PR2250 simulator uses whole-backing `rewind`/`erase`. Here the simulator receives segment-relative operations and a constructive local delimiter protocol. No frozen predecessor is edited. `TASK.json` preserves the assigned wider goal; this package closes its local tape-view part, with the remaining actual-caller/child integration listed below.

## Local representation and invariant

Each of sixteen physical payload tapes contains an arbitrary ancestor prefix, a distinguished delimiter 2, and a current binary segment. A segment exposes local size s and head h with 0<=h<=s; physical head is origin+h. Only the payload alphabet 0,1 is accepted. The currently installed origin is entry state, not a free operation locating an arbitrary remote prefix. `Arena.child` charges and simulates each subsequent payload-origin installation, given frame metadata supplied by the control-stack oracle. Initial fixture construction copies ancestor arrays as test setup and is not charged as an algorithmic operation.

Read k copies exactly the next k cells and advances k; write appends k cells and advances k; rewind walks h cells to the local delimiter; erase rewinds and sweeps exactly s cells out and back. Thus the source's charges are unchanged for the same logical calls. None depends on the absolute origin or ancestor extent. The source's only direct payload-data operation is `len(source.data)`; the view returns local size. `bytes(view)` is used only by test oracles. An inspection of all three retained modules finds no payload indexing bypassing the interface. Every primitive is therefore translation-equivalent to its original empty-ancestor execution by induction over its interface calls. All ordinary/compact/phase endpoint proofs and their mathematical assumptions remain inherited.

At suspension, every occupied local role remains in place; saving by delimiting it avoids a copy. Move each head from h to s, write and cross one new delimiter, and install the child origin just after it. Save each of sixteen presence, size and head triples using a self-delimiting binary encoding, followed by the complete descriptor bitstream. The simulator constructs these binary header bytes and actually decodes every triple at return. Parent access is rejected while a child is active. However, `frames.append/pop` stores and retrieves `(origins, parents, descriptor)` as Python objects: frame boundaries, saved length, origin metadata and object references are supplied by an unimplemented control-stack oracle. The header numbers are self-delimiting, but the complete descriptor frame has no implemented physical end delimiter or backwards frame-location routine. No separate fixed control tape is implemented or verified here. The descriptor meter entries are a conditional byte-transport cost model, not evidence of physical frame encoding, location or cleanup.

After child-local work is erased, the head is at the child origin. Erase/cross its delimiter and walk s-h cells back to the saved parent head. Restore the original role occupancy and descriptor. The saved payload was never accessed. The payload invariant composes inductively to arbitrary depth, conditional on correct saved metadata from the control-stack oracle, with one delimiter stack per fixed payload tape. The two-level fixture executes the actual compact source at both nested levels, with nonzero parked payload and nonzero head offsets.

For k=16 roles, current extents s_i and saved descriptor length d, let S=sum(s_i), H=sum(s_i-h_i), ell(v)=max(1,v.bit_length()), and D=d+sum_i sum_{v in {presence_i,s_i,h_i}}(2 ell(v)+1). In particular zero occupies one binary digit, so an absent role contributes nine header bits. Excluding child work, the implemented payload-boundary movement costs exactly 2H+4k primitive move/write/erase units. This payload bill is independent of all ancestor lengths. Separately the simulator adds 6D conditional descriptor read/write/move/erase units assuming frame boundaries and length are already available. `RESULT.json` separates `payload_boundary_steps` and `descriptor_transport_model_steps`; the general meter includes both. The 6D term does not account for producing, locating or removing a physical control-frame boundary, and is not a proved total continuation bound. No O(D^2+k) allowance is asserted to discharge that missing implementation. If S=O(V), the implemented payload overhead alone is O(V), which fits the inherited O(V e^(1-a2) polylog p) allowance for e>=1 and 0<a2<1. Absorbing the complete control-stack bill remains open.

## Source-derived role inventory

The finite inventory counts stream roles, not the exponentially many records. `phase_pass` has source, out, real and imag; `rotate` has source, left, right and out; `digit_permutation` has source, out and four buckets; `flip_digit` has source, out, left and right. `repair` retains source, good, bad and holes; while `stable_radix` runs, it adds two buckets and an output. Existing caller frames can retain erased input objects and previous bucket bindings, but each call site releases them before the next same-depth invocation. The lexical call depth through `execute_monomial -> execute -> ordinary -> digit_permutation` or `execute -> repair -> stable_radix` is fixed. Sixteen slots conservatively cover these roles plus two externally retained current roles for this boundary; the executed early/late cases peak at ten. This bound is for this documented call graph, not arbitrary Python callers retaining an unbounded list of old tape objects.

A fixed finite-state allocation table can bind these lexical roles to slots and release them at their source lifetime endpoints. `Arena` simulates the table using weak references, avoiding payload copies and object-retention cycles. Its fixed sixteen-entry scan is constant work. CPython reference counting is the replay mechanism, not a new physical free-allocation primitive. The actual machine schedules role lifetimes from the fixed source graph. Existing empty reusable buckets remain allocated after erase; treating erase as allocation release would alias simultaneous live buckets and is deliberately avoided.

The source interchanges use complete compact fields of width (f-1)G and preserve dirty address spectators. The reduced full rectangles use f=2, K=G=1, rho=0, with both source orders and arbitrary labelled records; their empty good-set case still executes all raw rotations, actual ordinary fallback, exceptional extraction, radix sorting, reinsertion, highest-bit operation and cleanup. No reduced guard is substituted into the generic invariant.

```sh

```

`RESULT.json` records normal-mode evidence; optimized-mode output was byte-identical. Ancestor lengths 16, 257 and 4096 give identical local operation totals in each source order. Controls reject out-of-segment reads and suspended-parent access. The unchanged original `Tape.rewind` reaches physical zero and pays ancestor length, and original `erase` destroys the ancestor; both failures are executed as controls. Actual right-recipe phase and inverse agree with an independently computed integer Gaussian rotation oracle. No assertion is relied upon for correctness.

The prototype preserves immutable return labels, role bytes and heads using the explicit control-stack oracle; it does not implement a complete physical continuation. The recursive C child remains an external ABI obligation; the nested compact invocation exercises suspension mechanics and does not implement C. The adapter currently closes/erases all child segments on return: routing a child's designated output back into the real packet must be composed and charged by the actual caller. Consequently the complete assigned FOUR/base suspend/child/return goal is **partial**, not complete. No full e147 payload, full affine monomial, native supplier, Lean, Docker or production build ran. No selected frontier changes or new kappa are claimed.

Test-authoring gate: the owned behavior is source-level local tape isolation and head restoration; credible regressions are a whole-backing rewind/erase, illegal ancestor access, or erased-slot aliasing. PR5041's transport fixture does not execute these actual compact methods, and PR2250's empty-ancestor tests cannot observe this isolation contract. Constructor binding is the physical implementation boundary; no frozen source test hook or export is added.
