## 2. Header comparison and physical fifth-code decoding

Compare both headers while consuming their six Gamma codes in parallel. For
each prefix zero append one unary1 to L. On the first1, move L back; each
erased L digit permits exactly one suffix bit. Reaching L's `^` ends the code
and returns L to its first blank cell. Thus every header bit is inspected and
the first DATA bit is found exactly. Unequal headers reject outside the stated
input domain. No numerical f,r,P,S or cutoff is decoded or treated as free.

For the fifth code only, initialize unary W to1 at its leading1. On suffix bit
b, replace W=n by2n+b: copy each W digit twice to B, append b if1, erase old W,
copy B back while erasing it, and return both heads. Each move is one cell.
L still controls how many suffix bits remain. This gives exactly the encoded
positive width w and leaves B blank. It never stores w in host control.

For width suffix prefixes n_i, `sum_i n_i=sum_{j>=1}floor(w/2^j)<w`.
Doubling/copying/retirement therefore costs O(w), not O(w log w) or an
unbounded numerical-cutoff loop. The remaining header cost is O(E).
Every unary descriptor and guide reset is included. The private tape alphabet
is fixed; all guide operations stop at B's permanent `^` and never erase it.

## 3. Complete component traversal and finite carry

At a component start W is at its first digit. Seek right by w paid unit moves
on source and target while traversing W, then step left to the component's
LSB. Traverse w bits right-to-left, writing only target. For ADD, the carry
starts0 and the bit total is `target_bit+source_bit+carry`. For SUB, it starts1
and the total is `target_bit+(1-source_bit)+carry`. Emit total modulo2 and
retain floor(total/2) in finite control. Carry is always0 or1.

After j low bits, the emitted suffix is the corresponding suffix of T+S or
T+~S+1, with the carried next bit. Induction on j proves the exact w-bit
residue. SUB never materializes -S in the public width, so minimum negative
source values can cancel correctly with the target.

The last original source sign s, original target sign t and result sign u
are retained in control. A provisional overflow flag from a lower bit is
ignored while W still has digits. Only when W reaches `^` after the MSB does
the graph reject for

* ADD: `s=t` and `u!=t`;
* SUB: `s!=t` and `u!=t`.

These are exactly the signed-overflow conditions. Opposite-sign ADD and
same-sign SUB lie between representable endpoints. In each remaining case,
changing the target sign in the modular result is equivalent to crossing
the appropriate signed bound. Thus no intermediate negation/product/carry
overflow causes a false rejection, and every true final overflow is caught.

On success, heads are one cell before that component. Move right once,
advance w paid steps following W, rewind W and begin the next component.
Each seek/arithmetic/return/guide reset costs O(w). There are V/w components,
including both parts of every Gaussian value and every spectator/coefficient
address. The common valid packed geometry guarantees exactly complete groups;
the outside delimiters are reached together. This is not a general validator
for a false declared V or a malformed packet.

## 4. Full field transaction, source and cleanup

B1's working duplicate. On final delimiters, erase unary W, return L/B and
