# Sharp image bounds for three binary pattern dimensions

**A complete noncoordinate binary projector pool in a three-dimensional pattern space containing no single-edge pattern has joint-image dimension at most four, and four is attained.** This replaces the previous upper bound seven for the missing zero-edge case. Combined with the credited edge-quotient theorem of #6782, it establishes that the exact maximum total joint-image dimension among **all** three-dimensional pattern spaces is six. **No new κ.**

Claim type: written all-width mathematical proof with finite exact corroboration. [PROOF.md](PROOF.md) includes all inherited lemmas needed for the corollary. Independent algebraic review is recorded in [REVIEW.md](REVIEW.md); it is not formal proof-kernel verification or independent human acceptance.

## What is new

Nick Petalas's #5921, `research/pattern-pool-cardinality`, gave a sharp pool cardinality theorem and left sharp joint-image dimension as an explicit question. #6782, `research/bit-three-relation-core`, subsequently proved the edge-quotient bound and treated the edge-containing rank-three cases; its zero-edge upper bound was seven. This package settles precisely that remaining total-image case.

Among any five distinct nonzero patterns in a binary three-space, there are two zero-sum triples meeting once. If their five image vectors were independent, the corresponding diagonal matrix sums would force the common projector to be coordinate, contradicting the pool definition. An even-parity construction gives a complete seven-projector pool whose images span four dimensions. This sharp example is reducible; it does not settle the irreducible no-edge maximum.

The universal maximum six combines the new result with #6782's existing edge-quotient argument and disjoint-edge example. Their predecessor credit is retained.

## Verification coverage and failure controls

The verifier imports no predecessor implementation. It checks all 21 five-point subsets of F2^3, all binary rank-one-idempotent fibers at widths one through seven, and complete pools for four witnesses:

| Witness | Pattern dimension | Edge count | Pool size | Joint-image dimension |
| --- | ---: | ---: | ---: | ---: |
| New sharp parity-code pool | 3 | 0 | 7 | 4 |
| Inherited three disjoint edges | 3 | 3 | 6 | 6 |
| Inherited two-edge scope control | 3 | 2 | 5 | 5 |
| Rank-four parity-code scope control | 4 | 0 | 15 | 5 |

The finite census enumerates every space generated by three independent **realized nonedge patterns** at each width, deduplicates spaces, then discards those containing an edge. It does not enumerate every three-space in the full off-diagonal ambient vector space.

| Width | Distinct generated spaces | Zero-edge spaces checked | Largest joint image |
| --- | ---: | ---: | ---: |
| 3 | 202 | 112 | 3 |
| 4 | 104,657 | 98,997 | 4 |

This domain contains every possible counterexample at these widths: if the realized patterns span at most two dimensions, fiber uniqueness bounds the pool size by three. Finite coverage is corroboration; the all-width result rests on the proof. Enumeration is deterministic, has no random seed, and stops only after its stated domain is exhausted.

Nine controls reject: a false cap three; an omitted complete-pool member; a nonidempotent factor; an admitted coordinate projector; the two-edge example used outside the no-edge hypothesis; the rank-four example used outside the dimension hypothesis; dependent images in the intersection lemma; nondiagonal dependency sums; and actual retained-source byte corruption in a temporary copy. The dependent-image control really has both diagonal sums and a shared noncoordinate projector, demonstrating why independence matters.

## Open next questions

- Can a complete no-edge pool be irreducible on a four-dimensional joint image? Start by classifying four independent image projectors and the remaining patterns. A universal argument or an explicit example is needed; the reducible sharp example here does not decide it.
- After a valid relation/cube-span and coordinate-call split, what paid-rank statement holds for the at-most-four-dimensional no-edge alphabet? First verify those inherited hypotheses, then derive the full endpoint and paid/target invoice. The scalar dimension bound supplies neither a saving nor a general word obstruction.
