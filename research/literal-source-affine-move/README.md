# Literal source-bound affine MOVE join

## Result

This package supplies a literal Gamma6/HOME implementation for one authenticated selected MOVE, event24476 `[MOVE,727,3,470,false]`, and a generic fixed nine-coordinate monomial service. For that event, the exact source map is $M_L C^{\otimes3}M_R$. The right monomial has output offset $5$ and absolute phase $2$; the left has zero offset and phase. A direct source-kernel cross-check and a separate sparse HOME execution agree with the original frame map.

The theorem starts with a complete owned packet and explicit numerical prefix promises. Require $3f\le cutoff$, the actual phase operations to fit the signed width, and every output of each positive $C$ prefix to be integral on the same grid and fit the signed width. The simple sufficient reserve in the proof is divisibility by $2^{3f}$ with $2^{3f}M\le 2^{w-1}-1$. This package does not show that a selected producer supplies these promises.

For $V=2PScw2^{9f}$, header length $E$, and $F=V+E$, the complete actual core costs at most $2^{25}(fV+E+1)$ and increases retained backing by at most $2048(V+E+1)$. The 35-tape HOME adapter adds $128(F+1)$ time and $64(F+1)$ backing. General B1 full-bank gathering, setup, source production and whole-caller costs remain separately paid. This direct leaf has no faster recursive tariff.
