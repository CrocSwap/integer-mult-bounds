# Source-bound native semantic review

This directory supplies independent author-side native application evidence
for PR6716's unchanged PR6702 native input, compared with the exact selected
PR6030 source. It changes no kappa, word, invoice or framework assumption and
does not claim external scientific admission.

Run with Python 3.10 or newer and only the standard library:

```sh
python3 -I -B verify.py
python3 -I -O -B verify.py
```

The default is read-only. All mathematical inputs and retained interpreters
are relative to this directory. It runs without Git, network access, an
executable PATH, a repository checkout, or any original `/tmp` directory.
It compares the inventories, checks every actual current emitted recipe's
exact full signature, checks all 512 columns only for the 39 unmatched maps
and five helper normalizations, and independently replays the current scalar
word. It does not run a historical native or caller suite.

Optional source custody against a checkout retaining the pinned objects:

```sh
python3 -I -B source_custody.py --repo /absolute/path/to/integer-mult-bounds
```

This reads only exact scoped Git objects and named archive members. The
5.7 MB source archive is not duplicated here. Default scientific replay needs
no repository or archive; exact current compiler members are retained locally
with their container custody. `--write` on the scripts is an explicit
authoring mode; it is not used by read-only validation.

`PROOF.md` gives the exact signature and factorwise argument and preserves
predecessor credit. `COVERAGE.md` separates checked obligations from inherited
scope. `SOURCES.json` and `SOURCE-CUSTODY.json` identify actual source bytes.
`COMPARISON.json`, `SIGNATURES.json`, `DENSE.json` and `SCALAR.json` are the
recomputed scientific receipts; `RESULT.json` binds them together.
