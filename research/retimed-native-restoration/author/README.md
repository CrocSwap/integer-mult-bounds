# Actual native restoration lists

This source-bound follow-up accounts for one explicitly excluded native
service role: the ordered complete matcher words in StrongBinarySource.raw's
restores list. It binds the actual BinaryWord.native wrapper, all productive
target tags, the literal Frame.matcher_to algorithm and the final reverse
inverse routes. It is a separate package and does not modify its inputs.

Every matcher has at most 123N operations. A six-bit signed numerator and
five-bit denominator cover the complete source/inverse coefficient family.
With P=18906 entries per context and C=2N^83 inclusive contexts, four separate
image-role maxima per fixed reusable service slot, binary-symbol encoding
and header slack fit below
2^28 N^84 h bits, hence below BNh for B=N^92 and h>=3000.

The target census covers all 18,906 tags, including helper start/final chart
pairs, and 2,120 distinct requests. The actual maximum target base length is
52; the proof uses the conservative common bound 61. Integer/zero input
bases are included. Other private route words, matcher-construction arrays,
native registers/frames, dispatch and numerical work remain outside.

The codec is an exact representation, not a claim about CPython storage.
The source replay abstracts numerical bank payload operations. No selected
assumption or kappa changes. Source pins and inherited assumptions are in
PROOF.md and inputs/decoder/SOURCE-BINDINGS.json. Exact unchanged source and
decoder-proof inputs make this package independently relocatable.
