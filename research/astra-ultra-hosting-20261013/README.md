existing pinned Python scientific engines are invoked unchanged.

From the repository root:

```sh
bun research/astra-ultra-hosting-20261013/verify.ts
bun research/astra-ultra-hosting-20261013/verify-native.ts \
  /path/to/checked-selected-native-local /path/to/fresh-output
```

all integral constraints and runs its five rejection controls. The second
