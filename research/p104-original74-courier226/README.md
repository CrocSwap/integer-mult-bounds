## Reproduction

From a normal repository checkout on Linux with CPython 3.12, run

```sh
python3.12 -I -B scripts/research_package.py --package research/p104-original74-courier226
```

The registered command reconstructs the #7645 word and this candidate from pinned, offline sources. It checks their invoices and protected observations, runs the actual native and signed applications, and prints the complete scientific result before removing its scratch directory. Allow about 17 minutes on a workstation. The native and signed stages in the direct run took 544 and 446 seconds respectively. The generic hook imposes its own stage deadlines.

The [independent reviewer](independent/README.md) checks all 1,501 public rows, the ordered observations at 630 private/COPY events, all 74 erased values, price inputs, and an actual wrong-sign control. To reproduce its checks against words freshly generated by the package, first run `python3.12 -I -B verify.py prepare` from the package directory. Take the scratch path printed after `REPLAY_WORKSPACE` and assign it to `work`. Then run

```sh
python3.12 -I -B independent/check.py --base "$work/baseline.json.gz" --candidate "$work/candidate.json.gz" --base-invoice "$work/baseline-invoice.json" --candidate-invoice "$work/candidate-invoice.json" --output "$work/independent-result.json"
python3.12 -I -B independent/compare_results.py independent/RESULT.json "$work/independent-result.json"
python3.12 -I -B independent/ordering_control.py --baseline "$work/baseline.json.gz" --candidate "$work/candidate.json.gz" --manifest "$work/manifest.json" --invoice "$work/candidate-invoice.json" --output "$work/ordering-result.json"
python3.12 -I -B verify.py cleanup
```

The ordering control tests a legal permutation with exactly the same invoice. It changes 65 public output rows while satisfying all 630 protected comparisons. [Direct native evidence](evidence/NATIVE-RESULT.json) and [signed evidence](evidence/SIGNED-RESULT.json) preserve the separate responsibilities of those stages. The native pass includes 2,959 pairs in the modular physical replay, 512 forward and 512 adjoint columns for each of 64 affected pairs and five route compositions, with absolute phase. The signed application checks 3,044 catalogue maps and 104 boundaries.
