# Finite ordinary BIT backend bootstrap

This finite bootstrap of the unchanged productive supplier from
[PR4760](https://github.com/CrocSwap/integer-mult-bounds/pull/4760)
admits ordinary BIT saving **1737729/500000000 = 0.003475458**, under its
retained completed-interface and implementation premises. This is
**0.454124296% above its previous exact ordinary saving**
17713901828029/5120000000000000.

The raw native WORD, its 11,400 independent originals and its complete paid
profile are unchanged. The changes are a tighter effective rank compiler,
a smaller paid cover loss with a larger fixed prime, and three finite
replacements of the completed ordinary atom backend. The complex supplier
and selected multiplication κ = 0.00302015 are unchanged by this contribution.

This uses the **finite acyclic leaf bootstrap of rohanarun's PR185**, with
the explicit recurrence/pricing lineage of PR199 and PR204. The contribution
here is its source-bound use with the current productive/delayed-cover supplier,
new effective constants, and independent arithmetic. No new native circuit
or priority for bootstrapping is claimed.

## Certificate and reproduction

```sh
python3.12 -B scripts/research_package.py --package research/bit-finite-ordinary-bootstrap
```

The two registered commands in VERIFY.json run through this wrapper. The first
authenticates and replays PR4760's exact raw/native/caller
certificate, then checks the new tails, compiler constants and all three
ordinary stages. The second uses the separate literal census and positive-series
engine, independently derives the new bounds, and rejects seven invalid
parameter/control ledgers. It does not import the primary price or tail engine.
All dependencies are repository paths declared in VERIFY.json; no Git or network
is needed by the direct verifier commands.

See [PROOF.md](PROOF.md), [RESULT.json](RESULT.json),
[INDEPENDENT.json](INDEPENDENT.json) and [RECORD.json](RECORD.json).
The author-side environment and export checks are in [VALIDATION.md](VALIDATION.md).
Finite replays and internal AI checks are separate from an independent external
mathematical review. The massive uniform program is algorithm-defined and is
not materialized. Newly generated fixed constants replace prior numerical
precision, tape, row and stock thresholds.

The tighter bound increases the sufficient rank exponent H1 from
262206447682297857 to **262208150916063859466241**, with N=2^H1.
This is an asymptotic exponent improvement with larger sufficient constants,
not a practical runtime improvement.
