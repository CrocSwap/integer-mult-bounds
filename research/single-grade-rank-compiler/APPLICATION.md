## Build the ordinary service from individual swaps

This step avoids importing a completed backend whose own proof could call an earlier compiler. For any fixed radix, exchange one pair of digits with all prefix, gap and suffix coordinates present using a constant number of sequential streams. In the input order `(prefix,x,gap,y,suffix)` send every suffix block to bucket `(x,y)`. Rewind the buckets once. In the output order `(prefix,y,gap,x,suffix)` consume the next suffix block from that bucket. Its head always advances in original prefix and gap order. The total scans and rewinds cost `O_q(V)` per digit pair for complete payload volume `V`. All other coordinates and arbitrary input bits return to the specified positions.
