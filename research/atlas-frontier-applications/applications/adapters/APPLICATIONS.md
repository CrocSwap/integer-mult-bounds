# Exact reader adapters and erased Pauli-class recovery

Two applications of the atlas were constructed and checked. Neither is claimed to improve the current integer-multiplication kappa by itself. The first gives an actual current-source, scratch-free native-reader primitive. The second repairs a complete six-qubit measurement design after loss of any one class; its generic checker accepts arbitrary valid input, not only the supplied field construction.

## 1. Actual native reader: a sparse involution

Let R be the eight-row scalar helper reader extracted by executing the literal scalar suffix of A in the authenticated PR2833 base or extra word. Prelude events are excluded explicitly; this is a reader theorem, not a claim about the complete supplier endpoint. Coordinates are the retained helper IDs in 224…703. The current centre-source permutation Q fixes 0…3 and swaps 4/5 and 6/7. Write v₁=e₄−e₅, v₂=e₆−e₇, dᵢ=vᵢᵀR. Exact source execution gives

j₁=(e₄₃₅−e₄₃₂)/2, j₂=(e₄₃₂+e₄₄₇)/2, Rjᵢ=vᵢ, dᵢjᵢ=2, dᵢjₖ=0 for i≠k.

**Sufficient construction theorem.** If any linear reader R and sections jᵢ satisfy these displayed identities for disjoint coordinate differences vᵢ, then Pᵢ=I−jᵢdᵢ is an involution, the Pᵢ commute, and R(P₁P₂)=QR. The construction acts on every input vector, including arbitrary correlated dirty helper contents.

**Proof.** Pᵢ²=I−2jᵢdᵢ+jᵢ(dᵢjᵢ)dᵢ=I. For i≠k, the cross rank-one products vanish, so the factors commute. Also RPᵢ=R−vᵢvᵢᵀR=(I−vᵢvᵢᵀ)R; because vᵢ has entries 1 and −1, the last matrix swaps the two relevant reader coordinates. The disjoint swaps commute, giving Q and the stated identity. No cleanliness or independence assumption on helper values enters this computation. Helpers outside the support of the emitted updates are untouched, and P²=I restores every helper exactly.

**Literal in-place implementation.** For j=(e_p+s e_q)/2, s=±1, the relevant d has d_p=2 and d_q=2s. Separate r=Σ_{h≠p,q}d_hw_h. The desired update is w'_p=−s w_q−r/2 and w'_q=−s w_p−s r/2. Swap the two coordinates with four scalar add/scale instructions, negate both when s=1, then apply two updates for each nonzero coefficient in r. No temporary field is used. Both actual d rows have 58 nonzero coefficients. The first reflection costs 4 + 2·56 = 116 instructions; the second costs 6 + 2·56 = 118. Total 234, all coefficients dyadic. Every touched helper has zero entrance frame, so the emitted adapter can execute at frame zero throughout, adding zero positive-rank recursive children. This does not assert that a later use at an arbitrary interior boundary is free. The independent exact Schur certificate in `reader_prefix.py` checks every one of 234 prefixes: the maximum squared operator-norm bound is 315, first reached at prefix 233. Thus a conservative five extra bits bounds the entire adapter, including arbitrary correlated tensor arrays and identity spectators. Atlas D039 permits paying this as a local prefix bound when a complete consumer supplies compatible boundary bounds.

`reader_adapter.py` independently re-extracts R from the requested word, checks these identities, symbolically executes all 234 instructions on all retained dirty helper variables, proves P²=I by exact rational execution, checks zero entrance frames, and rejects changed coefficients, a changed source and a deleted instruction. Receipts are `reader-PR2833-base.json` and `reader-PR2833-extra.json`. The word hashes are respectively `dda9878455b3a3bec64ca16b1ac7789bbf5ffb603d5713b8df8644485e85b1b7` and `bbe6bcba59e45e827a8e932ee4b23650d56ed4a0b8e0875c14f23c36b9e47eac`. Old PR2802 receipts remain separately labelled.

**Cost scope.** The construction keeps all eight rank-eight centre descents. It does not establish a complete gather/centre/scatter consumer, source-restoring changed supplier, physical hosting or new kappa. The adapter is nonunitary and can mix helpers assigned to different physical owner families. Its involution identity does not establish the family-local unitary premise of the delivered block-norm certificate. Although Q₀=I+P*P is a positive invariant metric (P*Q₀P=P*P+I), joint invariance with intervening native/owner operators has not been proved. Atlas D040 therefore cannot be applied as if these were coherent isometric gauges. Use the adapter inside a fully restoring local consumer, or prove and charge a new complete norm argument. The 234 helper-scalar count is not an apples-to-apples saving over PR2742’s 1316: that published construction uses an order-four action and additionally 120 monomials; here the action is a different order-two Q. The actual source scalar reader is certified, while full before/after centre Clifford adapters and a complete charged consumer remain separate.

## 3. Generic exact recovery of one lost commuting measurement class

Represent n-qubit Pauli labels by (x,z)∈F₂ⁿ⊕F₂ⁿ, with symplectic form ω((x,z),(x',z'))=x·z'+z·x'. Use the Hermitian representative P(x,z)=i^popcount(x&z)X^xZ^z. Labels commute exactly when ω=0. An n-dimensional isotropic subspace is a maximal commuting Pauli class with 2ⁿ−1 nonidentity labels.

**Sufficient completion theorem (atlas B098, binary specialization).** For n≥1, suppose 2ⁿ pairwise trivially intersecting n-dimensional totally isotropic subspaces of F₂^{2n} are supplied. The uncovered nonzero labels, together with zero, form a unique further n-dimensional isotropic subspace. Thus they repair the missing measurement class without any supplied candidate or field-construction promise.

**Proof.** Put q=2. The holes have cardinality qⁿ−1. For any hole h and old subspace L, the functional ω(h,−)|L is nonzero: otherwise h∈L^⊥=L. Consequently L∩h^⊥ has q^{n−1} elements. Since the old subspaces are disjoint outside zero, the number of holes in h^⊥ is

(q^{2n−1}−1)−qⁿ(q^{n−1}−1)=qⁿ−1.

This equals the total hole count, so every hole is orthogonal to every other hole. Their linear span H is isotropic and therefore has dimension at most n. But it contains all qⁿ−1 holes and zero, forcing dimension n and exactly that set of vectors. Any additional disjoint n-dimensional subspace must consist entirely of holes and zero, so equals H. This proves both a sufficient construction and uniqueness, including n=1.

**Measurement endpoint theorem.** Independent commuting Hermitian Pauli generators g₁,…,g_n yield 2ⁿ rank-one projectors Π_b=2⁻ⁿ∏_j(I+(−1)^{b_j}P(g_j)). For distinct subspaces in the completed spread, tr(Π_bΠ'_c)=2⁻ⁿ. Thus the repair returns an actual complete MUB measurement design as finite exact projector recipes.

**Proof.** Each (I±P(g_j))/2 is an orthogonal projection, and the factors commute; hence their product is an orthogonal projection. Expand the product. Independent labels imply that only the empty product has zero Pauli label; all other terms have zero trace. Therefore tr Π_b=2ⁿ/2ⁿ=1, so it has rank one. Different signs give orthogonal projections, and summing over all signs gives I. For two disjoint label subspaces, the trace of a product of expansions is zero unless both chosen labels are zero: equality of two nonzero labels would contradict disjointness. The sole remaining contribution is 2ⁿ/2^{2n}=2⁻ⁿ, which proves mutual unbiasedness. Literal Pauli multiplication phases are checked independently, not discarded.

## 4. Supplied practical object and checks

`six-qubit-recovery/INPUT.json` contains 64 commuting classes, six independent generators each, in a nontrivial seeded symplectic gauge. `RECOVERY.json` returns the unique lost six-generator class. `FULL-MEASUREMENT.json` gives all 65 classes and exact projector recipes; `PAULI-PARTITION.csv` lists every one of 4095 nonidentity six-qubit Pauli observables with its measurement class. There are 4160 rank-one outcome-projector recipes, with exact inter-class overlap 1/64. No hardware implementation, experimental calibration benefit or new MUB existence theorem is claimed.

The fixture is constructed from F₆₄ using an explicitly verified irreducible binary polynomial and the nondegenerate trace pairing, then conjugated by 17 symplectic transvections. Recovery does not receive the erased class. All 65 choices of erased class pass exact comparison against the separately retained full construction. Dimensions 1–5 provide boundary and additional regressions. Six negative controls reject two missing classes, duplicate classes, out-of-range labels, dependent generators, zero dimension and a noncommuting class.

`verify_pauli_recovery.py` imports no recovery code. It checks hashes, literal Pauli multiplication including fourth-root phases, independence and commutation, all 4095 partition labels, the recovered complement and the CSV. Its exact certificate gives rank-one projector traces 1 and cross-basis overlaps 1/64 by the displayed proof. This is a reusable repair/validation application, not a numerical smoke test. Runtime enumerates the explicit 4ⁿ label universe; the generic CLI is intentionally capped at n≤10, while the theorem is not.

Example commands, using any ordinary Python 3 interpreter:

```text
python -B pauli_recovery.py --input six-qubit-recovery/INPUT.json --out fresh-recovery.json
python -B verify_pauli_recovery.py six-qubit-recovery
python -B pauli_recovery.py --make-fixture --out fresh-six-qubit-fixture
```
