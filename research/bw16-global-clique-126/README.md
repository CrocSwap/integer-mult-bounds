# Global BW16 nonorthogonality clique bound 126

This contribution was produced by Nick Petalas. Apache-2.0.

Every pairwise nonorthogonal subset of the 2160 norm-eight BW16 lines has
at most **126** lines. This is a finite certificate with a scoped written
combinatorial proof. The [proof](PROOF.md) covers every subset of this fixed
shell, rather than a bounded search around one clique.

Nine 240-line D16 sets partition the shell. Each contains at most fifteen
clique members. The new equality-case step shows that fifteen members in
any one chart force the entire clique to have at most thirty lines. Thus
any clique larger than thirty has at most fourteen members per chart:

    |C| <= 9*14 = 126.

The baseline nine-chart count gives 135. The new step lowers it by nine.
The conditional thirty-line bound is attained. DaysSky's PR895 supplies the
published 72-line lower witness as a credited premise. It is not replayed.
The remaining global interval is therefore 72<=omega<=126.

## Reproduce

From the repository root, with standard-library CPython 3.12:

```sh
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -W error -B research/bw16-global-clique-126/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -O -W error -B research/bw16-global-clique-126/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/research_package.py --package research/bw16-global-clique-126
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/check_research_commit.py --package research/bw16-global-clique-126 --check-source-history
```

Another CPython 3.12 executable may replace that absolute path. The direct
marker is `PASS_BW16_GLOBAL_CLIQUE_126`. Verification is read-only and needs
no Git, network, source imports, numerical library or solver. `--emit` writes
a newly computed receipt to stdout; it is absent from registered checks.
[RESULT.json](RESULT.json) is generated by that code, bound to the package
source hashes and compared byte for byte in ordinary verification.

The certificate checks all 2160 shell members against an independent
Construction-D membership predicate, all nine disjoint blocks and all 17280
inverse chart images. It also checks 176 literal star fixtures against all
1920 odd lines, all 32768 sign patterns at center zero by a parity formula,
and all 435 pairs of a thirty-line attainer. Six controls reject wrong norm,
nonaffine support, odd sign parity, a damaged orthogonal matrix, duplicate
charts and the false compatibility of the two signs on one coordinate edge.
