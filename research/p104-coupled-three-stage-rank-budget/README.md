# A sharp stage-rank budget at every coupled width

For a shortest five-query tuple on4q independent fields, any three
commuting compatible full-stage projectors satisfying the actual
chronological-prefix conditions have total rank **at least7q**, for every
positive q over a commutative field of characteristic different from two.
The individual ranks may differ and internal coefficient blocks may fail
to commute. An explicit ordinary frame attains(2q,3q,2q) and the literal
independent-stage endpoint S diag(ABC,AB,B,C) at every q.

This rules out a coupled three-stage shortcut: two parallel copies cannot
reduce the total stage rank from14 to13 while retaining the actual stage
endpoint. An exact q2 rank13 compatible shortest tuple is included as a
scope control; it fails the required prefix identities. This is an
algebraic rank-inventory result. It does not provide a new native caller,
paid-call count, kappa, multiplication theorem or scientific admission.

[PROOF.md](PROOF.md) gives the uniform argument. The key step is that an
endpoint-adjacent full pair is compatible with the same square-zero
query, so its intersection has dimension at least2q. The other cross
intersection contributes q; the three-query Gram forces a union of at
least4q dimensions. The sum of stage ranks is therefore at least7q.
The central site on four blocks needs rank4q by an explicit invariant
column/row calculation, covering every possible triple of sites.

## Reproduce

Python3.12, standard library only; no network or Git is needed by the
mathematical checks. Run from the repository root:

```sh
python3.12 -B scripts/research_package.py --package research/p104-coupled-three-stage-rank-budget
```

In a Git-free package export, run `python3.12 -I -B verify.py` and
`python3.12 -I -B independent.py` from the package directory.

The registered normal/optimized checks are read-only. verify.py checks
source identities, dimension controls, the exact sharp formal stage word,
and the rank13 missing-prefix example. independent.py is a separately
written implementation with no import of the author verifier; it checks
the canonical and attaining words, ranks and rejected controls.
The written proof establishes unbounded q, while finite exact checks
corroborate its conventions. These are author-side AI-assisted checks,
not human or proof-kernel verification. VALIDATION.json records actual runs.
