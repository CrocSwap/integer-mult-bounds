The normalized channel does not strictly commute with the full target

Use P_sigma f(x)=f(sigma^t x), with D_I Fourier multiplier i^weight. Every
selected sigma is orthogonal. Define
  delta_j = (weight(column_j(sigma))-1)/2 modulo 2,
  t = sigma delta.
Then the exact relation is
  D_I P_sigma = T_t P_sigma D_I.
For families 600,...,607 the translations t are
  15, 15, 23, 39, 71, 135, 263, 15.
All are nonzero. Linear and pair phase coefficients were checked separately.
Thus orthogonality gives covariance with a translation, not commutation.
The scalar port matrix C commutes with a common address operator on each
input port. Therefore the same covariance holds for P_sigma C. Its image is
not restricted to translation-fixed vectors: one nonzero coefficient permits
an arbitrary payload. Strict commutation does not follow after that factor.

The seed two-tap identity does not prove a constant-cost all-size decoder

At the binary seed,
  D_p^-1 = a I + b T_p,
  a=(1-i)/2, b=(1+i)/2.
This equality is exact. But it cannot be tensor-lifted by keeping two taps.
On Fourier character (1,1), (D_p^-1) tensor (D_p^-1) has eigenvalue -1,
whereas a I+b(T_p tensor T_p) has eigenvalue 1. This is an exact two-bit
counterexample. The existing compiler treats the selected-coordinate
transform as a paid child. A different all-size implementation would need
its own proof and invoice. The orthogonal covariance identity is
multiplicative and does not have this sum-versus-tensor defect.

Exact hypotheses for endpoint uncompute

Suppose physical inputs are z and an arbitrary host h. A verified capture
adds Kz to the host. Suppose the complete later circuit has been proved to
leave source outputs Fz and host output Fh+FKz, with all other affected
outputs already correct. Then the required endpoint decoder is exactly
  K_end = F K F^-1.
Subtracting K_end(Fz) restores Fh. For F=D_I and the stated chart, covariance
turns this into the translated decoder T_t K. This is an operator identity,
not a price. It still requires the correct source entry inverses inside K.

Applying this lemma to the new construction requires a proof of the actual
later routed controller, all cover classes, the physical host response,
coexisting captures, arbitrary correlated dirt, and a legal all-size decoder
with its finite and recursive costs. Those claims are not supplied by the
800-column local replay. No new supplier exponent is certified here.
