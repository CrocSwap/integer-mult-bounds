## Reproduction

Run from the repository root with standard-library Python 3.12:

```sh
python3 -B scripts/research_package.py --package research/joint-relations-independent-validation
```

The registered manifest runs normal and optimized replays. Direct commands for
explicit receipt destinations are:

```sh
python3 -B research/joint-relations-independent-validation/verify.py --output /tmp/joint-normal.json
python3 -O -B research/joint-relations-independent-validation/verify.py --output /tmp/joint-optimized.json
```

The standalone verifier authenticates both helper modules before import, rejects
missing/symlinked/mutated working inputs and wrong claim/head/payload/premises,
then copies the minimal capsule into a private scratch tree. It creates fresh
bytecode caches, propagates explicit optimization to every child and runs the
eight scientific commands serially. After copying a read-only export, it sets
only the new private scratch directories to mode 0700 so caches and regenerated
outputs can be created; frozen/exported source bytes and permissions stay
unchanged. Fresh outputs are parsed for exact source bindings and complete
scientific coverage; a child exit code alone is insufficient. It uses no runtime Git reader or Git-blob fallback. Normal and
optimized executions remain separate recorded runs. Receipt destinations must
be outside the package and free of symlink/hardlink aliases. Cold receipts stay
outside frozen inputs, avoiding a source-hash cycle.

`SOURCE-BINDINGS.json` declares every package-local input with raw digest,
compressed-payload digest where applicable, original head/path/blob and offline
commit/tree membership proofs. `VERIFY.json.inputs` is empty because no runtime
input lies outside this package; its package-local inventory is explicit and
all package changes already trigger registered replay. The full capsule is
about 2.3 MB and retains the selected 31-file phase proof/reuse closure rather
than the historical research archive.

The first normal package replay completed all eight fresh commands in 23.47 s
under the root 1 GiB serial guard. That receipt predates the final bootstrap
helper hash check and is evidence for its exact pre-bootstrap wrapper only.
Final registered normal/optimized and committed/exported-byte receipts are
external publication gates. Engine bytes and mathematical input payloads are
unchanged. See the source/verification limits in `PROOF.md`.
