private banks, adapters and returns before resuming. After the final native
segment return its adapters and retire its private homes. A base program emits
its n sequential rank-one leaves with actual axis/embedding descriptors.

Induct on decreasing compiler rank and on the finite class traversal. The
existing source/port bijections prove that every emitted productive port is
the actual intended owner, including inherited private values. Existing
Pascal/live-role injectivity proves distinctness within a class and whole
child. Local segment order is unchanged; disjoint units admit the stated

return adapters. Every private tag is allocated once and retired after its

## 4. Permanent-home layout and physical reservation

Assign source row i home i for `0<=i<B`; append one fresh home per new owned
tag. This is an immutable owner/home bijection. One home tape contains

```
^ field_0 | field_1 | ... | field_(K-1) | $
```

Each complete body has F bits, including any binary-encoded format metadata.
A fixed larger payload alphabet can be encoded with a fixed block factor.
Outside delimiters are distinct from payload symbols. All origin markers and
the productive input's delimiter formatting are supplied at entry. Only the
B arbitrary productive fields are supplied as data. Working tapes are blank
except origins. The region for new homes is private blank storage, disjoint
from all external data; the suffix outside the complete K-home reservation is
blank or a preserved disjoint exterior. These are explicit entry premises.

`reserve` emits transitions to copy the first productive body's **extent** as
a zero-bit guide on a private tape, restore heads, seek the home `$`, and
append K-B complete zero bodies using the guide. It installs each delimiter
and the new `$`, erases the guide completely and returns every head. K-B is
unrolled in finite control. No integer F or per-bit counter is used. The
verifier supplies only B productive bodies, so this work is physically
executed and charged. Its time is `O(K(F+1))`.

Owned allocation and release zero the full reserved physical extent. This is
empty capacity; semantic initialization is the explicit charged service above. On
release, that zero body and its markers **remain physically in the packet**
and in historical backing. Source homes remain in original source order.
Gathered duplicates are private working copies and earn no output credit.

## 5. Literal gather/service/return

For a service on distinct homes h_1,...,h_a, a<=b, unroll the K home positions
in finite control. No runtime hash table or random-access payload array exists.

1. Scan every home. Copy the F bits of each selected body onto its designated
   operand tape and install its delimiter; skip other bodies. Return the home
   and active operand heads to origins.
2. Execute the supplied service to completion. Its arbitrary-input contract
   supplies exact returned operands, scratch retirement and head return.
3. Scan every home again. At selected homes write the completed operand body
   into the **same** home; preserve all other bodies and all markers. Check
   the selected delimiter, then return the home head.
4. Erase active operand bodies and delimiters while moving back to their
   permanent origins. Keep their complete historical extents charged.

Every physical loop branches on a fixed-alphabet symbol and moves each head
by at most one. Positions are finite controller choices. `tape_graph.py`
constructs and executes literal transition tables for the fixture primitives;
graph execution accesses payloads only through current-head read/write/move.
The host state dictionary simulates finite control, not an input-varying RAM.

Gather makes an exact selected-field copy without changing its home. The
service contract gives its completed value. Return writes it to that identical
owner, fixing all other complete fields. Working erasure touches only private
copies. Induction over the entire service word proves the physical result,
including all suspended parent values and frame contexts. A child may have
many productive ports: its expanded services use permanent homes as needed;
those ports are never claimed to fit on b tapes simultaneously.

No arbitrary coordinate permutation receives the copy price. Whole-job map
and phase services retain their own supplied primitive tariffs. These copies
only transport complete serialized fields between homes and operand tapes.

## 6. Full cost, historical backing and productive volume

Each gather/return uses two home traversals and two head returns, plus bounded
operand returns, erasure and marker handoffs. The generous bound outside its
primitive is `16(K+b+1)(F+2)`. The reservation prelude fits the same bound.
Adding every service's own time proves (1). All constants and complete field
scans appear explicitly; no extra factor d, f or p is hidden in a per-bit loop.

For private primitive tape t, take the maximum **visited extent in this call**
over all services, including the reservation guide, and sum these maxima as H.
All use the same origins. Let Hist_entry be complete pre-entry historical
backing, including opaque exteriors and previously larger retired buffers.
The unconditional increment bound is

`Hist_final <= Hist_entry + K(F+1)+2 + b(F+2) + H(F,theta) + O(b+m+1)`.

This can overcount overlaps with entry intervals, which is safe. All untouched
prior history remains in Hist_entry. Under fresh-origin/no-outside-history
entry, the initial productive prefix is contained in the final home interval,
so the cleaner total-capacity corollary is

`K(F+1)+2 + b(F+2) + H(F,theta) + O(b+m+1)`.              (2)

It includes all O tags, not just currently live ones. `Tape.read/move/write`
record actual head visits, including blank excursions; peak never shrinks.
If the supplied primitive history is `H<=C_H(F+2)`, (2) is linear with a fixed
coefficient. No current-volume bound is inferred after a larger history.

Reuse skips reservation only for the **same already-reserved packet, owner
bijection, root format and machine**. All private homes and work must have
returned to zero and all heads to origins. The verifier reuses the same four
Tape objects and their historical capacity. It does not rebind a different
template or silently shorten any field. This is distinct from dynamic
ordinary-recursion parking, which remains in supplied primitive contracts.

For productive logical volume V, retain B explicitly. Under the format bound
`F+2<=C_format V/B`, the dispatcher's extra term is

`16 C_format (R+1)(K+b+1) V/B`.                          (3)

Each paid leaf's complete field volume is V/B, **not V/K**. Owned homes have
not increased productive width. The full original coordinate factor remains
inside every body throughout. Actual precision padding and field-format cost
are prerequisites of C_format, not consequences of this transport proof.

R and K are frozen before varying input parameters. Thus (3) is a fixed
coefficient times V and does not add an input-varying d/f factor. It can replace
the qualitative finite dispatcher term in the selected review's actual W/O/G
ledger once its concrete native manifest and primitives are bound. This note
does not recompute that ledger or certify the huge selected word.

For variable R,K the implementation really pays `Omega(R K F)`. With Q
independent NOT services on K=Q source homes, it scans Q^2 complete bodies.
The verifier records this scaling. This is a cost of **this** implementation,
not a universal lower bound. Absorbing R,K is valid only for a frozen template.

## 7. Complete metadata and emitted-output cost

No free metadata RAM is needed for existence. Use #7423 section 5's serialized
source/node tables. Write its symbols `Z,D_c,G,H_s,Q_c,K_s,K_b,K_q,S,J,q`, with
Q_c the candidate-rank bound, unrelated to this note's event count. Put

```
A_setup = K_s + q H_s + Q_c + S^2 + 1,
A_query = D_c (K_b+K_q+Q_c+(G+1)J+D_c+1),
M_point = binom(G+d_s,d_s).
```

Here d_s is the fixed number of source-codec productive rank types, not the
varying input dimension d. D_c is the fixed compiler call-depth bound, not the
original complete coordinate-factor dimension.
Let M include the complete historical predecessor metadata, N-row library and
its real integer bit lengths, native descriptors, recursion frames, owner/home
records and emitted event word. Let E be the latter's total bit length, and
C_owner the number of exact source/owner queries actually made. The credited
serialized-table implementation bounds address work by

`O(N Z + (N A_setup+C_owner A_query)(M+1)^2)`.

The native class enumeration adds conservatively
`O(Q M_point (G+d_s+J+1)(M+1)^2)`. At a rank-n node use G_n: every class
contains a unit, since its least target product at depth h fits by
`A r_max^h k_min^(G_n-h)<=A k_min^G_n<=n`. Strict separation supplies
`r_max<k_min`, hence the required weak inequality. Maximize over n<=N.
Thus class visits can be charged to
emitted unit events, including all actual ordered paid paths.

Assign permanent homes by complete serialized owner-table scans, adding
`O(E K (M+1)^2)`. An explicit finite native descriptor table is included in M;
an arbitrary supplied factory adds its separately declared `T_factory` and
its actual historical workspace to M.
These are compilation costs, not unit-cost callbacks or polylogarithmic
generation claims for the unmaterialized selected native manifest.

If g_e is the size of the primitive graph instantiated at service e, the
unrolled controller contains

`O(K + R(K+b+1) + sum_e g_e)` states/transitions.          (4)

Let G_out be the actual bit length of its serialization, including state names.
A conservative schoolbook number/record implementation serializes it in
`O((G_out+1)^2)` time. Add E reading/writing and T_factory to the three displayed
metadata terms for a complete safe emission bill. Compiler storage includes M
and G_out when materialized; a streamed output tape still retains its written
output backing. None is silently removed after erasure or publication.

Equation (4) is output-sensitive in the actual unrolled controller. It can be
quadratic in the logical Q-event count when K grows with Q. The serialization
bound is deliberately loose, not a claimed linear output algorithm. All this
work is finite pre-input work for the frozen supplier. It does not prove a
polylogarithmic selected-library generator or an input-varying compiler tariff.
