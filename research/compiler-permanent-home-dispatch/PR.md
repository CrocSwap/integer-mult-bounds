# Execute compiler checkpoints through permanent physical homes (no κ)

The current chronological source/leaf codecs preserve field identities but
leave the native checkpoint stream and payload gather/return open. This package
connects the unchanged #7423/#7348/#7347/#7346 resolver chain to complete local
native segments, whole source complements, separate ordered exits, adapter
returns and per-instance owned lifetimes, then emits literal fixed-tape scans.

For R services, K total source/owned homes, B productive arrays and full root
extent F, dispatcher overhead is at most `16(R+1)(K+b+1)(F+2)`, plus every
primitive cost. All owned homes remain in physical backing after release.
Arbitrary entry history is retained through an increment bound. Productive
normalization remains V/B. R,K and finite native columns are frozen before
varying d,f,p,F; varying format metadata is handled by charged runtime services.
The graph has O(RK) states and can be quadratic in the logical event count.

The proof assumes actual native/adapter identities, typed initialization and
uniform complete-field primitive graphs. Raw zero homes are storage capacity;
structured fields need explicit charged header/format initialization. No
selected semantic field is inferred from zero bits.

reuse, actual head-visit history, quadratic scan scaling and ten rejecting
controls pass. The fixtures are synthetic binary primitives, not selected
rational/Clifford numerical implementations.
