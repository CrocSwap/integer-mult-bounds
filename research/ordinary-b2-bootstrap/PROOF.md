# One ordinary bootstrap step that clears the complex rate

Prepared for Ross Richardson with substantial OpenAI Codex assistance.
Apache-2.0. The construction composes Jose Manuel's completed ordinary and
fast-primitive sources, Rohan Arun's PR185/387 stopped-leaf argument, and the
retained PR589 BIT profile. It does not originate those components or their
bootstrap formula.

Under the stated source-relative physical contracts, one further ordinary
stage supplies

```
a2 = 57697923247/33292900000000
   = 0.001733039874778105842386815206845904...,
T_B2(V,e) <= 4283584 A V e^(1-a2),
```

for a finite uniform coefficient `A` specified below. It exceeds the present
complex endpoint `C=0.001730980255989036959962` by the exact positive rational

```
a2-C = 342853411912956978405651/166464500000000000000000000000.
```

This is an ordinary interchange construction from the **BIT** component.
It invokes no part of the new complex source. It removes an ordinary-rate
obstruction once the completed binary interface is connected to the complex
caller; it does not by itself supply that caller or its outer embedding.

## 1. Why a bootstrap at the complex rate is insufficient

The demonstrated preceding ordinary rate is
`a1=169711/100000000=0.00169711`. If one retains the selected convenience
choice `s=(1-10^-24)C-10^-27`, the one-step value is

```
a_next = s(1-s)+s*a1 = 0.001730921627244654642552821294... .
```

Although this exceeds the requested legacy kappa, the legacy outer margin is

```
q=(1-2*10^-24)*a_next,
(1-10^-24)*q/(1+q) = 0.001727930714600372546778004395...,
```

which is below `0.001727989140903569` by more than `5.8426*10^-8`.
Comparing an ordinary rate directly with kappa omits a necessary outer loss.

Instead choose the independent BIT coupling `c=1/577`. The BIT constructor
does not need `c<C`: the old common-rate restriction was a sufficient
parameter choice, not an input dependency on the complex algorithm.

## 2. The source-bound acyclic construction

Use one fixed source-admissible prime `q>2^80`, positive complete preceding,
intervening and trailing spectator extents, and the selected PR589 BIT
catalogue. The native ordinary interface maps the two complete radix-q
chunks of width `e`, preserves its borrowed input, returns a distinct owned
output, restores every spectator coordinate, and closes its owned work.
The binary wrapper preserves the same completed contract. Successful admitted
execution is the scope; interruption recovery is not asserted.

The previous `B1` is the actual ordinary construction of
[`selected-bit-recursive-closure`](../selected-bit-recursive-closure/PROOF.md)
and PR2899, with its fixed coupling `17/10000` and saving `a1`. Its sealed
coarse caller uses its elementary `A0` routes and swaps. The successor `C1`
is the physical program in
[`selected-bit-fast-primitives`](../selected-bit-fast-primitives/PROOF.md):
both the reached weighted/remainder swap and the reached complete owner-chart
route use that completed `B1`. Entering `B1` suspends the successor factory
scope and restores both preceding bindings. `B1` completes under those
preceding bindings. Exiting the suspended scope then restores the successor
bindings before the caller acquires its output lease, copies the protected
result and clears that result. The preceding output remains protected until
this copy/clear finishes, before any reuse.

The complete dependency order is

```
new complex caller -> binary B2 -> ordinary B2 -> C1 -> B1 -> C0 -> A0.
```

Only the leftmost caller is the new complex construction. Its correctness is
not used to construct anything to its right. Coarse recursive calls decrease
atom count; a call to the preceding ordinary implementation decreases the
fixed stage. `B1` never re-enters `C1` or `B2`.

The existing factory composition is precise. In the one cold namespace
authenticated by `stage_sources.activate()`, create two distinct `Ordinary`
instances on the same immutable selected BIT binding, topology and programs:

```
previous = Ordinary(q, binding, topology, programs,
                    profile=Profile())  # 17/10000, m=64, rmax=42
outer = Ordinary(q, binding, topology, programs,
                 profile=Profile(numerator=1, denominator=577))
registry, receipt = selected_registry(actual_selected_bit_catalogue)
native_B2 = promote_ordinary(outer, previous, registry)
binary_B2 = Binary(native_B2)
```

`selected_registry` must bind all 1,123 actual data/host charts and their
inverse factor words. An identity-only `Registry(64)` is insufficient.
`promote_ordinary` changes the controller view of the fresh outer root
session before it reads numerical input; it reuses that session's actual
physical roles and adds the fixed successor scratch allowance. It does not
copy an active machine or alias its work with `previous`.

The two predecessor exports are compatible at the source level. All 23 files
in `selected-bit-fast-primitives/inputs/pr2899.tar` are byte-identical to the
corresponding files in the retuned coupling's PR2899 export; the latter adds
twelve frozen dependencies. Their SHA256 values are respectively
`fc4a2e07423835737c8fb3872664b16ff12aa4cf83b1e26e49878debef40c531` and
`0fef1707c6460418fd01fd49faf0d8ff7945907fa57284765c852a12d2674d3c`.
The independently cold-guarded loaders should not both be invoked into one
already populated namespace.

This specifies a finite program composition under the retained source
arguments. The present arithmetic audit does not execute a production GL64
payload or claim a new full physical-machine replay of that composition.
Changing `Profile` on an unpromoted C0-backed `Ordinary` supplies only a
retuned first stage and does not establish this B2 bound.

## 3. Complete stopped BIT recurrence

Write `p1=1-a1`. Retain the complete paid BIT histogram and bad-class term:

```
H={1:381024,2:400416,3:22752,4:26880,
   5:29376,6:17376,7:26784,42:288},
m=64, W=28416, epsilon=10^-16,
F=32*64^2*sum(H)=118606528512.
```

Every paid request executes its complete low/high fibre; the per-request
bad-class estimate is retained. No average over selectively omitted prefixes
is used. The fast-primitive source's explicit local bill is bounded by

```
C_B1 V [252 w^p1 + (1598048/111)(w-1)^p1] + A_q V(n+1) + E_prep.
```

At `w=1`, omit the high-route term. The 252 bound is four calls for each
of at most 63 peeled pairs. The other coefficient counts both entrance and
return owner routes, with the actual same-q `B1` interface. It is a time
coefficient, unrelated to the old external row allowance also numbered 252.
`E_prep` includes coefficient/history preparation and is absorbed only in
the canonical root-coupled domain, by the complete target-fibre argument.

Choose a finite `A>=1` dominating these uniform coefficients, the preceding
`B1` bound, all source access and output disposal, the outer wrapper bill,
and its elementary fallback. It may depend on the fixed prime, source,
compiled registry and fixed machine inventories. It does not depend on
width, payload contents, ancestor, prefix ordinal or external multiplicity.
No empirical bound such as `A<2^512` is asserted.

For normalized time `T1(n,w)` and `f=floor(n/64)`, the actual stopped tariff is

```
T1(n,w) <= A w^p1                                      (0<n<64),
T1(n,w) <= sum_r (H[r]/W) T1(rf,w)
            + (epsilon F/W) max_(1<=j<=f) T1(j,w)
            + A(n+w^p1)                               (n>=64).
```

It includes all restoration, routing, selection, copying, marker work,
rewinds and private-work disposal. The preceding ordinary calls are in the
local toll, not additional C1 coarse children or parent row multipliers.

Define `mu_t=(sum H[r](r/64)^t+epsilon F(1/64)^t)/W`.
The exact full-profile calculation gives

```
mu_1 = 2874298095721977/2890625000000000 < 199/200,
mu_(576/577) in
 [999998938581682162866772413602,
  999998938581682162866772413603]/10^30 < 999999/1000000.
```

The old `9999/10000` power cap is false at this coupling. Use the increased
coefficient, not the predecessor's smaller number. Strong induction against
a monotone majorant, including the fallback maximum, yields

```
T1(n,w) <= 200 A n + 1000000 A n^(1-c) w^p1.             (1)
```

The linear contraction pays `A n`; the strict power gap pays `A w^p1`.
No monotonicity of the machine's measured running time is assumed.

The interval above was independently rechecked using both the outward
rational series in `frozen/interval_engine.py` and integer-power bisection: at scale
`Q=2^160`, consecutive integers bound each power through
`z^577 64^576 <= r^576 Q^577 < (z+1)^577 64^576`.
Both computations retain the rational fallback weight.

## 4. Actual stock, wrapper and all-width coefficient

Use the encoded selector of
[`retuned-ordinary-coupling`](../retuned-ordinary-coupling/PROOF.md), keeping
the original width fixed throughout each coarse root:

```
w=ceil(e^c),
D(e)=0 for e<64; D(e)=1+D(42 floor(e/64)) otherwise,
K(w)=269241600 |GL64(F_q)| q^(4096(w-1)),
stock=K(w)^D(e), k=min{j:q^j>=stock}.
```

Choose the stock before the body, then set `n=floor((e-k)/w)` and
`ell=e-k-nw`. Use elementary fallback if `2k>=e` or `n<64`.
The retained depth and stock proof gives `k<=16390 e^c log2(e)` for `e>=2`.
Since `17/10000<c<1/512`, the new `w` also meets the old preparation/history
lower bounds. The numerical contexts, canonical widths and root generation
level remain unchanged; `w` is not recomputed at descendants.

For `e>=2^20`, both actual fit predicates hold. The sufficient comparisons
include `17^128>32*16^128` and
`32780*(17/16)*20=696575<2^20`; then `n>e^(1-c)/4-1>64`.
This is a sufficient cutoff, not a claim of the smallest fit threshold.

The ordinary wrapper executes two completed reversed-body ROOT calls. Each
uses padding below two, so (1) is charged four times. Include the three
ordered body updates, restrictions, residual digits, high exchange, setup,
all scans, copying, rewinds, erasure and output return. Enlarging `A` as above
gives the complete bill

```
T_B2(V,e)/V <= A[801n + 4000000 n^(1-c) w^p1 + k+w+1].   (2)
```

The wrapper's retained elementary high/remainder operations are sufficient;
they are not silently promoted to a free weighted or reversed operation.

Now `a2=c(1-c)+c*a1`. Since `c>a1`,

```
n^(1-c) w^p1 <= e^(1-c) w^(c-a1)
             <= 2^(c-a1) e^(1-a2)
             < (17/16) e^(1-a2).
```

Also `a2<c`, `1-a2-c>1/2`, and `log2(e)<=2 sqrt(e)` for `e>=1`.
Consequently `n<=e^(1-a2)`, `k<=32780 e^(1-a2)`,
`w<=2 e^(1-a2)` and `1<=e^(1-a2)`. Substitution in (2) gives

```
801 + 4000000*(17/16) + 32780 + 2 + 1 = 4283584.
```

For the finite fallback range `e<2^20`, `e^a2<2^(20/512)<2`, so its
elementary `A V e` bound fits the same coefficient. The source's fixed-degree
logarithmic setup is retained and absorbed into `A`; the retuned proof uses
`(1+log2 V)^4<=512V`. Positive input volumes also absorb fixed compilation
allowances into a further finite coefficient. The binary wrapper pads two
complete fields by a factor below `q^2` and charges its own operations; this
only changes the fixed q-dependent coefficient.

For comparison with the PR185/387 generic cutoff method, the four exact gaps
are

| Gap | Value |
| --- | --- |
| `c-a2` | `2076753/33292900000000` |
| `1-a2-c` | `33177502076753/33292900000000` |
| `1-a2-c(1-a1)` | `331776/332929` |

Their minimum is the first. The generic sufficient recipe remains valid:
choose a genuine coefficient bound `A_*<2^h`, then
`L>=max(20,36/delta^2,2(4+h)/delta)` and use the preceding completed algorithm
below `2^L`, enlarging the next constant by its actual fallback cost.
It must carry the preceding constant. The explicit coefficient argument
above avoids needing that enormous time-absorption cutoff: its `2^20`
cutoff is for physical stock fit, while `A` is retained in the time bound.

## 5. Restoration and finite physical inventories

Each B1 primitive restores its borrowed source, complete spectators and row
coordinate at its own return, before the successor reuses any output or row.
The parent C1 retains its fixed roles while the preceding complete inventory
is active. The successor adds 128 fixed scratch tapes and its separately
counted fixed-capacity high numerical bank. Distinct B1 and B2 instances have
distinct owned work; immutable source tables may be shared.

The parent's stock quotient is reused only after each completed child
returns. Neither the two reversed-body calls nor the extra bootstrap stage
multiplies the externally supplied row divisor. B1's internal stock and
binary padding are included in its completed time/space contract. Depth-first
parking and the geometric child-volume sum give the retained
`O_q(V_root)+F_q` occupied/visited space, including blank retained backing
for the fixed roles. This is not per-return deallocation of host memory.

This is the completed-interface premise of PR185 and PR387, not merely a
final two-call endpoint: two erroneous row changes that cancel at the outer
return would not meet it. The source-bound `StagePool.suspended` and
protected-output copy/clear are the relevant implementation boundaries.

## 6. Boundary of the optional B2 route

This package constructs and prices the optional ordinary B2 stage under its
retained source-relative physical contracts. It uses the canonical BIT,
preceding ordinary and fast-primitive sources; it invokes no pooled complex
supplier and has no dependency on PR #4270.

The B2 rate is strictly above `C`, so it can be weakened to a desired
ordinary rate below `C`. This removes one rate obstruction. It does not
establish a complex or multiplication exponent. A consumer must bind the
completed B2 interface at its actual compact call sites and preserve every
native endpoint, hosting, width, restoration, stopping-rule and outer
analytic obligation at those calls. In particular, changing an ordinary
exponent does not remove exceptional repair, row separation or long-record
costs in the compact binary theorem of
[`physical-complex-compact`](../physical-complex-compact/PROOF.md).

That theorem's complete tariff includes

```
s sum_rows T_B2(v0,nG) + O_m(V+M A_len^6+delta M A_len(R+A_len)),
```

with four binary calls for an earlier source/toggle and twelve for a later
source. A candidate complex join must separately establish its global
binding over every actual call and chart, its one-active-node recursion
and parked-parent reserve, common-grid precision, and the stopping/root
contract needed by the outer parameters. A modular fixture or a rate
table cannot supply this global invocation.

The production B2 factory is specified by the source-relative composition
above, but this package's checker neither constructs nor executes it.
Implementation and caller admission remain open. They are not needed for
the exact conditional rate calculation and written cost derivation here.
