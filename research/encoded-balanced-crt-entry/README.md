# Derive balanced CRT node entry from the physical axis stream

This package removes the host node-selection and precision arguments from
the numerical-entry part of the CRT pipeline. One fixed finite-symbol
controller counts the actual axis records, manufactures a depth counter,
maintains half-size and node cursors on tapes, projects the current records,
and invokes the unchanged numerical Entry and CRT producer. The program
receives no width list, ell, start, level or numerical precision.

**No new kappa.** This is a source-relative numerical-node iterator and
quantified interface proof, not the complete CRT permutation or a full
foundational-assumption discharge.

## Actual result

For every admitted dyadic axis source of #5353, the iterator visits all
aligned nodes in level/start order. The actual source scans generate the
canonical left/right records and exact precision guide consumed by #5219
and #5053. Eight protected zero words are physically prepared from that
guide. The unchanged #5505 bank supplies the same 63 numerical backings as
node size, source position and precision change. All legacy geometry
arguments to its fixed call signature are None; the new bridge rejects
any supplied host geometry.

One live numerical result is handed off at a time. Closing it retires the
result before the encoded cursor advances. This is a linear-use current-lease
interface: consume the current result once and relinquish its borrowed
aliases. Retaining old Python lease objects does not provide a physical
stale-handle validation service. The source bytes and head are
restored at every boundary, and every older retained tail remains counted.
There are **78 owned roles plus the supplied source**:63 numerical, eight
protected, and seven topology/width roles.

[PROOF.md](PROOF.md) proves the encoded cursor/half-size invariant, exact
provider-input compatibility, lifecycle, complete per-tape historical
storage, and source-operation budget. If A is the sum of declared widths,
M=2+3A+4d and P_G is the current node precision, the full bill is

```text
C_front(M+2)^2 +4096
  +sum_nodes [2^20(P_G+2)^4 +2^16(P_G+2)^2 +4096].
```

C_front is fixed and input-independent. The new frontend's raw local Port
actions have the explicit envelope `2^16(M+2)^2`; the numerical expansion
constant for its finite control has not been certified. The complete bill
above retains that constant explicitly, and no explicit complete-control
numeric majorant is claimed.

This pays root count manufacture, source seeks and rewinds, each cursor and
level change, current guard preparation, the actual numerical operations,
pending output and all retirement. It includes the last/rightmost node.
For A<=p in the near-equal-width family it is O(p^4), with O(p^2) owned
retained tape cells plus the entire supplied source backing, including old
tails after its framed RIGHT. The source must still be supplied and its production paid by
the enclosing caller; source operations are not silently identified with
binary TM steps.

## Evidence

[RESULT.json](RESULT.json) records14 actual numerical nodes in four full
trees with 2,4 and 8 axes. The first four-axis case has a nonzero node start
and precisions7,5,11 on the same 78 roles. It performs370,212 measured Port
and numerical actions and retains1,135 cells including the source. The
eight-axis case executes all seven nodes, with 6,897,342 measured actions
and 3,807 retained cells, including 97 pre-existing source-tail cells. These counts corroborate the conservative proof;
they are not asymptotic extrapolations or literal binary instruction counts.

An independent exhaustive congruence oracle checks actual lower/product
words and complete output records. Observer decoding never supplies a
runtime value. Runtime geometry/decode names are poisoned in the new
module, and physical constructors plus Word.inspect are sealed after fixed
initial acquisition. Source snapshots, stable backing identity, exact
current guards and complete blank histories are checked at every node.

Eight controls detect a supplied host geometry, live reentry/close, a duplicate
close before a later entry, stale retained data, nondyadic source count with actual cleanup,
omitted half doubling and a Boolean/integer receipt substitution. The
nondyadic preparation uses 1,454 measured actions and restores its source
and all 78 owned histories. The proof separately retains the cost of each
rejected external call; arbitrarily many requests do not become free.
The receipt's `raw_action_bound` compares measured tape actions only;
it does not numerically certify C_front.
