# Uniform encoded owner-graph bound at the installed return cut

This is a source-level invariant for the exact traversal used by PR4986, not a bound on the entire Python heap. A graph has weight `V+E+A`: visited vertices, followed edges, and inspected `__dict__` attributes (including attributes whose values the omission alphabet skips). Tape bodies are opaque. Dict keys, set/frozenset members, function globals/closures and generator frames are not followed. The authenticated `observer.py` and `installer.owned_tapes` have the same omission alphabet. All quantities below are finite compile-time geometry, never decoded payload lengths.

## Parameters and bound

For each owner `i` in `(service, original native child, producer)`, let `S_i` be the weight of its exact source constructor graph before numerical input, `d_i` its binding dimension, `s_i` its packet slot count, and `R_i` the maximum weight of a scalar recipe in its compiled `scalar.recipes` catalogue. This is a pre-input graph evaluation, including the actual Ordinary capacity, topology, staged roles and fixed source programs; it does not run an input or maximize over an observed execution. It is permissible to upper-bound this compilation quantity when materializing a production controller is undesirable. In particular, six PhysicalArenas contain exactly `sum(capacity+1)` preallocated PhysicalWords, and every ScratchPool has its constructor's fixed Tape tuple. Their contribution is already in `S_i`.

Define

```
M(d) = 3*d*d + 3*d + 20
G_i  = 2*S_i + 43 + M(d_i) + R_i + 2*s_i + 128.
```

Let `e_0,e_1` be the two fixed engine-role list lengths, `a` the auxiliary-role length, `r` the caller-storage role length, and `b` the acquisition packet/output/pool capacity (all supplied by the actual Installation). Put

```
L = 2*(e_0+e_1) + 2*a + r + b + 1
H = sum(initial distinct owner Tape counts) + a + r + b
K = max(H, G_0+G_1+G_2+L).
```

The source's three inventories are disjoint, so the sum used in `H` is the size of their union. Counting auxiliary/storage/acquisition Tapes again is conservative. There are no physical allocations during admitted execution; adopted return exchanges only permute these roles. Thus persistent lifetime handles can be assigned from `[1,H]`, and every complete PR4986 snapshot has size at most `K`. This supplies a symbolic instantiation of its graph-size premise. It does not bound its separate encoding/frontend cost `F`.

## Fixed skeleton and replacement proof

Separate the constructor graph into its fixed object/container skeleton, scalar-valued fields, and the replacement slots below. Fixed skeleton attributes do not acquire runtime history links. Aside from the listed replacement slots, an object field is overwritten with a fixed role, fixed source object, scalar, or the same fixed-length Tape tuple. A mutable scalar may cease sharing a constructor leaf with another field; assigning one distinct new leaf per original outgoing edge bounds all such losses of sharing by `E_i`. Fixed container lengths are no greater than at construction: numerical `available` lists have length at most capacity, fixed role/program/action tuples retain their lengths, and numerical live sets are opaque. Thus unchanged-skeleton weight is at most `S_i+E_i <= 2*S_i`. This explicitly covers arbitrarily large counters as single encoded graph leaves, not as bounded-bit integers.

The `128` residual allowance covers the selection's extra dict vertex, the installed bound-method attribute/edge/leaf (at most three per owner), up to eight newly non-None scope Function leaves, and possible fixed-arity container replacements. After assigning all scalar-edge sharing losses to `E_i`, this residual requires fewer than 32 vertices/edges/attributes; 128 is deliberately loose. In particular it contains no term proportional to the number of invocations, recursion depth, source Tape extent, counter value, or completed generations. The source table above exhausts graph-bearing fields assigned by the reachable return, Ordinary, primitive and Context mutators. Private temporaries are not graph roots at this cut; pointers from excluded `binding/group/recipes/...` values are outside this exact encoding.

Combining these terms gives `G_i`. The lists included by the kernel have lengths: saved `e_0+e_1`, external `e_0+e_1+a`, auxiliary `a`, storage `r`, acquired at most `b`, plus its sentinel one; their sum is `L`. This proves the complete K inequality for every successful admitted external return and installation initialization. The same reasoning applies before and after the adopted-role permutation. Repeating successful generations does not alter it. Controlled failure/discard is not an extra admitted child-return phase.

## Check and limits

The checker runs the unchanged complete two-generation source case, inserting only the predecessor's read-only observer hook. It independently recounts graph sizes, validates every snapshot with derived K instead of assuming 65536, checks all source-cut pool/scope/numerical/selection/role cardinalities, and then runs the original inventory guards. It rejects a retained Context-history attribute, a stale lease retained in a pool, and an insufficient owner bound. A separate tiny shape control calls the literal inherited `restore_context` method with preallocated roles and a declared synthetic fixed vocabulary; no numerical invocation or arithmetic correctness is claimed for that control. This covers the Context shape that the reduced fallback-only Ordinary fixture does not execute numerically.

The fixture reproduces service-owner growth from 5033 to 5054 edges at 2327 Tape roles; it is calibration, not the uniform proof. K depends on the actual pre-input compiled object sharing, scalar catalogue, capacities and dimensions; the calibrated K is not asserted for a production geometry. `RESULT.json` records the CPython 3.12 calibration. No payload, selected frontier or frozen package is changed.

The parking simulator's visited/transitions sets accumulate history. The encoder treats them as opaque leaves; similarly, numeric counter bit lengths and Tape bodies are unpriced by this graph-size lemma. Therefore K must not be advertised as a full CPython-memory bound, finite-bit scalar encoding, or complete physical frontend theorem. PR4986's physical encoding/frontend `F`, bit-width validation, complete unmatched D* versus B* bill and supplier obligations remain separate.
