# Eight coupled helper outputs from the retained-center native word

This package constructs and replays an exact changed backward native provider
on all 632 original owners. It replaces eight rank-eight center calls by
retained earlier same-frame caches; eight later H1 inputs become identically
zero and their calls disappear. The resulting paid profile is
`{1:2193,2:412,3:510,4:127,5:40}`: the center-free profile minus eight H1 calls.

After explicit ordinary basis and boundary operations, the coupled outputs are

```text
X = D x - R y + R W h
Y = D y
H = D(h - Z y)
```

Here `R=DQ`, `D` is the native rank-eight Gaussian, `ZW=14I8`, and `WZ=I-C`
for the existing physical code `C`. The 400 other original helpers retain
their native jobs, with profile `{4:28,7:7,8:47,9:318}`. All nine owned fields
start arbitrary and finish zero. **The eight H outputs remain coupled; no
new autonomous Gaussian targets, complete caller or improved κ are claimed.**

[PROOF.md](PROOF.md) gives the every-positive-width argument, ownership rule,
exact local bill and precision boundary. [WORD.json.gz](WORD.json.gz) is the
complete changed native word. [PROVIDER.json](PROVIDER.json) is its ordered
boundary recipe, including explicit dyadic basis programs and phase-bound
monomial words; its references to the pinned source main normalizers are part
of that recipe. The verifier recomputes the word and recipe from authenticated
main inputs, with no scratch paths or network access.

The new schedule adds 1,644 ADD, 40 SCALE, 16 COPY, 24 CLEAR, eight physical
SWAPs and 464 monomial maps relative to the original raw source. The 464 maps

## Reproduce

From the repository root, using only Python 3.12 and its standard library:

```sh
python3.12 -B scripts/research_package.py --package research/native-rank8-helper-provider
python3.12 -I -Werror -B research/native-rank8-helper-provider/verify.py
python3.12 -I -Werror -O -B research/native-rank8-helper-provider/verify.py
```

The registered normal and optimized commands check all 641 native input
columns, every original endpoint, all nine owned outputs and 1,240 physical
phase bindings. Mutation controls reject a changed basis ADD coefficient, a
changed cache coefficient, nonzero zero-retag input and a same-tableau phase
error. A direct run takes about 13 seconds on the preparation machine; the
registered pair is bounded separately in [VERIFY.json](VERIFY.json).
`--emit` regenerates only the package-local `PROVIDER.json`; normal replay is
read-only. Frozen scientific source inputs are never regenerated or modified.
