# Common-tangent corollary for smooth helper arrays

This applies the source/funding theorem and its finite block lift in
PROOF.md and BLOCK-LIFT.md, with separate adversarial reviews A and B. It does not introduce a kappa claim or prove any framework assumption.

Let helper arrays lie in (F^D)^H, with a smooth promise submanifold S, and
let retained original whole fields I project submersively onto (F^D)^I
at some point. Main arrays remain arbitrary independently of S. Use the
same fixed finite normalized source observation/target maps as C40; these
are A_E tensor Id_D and c_E tensor Id_D. Exact whole cached targets must
be deterministic functions of their histories on the promise; every
deleted whole MOVE must vanish identically there. No regularity of the
cache functions is assumed.

For F=R use a C1 real submanifold. For F=C one can use a complex submanifold;
a merely real-smooth promise in complex arrays is instead realified to
2D real entries, using this source's rational-real coefficient property.

Choose one common locally constant-rank point in the open retained-
submersion locus, as proved in PROOF.md. The constant-rank fiber argument
applies to the full finite array coordinates and every whole target at
that same point. Its helper tangent is now arbitrary block-linear, with
annihilator U. Retained whole-field submersion makes the actual fully
debited helper set fund an expanded-column basis for U. All original
whole zero and cached-output benefits persist on that tangent domain.
The block-linear funding theorem bounds this tangent's optimistic payoff,
which is at least the original promise's payoff before preparation cost.
Consequently the same fine source-envelope bound extends to this smooth
array-promise class, under those hypotheses.

No assumption that this tangent has identical scalar equations per array
entry is needed after the block lift. The earlier conjugation example
still refutes a complex-SCALAR tangent identification, while its real
block tangent is covered by this broader route.

For an irreducible complex algebraic S dominating the retained array
coordinate space, characteristic-zero generic smoothness and finitely
many maximal-rank loci provide a common nonempty Zariski open of valid
points. Real algebraic promises need an actual real smooth/submersive
locus; complex dominance alone does not supply one.

Arbitrary discrete/exact-grid promises, nonregular encodings, approximate
recovery, main-dependent promises, data-dependent histories, fractional
MOVE/output splitting and newly decoded target types remain outside this
statement. Finite-dimensional tangent variation and accounting weights
do not reprice a native rank r as Dr or establish an all-column theorem.
