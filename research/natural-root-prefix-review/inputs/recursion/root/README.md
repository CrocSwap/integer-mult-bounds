# Natural root inputs for the physical recursive shape machine

This author-side construction generates root A/R/H from physical T,R_body,w
and unary depth before entering an exact unchanged all-depth recursive core.
One fixed table has 27 tapes and 31,821 microinstructions for L=4/q=3/N=1. Four
natural-root cases and six controls pass; no A/R/H is supplied to execution.

The new connection is literal root-descriptor production and cleanup. The
standard arithmetic, #5829 address identity, fixed-tape codec, stack and
protected return retain their source credit. PROOF.md proves an explicit
O_template(V0) root-prefix bill using geometric output growth, in addition to
the retained recursion's actual occurrence-sum cost. CONTRACT.md states the ABI.

The exact prior private core freeze is copied under inputs/core, including
its manifest, original receipt and eight pinned upstream inputs. CORE.json
does not mislabel newly authored recursive.py or its table as a 3bad tree file.
Only the two declared entry/halt links change in the new emitted table.

From this directory, using any Python 3.12 standard-library interpreter:

    python3.12 -B verify_files.py
    python3.12 -B check.py
    python3.12 -B -O check.py

The checks are read-only by default, need no Git/network/PATH tools, and read
only relative HERE inputs. --write is the explicit authoring option. The
separate integer oracle computes expected endpoints only; it never supplies
the literal machine with decoded descriptors, branches or products. TABLE.json.gz
is the sealed finite program and is compared to assembly on every fixture.

This closes a root-shape input boundary within a fixed two-call-site bit
grammar. It does not provide numerical ancestor weights, ordinary BIT or
Gaussian children, root integer-input padding/width selection, precision,
stock, full production, a new kappa, or external scientific acceptance.
