## Critical proof boundaries

At each inverse node, the current left coordinates determine the same fixed
rotation that the forward node used. Subtraction inverts that rotation on
valid right values; padded right values remain unchanged. Invalid left values
set that node's controlling integer to zero. This does not imply a globally
invalid padded vector is fixed by every lower node. Disjoint nodes within a
level commute, so reverse level order suffices for both composition identities.

Every invocation rebuilds its guide and guards at its current precision.
Retirement erases that interval; previously erased suffixes remain blank.
This invariant permits both shrinkage and later regrowth without scanning
the full maximum history at every small node. Historical backing is still
charged: 79 roles belong to one invocation, and two fresh forward/inverse
invocations retain 158 histories. Same-bank restarting is not proved.

The extra reverse bootstrap and halving work is linear in the total unary
lengths. Complete source staging and commits remain quadratic in source
length. Summing the quartic numerical budgets gives the claimed O(A^4)
source time and O(A^2) extra retained backing. The finite refinement constant
`C_inv`, ownership/source contracts and the allocated-versus-visited-space
qualification remain explicit. Source-model checks do not replace a literal
machine refinement theorem.
