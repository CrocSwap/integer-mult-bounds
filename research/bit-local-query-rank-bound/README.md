**NO VERIFIED GAIN.** Retaining the selected #7001 paired caller's 36
LOCAL stage assignments and exact 38-role endpoint requires at least four
paid rank-one QUERY terms at the original stage incidence. The proof
allows arbitrary constant bases and chronology, including initialized-clean

python3.12 -B scripts/research_package.py --package research/bit-local-query-rank-bound
