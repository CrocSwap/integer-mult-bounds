# Explicit finite completed-ordinary bootstrap

This supplies the actual ordinary multiplication saving required by the frozen modern outer ledger. It uses the retained completed-interface stopped-leaf construction of [PR185](https://github.com/CrocSwap/integer-mult-bounds/pull/185), as expanded in [the pinned PR387 proof](https://github.com/rohanarun/integer-mult-bounds/blob/d9fb9410b1ae6f6ada376a1e7fd12bc176e476ea/research/e8-outer-slack-refinement/PROOF.md). That source also preserves the reviewed PR185 proof. The initial ordinary saving is 384599/10^10, matching the inherited assembly's starting point. This bootstrap is an additional finite sufficient construction for the actual modern target; the supplier's separate legacy bootstrap remains intact.

Write C for the freshly admitted complex endpoint, b for the strictly smaller coarse endpoint in `outer/LEDGER.json`, and a for the exact effective ordinary saving `rows.struct_boundary_radix_union.a`. The same row has q<a<b and a=(q+b)/2. Choose the fixed rational atom exponent `s=(a+b)/2` and bootstrap slack `beta_boot=(b-s)/(2b)`. The replay checks `0<seed<a<s<(1-beta_boot)b<b<C<bit<1/32` using the exact source-bound complex and retained bit endpoints. Its bootstrap slack is separate from the modern outer's beta.

Starting with a_0=384599/10^10, recursively apply the retained construction at the same fixed s:

`a_(j+1)=(1-s)s+s*a_j`.

The exact closed form is `s-a_j=s^j(s-a_0)`. Every stage strictly progresses, stays below s, and has four strictly positive sufficient gaps: `s-a_j`, `1-a_j-s`, `1-a_j-s*(1-a_(j-1))` and `1-s`. The first pays for the stopped coarse atom, the second for input borrowing/restoration, the third for the stopped remainder, and the fourth for finite stock. Only the previous completed ordinary algorithm occurs at the stopped leaves. There is no recursive call to the algorithm currently being constructed.

For these exact frozen files, 12 stages are sufficient and 11 are insufficient. The fresh expected receipt records each rational saving and every gap, and checks `s^12*(s-a_0)<s-a`. The output ordinary saving a_12 is strictly above the actual modern target a. Consequently its time bound also implies the weaker saving a requested by the modern ledger, for every input width at least one. Together with the independently admitted primitive supplier and the retained outer hypotheses, this provides the ordinary-rate interface consumed by that ledger.

Each of the finitely many stages gets its own finite cutoff. Let C_j dominate all fixed instruction counts and all previous-stage constants, and choose an integer ell_j>=1 with C_j<2^ell_j. For the minimum positive stage gap delta_j, the sufficient stopped-coarse cutoff recipe is `L_j=ceil(max(1,36/delta_j^2,2*(4+ell_j)/delta_j))`; below width 2^L_j run the previous completed ordinary algorithm. Its constants are finite by induction over j. No actual previous constant is assumed below 2^512 or 2^2048; there is no claim of a small practical cutoff. Integer tails and arbitrary-width stopped leaves are part of the retained construction rather than an assumption of exact divisibility at every recursive call.
