# Bounds and verification limits

Separate Before Serializing Shared State kept new files in this package and
session cache, with only short shared Git operations under the common OS lock.
Prove It Works required exact trace agreement, actual owner-map inspection,
source-authenticated retained bytes and read-only export replay.

The new Python functions fit the 60-line review ceiling. Dispatch is direct
and nonrecursive. There are two stages, at most 28,000 events each, 712 field
bounds, 73 pivots for each checked owner matrix and at most nine lines per
local native recipe. The immutable sources bound coefficients and operand
bit lengths. All validation uses explicit exceptions and remains active under
optimized Python. No subprocess, network call, background process or runtime
plugin discovery occurs in the direct verifiers.

Power-of-ten rule 3 has a Python managed-runtime deviation: exact integers,
fractions and JSON allocate dynamically. Bounded input reads, fixed event and
field counts, and one finite trace bound live memory; no full payload arrays
are allocated. Rule 4 retains PR3226's existing longer audit routines as
immutable source: neither retained `audit()` is called by the new dispatchers.
Its bounded arithmetic primitives and at-most-nine-pivot internal elimination
are authenticated and inspected. Changing frozen source solely for style
would break predecessor byte identity and expand this task.

The rule 10 diagnostics are Ruff `E,F,B,I,UP,C4,SIM` and formatting on new
code, warning-as-error runs and registered Python 3.12 replay. The immutable
vendor source retains its historical formatting. Source capacities and rejection
controls cover malformed inventories, ownership, map actions and dimensions.
No Lean/Docker, all-depth proof, historical global suite or selected cold
replay is needed for this isolated reference contract; all remain unrun.
