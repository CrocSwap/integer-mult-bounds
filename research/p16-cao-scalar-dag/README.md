## Why this is a circuit change, not just a simulation

A rational elementary ADD `L_d += c L_s` commutes with a second ADD `L_x += b L_y` when `d != y` and `x != s`; it also commutes with unrelated scalar and warp operations. A later ADD `L_d += -c L_s` can be eliminated together with the first only if every intermediate event commutes with it. Both the forward and the inverse-transpose emitters must satisfy these **independent conditions**, including all 632 arbitrary source columns and dirty spectators.

`inverse_add_dag_search.py` screens all opposite pairs within 160 source events, finding 542 matching syntactic pairs, 19 valid in both orientations. `combined_inverse_add_certificate.py` chooses 17 **nonoverlapping** pairs (34 ADDs), removes them simultaneously, and reconstructs the complete native word with the original `warp_merge.synthesize`.
