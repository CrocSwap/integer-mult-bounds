# Fixed raw generation

The prelude is the same at every input length and carrier rank. It restores the pinned source bundle, applies the literal signed-margin changes, reconstructs the paired rational circuit and both caller schedules, and constructs the signed nine-axis Clifford factors. The word of each supplier includes its original ordered tags. The generator makes each Clifford pair from its source frame. A digest alone does not generate a factor.

Use a sequential, fixed-alphabet backend for these finite operations. A record has delimited binary integers, lists or strings. Keep two rewrite tapes and a key tape for a linear search. Use shift and add for integer multiplication, binary long division and Euclid for reduced fractions, and a serial list of ready vertices for the topological order. Use the same tie order as the source. A stable scan can replace sorting. Preserve all source, graph and phase checks. These choices bound the cost of the prelude independently of a Python interpreter.

The compressed source archive has 2,164,152 bytes. Its regular-file manifest checks each decoded file. The nested immutable source registries check their data too. A byte-oriented inflate needs only the literal tree, the back-distance and length fields and a 32,768-byte window. Even retrieving each copied byte by a complete scan of that window has a fixed price. JSON parsing and canonical serialization can use serial delimiter stacks, bytewise key comparison, and insertion sort. SHA-256 uses 64 fixed rounds per 64-byte block. The file sets, all public tag lists and the three journal reconstructions have fewer than $2^{32}$ input or output symbols apiece. The fixed source portals, 36 binary subcalls, 48 numerical subcalls, 6,965 scheduled vertices, 323,573 final rational donor terms, 2971 pairs and 104 primary ports fit these bounds. Numerical coordinates in this paragraph are fixed source coordinates.

Two journal updates use finite literal linear combinations of the input weight rows. The two helper splits include sums and exact rational divisions. The replay with the fixed Python 3.12 Fraction implementation counted 8,018,449 rational results while rebuilding the journal graph. Every observed reduced numerator and denominator had at most 65 bits. The retained graph and final atlas have coefficient and grid literals of at most 87 bits. Reduced fractions of this width use products and sums below 180 bits before reduction. This finite check applies to the unique pinned journals. The subsequent grade and input-dependent computations have separate all-size bounds.

For the Clifford prelude the frame dimension is 9. A tableau holds 18 signed Pauli rows. A binary row reduction uses at most 18 pivot stages with at most 18 rows per stage. A state-vector pass reads 512 Gaussian entries. The generator forms each endpoint from two canonical frames and a constant list of monomial, diagonal and Fourier factors. A canonical frame uses at most 9 commuting rotations and two linear maps. Each call to lower_child makes one partial Hadamard and at most three monomial reductions. Each reduction checks its input and output state at zero. The independent equality check uses the 18 conjugated generators and the zero state. The circuits at a single reduction have fewer than 1024 elementary gates. Each Gaussian numerator can gain at most two bits per gate. The 17-bit contact tables for the 104 ports use at most $2^{17}$ addresses and 17-bit binary forms. Allow full 131,072-bit Walsh masks, their temporary shifts, and both directions of each route.

For an explicit loose ceiling, take $L_0=2^{40}$. Every source table or emitted raw-field list has fewer than $L_0$ entries. Each raw tag, integer, literal address vector or Walsh bitmask has fewer than $L_0$ bits. Count the nested row searches in each weighted journal with one loop each over the file, journal entries, changed rows, covector entries, donor entries and ready vertices. Constructing and serializing one result can also visit every other row and every key. This is fewer than $L_0^{12}$ indexed operations, including the scan of all removed and inserted moves. For the frame generator allow one loop each over all pairs and ports, gates, state addresses, tableau columns, candidate basis vectors, rows, columns, and comparison entries. Repeating the loops for inverses, phase checks and raw caller transfers still fits $L_0^{12}$. The finite array of all intermediate records uses less than $L_0^{16}$ cells even if every indexed operation appends a separate $L_0^2$-cell record. Scanning and rewriting the whole store twice, schoolbook arithmetic, division, or at most $2L_0$ divisions for Euclid, cost less than $L_0^{50}$ per operation. The product, plus decoding, encoding, changes of data format, copies, rewinds and disposal, is below $L_0^{80}<2^{4096}$. Per-column projectors and basis changes on an actual large physical field are generated during its call and have their separate control and movement bill.

The proof bounds a specified serial lowering of the fixed generator. The finite journal trace, atlas counts and source digests can be replayed by the verifier. A kernel check of all raw circuits remains outside this contribution.
