## §1 Setting and the exceptional-line principle (PROVEN)

In pivot coordinates for a frame F (α_u(i) = M_{u f_i}/M_{f_i f_i}, β_s(i) = M_{f_i s}):

**Lemma W (witness).** (EC) with s₀ = f_k ∈ F: every row u ∈ Z with k ∈ T(u) has α_u(k) ≠ 0.
*Proof.* Pick c ∈ T(u)∖{k}; a tetrad T′ ≠ T(u) through {k,c} contains a line s with ε_kc(s) ≠ ε_kc(u), so s ⊥ u, and s ≠ s₀ (s₀ ∈ F) is an exact column. x_u = 0 gives α_u(k)β_s(k) + α_u(c)β_s(c) = 0; α_u(k) = 0 would force α_u(c)β_s(c) = 0, but α_u(c) = M_{u f_c}/M_{f_c f_c} ≠ 0 (column f_c ≠ s₀) and β_s(c) ≠ 0. ∎
**Lemma W′.** (ER) with u₀ = f_k ∈ F: a column s with k ∈ T(s) has β_s(k) ≠ 0 as soon as some pair {k,c} ⊆ T(s) has a Z-row u in another tetrad through {k,c} with ε_kc(u) ≠ ε_kc(s). Same proof with rows and columns swapped (x_u = 0 kills x_u y_s).

## §4 Rigidity with extra zeros on E8 ∖ (A2 triangle); Theorem R for ≤ 3 extra zeros per row and column

### §4.2 Rule ZA2 (PROVEN)
