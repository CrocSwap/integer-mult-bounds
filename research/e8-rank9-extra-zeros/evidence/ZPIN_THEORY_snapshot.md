# ZPIN: extra zeros in the rank-9 E8 pinning model (zero-aware rebuild of KSTAR pin.py)
Labels: PROVEN (one-line proof below) / CHECKED (machine) / OPEN.

## Setting
Frame F=(f_1..f_8), pivot coords: alpha_u(i)=M[u,f_i]/M[f_i,f_i], beta_s(i)=M[f_i,s] (i in tetrad T(u)), x_u,y_s from the exact rank-1 Schur complement. M_us = sum_{i in T(u)∩T(s)} alpha_u(i)beta_s(i)+x_u y_s.
An extra zero M_{u f}=0 (u not orth f) is exactly a zero coordinate alpha_u(f)=0 (or beta). Other extra zeros M_us=0 (u,s off F) are "hidden". Variables: nz(e,i) (coordinate nonzero), x/y status, zp(e,p)=both coordinates at pair p zero (the zero-vector state, absent from the old model), E(p,e1,e2)=same point of P^1 and both nonzero vectors (row/row, col/col: proportional; row/col: dot product 0, i.e. pt(row)=[al_a:al_b], pt(col)=[be_b:-be_a]), RQ_i(u,w): x/coord_i equal and defined. g-vars: dim of span of (coord_a,coord_b,x) vectors of a set >=2.
Scopes: n = no extra zero (old model); a = exactly one zero, at (u0,f0) with f0 in F; b = zeros only in row u0 (NON dropped for row u0 only); kK = at most K visible exceptions (zero coordinates + hidden cross pairs h); z = zero forced at (u0,f0), everything else free, NON off; c = fully free.

## Rules and one-line proofs (all PROVEN; each is a necessary condition of M=ABt, rank 9, orth zeros, M_tt!=0)
- E-axioms: E => nonzero vectors; E => equal zero-pattern (proportional / dot-0 nonzero vectors have matching zero coordinates); both vectors of the same pure type [1:0] or [0:1] => E; E transitive (equivalence on nonzero vectors).
- ORTH (u in T1, s in T2 through p, opposite sign => u orth s): M_us=d_p+x_u y_s=0 where d_p=alpha|p . beta|p. x_u y_s=0 => d_p=0 => zp(u) or zp(s) or E. x_u y_s!=0 => d_p!=0 => no zp, not E.
- NON (same sign, only where M_us!=0 is a hypothesis of the scope): M_us=d_p+x_u y_s!=0; if E or zp then d_p=0 so x_u y_s!=0. Dropped (scope c,z), dropped for row u0 (b), replaced by hidden-zero literal h (k).
- TRI row/row, col/col: with shared index m and nonzero coordinate m, pairs (m,x),(m,y) equal as points => vectors on {m,x,y} proportional => pair (x,y) equal or zero vector. WITHOUT the guard it is false (u=(1,0,1),w=(1,0,2)); the mutation TRInoguard is caught.
- TRI row/col: pi_i=alpha_u(i)beta_s(i), O_p:=(pi_a+pi_b=0). O_mx and O_my give pi_x=pi_y=-pi_m; if pi_m!=0 then d_xy=-2 pi_m!=0 (char!=2), if pi_m=0 then d_xy=0.
- Schur: complementary tetrads, orth, M_us=x_u y_s=0.
- DIAG: M_uu!=0 => some alpha_u(i)beta_u(i)!=0 or x_u y_u!=0. SAMET: orth u,s in one tetrad: sum of the five terms is 0, so not exactly one term nonzero.
- K/D1 (dimension duality): at p, sign eps, rows R_i of tetrad T_i with sign eps and columns C_j of T_j (j!=i) with sign -eps are orthogonal, so the K^3 vectors (al_a,al_b,x) and (be_a,be_b,y) satisfy U_i perp V_j; dim U_i + dim(V_j+V_k) <= 3. Sets: R_i,C_i and unions R_j∪R_k, C_j∪C_k. Sufficient conditions for g (dim>=2): two nonzero vectors with different zero pattern, or both ab-parts nonzero and not E. If g false (dim<=1) all vectors of the set are proportional: equal zero patterns (when nonzero), E when both ab-parts nonzero, RQ_i when x and coord_i nonzero. dim U>=2 => dim of the dual union <=1 (rule Gdual), monotone under subsets (Gsub).
- ZZ: two vectors with x=0, both ab-parts nonzero, not proportional, in a set S => span = plane {third coord 0} => every vector of the dual set is a multiple of e_3 => ab-part zero (zp). In the old model this was a contradiction (psi!=0); now a propagation. (A mutation ZZold cannot fire on any known family: x=0 rows with zero ab-part do not occur in B-form or A2, so ZZ-new is proven but not testable by data.)
- Q2: all four coordinates and x nonzero for u,w: rat_a/rat_b=alpha(b)/alpha(a)=rho_ab, so two of {RQ_a,RQ_b,E_ab} give the third.
- CP (common partner, generalised to any two rows of one sign class and any column of opposite sign in a third tetrad): E(u,w) means phi_u=lam phi_w; (u~-lam w~).s~ = (x_u-lam x_w) y_s=0 so y_s!=0 gives x_u=lam x_w: equal x-status and RQ_i when defined. Transposed likewise. (TW is subsumed: RQ_a,RQ_c => E_ac by Q2.)
- Hypotheses (as Theorem R): RES: for every line s not in F, D meets O_s or beta_s==0 on T(s) [(Sigma4): b_s^perp=H iff beta_s=0]; transposed with alpha_s==0; for s in F the plain form.
