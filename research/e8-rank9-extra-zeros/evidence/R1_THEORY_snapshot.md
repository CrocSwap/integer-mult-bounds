## §0 Dictionary (PROVEN)
* **Their object** (expSG §0): N ∈ Q^{120×120}, N = XYᵀ with X, Y ∈ Q^{120×9}, N_aa = 1, N_ab = 0 for a ⊥ b, all other entries free (zero allowed). "Completion" = such N of rank 9. R = root coordinates with r·r = 2 (their `RT`), G = RRᵀ.
* **Ours** (#2819): M over a field K of char 0, rank 9, M_tt ≠ 0, M_ts = 0 for t ⊥ s; extra zeros Ξ = {(t,s): t ≠ s, t not ⊥ s, M_ts = 0} (ZPIN2 §1). Our e8lib roots also have r·r = 2.
* **Normalisation.** N := D_M⁻¹M, D_M = diag(M_tt). Left multiplication by an invertible diagonal preserves rank, the zero pattern (forced and extra), B-form (D₁ ↦ D_M⁻¹D₁, c ↦ D_M⁻¹c) and the A2 family (rows rescaled). Conversely every completion N is an M with M_tt = 1. Q ⊂ K: every statement proven over all char-0 fields holds over Q.
* **Lift** (expSM §0, census3.py, expL1 §3). N is a *lift on S* (X-side) if rank N[T,:] = 8 for T = V∖S (equivalently rank X_T = 8); Y-side: rank N[:,T] = 8. Their closed results use, in addition, (R2) "N[T,T] is a root realisation" and then the normal forms:
  - **κ-family** (Prop. 0, `kfam.py`): X = [diag(α)R, κ], Y = [diag(α′)R, κ′], supp κ = A, supp κ′ = B, no a ∈ A, b ∈ B with a ⊥ b, 2α_aα′_a + κ_aκ′_a = 1. Derived by them for S = A with independent roots.
  - **A2-triple lift** (expSM §0 (iv), `a2lib.py`): S = an A2 triangle {s₁,s₂,s₃}, x_t = (r_t, 0) on T, x_s = ξ_s(c_s, 1), c_{s_i} = μ_i r_{s_i} (i = 1,2), c_{s₃} = μ₃r_{s₃} + ν n (n ∈ ⟨r_{s₁},r_{s₂}⟩, n ⊥ r_{s₃}); y_t = (r_t/2, η_t) with η_t = −c_s·r_t/2 on O_s; y_s = (β_s r_s, η_s). ν ≠ 0 (scaled to 1) = non-concurrent; ν = 0 = concurrent = κ-family.
  - A2 family of #2784/#2819 (`a2e8.py build_a2`): rows a_u = (r_u, 0) off the triangle, a_{u_i} = (r_{u_i} + g_i, 1), g₁ = 0, g₂, g₃ ∈ ⟨r_{u₁}, r_{u₂}⟩; columns (r_s, z_s), z_s = −g_i·r_s on O_{u_i}. This is `a2lib` up to the GL₉ × torus gauge (g_i ↔ c_{s_i} − c₀).
* **Definition used by philippeVV (follow-up 7, per the audit):** N is a lift on a pairwise-odd S if it agrees with a torus orbit of G/2 except on odd (non-orthogonal) pairs touching S; their R2 is universal rigidity on T = V∖S. Under that definition R1 is not vacuous. The Lift Lemma consumes the weaker per-N form used here (rank N[T,:] = 8 and N[T,T] a root realisation); our theorems give the per-N form, and B1/B2 show it in the follow-up-7 sense whenever S is pairwise odd (S = A clique, or S = B when B is a clique, or an A2 triangle). (Bare "rank 8 off some S" would be vacuous: take S = V∖{rows ⊥ z}, z ⊥ 8 independent rows.)

## §1 The bridge: B-form ∪ A2 = κ-family ∪ A2-triple lifts (PROVEN; CHECKED instances)
**Theorem B1.** Let N = D₁GD₂ + cβᵀ be a rank-9 B-form completion (N_aa = 1, c_uβ_s = 0 for u ⊥ s; D₁, D₂ diagonal, possibly singular). Put A = supp c, B = supp β, α = diag(D₁), α′ = diag(D₂), κ = c, κ′ = β. Then:
(a) N = [diag(α)R, κ][diag(α′)R, κ′]ᵀ is a κ-family member with these A, B; A, B ≠ ∅; and α_a = 0 or α′_a = 0 only for a ∈ A ∩ B.
(b) It is a lift with R2 automatically true: if A has no orthogonal pair, on S = A (X-side); otherwise on S = B (Y-side). In both cases N[T,T] = diag(α)G diag(α′) on T with α, α′ ≠ 0 on T.
*Proof.* (a) GD₂ entries: (D₁GD₂)_{ab} = α_a (r_a·r_b) α′_b, so N_ab = x_a·y_b with the stated rows. "c_uβ_s = 0 for u ⊥ s" is literally "no a ∈ A, b ∈ B with a ⊥ b". N_aa = 2α_aα′_a + κ_aκ′_a = 1 is their diagonal identity. If cβᵀ = 0, rank N ≤ 8; so A, B ≠ ∅. If α_a = 0 then κ_aκ′_a = 1, so a ∈ A ∩ B (same for α′).
(b) Case A has no orthogonal pair. Pick f ∈ A. A ∖ {f} ⊆ Nbar(f), and Nbar(f) contains orthogonal pairs (a frame not containing f has its f-tetrad, 4 pairwise orthogonal lines, inside Nbar(f)), so A ⊉ Nbar(f) and some g ∈ Nbar(f) ∖ A. O_f ∩ A = ∅ (A ⊆ {f} ∪ Nbar(f)). Hence O_f ∪ {g} ⊆ T = V∖A and r(O_f) spans r_f^⊥ (S1), r_g ∉ r_f^⊥: r(T) spans K⁸. On T, κ = 0 and α ≠ 0 (by (a), zeros of α lie in A), so X_T = [diag(α)R_T, 0] has rank 8.
Case A ∋ s, t with s ⊥ t. (If B is not a clique either, S = B is not pairwise odd: then N is a lift only in the per-N / their §4–R3 sense; the κ-family form is unaffected.) Every b ∈ B is non-orthogonal to s and t, so s ∉ B and O_s ∩ B = ∅; T = V∖B ⊇ O_s ∪ {s} spans K⁸, and Y_T = [diag(α′)R_T, 0] (κ′ = 0 off B, α′ ≠ 0 off A∩B ⊆ B) has rank 8.
In both cases N[T,T] = diag(α)G diag(α′)|_T (the rank-1 part vanishes on T × T because κ or κ′ vanishes on T), with α_t α′_t = 1/2 ≠ 0. ∎
**Theorem B2.** Let N be a rank-9 completion whose rows off an A2 triangle S are Gram rows, N[t,:] = d₁_t r_tᵀRᵀD₂ (t ∈ T = V∖S, d₁_t ≠ 0), D₂ possibly singular on S only. (This is the A2 family of #2784/#2819, and also the A2 alternative of Theorem G / G⁻ below.) Then N is a lift on S (X-side) satisfying R2, and in their `a2lib` normal form; ν = 0 exactly when it is concurrent, i.e. a κ-family member.
*Proof.* rank N[T,:] = rank RᵀD₂ = 8 (D₂ singular at most on S, and r(T) spans), so X-side lift on S; N[T,T] = D₁GD₂|_T, and D₂ ≠ 0 on T because N_tt = 2d₁_t d₂_t ≠ 0: R2 holds. Gauge: choose Y's first 8 columns = diag(d₂)R (possible: N[T,:] = (d₁_t r_t, 0)·Yᵀ for all t forces y_b[1..8] = d₂_b r_b since r(T) spans), then X_T = [diag(d₁)R_T, 0]. For s ∈ S, x_s = (a_s, ξ_s); ξ_s ≠ 0 for at least one s (rank 9), and ξ_s = 0 makes row s a Gram row (a_s ⊥ r(O_s) ⇒ a_s ∝ r_s by (S1)), which can be moved to T. Forced zeros on O_s: η_b = −d₂_b c_s·r_b with c_s := a_s/ξ_s; on O_s ∩ O_{s′} (s, s′ ∈ S, spans ⟨r_s, r_{s′}⟩^⊥ by (S2)) this forces c_s − c_{s′} ∈ ⟨r_s, r_{s′}⟩ = P (the A2 plane). Write c_s = c₀ + p_s, p_s ∈ P; the GL₉ shift x ↦ x − ξ(c₀,0) (dual shift on Y) removes c₀; a shift by w ∈ P with p_{s₁} − w ∈ Kr_{s₁}, p_{s₂} − w ∈ Kr_{s₂} exists (P = Kr_{s₁} ⊕ Kr_{s₂}); then c_{s₃} − w = μ₃r_{s₃} + νn. Torus scaling gives d₁ = 1, d₂ = 1/2 on T. This is `a2lib.py`'s normal form (y_s = (β_s r_s, η_s), β_s = d₂_s possibly 0). If ν = 0, all c_s = μ_s r_s are concurrent and N = D₁′GD₂ + ξ̃ η̃ᵀ is κ-family. ∎

## §2 Theorem Z3′: ≤ 3 extra zeros in every row and every column (any total) ⇒ B-form or A2 (PROVEN modulo CHECKED; hand steps audited)

### §2.1 Lemma R′ (Z-rows are exact). PROVEN
Every u ∈ Z ∖ F has α_u(k) ≠ 0 for all k ∈ T(u) (dually every s ∈ Z′ ∖ F has β_s exact), provided every frame row (column) has ≤ 7 extra zeros.
*Proof.* α_u ≢ 0 on T(u): otherwise a_u = (0, x_u) = 0 and M_uu = 0. Let α_u(k) = 0, α_u(c) ≠ 0. The two tetrads T′, T″ ≠ T(u) through {k,c} contain 8 lines s opposite to u at {k,c}; s ⊥ u and x_u = 0 give α_u(c)β_s(c) = 0, so β_s(c) = M_{f_c s} = 0 with s not ⊥ f_c (c ∈ T(s)): 8 extra zeros in row f_c. ∎
### §2.2 Lemma C′ (witness). PROVEN
If β_s(k) = 0 ≠ β_s(c) (k, c ∈ T(s)), then no tetrad T′ ≠ T(s) through {k,c} has a line of Z in its class opposite to s at {k,c}. *Proof.* Such u is ⊥ s, x_u = 0, so α_u(c)β_s(c) = 0, α_u(c) = 0, contradicting R′. ∎ (Dually for rows of D against Z′.)
**Corollary (pure-or-exact).** Let I ⊆ T(s) be an index set such that every pair {k,c} ⊆ I has, among the two tetrads ≠ T(s) through it, one whose lines all lie in Z. Then β_s|_I is either exact (no zero) or identically 0. (Take k ∈ zeros, c ∈ nonzeros inside I.)
