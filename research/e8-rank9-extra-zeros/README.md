# Rank-9 realisations of the E8 pattern with extra zeros (at most 3 per row and column) are B-form or A2: philippeVV's R1 in that regime (no κ claim)

> **Scope, stated first.** Pure matrix classification on the **E8 unit** (120 lines). **No κ claim**, no window, no supplier, no decoder cost. It extends #2819 (*Rank-9 realisations of the E8 pattern are B-form or the A2 family*, ready), which classifies the realisations with the full iff pattern, to realisations that may have **zeros on non-orthogonal pairs ("extra zeros")**, and it compares the result with philippeVV's normal forms and open item R1 (Discussion #1587, follow-ups 7 and 8). **R1 for an arbitrary number of extra zeros is not claimed** (§5).
> Labels: **PROVEN** (argument in this README or in the shipped card text), **CHECKED** (recomputed by `verify.sh`; SAT steps are kissat 4.0.4 UNSAT with a DRAT proof accepted by the standard `drat-trim`), **RECORDED** (a run whose log is shipped and whose headline line `verify.sh` asserts, but which the default `verify.sh` does not repeat), **CONDITIONAL [verify]** (an external fact not checkable here). kissat only, never CaDiCaL.
> **Credit.** The κ-family normal form (expSM Proposition 0), the notion of lift, the A2-triple normal form (`a2lib`), the formulation R1 to R4 and the census of completions are philippeVV's (Discussion #1587 follow-ups 7, 8 and 9; artifact `github.com/philippeVV/integer-mult-bounds` @ 93766d7d, `research/plane-port-decoder-screens/decoder-law/` with `lift-family`, `lift-family-2`, `kfam.py`, `a2lib.py`, `census3.py`; and @ b5ce9d22, `research/complex-budget-law/closures-3/decoder-law-subsets` for Theorem R3). Nothing here runs their code; §2 compares normal forms by proof and by exact members. The classification steps for the iff pattern (Theorems G, P, A, S, Σ, R) are #2819's; #2784 is the A2 family.

## 2. The bridge to philippeVV's R1 / R2

**Dictionary.** Their object (expSG §0): `N = X Yᵀ`, `X, Y ∈ Q^{120×9}`, `N_aa = 1`, `N_ab = 0` for `a ⊥ b`, all other entries free (zero allowed), roots with `r·r = 2`. Ours: `M` as above over `K ⊇ Q`. Put `N = diag(M_tt)⁻¹ M`: left multiplication by an invertible diagonal preserves rank, the forced and extra zeros, B-form (`D₁ ↦ diag(M_tt)⁻¹D₁`, `c ↦ diag(M_tt)⁻¹c`) and the A2 family; conversely every completion is an `M` with `M_tt = 1`. So everything below is stated for `N`.

**Lift (as we use it).** `N` is a lift on `S` (X-side) if `rank N[T,:] = 8` for `T = V ∖ S` (Y-side: `rank N[:,T] = 8`) (expSM §0, `census3.py`). Their closed results additionally assume **R2** and then have the normal forms: the **κ-family** (Prop. 0): `X = [diag(α) R, κ]`, `Y = [diag(α′) R, κ′]`, `supp κ = A`, `supp κ′ = B`, no `a ∈ A`, `b ∈ B` with `a ⊥ b`, `2α_aα′_a + κ_aκ′_a = 1`; and the **A2-triple lift** (`a2lib`: `x_t = (r_t, 0)` on `T`, `x_{s_i} = ξ_i (c_i, 1)`, `c_i = μ_i r_{s_i}` for `i = 1, 2`, `c_3 = μ₃ r_{s₃} + ν n`, `ν ≠ 0` non-concurrent, `ν = 0` concurrent = κ-family). The bare rank condition is satisfied by *every* rank-9 `N` for a suitable `S` (take 8 independent rows of `N`, let `T` be the set of all rows lying in their span, `S = V ∖ T`), so the meaningful form of R1, and the one their floor proofs consume, is **R1 + R2: `N` (up to transpose) is a κ-family member or an A2-triple lift with `N[T,T]` a root realisation.** That is the form proved here.

**Theorem B1 (B-form is κ-family; PROVEN).** Let `N = D₁GD₂ + cβᵀ` be a rank-9 B-form completion (`N_aa = 1`). Put `A = supp c`, `B = supp β`, `α = diag D₁`, `α′ = diag D₂`, `κ = c`, `κ′ = β`.
(a) `N = [diag(α)R, κ][diag(α′)R, κ′]ᵀ` is a κ-family member with these `A, B`; `A, B ≠ ∅`; `α_a = 0` or `α′_a = 0` only for `a ∈ A ∩ B`.
(b) `N` is a lift with R2 automatic: if `A` has no orthogonal pair, on `S = A` (X-side); otherwise on `S = B` (Y-side). In both cases `N[T,T] = diag(α) G diag(α′)|_T` with `α, α′ ≠ 0` on `T`.
*Proof.* (a) `(D₁GD₂)_{ab} = α_a (r_a·r_b) α′_b`, so `N_ab = x_a·y_b` for the displayed rows; "`c_uβ_s = 0` for `u ⊥ s`" is literally "no `a ∈ A`, `b ∈ B` with `a ⊥ b`"; `N_aa = 2α_aα′_a + κ_aκ′_a = 1` is their diagonal identity; if `cβᵀ = 0` then `rank N ≤ 8`, so `A, B ≠ ∅`; `α_a = 0` forces `κ_aκ′_a = 1`, so `a ∈ A ∩ B` (same for `α′`). (b) *`A` without orthogonal pair.* Pick `f ∈ A`; `A ∖ {f} ⊆ N̄(f)` and `N̄(f)` contains orthogonal pairs (the `f`-tetrad of a frame not containing `f`), so some `g ∈ N̄(f) ∖ A`; `O_f ∩ A = ∅`; `r(O_f)` spans `r_f^⊥` (S1) and `r_g ∉ r_f^⊥`, so `r(T)` spans `K⁸`; on `T`, `κ = 0` and `α ≠ 0` (zeros of `α` lie in `A`), so `X_T = [diag(α)R_T, 0]` has rank 8. *`A ∋ s, t` with `s ⊥ t`.* Every `b ∈ B` is non-orthogonal to `s` and `t`, so `s ∉ B`, `O_s ∩ B = ∅`, `T = V ∖ B ⊇ O_s ∪ {s}` spans `K⁸`, and `Y_T = [diag(α′)R_T, 0]` has rank 8. On `T` the rank-1 part vanishes on `T × T`, and `α_tα′_t = 1/2 ≠ 0`. ∎

**Theorem B2 (A2 family is the `a2lib` normal form; PROVEN).** Let `N` be a rank-9 completion whose rows off an A2 triangle `S` are Gram rows `N[t,:] = d₁_t r_tᵀRᵀD₂` (`d₁_t ≠ 0`; `D₂` singular on `S` at most). Then `N` is an X-side lift on `S` satisfying R2 and is in `a2lib`'s normal form; `ν = 0` exactly when it is concurrent, i.e. a κ-family member.
*Proof.* `rank N[T,:] = rank RᵀD₂ = 8` (`r(T)` spans; `D₂` singular on `S` only); `N[T,T] = D₁GD₂|_T` and `d₂_t ≠ 0` on `T` because `N_tt ≠ 0`: R2. Gauge: `N[T,:] = (d₁_t r_t, 0)·Yᵀ` forces `y_b[1..8] = d₂_b r_b`. For `s ∈ S`, `x_s = (a_s, ξ_s)`; `ξ_s = 0` would make row `s` a Gram row (`a_s ⊥ r(O_s)`, so `a_s ∝ r_s` by (S1)), movable to `T`, so some `ξ_s ≠ 0`. The forced zeros on `O_s` give `η_b = −d₂_b c_s·r_b` with `c_s = a_s/ξ_s`; on `O_s ∩ O_{s′}` (spans `⟨r_s, r_{s′}⟩^⊥` by (S2)) this forces `c_s − c_{s′} ∈ P = ⟨r_s, r_{s′}⟩` (the A2 plane). Write `c_s = c₀ + p_s`, remove `c₀` by the GL₉ shift, then a shift by `w ∈ P` (`P = K r_{s₁} ⊕ K r_{s₂}`) gives `c_{s₁}, c_{s₂}` proportional to their roots and `c_{s₃} = μ₃r_{s₃} + νn`. Torus scaling gives `d₁ = 1`, `d₂ = 1/2` on `T`: `a2lib`'s form. If `ν = 0` all `c_s = μ_s r_s` and `N = D₁′GD₂ + ξ̃η̃ᵀ` is κ-family. ∎

**Converse (PROVEN).** κ-family members are B-form by (a) read backwards; `a2lib` members have Gram rows off `S`, so by Theorem G^K (§3.2) they are B-form or in our A2 family. Hence {B-form} = {κ-family} (after `N_aa = 1`) and {A2 family} ∪ {B-form with `supp c ⊆` triangle} = {A2-triple lifts with Gram `T`-rows}: the two vocabularies name the same objects. **CHECKED** (`bridge.py`, exact `Fraction`s and mod-`p` ranks): 12 members, each with forced zeros, `N_aa = 1`, rank 9, rank 8 off the `S` chosen by B1(b), and `N[T,T] = d_t d′_s G_ts` on all of `T × T` (entrywise, by exact propagation of `d, d′` from one entry, then every entry compared): `A = {f}`, `B = C(f)`; `A = C(f)` (57 lines), `B = {f}`, `α_f = 0`; cliques `|A| = 3, 5, 7` with `B = C(A)` and `α = 0` at two lines of `A ∩ B`; two pairs with **`A` and `B` both dependent and non-clique** (`|A| = 5`, `|B| = 8` and 6); `A = B` an A2 triangle with `α = 0` at a vertex; four A2 members (triangles 0, 17, 400, 1119).

**Relation to their definition of lift (follow-up 7), stated precisely.**
* *Shape.* As we read follow-up 7 (wording ours), a lift agrees with a torus orbit of `G/2` except on odd pairs touching a pairwise-odd `S`. For a B-form realisation, `N − D₁GD₂ = cβᵀ` is supported on `A × B`, and every pair in `A × B` is non-orthogonal ("odd"): so when `A` (resp. `B`) is a clique, `N` has exactly that shape with `S = A` (resp. `B`), and `N[T,T] = D₁GD₂|_T` is the orbit on `T × T` (B1(b)).
* *Non-vacuous.* Under this shape (and not under the bare rank-8 reading, which every rank-9 completion satisfies, see above), R1 is a substantive statement, and the form we prove (κ-family or A2-triple lift, with R2) is the one their Theorem 1 and floor arguments take as input.
* *R2.* Theirs is universal rigidity on `T` (every rank-8 completion on `T` is a root realisation); the form used by the Lift Lemma, and proved for each member above, is per `N`: `N[T,T]` is a root realisation. Universal R2 for `T = E8 ∖ C`, `C` a clique (including `C = ∅` by monotonicity; with the iff pattern, rank-8 rigidity on E8 is #1212), is Theorem RK (§4).
* *Both `A` and `B` with orthogonal pairs.* Then `S = B` (or `A`) is a lift in the rank sense of B1(b) and in the sense of their §4 and follow-up 9's Theorem R3 (dependent or non-clique `S`), not in the pairwise-odd sense; the κ-family form is unaffected. Such pairs exist (two exact members in `bridge.py`).
* *R3.* Theirs (follow-up 9, Theorem R3; artifact `closures-3/decoder-law-subsets` @ b5ce9d22): lifts on dependent or non-clique supports of at most 26 lines (and all dependent 4-set orbits) are κ-family members; they leave open the residue with at least 10 bad lines. Ours is a separate, normal-form statement for Gram `T`-rows only: if the rows off `S` are Gram rows (R2 plus `rank N[T,:] = 8` with `r(T ∩ O_b)` spanning `r_b^⊥` for every `b`), then `N` is B-form with `supp c ⊆ S` (κ-family, concurrent) or an A2-triple lift (Theorems G^K, B2); non-concurrency occurs only on A2 triangles. No cost claim, and nothing here extends or replaces their R3 range.

## 3. Theorem Z3′ and the earlier results

Notation as #2819 (BSTAR §2 in `evidence/`): a frame `F` (8 pairwise orthogonal lines), pivot coordinates `α_u(i) = M_{u f_i}/M_{f_i f_i}`, `β_s(i) = M_{f_i s}`, `x`, `y` the exact rank-1 Schur remainder, `D = supp x`, `D′ = supp y`, `Z = L ∖ D`, `T(u)` the `F`-tetrad of `u`; `M_us = Σ_{i ∈ T(u) ∩ T(s)} α_u(i)β_s(i) + x_u y_s`. `Σ_a = {u : dim span a(O_u) = 7}`, `Σ_b` likewise. Full texts: `evidence/R1_THEORY_snapshot.md` §2, `evidence/ZPIN2_THEORY_snapshot.md`, `evidence/ZPIN3_THEORY_snapshot.md`, `evidence/ZPIN_THEORY_snapshot.md` (rule proofs of the SAT model); #2819's BSTAR / CONJB / KSTAR snapshots for the iff-pattern calculus.

### 3.1 Why zeros enter only through the budget
In every step of Theorems P, A, Σ, S an entry `M_us` of a non-orthogonal pair is used (1) as a pivot coordinate (`α_u(i) = 0 ⇔ (u,f_i) ∈ Ξ`), (2) in the step `Π(+) ≠ Π(−)`, and (3) by the SAT model's rule NON (only in the residue step). Everything else uses forced zeros only. The s56 CNF contains only orthogonality incidences, so it is a sound abstraction for arbitrary `Ξ` once rows and columns are points and lines of `P²` (§3.2, S(b)).

### 3.2 Proof of Z3′ (budget: ≤ 3 extra zeros per row and column)
* **Lemma R′ (Z-rows exact).** If every frame row and column has ≤ 7 extra zeros, every `u ∈ Z ∖ F` has `α_u(k) ≠ 0` for all `k ∈ T(u)` (dually columns of `Z′`). *Proof.* `α_u ≢ 0` (else `a_u = (0, x_u) = 0`). If `α_u(k) = 0 ≠ α_u(c)`, the 8 lines `s` in the two tetrads `≠ T(u)` through `{k,c}` opposite to `u` at `{k,c}` are `⊥ u`, so `α_u(c)β_s(c) = 0`, i.e. `M_{f_c s} = 0` for 8 non-orthogonal pairs in row `f_c`. ∎ **Lemma C′ (witness).** If `β_s(k) = 0 ≠ β_s(c)`, no tetrad `T′ ≠ T(s)` through `{k,c}` has a line of `Z` in its class opposite to `s` (else `α_u(c) = 0`, contradicting R′). **Corollary (pure or exact):** on an index set `I ⊆ T(s)` in which every pair has one of its two other tetrads lying in `Z`, `β_s|_I` is exact or identically 0.
* **P(b), A(b) (any frame).** Budget ≤ 3 per column excludes pure off-frame columns (`β_s ≡ 0` on `T(s)` would be 4 extra zeros). Suppose a column `s` had a zero set `Z_s ≠ ∅` and a nonzero set `N_s ≠ ∅` in `T(s)` (`|Z_s| + |N_s| = 4`). By Lemma C′ each pair `{k,c}`, `k ∈ Z_s`, `c ∈ N_s`, is unpinned for the sign opposite to `s`, so `Z_s × N_s ⊆ 𝒰` has ≥ 3 pairs, two of which share a vertex; but `𝒰` is a matching in the Theorem P setting (A(b): `𝒰 ⊆ {{1,2}}`; Σ(b): below). So all columns are exact. `Π(+) ≠ Π(−)` holds by budget (otherwise a `+`-row would have 8 > 7 zeros). BSTAR §3 (i) to (iv) then run verbatim (all E8 frames are P-compatible: `pframes.py`); `D₂` is invertible; Theorem G gives B-form (`supp c ⊆ D`) or A2. For A(b) (`f₁ ⊥ f₂ ∈ Σ_a`, a frame through both): forced zeros give `D ⊆ Λ₁₂`, an unpinned pair needs two tetrads whose class lies in `D`, only `{1,2}` qualifies, P(b) applies; the transposed case is symmetric.
* **G^K (Theorem G with `D₂` singular on a set `K` inside a clique).** Holds provided (S1−K): `r(O_u ∖ K)` spans `r_u^⊥` for all `u`, and (S2−K): `r(O_u ∩ O_{u′} ∖ K)` spans `⟨r_u, r_{u′}⟩^⊥` for all `u ≠ u′`. *Proof.* As Theorem G⁻: `RᵀD₂` keeps rank 8; for `x_u = 0`, `w_u ⊥ r(O_u ∖ K)` gives `w_u ∝ r_u`; for `u ∈ X′`, `z_s = −d₂_s g_u·r_s` on `O_u` (so `z_s = 0` on `O_u ∩ K`); the cocycle on `O_u ∩ O_{u′} ∖ K` uses (S2−K); `M_ss ≠ 0` with `d₂_s = 0` forces `s ∈ supp x ∩ supp z′`. In the A2 alternative the rows off the triangle are Gram rows with `d₂_s = 0 ⇒ M_ss = 0` unless `s` is on the triangle, so `K ⊆` triangle. ∎ It suffices to check maximal cliques. **CHECKED** (`cliquespans.py`, exact ranks mod `2⁶¹ − 1`): Bron–Kerbosch gives 44 320 maximal cliques = 1120 A2 triangles + 34 560 seven-cliques (rank 7) + 8640 eight-cliques (rank 8); the reflection BFS shows each size is one `W(E8)`-orbit; on one representative per orbit (S1−K) and (S2−K) hold (0 failures). `spansminus.py` (single-line version, G⁻): (S1⁻) 0/7560, (S2⁻) 0/241 500, (C-A) 0/3136 failures.
* **Σ(b), S(b) (`f₁ ∈ Σ_a`; frame through `f₁`).** *Σ(b).* Pairs `p ⊆ {2..8}` have two tetrads avoiding index 1, both in `Z` by (Σ1), exact by R′; by the Corollary the columns are exact or 0 off index 1, and columns of `O_{f₁}` are exact (a pure one would give `M_ss = x_sy_s = 0`). `Π_p(+) ≠ Π_p(−)` by budget (4 > 3 zeros in a row); the pinning across the third tetrad `T_c` uses that not all four of its `(−ε)`-columns can vanish on `p` (frame row `f_j` would have 4 extra zeros); the gauge: the seven tetrads through 1 give a Fano plane on `{2..8}`, a triple lies in a tetrad avoiding 1 iff it is not a Fano line, so `ρ_ab(+) = μ_b/μ_a` on all pairs; hence `β_s|_{T(s)∖1} = κ′_s D_μσ^s`. (iii)–(iv) use only columns of `O_{f₁}` and forced zeros ((S2), (S3′), (W2), `spans3.py`). Case 1 `f₁ ∈ Σ_b` is S(b); Case 2 gives `s ∈ O_{f₁} ∩ Σ_a`, and A(b) applies to `f₁ ⊥ s`. *S(b).* Both sides Gram-shaped off index 1; `P̂_u = (α_u(1), x_u, κ_u)`, `Q̂_s = (β_s(1), y_s, −κ′_s)` satisfy `M_us = P̂_u·Q̂_s + κ_uκ′_s g_us` on `N̄(f₁)`, so `P̂_u·Q̂_s = 0` for `u ⊥ s`: points and lines of `P²`, and the s56 CNF (UNSAT, drat-trim VERIFIED) yields a point class `A₀` meeting every `Γ(s)` (or the dual line class). `A₀` is not at infinity: otherwise `κ_u = 0` on `A₀` and `M_uu = P̂_u·Q̂_u = 0`. So rows of `A₀` are Gram rows; the singular set `K = {s ∈ N̄(f₁) : κ′_s = 0} ∪ ({f₁} if p₀ = 0)` has all its columns proportional to one vector `b* ≠ 0`, hence pairwise non-orthogonal (`M_ss ≠ 0`): **K is a clique**, and G^K applies. The dual class `B₀` is the transpose.
* **Residue (`Σ_a = Σ_b = ∅` is impossible).** The scope-z model with rules RES, NG, RANK, ZRIG, ZA2 and NOPURE is UNSAT (`np_z`: 74 368 variables, 3 697 927 clauses; kissat UNSAT; drat-trim VERIFIED). Reduction: if `Ξ = ∅` this is #2819's Theorem R; otherwise take `(t,s) ∈ Ξ` and a frame `F ∋ s`; by `W(E8)`-transitivity on (frame, frame line, off-frame line) we may take the scope's data; a pure row or column needs 4 extra zeros in its line, so NOPURE holds; every other clause is a necessary condition for arbitrary `Ξ` (one-line proofs in `evidence/ZPIN_THEORY_snapshot.md`; rule ZA2 uses Lemma RA2: `E8 ∖ (A2 triangle)` has rank-8 rigidity with arbitrary zeros, `rigA2.py` and `evidence/ZPIN2_THEORY_snapshot.md` §4.1). So the exact Boolean data of such an `M` would satisfy the CNF: contradiction.
* **Assembly.** `Σ_a ∪ Σ_b ≠ ∅` gives B-form or A2 by Σ(b) / S(b) / A(b) and G^K; the residue is empty. By the bridge (§2) `M` is a κ-family member or an A2-triple lift with R2 per `N`. ∎

## 4. Theorem RK: rank-8 rigidity with arbitrary extra zeros on `E8 ∖ C`

**Statement.** `C` a clique (pairwise non-orthogonal lines; contained in an A2 triangle, a 7-clique or an 8-clique), `L′ = E8 ∖ C`. If `N ∈ K^{L′×L′}` (char 0) has rank ≤ 8, `N_tt ≠ 0`, `N_ts = 0` for `t ⊥ s`, other entries free, then `N` has **no extra zero** and `N = D₁GD₂` with `D₁, D₂` invertible.

## 5. What this gives for R1, and what remains

* **Proved:** R1 + R2 (§2) for rank-9 completions over `Q` (indeed any field of characteristic 0) whose every row and every column has at most 3 zeros on non-orthogonal pairs, with no bound on the total; for all zeros in one row or one column (Z1); for `|Ξ| ≤ 3` (Z3); for no extra zeros (#2819). Universal R2 on `E8 ∖ C` for every clique `C`, with arbitrary zeros (RK).
* **Not claimed: R1 for an arbitrary number of extra zeros.** Exactly where the argument stops: the budget is used in three places only: Lemma R′ (a frame row or column with ≥ 8 extra zeros), the step `Π(+) ≠ Π(−)` (a `Z`-row with ≥ 4, in P(b) ≥ 8, extra zeros), and "no pure off-frame column" in P(b). Points at infinity in S(b), singular `D₂`, and the clique `K` need no budget. The residue step (Theorem R) is CHECKED only for ≤ 3 extra zeros per row and column (`np_z`). The first uncovered configuration is a **pure line**: **Lemma PL (PROVEN, no budget).** For any frame `F`, the off-frame rows with `α_u ≡ 0` on `T(u)` satisfy `M[u,:] = x_u yᵀ` (from `M = M[:,F]M[F,F]⁻¹M[F,:] + xyᵀ`); they are pairwise proportional with `M_uu ≠ 0`, hence pairwise non-orthogonal, a clique `P_F` with `supp y ⊆ ⋂_{u ∈ P_F} ({u} ∪ N̄(u))`; dually pure columns form a clique with `M[:,s] = y_s x`. A pure row has ≥ 4 extra zeros, so it is excluded by the per-row budget and untouched by Z3′.
