# Uniform sequential-arena Beneš compiler and queried bit

This is a component audit of Cinna Davis's PR4100 `CRT.md:94–116` and
retained `check_batched_crt.py:12–50`. The original compiler, cycle
coloring and proposed full-scan simulation are predecessor work. This
note supplies a uniform encoded schedule, explicit arena traffic and
owned-output cleanup. It does not supply the complete CRT evaluator.

## 1. Exact component interface

Inputs use canonical self-delimiting binary encodings of positive integers
`h,p` (for example Elias gamma), of total O(log(p+2)) bits, with
`1<=h<=p`, and a **complete** permutation of `N=2^h` wires, as N
consecutive h-bit words on a protected sequential input tape. The
source tape is preserved. The program rejects repeated or out-of-range
entries; it does not call an uncharged sorting routine.

The owned output contains `(2h-1)N` Boolean table entries in layer-major,
then wire-major order. The known layer schedule is

```
0,1,...,h-1,h-2,...,0.
```

A second interface takes that protected encoded network and `layer,address`
in fixed fields of widths `max(1,ceil(log2(2h-1)))` and h, respectively,
scans the whole network, and returns one owned bit. There are no arbitrary
leading-zero header strings or unbounded encodings within this input domain.
The finite simulator receives the decoded header integers; canonical header
decoding is part of the written uniform lowering, not executed microcode.
On successful calls all input/output heads return to their left markers. All private arena,
key and bounded-register workspace is cleared and returned. Uniform
parameters are read as data; no size-specific code, advice table or
random-access oracle is supplied.

The alphabet is fixed: bit zero, bit one, blank and boundary markers.
The number of sequential tapes is fixed. A constant number of binary
registers and arithmetic scratch regions may occupy a fixed tape bank;
their widths are data, not new tapes or control states.
The owned output and owned queried-bit tape are fixed **roles**, reused
after their consumer transfers/clears the previous result. Python Tape
objects in the fixture model configurations, not newly allocated physical
tapes. A caller retaining many answers must serialize them to a fixed
output region and pay its additional copy/head movements.

## 2. Flattened recursion and explicit stack

Use binary-heap node IDs: root 1 and children `2v,2v+1`. Nodes at depth
`a=0,...,h-1` have size `m=N/2^a` and height `s=h-a`. Leaves have m=2.
For each node preallocate arrays P, INV and COLOR of m words and OUT
with `(2s-1)m` Boolean entries. Preallocate one shared N-entry DFS stack.
Every entry is a fixed-width record

```
(node,kind,layer,index,value), each field w=4p+8 bits.
```

Record kinds form a fixed finite set. No dictionary, object pointer,
host-index lookup or tape per node is part of this program. The record
layout is generated by fixed nested counter loops over depth, node,
kind, layer and index. There are exactly

```
J = N(h²+3h+1) records,
B = 5wJ arena cells.                                     (1)
```

Indeed the all-node Boolean tables contribute `Nh²` entries, since
`sum_(s=1)^h (2s-1)=h²`; the three other arrays contribute `3Nh`
and the shared stack contributes N. All widths are explicit, including
unused padding in the Boolean values.

Every logical get or put constructs its four-field key on **one reused
key tape**. It scans all J records from the left marker, compares all
four key words, reads or replaces the matching value, continues to the
end and returns the arena head. It returns the key head after each
comparison, then clears and returns that scratch tape. There is one
matching record. It may skip an unmatched value by w consecutive
right moves; this is not a jump to an addressed record.

Copy the incoming permutation to root P. Process nodes in increasing
depth, using only bounded loop counters:

1. Validate each node's P by range checks and pairwise distinctness.
2. For m=2, write its one identical-bit switch table and continue.
3. Otherwise build INV; then visit initial wires in increasing order.
   For an uncolored wire assign color zero and push it on the shared
   encoded stack. Pop in LIFO order and inspect neighbors, in this
   order, `x XOR 1`, `INV[P[x] XOR 1]`. Mark a newly discovered vertex
   before pushing it. Clear each popped stack entry immediately.
4. Write first/last tables and both child permutations, exactly as in
   the retained compiler.

No Python recursion stack is used by `compile_stream`. The graph DFS
stack is the explicit arena array; its top is a bounded register.
Each vertex is pushed and popped once, so capacity N suffices.
At the end of each node the stack is empty and its slots are cleared.

Then process depths in decreasing order. Interleave each pair of
child tables using child `x mod 2` and child wire `floor(x/2)`;
write parent layers shifted up by one. Finally copy the entire root
table into the owned output using charged arena gets and sequential
output writes. Only **after** serialization erase the whole private
arena and return its head. There is no returned host list that silently
owns an uncharged network copy.

## 3. Source equivalence and endpoint

The two input-neighbor relations are perfect matchings. Their union
is a disjoint union of alternating even cycles, allowing parallel
matching edges. Opposite colors exist. Mark-before-push means each
vertex enters the stack once. The traversal order within a node is
the same as the source, so component orientation and every resulting
color agree exactly, not just up to an equivalent network.

Every input pair and every output pair has one member of each color.
For each color c, `floor(x/2) -> floor(P[x]/2)` is therefore a
permutation on m/2 wires. This proves child validation and permits
induction. Distinct child calls share no state: replacing source DFS
recursion by top-down construction and bottom-up assembly preserves
the returned tables byte for byte. The first/last tables and child
selector use precisely the source formulas.

Induction gives the desired permutation endpoint. First and last
tables are equal on the two wires of their target pair because
matching colors differ. An interior table inherits target independence
from its child: flipping its higher target bit preserves the selected
child parity. Thus each returned queried bit is independent of its
own active target bit. This is a theorem about the component; it
does not establish the full CRT caller's simultaneous target omission.

## 4. Traffic, scalar lowering and quantified bound

There are three separate statements: the **executed arena/key cell
invoice**, the **written bounded-scalar lowering**, and the resulting
**uniform asymptotic bit bound**. The Python simulator is not a
complete finite-state transition-table certificate.

For a logical arena access, the arena/key tapes execute exactly

```
26wJ + 25w read/write/one-cell-head actions.              (2)
```

Arena key reads cost `8wJ`; unmatched value skips plus the matching
read/write cost `wJ+w`; arena return costs `5wJ`. Key comparisons
read/return `12wJ`, and constructing/clearing/returning its key costs
24w. Sum these terms to obtain (2). Initialization and final arena
erasure/returns add `6B`. The modeled protected input read/return costs `3Nh`;
this excludes the host pre-admission length/bit-format checks. Their sequential
implementation is separately charged in the written scalar lowering below.
Owned network writing/return costs `3(2h-1)N`. Each complete query scan,
return and one-bit owned output costs exactly `3(2h-1)N+3` tape actions.
These exact numbers exclude scalar instruction work, not its cost.

The finite simulator batches a contiguous block read/write/move by
charging the corresponding number of repeated one-cell operations.
Such methods advance from the current head only. An expanded one-cell
execution is checked against the batched version on the same case.
They have identical tape contents, heads and traffic. Byte slices used
to batch those moves are not indexed logical-array access instructions.

To lower the remaining control, use a fixed bank of O(1) w-bit
registers with binary counters. Every integer comparison, copy,
increment, halving, parity/XOR, add, or schoolbook product used here
has a fixed sequential implementation in O(w²) time and O(w²) scratch,
including local head returns. Key equality is a streaming equality
flag, not an uncharged comparison of host strings. Input bit-format
checks, record construction, all loop/index/key generation and query
selection counters are charged by the same conservative envelope.
The Python integer mirrors are observations of this bounded control;
they are not treated as unit-cost machine arithmetic.
The bank explicitly includes candidate and supplied four-word key
buffers, the decoded value, parameters, node/depth/layer/index/top
counters and a fixed number of temporary arithmetic words. These
are O(1) fixed-width roles, not host lists growing with N. Reading
encoded parameters and clearing/returning every such private role
are included in the envelope.

The width also covers full arena offsets, rather than only wire IDs:

```
B <= 20 * 2^p * (p+2)^3
  <= 160 * 2^(4p) < 2^(4p+8) = 2^w.                     (3)
```

Here `p+2<=2^(p+1)` for p>=1. All node IDs, values, sentinels,
depth/layer indices, DFS tops and record/cell loop counters fit in w
bits. Observer-only accumulated receipt counters need not be runtime
registers. A product may use two w-bit registers while being reduced
to a known in-range result. No growing collection of scalar registers
is hidden in the bound.

Let A be the number of logical arena accesses. Across depths, total
node-size is Nh. Pairwise validation uses `N²-N-Nh/2` comparisons;
initial reads add Nh. At a nonleaf node with m wires and c components,
coloring uses m initial tests, 2c component-start accesses, 2m stack
pop/clear accesses, 6m edge accesses and `2(m-c)` discovery writes:
exactly 11m. Inverse and first/last/child construction add 2m and 7m,
giving exactly 20m nonleaf accesses. Bottom-up assembly uses
`2N(h-1)²` accesses. Root loading/serialization add `N+(2h-1)N`;
leaves add `3N/2`. Thus the exact valid-input census and a convenient
conservative bound are

```
A = N² + 2Nh² + (37Nh-35N)/2,
A <= N² + 2Nh² + 24Nh + 3N = O(N²(p+2)²).              (4)
```

The displayed bound is conservative; it is derived from the loops,
not fitted to finite receipts. Loop control outside scans has
O(A+J) iterations. Scan/key comparison control has O(B) elementary
cell/word iterations per access. Charging each bounded scalar
instruction by O(w²), including its register access, gives

```
T_compile = O((A+J+1) B (p+2)²)
          = O(N³ (p+2)^7),                              (5)
visited space = O(B+(p+2)²+Nh) = O(N(p+2)^3).            (6)
```

Owned output and protected input are included in visited space.
The fixed inventory is the arena, reused key tape, input, owned
output, and a fixed scalar-work bank. The queried-bit interface uses
the protected output, one new owned bit, and that same fixed bank;
its time O(N(p+2)^3) is absorbed by (5). Register-work erasure/returns
are included in the scalar envelope. All parameters have one uniform
encoded implementation, independent of input size.

For the source family `1<=h<=ell<=p`, (5) is bounded by
`O(2^(3ell)(p+2)^7)`, hence by the stated `O(2^(4ell)(p+2)^16)` E
allowance after a fixed constant. Even O(p) such component invocations
fit that allowance. This comparison does **not** certify all the
other work charged to E: CRT reconstruction/modular inversion,
transported descriptors, macro inverse keys, parameter generation
and the complete evaluator remain separate obligations.

## 5. Corroboration and remaining boundary

`verify.py` checks exact retained source bytes before calling its
reference compiler. Its executed arena traffic covers every get/put,
all DFS data, table serialization, erasure and head returns. Scalar
microcode is justified by the written construction above; its complete
literal transition table is not emitted or executed. No native or
full outer replay is represented by these tests.

Finite cases include all permutations on two/four wires, modular
rotations and other eight/sixteen-wire permutations. Every output
table is compared exactly to the retained source, every query and
its target independence is checked, and every wire endpoint is
checked. Mutation/admission controls cover malformed encodings,
duplicate permutations, an incorrect matching edge, and missing
arena/query head returns. All checks remain active under Python -O.

The result is a scoped constructive component proof plus independently
replayable corroboration. It is not a complete CRT evaluator, physical
ordinary interchange, native/precision closure, multiplication theorem
or selected-frontier change.
