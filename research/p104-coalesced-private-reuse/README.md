## Reproduce and inspect

From the repository root, Python 3.12 and the standard library:

```sh
python3.12 scripts/research_package.py --package research/p104-coalesced-private-reuse
# Direct replay also works without Git:
python3.12 -I -O -B research/p104-coalesced-private-reuse/verify.py
```

The registered command recomputes and compares [RESULT.json](RESULT.json).
It writes only temporary files; `--write-result` explicitly regenerates the
receipt. It checks all literal transports with the retained exact native
compiler and independent Gaussian interpreter, including signed Pauli action,
global phase, 208 intrinsic endpoint adapters and 4096 private-path basis
columns. Ten additional controls reject a missing contact, wrong coefficient,
retained dirty compensation, ascending private step, stale source event map,
omitted public/private charges, retired helper with stale owner widths, wrong
owner binding and changed predecessor bytes. The native checker also rejects
a corrupted global phase. This is exact finite verification, not a proof
assistant verification or independent human review.

The complete registered replay passed on CPython 3.12.3 with assertions
disabled. CPython 3.14.4 also reproduced the receipt from a Git-free, read-only
export of ten package files and thirteen declared inputs; a write probe was
rejected and all 23 exported file hashes remained unchanged.
