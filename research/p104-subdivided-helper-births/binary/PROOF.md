## One birth

Work in the transposed native network, with complete binary transfer $M$. Let an existing productive owner $h$ start in chart $A$ and return in chart $B$. Subdivide one paid move $a\to b$ into $a\to c\to b$ at an intermediate chart $c$. The second leg initially copies the first arrival. The chart sequences $a,c,b$ and $A,c,B$ must each be strictly nested rational frames, in either orientation. Subdivision preserves the original scalar transfer and provides a new local arrival and sender on chart $c$.

Let $x$ contain the old arbitrary public inputs. At $c$, the replay finds readout and calibration forms with measured rows $q$ and $k$ on $x$. The input direction $d$ and $q$ use only owners on $A$. An XOR into a specified subset of the paid sends on $c$ produces the measured terminal response $v=M d$, supported on $B$. The output covector $kM^{-1}$ is also supported on $B$. Require $v_h=1$, $q d=1$ and $k d=1$. The readout and calibration have zero response to the injection. The replay checks these two zeros for every recorded edit before scheduling the new graph.

Take $x^0=x+e_h x_h$ and feed the old graph

$$
U(x)=x^0+d(x_h+q x^0).
$$

Then $qU(x)=x_h$, so the local readout at $c$ returns the old owner's value. With a fresh independent input $w$ on $c$, inject $w+kU(x)$. The old terminals become

$$
Y=M x^0+v(x_h+q x^0+w+kU(x)).
$$

The $h$ coordinate of $M x^0$ is zero because $h$ was an independent helper. Adding $Y_h$ to the other affected returns on $B$ leaves $(M x^0)_i=(M x)_i$ for every $i\ne h$. The fresh return on $B$ is $(kM^{-1})Y=w$ because $kd=1$. This preserves all other helper inputs and the main transfer, and gives both independent daughter returns on arbitrary fields.
