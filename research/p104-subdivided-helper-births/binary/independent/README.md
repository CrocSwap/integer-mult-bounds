# Independent binary replay

Run from the package directory with Python 3.11 or later. Give `--source-root` the sparse `source` tree prepared by `prepare_sources.py` for PR #7776 at `4f7c67ae387cc91580f469aeda4d508b372b9ec1`.

```sh
python3 -B binary/independent/verify.py \
  --source-root /path/to/pinned-sources/source \
  --word binary/WORD.json.gz \
  --out independent-binary.json
```

The command writes one receipt with `native` and `finite` sections, and finishes with `PASS_INDEPENDENT_BINARY_BIRTHS_AND_FINITE_ORDINARY`. The source tree needs the selected claim, paired caller, selected native tape, and original #7776 binary and complex result files listed in the package source lock. The command authenticates these inputs, the published birth recipe, and both compressed and decompressed bytes of the checked-in word.

The literal verifier rebuilds the #7776 route inventory from its selected native tape and eight published deletions. It checks each of the 21 archived source clocks, nested daughter ranks and productive boundary changes against the literal word. A separate interpreter replays the word and its adjoint, checking every chart tag and private lifetime. Its held-out controls omit one XOR into a paid bank from helper 671 and omit a dirty CLEAR. A packed polynomial interpreter verifies the paired caller in each direction. The 36-call paid and target histograms and the ordinary allowances are derived from those operations.

The pricing verifier uses outward-rounded rational Taylor bounds for the two public #7776 crossings, the new signed crossing and the finite product. It then checks the finite separation, uniform carrier threshold and exact bootstrap inequalities. The package's two ordinary stages reach `0.00386969950` under the retained assumptions. The receipt also gives the optional third stage to `0.00386969970`. Joint multiplication requires the compatible complex supplier and outer application.
