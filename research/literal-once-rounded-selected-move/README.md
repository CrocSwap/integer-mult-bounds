# A literal once-rounded selected native MOVE

**One source-specific physical mechanism; no new kappa.** A fixed
84,935-location, 54-tape program executes actual selected #7000 MOVE24472
`["MOVE",415,3,99,false]` on arbitrary original signed-w Gaussian payloads,
including the most-negative input, then rounds once per completed output
component by nearest-UP `floor(t+1/2)`. The full right phase/G/offset,
positive all-f C tensor and left phase/G are the immutable source-bound
literal core. Absolute i^f and all 9f native address bits are retained.

The program physically generates `k=ceil(f/2)` and `W=w+2k+1`, builds a
private canonical header, sign-extends and scales input components, executes
the complete core, reads every discarded bit, and rounds by adding the
highest discarded bit to the entire high prefix. Signed fit is checked
**after** that increment. Thus -2.5 rounds to representable -2 at w=2;
pre-round fit would wrongly reject it. Negative half ties go toward positive
infinity, and all-one -1->0 carry wrap is valid.

Only true final signed-w overflow is a numerical rejection on the valid
packed/cutoff entry. The whole output is staged before the sole original
public owner commit. Finite overflow preserves public DATA and HEADER even
after earlier outputs were staged. Success restores all 54 heads, private
bodies/guards and opaque exteriors. Failure retirement/retry is unclaimed.

Entry is the supplied complete `[P] x [2^f]^9 x [S]` array, with r Gaussian
coefficients per address, MSB signed real/imaginary components, six Gamma
codes f,r,P,S,w,cutoff, w>=2 and f<=cutoff. Here r is coefficient
multiplicity; the fixed native rank is one, so the Gaussian-axis count is f.
The common grid is unchanged. With `V_W=2PSr2^(9f)W` and E the actual
original six-code length, complete direct bounds are
`T<=2^26(fV_W+E+1)` and `K_final<=K_entry+4096(V_W+E+1)`. Every widened
core service, descriptor, read, conversion, carry, stage, return, cleanup
and historical cell is paid. This supplies no recursive f^sigma tariff,
old #6030 Count/Tape substitution or enclosing selected caller.

PROOF.md gives concrete #7429 W+2 temporary admission, exact signed
