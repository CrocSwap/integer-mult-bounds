# Price sharing at its physical owner boundary

**Pre-construction result: neither tested mechanism supplies 100 net rank
units per invocation. No supplier was built and no new kappa is claimed.**

This follows the arithmetic screen in `../bit-role-sharing-budget`. It adds
an exact scalar sharing candidate, a storage plan, and an independent
reconstruction of all 126,432 frozen helper reservations. It does not turn
an optimistic profile into an implemented algorithm.

| Candidate | Gross saving per local invocation | Paid return / limitation |
|---|---:|---|
| Nine running decoder accumulators across the nine stages | At most 7 rank units | 288 persistent owned rows, nine temporary rows; ADDRESS alignment remains unproved |
| Eliminate helper indices 0..12 with a hypothetical free producer | 104 rank units | Exactly 104 rank units return at the idle owner boundaries; net zero |
| Grant all 439 helpers free, then merge every data climb | Rank mass unchanged | Target moment 1.006919923493207 with COPY retained; fails |

The earlier **100** threshold grants rank-8 consolidation of all local mass.
With the 222 rank-7 data climbs held fixed, even that favorable relaxation
fails at 100 (moment 1.000209625827279) and 101. It first passes at **102**.
This is a scoped refinement, not a claim that 102 is attainable or sufficient
for a different supplier.

Run from the repository, Python standard library only:

```sh
sh research/bit-sharing-hosting-gate/replay.sh /tmp/new-hosting-gate
```

The checker supports `python3 -I -O -B`. It replays every local Boolean
column, checks independent forward/backward window enumeration and owner
allocation, prices 449 profiles with two rational interval engines, and
rejects six false-admission/ownership controls. Exact results are in
`evidence/PRICE.json`; derivation, costs, and the success gate are in
[PROOF.md](PROOF.md).

The active research goal remains unachieved. It requires a changed operator
or boundary obligation with an actual hosting witness, at least 100 net
units saved per invocation, and a strict complete moment below one at a
saving greater than 1/99. Both supplier bounds are needed before kappa=0.01
could be claimed; the complex supplier is unchanged.
