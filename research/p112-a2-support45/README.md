# P112 A2 shortening through common support 45

Three pieces of binary support rank at most five have root-code intersection
at most one after deleting one common set of at most 45 P112 coordinates.
This improves PR3249's sufficient threshold from 44 to 45 over every
characteristic-zero field. Pieces may be dependent and coefficients arbitrary.
Global sharpness remains unknown.

The new finite premise rules out the previous counting equality. Ten singleton
labels in an A2 projective fiber span a binary five-space containing exactly
those ten full E8 root labels. A piece with ten such singleton sites therefore
has support at most ten, and cannot simultaneously attain support twelve.
[PROOF.md](PROOF.md) gives the complete implication and inherited premises.

## Evidence and reproduction

From the repository root, with CPython 3.12 and the standard library:

```sh
python3.12 -W error -B scripts/research_package.py \
  --package research/p112-a2-support45
```

The registered commands run the following checks without writing into the
checkout. An external `TMPDIR` can keep runner scratch in a session cache.

- `verify.py` checks all 8,001 fiber five-flats and all 648 tight full-E8
  closures, authenticates the live geometry source and compares RESULT.json.
- `crosscheck.py` independently reconstructs roots/labels and checks all
  242,190 five-label subsets. Both methods agree on the complete tight-flat
  set hashes, not only the maxima.
- `test_controls.py` runs eight optimized behavioral/rejection groups,
  including an extra-root mutation that invalidates the closure premise.

`VERIFY.json` registers the exact commands. `SOURCES.json` pins the inherited
proof/receipt and source geometry. `ENGINEERING.md` records bounded resources,
diagnostics and runtime limitations. `CHECKS.json` records execution and review
coverage. The new finite facts are author-checked; no independent human or
proof-kernel verification is claimed.

The existing task-card positive control
`python3 -B research/complex-local-word-ceiling/verify.py` passed. It only checks
the historical planning ceiling and is not evidence for the new theorem.
