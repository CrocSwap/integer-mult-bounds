# Verification and resource boundaries

Separate Before Serializing Shared State kept this package, its claim and its
external session cache disjoint from sibling workers. Only short shared Git
metadata changes use the run's common OS lock. Prove It Works led to checking
all full-E8 closures and comparing complete tight-flat sets in a separately
written root/label and five-label-basis implementation.

Power of Ten inspection covers the three new Python entry points. There is no
recursion, general code evaluation, mutable global state or asynchronous work.
Every enumeration has a fixed domain: 120 roots, nine binary coordinates,
three 27-label fibers, at most 8,001 annihilator flats or 242,190 five-label
subsets. A binary span has at most 512 vectors, and stored rank-five spans at
most 32. Each independent fiber keeps at most 2,667 five-row bases. Functions
remain below 60 physical lines. Explicit exceptions preserve mathematical
guards under optimization. Output creation refuses overwrite and requires an
external destination. Imports use one static, SHA256-authenticated geometry
path. The independent checker imports neither that module nor the primary.

Rule 3, fixed memory. CPython allocates integers, sets and tuples during bounded
enumerations. Replacing these allocations would require a different runtime.
The scope is the exact finite domains above, with one verifier process per
registered command, 120-second command limits and no recursive traversal.
Tests and exact result comparisons check those bounds. If domains become
runtime parameters, enforce capacities before accepting them or move to a
preallocated implementation. Runtime allocator internals are not audited.

Rule 8, source import. The primary's import path is selected from the one
declared input after SHA256 comparison. This is the repository's frozen
geometry convention, not a user-selected plugin. The registered runner adds
private bytecode-cache isolation. Direct runs use `-B` and source pins but do
not independently isolate preexisting bytecode reads; use the registered
command for the supported reproduction contract.

Diagnostics are CPython 3.12 with warnings as errors, an optimized behavioral
control run, and Ruff's E/F/I/UP/B/SIM/RUF checks. The source-pinned predecessor
is read-only and is not refactored. Its historical expensive censuses and
written chamber argument are inherited, not passed off as new execution.
