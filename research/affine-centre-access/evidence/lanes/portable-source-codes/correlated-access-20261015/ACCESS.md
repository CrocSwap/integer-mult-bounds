# Affine access to the correlated native phase sector

This note gives a sharp bound for affine parts of the correlated phase
sector. It also gives an exact, reversible arithmetic graph for their
projectors. The graph has no Fourier child and restores an arbitrary
source. It can act on an arbitrary target. The largest affine parts have
an exponentially small fraction of the payload. Thus a bounded set of
these parts does not give access to the positive-fraction sector.

The arithmetic graph is not an admitted packed-stream layer. Its address
schedule, accumulator storage, precision, and owner placement need a
separate implementation. There is no new supplier or kappa claim.

## 1. The actual phase question

Use n native coordinates and tensor width l. Write a Fourier address as
an n-by-l binary matrix X, with rows x_1,...,x_n. For an odd vector q,

    f_X(q) = wt(sum_i q_i x_i) mod 4.

The inherited native line is C_q=(I+X_q)/2+i(I-X_q)/2. Its l-fold
tensor power has phase i^f_X(q) at this Fourier address.

Let S_n be the set of addresses for which f_X is constant on all odd q.
The constant d can depend on X. Let S_(n,d) be the part with fixed d.
The companion proof `coherent-port/shared-cover-quotient-20261015/QUOTIENT.md`
has SHA256
`0e16a12d172ba215041c1096627772262863beca0c2296c8d773bdbac2d6c3d0`.
It proves that equal-rank orthogonal owner frames agree on S_n. It gives
the exact fraction delta_l of this sector. For the sufficient n=73
sector, delta_l tends to 2^-2700. It does not implement its projector.

The access problem concerns the whole spectral subspace, not a set of
known input addresses. Inputs remain arbitrary. A projection must occur
inside an invertible operation, or its complement must also be kept.

## 2. Sharp affine bound

Suppose n>=2 and an affine binary set A+V is contained in S_n. Then

    dim V <= n floor(l/2) + (l mod 2).                    (1)

This bound is attained for every positive l. If A+V is contained in one
fixed-d part, then

    dim V <= n floor(l/2).                               (2)

Here V can mix all native coordinates and all tensor layers. No product
form or code basis is assumed.

For each row i, let p_i:V -> F_2^l be its coordinate projection. On A+V,
the weights of row i and row 1 agree modulo four. Polarize this equality.
For binary a,u,v, the second difference of wt(a+u) modulo four is
2(u.v). Thus all the pulled-back binary forms

    B_i(u,v) = p_i(u).p_i(v)

are one common form B on V. Let r be its rank and let K be its radical.
Put W_i=p_i(V). The restricted dot form on W_i has rank r. The image
p_i(K) is the radical of W_i. If s_i is its dimension, nondegeneracy of
the ambient l-dimensional dot form gives

    r+2s_i <= l.

The combined row map is injective on K. Therefore

    dim V = r+dim K
          <= r+sum_i s_i
          <= r+n floor((l-r)/2).                         (3)

Maximize (3) over 0<=r<=l. For n>=2 this gives (1). If d is fixed,
polarization of each row weight itself makes B_i zero. The combined
row map then gives (2).

Here is an equality construction. First take l=2k. Let D be the
self-dual pair-repetition code generated by

    e_1+e_2, e_3+e_4, ..., e_(2k-1)+e_(2k).

Let a=(1,0,1,0,...,1,0). Every vector in a+D has weight k. Give every
row the offset a, and take V=D^n. Every odd sum of rows is in a+D.
Thus this affine set is in S_(n,k mod 4), and dim V=nk.

For l=2k+1, use these pairs and append one common free last bit to all
rows. Every odd sum has weight k plus that bit. The dimension is nk+1,
which attains (1). Fix the last bit to attain (2).

It follows that a union of M affine sets contained in S_n has fraction
at most

    M 2^(-nl+n floor(l/2)+(l mod 2)).                     (4)

For even l, a cover of the whole sector needs

    M >= delta_l 2^(nl/2).                               (5)

For n=73 and l=152, the companion lower bound delta_l>=2^-2700 gives
M>=2^2848. This is an exact power-of-two bound, not a numerical estimate.

The same rank bound applies to a spanning family of spectral subspaces
with these affine supports. It also applies to a positive sum of their
projectors that equals the sector projector: positivity prevents an
outside component from cancelling.

Equation (5) is not a lower bound for a general projector circuit.
Signed terms can cancel. A nonlinear encoding can have a different
support. A staged circuit can share intermediate values. None of these
classes is excluded here. The sharp affine bound only rules out the
proposed access through a bounded collection of affine code pieces.

## 3. Exact projector shear on arbitrary inputs

Let H be a binary translation space of dimension k on an address space
of size N. Let chi(h)=(-1)^(a.h). The projector onto the Fourier support
a+H-perpendicular is

    Pi = 2^-k sum_(h in H) chi(h) X_h.                    (6)

One can also restrict to a union of H-cosets in physical addresses.
The restriction commutes with the translations in (6). This includes
the CSS projectors below.

Partition the selected physical addresses into cosets of H. For each
coset choose a pivot p, and put epsilon_j=(-1)^(a.(j+p)). The pivot has
epsilon_p=1. On separate arbitrary source x and target y, do this:

1. Add epsilon_j x_j to x_p for all nonpivot j in the coset.
2. Divide x_p by 2^k.
3. Add epsilon_j x_p to every target y_j in the coset, including p.
4. Multiply x_p by 2^k.
5. Undo step 1 in reverse order.

The source is restored exactly. The target gains Pi x. The inverse
uses the opposite sign in step 3. No initial value is discarded, and
no added signal field is used. In particular, an arbitrary borrowed
source does not have to contain zero.

Let s be the number of selected physical addresses and c=s/2^k the
number of cosets. There are 3s-2c complex unit ADDs and two power-of-two
scales at each pivot. Under the retained real-primitive convention, a
complex unit ADD costs eight and these two scales cost 4k. The exact
arithmetic bound is

    24s + (4k-16)c.                                      (7)

For a full affine Fourier projector, s=N. This is at most 25N for all
k>=0. The proof of this bound uses (4k-16)/2^k<=1. This bound concerns
arithmetic gates. It does not price a new address controller.

The largest source pivot is at most 2^k times the largest source entry.
The completed target increment has infinity norm at most that of x.
Thus the simple graph can require k extra magnitude bits at a pivot.
The division can also require k extra fractional bits on an exact
integer input grid. Equation (7) counts the shift primitives. It does
not prove a record-width allowance for them.
This is an explicit prefix bound, not a complete error analysis. A
balanced averaging graph can change the prefix bounds, but is not part
of this packet.

Three such shears give an invertible finite-order operation on two
arbitrary fields:

    x += Pi y;  y -= Pi x;  x += Pi y.

On im Pi this is (x,y)->(y,-x). On ker Pi it is the identity. Its fourth
power is I. The graph restores the source of each shear and uses only
the two existing fields. This gives a valid arbitrary-input embedding
of the projection into a reversible mode operation.

For the even-width equality example in section 2, H=D^n and the offset
has a in every row. Equation (6) becomes the product of the projectors

    (I-X_(i,2j-1) X_(i,2j))/2

over all rows i and pairs j. On this range, every odd C_q tensor l is
the scalar i^k. Therefore all complete equal-rank owner frames agree
on this range. Its exact fraction is 2^(-nl/2). This is a real local
projector graph with a small arithmetic bill; it is not a
positive-fraction solution to the full correlated-sector problem.
The statement is about complete owner frames. It does not permit this
projection at an arbitrary internal canonical-frame cut.

For the actual gap query G'_s=S_sigma_s R D_s(I-Q), a cover sum A on
this even-width range has

    A Pi G'_s = (1-i^k) R A Pi,

independent of s. The source-domain and phase conventions are those in
the companion quotient proof. If k is zero modulo four this query is
zero. For the other residues it is a nonzero common source query.
The response code and a complete controller still need their own proof.

The current owner receipts admit pointwise scalar ADDs and whole-field
monomial address maps. They do not admit this cross-address graph from
its gate count alone. A fixed tensor-product basis permutation can make
the cosets contiguous in some cases. A stream implementation must then
price the reduction, broadcast, reverse restoration, accumulator bits,
address maps, and source exteriors. General l-dependent routing is an
additional obligation. The source-domain worker confirmed this boundary.
For the pair-repetition example, the fixed binary map
(u,v)->(u+v,v) on each pair, followed by a bit-order shuffle, puts the
translation cosets in contiguous address blocks. This gives a concrete
case for a stream check. A sum accumulator needs the input record width
plus the stated k-bit magnitude allowance. This packet does not allocate
or restore that stream accumulator in the actual owner schedule.

## 4. Why a CSS invariant subspace is not sufficient

Let N_0 be a doubly-even self-orthogonal code in F_2^l, of dimension r.
The zero-syndrome CSS projector on one native coordinate is

    P_N = 1_(N_0-perpendicular) 2^-r sum_(h in N_0) X_h.   (8)

On n coordinates use its n-fold tensor product. Formula (8) is a special
case of section 3. Its rank fraction is 2^(-2nr). It commutes with every
Clifford tensor power. For example, the Walsh transform exchanges its
X and Z constraints. A phase gate preserves each code coset because
N_0 is doubly even. A row CNOT preserves the common code and its dual.
These operations generate the required Clifford maps.

This invariance is established theory. The CSS commutant construction
is in Gross, Nezami, and Walter, Theorem 4.21:
https://arxiv.org/html/1712.08628v3#S4.SS2 .
The representation and code structure are also in the introduction and
section III of Montealegre-Mora and Gross:
https://arxiv.org/html/2208.01688v2 .
This note does not claim these constructions as new.

Commutation is weaker than the required equality of frame actions.
The code can retain a nontrivial native operation. The coset states have
phase i^wt(v) for v in N_0-perpendicular in the Fourier representation.
If the native C tensor l is scalar on the whole code, all these weights
must be zero modulo four. Thus N_0-perpendicular is self-orthogonal.
Since N_0 is also self-orthogonal, this forces N_0=N_0-perpendicular.
The code then has rank one on each native coordinate. Its fraction on
n coordinates is 2^(-nl).

An affine coset does not avoid this dimension condition. Constancy of
wt(a+v) modulo four forces the direction space to be self-orthogonal
by polarization. The finite checker includes all self-orthogonal codes
and all affine offsets through length six.

For a positive-rank orthogonal owner frame on the product CSS code,
the same conclusion holds. Change to its orthogonal coordinate basis;
the code is invariant under that address map. A tensor product of a
non-scalar invertible factor cannot be scalar when its factors have
independent inputs. Thus making one such complete frame scalar already
forces the one-coordinate condition.

This distinction also explains the actual common-query limitation.
P_N F_g=F_g P_N does not imply F_g P_N=F_h P_N. A commuting projector
alone does not permit a cover sum between different native exteriors.

## 5. Original complex Bell phases and the earlier bound

The earlier campaign Bell packets used the doubled Walsh retarget.
Their access limitation remains: an encoded mode does not make a
scatter into unencoded data free. The following phase identity binds
the same issue to the original complex native line.

Let B=CNOT_(1->2)(H_n tensor I), where H_n has kernel
((1+i)/2)^n (-1)^(b.x). The Bell column labelled (b,a) is

    B|b,a> = ((1+i)/2)^n sum_x (-1)^(b.x) |x,x+a>.

Direct expansion gives

    B^-1(C_q tensor C_q)B |b,a>
       = |b,a+q>,       if b.q=0;
       = i |b,a>,       if b.q=1.                        (9)

For inverse native lines replace i by -i. A simultaneous translation
X_t tensor X_t gives the phase (-1)^(b.t). A binary address map A on
both copies sends (b,a) to (A^-T b,Aa). These phases are part of the
operation.

One Bell conversion on a pair of n-bit copies needs one rank-n native
Fourier block, two diagonal phase maps, and the CNOT address map.
Indeed H=S C S with S=diag(1,i) on each axis. The inverse conversion
has the same width. For even l, the total binary Fourier width is
nl/2 per entrance or exit. The two boundaries have total width nl,
equal to the complete productive width. Changing the tensor grouping
does not remove this width from a recursive invoice.

The old invariant-Lagrangian proof also applies directly to C_q. Its
symplectic action is the transvection with axis (q,0). If one common
Clifford gauge makes all l-copy native lines monomial, and the labels
span d dimensions, the gauge has Fourier width at least d ceil(l/2).
For pure-Z elements in its invariant Lagrangian, isotropy gives

    sum_j (q.z_j)(q.w_j)=0.

Use d independent q and the dimension bound for a self-orthogonal
subspace of F_2^l. Partial Bell transforms attain this bound. Thus
tensor-layer mixing does not make the full common gauge cheaper.
This is not a bound for a projector on a restricted sector or for a
general staged arithmetic circuit.

`review-gauss/bell-compression/BELL-GAUGE-LOWER-BOUND.md`,
`review-gauss/bell-compression/DIRECT-WEIGHTED.md`, and
`WEIGHTED-GAUGE-BOUND.md` in the same physical-algebra lane. This note
reuses their distinction between an algebraic frame and paid access.

Even a single native phase projector need not be a short flat monomial
sum. Let P_d select wt(x)=d modulo four on l Fourier bits. Away from
the two exceptional translations 0 and the all-ones vector, its
convolution coefficient at a vector of weight k is

    2^(-l/2-1) cos((l-2k-2d) pi/4).

For odd l>=3 every row has 2^l nonzero entries. For even l>=4 the count
is 2^(l-1), or 2^(l-1)+2. The latter occurs when l/2-d is odd. A flat
sum of weighted permutations therefore needs at least 2^(l-1) terms.
This is not a lower bound for the staged graph in section 3 or for an
arbitrary scalar algorithm.

## 6. Checks, limits, and next step

Run `check_access.py --lanes PATH_TO_LANES --out OUTPUT.json` with Python
3 and the standard library. The expected status is
`PASS_EXACT_CSS_ACCESS_AND_ORIGINAL_BELL_PHASE`.

The checker uses exact integers and rational numbers. It checks whole
input bases for the small projector graphs, source restoration, inverse
shears, projected quarter-turn order, CSS commutation, affine scalar
criteria, and the original Bell phases. It also checks every affine
subspace in the stated small ambient spaces and the sharp examples.
The retained 112-label source is bound to its exact hash. The general
dimension and gate-count arguments are proofs, not finite-search claims.

The broad remaining possibility is a direct circuit for the nonlinear
correlated sector, or a representation that carries its complement
with lower total access cost. The affine bound does not forbid such
a circuit. The next useful test is a complete stream implementation
for one non-affine projector, including its primitive-prefix and
restoration costs. Repeating a full-space Bell gauge or a bounded set
of CSS states does not supply that result.
