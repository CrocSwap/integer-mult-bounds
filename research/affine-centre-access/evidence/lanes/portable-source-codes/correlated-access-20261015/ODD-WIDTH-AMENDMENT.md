# Odd-width attainment in the common-gauge bound

This note clarifies Section 5 of `ACCESS.md`, SHA256
`a5a91cdc4deed08aa15693aedbcc01f48186859f8902acdb864aa74fb6feba4d`.
The original file remains unchanged.

For even tensor width, partial Bell transforms attain the stated lower
bound. For odd tensor width, use partial Bell transforms on each of the
`floor(lambda/2)` pairs and a Fourier transform on the `d` active axes
of the last layer. The total Fourier width is `d ceil(lambda/2)`.
The unpaired-layer operation is required. The earlier sentence about
attainment omitted that operation; the bound and all numerical claims
remain unchanged.

The independent reviewer identified this omission. This amendment makes
no new stream, owner, precision, or supplier claim.
