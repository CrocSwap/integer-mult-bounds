# Notice — disjoint-tensor frame unions

Douglas R. Colkitt authored the disjoint-tensor compression screen, the
`DisjointTensor` recurrence, embedding and original `frame_data` /
`verify_frames` checkers consumed by this tooling package.

Stephan Arrington’s `research/disjoint-frame-unions/` (#1044) proved the exact
target-union propagation algebra as an opt-in adapter with identical
historical-certificate bytes. This package promotes that algebra into the
default production `DisjointTensor.frame_data` path, with identical
`verify_frames` receipts and updated source pins only.
