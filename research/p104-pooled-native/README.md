The 91-helper word in [PR2548](https://github.com/CrocSwap/integer-mult-bounds/pull/2548)
has exact native Clifford transports at its stated dimension-gap ranks. This
package closes its explicit finite native-transport handoff: it compiles the
actual word, checks each complete operator including global phase, and binds
the result to all arbitrary dirty input columns. Physical source delivery,
address routing and complete supplier admission remain open. No new kappa is
claimed.

The source is Nick Petalas's PR2548 at
`c7a3286860057f9240e0371b33ada37cc63b7ad7`. Its complete insertion circuit is
retained byte-for-byte in `inputs/PR2548-CIRCUIT.json`. The original 4,058-event
P104 channel is the pinned main-tree input. No predecessor files are changed.

## Exact operator argument

For a physical binary frame W, let Gamma_W be the retained canonical Clifford
chart. The checked transport A -> B is the entire operator

`Gamma_B Gamma_A^(-1)`.

Its recipe rank is checked against `abs(dim B - dim A)`. Signed Pauli actions
determine a Clifford up to scalar; an exact Gaussian state column fixes that
scalar, so the native test includes global phase. Testing only a symplectic
matrix would not suffice. All persistent paths ascend. The original private
copy paths are explicitly exempt from that claim.

At every event maintain: the physical array in register r is Gamma_(current
frame) applied to its exact logical row of arbitrary input arrays. Transport
preserves this invariant by the checked operator identity. Every scalar ADD
and COPY has equal operand frames; it therefore preserves the invariant by
linearity. Original owned allocation/disposal steps retain their stated local
semantics. A separate Fraction row replay executes all 4,852 events and checks
the final 371-by-371 coefficient matrix, including every dirty input.

Let C have rows `C[t,s]=delta[t,s]` for t=0,1,2 and
`C[t,s]=<p_t,p_s>/2` otherwise, with the actual ordered P104 roots. The result is

`Y_t <- Y_t + sum_s C[t,s] X_s`,

with every X and all 163 persistent dirty helpers restored logically. The
other 101 target rows remain G/2 rows. If Gamma_i and Gamma_f are the full
entry and exit chart blocks, the canonical physical map proved here is
`Gamma_f S Gamma_i^(-1)` for this logical S. Logical identity rows are not a
claim that unrelated physical entry and exit charts coincide.

The 104 source adapters bind intrinsic C_q inputs to their canonical line
charts. The 104 target adapters bind canonical output hyperplanes to
`F9 C_q^(-1)`. All 208 are checked monomial operators of rank zero, including
phase. Supplying those physical inputs, implementing scalar/address traffic,
and realizing the full caller remain separate obligations.

## Reproduce

Python 3.12, standard library, no network. Default replay writes nothing.

```sh
python3.12 -I -O -B research/p104-pooled-native/verify.py
python3.12 -I -O -B research/p104-pooled-native/test_verify.py
python3.12 scripts/research_package.py --package research/p104-pooled-native
```

`build.py --out NEW_FILE` recompiles the whole native payload and refuses to
overwrite existing evidence. Tests compare the complete decompressed JSON
payload, not gzip headers. The checker authenticates every external source
before executable import, requires the complete source set, and compares the
entire typed receipt. No assertion statement is needed for acceptance.

Six semantic controls remove either pooled fanout, alter a POOL1 transport's
global phase or positive rank, omit its actual event occurrence, and corrupt
an endpoint normal. Three behavioral test groups cover complete regeneration,
equivalent frame bases, and optimized Git-free read-only export with drifted
source, missing evidence, omitted source pin, corrupted receipt and exclusive
output controls. Source-before-import rejection uses a deliberately poisoned
interpreter file. `RESULT.json` stores mathematical outputs, not benchmark data.

Native CPython 3.12.7 passed the registered primary replay and all three
behavioral groups. A separate AI reviewer read the operator argument and
source checks and independently passed optimized CPython 3.12.14 replay,
including all six semantic controls. This is not independent human review.
