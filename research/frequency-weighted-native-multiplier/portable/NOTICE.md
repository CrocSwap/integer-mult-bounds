# Sources and licenses

The scientific compiler and signed multiplier come from CrocSwap/integer-mult-bounds and its credited predecessors. The weighted installer retains the ordinary circuit, the Gaussian operators, exact chart and role generators, and both public profiles. This package binds them to a finite portable interpreter. The original authors and source hashes are listed in the parent package. [Scientific attribution](../NOTICE.md) · [Source manifest](../SOURCES.json)

The two external files are from VMware Labs' `python/3.12.0+20231211-040d5a6` release. The VMware Labs packaging repository uses Apache-2.0. CPython and its standard library carry the Python Software Foundation license and included component notices. The interpreter and library are fetched directly from upstream. The module and archive each have their own digest in the replay driver.
