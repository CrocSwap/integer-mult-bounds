## Reproduce

From the repository root, with Python 3.11 or later and no third-party dependency:

```sh
python3 -I -B research/nonchain-root-transport/verify.py
python3 -I -O -B research/nonchain-root-transport/verify.py
```

`report.json` is the checked report. `--write-report` deterministically refreshes
it. `certificate.json` contains exact rational dual variables; verification uses
exact rational arithmetic throughout its proof-relevant comparisons.
`discover_certificate.py` is an optional proposal generator requiring NumPy and
SciPy. Its solver output is not trusted by the replay.

Read [PROOF.md](PROOF.md) for the new mixed carrier formulas, arbitrary-input
stage identity, uniform complete-invoice comparison, pairing-rank formula and
LP dual proof. `retained/SOURCE-PINS.json` pins the three retained #6833 files
by commit, Git blob and SHA256, together with the independently recounted
native export from #6835. Their bytes and original attribution are unchanged.
`SOURCES.json` separately binds the canonical selected record and original task
card as historical provenance.

The standard package hook checks metadata, runs both primary replay modes,
and runs the separate independent audit with the retained native census:

```sh
python3 -B scripts/research_package.py --package research/nonchain-root-transport
```

No source-history ancestry pass is claimed for this shallow checkout. The
scientific replay is self-contained; it needs no cached unmerged Git objects.

## Open next questions

- Can a different mask change admit cross-side carriers with a complete target
  and idle bill that survives the favorable interval-capacity test? This matters
  because mixed transport itself is possible. First derive its incidence profile
  and all common pairing ranks before building a literal caller. Blocked by a
  positive complete budget; neither tested target should be reswept.
- Can a valid non-shortest root change the pairing capacities or target
  incidence enough to pay for its extra thin queries? Start with an exact small
  arbitrary-input root and include every query in its bill. The current
  certificate makes no claim about that contract.
- Can interval capacities yield a reusable global lower bound for other
  commuting stage-mask systems? Start by comparing a candidate's exact primal
  schedule with its rational dual. Simultaneous realizability is not implied by
  satisfying all interval inequalities.
