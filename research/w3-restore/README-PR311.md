## Reproduce

Python 3.11+ (NumPy/SciPy/SymPy per `requirements.txt`), a C++17 compiler and Boost headers:

```sh
python3 -m pip install -r research/w3-target-prefix/requirements.txt
python3 -B research/w3-target-prefix/verify.py --output /tmp/w3-target-prefix-proof --cxx g++ --boost-include /usr/include
```

About 10 minutes; both prerequisite source verifiers (PR249, PR256) rerun fresh. Prints `PASS conditional kappa = …`.
