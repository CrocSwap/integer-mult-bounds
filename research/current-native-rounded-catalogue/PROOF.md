# Complete local coverage and the scalar cost sum

Fix the exact native word and retained compilers in SOURCES.json and
VENDORED.json. The native program has 139227 ADD occurrences and 4149
SCALE occurrences. It has no COPY operation. This proof concerns those
local scalar sites only.

## A complete finite registry

Scan the literal program in chronological order. Track each public field's
chart and each owned field's live interval. An ADD must use distinct live
fields in the declared common chart. A SCALE must name a live field in its
declared chart. INIT, MOVE and CLEAR update the chart metadata, including
the owned/public class. The final metadata must equal all declared public
end charts and leave no live owned interval.

For each scalar event, form the complete local key (local, clock, raw event).
Group keys by operation and reduced rational coefficient. Reduction changes
only which fixed coefficient table is shared; each raw event remains in
its own source key. Different clocks give different keys even when their
raw events match. A reverse raw-opcode census checks each group's size.

There are 2196 ADD groups and 74 SCALE groups. Construct each group's table
with the unchanged corresponding compiler and map every key in that group
to that table. The groups are disjoint and cover every scalar clock, so the
union is a complete finite local registry. The verifier builds each group
and its actual table object in turn. It authenticates the complete ordered
key lists and complete tables by SHA256, and checks every literal branch,
port and unit-move target. This is not a runtime recursive loader.

For ADD, let a/b be reduced, b=2^d o, and
L=max(bitlength(abs(a)),bitlength(b)). The source gives L<=18, d<=11 and
o<=25. Thus it satisfies the retained compact compiler's o<=125 domain,
and its numeric extension K=L+2 is at most 20. For SCALE the corresponding
maxima are L<=8, d<=6 and o<=9. The compiler's finite carry and residue
construction therefore applies at every source coefficient.

The retained all-size theorems prove nearest-up arithmetic and final-range
rejection on every canonical field satisfying their physical premises.
The new literal cases independently compare each table with signed integer
floor arithmetic. They include a nonzero signed case for every coefficient,
a late overflow for every ADD coefficient, and width-one endpoints. The
cases corroborate the source-bound instantiations; they do not replace the
retained all-size proofs. Wrong-table and nonunit-move controls reject.

## Accumulate the complete scalar service bound

For one ADD, let R be its real component count and S=sum_j(w_j+1) its
numeric virtual extent. With K=L+2, the retained bound is

```text
512(L+8) [1+S+(L+3)R] + 7A + 16Q.
```

Here A is the total old contiguous physical length of its two work bodies,
and Q is the count of borrowed contexts at their origins. The bound includes
all source reads, numerator passes, division, staging, copying, head return
and retirement. Resident private storage is
max(H_N,3[1+S+(L+3)R])+max(H_O,3S), with historical capacities H_N,H_O.

For one SCALE, the retained bound is

```text
512(S+1) + 64dR + 7A + 16Q.
```

Its private backing is max(H_0,3S)+max(H_1,3(S+1)). The full field is staged
before public installation in both services. Successful calls preserve
borrowed data and return heads; rejected calls protect the public target
but can leave dirty work and displaced heads.

Now choose S and R as upper bounds for every local scalar field in the
native invocation. All coefficients in the cost formulas are nonnegative,
so replacing each field's actual sizes by these common upper bounds is
valid. Sum the per-call costs with literal source multiplicities. ADD gives
746570752(S+1)+4241681408R, and SCALE gives
2124288(S+1)+68352R. The sum is

```text
748695040(S+1) + 4241749760R + 7 sum_i A_i + 16 sum_i Q_i.
```

COST.json is generated by a reverse per-event source sum. Each registered
replay independently reconstructs its part from the table construction
receipts and occurrence counts, then checks the combined sum. Old dirt is
not assumed to vanish between calls. A complete provider must establish
which work banks are reused and how their historical capacities are charged.

The unshared catalogue contains 33556789 literal rows and 14593712 states.
They are fixed finite control data for this source. Their positive setup
and representation costs are separate from the per-invocation bound.
No state sharing, source setup, table access or private storage is free by
this argument. The numerical coefficients above are not comparable with
the source's ordinary-model units without a proved conversion.

## What remains outside the result

The union construction supplies every local coefficient table, not the
complete recursive controller, row exporter or signed caller. It assumes
canonical matching formats, physical nonaliasing, required origin heads,
contiguous old work and the final signed-range contract. It does not derive
these premises for all admitted recursive states.

Native MOVEs, owned erasure, recursive delivery, caller scalar operations,
complete private backing, common physical pricing and rounded outer recovery
remain separate. The five framework assumptions and selected kappa are
unchanged. This is a complete finite local catalogue with retained universal
primitive theorems, not a complete multiplication theorem.
