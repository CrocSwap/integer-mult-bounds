# Source and validation record

The source is the `centre-encoding-campaign-20261014` campaign. The 170 runtime and proof
inputs under `frozen/` are exact copies. [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json)
records their original paths, reasons, sizes, SHA256 values, and compressed
payload hashes. This is the selected proof and checker closure. It does
not include every lane or every producer experiment. Eight additional linked
historical freeze records are exact copies listed in
[REFERENCE-MANIFEST.json](REFERENCE-MANIFEST.json). These source records
supply attribution and context; their archived suites are not rerun.

All seven exact checker files are unchanged. Six local service checks
import no producer code. The D25 joined-service check imports one pinned
independent mathematical helper. It checks the original native phase
source bytes and their 35-file input record; it does not repeat the old
4194304-coefficient spatial interpreter. The separately assembled
[90-file join closure](evidence/FIXED-READER-JOIN-CLOSURE.json) is fully
contained in this package with equal hashes.

The new runner uses a fresh copied source tree for the two checkers that
write beside their source. It saves the outputs and removes only that
new temporary copy. Other checkers use their existing output-directory
argument. No checker path, arithmetic, import, phase, endpoint, or price
logic is patched.

Old result JSON records contain absolute source paths. The runner maps
only registered values of fields named `path` to the matching package
path. Unknown paths fail. It then compares every JSON value with the
frozen receipt. This is not a claim that raw receipt bytes with different
absolute paths are equal. Program outputs are compared byte for byte
after decompression. Both Python modes must give equal canonical results.
The file-access audit allows only the package, output tree, and Python
runtime; it is a reproducibility check, not a security sandbox.

The [fresh receipt](evidence/REPLAY.json) records fourteen sequential
checks with Python 3.14.7 on macOS arm64. Their measured total was 32.025
seconds. All checks passed. All 170 source files retained their hashes.
The retained normal and optimized outputs, canonical comparisons, logs,
and file-access records are under `evidence/replay/`. No archived producer
emitter, complete native spatial phase suite, selected frontier, complete
recursive supplier, or Lean formalization was rerun.

The publication context was checked on 2026-10-22 against upstream main
`b58ad9ef4d4e861b0eaa5dba41742bdc072dca51`. Its selected record names
[PR #4470](https://github.com/CrocSwap/integer-mult-bounds/pull/4470), with

This package does not transplant them into it or change its complete cost.
