The moving-code theorem, generic scalar conjugator, phase order,
four-step cycle, opposite-sign return, and actual constant matrices
agree with the independent proof in `REVIEW.md`. The cost rows agree
with `CHECKS.json`. The text distinguishes the separate centre-bank
swap from the code on the existing 112 fields. It retains the final
decode, routed commutation, interleaved caller, and recursive cost
as open obligations.

The older phase proof agrees with the independently checked character
certificate and physical inverse kernel. Its exact norm 88/5, common
denominator 120, and required odd primes 3 and 5 are supported by
the frozen phase-section review.

Two wording qualifications apply:

1. The statement that the unnormalized sum code is dyadic also requires
   dyadic U and V, in addition to a dyadic U_P^-1. Both actual source
   factors have that property. It is not a consequence of the general
   scalar hypotheses alone. For example, U=1 and V=1/3 have U_P^-1=1
   but a non-dyadic sum code V.
2. In the older proof, QU has invertible cross-matrix T with VQ.
   It is a right inverse of the normalized reader T^-1 VQ. The
   displayed equation (VQ)(QU)=T is correct; the word "section" must
   use that normalization.

These qualifications do not change either actual construction or
any numerical result. The frozen source files were not changed.
This addendum does not review the separate D11 route32 extension.
