# Replay coverage and limits

The runner checks every source byte count and SHA256 before and after
execution. It also checks decompressed hashes when recorded. It runs
one process at a time, in normal and optimized Python. Each job has a
private package copy, so old scripts which write beside themselves
cannot change the frozen files. No source or import is patched.

| Job | Fresh checks | Boundary |
| --- | --- | --- |
| Original pivot emitter | All 640 independent inputs; 528 unchanged roles; centre and complement rows; both scalar and spatial inverse orders; full diagonal response; 2078/16 invoice; norms and heights; wrong-side-square control | It imports the pinned producer's matrix and tariff helper; it is not the independent review |
| Prior moving review | Separate rational engine; actual 112-column pivot code and inverse; both inverse products; full diagonal response; its other retained moving-entry checks | This old review proves the pivot algebra; it does not separately certify the precise 2078 invoice and prefix grid |
| Invoice/domain check | No producer import; full literal tariff; eight exact valid-image divisions on 112 columns; inverse restoration; generic 1/12 witness | It verifies an existing word and its domain; it does not prove that a middle operation preserves the image |

The original emitter's complete JSON outputs match byte for byte.
The prior review writes absolute source paths in its receipt. Before
comparison, the runner requires every such path and hash to match a
registered frozen input. It replaces only those path values with their
registered relative paths, then compares every JSON field. It compares
the complete generated program after decompression and checks that
payload's declared hash. No claim is made that absolute-path receipts
have equal raw bytes. The invoice/domain receipt matches byte for byte.
Normal and optimized outputs must agree under the same rules.

[REPLAY.json](REPLAY.json) records six passing runs. The historical
moving checker also executes its rank-30 and entry-swap checks because
they are part of the unchanged checker; this annex does not repackage
those as new results. The fresh publication review is separate from
that historical review.

The wrong-side-square control directly rejects incorrect entry order.
The generic inverse witness rejects the claim that the inverse is a
dyadic unit on arbitrary code coordinates. Valid-image divisions pass
on every original input column, not on a sample of values.

This replay does not rerun native phase compilation, a common-root
conversion implementation, the scan bit loop, a complete productive
caller, raw terminal decode, helper hosting, the recursive grid invoice,
the selected frontier, or a complete kappa calculation. The scan and
common-grid proofs are retained premises, not fresh machine-level tests.
