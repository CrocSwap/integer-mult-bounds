## 2. Arbitrary fresh inputs at every cut

The cut lemma is valid even when the old prefix and suffix contain owned zero
projections. Let `P,S` be the normalized-coordinate prefix and suffix, and let
the witnessed bases satisfy

```
a P = c,     S b = d,     a b = c d = 1,
e_p^T B0 = c,    B0 d = e_p,
e_p^T BF = a,    BF b = e_p.
```

Define `C=BF P B0^-1` and `D=B0 S BF^-1`. The support of `B0` lies entirely in
an autonomous identity helper block of the old endpoint `E`, so `B0 E B0^-1=E`.
Consequently `DC=E`, `e_p^T C=e_p^T` and `D e_p=e_p`.

For any old input `x`, the cut field is exactly `x_p`. Replacing only that
field by a wholly arbitrary fresh input `z` changes the cut vector by
`e_p(z-x_p)`. The completed suffix changes by exactly the same vector, because
`D e_p=e_p`. Every other output, including every owned final component, is
unchanged. The successor output is `z`; the retired old field is `x_p` and
remains untouched thereafter. No invertibility of `P` or `S`, zero fresh input,
statistical independence of intermediate values, or product-state hypothesis
is used. The fresh input must have a distinct physical slot.

The common-frame hypotheses are physical requirements. The boundary supports
use only public helpers with the same literal initial/final chart. The middle
supports, including any live owned labels, share the exact current chart.
Every emitted basis and inverse consists of priced same-chart ADDs and dyadic
unit SCALEs. The actual word's complete current-chart scan verifies those
conditions, so a logical dense change of coordinates is not being assigned
