# Replay the #7113 caller as normalized P104 word primitives

Compares the source records with normalized primitive events over q⁴=1 and i²=−1 at all 4,783 source boundaries, including 72 target rows and 1,768 stage-port contacts.

A role-only first-J mutation leaves packed price data intact but changes 96 contacts and fails the exact endpoint. Generated Lean literals are included as uncompiled data.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `a76555f14080a886f0bbe2e980fb1da7607500c6c8adff51887f7134f7b598d3`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run `python3 -B verify_packet.py`.
