## 2. Accounting: `s = 7` forces Class I (R1)

Put `z := dim(ker ρ ∩ S)`, `x := dim ρS − dim(T + 𝒞)`, `c_8` = excess of the non-`T` members of a minimum basis of `ρS` over weight 8, `drop(b) = w(b) − w(ρb)`.

**2.1 Z-lemma (PROVEN).** `cost_w(S) ≥ cost_w(ρS) + z`. *Proof.* Let `B_0 = {b ∈ B : ρb = 0}`, `z_0 = |B_0|`, `B_1 = B∖B_0`. `ρB_1` spans `ρS` and has `dim ρS + (z − z_0)` members, hence contains a basis plus `z − z_0` surplus members of weight `≥ 1`: `Σ_{B_1} w(ρb) ≥ cost_w(ρS) + z − z_0`; `Σ_{B_0} w(b) ≥ z_0`; `w(b) ≥ w(ρb)`. ∎ (Equality forces all surplus and `B_0` members to have weight 1.)

**2.2 Peeling for `ρS` (INHERITED).** `cost_w(ρS) = 64 + s + 8x + c_8`. Since `Σ_F w ≥ cost_w(ρS)` for the spanning family `F = ρB`, `Δ ≥ s + 8x + c_8`.

**2.3 Theorem R1.** Suppose `cost_w(S) ≤ 71` and `s = 7`. By 2.1 and 2.2, `71 ≥ cost_w(S) ≥ cost_w(ρS) + z = 64 + 7 + 8x + c_8 + z`, so `x = c_8 = z = 0` and `cost_w(S) = 71`; with `cost_w(S) = 64 + Δ + D`, `Δ ≥ 7` forces `Δ = 7`, `D = 0`, `Σ_F w = 71 = cost_w(ρS)`. Thus `F` is a minimum-weight basis of `ρS`, and by matroid greedy the members of `F` of weight `≤ 7` form a minimum basis of `T`. Every `b ∈ B` has `drop(b) = 0` (`D = 0`): the pieces are basis members of `S` with drop 0 (**Class I**). ∎

**2.4 The `s = 6` scenarios (R1′).** For `s = 6`: `x = 0`, `c_8 + z ≤ 1`.
(α) `z = 1`: equality in 2.1 forces `z_0 = 1` (the alternative would give a basis vector proportional to a single `δ_t`, impossible), so `B_0 = {δ_f}` for a frame line `f`, `F` is a minimum basis of `ρS`, `Δ = 6`, `D = 1`, all other members drop 0: **Class I with one extra line `f`**.
(β) `z = 0`, `c_8 ∈ {0,1}`, `Δ + D ≤ 7`: (β1) `Δ = 6, D = 0`: Class I as in 2.3; (β2) `Δ = 6, D = 1`: one member `b*` drops (it is a non-`T` member, or the unit, or a piece of weight `w` whose lift has E8 weight `w+1`); (β3) `Δ = 7, D = 0`: (β3-i) `F_T` is a basis of `T` of total weight `κ+1` (one piece one heavier), or (β3-B) one weight-7 piece is missing and `d` drops by one.
*Use in this note:* a cell with `s = 6` is declared dead only if **all** of the following variants are dead (kill engine `scen()` in `checks/rrc_audit.py`): the base cell; the base cell with every cap raised by 1 (extra line `f`); for every weight `x` present, the cell with one piece of weight `x` replaced by `x+1` (the dropping member); and, if a 7 is present, the cell with one 7 removed and `d` lowered by 1. The audit verified the scenario list as complete (Gale dominance) for the `s = 6` rows and found that the original script's `robust6` helper accepted a variant without testing the base configuration; the shipped engine tests the base cell too, and no result changes. For `s ≤ 5` no scenario analysis is attempted: those rows are killed only by the `T`-level Lemma P (§5).

## 3. Circuit Lemma (R2)

Let `q_1..q_a` be a minimum basis of `T`, `supp q_j ⊆ Λ(F_j)`, `dim F_j = w_j`, and `R := {c ∈ K^a : Σ c_j q_j ∈ 𝒞}`. As the `q_j` are independent, `c ↦ Σ c_j q_j` is injective and `dim R = dim D = d`. Define `h(c)` by `Σ c_j q_j = p_{h(c)}|_{P112}`; `c ↦ h(c)` is linear and injective (`p_h ≠ 0` for `h ≠ 0`).
**Lemma.** For `K ⊆ [a]`, `\|K\| ≤ d−1`: `{c ∈ R : c|_K = 0}` is the kernel of `\|K\|` linear conditions on a `d`-dimensional space, so has dimension `≥ d − \|K\| ≥ 1`. A non-zero `c` of it has `Off(h(c)) ⊆ ∪_{j ∈ supp c} supp q_j ⊆ ∪_{j ∉ K} Λ(F_j)`, and `\|Off(h)\| ≥ 53`. ∎
**E8 version (Class I).** If the pieces are basis members `b_j` of `S` with drop 0 and `z = 0`: let `y_j` be the E8 vectors, `supp_E y_j ⊆ Λ_E(F_j)` with `F_j` the label span of `supp_E y_j`, `dim F_j = w(b_j) = w_j` (this is the definition of E8 weight). Then `Σ c_j y_j ∈ S` restricts on P112 to `p_{h(c)}|_{P112}`, as does `p^E_{h(c)} ∈ 𝒞 ⊆ S`; their difference lies in `ker ρ ∩ S = 0`. So `Σ c_j y_j = p^E_{h(c)}` exactly and `Off_E(h(c)) ⊆ ∪_{j ∈ supp c} Λ_E(F_j)`, `\|Λ_E(F_j)\| ≤ g(w_j)`. (With `z = 1`, add the single line `f`.) ∎
**G1 (classical).** `\|Off_E(h)\| = 120 − \|Φ ∩ h^⊥\|`; `Φ ∩ h^⊥` is a closed root subsystem of rank ≤ 7, so `\|Off_E(h)\| = 57` if `h` is parallel to a root and `≥ 78` otherwise. **Consequence:** an element `c` with `cap(supp c) := Σ g(w_j) ≤ 77` has a **root** direction `h(c)`; `\|Off_E\| ≥ 57` always.

## 4. Relative root counting (R3)

**Statement.** Class I (E8 version). `K0 ⊆ [a]`, `\|K0\| = d−j`, `j ≥ 2`, `comp = [a]∖K0`, `cap(S) = Σ_{i ∈ S} g(w_i)` (plus 1 for an extra line `f` where §2.4 requires). Let `F` be a family of `(j−1)`-subsets `M ⊆ comp` with (i) `cap(comp∖M) ≤ 77`, (ii) `cap(comp∖(M∪M')) ≤ 56` for distinct `M, M'`, (iii) `\|F\| > N_j`, where `N_j` = the maximum number of E8 root lines in a `j`-dimensional subspace, `N_1..N_6 = 1, 3, 6, 12, 20, 36`. Then no `S` with `cost_w(S) ≤ 71` and this cell exists. *Immediate rule:* if some `(d−1)`-subset `K` has `cap([a]∖K) ≤ 56` the cell is dead at once (`\|Off_E\| ≥ 57`). For `K0 = ∅`, `j = d` this is the earlier root-count note.
*Proof.* `R_{K0} = {c ∈ R : c|_{K0} = 0}` has dimension `≥ j`; take a `j`-dimensional `R′ ≤ R_{K0}`. (1) For `M ∈ F`, `{c ∈ R′ : c|_M = 0}` has dimension `≥ 1`: pick `c_M ≠ 0`; its support lies in `comp∖M`, so `\|Off_E(h(c_M))\| ≤ cap(comp∖M) ≤ 77`, and by G1 `h(c_M)` is a root direction. (2) The roots are distinct: if `h(c_M) ∥ h(c_{M′})` then by injectivity `c_M ∥ c_{M′}`, and the common vector vanishes on `K0 ∪ M ∪ M′`, so `57 ≤ \|Off_E\| ≤ cap(comp∖(M∪M′)) ≤ 56`, contradiction. (3) So `\|F\|` distinct root lines lie in the `j`-dimensional space `h(R′)`. The root lines in a subspace `U` form a root system `Φ ∩ U` closed under its own reflections, of rank ≤ `j`, simply laced (ADE), with at most `N_j` positive roots (`j=2`: A2 3; `j=3`: A3 6; `j=4`: D4 12 (A4 10); `j=5`: D5 20 (A5 15); `j=6`: E6 36 (D6 30, A6 21); reducible types are smaller since `N_{r1} + N_{r2} ≤ N_{r1+r2}`). `\|F\| > N_j` is a contradiction. ∎
**Finite inputs.** `g` by exhaustive enumeration of all affine flats of `F2^8` against the 120 root classes (`gtab.py`, own E8 model `e8.py`: 1,2,4,8,12,20,36,64). `N_2 = 3`, `N_3 = 6` by exhaustive enumeration of all root-spanned subspaces (`nj.py`: 4900 and 85680 subspaces); `N_4 = 12` likewise (661,542 subspaces; `FULL=1`, log `evidence/logs/nj4.out`); `N_5 = 20`, `N_6 = 36` by the ADE classification stated above (not enumerated).
**Application.** `checks/rrc_audit.py` searches, for every cell, over all multisets `K0` of `d−j` pieces (`j = 2..d`) for a family `F` (greedy, several orders); `verify()` re-checks every certificate (sizes, caps, distinctness, `\|F\| > N_j`) independently of the search. `s = 7` rows: one variant (Class I). `s = 6` rows: all variants of §2.4. Result: `s = 7`: 298 of 404 rows dead, `s = 6`: 89 of 153 rows dead; all 47 class-B rows and all 25 earlier root-count rows are dead (`check_ledger.py`).

## 5. Lemma P and Lemma P′ (R4)

Setting (`T`-level, no scenario): `λ: T → T/D ≅ K^e`, `M` the matroid of `λ_j = λ(q_j)`. For `P ⊆ [a]`, `R_P = {c : supp c ⊆ P, Σ c_j q_j ∈ 𝒞}`, `dim R_P = \|P\| − r_M(P)`.
**Lemma 1 (contraction by small pieces).** Let `S ⊆ [a]` with `Σ_{S} g(w_j) < 53`, `X = ∪_S supp q_j`, `s = Σ_S g(w_j) ≥ \|X\|`. (a) `S` is `M`-independent (a dependency is a codeword supported on `< 53` lines). (b) `n_{M/S}(P) = dim R_{P ∪ S}`. (c) Every circuit `C` of `M/S` gives `c_C ∈ R_{C∪S}` unique up to scalar with `supp c_C ∖ S = C`; distinct circuits give distinct direction lines `h_C`, and `Off(h_C) ∖ X ⊆ ∪_{j ∈ C} Λ(F_j)`.
**Lemma 2 (plane lemma).** A minimal `P ⊆ [a]∖S` with `n_{M/S}(P) = 2` has circuits exactly `C_i = P ∖ K_i` for the `t ≥ 2` parallel classes `K_i` of `N^*` (`N = (M/S)|P`), whose `t` direction lines are distinct and lie in the 2-dimensional space `h(R_{P∪S})`. **Fact E:** the roots in a real plane form A1, A1×A1 or A2, so a plane holds `≤ 3` E8 lines, `≤ 1` frame line if it holds an A2.
**Fact D (direction list; proof of completeness in `dirs.py`'s header: rank-7 perps are `h` of norm `≤ 16`, rank-6 perps are root-spanned planes, rank `≤ 5` perps force `\|Off\| ≥ 92`).** All directions with `\|Off\| ≤ 89`: 112 roots (53), 8 frame (56), and **21,340 non-E8 masks** in 17 orbits of the frame stabiliser (sizes 70 … 89; CHECKED: `dirs.py`, `mkreps.py`). *Correction:* the original text claimed no `Off` of 89–91 lines; in fact one orbit of 3584 directions has `\|Off\| = 89` (e.g. `h ∝ (3,0,1,0,1,0,1,0)/2`). It is harmless: the bound needed is `\|Off\| ≤ 80 + s ≤ 89` for four ≤6-flats plus `X`, and four 6-flats cannot cover 80 of those 89 lines (the exact covering run has no leftover of `≤ 9` lines for this orbit; `facts_check.py`).
**Lemma P.** Let `S` be as in Lemma 1 with `s ≤ 9`, `e′ = e − \|S\|`, `Q` = pieces outside `S` of weight `≤ 6`, `m = \|Q\|`. A 3-circuit of `M/S` in `Q` is *special* if its direction is a root (not frame), an *other* 4-circuit has a non-E8 direction; `σ ≥ #special 3-circuits`, `ω′ ≥ #other 4-circuits` (valid for every admissible `X`, from the covering facts). **(L1)** `e′ ≤ 2`, `m ≥ 4`: impossible. **(L2)** `e′ = 3`, `m ≥ 5` and either `C(m,5) > σ·min(7+σ, 3(⌊(m−1)/2⌋−1)) + ω′(m−4)` or (`ω′ = 0` and `m − σ ≥ 5`): impossible.
*Proof.* No loops or 2-circuits (caps `20+s`, `40+s < 53`). A 3-circuit has cap `≤ 60 + s ≤ 69`, so by Fact D its direction is a root or a frame line (frame: ≤ 8 distinct). A minimal `P ⊆ Q` of nullity 2 with `\|P\| ≤ 5` is one of: (I) `\|P\| = 4`, four 3-circuits, four E8 lines in a plane (contradicts E); (II) `\|P\| = 5`, classes (2,2,1): two 3-circuits through `x` and a 4-circuit, not both 3-circuits frame (A2 holds ≤ 1 frame line), so one is special; (III) one 3-circuit + three 4-circuits; (IV) five 4-circuits: ≥ 4 directions in a plane hold ≤ 3 E8 lines, so some 4-circuit is other. (L1): any 4 pieces of `Q` have nullity ≥ 2 (rank ≤ 2), only (I) remains. (L2): every 5-subset has nullity ≥ 2 and is of type (II) with a special 3-circuit (determined by a pair of 3-circuits: ≤ `σ·min(7+σ, 3(⌊(m−1)/2⌋−1))`) or contains an other 4-circuit (each lies in `m−4` five-subsets); counting gives the inequality; the hitting form deletes one piece from each special 3-circuit. ∎
**Lemma P′ (weighted count; replaces `ω′(m−4)` when `ω′ > 0`).** Let `rank_{M/S} Q = 3` (else L1). The triples are lines of a linear system, `n_3 ≤ ⌊m⌊(m−1)/2⌋/3⌋`. Weight each 5-subset by a lower bound on the number of other 4-circuits inside: type IV `≥ 2` (5 directions in a plane, ≤ 3 E8 lines), type III `≥ 1`, type II `≥ 0`; ≥ 3 triples in 5 points are impossible. With `A = #III`, `B = #II`, each triple in `C(m−3, 2)` five-sets: `ω′(m−4) ≥ 2C(m,5) − n_3·C(m−3,2)`. For `m = 10`: `6ω′ ≥ 504 − 273`, `ω′ ≥ 39 > 32`. ∎ (The brute-force check of the extremal inequality over 3000 random maximal triple systems is not re-run here.)
**Parameters `(σ, ω′)` (`lemp_audit.params`; each backed by a covering fact, §7).** `X = ∪_S supp q_j`: `s ≤ 3`: `(s, 0)`; `s = 4`: `(4, 0)` if `Σw ≤ 3` else `(5, 0)`; `s = 5`: `(9, 0)`; `S ∈ {{1,1,3},{2,3}}`: `(34, 0)`; `S = {4}`: `(9, 0)` or `(9, 32)`; `S = {1,4}`: `(17, 0)` or `(17, 32)` (both cases must kill). The audited engine applies L1/L2/P′ to **all 603 rows** (not only class A): **375 rows are killed** (125 by L1, 250 by L2/P′), including all 74 original class-A kills.
**D7 plane fact (CHECKED, exact rational arithmetic, `d7plane.py`).** The 32 directions served by one D7 8-set lie in no plane with a third of them, and a plane through two of them holds 0 (384 pairs) or 2 (112 pairs) E8 lines. (Not used by any kill; kept as the supporting fact for the open `[7,6^8,4,4]`-type rows.)
