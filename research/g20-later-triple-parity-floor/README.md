# Later G20 triple capture loses more than 13/2

On the fixed PR5708 word, capturing helpers **{297, 465, 591}** with later
reinjection at events 6292, 6296 and 6622 cannot improve the local BIT bill.
All delivery, restoration and ownership costs may be granted free. For every
saving `0 <= C <= 0.01`, the removed paid tariff minus the surrendered target
tariff is strictly below **-13/2**.

Claim type: scoped proof with an exact finite certificate. No new kappa.

The new step enforces consistency among all three injected payloads. An exact
parity relaxation has maximum removed rank 13, against target ranks 8, 4, 8.
Choosing the best response for each dependence class separately would give 20;
those responses cannot all come from one choice of the three payloads. The
parity maximum is attained in the relaxation, with query ranks 1, 5, 5 and 2.
Native attainment is not claimed.

[PROOF.md](PROOF.md) states the candidate contract and proves the reduction.
[RESULT.json](RESULT.json) is generated by [verify.py](verify.py). Two finite
oracles agree: 834 small basis candidates and every one of the 131,072 equation
subsets. The result settles this first triple continuation of the proposed
joint-dead pair {297, 465}; it leaves other capture schedules open.

## Sources and limits

The question is PR6117's first Open next question, by Jerry Chen / CubeJerry.
The candidate extends Matarener's PR6113 joint-dead pair under the B1 capture
model. Their native word, semantics and existing results are cited premises,
not review targets. Canonical main is
`7c49fe32c55de02c2c873655c804b16e4c3fef0a`, priority revision 8. Exact source
pins and predecessor provenance are in [SOURCES.json](SOURCES.json).

Only this fixed schedule, complete target surrender, native permutation-linear
payloads and zero-payload call deletion are covered. Arbitrary public inputs
remain independent outside the three surrendered helpers. Other replacement
times, added injections, rank lowering of nonzero queries, changed words and
supplier admission remain open. All five framework assumptions remain. The
selected frontier is unchanged. Independent human and formal proof-kernel
review are unclaimed.

Live open PRs and claims, current-main text, merged PR searches and the task
overlap helper were checked. The overlap helper reported complete remote
pagination but sparse local-note coverage, so a lack of hits is not a novelty
certificate. The advance [CLAIM](https://github.com/CrocSwap/integer-mult-bounds/discussions/1166#discussioncomment-19358884)
planned a wider triple search. Work stopped at this first original obstruction.
