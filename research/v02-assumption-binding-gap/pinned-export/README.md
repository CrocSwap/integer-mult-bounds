# V02 compiler-input and lookup evidence archive

This source archive makes a completed static prerequisite inspectable. It contains
471 conservative compiler-input metadata rows, a retained 6,424-name lookup frontier,
and two explicit finite filesystem graphs. The portable check reproduces the
354 declared-file / 6,070 first-missing lookup partition and 12 literal specs
first-missing results in both graphs. The census plan adds two files without changing
any of those outcomes. This is a finite graph result conditional on the retained
frontier and configuration assumptions.

The original V02 task remains incomplete. This archive admits zero C05 input
sets, zero original decisions and zero of the eight required omission cases.
It establishes no installed namespace, actual compiler selection, original command
execution, performance improvement, theorem, or selected-frontier adoption.

## Files and source identity

`FIXTURE.json` is the public replay input. It preserves candidate sizes, modes,
SHA-256 values, graph node metadata, raw lookup components, and the 56 inherited
configuration assumptions. `literal_walk.py` retains the exact pure function body
from the original observer. `verify.py` adapts the existing projected join and
census-equivalence checks to this self-contained export. It does not import or run
the original observer, collector, compiler, or source scanner.

`SOURCE_MAP.json` records eleven original artifact paths, byte counts and SHA-256
pins, their extracted fields, upstream base and predecessor heads. Those original
archives are external provenance, not public replay inputs. There is no public
fetch contract for the omitted archives. Re-deriving the source scan or checking
the extraction independently requires an author-provided copy matching those pins;
the package does not imply that those private records are available upstream.
The public finite replay needs only the files in this directory and Python's
standard library.

`EVIDENCE.json` preserves selected historical findings. Its original outcome hash
is for the original unrelocated paths and is not the public fixture's outcome hash.
`MANIFEST.json` gives exact public file paths, byte counts and SHA-256 values. The
manifest does not authenticate itself; bind it to the reviewed upstream commit.
This is an archive format, with no registered `VERIFY.json` replay hook.

`/home/fixture-user/.fixture/fixture-projects/project-v02` at the same depth.
Explicit ancestor nodes and absolute symlink targets use the same substitution;
relative symlink targets and all subsequent components are unchanged. Raw `..`
components are preserved. This is logical graph relocation, not a claim about a
real filesystem at the public prefix. System paths are retained as graph labels.

During export, the exact pinned original pure walker was evaluated on all 6,424
ordinary names and 12 specs names in each original and relocated graph. All
12,872 comparisons commuted with the path substitution. `SOURCE_MAP.json` records
that export-only check and the mapped outcome hash. Public replay checks the
exported fixture; it cannot repeat original-to-export comparison without the
external original JSON artifacts. The relocation and new replay receive their
own review rather than inheriting acceptance of changed bytes.

## Reproduce the public check

From the repository root, with Python 3.12 or later:

```sh
python3 -I -B research/h25-v02-compiler-input-evidence/verify.py
python3 -I -B -O research/h25-v02-compiler-input-evidence/verify.py
```

Both commands check archive integrity, the 471 unique candidate rows totaling
99,377,921 bytes (largest row 30,487,984), baseline 749 nodes / 638 regular files,
census 751 nodes / 640 regular files, unchanged baseline nodes, and exactly the
two declared census additions. They then replay both graphs and reject an earlier
PCH file, an earlier PCH directory, a near quote-origin shadow header, and omission
of the specifically named gconv cache row. The first three graph controls adapt
the retained projected-join controls. The fourth is a new metadata guard for a
historically observed missing-input failure, not a replay of that failure trace.
Explicit exceptions keep these checks active with `-O`.

The verifier reads only this package's files. It never opens graph-named host
paths, starts native tools, writes artifacts or observes a mount namespace.
Keep the package stable while checking it. It verifies source bytes before
compiling just the pinned pure walker function, rather than loading local bytecode.
