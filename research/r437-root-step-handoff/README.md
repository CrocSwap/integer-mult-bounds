## Exact arithmetic and edge proof

Let

```
N = product(q^64-q^i, i=0..63), H = q^4096,
A = 28416*N*H,
D(n) = 0 if n<64, otherwise 1+D(42*floor(n/64)).
```

The executed `numerical.check_root_domain` checks the exact original-root
precision inequality `(w-1)^10000 < e^17 <= w^10000`, chronological bound and
canonical L/I/Q. Prime and source admission are checked independently. No call
to `checked_entry` is claimed: that wrapper requires a concrete integer stock.

Choose the retained conservative root contract `R=(9475*A)^D(2048)`. The supplied
symbolic `U=9475^D*A^(D-1)` satisfies **exactly** `U*A=R` and is divisible by 9475.
This authenticates the conditional `unused` premise; `prepare_child` does not
compute it and `SelectedBinding.check_stock` does not supply a proof of it.
The local row divisor comes from retained `fresh_rows.quotient`; no source guard
is weakened. Monomials `[c,a,b]` denote `c*A^a*q^b`; matching exponent/coefficient
identities are sufficient exact equalities, not a claimed globally unique integer
factorization.

**Nick Petalas's already-main #3246** establishes the sharper sufficient stock
`9475*A^D`. That theorem is **not new here**. The verifier keeps it separate from
the stronger old-entry divisor: at this depth its coefficient lacks the old
`9475^D` divisor. It does not claim that old `checked_entry` admits sharper rows.
This package instead answers the actual Program/capsule question requested by
**Mihir Srivastava's #4685 / #4682 arithmetic handoff**.

Since `floor(2048/64)=32`, the actual good event has

```
a = 0, b = (2*64-2)*32 = 4032, c = 2*32 = 64, total = 4096.
```

There is no embedding remainder. The two selected chunks are `[0,64)` and
`[4032,4096)`. Their complete spectators are

```
B' = 2, G' = 3*(q^2)^3968 = 3*q^7936, S' = 5.
```

All 3968 unselected atoms and the external gap appear exactly once, and
`B'*G'*S'*(q^2)^(2*64) = 30*(q^2)^(2*2048)`. U remains a separate factor.
With B=2, confusing `leading=2*U` and `unused=U` is observable. Doubling U remains
locally divisible but fails **exact parent/child quotient equality**.

### Bounded codec ordinal-count adapter

The original GL codec enumerates `range(value)` while ranking and `range(q)`
while unranking. Common preparation inverse entries may be `q-1`, so literal
q127 enumeration is not feasible. Only these candidate-count loops are replaced;
original `Constraints`, source tags, matrix/range guards, encode/decode and outer
mixed-radix rank/unrank are retained. This is **harness count arithmetic**, not a
claim that the original implementation runs at q127. Its identity is the emitted
package `verify.py` hash, distinct from the unchanged catalogue identity (which
hashes original file bytes). Exact codec results are memoized; authentication is
not cached or bypassed by the harness.

For one column let `T=q^(dimension-column-1)`, and let C(t) count admissible
candidates with value `<t`. Summing the original `Constraints.excluded` gives:

* already inconsistent: `C(t)=t*T`;
* pivot exists: `C(t)=t*(T-q^(len(rows)-len(basis)-1))`;
* no pivot: `C(t)=t*T - [rhs<t]*q^(len(rows)-len(basis))`.

Rank adds C(value) and calls the unchanged `choose`. Unrank finds the first
endpoint `t` with `C(t)>ordinal`, chooses `t-1`, and subtracts C(t-1). The strict
upper bound skips zero-count plateaus. Each step checks `0<=ordinal<C(q)`;
final rank-zero/independence guards are preserved. Thus induction over columns
and unchanged mixed radices gives the same GL ordinal, not a new codebook.
Permanent finite-q comparisons enumerate every independent row prefix in
GL2(3), every candidate next row and every ordinal, including dependent rows,
invalid endpoints and zero-count plateaus. The actual q127 low matrix also
round-trips through encode/decode. These tests support, not replace, the formula
proof.

## Permanent rejection controls

* Valid other replica with original request key; native/common mismatch; stale
  source identity; foreign Specifications catalogue.
* Equal-byte but distinct parent Program object, changed event source,
  width or depth; below-cutoff false recursion from an actual emitted event.
* Serialized rank, source code, parent/child width, field, root size, root unit
  and history changes, including the predecessor-shaped `64→2` confusion.
* Child-reset precision, root-index reset and changed root prime/domain.
* Doubled child rows; leading substituted for unused with B>1.
* Missing/doubled external gap, omitted unselected atoms, lost before or suffix.
* Exact source SHA/Git bindings, mapped closure conflicts, links and extra/missing
  historical inventory fail closed before imports. Receipt comparison cannot
  authorize a mathematically rejected edge.
