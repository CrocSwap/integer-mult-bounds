## What the additional controller rounds established

The first exact search lets the old global controller omit selected idle
windows and then changes its constant boundary bases. It tests formal
coefficient matrices, not sampled numerical operators. For two through six
pairs, the complete paired-window survivor counts are 3, 8, 20, 48 and 112.
All 192 survivors across one through six pairs lift to exact signed Laurent
identities for the complex construction; no reduction modulo an operator order
is used to justify that lift. The best BIT member is the three-pair case with
keep mask 43. Simply extending the path to more pairs does not improve it.

A broader three-pair probe separates the two fields of each idle window:
4,096 choices give 64 exact factorizations, including 56 asymmetric ones. A
second probe allows independent stage projectors and tests all 123,904 complete
compatible choices in its stated family. It recovers the old best all-fresh
three-pair bill, rather than a new saving. These are scoped exhaustive results;
they are not lower bounds for all possible global controllers.

The actual PR589 state-sharing probe examines all 96,141 helper pairs. Only
five pairs have compatible full monotone frame timelines. Two cause a

No pair has disjoint forward lifetimes. Separately, both the nine center
producer signals and their consumer matrix have rank nine. A same-cut
eight-signal compression therefore fails before transport and cleanup costs
are considered.

## A real cheaper local primitive, and its remaining global debt

Removing the nine old copied centers and rebuilding dirty compensation gives
an actual clean response

\[
J=I+UV
\]

over `F2`, with `V` the nine center producer rows and `U` their actual scatter
map. Select nine source coordinates `A` for which `V_A` is invertible and set

\[
M=V_A^{-1}VU,\qquad U'=U+E_A M,\qquad H=I+U'V.
\]

Then `VU'=0`, hence `H^2=I`. Only nine output rows are corrected. Each query is
gathered from unchanged completed source arrays, moved through its selected
rank-one target hole, read, and erased under the inherited owned-stream
contract. The complete local bill becomes

\[

\]

with rank mass 5,075, saving 54 from the old 5,129. The native word has 11,955
ADDs and one owned stream reused nine times. Both orientations restore all
439 arbitrary helpers. Its common-frame involution has a three-shear
implementation of only `474 + 504 + 474 = 1452` ADDs. A separate independent
audit in `../transfer-audit/h-branch/` reconstructs the matrices, every frame
rank, all 661 input columns and the owned-erasure model.

The further minimum-completion probe observes that `rank(J)=108`. It changes
only rows `106,109,110`, replacing them by source coordinates `0,1,2`, and
obtains an invertible `G`. Three changed rows are optimal by the elementary
rank bound. This costs only three new rank-one gathers, giving rank mass
5,069 and 11,625 local ADDs. Forward common-frame wrappers use `G`; reverse
wrappers use `G^-1`. Four literal native replays check the plain and wrapped

The separate `BIT-MINIMUM-COMPLETION-AUDIT.json` in
`../transfer-audit/h-branch/` independently reconstructs the completion,

line-to-hyperplane contacts; all four native variants pass.

Neither local improvement is advertised as a new global supplier. The exact
noncommuting three-pair controller produces three interval products, for
stages `(0,1,2)`, `(4,5,6)` and `(0,...,6)`. One bank of each pair can erase its
remaining product by costed scalar/cover operations. The other has a

Both direct constructions fail even at exponent zero. These receipts prevent

The next useful larger-gain question is therefore whether the three actual
