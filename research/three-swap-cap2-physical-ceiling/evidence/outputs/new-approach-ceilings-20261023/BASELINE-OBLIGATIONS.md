## Screening quantities and types

Declare an exact domain `D=[a,b]` with `0<=a<=b<1`. Write
`H_r(C)=r^(1-C)` for positive integer **recursive-child rank**, and `H_0=0`.
For an actual complete independent productive inventory T and complete paid
recursive inventory P,

```
T_t(C) = sum_r T[r] H_r(C),  P_t(C) = sum_r P[r] H_r(C),
M(C) = T_t(C)-P_t(C).
```

Each credit needs a distinct arbitrary original input, the complete requested
endpoint, an autonomous whole-job normalization, and all-positive-column lifting.
Correlated contents in distinct physical owners are allowed; duplicated inputs,
owned zeros, scratch, intermediate outputs, copied sources and erased fields earn
no extra productive credit. Helper owners are retained once, not replaced with
an average rank or recredited at each transport.

Every charge carries dimension type, multiplicity, owner/occurrence identity,
orientation, entry/exit charts and the actual child ABI. Scalar projector rank,
address rank, owner count, field volume, column multiplicity, and recursion rank
are different dimensions. An owner-rank-two invocation is not priced as H_2
unless a source-bound physical reduction proves that exact recursive call.

A legitimate reward upper bound U and recursive-cost lower bound L give

```
T_t(C)<=U(C),  P_t(C)>=L(C)  =>  M(C)<=U(C)-L(C).
```

The inequalities must hold simultaneously for the declared candidate and C.
A speculative target profile without a proved inventory can be used only as an
explicit optimistic premise of an exclusion. It supplies no admitted positive
moment. An implementation's constructive upper bill is not a lower bound on all
other implementations. A lower bound can reject only the policy/class whose
assumptions establish it.

Point enclosures apply at that point. For a nonnegative rank histogram, H_r is
nonincreasing in C, so on [a,b] a valid interval exclusion is
`M(C)<=upper(T_t(a))-lower(P_t(b))`. The difference M need not be monotone.
Unknown credits/costs are never replaced by zero to issue an admission decision.

## Required reserve before a retained-route GO

A positive raw M is only the first screen. With a declared source contraction
reserve e>0, the retained first-ratio test is **strict** `P_t/T_t<1-e`.
Thus a necessary optimistic condition is

```
L(C) < (1-e) U(C),
R_e(C) := (1-e)U(C)-L(C) > 0.
```

If R_e<=0 the specified reserve cannot pass. If R_e>0 this lower/upper screen is
inconclusive: it does not prove the true inventory ratio or either paid tail.
For uniform exclusion, use `(1-e)upper(T_t(a))-lower(P_t(b))<=0`.
This reserve-adjusted screen is stronger than merely bounding M by U-L.

When a changed caller has exactly the same **proved complete** target inventory
as a pinned baseline, and its total paid change is a saving G(C), the exact
first-ratio gate is

```
P_new=P_old-G,
G(C) > P_old(C)-(1-e)T(C).
```

This uses the actual invoice, not the distance between raw crossings. Changed
helper returns, autonomous output counts or ranks invalidate target cancellation.
