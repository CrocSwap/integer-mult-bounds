   The complete T74 invoice with the edited providers equals PR3021's profile.
2. Map each old call time `t` to `2t+c` and replica `r` to `r+74c`, for
   `c=0,1`. Each replica projects to the same nine source stages. Exact doubling
   alone leaves the normalized moment unchanged. Apply PR3022's 86-row journal
   only after that lift. Full geometry checks every resulting role, source
   window, family exclusion, mask and compact prefix.
3. R1 changes the local per-call profile by `-2 H1 + H2`, without changing the
   ordered helper widths. It therefore composes with the owner journal. The
   geometry checker recomputes the sum of actual local calls
   and actual idle remainders; it does not infer that sum from rank mass.
4. With `H_r(b)=(r/73)^(1-b)`, compare the complete moment divided by `896T`.
   Directed integer intervals certify both endpoint signs. Every child rank
   is below 73, so this moment is strictly increasing and the bracket isolates
   its unique root. The new root exceeds PR3021's by between
   `1.1331599399226515e-9` and `1.1331599399226517e-9`. This interval is for the
   composed edited words, not PR3022's unedited-word interval.
5. Replica-dependent costs are not held fixed. Live families increase from
   66,304 to 132,608; complete physical families increase from 66,813 to 133,117.
   The serial scratch namespace remains 408 reserved helper tableaux,
   8 centres, 91 private buffers and 2 coefficient families. Both 1,332 local

6. Compute the group exactly as
   `|Sp(72,2)| = 2^1296 product(j=1..36, 2^(2j)-1)`.
   The physical-stock bit length increases from 2644 to 2645, so the charged
   stock-to-L2 exponent increases from 1322 to 1323. The conservative prefix

## Limits and engineering notes

This is a finite conditional construction, not a complete multiplication
proof, practical speedup, independent human review or selected-frontier update.
All-size/compiler, physical backing and movement, precision/fixed-tape,
analytic transfer and universal block-energy obligations remain inherited.
Replica-dependent storage doubles; this is not a storage-saving claim.
There is no integral-optimality claim. PR3024's T740 cap attainment and its
active R1/admission follow-up have a different, larger-stock scope. They are
not preempted or validated here.

The new code has bounded input counts, finite bisection and source-authenticated
imports. Retained kernels execute compiled authenticated source bytes rather
than possibly stale default-import bytecode. Python requires managed allocation.
Geometry limits live collections to 1,332 calls, 543,456 roles and 298,368 bins. The three retained import targets
are fixed by hashes. Existing source exporters and native validators retain
their original assertion and dynamic-code mechanisms rather than undergoing an
unrelated rewrite. Full stages have a 1,800-second timeout with process-group
cleanup; the registered finite commands have 120-second limits. These are
bounded research-runtime deviations from fixed allocation and direct dispatch.
Future changes to the source interface must revalidate those bounds and pins.
