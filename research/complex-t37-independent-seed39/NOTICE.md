`VENDOR-PINS.json` identifies every selected unmodified vendored file and its
source PR head. This is a selected subset, not a copy of PR870's whole package.
`data/ADAPTER-EDITS.json` gives every literal before/after source edit and its
required multiplicity. The generated runtime retains the upstream notices.
`DEPENDENCY-PINS.json` pins the existing replay drivers/manifests and direct
dependencies. Their full source and artifact checks run through the retained
ancestral verifiers. `MANIFEST.json` binds this package, including all data and
proof-relevant source bytes.
