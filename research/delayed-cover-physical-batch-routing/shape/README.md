# Physical child grants connected to the whole-high router

This prototype removes the two external child-shape grants at one physical
PR6719 continuation boundary. A fixed finite nine-tape table reads binary
parent A, common H and parent R headers, computes A_child=A/(L*H) and
R_child=H*R without host arithmetic, and erases all conversion work. A linked
literal table immediately feeds those generated descriptors to the unchanged
child splitter. Its payload is one complete parent bank of size V/L.

One real B2/GL1(F3),w2,L4,H3 case runs that table through the retained3-bit codec
and full physical continuation. It generates both grants before suspension,
executes two changed child returns, restores parent/input headers and erases
all owned copies, grant backing and scratch. It uses28 fixed physical tapes.
This is a one-edge bit-complement fixture. H-from-width, numerical ancestor
weights, arbitrary-depth production, Gaussian children and a multiplier are
not claimed. See [PROOF.md](PROOF.md) for exact quantified interfaces and bills.

The contribution is source-bound physical glue, not new generic arithmetic.
PR5829 supplies the batch map; PR2776 the unchanged finite machine/counter;
PR6719 exact head a7a22201327689fc81496cf031d68e53283fef49 the router and codec/
stack runtime. Existing selected-binary-control and R437 quotient work already
cover generic binary arithmetic and numerical descriptor predecessors. All
exact source commits, blobs and SHA256 are retained in SOURCES.json.

Run with standard-library Python3.12:

    python3.12 -I -B verify.py
    python3.12 -I -O -B verify.py

Default runs are readonly and compare RESULT.json. `--write` is explicit receipt
authoring only. Copy this entire directory unchanged: all source reads/imports
are HERE-relative, with no Git/network/workspace dependency. The verifier
authenticates every source copy before scientific imports.

New code: producer.py (finite assembler and direct linker), bridge.py (fixed
codec port adapter), verify.py (separate numeric oracles and physical observer).
