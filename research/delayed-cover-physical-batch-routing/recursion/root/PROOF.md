# Natural-root physical descriptor production

## Statement and attribution

Fix integers L>=2, odd q>=3 and N>=1 before execution, and put b=q^(N*N).
The actual complete cover further specializes L and q as described in the
retained delayed-cover bridge. Runtime inputs are positive canonical physical
binary packets T, R_body and w, a readonly unary string of d>=0 ones, and an
arbitrary complete payload of the promised length. Define only for the proof

    H=b^(w-1), g=L*H, A_k=T*g^k, R0=H*R_body,
    V0=L*A_d*R0.

The executed machine is not supplied A_d, R0 or H. It receives no decoded
descriptor, host product, host power, child grant or continuation. It produces
those three headers, invokes the exact retained recursive mechanism on them,
and erases the generated root headers at completion. Original T, R_body, w,
the unary depth string and the original payload remain unchanged, including
their original head positions. The output is the same complete packet as the
retained two-call-site recursive bit grammar on these shapes.

The retained generic arithmetic, binary-to-unary counter, codec, physical
stack, protected return, and #5829 whole-high address identity are predecessors,
not new arithmetic theorems. The bounded new connection is producing the
actual root shape from T/R_body/w/depth and handing it to the unchanged
all-depth machine in literal finite control. This is not a Gaussian/BIT child
or a complete multiplier and changes no paid profile or kappa.

The recursive builder and its sealed table under inputs/core were newly
authored in this submission's earlier private freeze; they are NOT asserted
to be files in the 3bad Git tree. CORE.json binds their exact private manifest.
Only the eight upstream inputs in the retained SOURCES.json have the stated
3bad tree/blob provenance. No scientific admission is inherited from a seal.

## Literal prefix and unchanged core

The old table first computes H from physical w using its existing finite
constant-b multiplier. The old jump immediately after that work is redirected
to the appended root prefix. The prefix copies T into owned root A and copies
H into the otherwise empty reserved return role. Applying the existing
finite-carry constant-L multiplier to that copy yields a dummy header g=L*H.
The H header is restored to its exact body origin and remains immutable.

The unchanged nine-port shape producer, on inputs (A,H,R), returns the actual
binary packets (A/(L*H),H*R) on its exact-divisibility domain. Give it the
dummy A=g. Its first output is therefore exactly one, and its second is H*R.
This is a literal use of the emitted counter/quotient/product loops, not a
new variable-multiplication primitive. All distinct input/output/work ports
remain distinct. After each use, the quotient and four guide/work banks are
physically retired, including the real 000 backing of coded logical BLANK.

First use R=R_body to produce owned root R0. Then read each physical unary
depth mark once. Given owned A=A_k, invoke the same producer with R=A_k to
produce H*A_k in the separate grant-R role. Retire old A, copy this result
back, retire the temporary, and execute the fixed-L multiplier. The next A
is exactly A_(k+1). After d marks the machine rewinds the unary depth head,
retires dummy g, and enters the original node-entry label with exactly the
original core's expected A_d/R0/H packets and no other live owned payload.
The original T and R_body are readonly packets on two added tapes. Their
heads are restored explicitly after each borrowed raw copy.

For L=4/q=3/N=1, the new program has 31,821 literal instructions on 27 tapes.
The retained program has 20,897 instructions on 25 tapes. Static comparison
checks every retained instruction and permits exactly two changes: old PC1861
(the post-H entry jump) and PC20895 (the final halt). The former calls the
appended prefix, whose halt is statically linked back to old node entry 1862.
The latter calls appended root-A/root-R retirement. Every recursive node,
generated child grant, suspension, child output protection and return remains
the identical old instruction. The two extra tapes are outside all frames
and the old core never addresses them. No per-depth tape is added.

At final root return the unchanged core erases H. The new final suffix then
physically erases generated root A and R and restores their head origins.
They are owned descriptors, not independent supplied inputs or productive
targets. No zero-value erasure premise is used. Original binary T/R_body
packets survive, as do the original width, depth and payload.

## All-depth shape and address consequence

Induction on the prefix loop proves A=A_k after k unary marks and proves its
termination on every finite unary d. The retained all-depth proof then applies
without changing its domain: at node depth j,

    A_j=T*(L*H)^(d-j), R_j=H^(j+1)*R_body,
    V_j=L*A_j*R_j=V0/L^j.

Every child grant is generated on path from that node's actual live A_j/R_j.
The complete parent high coordinate remains inside R_child=H*R_j. Writing
a_parent=(a_child*L+l_child)*H+h_child gives the exact address equality

    a_parent*R_j+r_parent
      =(a_child*L+l_child)*(H*R_j)+h_child*R_j+r_parent.

Thus this prefix does not merely arrange equal volumes. It supplies the exact
domain for the retained split/merge, ancestor isolation and output-before-pop
induction. The two statically named child sites and the bit-complement leaf
remain a scoped grammar, not an assertion about the final Gaussian template.

## Explicit root-prefix cost

All following costs include setup, source restoration and physical retirement.
The source producer code gives, for S=A+H+R and Kp=H*R,

    T_product <=48*S+32*A+10*H+24*Kp+46.

This follows directly from the retained <=44*x binary-to-unary converter,
<=18*k amortized binary increments, one quotient scan, the complete H-by-R
scan, and the guide/work cleanup. It is an upper bound on actual logical
microinstructions, not a fitted fixture counter. Here A=g in every product,
so the displayed expression is

    80*g+58*H+48*R+24*H*R+46.

The existing stateless codec uses at most 32 physical instructions per logical
instruction. Subsequent raw retirement covers the coded 000 backing rather
than treating logical BLANK as physical blank. The five local retired regions
have total extent bounded by a fixed multiple of g+H+R+H*R+1. Raw copy,
retirement and marker restoration each need fewer than 128 microinstructions
per participating position. A fixed-L multiply scans binary digits and
finite carry, costing at most (20+20*ell(L))*(ell(input)+ell(L)+1) logical
instructions; this deliberately bounds each body/carry/rewind transition.

Crucially the repeated root products are not billed as d copies of V0.
For d>=1 and g>=2,

    sum_(k=0..d-1) A_k <=A_d/(g-1),
    H*sum_(k=0..d-1) A_k <=A_d,
    d*g <=g^d <=A_d, and d*H<=d*g.

The second inequality uses H/(L*H-1)<=1. The third follows from
d<=g^(d-1), by induction. These inequalities separately pay for every
repeated conversion of dummy g and H, every input-A conversion, and every
actual H*A product. All binary lengths are bounded by their positive values;
the constant-L multiplication scans and its carries are consequently bounded
by O((ell(L)+1)*A_d) over the whole loop. For d=0 the loop is absent and
these empty sums are zero, so no inequality involving d*g is needed.

The single root-R product costs O(g+H+R_body+H*R_body). The initial g/T
copies and the final A/R erasure cost only their actual binary extents.
A_d,R0,T,R_body,H,g<=V0, including d=0. The inherited once-only H-from-w
generation costs O((ell(b)+1)*w^2), and w^2<=2*b^(w-1)=2H for b>=3.
Thus its real unary guide and physical cleanup are also covered by V0.
The unary depth and both new input headers are charged: d<=A_d for d>=1,
ell(T)<=A_d and ell(R_body)<=R0. Empty depth has only its fixed marker.

Let k=max(16,L+11), e_b=ell(b), e_L=ell(L). Directly enlarging the above
scan bounds gives the following intentionally coarse explicit constants:

    C_root=10^8*(k+e_b+e_L+1),
    S_root=1000*(k+e_b+e_L+1).

These bound the new root setup, inherited H setup and final cleanup by
C_root*V0 microinstructions and S_root*V0 visited/retained positions. For
space, only fixed many guides, binary packets, dummy g and a single product
exist at once; their aggregate extent is O(k*(g+H+A_d+R0)), plus the already
charged input backing. Sequential loop iterations reuse these same suffixes;
erasing cells does not subtract them from the retained-space bill.

Together with the separately retained core constants C_core and S_core,

    time <=C_root*V0+C_core*(V0+sum_actual_nodes V_node),
    local backing <=K_entry+S_root*V0
                     +S_core*sum_(j=0..d) V0/L^j.

The coarse core term already allows its old H setup; counting it a second
time is a valid overestimate. The complete time is not 94*V0 and need not be
linear for a different final template's number of recursive sites. The two
sites here give sum_nodes V_node=V0*sum_(j=0..d)(2/L)^j. The fixed template
and its actual occurrence recurrence retain their own full pricing obligation.

## Finite evidence and limits

The same sealed table runs four inputs (w,d,T,R_body): (1,0,2,3), (2,1,1,1),
(2,2,1,1), and (3,1,1,1). No case supplies A,R or H. The
two-level case physically generates A144/R3/H3 at root, then actual nodes
(12,9,432) and (1,27,108), seven entries and six protected returns. The
observer independently compares every live header, grant, parked parent
byte/head, whole output and final ownership. It contributes no executed branch.

Five literal-program faults are rejected: skipping root production, skipping
depth-head restoration, popping before output protection, omitting return
depth restoration, and replacing immutable H by current R. The last mutant
still passes a one-edge positive control where R0=H, but fails on actual
grandchildren where R1=H^2. Controls therefore test the on-path dependency.

The written inductions, not finite tests, supply the all-size claim. Root
padding T, w and depth still enter physically from the outer interface. This
does not generate numerical ancestor weights, their source-specific orientation
or Good/Pair descriptors, an ordinary BIT/Gaussian leaf, routes, precision,
stock or a final compiled template. There is no new kappa or self-admission.
