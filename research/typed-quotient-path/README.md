# Consume the type-B quotient ports and locate the remaining bottleneck

**No new K is claimed.** Starting from Dugongue's PR4654 typed supplier,
one ordinary output subtraction turns each of its 56 type-B pairs into
independent rank-7 and rank-8 Gaussian jobs. This preserves all arbitrary
inputs and adds 112 autonomous helpers. The inverse-transpose orientation
uses the opposite output shear. No extra Gaussian request is needed.

The resulting local interface has 56 active type-A pairs and 520 independent
helpers. Its helper rank mass is 4246; the complete paid rank mass is 5094.
The excess over the active transverse work is still 64. For **every**
minimal-cut path pair count p>=1, every split, every native/thin stage
subset with n full calls, and every 0<=C<1, the complete moment fails:

    F(C) <= -(8n+56) * 7^(-C) < 0.

[PROOF.md](PROOF.md) proves the exact operator normalization and all-p,
all-concave-moment bound. [RESULT.json](RESULT.json) records source-bound
counts, exact matrix controls and the rational separator certificate.
This is stronger than failure of a bounded parity search, and remains
specific to the unchanged A-path and retained center invoice. Mixed A/B
controllers retaining B ports actively, changed words, phase schedules and
center recipes are outside scope.

The constructive next target is concrete: with this autonomous-B interface,
the center excess must fall below 56 per full invocation to have positive
rank surplus for sufficiently many calls. It is currently 64. Saving nine
rank units would cross that necessary integer threshold; it is not a
sufficient moment or compiler certificate.
