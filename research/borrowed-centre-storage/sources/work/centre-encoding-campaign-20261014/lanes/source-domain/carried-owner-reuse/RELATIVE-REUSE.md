# All 512 external dirty queries use old helper advances

The selected owner allocation can carry every row of the 64 proposed
backward-to-forward query caches without a new native child or a new
field. A certificate assigns all 512 rows to 512 distinct old owners.
Each owner receives eight native axes through complete helper jobs
that are already in the selected invoice. No selected owner has a
data, bridge, or terminal use while it holds a query.

The change is in the cache representation. The saved physical query
is added to the owner's old physical value. The two values need not
have the same logical entry frame. Only their native advance through
the interval must agree after an exact cover reindexing. This weaker
condition holds on the actual selected schedule.

This is an external dirty-cache transport theorem. It does not put a
clean query in a local C register. It does not restore the source
code G left by the query logger, complete a controller, or improve
kappa by itself.

## Transport lemma

Let a be an arbitrary old physical field value at the capture cut.
Suppose that, until the erase cut, its original complete jobs act by
an invertible native map T. Assume that no data or other scalar use
of the field occurs in that interval. Let q_0 be the physical query
at capture and q_1 its available source alias at erase. If a known
monomial map M satisfies

\[
 TMq_0=Mq_1,
\tag{1}
\]

then the following sequence restores the old field exactly:

\[
 a\ \longmapsto\ a+Mq_0
 \ \longmapsto\ Ta+TMq_0
 \ \longmapsto\ Ta.
\tag{2}
\]

There is no condition on a and no equality between its entry frame
and the query frame. The complete helper contract is an identity on
arbitrary input values, so it also holds when the added query is
correlated with data used elsewhere in the local invocation. The
other data and helpers have their unchanged complete outputs.

Equation (2) only states transport and erasure. A gate that uses the
cache while the query is present must also cancel the unknown a.
Nothing in this lemma makes the cache a clean source. In particular,
this proof does not alias the cache to one of the eight local C
registers. Such an alias could conflict with its original helper role.

## Exact native operator on the actual query window

Use the original complex construction, with parent dimension 73.
Let E_s be the fresh eight-coordinate block of a positive stage s.
The four windows have s in {1,3,5,7}, from just before B_s to just
before F_(s+1). The selected query ports are

```text
[21, 37, 47, 76, 81, 87, 92, 110].
```

The exact source alias is the separate premise in
[CARRIED-QUERY-ALIAS.md](../../residual-syndrome/physical-algebra/CARRIED-QUERY-ALIAS.md).
Its normalized query is Q_T y=R_T^-1 R y. The logger puts row k in
the selected Y output. That source is unchanged before the next
forward entrance. In the original owner chart, its native frames
change from F_(U_(s-1)) C_p^-1 to F_(U_s) C_p^-1. All original
entry, exit, and cover phase terms are retained in that alias proof.
Their relative operator is exactly F_(E_s), with scalar phase one.

At physical cover class g, the query therefore obeys

\[
 q_1(g)=P_g F_{E_s}P_g^{-1}q_0(g).
\tag{3}
\]

The query at capture is a computed value, not the old selected Y
coordinate. The normalized prefix forms it with the actual local
entry gathers. Equation (3) uses the selected source alias after
the logger. It does not assume a fixed original y or an invariant
cover input.

Now choose an old owner's interval with eight distinct pending axes
v_1,...,v_8 from its actual orthonormal chart. The selected certificate
uses only complete helper jobs. It includes no idle translation and
no suffix. Its exact owner-chart interval map is

\[
 T_0=\prod_{j=1}^{8}C_{v_j}.
\]

Choose an orthogonal 73-axis map U that sends the ordered unit basis
of E_s to (v_1,...,v_8). The producer completes this map with the
remaining columns of the actual orthonormal owner chart, in order.
The selected cover is all of O(73,2), so U is already an allowed
cover element. Exact orthogonal conjugation gives

\[
 T_0=P_UF_{E_s}P_U^{-1}.
\tag{4}
\]

There is no original-C phase loss in (4): each individual C_e maps
exactly to C_(Ue). The certificate checks the columns and inverse,
the eight actual pending axes, and every Fourier character on that
eight-axis factor. The factors fix the zero character, so the scalar
phase is one. The identity extends by the spectator identity and by
tensor products to every positive tensor multiplicity.

For a query field at cover class g, use the donor at

\[
 h=gU^{-1}.
\]

Equivalently, define the cover permutation (Mz)(h)=z(hU), leaving the
physical native address unchanged. The donor's interval map is

\[
 T(h)=P_hT_0P_h^{-1}
      =P_{hU}F_{E_s}P_{hU}^{-1}.
\]

This is precisely the source map in (3) at g=hU. Hence TM=M T_query
on arbitrary full-cover arrays, and equation (1) follows. The exact
cover permutation moves a payload between independent classes; it
does not equate their contents. A more general path with a net
translation would require that same translation on the erase ADD.
All 512 selected paths here have zero net translation.

## The complete selected allocation

The [producer](check_relative_reuse.py) reads only the pinned selected
archive plus the frozen alias receipt. It reconstructs all original
owner native histories and all scalar-use barriers. It checks the
exact complete helper routes, residual widths, spectator choices,
and all non-repeated pending axes. It preserves the old eight
private C fields outside the live owner namespace.

For each of the 64 windows it tests every old live owner. It retains
only paths with no scalar use and exactly eight new native axes.
It then gives each of the 512 query rows a distinct owner. This is
stronger than merely finding non-overlapping repeated uses of one
field. A matching of 512 rows establishes full row coverage; no
optimality argument is needed for this construction.

The [receipt](RELATIVE-REUSE.json) records every row, owner, full
intervening path, native axis, cover map, inverse map, and phase.
The selected assignment has the following exact counts:

- 348 old X owners and 164 old Y owners;
- 499 rows whose query and donor have different entry native ranks;
- 479 complete rank-eight helper jobs and 66 complete rank-four jobs;
- total already-paid rank 4096=512*8;
- no idle suffix, idle translation, new native child, or new field;
- all 64 eight-row cohorts covered.

Every chosen donor is outside the current source pair at capture.
It can be an ordinary helper of the backward call or a later call.
The entire local arbitrary-helper identity remains applicable.
When the query is erased, the old field has its exact original value
and frame, so its later data use is unchanged.

## Full-cover order and cost scope

Capture is a complete cover sweep before any invocation in the B_s
core sweep. Erase is a complete cover sweep before any invocation in
the F_(s+1) core sweep. A donor can occur as a helper at a routed cover
class different from its capture class. Thus capture must not be
interleaved with local core invocations. These new scalar sweeps
preserve every original core, helper, idle, and bridge event order.

The source alias supplies the literal normalized prefix and erase
counts. Across all windows, these give 27,136 complex capture ADDs
and 512 complex erase ADDs, with real primitive bound 274,432. The
cover reindexings and exact source entry gathers still need their
finite address/control and precision bill. The receipt does not
claim that this scalar subtotal is the complete added cost.

The live and physical stocks remain 14,336 and 14,826. No productive
rank credit is added. The original native child profile is unchanged
by the cache transport itself. The local query logger has its own
already stated extra native and scalar bill; this theorem does not
remove it. Compared with the separate 128-owner cache proposal,
there is no need to add its {8:1024,9:128} cache-native history, but
its 128 new productive rows are also absent.
