# A masked query cleanup with one local scratch field

The masked F2 query has a complete local donor erase word. The word
uses one owned scratch field, no new native child, 240 complete-family
cover maps, and 25,124 real scalar primitives. All temporary data codes
are restored. All eight arbitrary donor baselines are restored. No
private value moves between cover owners.

This result assumes the stated post-F2 complete cut. It does not admit
the changed F2 target code in the later controller. It does not close
the full supplier or change kappa. Native child hosting, stream address
work, primitive prefix precision, and the full controller invoice remain
separate obligations.

## Input and required erase

Use A, T, U and the routed maps from MASKED-QUERY.md. Put V=A union T.
The two current data pairs have these logical values:

    X0_U=x_U+c_U,       X0_V=c_V,
    X1_U=c_U,           X1_V=d_X,V,
    Y1_V=d_Y,V,         d=z+E h,       z=(x,y).

The eight selected Y0_A fields supply P2_A q, where

    q=R2_U(X0_U+y_U).

Each donor contains h+Gz. The exact error and read identities are

    R0 d_X=R0 x,
    d_X,T+d_Y,T=x_T+y_T,
    Gz=P2_A[q-R2_U c_U+R2_T(d_X,T+d_Y,T)
                 -R2_offA P0_offA R0 x].       (1)

All X0 and X1 fields, Y1_V, Y0_A, and the aligned donors have the same
completed U2 native frame. Y0 outside A and Y1_U need not have that
frame. The word does not read or change those Y fields.

The symbols c, h, and the unused target values are arbitrary. They may
be correlated with x and y. The proof uses linear identities, not
independence of these values.

## Temporary real-family aliases

First subtract Y0_A from the donors. This removes P2_A q.

For each U port, apply X0_p-=X1_p. Exchange X0_p and X1_p on each V
port by the exact four-scalar physical swap. The state is now

    X0=d_X,       X1=c.

The two banks have the same native frame at this cut. Every scalar ADD
in this preparation is legal. No borrowed data is cleared.

Next apply Y1_T+=X0_T+X1_T. Define

    f=R0 X0=R0 x,
    a_offA=c_offA+P0_offA f,
    b_T=c_T+d_X,T+d_Y,T.

Form the alias X1_offA+=P0_offA R0 X0. Its source bank X0 is unchanged.
For each cover owner, clear the owned C at the completed frame. Form
each of the eight R0 X0 rows in C and scatter its quarter response to
X1_offA. Clear C before the next row. After the eighth row, clear C at
the identity frame and end this owner's body. C has no value at any
other cover owner. The actual alias is held in the real X1 family.

The same owner loop can run in reverse sign to undo this alias. Its
source X0 remains fixed throughout both directions. Thus no inverse of
J and no non-dyadic scalar division are required.

## Ordered cover read and restoration

After the complete alias sweep ends, gather these real families through
their registered stage-2 views:

- the eight A donors;
- the 104 off-A X1 fields, which contain a_offA;
- the eight T fields of Y1, which contain b_T.

Every gathered field has the complete U2 frame. The pinned route and
its registered translation preserve that exact native phase. The query
has 416 half ADDs from X1 and 32 half ADDs from Y1. In the gathered
coordinates, add the former and subtract the latter into the donors.
The added value is

    P2_A [R2_offA a_offA-R2_T b_T]
      =P2_A [R2_U c_U+R2_offA P0_offA f
                       -R2_T(d_X,T+d_Y,T)].     (2)

Equations (1) and (2) leave each donor equal to h. Return every source
and donor view in reverse order. Then undo the X1 alias, undo the T
sum, and undo the initial source-bank preparation. This restores every
temporary data value. Finally subtract E h from the parked selected
data fields. The original selected values x_V and y_V are restored.

The output X0 and Y0 are unchanged by the complete cleanup. The output
X1_U and Y1_U are unchanged. The output donors equal their arbitrary
original baselines. The owned C is zero at the identity frame. The
480 inherited helpers are not used by this word.

## Why the private storage is legal

The literal payload records complete `owner_sweep` and `family_sweep`
blocks. A family sweep consists only of maps on real data or donor
families. An owner sweep has no cover map. Every use of C is inside one
private owner body, with a final CLEAR before the next owner starts.

There are two private owner sweeps: the alias and its inverse. Neither
overlaps a family sweep. All cross-owner response data resides in X1,
which is a complete real family. No local C array is treated as a
complete cover family. The source and response destination banks are
disjoint, so the source query does not change during either alias.

The source-domain access check accepts this complete-family pattern
conditionally on exact source phases, view order, disjoint fields and
costs. The executable checks those local conditions. The actual global
owner trace for the changed masked F2 word remains a separate step.

The earlier `emit_cleanup.py` did not satisfy this storage condition.
Its map on C was a whole-family algebra calculation. The correction and
the withdrawn cost are recorded in PRIVATE-COVER-ISSUE.md. Those earlier
bytes remain fixed.
