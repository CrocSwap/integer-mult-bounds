# A typed consumer for the common-frame QQ16 repair

The mass-240 common-frame repair has a legal consumer in the actual
482-event owner schedule. For any chosen set W of ports, two physical
bank swaps put the recovered pair-0 values on W outside all later active
calls. Complete old helper jobs can still use these fields. They preserve
each recovered value and its extra line code. A final correction gives
the full completed transform of the original raw inputs on these fields.

The added native profile per replica is always

    {1:224, 8:16},  rank mass 352,  480 native wrappers.

This profile includes the common-frame repair, the partial Y return, and
the final X correction. It does not include the retained source calls.
The checker binds two cases to all 482 source events: W=A union T, with
16 ports, and W=all 112 ports. The second case retires a full 224-field
data pair. It changes the ordinary bridge interface as well as the
selected bridge interface.

This is a partial output construction. The other three pairs, and the
unselected pair-0 outputs when W is smaller, do not have a proved target
map. The new records and children do not have a complete owner or
precision invoice. There is no complete supplier or kappa claim.

## Input and source contracts

Use the exact QQ16 source and the independently checked common-frame
repair. At an owner g, put Q_p=C_(g q_p). The initial virtual types are
X:Q and Y:I. If the raw physical inputs before F0 are (a,b), their logical
values are (Q^-1 a,b). The common-frame repair after F0 and B1 gives

    X=F_U1 Q^-1 a,   Y=F_U1 b.

All 224 data columns and all 480 arbitrary helper columns are covered by
the source contract. The sixteen early records are owned; they may have
arbitrary values before capture and end at zero. The local owned scratch
also ends at zero. The common-frame proof and independent review remain
unchanged.

The actual source has four bank pairs per replica and sixteen replicas.
At a completed level s, its original types are

    X:F_U_s,   Y:F_U_s Q^-1.

Each complete helper output is its assigned native operator on its own
arbitrary input. It has zero dependence on active data and other helpers.
Active data outputs have zero dependence on the helper input. The full
QQ16 native review supplies this content premise. The original complex
phase and owner review supplies the fixed-owner endpoint operator.
Neither premise is asserted at a partial helper cut.

## The physical swap

For arbitrary physical arrays a and b, use the ordered scalar word

    a += b;   b -= a;   a += b;   b = -b.

The result is (b_old,a_old). This identity does not require a and b to
have the same native type. The intermediate arrays need not have one
logical frame. All four operations are complete pointwise cover sweeps,
with no helper event inside this block. The cost is three complex ADDs
and one sign SCALE, or 26 real primitives in the retained scalar invoice.

This is the needed distinction from an unchanged ordinary bridge. If
the source Y has type F_U1 and the destination Y has type F_U1 Q^-1,
the unchanged subtraction has an extra Q on the source logical value.
It does not give the old bridge. The physical swap exchanges both values
and both types exactly.

## Ordered continuation

Fix a nonempty W contained in the 112 ports. Make these changes in each
replica. All source cover sweeps and all old helper jobs remain in order.

1. Capture the sixteen QQ16 records after F0. Apply the common-frame
   repair after B1.
2. Apply inverse C_q to Y only on the complement of W. These ports have
   the original mixed endpoint. The ports in W retain common F_U1.
3. On W, make each of the first six bridges a physical swap on both X
   and Y. Off W, retain the ordinary bridge. Omit the last three bridges,
   the terminal Y translation, and the signed terminal exchange on W.
4. After the complete old native tail, apply positive C_q to X on W in
   pair 0. Do this before the last common cover translation.

The first two swaps are the only swaps that carry the protected values.
For replica 0, B1 is event 4, the initial pair-1 idle is event 5, and the
first bridge is event 6. The first swap sends the recovered pair-0 W
values into pair 1. Pair 0 receives the original mixed types from pair 1.
Thus F2 at event 18 has its required entrance on every port. The old
pair-1 idle at event 19 advances the protected values to level 2. The
second swap at event 20 returns them to pair 0. Pair 1 receives the F2
output with the original types required by B3.

Pair 0 has no later active call. The remaining four early swaps use
other pairs. The omitted final bridges and terminal leave its W values
in place. The same sequence holds at the actual event positions in all
sixteen replicas. The checker uses the literal call owner lists; it does
not infer access from pair names alone.

## Complete helper jobs and the final phase

At a fixed owner g, an unchanged helper job has an endpoint equal to a
product of intrinsic C_(g v) factors and its recorded translation. These
are convolution operators and commute with C_(g q_p). A temporary gather
inside the helper call returns to the same owner. Its complete endpoint
identity is therefore sufficient; commuting an internal gather is not
required.

Suppose a protected input has the extra factor C_(g q_p) relative to the
original Y type. A whole helper job preserves that factor. It also keeps
the protected input separate from active data, by the two-sided arbitrary
helper contract above. Same-port swaps keep q_p unchanged. Complete old
idles have the same commutation property. The checker finds 894 such
helper jobs for W=A union T and 6,016 for W=all ports. None is replaced or
given a new owner.

At the end of the old tail, before the final common cover translation,
the protected pair-0 values are

    X_W=F_73 Q_W^-1 a_W,   Y_W=F_73 b_W.

The positive X lines give (F_73 a_W,F_73 b_W). The exact Gaussian identity
C_q C_q^-1=I is checked. No negative Y line is then needed on W. The
initial virtual X factor is paid for, rather than treated as identity.

The protected raw inputs occur in no other data output. Immediately
after repair, all pair-0 logical data are their independent original
values. The first swap removes the chosen values before F2. Later active
calls do not read them, ordinary bridges operate only off W, and complete
helper jobs have zero cross-dependence. Thus the data map splits as the
proved completed transform on these fields and a separate map on all
other input fields. This statement does not identify that other map.

## Costs and lifetimes

Write w=|W|. The native count is

    240 + (112-w) + w = 352.

The partial return and final correction partition the 112 ports. The
complete added profile is 224 rank-one children and 16 rank-eight
children. The added scalar allowance remains 16,338, and the repair has
208 complete cover maps. Native wrapper counts include the new return
and endpoint lines. Their physical stream cost is separate.

The first two boundary bridges cost

    4(112-w) complex ADDs + 4w physical swaps,
    real allowance 3584+72w.

All nine modified bridges together cost

    18(112-w) complex ADDs + 12w physical swaps,
    real allowance 16128+168w.

These are the full bridge costs, not an increment over the old bridge
bill. They exclude the retained terminal off W, old idles, source local
calls, the final common translation, and their costs.

| W | Added native mass | Two boundary bridges | All nine bridges |
| --- | ---: | ---: | ---: |
| A union T, 16 ports | 352 | 4736 | 18816 |
| All 112 ports | 352 | 11648 | 34944 |

Returning all Y lines first, then correcting both parked X and Y at the
endpoint, would cost 352+2w native mass and 480+4w wrappers. The present
typed consumer removes those 2w redundant rank-one calls. This is a
comparison of these two specified interfaces, not a lower bound.

The literal global order has four F0 captures before its first B1 repair.
An exact interval allocation needs four sets of sixteen whole-cover
records, or 64 record fields at the peak. The receipt gives each interval
and its reused slot. The producer's one local scratch role is separate.
These are owned roles; this note does not host them in old arbitrary
productive fields or add productive credit. The source calls have no
permission to borrow these new records. All new child hosting, record
storage, access and precision costs remain explicit open obligations.

Run from the workspace with Python 3 and the pinned archive and lane
files. The command uses one CPU and writes only the named output files.

```sh
python3 -I -O -B work/centre-encoding-campaign-20261014/lanes/portable-source-codes/common-f-review-20261015/check_consumer.py --repo /Users/aliromman/Projects/IntegerMultiplicationBounds --lanes /Users/aliromman/Projects/IntegerMultiplicationBounds/work/centre-encoding-campaign-20261014/lanes --out /private/tmp/common-f-consumer.json
```

The expected status is `PASS_PORT_RETIREMENT_TYPED_CONSUMER`. The checker
emits a literal patch word and receipt. It checks all 144 active owner
sets, all 482 old events, all 96 early bridge instances, the complete
protected-field trace, record lifetimes, F2 route normals, and exact
physical swap and endpoint identities. Controls remove a required Y
return, either of the first two swaps, the swap sign, or a final X line.
Each control fails at its stated obligation.

The checker does not re-run the inherited QQ16 native kernels or prove
the other output map. It does not turn the patch into a complete admitted
supplier. The source hashes and exact inherited review hashes are in the
receipt. `CONSUMER-MANIFEST.json` binds this proof, checker and outputs.

treating this consumer as accepted.
