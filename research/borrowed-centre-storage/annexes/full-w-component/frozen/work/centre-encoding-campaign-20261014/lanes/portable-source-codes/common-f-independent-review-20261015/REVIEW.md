## Consumer checks

The checker imports no producer or upstream module. It reconstructs all
69,120 whole helper jobs, 7,526 idle suffixes, and 160 strict idle windows
from the source archive. It checks each literal helper owner, width, route,
axis slice, deadline, and partition. An exact phase is then carried through
all 482 source events and all 144 ordered active owner sets. This replay
includes helpers from other replicas and partial advances before an idle
deadline.

Two early-owner gates were added to the review. For each of the sixteen
replicas, all 224 pair-0 data families have no active or helper use before
their own F0. They also have no such use strictly between F0 and B1. There
is no pair-0 idle or bridge in either interval. The per-replica event
positions and all zero counts are in `INDEPENDENT.json`. These gates bind
the raw inputs to the global entrance and keep the captured F0 records
aligned with their source arrays until B1. Later helper commutation does
not replace these gates.

The scalar swap was checked on two independent physical symbols. Its
prefixes are `a+b`, `-a`, `b`, and `a`. Thus the last sign is required and
the complete operation exchanges both arrays. Equal native types are not
an assumption. It needs three complex ADDs and one complex sign, with
retained real allowance 26. It adds no fractional reserve. Its component
bound is `H_a+H_b`.
One magnitude guard bit is sufficient above a common input bound. The
final positive X line is a rank-one physical operator. Its conditional
fractional reserve is `ceil(lambda/2)` and its box gain is
`2^ceil(lambda/2)` on its physical input.

The first two swaps put the protected values in pair 1 during F2, then
return them to pair 0. All later active calls have their original native
types and read no protected value. The first six bridge positions agree
with the literal source events in all sixteen replicas. The final three
bridges and terminal actions are omitted only on the chosen ports.

A complete helper job is a block diagonal physical operator under the
inherited arbitrary-input contract. Its helper output depends only on
that helper input. The active outputs have zero dependence on the helper
input. A different actual helper type does not change this linear identity:
the declared entrance frame is invertible, so it can represent every
physical input. Its fixed-owner endpoint is a product of intrinsic native
lines and translations. Those convolution operators commute with the
extra `C_(gq)` factor. No internal gather is commuted through a query.

The exact phase replay checks 1,436 whole helper jobs on protected fields
for the 16-port case. Of these, 894 carry the extra Y line. For all 112
ports, the corresponding counts are 9,619 and 6,016. All old jobs and idle
translations remain in their original order.

Before the last common cover translation, the protected raw X operator is
`F_(gU8) C_(gq)^-1`; the raw Y operator is `F_(gU8)`. All 112 positive line
recipes have inverse native wrappers, the actual label q, and zero extra
positive-line translation. They cancel the X inverse exactly. The retained
all-cover correction then gives the global `F_73` on both original raw
inputs. The checker does not replace `F_(gU8)` by the global `F_73` before
that correction.

The chosen inputs have no coefficient in other outputs. After the inherited
repair, each chosen original value occurs only in its own data field.
Swaps move that value without a copy. Later active calls and ordinary
bridges do not read it. Each complete helper keeps it separate. This proves

The full phase replay checks the 16-port case, all 112 ports, and the empty

the argument for all subsets; the checker does not enumerate `2^112` sets.

## Precision checks

The independent replay starts from raw physical entry arrays. Each term
contains a source name, its actual right-owner matrix, a dyadic coefficient,
and a physical quadratic phase. A native line adds its physical phase.
A map `M_(g,delta)` sends an owner h to gh and sends phase P to
`gP+2 parity(delta)`. Each ADD combines exact equal-source terms.
The full 73-column matrices are retained.

A separate check compares every resulting physical term with `F-hS`,
where F is the current frame, S is its source frame, and h is the actual
right-owner matrix. There are 86,284 such checks in the common-F case.
Reversing matrix composition is rejected. Thus the precision replay does
not substitute a payload permutation for an actual cover route.

Every published prefix-table hash is reproduced exactly. The common-F
word has 2,054 events and 2,275 changed-field boundaries. The 96-return
extension has 2,150 events and 2,371 changed-field boundaries. Their
relative ranks are 0, 1, and 8. Their scalar debt maxima are 1, 1, and 2,
and their absolute coefficient-weight maxima are 136, 136, and 412.

The Gaussian phase argument was checked independently with direct exact
Fourier sums: 548 quadratic forms, 4,232 coefficients, and 256 C8
coefficients. The unchanged upstream small checker also passed:

```text
PASS_QQ16_PHASE_KERNEL forms=548 coefficients=4232 c8_coefficients=256 controls=4
```

For phase rank r, the kernel has `2^r` nonzero coefficients of squared
modulus `2^-r`. The Gaussian dyadic components have denominator exponent
`ceil(r/2)`, and the real-component box norm is `2^ceil(r/2)`. Tensor depth
lambda changes r to `r lambda`. The scalar coefficient is unchanged.
The observed debt maxima therefore give `4 lambda+2` fractional bits.

The magnitude certificate is

```text
H [136+136*2^ceil(lambda/2)+412*2^(4 lambda)].
```

For every positive integer lambda, `2^ceil(lambda/2)<=2^(4 lambda)/8`
and `1<=2^(4 lambda)/16`. The bracket is at most
`(875/2)*2^(4 lambda)`, which is strictly below `2^(4 lambda+9)`.
This proves the stated all-layer magnitude reserve. At one layer, the
largest triangle certificate is 7000H at event 1973, field X36. The
certificate need not be attained by any complete input field.

After the 96 ordinary Y returns, the physical row is exactly the inverse
line applied to minus the corresponding current X entry. It does not send
an early record term through a new line. The same bounds therefore hold.
Returning all 112 Y ports introduces ranks 2 and 9. The separate sufficient
term bound is `2+ceil(9 lambda/2)`. No minimum-precision claim follows.

There is one census-label finding. The producer's value 4,804 is the number
of distinct cache keys `(frame tuple, source label, owner matrix)`. The
frame tuple is not a canonical phase polynomial. Thus this is not a count
of mathematically distinct relative phase operators. The independent
canonical physical census has 856 distinct `(source, owner, phase)` terms
in the common-F case. The receipt also gives the counts with source labels
removed, and with owner matrices removed. Suggested wording for 4,804 is
"distinct relative-phase cache keys". This label has no effect on the
prefix hashes, ranks, debts, weights, or theorem bounds.

The separate clarification was read and its pins were checked. It uses
the correct cache-entry meaning for all three cases and keeps all original
bytes unchanged. It resolves this finding. The exact canonical counts are:

| Case | Source, owner, phase | Owner, phase | Phase polynomial |
| --- | ---: | ---: | ---: |
| Common F | 856 | 602 | 602 |
| 96 Y returns | 952 | 698 | 698 |

Here phase means the canonical mod-four quadratic polynomial. The three

`PASS_INDEPENDENT_COMMON_F_CONSUMER_AND_PRECISION_REVIEW`.

sixteen early entries, 224 current entries, and owned dirt. It does not

and cover maps. It does not cover approximate children, scalar primitive

idle prefix precision. The old tail and endpoint line have no combined
entry-bound certificate here. The modular swap and endpoint estimates
must not be added to the local result as a complete controller format.
