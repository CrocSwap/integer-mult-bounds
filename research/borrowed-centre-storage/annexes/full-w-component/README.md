borrowed fields live at one time. It adds no owned record family. Its

## Replay

Use Python 3.10 or later, its standard library, one CPU, and at least
3 GiB of free space. No Git checkout, network, or external package is
required. From this annex directory, use a new output directory:

```sh
python3 -I -B replay.py --out /tmp/full-w-component-check
```

The final line must be:

```text
PASS_FULL_W_COMPONENT_ANNEX
```

The runner executes four frozen independent checkers with `-I -O -B`,
one at a time: ordered composition, actual donor allocation, literal
delayed cleanup, and the independent all-output difference check. It
compares each resulting receipt byte for byte with its frozen receipt.
The sources are checked before and after execution. The old raw native
kernel suite and the clean-owned reference consumer are inherited
premises, not additional replay jobs.

[SOURCES.json](SOURCES.json) pins all 66 retained files. The exact historical
6,095,634-byte source archive is included. The archive and member checks
remain unchanged. The only [portable change](ADAPTATIONS.patch) replaces
one absolute repository root with the root derived from the source path.
No formula, event, check, source pin, or receipt comparison changes.
