# Consolidated root theorem for the P104 root (statement, proofs, hypothesis ledger)

Tags: [P] proved here, [C] exact computation in `check.py`, [Q] quoted from a named prior result, [A] open assumption.
No kappa claim, no word, nothing priced beyond the stated formula. The base is #6868 (chain-nested root optimality); the chain root itself is #6833.

## 0. Verdict

Under the model of section 1 and the ledger of section 4, the chain-nested root `chain(9|9)` minimises `D_root` among all shortest roots; no direct sum of shortest roots pays; roots with one extra unit need `D_root <= 1120.2` and have a floor of `1276.0` (conditional on R1-R4). The statement is **not** claimed from the verifier's rules alone: it needs the listed assumptions. Section 5 lists what is open.

## 1. Setting

A root is a tuple of rank-one units `T_k = I - 2 x_k y_k^T`, `y_k x_k = 0`, `k = 0..N-1`, on `F^n` (char F != 2), with product `T_{N-1} ... T_0 = -I`. Site `k` carries a data scalar `D_k`: the unit actually run is `Phi_k = Delta_k T_k`, `Delta_k = I + (D_k - 1) P_k`, `P_k` a projection with range `M_k` (the mask). `M(D) = Phi_{N-1} ... Phi_0`. Notation: `A_k = T_{N-1} ... T_{k+1}`, `U_k = T_k ... T_0`, `G_ij = y_i x_j`. The P104 root has `L = 18` productive sites, `n = 20`, `N = 21`, three thin queries; per-port constants `v = 104`, `c = 56`.

## 2. Lemmas and proofs

**Lemma 1 (Dieudonne, `N >= n+1`; parity) [P; C].** Product formula `T_{N-1}...T_0 = I - 2 X K^{-1} Y`, `X = [x_0..x_{N-1}]`, `Y` the matrix of rows `y_k`, `K = I + 2 Lo`, `Lo` the strict lower triangle of `G = YX` (induction on N). If the product is `-I` then `X K^{-1} Y = I_n`. For `N = n`, `X, Y` are square and invertible, so `K = YX = G`; but `diag K = 1`, `diag G = 0`. Hence `N >= n+1`. Each `T_k` has determinant 1, so `n` is even. For `N = n+1` the sign-Gram root `y_i x_j = sgn(i-j)` multiplies to `-I` exactly over Q for every even `n = 2..20` [C].

**Lemma 2 (rigidity of the shortest root) [P; C].** Let `N = n+1` over a field of char != 2. Then `G` is gauge-equivalent to the sign matrix (every `G_ij != 0`, `G_ij G_ji = -1`) and `(X,Y)` is unique up to `X -> gX, Y -> Y g^{-1}`; the tuple is unique up to conjugation and rescaling `x_k -> l_k x_k, y_k -> y_k/l_k`.
Proof. From `X K^{-1} Y = I_n` (divide by 2), `E = K^{-1} Y X` is idempotent of rank `n`, so `rank(I - E) = N - n = 1` with no trace argument. `I - E = K^{-1} Z`, `Z = I + Lo - Up` (diag 1), so `rank Z = 1`: `Z = a b^T`, `a_i b_i = 1`, all entries non-zero, `G_ij = sgn(i-j) Z_ij`. The gauge `l = a` brings `G` to the sign matrix. Given `YX = S`, `ker X' = ker X` forces `X' = gX`, `Y' g = Y`. QED. Katz's rigidity theorem is not needed. The same argument gives `rank Z = N - n` for any `N` (rank 2 at `N = n+2`).
Exact check [C]: the tangent space of `{y_k x_k = 0, product = -I}` at the sign-Gram root equals the gauge-orbit tangent (dimension `n^2 + n`) for `n = 2, 4, 6`, over Q.
Characteristic: char 2 degenerates the model (`I - 2xy^T = I`, `-I = I`), so char != 2 is part of the definition. For the dyadic Gaussian ring `Z[1/2][i]`, 2 is a unit, the fraction field `Q(i)` has characteristic 0 and every residue field has odd characteristic, so the hypothesis holds automatically and every step above holds over the fraction field and over every reduction.

**Lemma 3 (masks) [P; C].** Exact identity `M(D) = -(A_{N-1} Delta_{N-1} A_{N-1}^{-1}) ... (A_0 Delta_0 A_0^{-1})`. Under whole-job credit (target `-diag(prod D_k^{eps_rk})` in the constant output basis, exponents in {0,1}), the identity is multilinear in `u_k = D_k - 1`; extracting the coefficient of `u_k` gives `A_k P_k A_k^{-1} = E_k = diag(eps_.k)`. So the transported masks are coordinate projections of the output basis and commute. The identity holds for every `P_k = A_k^{-1} E_k A_k`, and such site-frame masks are generally neither diagonal nor commuting with `T_k` [C: n = 4, 3 of 5 not diagonal, 4 of 5 not commuting with their unit]. Hence the step "site-frame masks are coordinate sets with `[P_k, U_k] = 0`" is an extra assumption (H7, H8 below); see section 5 for what is known about twisted masks.

**Lemma 4 (star optimality) [P modulo float evaluation; C at 50 digits].** A field with `h` hosts and `m` sites costs `>= f(8m+1) - f(8(m-h))` and covers `h(m-1)` ordered pairs; the star (one field, `h = m = N`) costs `f(8N+1)`. Weak duality with `rho_N = f(8N+1)/(N(N-1))`: every non-star field has price per covered pair `> rho_N`, for every `N = 2..1199` (smallest margin 0.0645% at N = 1199; 3.44% at N = 18) [C]. So an optimiser free to choose the topology picks the single all-field.

**Lemma 5 (staircase) [P; C] (base package).** Model R1-R3 below; `D_root = f(8L+1) + sum over non-A fields [f(8|M|+1) - sum of f(8 r) over maximal idle runs]`, `f = x ln x`. (i) Sign factorisation: realizable iff there are signs `p_i, q_j` with `sgn(i-j) = p_i q_j` outside the field of `i`. (ii) A field of size `n` with the host at an end costs `c(n) = f(8n+1) - f(8n-8)`, increasing. (iii) `#{i : n_i <= t} <= min(2t, L)`. (iv) `D_root >= f(8L+1) + sum_{k=1..L} c(ceil(k/2))`, equality only for `chain(g|g)` and its outer-nested twin; at `L = 18` this is `1418.8458829299`. [C] for L = 4..18 including the exhaustive minimum over all sign patterns.

**Lemma 6 (the S identity; extra units; block roots) [P given the quoted constants; C].** `S = L(v - c) - (N - n) v`, `v - c = 48`; at `L = 18`, `N - n = 1`: `S = 760`. Each unit beyond `n+1` lowers `S` by `v = 104` (13.68%). A direct sum of `b` shortest roots has `N - n = b`. With the native held fixed (total D 226939/104 per port, quoted) and `kappa ~ S/D`, all 384 partitions of 18 into `b >= 2` parts have negative true-S gain; the best is `-4.80%` at (9,9) (D-only gain +10.3%). Per `b`: 2: +10.3 / -4.8; 3: +17.3 / -14.8; 4: +22.5 / -27.8; 6: +30.5 / -58.8. Break-even `D_root` for a non-block root with `e` extra units: 1120.2 (e = 1), 821.6 (e = 2), 523.0 (e = 3) [C].

**Lemma 7 (D_root formula from the #6833 invoice) [P; C].** The invoice charges, per port: a credited target of rank `8|M_c|+1` for each field `c` (eight axes per carrying stage plus the parity bit; the empty field has rank 1); a paid whole idle of rank `8r` per maximal idle run (the chain-merge lemma fuses the stage factors of `r` consecutive sites into one job); paid rank 1 per thin query; ordinary scalar work outside the Gaussian budget. Rank-1 terms contribute `f(1) = 0`. Hence `D_root` is term for term the stated formula. [C] to 1e-40 (50-digit Decimal): the root part of the published invoice equals the root events of the literal caller word; its credited diagonal gives masks `1..9` twice and the all-field `18`, its idle events runs `1..8` twice; `D_root/104 = 1418.8458829299 = chain_D(9)`; the root is 65.02% of the linearised total.
*Linearisation.* Exactly `F(kappa) = S - kappa D_kappa` with kernel `phi_kappa(x) = (x - x^{1-kappa})/kappa`; `f = x ln x` is `phi_0`. At `kappa = 0.0033718`, `D_kappa,root = 1407.8057` (-0.78%). The theorem uses only `phi(0) = 0` and convexity, both true of `phi_kappa`; [C] the exhaustive sign model with `phi_kappa` equals the chain for L = 4..12 and every `chain(a|18-a)`, `a != 9`, is strictly above. The rescaling does not change the theorem.
*Support outside the mask.* In the caller grammar a coordinate touched by `x_k` or `y_k` is scaled by `D_k`, so it is in the mask by definition and the formula prices it. Keeping the support without `D_k` in the target needs an extra paid job `D_k^{-1}` of rank at least 8 per port, against `S = 760/104 = 7.31` per port: one compensation job per port gives `S = -72` and no positive kappa. Families that look cheaper only by ignoring this are cost-model artefacts.

**Lemma 8 (dense x and dense y) [P for private fields; C exact for L <= 8].** Drop R2: field `c` has mask `M_c` and host set `Y_c` (sites where `y` has a `c`-component); `x` is free on the whole mask. (a) `cost_c >= c(m) + (h-1) f(8)`. (b) `c(a) + c(b) >= c(a+b-1)` (sharing a host). (c) The sign-cover argument transfers: with `F_i` the union of masks of fields hosted at `i`, `#{i : n_i <= t} <= min(2t, L)`.
**Theorem A (all L).** If every non-A field has one host (a row may host several fields) and every row hosts a field, then `D_root >= chain_D(g)`, equality only for chain and twin. Proof: `sum_c cost_c >= sum_c c(m_c) = sum_i sum_{c in C_i} c(m_c) >= sum_i c(n_i) >= sum_k c(ceil(k/2))`.
Exact data [C]: all families with `>= L-1` fields and cost `<= chain`, every (interval, host-subset) type, were enumerated; the sign prefilter keeps 10 (L = 4), 34 (L = 6), 60 (L = 8) of 1365 / 1,677,563 / 5,407,049,079; the Groebner decisions over Q give: L = 4: chain, twin and four uncovered-pivot families (savings 3.43957 twice, 0.43858 twice); L = 6: chain, twin and two pivot families (0.43858 twice); L = 8: chain and twin only (58 below-chain survivors, all unrealizable). A separate run over arbitrary (non-interval) masks with class-cancellation conditions gives the same realizable sets at L = 4, 6, 8. The pivot family has saving `2c(1) - c(L/2+1)`: +0.43858 at L = 6, a loss from L = 8 on (`-1.80` at L = 8, growing) [C]. `check.py` recomputes cost and sign prefilter of every stored family, redoes the L = 4 and L = 6 enumerations in Python and, if Singular is installed, re-runs all 104 decisions.

**Lemma 9 (roots with one extra unit) [P under R1-R4; C].** Rank-2 normal form: `rank Z = N - n = 2`, `Z = P Q^T`, `Z_ii = 1`, moduli of dimension `2n - 2`. A zero `G_ij` occurs only at an incidence in `P^1`. Under R1-R4 the productive-by-productive part of `Z` has rank <= 2; for rows `i<j<k` the sign columns of the blocks left outside all three masks span at most 2 dimensions, which forbids a free column in `B1` and `B2` together with `B0` or `B3`. Counting lemma: at most `5t` sites have mask size `<= t`, so the `k`-th smallest mask is `>= ceil(k/5)` and
`D_root(e=1) >= f(8L+1) + sum_k c(ceil(k/5))`, which at `L = 18` is `1276.03`, above the break-even `1120.2` (even `ceil(k/13)` gives 1136.3). [C] the exact minimum of the rank-2 relaxation at L = 4, 6, 8, 10 is 0.892..0.916 of the chain; the rank-1 version reproduces the chain bound; the counting lemma was checked by exhaustive search for `t = 1, 2, 3`, `L <= 12`. A second all-field would cost another `f(8L+1) = 721.7`. Not covered: dropping R2/R3 at `e = 1`, `e >= 2`, liveness.

**Lemma 10 (border and CLEAR) [Q, scoped].** A border root that beats Dieudonne's +1 has first and last units with a high-order pole and is never slot-transparent (priced -13.76% in the best case; no root if a bad unit is native). A discarded scratch that saves the +1 touches every unit and charges every native plane a junk direction (at least 144 rank mass per port per stage), giving `S = -14112`. Conservation theorems for named classes only.

**Lemma 11 (bases; D-valued coefficients; D-jobs).** The verifier's event vocabulary has literal rational coefficients for ADD/SCALE and enters `D_s` only as a monomial shift of whole rows (LOCAL, IDLE), so every legal word is `C_N Delta_{N-1} C_{N-1} ... Delta_0 C_0` with `C_j` constant over `Z[1/2]` and `Delta_j` coordinate-diagonal D-monomials; ordinary bases, frames and transports are D-free by construction. This makes "D-free bases" (H2) a convention of the verifier, not a consequence of the symbolic identity: [C] at `L = 2` a D-dependent gauge `g = I + (D_a D_b - 1)E_{30}` leaves `M(D)` unchanged but 4 of 5 factors leave the legal form, and realising it needs a D-valued coefficient. A D-valued coefficient is an address-mixing step, not a scalar; the only consistent reading is an owned-copy child call, an uncredited job of rank `8|J|`, priced `f(8|J|)` per port (`f(8) = 16.64`, `f(16) = 44.36`) with no productive credit and at least `v * 8 = 832` of `S` per incidence (`S = 760` available), so any extra job gives `S < 0`. [C] at `L = 2` with fixed bases: one job `I + c m(D) E_ds` placed in any of the six slots of the chain word gives no diagonal `M(D)` (0 of 1296), and with one thin query removed 0 of 3240. **Open:** the *J-staircase lemma* (extend the sign-factorisation and counting lemmas to words whose compression contains rank-one `D_J`-dependent factors); and the sign of the idle term in the invoice relative to relocated jobs (a job that relocates an idle run adds `f(8|J|) >= f(8r)`, which raises `D` under the discount reading).

## 3. The theorem

**Theorem (consolidated root optimality).** Let a root be as in section 1, `L = 2g` productive sites, satisfying the hypotheses of section 4 marked "assumed". Then:
1. (Dieudonne, rigidity) `N >= n+1`, `n` is even, the shortest root is the unique sign-Gram root up to field frame, and it carries a single all-field of rank `8L+1`, optimal among pair-covering topologies (Lemmas 1, 2, 4).
2. (D optimality) `D_root >= f(8L+1) + sum_{k=1..L} [f(8 ceil(k/2)+1) - f(8 ceil(k/2)-8)]` with equality only for `chain(g|g)` and its twin: `1418.8458829` per port at `L = 18`. Valid with dense `y` and `x` for all `L` in the single-host class (Theorem A) and by exact decision for `L <= 8` in general (Lemmas 5, 8).
3. (S conservation) Each unit beyond `n+1` lowers `S` by `v`; direct sums of `b >= 2` shortest roots have negative true-S gain, best -4.80% (Lemma 6); roots with `e = 1` need `D_root <= 1120.2` and have `D_root >= 1276.0` under R1-R4 (Lemma 9).
4. (Pricing) the formula is the root part of the #6833 invoice to 1e-40, and the exact kernel changes it by -0.78% without changing the optimiser (Lemma 7).

## 5. Open items (stated, not closed)

1. **Twisted site-frame masks.** SPEC-style whole-job credit forces only `P_k = U_k E_k U_k^{-1}` with `E_k` the coordinate output mask; `P_k = E_k` is an extra assumption. Facts: sites 0, 1, N-2, N-1 are untwisted if the unit lies inside its mask; a twisted site needs `2 <= k <= N-3`; a unit inside a mask needs `|S| >= 2`. An exact twisted witness over Q exists at n = 4 (`P_2` on coordinates {0,1,2}, `E_2` on {1,2,3}), outside the regime where Lemmas 5 and 8 were proved (`J(D) != -I`). **Closed at L = 2** (n = 4, N = 5): a validated pricer (reproducing chain(1|1) = 87.7147, chain(2|2) = 217.9930, chain(9|9) = 1418.8458829299) puts every twisted-mask root at `>= 90.854 > 87.7147` in a frame-free relaxation, and twisted sites with `|S| = 2` do not exist (Groebner basis `{1}` over Q for `S = {0,1}`, `S' = {2,3}` and `S' = {1,2}`; `supp/twisted_site_singular.py`, run with `--twisted`, about 90 s). **Open for L >= 4.**
2. Fields shared by `h >= 2` hosts and pivot rows at `L >= 10` (Lemma 8 proves only single-host fields for all L; a charging argument has a thin margin at L = 18 and reverses only beyond L of about 5000).
3. Roots with `e >= 2` extra units; dropping R2/R3 at `e = 1`.
4. The J-staircase lemma (Lemma 11).
5. Escapes outside the model: non-coordinate masks, rank-2 units, non-gadget implementations, and the border/CLEAR escapes of Lemma 10.
