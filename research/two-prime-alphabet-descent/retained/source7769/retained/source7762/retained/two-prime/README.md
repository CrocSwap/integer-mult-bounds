# One-column completion over two-prime odd alphabets

This scoped proof was produced by Nick Petalas. Apache-2.0.

Let `m = p^a q^b`, where `p, q` are distinct odd primes and `a, b` are positive.
Let `A` be an `n`-by-`(n-1)` matrix with entries in the `m`th roots of unity
and `A* A = nI`. If `3 <= n < pq` and either prime divides `n`, the unique
normalized missing column uses only `m`th roots. It preserves every supplied
column. For example, at alphabet order 15 this covers row counts 5, 6, 9, 10,
and 12 in addition to 3.

The proof gives a separate sufficient condition at any `n >= 3`. Project each
entry to one prime-power component in its unique factorization into a
`p^a`th root and a `q^b`th root. If that projection preserves column
orthogonality, the missing column uses the original alphabet.

## Proof

Write `P = p^a` and `Q = q^b`. By symmetry, use the projection `pi` that sends
`x y` to `x` for `x` a `P`th root and `y` a `Q`th root. Denote the
projected matrix by `B = pi(A)`.

**Orthogonality below `pq`.** For any two distinct columns of `A`, their
inner product is a vanishing sum of `n` roots with repetitions allowed.
Lam and Leung show that every such sum over this alphabet splits into
rotated prime cycles. If there are `r` `p`-cycles and `s` `q`-cycles, then
`n = pr + qs`. When `p` divides `n`, it divides `s`. A positive `s`
would give `n >= pq`, so all cycles have length `p`. The projection sends
each rotated `p`-cycle to a rotated `p`-cycle, which still sums to zero.
The projection commutes with phase inversion, so these are exactly the
off-diagonal column inner products of `B`. The diagonal entries stay
`n` because each projected entry has modulus one.
[Lam and Leung, Theorem 3.3 and Corollary 3.4](https://arxiv.org/pdf/math/9511209#page=7)

**Removing the sign.** Use the normalized missing columns
`w = (nI - AA*) e_1` and `v = (nI - BB*) e_1` from PR #5865.
That result gives `w_i` among the `2m`th roots and, because `B` uses an
odd prime-power alphabet with `n >= 3`, it gives `v_i` among the `P`th roots.
Thus `w_i = eps x y` for `eps` equal to 1 or -1 and roots `x, y` of orders
dividing `P, Q`, respectively. [PR #5865](../cyclotomic-column-completion/PROOF.md)

Let `X, Y` represent primitive roots of orders `P, Q`. The ring of integers
generated by these roots has the presentation
`Z[X,Y]/(Phi_P(X), Phi_Q(Y))`. The monic relations give a basis of
`phi(P) phi(Q)` powers, and these powers are independent over the rationals
because the roots generate the cyclotomic field of degree
`phi(PQ) = phi(P) phi(Q)`.

Reduce coefficients modulo `q` and send `Y` to 1. This gives a ring map
to `F_q[X]/(Phi_P(X))` because `Phi_Q(1) = q`. It sends each entry of
`A` to the same residue as the corresponding entry of `B`, including
after conjugation since conjugation inverts the roots. The column formulas
therefore give the same residue for `w_i` and `v_i`.

In the residue ring the class of `X` generates a group of odd order dividing
`P`, since `X^P = 1`. The element `-1` has order two because the
ring has odd characteristic. The residues of the `P`th roots and their
negatives lie in disjoint cosets. The equal residues of `w_i` and `v_i`
force `eps = 1`. This proves the sufficient condition and, with the first
step, the row-count theorem.

## Exact examples

The first fixture has row and column indices `(r,s)` and `(j,k)`
in `{0,1,2}^2`. Its entry is
`zeta_3^(rj+sk+sj) zeta_5^(sj)`. If two column indices differ in `j`,
the sum over `r` vanishes. With equal `j` and different `k`, the sum over
`s` vanishes. Both arguments survive projection to the third roots.
The cross ratio on rows `(0,0),(0,1)` and columns `(0,0),(1,0)`
has order 15, so the mixed phases cannot all be removed by row and
column scalings into either prime-power alphabet.

The verifier uses integer power bases modulo the two cyclotomic polynomials.
It checks 6 mixed fixtures, all 86 single-column erasures, and all 1,574
recovered entries and their opposite signs. The fixtures include order 225
and a 25-row order-15 example for which the sufficient condition applies
outside the automatic row-count range. The two projection controls use
an eight-term sum of one 3-cycle and one 5-cycle, and the 15-row partial
Fourier tensor. The latter retains a collision under either projection
and marks where the automatic projection argument can fail. It has an
original-alphabet completion.

## Reproduce

Run from the repository root with CPython 3.12.15 and its standard library.

```sh
python3.12 -I -W error -B research/two-prime-column-completion/verify.py
python3.12 -I -W error -O -B research/two-prime-column-completion/verify.py
python3.12 -B scripts/research_package.py --package research/two-prime-column-completion
python3.12 -B scripts/check_research_commit.py --package research/two-prime-column-completion --check-source-history
```

The direct checks print `PASS_TWO_PRIME_COLUMN_COMPLETION`. The verifier uses
fixed inputs of at most 25 rows and 25 columns. Its coefficient tables have
at most 120 entries and its exponents are reduced modulo fixed prime powers.
Python allocates these bounded objects and dispatches their operations at
runtime. No runtime source files, external dependencies, or generated files
are needed. Both registered modes keep the mathematical checks active.
