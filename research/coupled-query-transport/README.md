# Coupled outputs through two real query consumers

This package supplies a source-bound two-generation test of Dillon's coupled
provider in PR5402. The first return survives the actual next paid query, but
its defect cannot be absorbed solely by updating the following FULL's eight
helper inputs: the necessary equation W3 T=D1 W1 fails even for arbitrary
linear T. A 17-bit, phase-correct witness has residual rank eight. The zero
address alone incorrectly passes; a nonzero central input exposes the defect.

A constructive local exit identifies a smaller useful observation contract:
**b=ZQY, eight versioned fields**. If supplied at the native return, it restores
all original outputs with eight H1 calls, 456 ADDs and 240 monomial field maps,
and preserves the borrowed observation. Buying a full QY response instead
costs 120 H1 calls per replacement. On the selected controller's 16 backward
FULLs that purchase changes rank surplus 752 to -16 and fails an exact .004
moment screen. All existing queries remain paid. An already executed consumer
needs its propagated defect repaired too; the local exit is not a free late
repair.

[PROOF.md](PROOF.md) gives the exact contracts, source chronology, physical
Gram witness, local operation bills, residual-error bound and limits.
[RESULT.json](RESULT.json) records the reproducible rational evidence.
No complete coupled recursive family, compiler admission or new κ is claimed.
The selected conditional κ remains 0.0030217758. This is an author-checked
scoped result, not independent human or formal-kernel acceptance.

The same fourteen consumer instructions are byte-equal in the newer PR5398 all-backward caller, at events 5 through 18. The checker also rejects the purchased-response price screen against PR5413's declared neutral profile; this comparison does not replay or admit that primary construction.

## Reproduce

```sh
python3.12 -B scripts/research_package.py --package research/coupled-query-transport
```

The normal and isolated optimized commands use Python's standard library and
explicit checks. They authenticate inputs, interpret all 120 monomial maps on
all 512 addresses including phase, replay the two source consumers, reconstruct
the selected whole invoice, calculate the exact residual Gram matrix, reject
semantic mutations, and compare every result field. Expected token:
`PASS_TWO_GENERATION_COUPLED_QUERY_TRANSPORT`. Runtime is a few seconds. All three literal exit programs are generated and replayed on every adapter input column; their exact operation counts and payload hashes are recorded. To inspect their instruction arrays, add `--emit-exits /tmp/coupled-exits.json` to a direct verifier call.

The mathematical native endpoint and its uniform physical model are explicit
pinned premises. No full native provider replay, selected cold replay, all-history
suite, Lean, Docker or outer/compiler admission is run for this local result.
