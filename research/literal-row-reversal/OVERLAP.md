## Precise proposed claim

One fixed local-symbol program consumes three supplied canonical binary
P,R,B descriptor fields and a complete ordered bit array, reverses whole
records within each prefix, validates exact cardinality before modifying
DATA, commits on the same owner, and restores all private banks/heads.
Uniform linear cost includes binary-to-unary setup, every reset, complete
staging, source return, commit, retirement and retained historical backing.

## Cost and composition gate

The initial optimistic complete budget was `65536(V+E+1)` time and
`K0+8V+2E+32` private history. The actual graph admits the substantially
sharper exact census in PROOF.md and history `K0+8V+E+18`. Since each unary
P,R,B guide is at most V, unary expansion does not create a hidden factor.
GROUP's peak is RB; OUTPUT and DTRACE each reach the entire V, and both
are explicitly charged.

For `R=2^f` the exact row map is all-ones XOR on a contiguous f-bit block.
For the retained `flip_digit` source on the complete d-bit rectangle
`V=2^d b`, `P=2^j,R=2,B=2^(d-j-1)b` matches its left-numbered bit-position
map. On other accepted complete slab multiples, use `P=V/(2^(d-j)b)`.
This makes a useful scoped caller join.
No free stride-K packing or free collapsed-descriptor production is assumed.
The whole current monomial caller is still open, and no kappa change follows.

## Stopping rule and disposition

The task would have stopped on an already matching literal same-owner full
field routine, an incompatible complete bill, or absence of a useful source
join. None was found in the bounded evidence above. The completed result
must still receive independent graph and universal-proof review before the
parent publishes it. A later package that supersedes the scope should be
credited and recorded without rewriting these frozen predecessor facts.
