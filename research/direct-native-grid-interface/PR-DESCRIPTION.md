## Sequential follow-up: bind native requested return precision to exact raw H

The original direct word uses exact raw Hadamard sums and differences,
while the retained native interface returns a normalized layer after a
final toward-zero truncation. This source-bound supplement makes the
requested output grid explicit and proves the exact encoded return.

For an h-bit call on P-grid input of modulus at most 2^E, set R=E+1 and
Q=P+R+h. Shift every input integer numerator left by h and supply the full
field at precision Q. The normalized output is already on Q-grid, making
final truncation transparent; its integer numerators are exactly the
external raw-H result at precision P. A one-bit-coarser return erases a
legal basis input, so Q is sharp for this scaling and unchanged service.
