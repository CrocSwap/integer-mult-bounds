# Actual JSON format adapters

Author-checked source context: kappa = 836330098538459/500000000000000000 = 0.001672660197076918. These generic theorems do not use kappa, change it, or establish the full multiplication theorem.

This package adds four dimension-parametric Lean modules, totaling 31,026 source bytes. They consume actual `Lean.Json` values and reuse nine unchanged public modules. `SOURCE_MANIFEST.json` gives all exact hashes, public prerequisite revisions and the complete thirteen-module import order. `ACCEPTANCE.json` records the nineteen observed axiom probes and six complete printed types for the accepted sources. All four final checks produced no warnings or errors; a separate peer independently reviewed each source and completed result.

## Results

- `JsonTableGather`: successful bounded index-array decoding yields the ordered logical payload list, for arbitrary payload universes, lengths and repeated indices.
- `JsonOwnerFieldAdapter`: strict two-field rows preserve each bounded family, complete raw route and its actual decoder equation. Named `owners` lookup and an executed assignment comparison derive ordered payload output.
- `JsonGlobalCallAdapter`: checks the actual `calls` array count, selects its original bounded position, and composes the complete owners decoder. Missing fields, wrong shapes and count mismatch fail explicitly. Success retains both selected field ASTs.
- `JsonPackedColumnDictionary`: decodes a named dictionary entry into bounded ordered packed columns, checks a separate auxiliary JSON certificate and compares its columns, then derives the column operator, inverse laws and arbitrary-payload cancellation.

The source-matched formats are the ordered `calls`/`owners` fields and the key-to-packed-column-array ACTUAL-SIGMAS dictionary emitted by the exact source listed in the manifest. Object field lookup uses keys; no dictionary iteration order is used as a call or owner ordering.

## Boundaries

Successful checking of an original selected artifact, byte-to-AST interpretation, duplicate-key rejection and digest validity remain separate. The numeric rule is exponent-zero in the `Lean.Json` AST; it is not a lexical integer-only guarantee. Array order and repeated entries are retained. The provider dictionary does not emit the auxiliary chart certificate fields, which remain separate checked inputs. Physical C allocation, complex phase, executor direction, precision and priced memory access/copy/time/space are not established. Gathering is a logical out-of-place read operation.

Canonical owner export and restricted provider recovery follow-ons are outside this four-module package. See `REPRODUCE.md` for hash-checked public-source retrieval and topological checking in fresh scratch.
