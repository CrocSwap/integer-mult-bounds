# Exact minimum state under a restricted update group

Let G be a finite abelian group, let d:G -> A be an arbitrary function and
let H be a subgroup of G. A code consists of a map c:G -> C, a decoder
v:C -> A, and update maps u_h on the reached code states, such that

    v(c(x)) = d(x),     c(x+h) = u_h(c(x))       (x in G, h in H).

Updates may read h and the code, but not x or another source observation.
Unused states in a binary implementation are outside this abstract definition.
No linearity or additivity of c, d, v or u_h is assumed.

**Theorem.** Define the signature S_H(x)=(d(x+h))_(h in H). The minimum
number of reached states is exactly |{S_H(x):x in G}|. Its equivalence classes
are the coarsest H-translation-stable refinement of the fibers of d.

*Necessity.* If c(x)=c(y), then u_h(c(x))=u_h(c(y)), so applying v gives
 d(x+h)=d(y+h) for every h in H. Thus different signatures require different
codes. This argument applies even if the original code keeps extra history,
provided its state is a function of the current x as stipulated above.

*Sufficiency.* Use S_H itself as c. The decoder takes its h=0 coordinate.
Translation by k in H maps the coordinate at h to the old coordinate at h+k.
If two inputs have the same signature, their translated signatures therefore
agree. This defines u_k independently of the chosen input representative.
It has inverse u_-k, hence is a permutation of reached code states. These
maps satisfy u_h u_k = u_(h+k). Each can be extended to a permutation of
all b-bit labels, b=ceil(log2 |C|), by fixing unused labels. This extension is
an abstract reversible permutation, not a circuit or a free operation. QED.

For a specified generator alphabet, take H to be the subgroup it generates.
If only positive repetitions of a generator are allowed, the same result holds
on finite G because its inverse is a positive power. If only one update is
ever allowed, or if future choices depend on extra source information, this
H-closed contract does not describe that caller.

When H=G, equality of signatures is equivalent to x-y being a global period
of d. For proper H the classes need not be additive cosets or have equal size;
calling this code a quotient group would in general be wrong. For H={0} the
classes are exactly the pointwise fibers. These are the predecessor's two
endpoint contracts, recovered as controls rather than claimed as new.

## What this decides

The exact reached-state counts and fixed-bit minima are in RESULT.json. At
ranks two and three, even one repeatedly updated coordinate can remove the
one-bit pointwise saving. This tests a deliberately favorable restriction of
the mutable-source mechanism. It does not prove an all-rank obstruction or
exclude a different restricted direction, bounded update horizon, changed
lifting word, variable-length coding, or a consumer with source-dependent access.
No rank-seven defect image is counted or extrapolated.

State minimization does not bound circuit size, peak physical storage, work,
communication or recursive cost. Acquisition must compute the code; update and
decoding permutations must be implemented and uncomputed according to the
actual caller. A code oracle used inside the predecessor's dirty consumer
still pays two numerator shears, two defect additions and two quotient reads.
Defect additions via compute/add/uncompute each pay their oracle twice, the
wide add and all code/output/ancilla banks. Arbitrary borrowed dirt must return;
a state permutation alone does not establish this physical caller contract.
