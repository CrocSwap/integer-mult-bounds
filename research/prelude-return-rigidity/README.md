operators 47–58 cannot widen their later prelude contacts or inverse return.

theorem. The new source bound starts **after the inverse**, at the next scalar
contact. Eight literal paths to main-Y exits force this space into the original
main-X entrance line. Consistency of one invertible G and its inverse closes

```
<a> <= U <= G^-1 V = W <= next contact <= <a>.
```

The argument releases all helper and owned boundaries and cuts every other
native-warp incidence. It uses no paid census, floating solver or native-map

This is a scoped construction constraint; it establishes no new kappa,
moment ceiling, native supplier or full multiplication theorem.

## Evidence and scope control

The frozen source is Cao Yifan's PR4610 round-three word, payload SHA256
`cfcd36b40326d7a5815e1db5313444379b3fb756b27d5201c561574c085cc0dd`.
The source certificate checks 96 paths and 993 literal owner links in each
orientation. Each eight-normal matrix has rank eight; a separate enumeration
of all 512 vectors confirms its one-dimensional kernel. Six certificate
corruptions and one source-byte corruption are rejected.

A separately written checker imports neither the generator nor its graph
builder. It reconstructs individual owner timelines, all reachable main-Y
exits, and all 1,986 submitted path links. This is separate AI-assisted finite
verification, not independent human or proof-kernel acceptance.

Deleting the single scalar-owner edge `(9067 -> 9068, owner33)` makes a
three-dimensional return feasible in the relaxed containment model. The
positive control checks every other edge and gives an explicit invertible G.
It is not a valid new native circuit: the missing dependence would need an
actual replacement program with its complete paid bill. Thus the scope does
not extend to changed scalar graphs or nonmonotone paid itineraries.
