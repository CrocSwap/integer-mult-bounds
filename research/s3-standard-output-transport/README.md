# Faithful S3 output transport across recursive child boundaries

This scoped recursive-interface construction carries noncommuting workspace
changes through a smaller, faithful two-dimensional output. For the seed-58
eight-child example, the complete dirty echo uses **404 scalar ADD/NEG
instructions instead of 524**, saving **120**. The boundary alone costs **36
instead of 96**. Both copies, both directions of every child, physical output
frame operations, and final restoration are included.

No selected supplier or new kappa is claimed. The fixed-child interface is
essential: opening these small matrix leaves permits cheaper direct evaluation.
No actual multiplication supplier with this indivisible boundary has been
identified. The forward prefix row-L1 bound grows from **65 to 114**. This is
instruction-count evidence, not a runtime, precision, or complete-theorem result.

## What this adds

Ross Richardson's [PR1287](https://github.com/CrocSwap/integer-mult-bounds/pull/1287)
already gives cyclic output frames and the admission gate `R P = Q R`, following
Sagar Thakrar's paid sign frames in
[PR1227](https://github.com/CrocSwap/integer-mult-bounds/pull/1227). General output
transport and dirty-echo cancellation remain predecessor credit.

The added case has **noncommuting output transformations**, including a genuine
two-register shear/negation. Its faithful output retains the whole six-element
group action. The active
[Discussion1381](https://github.com/CrocSwap/integer-mult-bounds/discussions/1381)
instead investigates a one-row sign-character output with a nontrivial kernel.
That concurrent scope was inspected before claiming this work; its results are
provisional and are not a dependency here. A scalar representation cannot be
faithful for a nonabelian group, since nonzero scalars commute. Two dimensions
are therefore necessary for this faithful-transport requirement and suffice
below. This is not an output-width lower bound for other tasks or interfaces.

The new evidence is the exact integer representation, its admitted reader
class, a chronological six-state recurrence, complete primitive words,
independent unaligned-schedule enumeration, and recursive dirty-state replay.
The implementation imports no predecessor verifier. Exact references and
notices are retained in [PREDECESSORS.json](PREDECESSORS.json).

## Fixed child and frame contracts

Work over characteristic zero. The six group elements, in the certificate's
order, are the integer matrices generated by

```
Q_s = [[0, 1], [1, 0]],       Q_t = [[-1, 0], [-1, 1]].
```

They obey `s^2=t^2=(st)^3=e`, and `st != ts`. They can also be derived by
permuting three coordinates and acting on `(z1-z0,z2-z0)`; `oracle.py` uses that
independent description. This is an algebraic derivation, not a runtime
conversion or a hidden third output register.

Index the six arbitrary dirty workspace coordinates by `h in S3`. Let
`P_g e_h = e_(gh)` be the left regular permutation. The two-output reader

```
R(v) e_h = Q_h v,                 v in K^2
```

satisfies `R(v) P_g = Q_g R(v)` for every `g`. Conversely, any intertwiner has
this form: its column at `e` determines every column by the same equality.
Thus admission is a reader-class characterization, not just a test of the
example. Checking generators `s,t` suffices by closure. `R((1,0))` has rank two.

Each fixed, indivisible child has a known drift `g_i` and the contract

```
C_i(D,W) = (D + R(v_i) W, P_(g_i) W).
```

It preserves private dirty scratch and exposes its literal inverse with a
complete price. The parent uses the same frame schedule for every independently variable
tuple of admitted readers `v_i`. It may insert only complete `P_a` operations on the
six workspace rows and complete `Q_b` operations on the two output rows in
gaps around the ordered children. Source and output rows are disjoint; none
is descendant scratch. No copy, temporary, frame annotation, role change,
or primitive is free. The emitted integer examples require no clean cell.

Nonidentity `P_g` costs 12 instructions in the declared cycle backend: an
order-two element has three swaps, each `3 ADD + 1 NEG`; an order-three
element has two three-cycles, each six signed ADDs. The latter is the existing
cycle word retained by PR1287 and credited there to PR1145. No new unrestricted
permutation-circuit optimum is claimed.

In certificate order, `Q_g` costs `[2,4,4,4,2,0]`. Literal words are in
`model.Q_WORDS`. A separate exhaustive breadth-first enumeration of all
two-register signed ADD/NEG endpoints through radius four checks these local
minimum costs: its layer sizes are `1,6,21,58,122`. This excludes temporary
registers and other primitive alphabets. For example `Q_t` is just
`D1 -= D0; NEG D0`. Every group frame is physically emitted.

## Exact chronological boundary recurrence

Before a child, write the workspace frame as `p` and output frame as `q`.
Its normalized response is `Q_q^-1 R(v_i) P_p W = Q_q^-1 Q_p R(v_i) W`.
Uniform correctness for independently variable readers forces `p=q`: set all
other readers to zero and use the rank-two reader `R((1,0))`; faithfulness then
forces equality of group elements. Conversely, aligned phases are sufficient.
This necessity concerns uniform schedules. It does not exclude accidental
cheaper words for one fixed tuple of readers.

At aligned phase `t`, child `g` leaves workspace phase `gt` and output phase
`t`. To reach aligned phase `u`, the unique gap is

```
a = u t^-1 g^-1      on workspace,
b = u t^-1          on output,
c_g(t,u) = cP(a) + cQ(b).
```

Order matters. Moving `g^-1` to the left is generally wrong; a mixed-frame
positive/negative pair in the verifier isolates this error. In the optimal
seed word every gap happens to be pure workspace or pure output, so that word
alone would not detect the bug.

With arbitrary entrance frames charged, the exact boundary recurrence is

```
F_0(t) = cP(t) + cQ(t),
F_(j+1)(u) = min_t [F_j(t) + c_(g_(j+1))(t,u)],
B(g_1,...,g_k) = F_k(e).
```

Both endpoints are canonical. A required canonical cut after child `j` restricts
that layer to `u=e`. At a normalized aligned boundary, canonical output also forces phase `e`
because this representation is faithful. A sign-character output can instead
have an invisible nonidentity aligned phase. Observing partway through a
mixed, unaligned gap is a different interface and is not optimized here.

Every uniform legal word reduces to such a path. Workspace and output frames
act on disjoint registers and commute with each other. Within either register
their products are group elements. Replacing multiple workspace macros by the
single reduced macro never increases cost (`cP=12` off the identity), and the
output's minimum primitive costs obey the triangle inequality. Conversely,
every path emits a legal word. Induction proves the recurrence for every finite
child list. The finite census checks its implementation; it is not the proof
of the all-length statement.

The seed chooses group indices `[4,1,1,1,0,1,3,3]` using `random.Random(58)` after
the OS assignment draw. The optimum path is `[5,4,0,0,3,2,5,3,5]`, where `5=e`.
It costs 36, versus 96 for eager workspace restoration. The certificate also
contains forward distance potentials. An independent checker verifies all 288
transition inequalities plus six entrance inequalities by enumerating actual
permutation-frame pairs, without the planner's gap formula. These prove a lower
bound of 36; the emitted path attains 36. An overstated bound is rejected.
Requiring a canonical frame after child four costs 46 and yields a complete
echo of 424 instructions.

**A frame checkpoint inside the batch is not a public source-only checkpoint
inside its dirty echo.** It still contains the current workspace's contribution.
Public observation waits for the whole echo; splitting the echo for earlier
observations requires another priced contract. The verifier rejects conflating
these two interfaces.

## Complete echo and recursive invoice

Let the completed batch be `H(D,W)=(D+R_total W,W)`, where
`R_total=R(sum_i v_i)`. Execute

```
W += X; H(D,W); W -= X; H^-1(D,W).
```

The result is `(D+R_total X,X,W_initial)` for every initial dirty `D,W`.
The inverse is the literal reversed instruction word, not another forward
call. Nonlinear readouts do not inherit the cancellation.

A leaf emits its integer reader ADDs and complete `P_g` drift. An internal
child emits this echo, then `P_(g_v)` on its own source. Reader sums remain
intertwiners, so this closes the recursive contract. Siblings reuse a workspace
only after a complete return. A leaf uses eight scalar registers; a child of
depth `h` uses `2+6(h+1)`; an echo over children of maximum depth `h` uses
`2+6(h+2)`.

With `J_v` counting all emitted ADD/NEG instructions, including descendants,

```
leaf:      J_v = sum_abs_entries(R(v)) + cP(g_v),
internal:  J_v = 2 sum_i J_i + 12 + 2 B(g_1,...,g_k) + cP(g_v),
root echo: J   = 2 sum_i J_i + 12 + 2 B(g_1,...,g_k).
```

The 12 is both six-coordinate source-copy passes. Eager restoration substitutes
`sum_i cP(g_i)` for `B`. This is a complete depth/instruction recurrence. It is
not a contracting input-size recurrence or a new supplier moment. For length-L
arrays with componentwise exact operations, every scalar instruction expands
to L instructions; the identity holds over any vector space. The receipt
includes literal L=2,3 tensor lifts, with every component charged.

| Complete scalar echo | Eager | Transport |
| --- | ---: | ---: |
| ADD | 476 | 372 |
| NEG | 48 | 32 |
| All instructions / writes | 524 | 404 |
| Data reads | 1,000 | 776 |
| Four-field instruction records | 2,096 | 1,616 |
| Declared data-address travel | 3,796 | 3,558 |
| Registers, all possibly dirty | 14 | 14 |
| Forward prefix row-L1 peak | 65 | 114 |

An ADD reads two cells and writes one; a NEG reads and writes one. Each literal
instruction has four fields. The travel score follows source then destination
for ADD, destination for NEG, starting and returning to address zero. It is a
specified access-trace score, not a physical tape-machine construction.

Coefficient access is included in the emitted integer word: signs and operand
addresses are instruction fields, with larger integer coefficients expanded
into repeated signed ADDs. There is no runtime coefficient oracle. Parsing the
tree, validating admission, planning, materializing and reading this word are
additional preparation/program costs. The tuple-path planner takes O(k^2)
time and O(k) live state for a k-child node (six states, path copies); sum this
over internal nodes. A conservative emission/preparation bound for tree
description size M, output length J and height h is
`O((h+1)(M+J) + sum_v k_v^2)` time, with materialized word storage O(J) in
addition to the tree, plans and call stack. No preparation speedup is claimed.

Exact arithmetic is assumed. The recorded row-L1 peaks bound intermediate
magnitudes for bounded inputs, including every emitted prefix; standalone
inverse peaks are recorded separately. Larger coefficients may cost more bits.
Rounding, fixed precision, physical source layouts, tape access, hosting,
common-label realization and outer analytic transfer remain unproved or
inherited from any future supplier using this interface.

## Reproduce and completed coverage

Python 3.12, standard library only, from the repository root:

```sh
python3.12 scripts/research_package.py --package research/s3-standard-output-transport
```

Expected main marker:

```
PASS_S3_STANDARD_OUTPUT boundary=36_vs_96 echo=404_vs_524 saved=120 controls=11 no_new_kappa
```

The registered replay also runs five package tests and ends with
`PASS_REGISTERED_RESEARCH_PACKAGE research/s3-standard-output-transport outcome=completed`.
Direct replay is `python3 -I -O -B research/s3-standard-output-transport/verify.py`.
It recomputes every certificate field and fails on disagreement. `--emit PATH`
writes a fresh certificate and refuses to overwrite one.

Completed bounded domains, with no heuristic pruning:

- All 36 group products, 12 literal frame words, 150 exact intertwiner identities
  for `v in {-2,-1,0,1,2}^2`, and 300 single-entry admission mutations.
- All 378,504 unaligned schedules for every `s/t` word of length 1..3, after
  forcing only terminal frames. The independent oracle carries each child's
  separate response through actual permutation/difference actions; it does not
  use the planner's alignment condition or gap formula. Its 1,884 admitted
  schedules give the same 84 minima at workspace price multipliers 1..3 and
  output multipliers 1..2. Another 186,624 enumerated schedules check four
  canonical-cut policies and 24 price comparisons.
- 24 eager/transport recursive-child cases at depths 0..3, 816 forward/inverse
  basis columns, and 36,352 primitive occurrences. The seed root, constrained
  midpoint, and L=2,3 array lifts add separate exact full-state checks.
- Eleven semantic controls, including chronological multiplication, source copies,
  inverse direction, output transport, premature observations, replacing the
  faithful output by a scalar sign, nonlinear readers, aliased instructions,
  and an overstated lower-bound certificate.
  Five package tests cover read-only relocation, immutable source/certificate
  mutations, a wrong output macro, and refusal to overwrite a certificate.

The independent implementation was written in the same AI-assisted session;
it is not independent human review or proof-assistant formalization. No full
selected-supplier cold replay was needed or run for this isolated package.

## Open next questions

The structured questions are in TASK.json. The material blocker is an actual
supplier with the admitted fixed-child boundary: a first step is to extract
its literal entry/exit maps and test the two generator equalities before
pricing a replacement. A favorable toy instruction count does not resolve
that admission or justify a new kappa.

For this interface, a second question is whether different equal-cost phase
paths lower the prefix magnitude bound. The first step would compare exact
prefix row-L1 envelopes on the finite set of tied minimum paths while
preserving the complete word and invoice. This session did not perform that
secondary optimization or make a precision claim.
