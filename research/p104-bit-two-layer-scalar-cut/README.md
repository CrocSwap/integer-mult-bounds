# Exclude three-scalar BIT repair for two lifted carriers

For two terminal carrier seeds in a fixed two-copy geometry, three same-clock scalar receipts from eligible original donor charts cannot restore both independent target directions.

The single-donor quotient is trivial. In a three-vector repair each distinct pair sum must be a nonzero target direction, so the selected charts need a triangle in the useful donor-pair graph. All 1,225 and 1,326 pairs reproduce the same two-edge star. Four receipts would force replicated grades {4,4,12,12} in this tested model, giving a negative partial tariff.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.
