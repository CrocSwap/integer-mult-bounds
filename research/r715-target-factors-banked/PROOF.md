## Literal bit address operators

Over each admitted odd address field, the inherited address matrix for a frame
with orthogonal projector P is

`D_P = [[I-P,P],[P,I-P]]`.

In sum/difference coordinates it has blocks I and `R_P=I-2P`, so equality of the
checked R blocks is equality of the doubled address operators. For nested P<=Q,

`D_(Q-P) D_P = D_Q`,

and the reflected path uses the same positive child:

`D_(Q-P) D_(I-Q) = D_(I-P)`.

Define the pullback `Lambda_P f(z)=f(D_P z)` on arbitrary bit arrays. Its action
depends on the frame and actual address chart. It does not depend on a register's
designation as source, target or helper. Inherited port routes bring operands
to the common local chart. For any two arrays a,b,

`Lambda_P(a xor b) = Lambda_P(a) xor Lambda_P(b)`.

The invariant is `physical_r=Lambda_current_r(formal_r)`, with initial formal
array `Lambda_start_r^-1(physical_input_r)`. Exact nested MOVE identities and
common-frame ADD linearity preserve it. The inherited charged COPY/scatter/ERASE
episode transports the temporary between source and scatter labels. Reflected
ERASE becomes a fresh COPY from the unchanged center, followed by transport from
I-F to I at the scatter; copied work closes afterward.

Thus a scalar map M lifts to
`diag(Lambda_final) M diag(Lambda_start)^-1`. Input and final words have identical
root lines, frame lists, initial/final labels, retained totals and A/C phases;

local array operator, including arbitrary correlated dirty contents, in both
