# The exact rational kernel of two-column GL3 tests

For G=GL_3(F2) acting on rational or complex payloads, the action on two
point columns has image dimension **150** and kernel dimension **18**.
Its entire kernel is generated by the explicit central element

    E = 6[1] - 2 sum_(order g=2) [g]
             + 2 sum_(order g=4) [g] - sum_(order g=7) [g].

The exact identities are E^2=56E and ker(rho_2)=Q[G]E, where
rho_f([g])=P_g^{tensor f}. A restored two-register word is formally
(x,y) -> (x+E y,y), yet is identity on every input at widths one and two.
At width three it has an explicit witness with 112 nonzero output entries.
The third-column regular orbit recovers every formal coefficient.

This is a **scoped algebraic proof with an exhaustive finite certificate**,
not a complete complex unit, supplier admission or new kappa. The added
information is the complete characteristic-zero kernel and a literal
restored witness for the finite-testing interface. [PROOF.md](PROOF.md)
gives the argument without relying on a character table.

## Why this question matters

Small tensor-width tests can accept a formal endpoint with a hidden cross-role
coupling. ywz65's [#2599](https://github.com/CrocSwap/integer-mult-bounds/pull/2599)
proved the sharp stream boundary over F2. Its group norm cancels in
characteristic two. That norm has value 168 at the fixed zero pair over Q,
so it is not this characteristic-zero witness. This package determines
exactly what the two-column Q or C action loses, rather than repeating
the earlier binary-payload result.

Jacob Alan Sussman's [#4628](https://github.com/CrocSwap/integer-mult-bounds/pull/4628)
provides the complex small-unit context and the warning that a fixed tensor
width alone need not certify a uniform program. Woklerx's
[#1440](https://github.com/CrocSwap/integer-mult-bounds/pull/1440) supplies a
different support-bound finite quotient criterion. Their results and executables
are cited, not audited or replayed here. Three-column faithfulness in this
note concerns only the address algebra, not words containing paid C-calls
or phase letters.

The first line of direct verifier output is

```text
PASS_GL3_RATIONAL_TWO_COLUMN_KERNEL group=168 image=150 kernel=18 E_squared=56E support=112 dirty_columns=144 no_new_kappa
```

The following JSON is a generated receipt binding the six package files by
SHA256. It records the complete modular minor, exact counts and controls.
An optional `--receipt /new/path.json` creates that receipt exclusively.
The verifier otherwise writes nothing and needs only the standard library.

It constructs the group independently from binary columns and elementary
row additions, checks all 168 convolution coordinates and all 4,096 entries
of the two-column annihilator, and recomputes a nonzero 150 by 150 minor
modulo the checked prime 65537. The idempotent trace supplies the matching
18-dimensional kernel. The chronological shear is replayed on all 144
dirty input columns at widths one and two and on its width-three witness.
Omitting each of the four nonzero order classes is rejected. The group norm
is checked to be visible over Q. The proof does not use a modular upper rank
as an upper rank over Q.

The base is canonical main `624de9dc66858af0945e5f8a0942488d62280d43`, priority
revision 7. The card `complex-rank-shape-decoder` changes to this interface

## Limitations

No paid-call optimum, phase-letter identity, complete engine test, physical
movement, precision, restoration price, compiler, stock or outer bound is
provided. The algebraic word restores arbitrary dirt, but its physical invoice
is unknown. No Lean build or full selected construction replay was run.
The selected source-binding orientation command was attempted and stopped
because the sparse checkout omits `research/fresh-helper-thinned/PROOF.md`.
That is not a failed scientific check of this package or of its predecessor.
Independent human and formal proof-kernel review are unclaimed.

The bounded verifier deliberately uses managed Python allocations. All
collection sizes follow from the fixed 168-element group, matrices of order
at most 168, and payload replays with at most 512 address rows and 128 input
columns per register. It has
no recursion, network access or unbounded search. Invariant failures use
explicit exceptions and remain enabled under optimization.

## Open next questions

1. Determine the characteristic-zero kernel for three-dimensional affine
   address maps at their last unfaithful width. This would identify another
   precise finite-test blind spot. Start with orbit-stabilizer data and an
   exact permutation Gram minor. The group size and certificate cost grow.
2. For a fixed small-unit candidate containing paid calls or phases, identify
   a sufficient tensor width or a formal algebra certificate. Start by pinning
   the actual generated operator algebra. The GL3 address-only proof does not
   cover those extra operators.
