## 7. Fixed tapes, setup and a new eventual threshold

The F-fold gives a finite number of streams/banks/descriptors and a finite
list of binary movement/phase recipes. The source depth-first fixed-tape
execution parks unused role streams and all live parent banks, executes a
child to completion, restores adapters/ordering and resumes the parent.
Tape count is fixed by F, not by online input width or tensor multiplicity.
Descriptor preparation, phase evaluation, normalization and every bank scan
retain their source cost. The ordinary tree has at most P^D(d)=d^O(1) nodes;
fixed larger setup degrees remain polynomial. The retained superpolynomial
record fiber absorbs those fixed degrees only after a new eventual threshold
and with strict epsilon<1. Neither setup nor parking is zero-cost.

For any selected rational epsilon=a/b in(0,1), normalized layer bound
`d<=c*p^epsilon` with fixed c>=1, let L be the binary bit length of
`4*C0*ceil(c)`, and set

`t=max(4,ceil(b*L/(b-a))); p_grid=2^t`.

Then for every p>=p_grid, `p^(1-epsilon)>4*C0*c`, and the new integer guard
`Delta=C0*d<=p/4`. A source signed component with p+Delta fractional bits
and Delta+3 magnitude/sign bits has width `p+2Delta+3<=2p`. This compressed
power-of-two description is effective; no such bit array is allocated.
The complete new eventual threshold is the maximum of p_grid, the stopping
condition `d^beta_stop>=2N`, new row-stock reserve threshold, all source
movement/record-reservation thresholds, prime/analytic thresholds, and new
fixed setup-polynomial absorption thresholds. Claiming old p0 suffices would
invalidate this specialization. The new constants affect these thresholds
