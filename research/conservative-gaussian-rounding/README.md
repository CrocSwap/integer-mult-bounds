# Conserved reversible Gaussian rounding

A changed nearest-grid Gaussian butterfly now preserves the exact pair sum,
commutes with global Gaussian unit phases, and has an exact same-grid inverse.
It needs no rounding history. Every input attains the least possible Euclidean
error among grid outputs. The proof classifies all optimal centers in the
stated affine-on-difference family, rather than stopping at one example.

The kernel is installed through an explicit backend argument in the complete
retained two- and three-call C0/C2 ports. Both arbitrary stored dirty banks
return exactly under the literal inverse program. The prior sufficient
accuracy and signed-width bounds remain valid. A complete native Cj tensor f
call also preserves4^f independent spectator-fiber sums exactly, including
through appropriately transformed monomial observables.

Reversible nearest-error lifting already exists in Tekalign's P104 package.
The new part is the exact sum/phase contract, its sharp center classification,
and the complete port binding. No new kappa, native admission or accelerated
recursive tariff is claimed.

## What the construction does not preserve

It is nonlinear, fails pair exchange and common translation covariance, and
rounded axes need not commute. [PROOF.md](PROOF.md) gives explicit failures
and scoped incompatibility proofs. An inverse must reverse the actual stage
order. The result does not repair arbitrary native graph cycles or permit
linear supplier identities to be applied to the rounded map.

## Cost, sources and scope

For N=8^f, each direct call costs fN/2 pair operations. A k-call port costs
kfN/2 pairs plus all retained mixing, four or six monomial passes, route setup,
validation, reads, writes and owned cleanup. Total indexed work is O(fN)
bounded-word operations or O(fN*(w+f)) bit work, with O(N*(w+f)) stored bits.
The proof gives the arithmetic components and an eight-word pair schedule.
It is not a fixed multitape implementation. Accelerated recursion, physical
routing, stock, complete caller funding and all five selected assumptions
remain open.
