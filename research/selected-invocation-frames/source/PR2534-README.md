# Execute Compact around an actual selected complex child

PR2483's selected-child return demonstration covers f=1 and never calls Compact.
This package executes selected child 7 with two tensor columns: both actual
monomial adapters, real Compact dirty controls and exceptional repair, an exact
C^2 leaf, its literal inverse and the parked caller return. The contribution is
their composition; the existing primitives retain their attribution.

All 512 native columns and both 512-column monomial maps prove that this actual
nine-axis child acts on four axes and fixes five. The complete finite execution
has 12,288 records, all dirty u/t/b values, active fields and a spectator, and
three outer rows. A separate direct tensor operator checks the forward output;
the literal inverse and actual work/parking checks establish return. The five
original spectator axes per column are covered by the written factorization,
not enumerated in that reduced finite payload. See [PROOF.md](PROOF.md).

The primary K=G=1 fixture executes all-exception repair, but omitting it happens
to preserve that small endpoint. This is recorded as a positive boundary case.
A separate complete 2048-record K=2 fixture executes an actual selected adapter
gate followed by the real C^2 child; omitting repair changes its endpoint. This
distinction keeps the finite evidence honest. Neither fixture is the asymptotic
sparse-repair/long-record regime, and the K=2 fixture is not the entire child.

## Reproduce

From repository root, Python 3.12 standard library:

```sh
python3.12 scripts/research_package.py --package research/selected-child-compact-return
```

Default replay compares the complete receipt without writing. `verify.py --write
PATH` creates a new receipt and refuses overwrite. External code/archive bytes
are authenticated before imports. SOURCES.json and VENDOR.json preserve exact
Git/SHA256 pins; export replay needs no Git. Source-method reuse is explicit.

Controls cover repair/inverse keys, tensor phase, return rounding, source
translation, reserved grid and ancestor access. Data movement and arithmetic
meters are distinct. No full selected cold replay, hosted CI, fast recursive
callee, native supplier saving, new kappa or formal-kernel proof is claimed.
