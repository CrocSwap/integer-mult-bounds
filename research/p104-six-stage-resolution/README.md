# Six-stage resolution of the fixed P104 moment tariff

For the fixed 36-call P104 binary source, this package proves a logarithmic
scaling theorem for a specified split/prune moment certificate, computes an
exact upper envelope for the source's six-stage reporting grid, and gives a
concrete conditional installation at its last permitted grid tick:
**κ ≥ 0.003890115286594445**. The increase over #8035's conditional
`0.0038901152865907` is exactly `0.000000000000003745`. This is a
nearer installation of the same paid word, not a cheaper word, a practical
crossover, or a change to the selected result.

The abstract moment certificate has supremum \(c_*\) in the directed
interval `[0.003890115286594461129996942,
0.003890115286594461129996943]`. For a distance \(\delta\) below this
crossing, the least sufficient power is \(\Theta(\log(1/\delta))\) when
the floor may grow. A second-order expansion quantifies an asymptotic
49.83-factor saving for the refined split coefficient before rounding. This result is about that invoice; it does not supply
all-size multiplier implementations as the power tends to infinity.
The literal six-stage rule, with its five floor-minus-one `10^-18` grid
rates, has the stricter limiting ordinary bound
`0.003890115286594445189476955228` at the upper endpoint. It permits no
higher `10^-18` reported κ for this rule and fixed raw source.
[Statement and proof](PROOF.md) · [Directed calculations and finite examples](SCALING.json)

The last-tick profile uses a `430`-factor binary word, `15^430`
productive cutoff, `12^430` paid cap, floor `2^70`, stop exponent
`g=10^-21`, dyadic binary trial
`1175715202810401744919/302231454903657293676544`, and full binary and
positive debits of 31 and 10. The independent directed engines certify
a strict classic split-tail surplus greater than `3906/10^21` before the
`2/2^70` surcharge. The six rank logarithms are `10^21 * 4^i`,
`i=0,...,5`; the largest is `1024000000000000000000000`. The sufficient
public precision exponent is `1365004016064257029713503`. These constants
are enormous, and no host executed a production-dimensional tape.
[Last-tick receipt](LAST-TICK-RECEIPT.json)

The hosted nine-stage local-word packing ceiling in
`research/complex-local-word-ceiling/ceiling.py` assumes a different
coverage law; its applicability to this 48-call paired supplier is not
established. As a replacement scoped bound, the fixed binary word's raw
crossing gives \(0.999999999999995853594108487 < \kappa/c_* <
0.999999999999995853594108745\) for the reported candidate. This is a
fraction of that raw price ceiling, not a complex local packing cap.

An earlier `384`-factor installation at `0.00389011528659443` is retained
as a separately checked intermediate profile. [Receipt](CANDIDATE.json)
Both profiles retain #8035's all-size premises: all-column native action,
owned erasure and restoration, compiler transfer, precision and tape
services, and analytic recovery. Their stated asymptotic implications are
conditional on those premises in an ideal finite-tape model. The finite
replay tests source identities, arithmetic, selected feasible operator and
product controls; it does not independently establish the inherited
all-size premises. CPython array and file limits preclude the astronomical
instances, and the necessary final rank bound already exceeds this
machine's shift-count range. The actual source forest depth exceeds
`2381395348837209302317`, and eagerly materializing its retained targets
would require more than `2^3440` tuple entries. A tape implementation must
explicitly lower and pay the enumerator, stack, offsets and record scans;
[the bounded bridge](BRIDGE.md) establishes selected controls, retaining
the inherited compiler-accounting premise. A green finite replay is not a
human or proof-kernel review.

## Reproduction and source identity

Use CPython 3.12 and the standard library from a checkout containing this
package:

```sh
python3.12 -IB scripts/research_package.py --package research/p104-six-stage-resolution
```

For a self-contained offline copy of this directory, run the same cases
from inside it:

```sh
for case in price band dense binary grid atlas physical product; do
  python3.12 -IB verify.py "$case"
done
```

`VERIFY.json` specifies the registered per-case timeouts. Each case
reconstructs a private temporary tree. The archive is the byte-identical
#8030 package at `6285dd829114705862e8d91facaedc1f31d3cfcb`;
`PREDECESSOR-SOURCES.json` and `OVERLAY.json` are exact #8035 files from
`ea776471bf8ed143a0625cf2d7532f65d15eb5f9`. The verifier authenticates
all 91 archived files, their Git package-tree identity, the sequential overlays,
and unchanged inherited profile rows. The archive contains the sole copy
of the #8027 graph (SHA-256
`74e93daf2b7acf794ffb51f92f03f51556f68126d41ee13a8969bddb4cbe6326`).
The exact independent log/exp reader `verify_funding.py` comes from #8041
at `05f6172d4d9487090fa24c75137a7c60e6fcd67e`; it is used as a library,
with the graph and caller read from the authenticated reconstructed
archive. No second copy of the graph or ancestor archive is required.
Archive and file identities do not establish that the full source history
is present. Concurrent [#8042](https://github.com/CrocSwap/integer-mult-bounds/pull/8042)
at `3d33cb0c8a523b66d91e8de8250b85d0a436eb35` retains the #8035 rate
and uses a different unpowered retimed construction; it is not a replay
or proof of this powered profile. Related #8040 was inspected at
`c7f35d0f798aae9bf27bce2a64e8d4e2390d78d5`. The scientific branch is based on prerequisite commit
`0618e75a22cec54d1651394ef83d088551b7f026`, whose parent is the pinned
upstream main snapshot `e54523517d0f03e58352e647c403a5af3e525a57`.

The `price` case checks both retained profiles, their strict margins, the
source-grid ceiling and the scaling receipt; the other cases cover
feasible band, dense, binary, grid, atlas, physical and signed-product
controls. Last-tick receipt comparison records the host `sys.maxsize` but
excludes that environmental field from byte-independent numerical
comparison. A candidate-profile Product is explicitly bound and checked
on the feasible product. All 157,248 H calls in that small product use
the local kernel, not the candidate positive supplier. Separate tests use
a mock to check `Product.h` supplier-parameter forwarding and halt the
positive stop branch before the supplier; they do not run that word at
production scale. `BRIDGE.json` records the finite tape and dispatch
controls. See `VERIFY.json` for the per-case scope.

## Open next questions

1. Can a legal changed binary word raise the raw crossing? Start with one
   explicit changed incidence, and recompute its complete paid/productive
   inventory, typed owner restoration, and full caller operator. The
   present source has no such replacement.
2. Can all supplier, stripe, precision and recovery obligations be proved
   uniformly for a growing number of tensor factors? First derive a
   positive-rank and stock allocation as a function of the factor power;
   fixed positive height does not support an unbounded naive extension of
   the present stripe bound.
3. Can the five inherited all-size premises be independently formalized or
   established by a separate proof? Start with an arbitrary-column native
   action and its owner/erasure invariant at the stated ideal-tape interface.
