## Reproduce

Use CPython 3.12 with assertions enabled and the standard library. From the package directory in a clean checkout or Git-free export:

```sh
python3.12 -I -B replay.py
```

To inspect the exact sparse domain matrices, pairing forms and minors, run `python3.12 -I -B replay.py --output replayed`. This materializes the [17 path-keyed receipts](receipts/SHA256.json). All inputs travel with the package. [Source provenance](PROVENANCE.json)
