# What is replayed

Eight registered commands use only Python 3.12 and the standard library. The direct comparators and graph traversals are separate implementations by the same assisted author. The proofs establish the all-parameter statements. Finite enumerations check the listed domains.

The four small-field formulas have their own comparisons. [Partitions](PARTITIONS.json) |

Ternary scalar order counts agree with direct enumeration where stated. Actual words attain each of 128 prescribed lower or upper endpoint prices. The matrix and state graphs represent different objects. A matrix is a specific invertible header. A tuple fixes the image and covectors. A free orbit is a set of tuples identified by monomial changes. The raw domains overlap across experiments, and their counts should not be added as unique matrices.

## Optional extension

From the package directory run `python3.12 -I -W error -B orbit_oracle.py --extended` for ternary dimensions 9 through 12. Each row retains the packet-distance digest and exact orbit multiplicities. The first weighted gap of three over the larger diagnostic occurs in dimension 12, after none in dimensions 2–11. Exactly 12,165,120 labeled dimension-twelve tuples have that gap. [Larger orbit data](LARGE-ORBITS.json)

SHA256 traces of raw tuples or matrices visit them in lexicographic integer-encoding order. Orbit traces use sorted packet labels. These are deterministic checks of the finite computations. The optional large-domain counts do not replace the upper-bound and attainment proofs.
