# Independent clean verification

Two complete fresh reconstructions of the exact `complex-doublecold` source
manifest passed: Windows Python 3.14 and Linux Python 3.12. Each directory
contains the top-level proof receipts and every stage log. `COMPARISON.json`
records exact environments, durations, source identity and numerical agreement.
The complete source is checked before and after each run. Neither run uses
calibration outputs. The retained baseline sources are byte-pinned; explicit
attributed adapters validate regenerated promotion words by exact payload.

The selected conditional kappa is **0.001593667716067094**, exceeding PR564's
0.001593134158181640 by **0.03349108314035%**. The conservative result is
0.001593667713327391. Both models use independent rational engines and strict
outer certificates, with rejection of adjacent grid endpoints.

All 18 required repository baseline groups passed across the documented runs.
The first `make verify` run passed seven groups and then stopped at Gen4's
SymPy prerequisite: 1.12 was installed, while 1.14.0 is required. After an
isolated dependency correction, Gen4 and the remaining ten groups passed.
One later C++ group also needed the existing Boost header directory supplied
through its compiler include path; its failed attempt and recovery are recorded.
The isolated test group passed all 83 modules, then needed explicit Linux Git
worktree paths for its remaining patch checks; that recovery is also recorded.
`baseline/BASELINE-RECOVERY.json` binds these logs and receipts. This is not
a claim that the initial single `make verify` process completed successfully.
Historical generated baseline receipts are not changes in this PR.

Large regenerated scalar programs, templates and nested work directories are
reproducible outputs rather than duplicated here. Receipt hashes bind every
retained top-level proof artifact and stage log; the validation manifest also
binds the retained logs from the baseline suite.

The PR543 bit operator is repriced, not physically rebuilt. All inherited
all-size compiler, common-label/mutable-source, whole-call hosting,
precision/tape, analytic-transfer and bit H1-H5 assumptions remain. These
checks establish conditional finite evidence, not formal verification of the
full integer-multiplication theorem or a measured practical speedup.
