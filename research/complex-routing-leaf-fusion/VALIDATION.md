All results below concern this exact finite construction and its inherited
conditional outer theorem. They do not establish an unconditional integer
multiplication bound or benchmark a physical multiplication implementation.

## Portable registered replay

Run from the repository root with Python 3.12:

```sh
python3.12 -B scripts/research_package.py --package research/complex-routing-leaf-fusion
```

The five commands in VERIFY.json authenticate the original PR2751 export,
regenerate the complete words, check forward and dual arbitrary-input maps,

allocation, check all 276,390 roles and derive the full paid histogram.
The primary check retains ten mathematical rejection controls. A separate
endpoint/frame implementation runs under `-O` with three controls. A separate
rational moment implementation runs under `-O` with five controls. The
packing-cap checker uses the pinned unchanged ceiling engine.

`test_integrity.py` runs the public primary checker in a temporary Git-free
export with an empty PATH, checks read-only file inventory, and rejects source
corruption, an omitted frame edit, and a float substituted into the typed
receipt. It also checks the primary checker's explicit refusal of `-O` and
that generation preserves an existing output directory. These controls test
failure modes beyond merely matching the producer's JSON.

`RESULT.json` is the expected full typed primary output, not an acceptance
flag. `FINAL-PORTABLE-REVIEW.json` in evidence binds the final portable bytes
to the separately completed full release. The initial full-release wrapper
ran the earlier primary checker; its native, supplier and outer inputs did
not change when the portable primary gained the final exact CLAIM checks.
The final portable replay reruns those strengthened checks explicitly rather
than replacing the historical release receipt's script hash.

## Review and limits

The final cap-loader review exercised a valid-timestamp forged bytecode cache
in a temporary export. The original import-loader path triggered the fault;
the corrected checker compiled authenticated source bytes and passed under
`-I -O -B`. Equivalent binary frame bases also preserve the separate geometric
checker's result, while the exact artifact checker correctly binds its declared
generator output.

Separate mathematical and implementation agents reviewed the frame proof,
exact root, source binding, patches and public replay. This is AI-assisted
review, not an independent human review or proof-assistant verification.
The conditional physical, compiler, source-access, precision, fixed-tape,
BIT, recurrence and analytic assumptions remain those listed in PROOF.md.
The selected construction was not changed, so its unrelated historical cold
replays were not rerun. The contribution adds only this scoped package.
