# A bounded butterfly search does not improve the historical factory

**Scoped negative result; no new κ.** Two explicitly enumerated families of
weighted input prefixes, output butterflies and four deterministic residual
elimination rules do not beat Alluri's PR681 eight-register factory circuit
under Sagar Thakrar's PR696 primitive lowering.

| Finite family | Labeled recipes checked | Best real primitives | Gates in that witness |
|---|---:|---:|---:|
| Output pair butterflies | 3,072 | 95 | 46 |
| Weighted input prefixes plus output butterflies | 75,656 | 93 | 42 |
| Retained PR681 incumbent, for comparison | — | **81** | **34** |

All **78,728** recipe outputs pass an exact eight-column dirty-input matrix
check. There are no failed-pivot skips. These are labeled parameter tuples,
not necessarily distinct circuits; the two families overlap. The result
excludes improvements only among the programs generated by these precise
rules. It is not a minimum over all butterfly circuits, all elimination orders,
all helper choices or all complex suppliers.

The best losing witness is retained in `candidate.json` for inspection. It is
**not proposed as a replacement**. Its historical Horner price is 145 versus
the incumbent's 128; its accepted PR696 price is 93 versus 81. Every source
read, coefficient operation, sign, scale and private clear is charged.
Across fourteen windows, inverse cleanup and both real components, the local
PR696 disadvantage is `14 × 2 × 2 × (93−81) = 672` primitives per orientation.
The complete forward scalar primitive bill is **123,768 → 124,440** and inverse-transpose bill
**123,784 → 124,456**. These are exact finite instruction counts, not runtime
benchmarks. The inherited positive prefix bounds also grow: forward
**68,417 → 425,853**, backward **1,649,462 → 48,573,157/4**. Both replays retain
the original 192-bit charged allocation; no precision improvement is claimed.
The pinned local invoice allowance also charges for scalar macros. For the
closest witness, macros grow **15,512 → 15,736**, adapter allowance
**320,000 → 323,584**, and the PR696 local bound grows
**8,298,987,643,784 → 8,391,936,304,680**. This is an arithmetic local recount,
not execution of the whole-owner/global invoice. The negative search statement
concerns its declared primitive-count objective, not optimal total local cost.

## Reproduce

From a current Git checkout, with Python 3.11+ and the standard library:

```sh
python3 -I -B research/complex-factory-butterfly/pinned_replay.py
```

This offline entry point authenticates the original `SOURCES.json` and exports
its 29 exact files from historical base
`91a2094f2e022930069e8cfdc810a3ea1b81cd09` into a private temporary tree. The
checkout must contain that Git history. It then runs the unchanged verifier
with assertions enabled, checks that the source checkout is unchanged, and
prints `PASS_PINNED_FACTORY_BUTTERFLY` after the original pass marker.
`--out /path/to/new-directory` retains generated products outside the checkout;
`--check-sources` checks only the export and is not a complete search replay.
See [FOLLOWUP.md](FOLLOWUP.md) for the completed review continuation and limits.

The original interface remains available from the exact historical checkout,
or from its declared Git-free source closure:

```sh
python3 -I -B research/complex-factory-butterfly/verify.py
```

Use an absolute script path when outside the checkout. This command reruns the
entire finite domain, compares both search-stream digests and the exact frozen
receipt, independently checks the closest witness, rebuilds the raw constructor,
and replays both complete native scalar orientations with both lowerings.
It does not use a network, solver, cached source checkout or selected replay.
Expected marker: `PASS_FACTORY_BUTTERFLY`, with 14 blocks, incumbent/candidate
gate counts 34/42 and primitive savings **−672 in each orientation**.
`--out /path/to/new-directory` retains generated words and replay logs.

Additional checks:

```sh
python3 -I -O -B research/complex-factory-butterfly/test_independent.py
python3 -I -O -B research/complex-factory-butterfly/test_package.py
python3 -I -O -B research/complex-factory-butterfly/test_pinned_replay.py
```

The first two checks use the historical source closure. The last checks the
new export boundary, corrupt/missing sources, path and symlink rejection,
checkout mutation detection, and preservation of assertions under an optimized
caller; it does not rerun the expensive finite search.

`SEARCH.json` records both complete Cartesian products, the four pivot score
rules and deterministic tie order, counts, minima and SHA256 streams over every
recipe's cost/full map and emitted word. `factor.py` can replay that enumeration
alone. `EXPECTED.json` includes the independently implemented dyadic checker,
complete native and primitive bills, physical invariants and adverse controls.
`SOURCES.json` pins every consumed predecessor source at the exact base.

## What was tested and why

Assignment seed **21** was drawn with `secrets.randbelow(100)` from operating
system randomness. It selected the complex track and initial historical window
`21 mod 14 = 7`. All fourteen windows have the same exact scalar template, while
their physical register sets and frames are rebound separately. The seed is
not a reason to repeat a stochastic search: this experiment has no stochastic
search parameters.

PR681 had already improved the original 87-gate word to 34 using Gaussian and
two-sided sparse reductions. This experiment explicitly exposes sum/difference
coordinates before deterministic elimination. The first family failed; one
bounded pivot added seven prescribed coordinate prefixes on each of `(1,7)`
and `(2,5)`, suggested by the fixed matrix's half-input/helper pairs. Some
prefixes are triangular, not complete butterflies. Exact prefix tables and
both stopping rules are recorded. No further family was tried after the
second failure. The replay re-enumerates exactly those completed domains.

Optimistic pricing already fixes the exponent outcome: the full dirty map,
helper stock, frames and recursive child widths are held constant. Even a
successful scalar rewrite would reduce only a finite invoice, not increase κ.
The negative screen deliberately omits additional precision admission costs;
none of its words beats 81 even under that favorable restriction.

A concrete extra limitation is retained: the closest witness **fails** the
original 87-gate verifier's stronger sufficient criterion at
`cleanup: endpoint growth increased`. Exact-map success does not imply
entrywise envelope domination. Its four local prefix/envelope comparisons
and freshly measured full-word precision bounds are reported separately.
A native replay pass does not establish no-worse precision than PR681.
