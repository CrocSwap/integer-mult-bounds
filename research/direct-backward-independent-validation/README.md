## Reproduction

From the repository root, with standard-library Python 3.12:

```sh
python3 -B scripts/research_package.py --package research/direct-backward-independent-validation
```

The registered manifest runs both normal and optimized modes. For explicit
receipt destinations:

```sh
python3 -I -B research/direct-backward-independent-validation/verify.py --output /tmp/direct-backward-normal.json
python3 -I -O -B research/direct-backward-independent-validation/verify.py --output /tmp/direct-backward-optimized.json
```

The verifier begins with a builtin-only isolated-Python bootstrap so local
standard-library shadows cannot execute. It authenticates both helpers before
executing either, and the complete input
manifest before any engine executes. It rejects changed bytes, undeclared files,
symlink or hardlink input aliases, stale bytecode caches, wrong source heads and
Git membership proofs. Raw Git commit/tree data establishes file membership
offline; replay needs neither Git nor a private object store nor a network.
The independent scientific engines are preserved byte for byte at their final
review freezes.

Replay copies the capsule to a new private scratch tree, sets only its newly
created directories to `0700`, and gives every subprocess a fresh bytecode-cache
prefix. Frozen `0444` files and `0555` directories remain untouched. The three
engines run serially, with explicit `-O` propagation; fresh JSON is checked for
complete semantic coverage and source/claim identity. Exit status alone cannot
satisfy the review. Outputs and raw logs stay outside the frozen package.

`SOURCE-BINDINGS.json` lists every package-local input; its exact bytes and the
command schedule are pinned by the committed verifier. `SOURCES.json` records
canonical provenance. Published PR5396 proof documents have offline Git
membership proofs. The separately labelled old raw algebra/ownership receipts
were frozen external execution evidence; they were **not** files in PR5396's
published tree. Their reuse does not assert a fresh historical replay.
