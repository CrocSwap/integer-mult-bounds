## Reproduce

With Python 3.12 or 3.13, mpmath, a C++17 compiler and Boost headers available to the inherited bit checks, run from any directory:

```sh
python -B verify.py /absolute/path/to/a-new-output-directory
```

Keep assertions enabled. Set `CXX` if needed. The inherited source tools require paths without whitespace. The output must be new and outside all source packages. No network or discovery search is used. All dependencies are frozen sibling research directories listed in `SOURCE.json`; `--help` shows path overrides.

The default first runs the complete frozen two-window entry point, including its ancestors and the corrected signed-bit replay. It restores all 136 native PR401 files from four ASCII carriers, verifies their Git-blob and SHA256 identities, reconstructs both the original and changed normalization, and reruns unchanged upstream local, native phase, bank emission, independent decoder and finite reserve checks. It binds the unchanged old phase recipes to this run's fresh ordinary ten-stage output. It then runs both exact moment engines and the eight charged signed-bit continuations with all 47 strict outer inequalities. A separate output reproduces PR401's original six-level parameter choice.

`RECEIPT.json` is written only after exact `EXPECTED.json` equality and a final recheck of the package, all 13 frozen dependencies and all restored upstream files. `VALIDATION.json` and `composition/SCIENCE.json` are portable scientific receipts. The unchanged upstream outputs retain their original path-bound provenance. Their source bindings are checked before a narrow documented projection removes only source-path maps and elapsed time and rebinds the corresponding scientific receipt hashes.

All public package files use terminal LF. Original CRLF and missing terminal newline states are restored byte for byte inside the generated upstream tree. `MANIFEST.sha256` covers every package file except itself; neither construction nor source validation depends on the final expected receipt.
