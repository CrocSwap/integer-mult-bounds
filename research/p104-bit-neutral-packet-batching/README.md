# Test two one-call BIT batching models on the pinned caller

Checks two distinct single-call proposals: matching-specific joint IDLE groups and a neutral grade-eight owner wrapper.

The fixed coordinate matching needs independent rank 14; all 5,040 matchings show that the common-image rank ranges from 8 to 14. The separate complete-domain neutral-wrapper bound rules out the named 131/196 clock-pair family.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `64252a230fe05ffb2c5c0f77c72956bd09f2a6709d1342c12dd349a593627c68`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run `(cd two-port && python3 -I -B replay.py)` and `(cd mixed-packet && python3 -I -B replay.py)`.
