# Exact-byte portable replay contract

`portable.py` first authenticates the unchanged independent 28-file manifest (`3fa257834b…`), the unchanged six-file author manifest (`a7d684b92f…`), both mandatory clarifications and every upstream input. The original relative archive hierarchy is copied into private temporary scratch. Frozen script files themselves remain unchanged, including the original sibling mixed-checker path and its SHA guard.

Only three transport sites are adapted at execution:

1. The single `runpy.run_path` call in `bank_span.py` dispatches its original dependency path to this loader.
2. The single `runpy.run_path` call in `grade_gate.py` dispatches the original bank checker the same way.
3. The mixed checker's `fetch(head,path)` reads exact retained bytes for that **same original request**, rather than invoking Git.

The AST transformer checks exactly one site per script. It does not rewrite a scientific expression, scalar coefficient, source pin, assertion or receipt. The independent checker is already Git-free and runs without AST adaptation. No network or fallback source lookup is permitted. Original request, local copy, Git blob and SHA256 are recorded in `INPUTS.json` and registered in `SOURCES.json`/`VERIFY.json`.

Every verbose stdout is captured into private scratch and compared byte-for-byte with its frozen receipt before a compact success summary is printed. The 702,206-byte grade receipt is not dumped to routine terminal output. Scratch is removed on exit; source and evidence files are not regenerated. Only the retained independent script's opt-in `--emit` could write its receipt; the wrapper never passes that option.

The five wrapper rejection controls exercise an unretained source request, undeclared dependency path, altered mandatory reset clarification, altered scientific input bytes and wrong scientific receipt. Source scientific controls are also rerun unchanged: all eight nonzero diagonal terms and the uncoded/homogenized frames expose grade9; the uncoded bank span recovers all four targets. Controls are verification fixtures, not new research searches.

The source-history preflight remains separate. The actual source and original arithmetic heads are ancestors of the publication history. `SOURCES.json` declares their exact pins; a local object cache alone is insufficient. The official exporter includes all package bytes and declared inputs. The exported direct verifier uses no Git, although generic metadata validation still requires a Git checkout for catalogue/selected provenance.

This transport adapter is part of the new packaging and needs its own review. The retained independent review certifies the frozen proof, dependency trace and grade census, not arbitrary future modifications to this loader.

## Retained-path metadata binding

The shared package schema requires the path in each explicit source pin to equal its row path. Package-local live inputs therefore bind to their exact same paths at retained ancestor `75d394d2d5b45803dd0da8a35d1220c6e575c14d`. Separate provenance rows bind every original upstream path/head/blob/SHA. The retained bytes are byte-identical to those upstream Git blobs, and `INPUTS.json` plus the loader still use the original upstream requests. This two-layer metadata binding is explicit; it does not change a scientific source pin or substitute a different arithmetic request. Both layers must pass publication source-history checks.
