Every later paid gate keeps its original frozen input; no saved value is injected into it.

For original main bank0, all observed coefficients are signed occurrences of `I`, `Q^-1`, `C1 Q^-1` and `Q^-1 C1 D1`, or zero. This original input never reaches D3. The actual F transpose has 104 zero-diagonal columns, each with 52 supported late terms. All **5,408** literal words `Q^-1 K_i^-1 K_j D1` have Fourier grade7; earlier terms have grade0/1. The required original first-bank target `D1 Q^-1` has grade9.
