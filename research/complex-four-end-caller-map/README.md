# Caller-interface map for the four-end k8 frame proposal

**Scoped interface audit; no new kappa and no supplier admission.** This checks
the concrete four-end attaining assignment in the unrestricted terminal-frame
certificate, PR #2013, surfaced by its handoff in Discussion #2000. It answers
the remaining question “physically host the four-end word” only as far as the
source-bound local interface permits.

## Exact question

For the assignment changing helper ends `574, 575, 580, 581`, what source
register and last-use frame must each new endpoint accept? Does the earlier
physically admitted two-end recipe provide the same outer caller for this whole
four-end assignment?

The stop test was: derive and check every changed endpoint's native source
containment; compare the complete candidate frame annotations with the earlier
two-end physical recipe; stop if an outer owner/restore invoice is absent. This
complements endpoint-moment planning and small-instance work without extending
the ideal lever grid.

## Result

The four changed endpoints each drop from rank 8 to rank 7. The source-bound
prefix dependency and last-use obligations are:

| Changed helper end | Required source register | Last use | Required boundary subspace | Candidate end basis | Result |
|---:|---|---|---|---|---|
| 574 | helper 412 | B994 `ADD(392,412)` | `(261,131,96,20,10)` | `(256,128,96,17,9,5,3)` | contained |
| 575 | helper 414 | B995 `ADD(102,414)` | `(259,133,96,20,10)` | `(256,128,96,17,9,5,3)` | contained |

Each row is the exact `K_q` support from the pinned scalar prefix, not a guess
from the endpoint label. The four containment checks pass. This is the local
native cone obligation; it does not assign these data registers to outer-call
owners or show when their values are copied, consumed, or restored.

The rank bill also closes exactly: the profile changes by
`-12 H1 + 28 H2 - 16 H3`, taking local rank mass `5586 -> 5582`. The coverage
identity fixes total paid mass at `7232`, so ideal idle mass rises `1646 ->
1650`. The four units are returned to the idle pool; they are not free work.
The 2,589 “free gate” nodes in PR #2013 are frame-choice variables while its
scalar operations remain fixed.

The earlier physical two-end recipe matches the four-end candidate at ends
574/575 and at eight B-frame plus two early-cleanup annotations. The full
four-end candidate changes **159** gate-frame annotations: 61 A, 94 B and 4
early-cleanup. The two-end recipe covers only 10 of those; 149 additional
annotations and the two new endpoints 580/581 lack that recipe's caller
receipt. Therefore the earlier owner schedule does not transfer to this exact
candidate. PR #2013 also explicitly leaves phase/wrapper admission, a new
complete physical owner allocation and the outer invoice unreplayed. Its local
frame certificate is not outer caller admission.

## Reproduction

From the repository root:

```sh
python3 -B research/complex-four-end-caller-map/verify.py
python3 scripts/research_package.py --package research/complex-four-end-caller-map --check-only
python3.12 scripts/research_package.py --package research/complex-four-end-caller-map
```

The verifier checks source word identity, the exact four source supports and
containments, profile-to-idle conservation, the two-end recipe matches, and the
changed-frame counts. Expected marker:
`PASS_FOUR_END_CALLER_MAP_LOCAL_ONLY changed_ends=4 native_cones=4/4
additional_frame_changes=149 outer_call_admission=UNRESOLVED`.

## Scope and credit

The selected word and changed-end assignment are source-pinned through
`research/selected-k8-unrestricted-ends`. PR #2013's exact dual and independent
checker remain its evidence; this package does not rerun them. The caller audit
is limited to the four native cone inputs and comparison with the earlier
two-end `END-RECIPE`. It does not build native programs, execute phase/wrappers,
map owners and lifetimes for all 159 changed frames, verify dirty restoration,
or evaluate the complete outer invoice. No full multiplication theorem,
selected-frontier change or new kappa follows.
