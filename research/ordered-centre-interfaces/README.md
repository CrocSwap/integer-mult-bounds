# Ordered centre interfaces and their paid endpoints

This package gives exact controller identities, a conditional physical
coordinate compiler, and a checked one-pair endpoint with its full native
rank cost. It retains results from the October 2026 centre campaign. It
does not improve the complete multiplication exponent or certify a new
selected result.

The concrete endpoint uses 224 independent productive roles over the
regular cover of dimension 25. Three native calls leave the ordered code
`Q E2 E1 E0 Q^-1` on one output bank. Two explicit terminal constructions
remove that code. Both have total native rank mass `5600 = 224*25` and
fail the native moment inequality for every positive improvement exponent.
This is a limit of these two complete constructions. A cheaper decoder
is not excluded.

[PROOF.md](PROOF.md) states the claims and their assumptions.
[DIRECT-SOURCES.json](DIRECT-SOURCES.json) maps each claim to its full
proof and decisive checker. [SOURCES.json](SOURCES.json) binds every
retained byte. The complete original proofs and source reviews are in
`frozen/`; they are unchanged.

The helper completion does not add 408 productive fields to the data-only

the completion is available when a different data word must retain the

## Replay

Python 3.11 or later and its standard library are sufficient. Run one
process. The output directory must not exist. Keep at least 3 GiB free.

```text
python3 -I -B replay.py --out /tmp/ordered-centre-replay
```

The command runs ten checks, first normally and then with `python -O`.
It uses isolated temporary copies and does not change the frozen files.
It checks each source hash, compares each fresh receipt with its frozen
receipt, and compares the normal and optimized outputs. For gzip output
it compares the decompressed bytes. The final line must be:

```text
PASS_ORDERED_CENTRE_INTERFACES
```

`--mode normal`, `--mode optimized`, and `--only NAME` permit a focused
replay. The receipt records the selected checks, so a partial command
does not assert a complete package replay.

One source-read change is needed for portable replay. The D25 access
checker reads the exact `DATA-PHASES.json` member from a retained file
instead of opening the large historical archive. Its member hash and
every mathematical check are unchanged. The original archive hash was
checked at extraction. The original checker, the adapted checker, and
the exact diff are retained in [PORTABLE-ADAPTATION.json](PORTABLE-ADAPTATION.json)
and [PORTABLE-ADAPTATION.patch](PORTABLE-ADAPTATION.patch). Only that
checker's self-hash is excluded from its comparison with the old receipt.

The replay checks ordered identities, all 224 data columns, source and
terminal phases in the stated checks, scalar code inverses, helper
paths, route records, and negative controls. It does not rerun the full
native phase compiler, prove the all-size recursive compiler, run the
selected construction, or establish finite precision and integer recovery.
The original source phase reviews remain pinned premises.

## Open next questions

step is to give an ordered native construction on the retained D25
routes and price every map and child. The current rank equality blocks
the two terminal choices in this package.

Can the raw or weighted content inverse obtain its queries in the
required physical cuts? A first step is a typed reader and scatter
certificate for the exact retired-Y maps. The content identities alone
do not supply those views or their cost.

Can a proposed physical monomial compiler preserve every later helper
use and the admitted map grammar? A first step is one complete-state
conjugation certificate. Logical monomiality of a local response is
insufficient.
