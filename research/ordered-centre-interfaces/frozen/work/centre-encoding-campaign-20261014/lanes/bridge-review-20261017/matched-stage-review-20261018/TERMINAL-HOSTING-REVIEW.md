## Actual path calculation

The actual response preserves two sets of ports. Each of its 48 dense
rows has four entries. Each of its other 64 rows has one entry. For
each ordered triple, the checker composes the actual stage edge maps.
It checks every path, rather than replacing a routed stage by a local
matrix.

There are 3,136 paths in each direction: 3,072 on the dense set and 64
on the permutation set. For fixed output and input ports, all complete
cover maps are distinct. Right multiplication by such a map sends a
fixed regular-cover owner to a distinct owner. Thus arbitrary cover
inputs can separate the paths; cancellation between different owners
is not available.

For a path with map A and scalar coefficient c, the complete operator
in the output chart is

```text
c X_delta C_a C_b^-1 P_A,
a=q_p, b=A q_r.
```

Here X_delta is the payload translation on every tensor copy. Both
line vectors are nonzero and distinct. In the actual packet they are
orthogonal as well. The checker derives the FULL conjugation phase
from the values of its Z4 polynomial on zero, each basis vector, and
each sum of two basis vectors. These values determine all constant,
linear, and quadratic coefficients. There are 1,022,336 such checks
for each triple direction.

The cover map and the payload map have distinct roles. The cover map
sends output owner h to input owner hA. The factor P_A writes the
source chart in the output chart. If local chart coordinates are
converted to physical coordinates, the complete path is conjugated
on its two sides by the corresponding output and input charts.
This is one field-and-address map; it does not require a duplicate
input field. The inherited final full-cover correction remains part
of the common-FULL convention.

Each path has four nonzero one-copy address branches, so it has
support 4^f at width f. Other paths at the same output cannot cancel
these branches, because they have different source owners. This
excludes a fixed number of scalar and monomial passes for the stated
raw operator. It is not a lower bound on native children in a coupled
decoder.

ports form a permutation. Each cover map is invertible. These facts

Write alpha=(1+i)/2 and beta=(1-i)/2. The exact line kernels are

```text
C_v = alpha I + beta X_v,
C_v^-1 = beta I + alpha X_v = X_v C_v.
```

The supplied orthogonal basis G has first two columns a and b. The
checker verifies G, both inverse orders, and every serialized


The inverse line contributes the translation b. The sign -1 is a
scalar sign on the whole field; it is not an unrecorded phase per

Omitting the scalar sign fails. The exact one-copy identity tensors
to every positive width.

## Owner and row hosting

Use the regular cover G=O(25,2). For each side and port, the rule
h=d rho_(s,p) is a bijection between body labels and owner labels.
The 224 side-port families are disjoint. A complete cover sweep
therefore partitions all productive data fields. A later code or
local stage starts after that sweep has finished. No helper reuse
or input replication is needed for this argument.

The all-ones vector in dimension 25 has norm one and is fixed by
every isometry. Its orthogonal complement is a 24-dimensional
nondegenerate alternating space. Restriction identifies O(25,2)
with Sp(24,2). A first symplectic pair has
(2^24-1)2^23 choices, and the count then continues on its
22-dimensional complement. Hence

```text
|G| = 2^144 product_(j=1..12)(2^(2j)-1).
```

The checker calculates the same order by this recurrence. Its bit
length is 300. The productive role count N=224|G| has bit length
308. This large finite factor cancels from a normalized native
moment. It remains in physical stock and row reserve.

The row split and LIFO argument in the pinned primary stream proof
applies to N arbitrary roles. If row counts are divisible by N^k,
the decomposition u=N g+w gives each role one complete suffix and
exactly 1/N of the parent volume. A child removes no address from
that suffix. The other streams are parked and restored. These are
layout facts and do not require four data pairs or the old helpers.

The primary proof's complete asymptotic theorem assumes a strict
native moment inequality. That theorem cannot be invoked for this
word: the completed word fails the inequality. Only its row split,
complete-range, and LIFO arguments are used here.

The parent has 25 address slots, so a binary row addition can use a
third distinct payload slot and restore its arbitrary bits. This
slot is an address part of the active stream, not an additional
productive field. The grouped children have rank at most eight;

row reserve follow under the admitted size-reduction rule. Actual
