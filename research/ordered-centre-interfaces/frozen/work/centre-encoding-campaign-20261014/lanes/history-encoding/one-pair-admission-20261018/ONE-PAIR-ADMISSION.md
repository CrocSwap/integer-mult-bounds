# One pair: data stock, native hosting, and the paid terminal

## Result

The fresh matched word can use one pair of 112-field data banks. Its
three local calls are F0, B1, and F2. The ambient label space has
dimension 25. No local helper, query buffer, inter-pair bridge, or
nonzero idle job is required by this word.

This is a new 224-role local contract. It does not remove helper
progress from an old 632-role contract and then count that progress
as free. The checker verifies that every event in the new word uses
only roles 0 through 223. The other 408 slots in its source payload
have no event and have identical start and final frames. Their frame
rank counts are {0:274, 1:108, 2:24, 4:2}. Thus the direct summand on
the 224 data roles is exact for arbitrary input data.

The current-stage controller has a literal paid completion. It uses
224 additional rank-one children. This completion has total rank
5600 = 224*25 and fails the native moment test for every positive
improvement exponent. The obstruction in this construction is its
terminal cost, not a requirement for four data pairs. A cheaper
terminal is not ruled out.

This packet proves the changed row and owner contract under the
inherited all-size native-child and stream compiler contracts. It
does not prove those general compiler contracts again. It does not
supply a complete finite precision, map, tape, or kappa invoice.

## The local stock is 224, not 632

The word has only two event types: scalar and native. Its scalar
events are reversible ADD and signed dyadic-unit SCALE operations.
Each native event acts on one data role. Its two side maps act on
that role's payload address. Neither type names another physical
field as hidden scratch.

The local profile is

```text

It has 432 children and rank mass 1792. Every one of the 224 fields

the serialized events. The local maximum-array norm bound is six.

The two providers have the same coefficient response E. The exact

```

The endpoint adapters in the source are part of this contract.

## Complete owner layout at dimension 25

Let G=O(25,2). Allocate the independent productive fields

```text
(side, port, h),  side in {X,Y},  0 <= port < 112,  h in G.
```

Thus 224 is the local field count. The recursive row split uses
N=224*|G| independent roles. Distinct cover owners do not contain
copies of the same input, and no such promise is used.

At stage s and body d, port p uses owner h=d rho_(s,p), with the
literal DATA entry and exit translations. Each rho_(s,p) belongs
to G and is an involution. For a fixed side and port, right
multiplication by rho_(s,p) is a bijection of G. Different ports
and sides are separate families. Therefore the 224-role body
invocations partition the productive fields. Complete a whole
cover sweep before the next stage or port-code sweep.

The dimension-25 packet checks all 336 route records, 672 entry
phase identities, 672 exit phase identities, 336 future-Y views,
and 672 past-X views. All translations use the first 25 axes;
the discarded 48 route columns are identity columns. This is an
exact restriction of the supplied charts, not a dimension-only
argument. The inherited final full-cover correction remains part
of the output convention.

There is no helper assignment or collision condition left in
these data-only sweeps. In particular, no old helper is silently
reassigned to a data owner. The number of replicas can be one.

For reference,

```text
|O(25,2)| = 2^144 * product_(i=1..12) (2^(2i)-1).
```

The cover order has 300 bits and N has 308 bits. The formula follows
by fixing the all-ones vector and counting symplectic bases in its
24-dimensional orthogonal complement. The finite cover cancels
from a normalized native moment. It does not cancel from row
reserve, map work, or physical stock.

## A literal two-line terminal

Let Q be the diagonal intrinsic line operator. Let F be the
completed common 25-axis frame, with the standard full-cover
correction included. The raw input is (Qx,y). Before the old
terminal the fields are

```text
(-Fy, F Q^-1 Kx).
```

The old translated signed exchange gives (F Q Kx,Fy). Execute
the following operations on the first output bank:

1. Apply Q^-1 to each of its 112 fields.
2. Apply E2^-1, then E1^-1, then E0^-1 at FULL.
3. Apply Q to each of its 112 fields.

The states are F Kx, F x, and F Qx. The second output remains Fy.
This proves the original raw output contract. The order in step
2 is required. The checker rejects its reverse and also rejects
omission of the final Q.

These line calls have explicit native address charts. For a
nonzero intrinsic vector q, choose a bit j with q_j=1. Let A_q
have first column q and all standard basis columns except e_j
as its other columns. This is an invertible 25 by 25 binary
matrix. The checker emits it for every port. Put

```text
alpha=(1+i)/2, beta=(1-i)/2,
C_q=alpha I+beta X_q.
```

Then

```text
P_Aq C_first P_Aq^-1 = C_q,
C_q^-1 = X_q C_q.
```

Both equations include the complete scalar phase. They follow
by conjugating the literal translation X_first and using C_q^2=X_q.
For owner h, use h A_q and direction hq. These payload maps leave
the owner index fixed and use full payload ranges. The payload
chart can be in GL(25,2); it need not be in O(25,2). The binary
row-addition compiler admits such a chart. At width f the
same identity acts in each of the f columns. Each Q or Q^-1
pass therefore has exactly 112 rank-one children per cover.
The inverse pass has a translation wrapper as well. No owned
query field or arbitrary helper baseline is used.

This is a separated 224-H1 construction. The three port codes
between the line passes do not generally commute with Q.
There is no emitted 112-H2 fusion claim.

## Recursive row and work-area contract

The primary stream proof at lines 540 through 614 splits complete
rows among the finite network roles. It then parks the other role
streams on a LIFO tape and passes only the active stream to the
child. Its proof uses arbitrary values in every role. It does not
require a particular number of data pairs or the old local helpers.

Use that split with N=224*|G|, not with 224 alone. A native event
then gets one active stream of volume V/N. That stream retains
every spectator range and all f columns of its active axes. The
serialized monomial side maps change only that stream. The
remaining role streams are parked and are restored after the
child returns. Coefficient registers and the fixed work tapes
belong to the stream machine; they are not additional independent
productive input owners.

The row reserve must cover the depth of the admitted child tree.
For a grouped child of rank r, the active dimension is r/25 of
the parent at an exact split. Here r<=8. Thus a reserve for any
upper bound on that tree depth is finite and logarithmic in the
input dimension. This statement does not replace the inherited
arbitrary-size grouping and remainder rules. If those rules are
used, their actual depth bound must be used in the row reserve.
The native size guard has margin

```text
25^2 - 2*8^2 = 497 > 0.
```

The binary payload compiler uses a third address slot for a row
addition and restores its arbitrary bits. That slot is part of
the active payload, not a new field. The ambient 25-slot parent
has such a slot. The primary proof at lines 130 through 188 and
450 through 470 supplies this distinction. A recursive child
uses the same admitted machine contract on its own active
stream; it does not borrow an old parent helper field.

This proves that the new local stock causes no new recursive
helper-hosting or parent-row obstruction under the stated child
contract. It is not a new proof of the arbitrary-size compiler,
the finite precision transfer, or exact integer recovery.

## Complete rank consequence and remaining cost

The three data calls have profile

```text
{1:480, 2:144, 5:144, 7:336, 8:192}.
```

Their mass is 5376. The paid terminal gives

```text
{1:704, 2:144, 5:144, 7:336, 8:192},
```

with 1520 children and mass 5600. Multiply every count and the
productive role count by |G| for the whole cover. All paid ranks
are less than 25. Hence, for every b>0,

```text
sum_r n_r r^(1-b) > 25^(-b) sum_r n_r r
                       = 224 * 25^(1-b).
```

The specified full word cannot give a positive native improvement
exponent. Finite scalar and map costs cannot reverse this failure.
This is a statement about this full word, not a lower bound on
every decoder for Q K Q^-1.

The exact subtotal for the three local scalar words and all eight
E-code occurrences is 30440 real primitives per cover. The old
signed exchange, global views, line wrappers, final cover maps,
recursive work areas, and precision must also be charged. A norm
bound for the three local words and eight E-code words is
6^3*4^8=14155776. This bound does not replace a full finite invoice.
