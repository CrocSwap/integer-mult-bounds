## Replay

Use Python 3.10 or later and the standard library. Keep at least 3 GiB
free and use one process. From this annex directory, run:

```sh
python3 -I -B replay.py --out /tmp/ordered-access-algebra
```

The output directory must be new and outside the annex. Its parent must
exist. The final line must be:

```text
PASS_ORDERED_ACCESS_ALGEBRA_ANNEX
```

The wrapper runs three unchanged independent checkers in normal and
optimized Python, in sequence. Each run uses a fresh local layout.
The copied runtime receipt is removed before execution, so the checker
must produce it again. Every complete receipt must equal its frozen
bytes. All source hashes are checked before and after the run. Only
the generated runtime copies are removed; logs and receipts remain.
The annex can run from a copy outside the workspace without Git or
network access. No producer checker or native emitter is imported.

The access check verifies all 4,032 future-Y and 4,032 past-X phase
identities, both scalar signs on 224 arbitrary input columns, and the
complete owner/helper phase ledger under uniform and mixed retirement.
The controller check uses free ordered words for pair counts one through
eight. The proof covers all positive pair counts. The partner check
uses all 224 local and all 224 original data/borrowed columns, both full
104-port principal blocks, and both inverse orders. Negative controls
reject missing or misordered translations, the wrong tail coefficient,
an early idle-X reset, omitted selected Q, an omitted ordinary gauge,
and moving q through a graph entry. The first-response control confirms
that the later query criterion does not settle pair zero.

The 34 exact source/license copies close these checks and retain their
