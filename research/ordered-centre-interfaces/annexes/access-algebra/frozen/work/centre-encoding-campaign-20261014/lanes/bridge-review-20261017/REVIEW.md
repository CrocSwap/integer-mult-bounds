## Exact access identity

Write `q,b_1,...,b_8` for a port's actual orthonormal chart in the initial
nine-dimensional block. The review obtains these columns from the source
idle recipe. It builds `rho_t` by exchanging `b_j` with the corresponding
coordinate of block `E_t`, while fixing q and the other external blocks.
This construction is independent of the producer's transvection formula.
It gives an orthogonal involution on all 73 coordinates.

The Fourier phase of Y at completed level h is

```text
phi_Y(q,h)(z) = sum_(j<9+8h) z_j - <q,z> mod 4.
```

Here each binary dot product is first evaluated as zero or one. Its
integer polynomial modulo four is

```text
<v,z> = sum_(j in supp(v)) z_j
        - 2 sum_(j<k in supp(v)) z_j z_k mod 4.
```

This formula permits a direct comparison of every phase coefficient. It
does not use the producer's packed phase representation. Let
`beta_j=(weight(b_j)-1)/2 mod 2`. For h<t the review verifies

```text
phi_Y(q,h)(rho_t z) + 2<q+lift_t(beta),z>
  = sum_(e_j in E_1+...+E_h+E_t) z_j mod 4.
```

For h>=t, the X identity is

```text
phi_X(h)(rho_t z) + 2<sum_j beta_j b_j+lift_t(beta),z>
  = phi_X(h)(z) mod 4.
```

The constants are zero. These are full quadratic identities, not only
equalities of their polar subspaces. They hold in all 4,032 future-Y cases
and all 4,032 past-X cases. Omitting the translation fails in all 8,064
cases. Applying the Y translation on the wrong side of the route fails
in all 4,032 Y cases. The exact identities tensor to every positive width.

The review compares the two translations with the actual `entry_Y` and
`exit_X` source adapters. Thus the logical route in this program is the
same route used by the local supplier. In operator notation the physical
view satisfies `A_(q,t) T_(q,h)=F_common D_(q,t)`. The D on the right acts
on content. It is not the full physical view A on the left.

The actual selected minor gives `R_A^T R_A=4I`. The review also verifies
`R R^T=56I`, and hence `B B^T=13I` for `B=R_A^-1 R_U`. The actual B has
416 nonzero half coefficients, with 52 per selected row. For distinct banks,
the program first adds each ordinary source to its same-port ordinary
target. It then aligns the 104 ordinary sources and eight selected targets,
applies the 416 selected-target half ADDs, and undoes each view. Therefore
it adds

```text
c D_t^-1 [[0,-B],[0,I]] D_t source
```

to the target. The same-port ordinary prefix equals the diagonal ordinary
part of this expression because its two routes cancel. The cross-port
suffix uses the common frame just proved. Both signs are checked on every
one of the 224 arbitrary bank input columns. No source value is discarded.
The eight selected sources are unchanged and are never read. Unrelated
fields are not accessed.

## Matched controller proof

The local B map is invertible even when P is not idempotent. For
`w=(I-P)Ax-y` and `v=y+PAx`, its inverse is

```text
x=A^-1(w+v),    y=(I-P)v-Pw.
```

The identity uses only `(I-P)+P=I`. Let eta_i be the Y input to this map.
After B, define

```text
w_i=U_i A_i z_i-eta_i,
v_i=eta_i+P_i A_i z_i.
```

The prepared next X supplies `A_i z_(i+1)`. Thus the intervening F map
outputs `r_i=G_i A_i(z_i+z_(i+1))=E_i x_i`. The subsequent subtraction
restores w_i. The next Y input is exactly

```text
eta_(i+1)=y_(i+1)-W_i eta_i-W_i P_i A_i z_i+T_i r_i.
```

In descending order the tail adds `W_i w_i` to the next X before w_i is
changed. The two eta_i terms cancel. The remaining preceding-stage terms
are `W_i(P_i+U_i)A_i z_i=W_i A_i z_i`. This proves the stated endpoint for
every positive pair count, with no commutation or idempotence assumption.
The separate first response is

```text
H_0=C^-1(U_0 A_0-V)z_0.
```

If P_i is idempotent, the later projected response equals

```text
(P_i W_(i-1) A_(i-1)-P_i T_(i-1) E_(i-1)) z_(i-1)
 -P_i T_(i-1) E_(i-1) z_i.
```

The suffix map from x to z is a unit triangular map. Its two displayed
suffix variables are therefore independent. Since E and A are units, the
expression is identically zero if and only if
`P_i T_(i-1)=0` and `P_i W_(i-1)=0`. This proves necessity as well as
sufficiency. It is equivalent to factoring both maps on the left through
`U_i=I-P_i`. It imposes no relation between consecutive projections.
At pair zero the condition is instead
`P_0 C^-1(U_0 A_0-V)=0`; it is not automatic.

The independent executable check uses free noncommutative operator words.
It checks m=1 through 8 for arbitrary P, W, T and for both future-projection
choices. Only adjacent inverse pairs and the stated projection relation
are reduced. All 24 endpoint cases pass. All 42 controls that change the
tail coefficient or reset idle X too early fail. The first-response control
fails in all 16 future-projection cases, as it must.

For the signed specialization the check uses only `B_s D_s=13I`. It does
not commute graphs from different stages. It proves both signed inverse
orders, `P_s A_s=-Pi`, `U_s A_s=A_s+Pi`, and the response

```text
H_(i,U)=(D_(s_(i-1))-D_(s_i))(z_i)_A
        -D_(t_(i-1))(r_(i-1))_A,
H_(i,A)=-B_(s_i) H_(i,U).
```

This formula still contains original selected X suffixes. Preservation of
the original Y query does not itself make those X values available.
