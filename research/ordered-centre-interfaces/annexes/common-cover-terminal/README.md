# Common-cover terminal and its standalone rank limit

This annex supplies the actual terminal for the common cover response on
D=73 binary axes. It also proves a sharp standalone rank-two bound for
every orthogonal extension of the admitted first line cut. It is distinct
from the paid one-pair D25 terminals in the parent package.

No complete kappa improvement follows. The terminal is finite under the
stated map and child contracts. Fresh local native words, whole-cover
scheduling, recursive hosting, finite map costs, and precision remain
separate obligations. The full native-moment conclusion also requires
the complete path and idle ledger.

## Exact terminal

The actual common response acts only on the cover label:
(E f)_p(h)=f_p(h L_p), where each L_p is the pinned orthogonal ten-cycle.
The raw controller gives (-E^-1 y, E x) for every positive pair count.
This follows from the common-response change of variables and does not
use E^10=I. The check separately verifies the actual four-pair schedule
with nineteen content events and ten idle sites.

At the physical terminal, U=-F E^-1 y and V=F Q^-1 E x. Put
M_I=F E^-1 F^-1 and M_E=F E F^-1. The ordered terminal applies Q, M_I,
and Q to V; it applies M_E to U, then makes the signed exchange
(X,Y)=(V,-U). The endpoint is (F Q x,F y) on arbitrary input arrays.
No commutation of E with Q is used. No encoded result passes to an
unchanged outer twiddle or product.

For each actual port, the X branch uses the distinct positive line
transforms C_(h q) and C_(h L_p^-1 q). Their directions are orthogonal.
One rank-two native child implements their product. The exact wrappers
bind the cover direction, affine offset, and four Gaussian kernel
coefficients, including the global phase. The Y branch uses one FULL
cover/translation map and the retained signed exchange. The complete
polynomial and address identities hold at every tensor depth.

## Sharp class and limit

Let q and v be odd binary vectors with q^T v=0. Every admitted orthogonal
L with Lq=v gives w=L^-1 q with q^T w=0. Both q and w have norm one.
The standalone X terminal has Clifford upper-right block q q^T+w w^T,
which has rank two. Monomial views preserve this rank; the rank of a
Clifford product is at most the sum of its factors' ranks. Thus every
one-field Clifford terminal word in this class needs total native rank
at least two. The actual recipe attains the bound.

This is a theorem for a port-diagonal orthogonal cover-only response and
the stated first line cut. It does not bound circuits that mix fields,
change that cut, use a payload response, or fuse the terminal with an
earlier operation. It is not a multiplication-algorithm lower bound.

If the complete productive paths and idle accounting give rank
2mn(D-1), this terminal brings the total to 2mnD. For positive b and
child widths r at most D, r^(1-b) is at least r D^-b. Repartitioning that
same rank therefore cannot give positive native-moment savings. This
last application remains conditional on the full ledger.

## Replay and source scope

Run with Python 3.11 or later, the standard library, at least 3 GiB free,
and a new output directory. No network is required.

```sh
python3 -I -B replay.py --out /tmp/common-cover-terminal-annex
```

Expected final line:

```text
PASS_COMMON_COVER_TERMINAL_ANNEX
```

The runner uses unchanged source checkers in fresh copies. It runs the
independent terminal check and the separate finite rank-control check in
normal and optimized Python. All four receipts match their frozen bytes.
The terminal check verifies every actual port, full Z4 coefficients,
complete affine four-point kernels, both cover directions, and wrong-line,
missing-line, missing-translation, and wrong-cover controls. The finite
rank check enumerates all orthogonal matrices in dimensions three and
five and checks all 112 actual cycles. The universal rank claim follows
from the symbolic proof, not from these finite dimensions.

The old independent review did not rerun that finite enumeration. This
annex does, and records it separately. No producer emitter, complete
native supplier, global owner schedule, or recursive precision check was
rerun. [SOURCES.json](SOURCES.json) pins the eighteen original inputs.

## Open next question

A cheaper complete supplier would need a result outside the sharp class,
such as a proved fusion with productive work or a different admitted
response. Any such construction still needs the actual path, owner,
map-cost, and precision ledger. This annex proposes no new construction.
