## Replay

Use Python 3.10 or later, its standard library, one process, and at least
3 GiB of free space. Copy this annex anywhere. From its directory, run:

```sh
python3 -I -B replay.py --out /tmp/ordered-rank-completions
```

The output directory must be new and outside the annex. Its parent must
exist. The final line must be:

```text
PASS_ORDERED_RANK_COMPLETIONS_ANNEX
```

The wrapper verifies the annex manifest. It runs both unchanged
independent checkers in normal and optimized Python, in sequence. Each
run uses a new copy of the exact local layout. Each complete receipt
is removed from the runtime copy before execution and must be produced
again. It must equal its frozen receipt byte for byte. The wrapper then verifies
all copied source bytes and removes only its generated runtime copy.
Logs and receipts remain in the output directory. No Git or network
access is used. No producer compiler is imported.

The pure-cycle check covers all 172,032 native input columns and
22,134,784 nonzero coefficients, as well as the owner transfer, entry,
exit, FULL, terminal, and fresh-cycle phases. Its controls reject an
added global phase, a non-coordinate native line, and a translation on
only one tensor copy. The rank-nine check covers both providers, the
complete signed Pauli maps and exact Gaussian state images, all local
Fourier phases, later-event nonaccess, the source bijection, and the
complete profile. It rejects wrong signs and translations on every path.

The complete 1094 archive is retained because the unchanged pure-cycle
checker pins its complete bytes before it reads DATA-PHASES.json. The
34 copied files close the executed checks and retain their freezes,
source proofs, peer qualification, source credit, and license. Producer
checkers are retained where a freeze requires them. They are not run.

The prior 194 package files, including both earlier annexes and their

Pending-review and local-only text in frozen packets records the state
at that freeze. The later accepted reviews are retained without edits.

## Cost and open obligations

The contraction removes 64 children. Its 128 monomial wrappers and
64 complex negative signs replace the preceding terminal paths. Those
signs cost 128 real scalar primitives. The signed bank exchange remains.
No owned or private field is added. The minus sign is one scalar sign
per full field; it is kept separate from tensorized column phases.

For equal field volume and `0<sigma<1`, the native child moment falls by
`64*(7^sigma+2^sigma-9^sigma)`. The rank mass remains 5,600. Under the
inherited 224-field D25 normalization, the native moment remains above
one for every positive saving exponent. This contraction cannot by
itself give an admissible supplier.

Native recursion, the complete cover and owner cost, packed map prices,
finite precision, and revised recursive row hosting remain separate
obligations. The pure-cycle argument needs a new proof for incompatible
cross-port bases, operations inside a child boundary, or nonlinear
finite-grid maps. The one-field rank-nine obstruction does not apply
to cross-field scalar mixtures, centre sharing, or a changed target.
