# Proof map and limits

The source files and accepted reviews remain unchanged. The two results
use different circuit classes. Their bounds must not be combined into
a lower bound for a general supplier.

## Pure-cycle operation set

The [source proof](frozen/work/centre-encoding-campaign-20261014/lanes/history-encoding/terminal-line-fusion-20261018/PURE-CYCLE-RANK.md)
and [independent review](frozen/work/centre-encoding-campaign-20261014/lanes/bridge-review-20261017/pure-cycle-rank-review-20261018/REVIEW.md)
fix one port and one ten-owner orbit. There is one common orthonormal
73-axis payload basis. Complete children have pure coordinate-C net
maps in this basis, up to a uniform translation. The rank price of a
child is at least the size of its coordinate subset. A child and both
side maps form one atomic operation.

At tensor width at least three, choose frequency bits 100 or 111
independently at each basis axis. The directional-C eigenvalue is then
i or -i. Uniform-copy translations have the same value for both choices.
Scalar field operations also have the same matrix for both choices.
Changing the sign at one axis changes a one-field child matrix by rank
one exactly when that child uses the axis.

For products of operation matrices, the rank of their difference is
at most the sum of the ranks of the factor differences. The proof uses
an input embedding and an output projection. It therefore permits zero
allocation, CLEAR, and arbitrary borrowed columns without an invertibility
assumption on the free factors. A required full transform on N independent
productive inputs changes by rank N at each of the 73 sign tests. Thus
the total paid rank is at least 73N.

For m pairs, one port orbit has 20m productive fields. Sum over all
ten-owner orbits and 112 ports to obtain `2*m*112*73` per cover copy.
At m=4 this is 65,408. Independent productive inputs at every owner are
required. A repeated-data input restriction is outside this statement.
The current invoice `64,512+896=65,408` attains the rank count in this
operation set. It does not turn the bound into a complete supplier bill.

There is a conditional cost consequence. If every positive child rank
satisfies `1<=r<=73` and its recursive term is proportional to `r^(1-b)`, with b>=0,
then `sum r^(1-b) >= 73^(-b) sum r >= N*73^(1-b)`. This consequence
requires that rank cap and cost model. Rank-zero monomial work is outside
this recursive sum. It is not a full supplier bound.

The independent checker verifies the complete exact global phase of
every one of the 336 fresh child recipes. It also verifies that the
literal owner transfers and DATA entry and exit maps have the claimed
translation form. A non-coordinate odd native line can change under
three tests while costing rank one. That control shows why the native
frame premise is material. General cross-port mixing needs a separate
proof that one common family of tests is preserved.

The approximation statement is limited to linear circuits in the same
operation set. Both members of each sign-test pair must have operator
error below the smallest singular value of the required matrix A.
For the stated unitary A, that threshold is one. No nonlinear rounding
or finite-precision supplier theorem follows.

## Last-completion contraction and local optimum

The [source proof](frozen/work/centre-encoding-campaign-20261014/lanes/bridge-access-20261017/rank9-completion-20261020/RANK9.md)
and [independent review](frozen/work/centre-encoding-campaign-20261014/lanes/bridge-review-20261017/rank9-completion-review-20261020/REVIEW.md)
keep the actual source endpoint adapter M_p. At the final scalar cut the
deferred Y field is in its canonical frame `T_p=M_p*C_(q_p)`.
The removed completion and target adapter give

```text
R_r = F9 C_(q_r)^-1 C_(q_p)^-1 M_p^-1
    = X_Delta (product_(j=1)^7 C_(u_j)) M_p^-1.
```

Let rho be the literal last-stage route, A the inverse-triple owner map,
and e its DATA exit translation. Let a=q_p and b=Aq_r. The old raw
terminal contributes X_(q_r). Its transported translation cancels the
inverse-line translation in C_b^-1. The complete ordered path becomes

```text
-X_tau C_a C_b (product_(j=1)^7 C_(A rho u_j)) P_(A rho) M_p^-1,
tau = delta + A(e + rho Delta).
```

All binary vector sums use XOR. The nine displayed directions are
orthonormal on every pinned path. Each emitted rank-nine recipe contains
both complete monomial wrappers, including the source adapter, owner
map, and final translation. The scalar minus sign remains separate.

The independent checker proves equal signed Pauli conjugation and equal
exact images of a nonzero state. All operators are unitary. Pauli equality
fixes the operator up to a scalar, and the state image fixes that scalar.
This proves equality on arbitrary arrays. Cancel the common scalar minus
sign before tensorization, tensorize the remaining equality, then restore
one minus sign on the full field.

The literal event suffix has no later read or write of a deferred Y
target. The remaining scalar code uses only X fields. The signed bank
exchange is valid on arbitrary incomplete-frame arrays. The output-port
permutation and invertible owner maps give a source bijection. These facts
permit the deferral without a second bank copy or a zero-input premise.
They do not price the packed field-and-address permutation.

For a one-field Clifford operator, let B be the X block of the images
of the Z generators. Composition gives

```text
B_(12) = A_1 B_2 + B_1 D_2,
rank(B_(12)) <= rank(B_1) + rank(B_2).
```

A monomial Clifford has B=0. A rank-k native child has B rank k. The
complete target, in the fixed physical charts, has B rank nine. Every
one-field native circuit with arbitrary monomial Clifford wrappers must
therefore pay total native rank at least nine. Both the old 7+2 word and
the new rank-nine word attain that bound. It does not cover cross-field
scalar mixing, changed charts or targets, or productive centre sharing.

The complete profile changes from

```text
{1:576, 2:208, 5:144, 7:336, 8:192}
```

to

```text
{1:576, 2:144, 5:144, 7:272, 8:192, 9:64}.
```

The child count falls from 1,456 to 1,392. The rank mass stays 5,600.
For `0<sigma<1`, strict subadditivity gives
`64*(9^sigma-7^sigma-2^sigma)<0`. At the inherited D25 normalization,
`5600/(224*25)=1`; each rank is below 25. Consequently the normalized
native moment is above one for every positive saving exponent. Map
cost, full-cover correction, precision, and recursive hosting remain
open. No complete supplier or kappa improvement is proved.
