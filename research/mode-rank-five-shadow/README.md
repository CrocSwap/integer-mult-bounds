# A filled three-dimensional mode shadow along one rank-five flat

This contribution was produced by Nick Petalas. New work is Apache-2.0.
Independent human and formal proof-kernel review are unclaimed.

**Exact finite certificate with a scoped proof; no new kappa.** For the
112-by-8 mode matrix of Dillon Amburgey's #4933, the row flat generated by
rows 0 through 4 has a three-dimensional quotient whose entire closed
zonotope is lattice-filled. Every one of its **103,333** lattice points is
a subset sum of the projected modes. Exactly **94,599** are interior and
**8,734** are boundary points. Row numbering starts at zero.

This supplies one explicit case of Open next question 1 in Armin
Pourshafeie / apoursh's [#6829](https://github.com/CrocSwap/integer-mult-bounds/pull/6829).
That package establishes facet and ridge filling and leaves three-dimensional
shadows open. Its scientific verifier is not replayed here.

[PROOF.md](PROOF.md) gives the quotient map, lattice basis, complete exact
facet description and finite enumeration argument. The new verifier reads
the pinned original matrix, checks the flat, computes all subset sums twice,
and compares them with every lattice point in the quotient zonotope.

## Reproduce

From the repository root, with CPython 3.12 and the standard library:

```sh
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -W error -B research/mode-rank-five-shadow/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -O -W error -B research/mode-rank-five-shadow/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/research_package.py --package research/mode-rank-five-shadow
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/check_research_commit.py --package research/mode-rank-five-shadow --check-source-history
```

Substitute another CPython 3.12 path on other machines. Expected markers are
`PASS_MODE_RANK_FIVE_SHADOW`, `PASS_REGISTERED_RESEARCH_PACKAGE`, and
`PASS_RESEARCH_COMMIT_BYTES`. A sparse checkout needs this package and
`research/coded-native-caller/NORMALIZERS.json` materialized before replay.

The verifier enumerates a box of 416,295 integer points, 25 facet-normal
pairs, and all 103,333 distinct subset sums. Independent bitset and tuple-set
recurrences agree exactly; independent interval and pointwise scans agree
on closed and interior membership. Five control predicates detect a removed
interior subset sum and holes in a small counterexample. Receipts are
generated from the current file hashes and bitset; no receipt is handwritten.

## Limitations

Only one rank-five row flat is covered. There is no all-orbit census,
universal three-dimensional filling theorem, or proof of R=1. The current
rounding-radius interval remains 1 to 3/2. Exact-mode rounding itself is an
abstract interface. No physical rounder or complete multiplication theorem
is supplied; kappa, selected frontier and the five assumptions are unchanged.
Native/caller implementation, ownership, compiler, precision/tape and stock
costs remain open. No predecessor scientific replay, full selected cold
replay, Lean, Docker or separate type/lint analysis was run. Hosted CI is
separate from local finite verification.

The `uniform-transfer-audit` card has explicitly changed scope to this
analytic-recovery side result. Its actual-caller acceptance gate is unmet.
The source-binding baseline passed and is only metadata orientation.

## Open next questions

- Locate this 15-row flat in a complete signed-symmetry orbit catalogue of
  rank-five row flats. A complete catalogue is not part of this certificate.
- Test another orbit using an exact quotient-lattice basis and full lattice
  membership scan. Larger quotient boxes may need another representation.
- Connect any eventual full-dimensional filling result to a physical
  rounder and its complete caller costs. Shadow filling alone is insufficient.
