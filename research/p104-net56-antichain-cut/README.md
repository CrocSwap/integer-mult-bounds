# Prove the 56-drop P104 antichain case with two seven-dimensional gathers

With nine gathers, the specified two seven-dimensional gathers and an eight-depositor antichain, D≥56 for all depot charts of dimension at least seven.

A second argument settles one 6D and one 7D low depot when the other six are at least 8D. Equality controls have D=56.

The source archive contains the exact pins, proof, licenses, commands and control outcomes.

Archive SHA-256 `799188a1610e26856d95e0bd217ff149c80298a62188fbb7cc2b26a4e54b1fc3`.

Unpack in a clean directory, validate `sha256sum -c SHA256SUMS`, and run `python3 -I -B check_three_low.py`.
