This checks the complete **finite formal recursive-job bill**, under the
declared frame-rank tariff and frozen caller interface. It does not admit a

## Result

Two independent standard-library implementations derive the local and complete
paid/productive histograms directly from the frozen PR6349 and PR6353 words and
PR6348 caller data. The primary uses explicit binary spans and chronological
role tracking; the oracle uses pivot elimination and a separate caller count.
Neither imports an author constructor, checker, invoice assembler or interval
engine. The retained author RESULT is compared only after independent counting.

All public ascents and owned descents are charged. Owned scratch receives no
productive credit. Exactly nine helper targets change, one `9→5` and eight
`9→8`, at **each of nineteen calls**. The independently derived local deltas are

```
paid:    14 H1 - 4 H2 - 3 H3 + 4 H4 - 5 H5
targets: H5 + 8 H8 - 9 H9.
```

Complete deltas are nineteen times these quantities. The bill also includes
all sixteen thin queries, sixteen paired whole-idle events, and thirty-four
declared main targets, with 104 field copies. All those additions are counted
from the serialized caller and separately checked against its fixed-tree
formula. The scalar-work tally is not a proof that the full native, route or
ordinary-work budget is funded.

At the **author's fixed saving** `315057/100000000`, the independent rational
engine encloses `Σ(targets_r-paid_r) r^(1-saving)`. It certifies

```
new margin >  0.00306055749
old margin < -0.19287557317.
```

Full exact rational endpoints and every rank-power interval are in
`ORACLE.json`. This is a single-parameter raw-moment check, with no root search,
crossing-uniqueness claim, compiler/outer admission or new exponent claim.

## Evidence and reproduction

`verify.py` checks every literal MOVE's frame nesting, direction and ownership,
all owned lifetimes, helper boundaries and the complete formal caller bill.
Six **counterfactual invoice vectors** identify concrete differing rank
coefficients for omitted owned transport, a missing full call, an undeclared
target credit, an omitted target debit, an unpaid query or half an idle pair.
These are ledger controls, not claimed replays of modified physical programs.
The independent oracle also rejects an inconsistent literal output declaration.

The interval argument uses 48 positive atanh-series terms with an explicit
tail, range reduction, outward logarithm rounding to `10^-40`, and odd/even
exponential partials of degree 17/16. Sign-aware accumulation uses power
intervals rounded outward to `10^-30`. The proof and implementation retain
explicit domain and error bounds under optimization.

From the repository root with Python3.12:

```sh
python3.12 -B scripts/research_package.py --package research/p104-joint-output-invoice-audit --check-only
python3.12 -B scripts/research_package.py --package research/p104-joint-output-invoice-audit
```

```sh

python3.12 -I -O -W error -B research/p104-joint-output-invoice-audit/oracle.py
```

## Source bindings and limits

`SOURCE-PINS.json` lists seven byte-exact inputs, their original paths, commits,
Git blobs and SHA256 hashes. Both checkers independently authenticate them.
The retained Python tariff and controller sources are provenance data, never
imports. Package-local copies make scientific replay independent of pending
foreign Git history or network access. `SOURCES.json` separately pins the
catalogue and selected record at base
`7c49fe32c55de02c2c873655c804b16e4c3fef0a`.

The frozen caller's diagonal and rank-eight independent-stage interface are
premises of this bill. Counting does not prove its Laurent endpoint or physical
contacts. Native maps, absolute phases/all columns, physical erasure, complete
ordinary funding, compiler and outer contracts remain separate. The earlier
[rational audit PR6355](https://github.com/CrocSwap/integer-mult-bounds/pull/6355)
does not transfer those admissions. All five framework assumptions remain.
