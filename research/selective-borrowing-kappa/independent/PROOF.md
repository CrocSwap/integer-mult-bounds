# Exact operator partition on physical families

Run `python -I -O -B independent/verify.py` from the contribution directory. Only Python's standard library is required. The source package is read-only; generated charts and receipts go to a temporary directory. To retain them, pass `--work` with a nonexistent directory outside the source package. `SOURCES.json` pins every consumed source and native checker. `EXPECTED.json` freezes the complete deterministic receipt. The literal input parent is the T8, 72-call parent retained by the public PR1005 owner-repair lineage, not the incompatible T74 parent.

Write `X_v f(x)=f(x+v)` and `C_v=((1+i)I+(1-i)X_v)/2`. The algebraic identities in `../lean/Factors.lean` prove that these full Gaussian operators commute on an additive commutative address space, including their scalar phases. They also prove that a permutation of instructions preserving both physical family and axis preserves the family-wise operator, and that address translations commute with these products. Thus a literal factor partition within one untouched family interval is a sufficient equality certificate. A global bag of axes that forgets the physical family is insufficient.

This checker reconstructs the actual parent chronology, including both bridge reads and bridge writes. Each replica preserves the parent's source event sequence. Every complete helper invocation lies inside its donor child's untouched interval. Every helper is assigned to a distinct physical family outside that invocation's 224 source and target data families. The 73-column orthogonal charts are derived from the parent's actual port normals. Their first `w` columns are the literal assigned pending axes, with the remaining local axes treated as identity spectators. Both orientations' literal `R^-1` and `L^-1` wrappers are rechecked against their actual native payloads, including exact global phase: `L^-1 (T_F T_E^-1) R^-1 = C_w tensor I_(9-w)`. Data chart normals and source/target directions are checked against the source parent.

The audit partitions all 387,072 positive parent idle-child factors into 254,088 hosted factors and 132,984 literal remaining factors, retaining every physical family, source child, axis, and positive direction. All 16,128 original positive-idle-child record translations are explicitly retained, even when the remaining Gaussian rank is zero. The rebuilt paid profile has rank mass 520,704. Mutation controls reject a negative child direction, a cross-family axis swap that preserves the untagged global axis bag, and a wrong scalar phase. These controls specifically address the family-operator failure of the withdrawn cross-family axis-swap proposals.

The factor partition and chronology implementation imports no hosting constructor or owner emitter. Its native Gaussian interpreter is the same retained public signed-Pauli/exact-Gaussian engine used by the local native audit; this is an independent assembly audit, not a third independent native implementation. This finite certificate establishes the stated operator partition. It does not establish an all-size compiler, precision or tape complexity, the physical invoice, or the analytic transfer to multiplication; those are separate parts of the package and the project's inherited hypotheses.
