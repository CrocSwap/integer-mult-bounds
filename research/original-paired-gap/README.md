# Paired gaps in the original complex frames

Two replicas of the actual local interface can carry centre information
through an exact involution. The extra operations are scalar ADDs and
translations. The pair needs no added native child and no Walsh change
of frame. Its query and injection factors have zero product at every
pair of stages.

The general theorem applies when an invertible phase Q has legal
monomial square and inverse-square access. It does not assume `Q^4=I`.
It requires the stated raw interface, common productive frames, and
the R/K frame intertwiners. The fixed native instance uses the original
complex identity `C_p^2=X_p`, including its scalar phase.

Read the [proof](PROOF.md), [literal paired packet](data/PAIRED-PROGRAMS.json.gz),
[independent native review](evidence/NATIVE-REVIEW.md), and
[source pins](SOURCES.json). The lane proofs and native packet have
separate-agent review. The [independent portable package review](evidence/PACKAGE-REVIEW.md)
passed with no material finding. These are AI-agent reviews, not independent
human reviews.

This is a local construction and an enabling theorem. Full global
closure remains unproved. The package gives no complete supplier or
kappa improvement. In particular, the zero product does not make final
odd-phase H/G reads or injections free.

The [publication update](PUBLICATION.md) records the 22 October source
refresh and cold review. This package uses a historical supplier; admission
to the newer selected joint-helper construction has not been proved.

## Local contract

Each replica has 112 X fields, 112 Y fields, eight arbitrary mode fields,
and 472 ordinary borrowed helpers. The input frames are `(Q,I,I)` for
`(X,Y,u)`; the output frames are `(F,FQ^-1,F)`. The two replicas have
the same chart and stage. Their active data and mode roles are separate.
Ordinary helpers can share a physical owner only under a complete
restored-job and consecutive-frame schedule proof.

With `T=[[0,Q],[Q^-1,0]]`, set `G=R(I-T)` and `H=(I+T)K`. The maps are

```text
Forward:  x'=x,           v=-z-Gx,     y'=y+x+Hv.
Backward: x'=x-y-8Hz,     v=-z-Gy/8,   y'=y.
```

The 16 mode inputs z are arbitrary. Their outputs v are part of the
contract. All 944 ordinary helper contents are restored in their
specified output frames. The cores do not refer to private centre fields;
those fields are preserved by non-use. The pair has 1,408 persistent
input coordinates. It does not require an extra replica or a second
private core workspace.

The factors at any stages s and t satisfy `G_s H_t=0`. This does not
require equal centre row spaces or commuting R/K through the phase.
The two local maps have explicit inverses. They are not stated to be
inverses of each other. Their inverses in the proof are algebraic maps;
native boundary access for those inverses remains a separate question.

## Reproduce

Use Python 3.10 or later, the standard library, and Git. The repository
must contain commit `bce54fb3f895cbe5cd4c0eb477c3afeed100190f` and its
historical1042 source archive. No network or third-party package is
needed. Run one process from the repository root:

```sh
python3 -I -O -B research/original-paired-gap/replay.py --repo . --out /tmp/original-paired-gap
```

The command writes only to the explicit output directory, which must be
outside this package. Expected output:

```text
PASS_EXACT_ORIGINAL_PAIRED_MAPS
PASS_ORIGINAL_PAIRED_NATIVE_COMPONENTS
PASS_GENERAL_MONOMIAL_SQUARE_IDENTITIES
PASS_PORTABLE_ORIGINAL_PAIRED_GAP
```

It writes `PAIR-CHECKS.json`, `NATIVE-CHECKS.json`, `ALGEBRA-CHECKS.json`,
and `REPLAY.json`. The last receipt binds the source blobs, code bytes,
and the other three output hashes. The check uses explicit failures;
Python assertions are disabled in the command above.

The replay checks both cores on all 704 input columns and both paired
words on all 1,408 columns. It checks arbitrary helper and mode inputs,
private non-use, both algebraic inverse orders, chronological frame
records, all 10,112 retained native events per pair, and literal costs.
It checks all 57,344 positive line columns and all 1,008 actual affine
routes. The general operator check uses inverse cancellation for Q;
it does not reduce Q powers modulo four.

Controls reject a missing basis output, missing input graphs, omitted
translations, a changed backward old-mode read, an early forward target
update, an incorrect native scalar phase, a wrong owner direction,
unrelated stage phases, incompatible replica views, and an unrestricted
data bridge. The general check also exhibits the failure caused by a
missing productive-frame intertwiner and a case with `Q^4=-I`.

The old core native kernels and complete helper interface are inherited
from pinned source evidence. The replay checks their unchanged event
streams and local scalar frames; it does not repeat every old native
kernel calculation. The fixed local phase identities extend to every
positive tensor depth by exact tensoring and owner covariance, as proved
in PROOF.md. Finite column counts alone are not the all-depth proof.

Each retained core has scalar allowance 204,418 and native rank mass
5,522. The complete scalar entries include both cores and all added ADDs.
They exclude native child implementation, native wrapper and address-map
execution, owner access, mode preparation and completion, displaced-owner
backfills, the final decoder, storage, precision, and recursive assembly.
A translation count is not a unit-cost real-primitive bill.

For the actual unit-modulus wrapper, the prefix/suffix infinity-norm
bounds are 57/58 forward and 9/8 backward. These bounds cover only the
added wrapper. They do not bound the core, recursive children, complete
controller, or supplier precision. All added scalar coefficients are
dyadic.

## Owner applicability and open work

The separate [owner composition review](evidence/OWNER-BINDING-REVIEW.md)
accepts a schedule for 72 same-stage pairs with a 280-slot owner patch,
fresh one-shot modes, and explicit displaced-owner backfills. The
[source proof](evidence/OWNER-BINDING-SOURCE.txt) is retained byte for byte
as an archival text file. Its path references refer to the source
campaign. Its exact producer and receipt pins are in the review.

That result supplies a conditional owner and endpoint schedule. It is
not a full emitted global word. The local replay does not re-run the
owner patch, one-shot histories, or their child invoice. These are
separate applicability evidence, not hidden runtime inputs. Its
candidate productive stock remains conditional on content repair.

The remaining construction work includes legal final H/G access,
arbitrary-mode restoration in the complete controller, a complete
global word, the finite scalar and address bill, precision, and recursive
supplier admission. Neither a complete kappa calculation nor the
repository-wide test suite is run by this package.

## Open next questions

1. How can one complete physical H/G boundary operation be implemented?
   The zero feedback theorem does not provide that access. First emit and
   price one read or injection at the stated native endpoint, with arbitrary
   mode contents and exact phases. The blockers are unresolved native
   endpoint access and its complete cost.
2. Can a complete paired supplier be constructed and priced? Local pairing
   and the owner schedule do not establish that result. Start from the
   separately reviewed owner schedule. Emit and price the complete mode
   histories, backfills, and decoder, then check recursive admission.
   Arbitrary-mode restoration, complete scalar and address costs, and
   precision remain blockers.
