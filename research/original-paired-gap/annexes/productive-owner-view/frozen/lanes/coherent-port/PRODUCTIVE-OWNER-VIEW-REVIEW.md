## A changed logical coefficient does not require a conversion

Work in one invocation's physical address chart. Let L be its nine local
axes, let F_L be its complete local native transform, and let P be the
common exterior frame used for an active Y array. After its actual
monomial helper entry view, an old width-nine owner has frame

```text
O=X_delta product_{j in W} C_(e_j),  W disjoint from L.
```

The complete helper job advances this frame to O F_L. The fresh mode
interpretation instead uses P at entry and P F_L at exit. Define

```text
Delta=P^-1 O.
```

The nonmonomial factors of P and O act outside L. Their translations
also commute with F_L, since the native C factors are convolution
operators. Thus Delta commutes with F_L. The same physical mode input
has fresh logical value z=Delta h when its old-owner
logical value is h. The fresh and old output values have the same
relation. For several promoted owners, Delta is a diagonal block map
whose blocks can differ. It need not be monomial or common to the eight
centre indices.

Let B be the complete reviewed local content map in the fresh mode
interpretation. Let D_in and D_out be identity on data and ordinary
helpers and Delta on each promoted mode. Then the literal physical
program has the old-owner content map

```text
B_old=D_out^-1 B D_in.
```

In this local chart D_in and D_out have the same mode blocks. The order
in this equation is essential. No map Delta or Delta^-1 is executed.
The equation states what the existing physical program computes on a
different choice of logical variables.

For example, a fresh forward map

```text
v=-z-Gx,  y'=y+x+Hv
```

becomes

```text
h'=-h-Delta^-1 Gx,
y'=y+x+H Delta h'.
```

An exterior-frame discrepancy therefore changes the query and response
coefficients. It does not require a normalization child unless the
construction also requires the old fresh-mode coefficients or endpoint.
The full physical scalar graphs remain the same operations on arrays
with the same address domain. A frame label does not change their
elementwise meaning. The changed content must be tracked explicitly.
