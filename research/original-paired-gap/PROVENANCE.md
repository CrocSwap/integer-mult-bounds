# Publication extraction

This package copies the reviewed local paired-gap package. The source
manifest is retained as `evidence/PRE-WRAP-MANIFEST.json`. It binds the
50 files that were prepared before the publication hold. All proof,
program, source, notice, and review files from that package are unchanged.
The package had no published PR when this extraction started.

The current README already states that the independent portable review
passed. No stale review claim or publication hold required a text change.
The new `MANIFEST.json` covers this extraction and its added provenance.
Historical manifests and receipts keep their original bytes.

The historical source commit remains
`bce54fb3f895cbe5cd4c0eb477c3afeed100190f`. The result is a local native
construction and a typed operator theorem. It gives no complete supplier
or kappa improvement. Its physical decoder access, global mode closure,
finite implementation cost, and recursive admission remain open.

The publication audit read the full proof, source loader, replay driver,
and independent portable review. It ran the optimized isolated replay
again, plus the independent rectangular algebra example and the actual
Fourier-character mutation witnesses. The new receipt records each
command and compares the mathematical output bytes with the old receipts.
It does not replace the earlier cold package review.

The audit also checked the live list of the author's PRs. The related
Walsh lift, native source codes, and joint query transfers are already
published in PRs 1719, 1862, and 1969. This package retains their distinct
roles and source credit. It does not submit those results again.
