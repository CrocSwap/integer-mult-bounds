# A c=1 stabilizer element carrying one 8-dimensional joint basis

Prepared by unpaidmoon with substantial Cursor Grok assistance. Apache-2.0.

For the historical 8-by-112 centre query, the unsigned involution
`sigma = (0 3)(5 6)` lies in the order-3072 stabilizer of sector `c=1` and
outside the group generated by `H`, `g` and `t`. It carries the pinned
8-dimensional `(+1,+1)` basis of PR #7019 onto the `(+1,-1)` joint space.

The same census classifies every stabilizer element. Each of the four joint
spaces is the image of this basis under 768 stabilizer elements. The three
spaces other than `(+1,+1)` account for 2304 elements, all outside
`<H, g, t>`.

No new kappa. The selected conditional kappa stays `781451/250000000`.
[PROOF.md](PROOF.md) separates the witness, the census, and the facts that
are not claimed.

## Result

The live input is the query pinned in [SOURCES.json](SOURCES.json), SHA256
`5c6c51fbffc07a683e922f17532fd90262ae9e23cc3560a696002073dd234ef3`.

`H` is the order-16 sign group supported on coordinates `{1,2,5,6}`. The
character is `chi = eps[1] eps[2] eps[5] eps[6]`. The involutions `g` and `t`
split it into four joint spaces of dimension 8, supported on the coordinates
`L = {0,3,4,7}`. The inherited `(+1,+1)` pivots are

```text
128, 129, 134, 135, 170, 171, 172, 173.
```

The symmetry group of the query is the signed affine group of order 344064.
Its stabilizer of sector `1` has order 3072. The underlying permutations are
exactly the 96 affine maps that preserve `L`, and each has 32 sign patterns.

The witness `sigma = (0 3)(5 6)`, with all signs `+1`, sends coordinate 0 to
coordinate 3. Every element of the order-64 group `<H, g, t>` fixes
coordinate 0, so the witness is outside that group. It sends each canonical
`(+1,+1)` basis vector to the canonical `(+1,-1)` basis vector with the same
address coefficients. In these ordered bases, `B = 4 A_1` has the same
8-by-8 matrix on both spaces, so the witness intertwines the two restrictions.

| image of coordinate 0 | joint signs | elements | outside `<H,g,t>` |

| 0 | `(+1,+1)` | 768 | 704 |
| 3 | `(+1,-1)` | 768 | 768 |

## Evidence class

The witness is a proof of one finite identity. The fiber counts are an
exhaustive finite census of the order-3072 stabilizer: the symmetry group is
identified with the signed affine group, the orbit of address `1` has size
112, and the `T(1) = 1` scan matches that orbit-stabilizer count. This is
not a heuristic search and not an unrestricted claim about operators outside
the stabilizer.

## Reproduce

From the repository root, with CPython 3.12 and the standard library:

```sh
python3 -B -W error research/c1-joint-8-transporter/verify.py
python3 -B -O research/c1-joint-8-transporter/verify.py
python3 -B scripts/research_package.py --package research/c1-joint-8-transporter --check-only
```

The marker is `PASS_C1_JOINT_8_TRANSPORTER`. Acceptance uses explicit checks,
so `-O` does not skip a census step or a rejection control. On the measured
host the census takes about five seconds. No Lean, Docker, degree-881 replay,
degree-216 replay, or selected cold replay was run.
