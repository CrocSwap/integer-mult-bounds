The **selected complex** construction in [#7828](https://github.com/CrocSwap/integer-mult-bounds/pull/7828)
translates into [#7834](https://github.com/CrocSwap/integer-mult-bounds/pull/7834)'s
finite all-column C-word alphabet once fixed Gaussian-rational SCALE is admitted.
The translation preserves dimension, independent productive width and every
positive paid rank-one call. It adds explicit charged CLEARs for private rows.

This is a conditional **finite grammar admission**. It retains the source
native all-column identities, its exact owner/erasure semantics, the compiler's
funding theorem and the receiving physical row contracts. It supplies neither
the binary supplier nor a complete runtime theorem. The selected enormous
word is not materialized. No new kappa; all five selected assumptions remain.

## What the translation proves

| Source operation | Receiving instructions |
|---|---|
| Fixed Gaussian-rational scalar | Exterior `SCALE(a,b,q)`, applied once |
| Binary-affine quadratic-phase monomial | `x`, `s`, `cz`, `cx`, `unit` |
| Signed `L C_r R` job | Actual R, positive C job, actual L; independent factors retained |
| Complete axis placement | CNOT decomposition of the complete permutation and its inverse |
| General scalar ADD | Alias-safe private staging, SCALE, ADD, charged CLEAR |
| Complete row SWAP | Eight copy/add/clear instructions with one private temporary |
| Actual global LAMBDA | Exterior `(1±i)/2` coefficients around a complete translation |
| Positive rank-one leaf | Exactly one `paid` instruction |
| Private lifetime and final exit | Explicit CLEAR, with no productive credit |

The phase distinction is essential: scalar i acts once, while `unit` acts by
`i^f` at external column multiplicity f. A raw monomial's own multiplicity c
therefore needs phase `i^(a*c*f)`. Scalar coefficients remain outside all tensor
powers. Whole-job placements include every spectator coordinate and return
before a suspended parent resumes.

The selected global LAMBDA is a two-term operator on the entire column set.
It is not a tensor power of its unary scalar program. Its explicit translation
and a failing tensor-power control are included, along with a census of all
3,095 compact selected caller events. The expanded physical caller counts
retain their separately audited source meaning.

The source's selected uniform saving is
`181502908503/50000000000000`, strictly above the receiving price `1/500`.
Preserving P, W and N therefore preserves the exact funding inequality
`P^500 < W^500 N^499`. [PROOF.md](PROOF.md) gives the source mapping,
universal translation, explicit finite instruction bill and inherited premises.

The original receiver checks productive endpoints only. The translated word
also guarantees zero private endpoints by appending and charging one CLEAR
per private row. A rejecting control shows why productive admission alone
does not establish private zero.
