# Recover a compact dictionary without a supplied key list

This five-module Lean 4.21.0 chain discovers ordered key candidates from the original artifact bytes and executes the existing complete compact-dictionary checker. The executable inputs are artifact bytes, a selection index and the chart update/coefficient functions. Neither keys nor column arrays are supplied as executable inputs.

The scanner proves an exact alternating byte-region decomposition and is complete for the entire checked hex-key/compact-Nat flat layout. Separate logical UTF-8 proofs recover the original keys from the actual byte policy. The final theorem therefore removes the token-decoding success premise while preserving both actual JSON parser equations and the restricted chart conditions.

Successful execution retains all named columns and their order/bounds, complete artifact-byte equality, and the independent column operator with both inverse directions. Candidate scanning alone is not a general JSON parser. Escaped/nested JSON, parser internal spans, runtime extern refinement, external artifact/digest authentication, complex phases, physical execution and costs remain separate. No selected artifact or new literal census is checked here.
