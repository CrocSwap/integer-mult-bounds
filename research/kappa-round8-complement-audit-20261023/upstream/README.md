This package constructs two actual native local suppliers from PR #4610's round-three word. The new orthogonal-restriction supplier has a strictly smaller complete local paid moment than its predecessor for every exponent 0 <= t < 1. For a seven-axis Gaussian D and a disjoint central Gaussian Q, both suppliers have 56 ports of type A, `diag(D,D) Sy(Q^-1)`. On the same other 56 ports, the quotient supplier has type B, `diag(D,QD) Sy(Q^-1)`, while the restriction supplier has type C, `diag(QD,D) Sy(1)`. Thus their nonstandard interfaces are explicit and complementary. The backward interfaces are their exact inverse transposes; even-power monomial corrections are required when changing to the retained controller convention.
