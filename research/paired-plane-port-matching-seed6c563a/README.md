# Paired plane-port matching

This package gives one explicit finite decoder mechanism for the selected 112
complex E8 port labels. It symmetrically pairs the labels along zero-dot-product
edges, assigns each pair one common 2-plane, and factors the full selected
pairing matrix through those planes.

## Result and evidence

The exact construction uses 56 matched planes, of which 16 have nonzero query
matrices. Their exact B14 copy invoice is 126: nine rank-7 terms and seven
rank-9 terms. The verifier checks the complete 112 by 112 decoder identity,
the plane basis legality, and all 56 plane endpoint translations on 28,672
local computational basis cases. Four negative controls fail as required.
The hosted application frequency of those translations remains unpriced.

The changed local profile has a certified favorable complex relaxation at
`a_hi=0.003447203501`, with a planning transfer cap near `0.003435361112`.
This is a construction component and a conditional screen. It does not supply
the complete routed supplier, charge all hosting and interface work, establish

\(\kappa\).
