# Independent 400-helper owner check

Run from the repository root:

```sh
python3 -B research/complex-structure-seed39/anticipatory-stage-evidence/owners/check_owners.py --controls
```

Expected status:
`PASS_INDEPENDENT_400_HELPER_LITERAL_OWNERS_WINDOWS_AXES_AND_PROFILE`.
The command reads the existing candidate owner witness and never runs an
optimizer, emitter, owner constructor, or inherited controller audit. It
writes a receipt only when `--out PATH` is explicitly passed. Python `-O`
retains all checks.

This checker establishes the following finite obligations for the frozen
PR2269 T=74 invocation order and dispatch, with the PR2339 400-helper native
base/extra words:

- It recounts native paid ranks with complete F2 span bitmaps and checks both
  literal forward/backward local programs and source-bound replay receipts.
  It derives helper widths from native start/final subspaces and verifies
  the original-register complement for the 80 removed helpers.
- It expands the serialized source-event blocks in the actual invocation
  order, verifies every replica's exact 30-event projection, and reconstructs
  all 1332 strict pending windows including each of the 666 bridge touches.
  The reconstructed windows must equal the pinned plan's windows.
- It checks all 266400 roles, all 400 distinct native helper IDs per call,
  distinct physical families within each call, exclusion of active data
  families, and each role's full width inside its window and pending bin.
- It verifies the inherited 112 orthogonal bases and actual pending axes,
  including disjoint pending children sharing a physical family. Integer
  occupancy masks establish disjoint residual slices and complete prefixes
  in all 149184 pending bins. Each occupied slice receives a complete
  73-axis permutation with the required residual and spectator coordinates.
- It recounts every idle remainder, adds all 666 complete local paid
  profiles, and verifies rank mass 4816512 and deficit
  `73·66304−4816512=23680`. The receipt includes a canonical sigma-stream
  digest for comparison with a separately emitted controller.

Nine mutation controls must fail at their intended predicates: wrong width,
wrong physical family, wrong invocation time, duplicate helper, duplicate
family, slice overflow, active-data alias, crossing a strict bridge-aware
window, and overlapping residual axes. These are finite implementation
checks, not a formal proof of the multiplication theorem.

Source pins are enforced for PR2269 head
`b479fc5567bc09ab9185bffe89b62594f36d74e5`'s source template and frozen plan.
`PHASE-SOURCE.json` identifies the unchanged local repository copy of
`DATA-PHASES.json`, whose hash agrees with the pinned source template.
The output records exact candidate, native input, source, and checker hashes.
The candidate itself remains mutable during research; a final submission
must freeze the receipt and all source hashes together.

This result is only the owner/interface accounting obligation. Native scalar
identities, rank-zero warp realizations, local/global phase correctness,
equivalence of an emitted controller to the checked map, the complete finite
coefficient invoice, exact moments, and the outer reduction remain separate
requirements. The inherited `live+8+R+2` physical envelope is labeled as an
assumption; this script does not prove that the borrowed-word private zero
buffers and coefficient streams fit its private register allocation.
