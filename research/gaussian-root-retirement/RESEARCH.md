# Discovery and remaining scope

The new step changes a hypothesis of the PR6398 packing ceiling. That ceiling
keeps each complete Gaussian target intact. This caller returns one factor at
an intermediate cut and gives the suffix a fresh input. Its target inventory
is therefore outside that fixed-target model.

The discovery screen first set q²=1. It searched the equal-target groups and
paid-event cuts in the literal 34-field caller. It found the group 4,20,21 after
event 328. A separate q²=-1 calculation gave compatible dual pairs. Neither
specialized calculation was used as a substitute for the full-ring proof. The
published checker validates the unspecialized pair and complete caller.

The first emitted word normalized every original output. Only the three group
outputs need that normalization. The final construction uses 609 events instead
of 684. This reduces ordinary work and proof surface; it does not add another
κ gain. The native source was then updated from PR6398 to PR6529. The reported
increment compares the new caller with PR6529 and excludes that inherited gain.

The source invoice is preserved, except for the 104 legal target splits. The
strict raw bracket is less than 6.371e-9 above the conditional claim. This is
almost all the gain available from this exact invoice. It is not a global
ceiling for independent Gaussian retirement.

Further local discovery tests covered supplier-boundary shears, larger scalar
roots, changed query words, owned-lifetime output bases, and short moving-state
Gaussian-assisted templates. They did not produce another complete caller.
These were bounded searches, not universal impossibility proofs. Their work
files are not runtime inputs to this package and are not published as exact
exhaustive coverage claims. No relaxed favorable price is counted as a result.

A useful next construction needs a larger independent target split or a new
closed query interface. It must bind the actual native helper maps and charge
all helper debits, idles, routes, COPY/CLEAR work, restoration, compiler and
outer costs. The 1% target over PR6529 is 0.00332118199. This package does not
meet that target.
