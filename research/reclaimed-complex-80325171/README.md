# Reclaimed complex supplier with stopped product-ring interchange

This package supports the conditional exponent

\[
T(n)=O\!\left(n(\log n)^{1-80325171/10^{12}}\right),
\qquad \kappa=0.000080325171.
\]

The new ingredient is an exact, physically framed dependence-reclamation
compiler for the signed h24 complex supplier. Combining its independently
replayed component with PR104's reviewed stopped product-ring bit interface
improves PR104's stated kappa by approximately 3.050217%. The ordinary bit
component is now the limiting component.

## Reproduce

Python 3.11 or later and the standard library suffice. Preserve this directory
layout. No installation or network access is needed.

```
python3 run_checks.py                 # byte counts, pins, dependency closure
python3 run_checks.py --replay        # also replay complex events and assembly
python3 run_checks.py --bit-controls  # also bounded independent bit controls
```

The runner verifies the immutable release manifest first. Scientific checks
run in a disposable copy, so the frozen receipts are not overwritten. The
complex replay previously took 10.39 seconds and 93.8 MiB; the assembly check
is subsecond. Each check is capped at 120 seconds and, where supported, 384 MiB
address space. No upstream producer or upstream verifier is run or imported.

The frozen compact witness contains 402,941 events and all 20,264 terminal
records. Its graph, physical slots, elementary GL factorizations, signed exact
source relations, promises, paid frame transitions and terminal scatter are
independently reconstructed and checked. The event/checker entrypoints reject
optimized Python. The complete finite child histogram, three strict rational
moments, scalar guard, three-family row stock, 47 constraints and seven final
margins are checked with exact arithmetic.

The included emitter sources explain the construction. They are not run by
the release checker. Regeneration is unnecessary for validation; compressed
output includes historical gzip timestamps and is not advertised as a
byte-identical regeneration recipe.

## Scope

This is a conditional result in the retained analytic, exact-recovery,
admissible-prime, ordered-affine/whole-residual, complete-row and fixed-finite-
alphabet fixed-tape framework. It is not an unconditional theorem, an upstream
full-producer replay, a formal proof of the whole analytic stack, or a claim
of practical-size running times. Every changed complex cost and interface is
explicit. No arbitrary reversal, uncharged dirty reset, free frame raise,
or per-child outer wrapper is assumed.

The next 10^-12 grid point fails for the displayed assembly parameters only;
this is not an optimality claim. The unused stronger complex root cannot
improve the current bound without improving the bit side or assembly interface.
