# Reframing PR952 cannot reduce its paid bit moment

**Scoped negative result; no new kappa.** The shorter PR952 bit circuit has
more frame freedom than selected PR589, but none of that freedom reduces
its paid moment. For this fixed scalar word, original start/final and COPY
frames, and closed frames generated by the live E8 lines, the inherited paid
profile minimizes the moment for **every real `0 < c < 1`**. Every different
profile is strictly worse. Gate reorderings, changed copies, new helpers,
other scalar words and changed hosting remain outside the result.

This closes a concrete follow-up to PR952's scalar shortening. PR886 proves
frame optimality for PR589/555; it does not cover the changed PR952 gate
sequence. We retain PR952's credited **23,673 ADDs** and unchanged histogram
`{1:1323,2:1342,3:79,4:44,5:102,6:11,7:19}` of rank mass **5,129**.
No circuit is replaced and no selected frontier is edited.

These are **componentwise** counts, not a count of complete global assignments
or 19 global minimizers. The largest component has 13 gates. Additivity of
register-chain costs lets the component checks cover simultaneous global
frame changes without multiplying out all assignments.

Of the 934 strict alternatives, 933 have an integer certificate based on
truncated rank sums and discrete concavity. One has signed profile difference
`{1:+3,2:-3,3:+1}`. It fails that sufficient concavity test, but the separate
inequality `1 - 2*2^(-c) + 3^(-c) > 0` for `c > 0` proves its strict loss.
The [proof](PROOF.md) explains both cases; an unclassified profile makes the
checker fail. Uniform optimality is therefore not inferred from a finite
sample of exponent values or one numerical endpoint.

The old producer's scatter handling relaxes exact COPY equality. The separate
checker explicitly enforces actual frame equality, including a same-rank wrong
frame control; all 1,090 surviving assignments satisfy it. Cleanup C frames
remain relaxed below the H4 full-frame requirement, so the negative result
also covers the more restricted original interface.

## Reproduce

From the repository root, with standard-library Python 3.11+:

```sh
python3 -I -B research/r439-resynth-frame-seed10/check.py
```

Expected: `PASS_R439_RESYNTH_FRAME_INDEPENDENT`, 314 free gates, 13,730
component assignments, zero improving components, uniform power-moment
optimality `true`, and **9 rejected controls**. Runtime is about four seconds
on the recorded machine. The raw all-concavity flag is deliberately `false`
because the one exceptional profile is handled by its own proof.

The command independently reconstructs integer row spaces over Q, every
closed-frame interval, free-gate connectivity, legal assignments and complete
register-chain costs. It checks every field of `CERTIFICATE.json` and the
proof-relevant domain/coverage fields of `NOMINATION.json`. It imports no
producer search or geometry code. The shared rational interval engine is only
a fixed-c cross-check; the uniform proof uses the exact integer census and the
two written inequalities. Source files are checked against `SOURCES.json`.

Additional admission controls:

```sh
python3 -I -B research/r439-resynth-frame-seed10/test_package.py -v
```

Expected: **6 tests pass**, including omitted frame/component coverage,
changed COPY boundary, invented improvement, corrupt source and complete
execution with `-O`. The checker also recovers the original profile from a
legal least-frame degraded assignment, improving 77 of its components.

To reproduce the credited PR886 nomination on this new word:

```sh
python3 -I -B research/r439-resynth-frame-seed10/nominate.py
```

Expected: `PASS_R439_RESYNTH_NOMINATION free=314 assignments=13730 improving=0`.
This slower reference replay uses the original producer's modular geometry
and full-word profiles. It is **not** the independent checker. Regeneration
requires explicit `nominate.py --write` or `check.py --write-certificate`;
ordinary commands change no committed artifacts. The inherited producer uses
assertions, so its wrapper rejects `-O`; the independent checker works under it.

## Pins, search rule and scope

Exact base: **`8bddbee377e2f3ce1f1247196c4b290d55767d20`**. At this base the
accepted conditional result is PR942/T37, **κ = 0.001661960547713947**, with
unchanged PR589 bit supplier. We checked its source manifest (876 digests),
selected certificate hash and exact T37 arithmetic separately from this
experiment. The source PR952 head is
`11d24706f06e95271804c9438869546724c67aab`; runtime inputs are the immutable
in-tree bytes pinned in [SOURCES.json](SOURCES.json).

[CLAIM.md](CLAIM.md) records seed **10**, three candidates, timing and the
bounded hypothesis. The completed domain is this one fixed word and all its
allowed closed-frame assignments; the stopping rule is exhaustion of every
component. No search restart or further gate-order experiment was performed.
The seed selects the bit track and rotates boundary controls. The changed
input word, not a different random seed, makes this distinct from PR886.
[OVERLAP.json](OVERLAP.json) records the PR review; no sprint coordination
issue was found, so the claim is local.

The fresh owning checker validates all **661** arbitrary-input columns and
original H1-H5 on the unchanged PR952 word. This package does not newly run its
native 5/9/11-stage suite, a complete hosted supplier replay, `make verify`, or
the selected complex cold replay. Their existing source evidence is inherited;
[VALIDATION.json](VALIDATION.json) records exactly what ran here. There is no
new numerical witness that would require adoption into those pipelines.

The uniform comparison holds with the same call multiplier and idle remainder.
It is not a lower bound for altered owner allocations, COPY frames, labels,
scalar programs or arbitrary ambient subspaces. All-size/compiler,
common-label/mutable-source realization, hosting, precision/tape and analytic
assumptions remain. Finite enumeration plus a written proof is not formal
verification of the full multiplication theorem.
