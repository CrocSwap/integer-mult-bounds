# Privacy and provenance

No new personal author name, email, home-directory path or account credential is added by this package. Unpacked files and 1,633 archived text entries were scanned.

Original public contributor attribution is retained. Two historical files in the pinned source archive credit the existing public PR186 contributor handle. Public PR links also disclose their original submitters. This is a source-attributed package, not an anonymous-source archive.

Upstream copyright/license notices are preserved unchanged rather than silently redacted. This does not add a new personal authorship byline to the submission.
