## Result and evidence

The independent local check passes for both actual published words, and for
both words regenerated by the cold recipe. No local defect was found.
It imports only the Python standard library, with no predecessor evaluator,
producer, frame pricer or interval engine.

  preimages. Every unrelated word field is unchanged.

  from `7 -> 8 -> 9` to `7 -> 9`; the other three dimension paths agree.
- Six semantic controls per provider reject wrong aggregation, missing dirty
  restoration, an intervening source observer, an unpaid early restoration,

  applicable, rather than relying only on source-hash rejection.

## Reproduce the local check

From the repository root, Python 3.12+, standard library only:

```sh
python3.12 -B scripts/research_package.py --package research/pr3044-independent-cold-replay
python3.12 -I -O -B research/pr3044-independent-cold-replay/verify.py
```

The registered check is deliberately bounded. It verifies the local algebra and
frame statement, its source pins and the integrity of the saved evidence; it
does **not** run the long cold release or treat saved PASS strings as a fresh
native/outer verification.
`verify.py --emit` regenerates the complete local receipt without writing files.

## Reproduce the cold release

Use an isolated Python 3.12 environment with the exact package versions in
[ENVIRONMENT.json](ENVIRONMENT.json), a C++ compiler, and all nine Git objects
listed in PR3044's `GIT-SOURCES.json`. The tested versions are NumPy 2.4.5,
SciPy 1.16.1, SymPy 1.14.0, mpmath 1.3.0, gmpy2 2.3.2 and psutil 7.2.1.
Fetch the exact objects before starting the network-free computation:

```sh
python3 - <<'PY'
import json, subprocess
p = 'research/rank7-shared-restore-fanin/GIT-SOURCES.json'
heads = [row['head'] for row in json.load(open(p))]
subprocess.run(['git', 'fetch', '--no-tags',
               'https://github.com/CrocSwap/integer-mult-bounds.git', *heads], check=True)
PY
```

Choose a fresh absolute directory outside the checkout as `RUN`, then run the
unchanged published recipe. Its stages run serially. No predecessor is edited.

```sh
PYTHONPYCACHEPREFIX="$RUN-entry-bytecode" python3.12 -B \
  research/rank7-shared-restore-fanin/reproduce.py --repo . --work "$RUN"
python3.12 -I -O -B research/pr3044-independent-cold-replay/verify.py \
  --release-dir "$RUN/run/source-edits/new/borrow/words" \
  --release-pattern 'BORROW-WORD-43{provider}.json.gz'
python3.12 -I -O -B research/pr3044-independent-cold-replay/audit_run.py \
  --repo . --work "$RUN"
```

The actual audit used a fresh `git archive` export of the exact PR3044 source
and parent-word directories; the same pinned bytes are retained on this base.
All replay dependencies were fetched first. The execution sandbox disabled
network access during the computation. There were no failed or skipped stages.
The separate binding audit does not reimplement native semantics, chronological
owner legality, or analytic release inequalities. [ENVIRONMENT.json](ENVIRONMENT.json)
records the exact executed command and environment.
