# Uniform exceptional-record repair across complex recursion

**Conditional cost-composition audit; no new kappa.** The explicit PR2250
repair tariff, applied to the PR2287 selected recursion, sums to at most

    (1000000000/5333) J V d^(99733167/100000000)

when every descendant retains its complete long coefficient records and
compact guard ranges and satisfies the quantitative admission inequalities
in [PROOF.md](PROOF.md). J bounds the number of repair calls per node.
The constant is independent of depth and root size. It includes the source
guard evaluation, inverse-key preparation, radix traffic and cleanup tariff;
it is not an invoice for the whole supplier.

The result turns the source's per-call absorption statement into one
quantified subtree bound using the actual eight-rank selected histogram.
Two executable countermodels show why total volume and endpoint equality
alone do not justify it: promoting the coefficient suffix to outer rows
loses cubic preparation amortization, while restricting to a bad-only
compact fibre invalidates the global bad-density bound. The original
source packet rules preserve both conditions; no source bug is alleged.

PR2250 and PR2287, by Jose Manuel (`jmbarrancoml`), provide the repair
construction and proposed layer. PR2365, by Jerry Lin (`jerrylin-23`),
proves a scalar outer parameter envelope and explicitly leaves full callee
applicability open. This package addresses only the recursive repair cost
implication. It does not repeat that envelope, PR2413's outer format/error
audit, the original100 batch's P104 work, or the companion gather/scatter
contribution. Source snapshots are unmodified; exact heads, blobs and SHA-256
pins are in [SOURCES.json](SOURCES.json).

The primary checker uses rational atanh/exponential intervals for the
strict moment, exact weighted recurrences, 288 admitted tariff fixtures,
and 10,880 symbolic descendant row edges. It executes cubic per-record
preparation and complete-record radix transfers on correlated payloads.
The independent checker imports no primary or predecessor code and uses
outward-rounded integer intervals, integer tariff inequalities, a separate
radix implementation and four rejection controls. Assertions are not used.
The registered hook regenerates and compares [RESULT.json](RESULT.json).

These checks support the written theorem. They do not run the full source
supplier or supply a numerical J for its complete instruction catalogue.

analytic obligations remain separate. No selected files or frontier change.
