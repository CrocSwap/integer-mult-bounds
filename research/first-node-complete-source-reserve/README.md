# Complete first-node source reserve

The PR2825/2845 handoff asked for a total first-range caller ledger rather than
another numerical or action-local component. This package supplies an explicit
conditional `K0 + G + T + max(six phases)` source-array bound for the unchanged
PR2697 `Consumer.apply`: directory production, frame validation, all packet
actions, generator suspension, output copying and normal cleanup.

The new join retains warm numerical high water, every serialized/count/payload
category, and three easy-to-miss source lifetimes: a previous cleared directory
prefix during replacement, four empty validation callback stacks throughout
the packet loop, and closed count tapes until their final reference. Non-ADD
digit passes charge all `q²` bucket markers and intermediate payloads. R9's
complete ADD proof is reused with attribution, not relabelled a new result.

[PROOF.md](PROOF.md) states every parameter, six chronological cuts and ownership
premise. [ledger.py](ledger.py) evaluates the conservative expression; no sharp
maximum or physical tape capacity is claimed. Entry K0 includes arbitrary
borrowed blank tails and all allocated numerical slots/templates by identity.

The exact width64/rank1/depth2/modulus3 gate runs the original directory and
frame validation with two old prefixes, including a warm4500/80 arena case.
It intercepts packet entry before payload traversal. Separate complete small
packets execute ADD, swap and sign, both alone and in a four-pass sequence,
over moduli3 and9 with two prefixes. Their endpoints are checked by an integer
permutation oracle, all borrowed bytes/heads and live numerical ownership are
restored, and only the owned output remains. These are different calibrations:
no full64-dimensional payload is materialized or represented by a tiny fixture.
The exact fixture metadata is not selected-catalogue admission.

The entire 19-file caller cohort matches the credited PR2749 source snapshot.
Its lazy `children` dependency is additionally retained from PR2835; that path
is not silently omitted just because finite packet checks use a unit callback.
The child source and universal lifetime premises are inspected, while R9's real
callback finite calibration is reused rather than repeated. A weak observer
counts source arrays without retaining their frames or extending lifetimes.

A three-cell validation-stack budget rejects the actual four-cell cut. Closed
counter evidence separates blank contents from backing. Exact typed receipt,
source-hash and source-cohort checks are active under optimized Python.

Reproduce with Python3.12 standard library:

```sh
python3.12 -Werror -B scripts/research_package.py --package research/first-node-complete-source-reserve
```

This is a written conditional source-array theorem and finite corroboration,
not Python heap accounting, physical bank admission, a complete SelectedNode,
recursive or outer grant, H2/P3 tariff, full selected replay or new kappa.
Successful canonical semantics remain premises. Exceptional rollback is not
proved: several setup checks precede the source's try/finally boundary.
