# Prose statements refuted, corrected or withdrawn (combined package)

Each item is a Lean theorem or a documented correction in `lean/Nov15/`. None of the source notes was published. Nothing here is a κ claim.

1. **CallerCost: "invoice D0 ≥ caller floor + calls · (helper D0 floor)".** FALSE. With the numbers of the caller-floor note (helper floor 9,928.76 per call on #7630, caller D0 270,813 = 666,499 − 395,686, 17 calls, invoice D0 391,295.63),
   270,813 + 17 · 9,928.76 = 439,602 > 391,296: `CallerCost.naive_composition_false`. Reason: the native's main and owned MOVEs are credits (negative D0, `rest_negative`, about −2,842 per call), and the floor is on the helper D0 only.
   Corrected: `composition` (floor on TOTAL native D0 per call) or `composition_helper` (explicit credit cap R on the rest).
2. **Caller-ceiling note, section 3: sign of the stationarity slope.** The derivative in the native cost d of the numerator S'D − SD' is +(kS' − S) = +ρ (`CallerCost.stationarity_slope`), not −ρ. The conclusion (a cheaper native lowers the optimal k) is unchanged (`cheaper_native_lowers_k`). The statement is about the proxy S/D0, not the exact root κ.
3. **ClearCert: "COPY into a zero owned row keeps the rank, so every event except CLEAR keeps the rank".** Right only for a ZERO target: `ClearCert.copy_nonzero_loses_rank` (over ℚ, two public registers: COPY 0 ← 1 drops e₀ from the span). The checker enforces the zero-target condition, so the words are fine; the headline lemma survives (`span_step_le` needs only non-birth).
   Also: "lossless is implied by correctness" needs endpoint exactness at the span level over the input space U, not over all registers.
4. **CensusComplete: "every MOVE pair used by #7630 lies in the 981-pair census".** FALSE (`CensusComplete.used_not_subset_census`; witness (0,249); 2,143 of 3,024 used pairs are outside the census). Correct reading: the census covers every pair that differs from #7623's used set (`used_subset_base_or_census`); the rest is inherited from #7623.
5. **JointCeiling: "κ ≤ .0336321541 (thin 4) / .0400007313 (thin 3), argmax 2|2" is WITHDRAWN.** The generating script overcharged every arm of length 1 by 208 one-stage lines (P[8]; two lines per port, 104 ports), which breaks the ledger S = 3408(a+b) − 208. The true argmax is 1|1 (k = 2), not 2|2, and the numeric certificate list built from that script is invalid for arms of 1.
   Corrected: `callerG` (ledger-correct histogram) with `callerG_S : S = 3408(a+b) − 208` for all a,b ≥ 1, `FBc`; the ceiling becomes .0419448764 (thin 4); thin 3 becomes .0681203280 (B-form class only). For a,b ≥ 2 nothing changes (`FBc_two`, `callerG_eq_caller_F`).
6. **JointCeiling, hypothesis hB (B-form per-split optimality).** Holds on B ports; FAILS on A ports for the true sign-floor masks (centre-drop case: 6,009 and 5,879 failing layouts). So the ceiling is stated for the built-type class (A ports = 4 QUERY units, B-form masks), not for every caller.
7. **OwnedSkeleton: "the 180 lifetimes fit the allocation" / "one bank per label".** True only with reuse: 180 lifetimes per call on 68 labels (peak 50). The correct reading rests on E1 disjointness plus peak ≤ 68 (`lifetimes_exceed_labels`).
8. **OwnedSkeleton / OwnedTree, E3 read off the flat word.** Not possible: the flat word's lifetimes interleave (2,165 crossing interval pairs; 251 CLEARs while a field on a strictly smaller chart is live). E3's ancestor/descendant clause needs the unit tree, and under atomic calls it is implied by E1 (`execU_id`).
9. **OwnedAscent: floors that "owned registers only descend" rest on** (owned-paid-56, eight-unit relay, reader-497, surplus, H6 notes) do not transfer to the relaxed class (`W1_not_strict`, `W1_relaxed`, `W1_charge`). Not a false statement; the scope those notes already declared, now with a Lean witness.

10. **JunkLB2, the "public arrivals only" form of T4.** FALSE as written (`JunkLB2.T4_public_only_false`): a public helper h arrives with e_h + e_x and an owned register o arrives with −e_x; then h += o makes h its own token while the public span has dimension 1 > 0. The gap is the first step of the prose proof. Corrected: T4 with owned arrivals counted (`T4_departer` when there are none).
11. **Whole-word floor, "forced stops ≥ 88 at m = 16, argmin m = 16 (monotone)".** FALSE as written: the pricing only allowed owned MOVEs of rank 1..9, but Theorem Y counts all owned MOVEs, and a lateral owned MOVE (distinct charts, equal dimension, rank 0) enters σ_C for free. Counterexample `WholeFloorPrice.cex`, `cex_priced`, `r3_stops_not_forced` (12 rank-9 and 4 rank-1 paid owned MOVEs plus 88 lateral ones, no stops: D0 = −400 f 8 − 12 f 9, below the claimed floor by 88 · 2 ln 2). Corrected: `d0_floor` carries max 0 (88 − lat); the claimed floor (155,730.99; κ ≤ .0204110964) holds for words with no lateral owned MOVE. The verifier's nesting rule makes lateral MOVEs illegal (`WholeFloorNest.nest_rank_pos`, `nest_lat_zero`), which restores the floor for every legal word (`d0_whole_floor_nested`, `kappa_whole_floor_nested`). The cheaper all-words figure without nesting is 153,657.09 / κ ≤ .0207160184. Also a digit note: the root is .02041109645, so .0204110964 is rounded down and the kernel statement uses .0204110965.
12. **Delivery, TWO-STOP: "K-cost ≥ f(d) − max over three-way splits of Σ f, which is ≥ f(3) = 3.30".** FALSE as written. The "max over splits" is f(d) itself (split (d,0,0)), cost 0. Counterexample `Delivery.zero_gap_counterexample`: courier 0 → 8 → 9 → 9, D0 = f(9) − f(8) = 3.139 < f(3) = 3.296 (5 ln 3 < 8 ln 2). Corrected: with three genuine hops (all gaps ≥ 1) D0 ≥ f(d) − f(d−2) ≥ f(3) (`three_hop_cost`, `fL_three_gt`). The value 3.30 is numeric; Lean proves > 3.
13. **DesignLaws, ONE-READ: "a register reads at most one chart per owned lineage".** FALSE with owned ascent allowed (`DesignLaws.one_read_needs_descent`: a legal run in which owned register and reader both go 0 → 1 and read at charts 0 and 1). True with the DESCENT hypothesis on the owned lineage (`one_read`). Corrected: at most one chart per DESCENDING owned lineage.
14. **PsiLaw, the two span/obstruction statements.** (a) "A repair exists iff w lies in the row span" is only necessary: `span_law_not_sufficient` (one end row (1), w = (1): w in the span, stripped row 0, no V settle). Corrected: iff w is in the old span and in the stripped span (`span_strip_iff`). (b) "A relocated op is a pure G0-column operation only if neither register is read in between": reads of the source register are harmless (`add_swap` allows them); the obstruction is reads of the target and writes to the source (`exposed_read_no_prefix`, `move_early`).
15. **Shadow: "the twin has the same invoice T, P".** FALSE literally: the raw T and P histograms each gain the common summand `mains.flatMap (tT (e−b))` (`shadow_T_raw`). What is equal is the net T − P at every rank (`shadow_net`), hence S, F(t), D0 and κ. So the consequence holds for laws that factor through the net invoice, not for laws that read raw T or P counts; the cancellation needs the symmetry hypothesis `Sym`.
16. **FloorK22, the displayed recipe "270,812.82 − 46,300.0 − 2,006.0 + 17 × 1,036.95 = 240,134.84".** The arithmetic of the displayed recipe is 240,134.97 (`FloorK22.recipe_as_written`). Exact: mains −46,300.09, caller 270,812.8175, kept credits −48,306.0933 (17 × 2841.5349), stops +17,628.1191 (17 × 748 × 2 ln 2, not 17 × 1,036.95): total 240,134.843. The floor 240,134.84 is right; only the rounded recipe is off by 0.13.
17. **RankLaw: "every op except CLEAR is invertible" and "(ii) zero W0 part".** The first is false with COPY (`RankLaw.copy_lossy_example`; also SCALE by 0 is a CLEAR); minimal fix: except CLEAR, COPY over a live row and SCALE 0. The second is the right criterion only relative to a U meeting the span of the non-V targets trivially (`hUN`); in general the criterion is the (U ⊓ N)-component (`RankLawC.rank_law_proj`). "The V mix is unique" needs independent end rows.
18. **HubSettle: "M ∈ GL(A) iff the determinants are units of A".** The "if" holds (`solve_inGL`); the "only if" is false (`HubSettle.iff_false_example`: over ℤ ⊂ ℚ, A1 = B = (2) gives M = 1 ∈ GL(ℤ) with det A1 = 2 a non-unit).
19. **FrameSep: "any public that ever reads X_a can never meet Y_a".** True only AFTER the read (`reader_never_meets_Y_after`); the unqualified reading is false (`meet_before_read_possible`).
20. **DescentPrice / FloorD0, signed gaps (scope only).** The identity D0(r) = f(e − d0) − Σ f(gaps) uses signed gaps and equals the priced charge only on ascending registers (all public registers); it would fail for owned descents. Not false at its stated scope (see `FloorD0.md`).
21. **PadLift: "the lifted rank bound holds in every characteristic".** Needs characteristic ≠ 2 (counterexample `pad_rank_char2_fails` over ZMod 2); `pad_sq` and the block form need no assumption.
22. **WordDuality: "COPY becomes ADD under the duality".** FALSE as matrices (`WordDuality.copy_not_add`: COPY 0←1 has matrix [[0,1],[0,1]], whose transpose [[0,0],[1,1]] is not 1 + q·e_ab for any a ≠ b; ADD matrices have diagonal 1). The dual of a COPY is an ADD only on a clean target (INIT then COPY) and must carry the dual of the target's INIT (a CLEAR); `dualEv` maps COPY to ADD for legality only.
