# DesignLaws : DS1's structural laws for the X->Y layer in Lean

`Nov15/DesignLaws.lean`, Lean 4.33.0-rc1 + Mathlib, kernel only: no `sorry`, no `native_decide`; axioms `[propext, Classical.choice, Quot.sound]` (`one_read`: `[propext, Quot.sound]`). 8 s / 2.0 GB. Reuses TokenCancel (`St/Ev/step/run/LegalEv`, charts := `Submodule K E`), Annihilator (nesting = `Lineage.Legal`, cited; its descending-rank bound is a different count from s below), Delivery (TWO-STOP/TIME-ORDER style: co-presence + ascending charts). Source: internal notes (line numbers = the file's lines), RC5 gate 1: internal notes
Model: ports t have functionals phi t (Phi_t = ker phi t, DS1:7), tokens b have anchors u b; public x_b is born at a chart containing u b; orth(t,b) := phi t (u b) = 0; "non-isotropic" = phi t (u t) != 0.

1. **PCL** (DS1:8) `pcl`, `pcl_orth`, `supp_run`, `line_le_ker_iff`. TRUE as written (support half). If a register ends at a chart inside Phi_t with a nonzero coefficient of a token b with phi t (u b) != 0 (b = t included), then some OWNED move is non-ascending (`Desc`); equivalently without owned descent every token in such a register is orthogonal to t. Hypotheses: publics born at charts containing their anchor and public MOVEs ascend (`Disc`), owned INIT row 0. Proof: invariant "token b appears in a row only at a chart containing u b" preserved by every event (ADD/COPY need co-presence). `line_le_ker_iff`: <u_b> <= Phi_t iff orth, so an orthogonal X can sit at the dim-8 stop and a non-orthogonal one cannot. NOT formalised: the second sentence of DS1:8 ("owned-routed content O_t must equal e_t on N_t") is the DEFINITION of O (total content minus orthogonal public feeds); it is an input to RANK-FEED, not proved from the event model. "Descent" here = non-ascending (lateral owned moves count; nested-ness is Annihilator's separate rule).
2. **ONE-READ** (DS1:9) `one_read`. TRUE only with the DESCENT hypothesis on the owned lineage: public reader ascends (`MoveRel (<=)`), owned register descends (`MoveRel (>=)`), co-present at two read times => same chart. **SCOPE FIX:** Annihilator's lineages are nested in EITHER direction; with an owned ascent allowed the claim is false: `one_read_needs_descent` (legal ℚ-run over ℕ-charts: owned and reader both go 0 -> 1, reads at charts 0 and 1). Corrected: "at most one chart per DESCENDING owned lineage (ascending owned moves can be re-read)".
3. **HYPERPLANE** (DS1:9) `one_stop_per_dim`, `hyperplane_dedicated`, `finrank_ker_add_one`. TRUE for registers whose MOVEs ascend (publics): any two charts it occupies of equal dimension coincide (comparable + equal finrank). A nonzero functional has a kernel of dim = dim E - 1 (`finrank_ker_add_one`: 8 when dim E = 9). So a public register cannot stop at two different hyperplanes Phi_t != Phi_t' (either order, by symmetry) = "dedicated to t". Scope: PUBLIC registers (owned ones move non-monotonically and are not covered); "stop" = any chart occupied after a prefix of the run (stronger than "dim-8 op stop").
4. **RANK-FEED** (DS1:10-12) `rank_feed`, `rank_feed'`, `matrix_rank_le`, `rank_feed_st1`. TRUE, general: O_t : P -> K owned-routed content of port t, all in the span W of read owned states (s = finrank W), exact on N_t (O t b = delta there). Then N <= s + #{t : exists b != t, orth(t,b), O t b != 0}: at most s ports have residue-free owned content; >= N - s ports carry an orthogonal residue to feed/cancel. `matrix_rank_le`: rank(I+J) <= s. Instance `rank_feed_st1`: N = 104, s = 96 => >= 8 (RC5 gate 1: the 8 X-direct ports). Reading note: DS1's proof sketch counts ROWS t outside the spanning columns; the Lean proof counts COLUMNS (ports) with unit content (independent vectors in W). Both counts are valid (transpose); only the column form is formalised and is the one that matches "ports needing feeds".
5. **XCLOSE** (DS1:24) `xclose_add`, `xclose_exact`. TRUE. Closer X_sigma holds row lam e_sigma + g (lam != 0, g sigma-free) at Phi_t beside Y_t. One ADD y += a x: sigma-coordinate becomes y_sigma + a lam (own token cancelled), every other coordinate gets exactly a g (the correction), all other rows and locs unchanged. If Y's pre-close row is tau + k (X's row) with tau sigma-free, the ADD with a = -k is legal and yields exactly tau, and a = -k is the only coefficient that does. (X's clean-up at V = TokenCancel hub blindness.) Does NOT show the content exists: RC5 gate 3 is exactly that pre-close row is not of this form on st1.

Not covered: MULTIPLICITY, the FLOOR/cost numbers (DS1:14-17), the census counts.
