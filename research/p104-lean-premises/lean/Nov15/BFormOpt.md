# BFormOpt.lean: B-form per-split optimality on B ports, pointwise in F(t), for ALL arm lengths
Nov 17. Imports Nov15.JointCeiling (olean built into .lake/build/lib/lean/Nov15) + Mathlib concavity/rpow lemmas. Build: runlean.sh Nov15/BFormOpt.lean, 19 s, 2.9 GB. 20 `#print axioms` within [propext, Classical.choice, Quot.sound]; no sorry, no native_decide (`decide +kernel` = kernel evaluation only).
Source: (internal notes) sec 1 (L1-L4), AUDIT2.md item 3. Sign convention: F = sum (T-P) r^s, s = 1-t in [0,1]; "optimal" = F maximal (cheapest invoice), the hB direction `F <= FBc`. (The task text says "minimises F"; R2/hB mean the B form has the LARGEST F, i.e. minimal cost.)

## Model (BPort) = r2.py `port` for a B port (m = 2 mains), no a,b <= 4 / h <= 5 / e <= 4 cap
Per arm of length x: hubs h >= 2, own roles e_c entering at stage c (rank 8(x-c)+1), occupancy n_c = h+E_c-2, boundary cap_c = h+E_c-4, Floor E_j >= 2(j+1) (j <= x-2). A schedule is ANY list of lines (start, len), valid, with exact occupancy n_c and crossing <= cap_c (not only the canonical one). u = n+2-2k sign units each priced >= psi(1) ([H-odd]). F = h tau(k) + sum e tau - bill - unit cost.

## Proved (all s in [0,1], all a,b >= 1, all h, e)
- `spread`: two-point Karamata for x^s (from Mathlib `Real.concaveOn_rpow`); `dl_nonneg`, `dl_anti` (phi' increments nonincreasing, phi'(0)=0 so s=0 counts lines), `ps_anti` (psi nonincreasing).
- `abel_aux/abel_nonneg`: the Abel/Karamata engine (a antitone, partial sums of D >= 0 => sum a D >= 0).
- **L1 schedule lemma, `bill_lb`**: every feasible schedule has bill >= CB(n,cap). Proof: layer cake bill = sum_j dl_j N_j, N_j = #lines of length > j; partial sums sum_{j<J} N_j = sum min(len,J) >= sum n - sum_{k<x-J} cap_k (a line alive at c-J and c crosses boundary c-J; double counting `sum_len_eq`, `excess_le`, `partial_dom`); then Abel. This REPLACES the exchange argument (tail-swap/join) and the 58,873-schedule check by a proof for every length; no canonical schedule needed for the bound.
- **L2 closed form, `CB_closed`**: CB = (h-4) phi(x) + 2x phi(1) + sum_c e_c phi(x-c), for every x >= 1 (arm of 1 included: = n_0 phi(1)). Hence `F_le_G4`: F <= h Hc + Kc + Own_L + Own_R (R2 L4 form).
- **Own-role Abel step, `own_abel`** (R2 "sketch + finite check a,b <= 4"): sum_c (e_c-2)(psi(1)-psi(x-c)) >= 0 from the Floor E_j >= 2(j+1), g(x-1) = 0, g antitone. All x. `centre_role_neutral`: the last-stage (d=1) role contributes exactly 0 (B ports).
- **Hub step, `hub_nonpos`**: tau(k)-phi(a)-phi(b)-psi(1) <= 0 (subadditivity of x^s + one `spread`).
- **`bform_optimal`**: F(any B port layout) <= Gstar = F(B form h=2,e=2), pointwise on [0,1]. **`port_total`**: 96 FAport + 8 Gstar = JointCeiling.FBc a b th, for all arms >= 1, so Gstar is exactly the B-port share of FBc (arm-of-1 correction included).
- **hB discharged for B ports**: `hB_discharge` (caller = 96 built-type A ports + 8 ARBITRARY B-port layouts => `Finv <= FBc`), `inClassOfPorts` (InClass with hB proved), `ceiling_of_ports` (ceiling at tbar4; remaining hypotheses: native floor hN, NumCert 4 tbar4, [H-odd] in BPort, A ports in the built type, h hubs have no centre lines [H-centre]).
- Attainment: `sigB_feasible_small` (kernel eval, x = 1..8: the canonical B-form schedule has exact occupancy 2c+2, crossing <= 2c) and `sigB_bill_small` (x = 1..6: its bill is CB). General x attainment is r2.py `lines()`, not formalised.

## A ports: B form is NOT optimal (remark + witness)
`TA/PA` = r2.py A port 2|2 B-form ranks (`FrA_eq`: = FAport s 2 2 4); `TA'/PA'` = the layout with one last-stage own role dropped (its line and one QUERY go too). `A_drop_gain`: gain = 1 - psi(1); `A_drop_nonneg` (>= 0 for all s in [0,1]), `A_drop_strict_zero` (= 1 at s=0), `A_drop_strict_half` (> 0 at s=1/2). A QUERY costs 1 > psi(1): centre/own roles are a net loss on A ports. So hB is NOT provable for A ports; it holds for the built type (A masks fixed = B form), which is what `hB_discharge` assumes (`hci`).

## Corrections to R2 as written
1. **L2 closed form constant is wrong**: "-2(k-2) phi(1)" should be **-2k phi(1)** (R2 is +4 phi(1) too high). Checked numerically (r2.py port at 3|3, 2|5, 4|4, s=.5: port F = .5513 / -2.8222 / -5.2556 matches -2k, R2's formula gives 11.87 / 8.49 / 6.06) and by `port_total` (-2k reproduces FBc exactly). The L4 form (hub term, own term, [psi(d)-psi(1)]) and the conclusion are unaffected.
2. **L4 prices the u sign units at psi(1) each (= [H-odd])**; r2.py's rule (absorb into the SHORTEST 8-multiple lines) charges psi(l) < psi(1) once u exceeds the number of 1-lines (large e at stages <= x-2). There [H-odd] is violated literally, so this formalisation does not cover r2.py's spilled layouts. Numerics: 280,000 random layouts (a,b <= 4, h <= 8, e_c up to 20, s in {0,.05,.3,.7,1}), spill included, 0 violations of F <= F_B (own script). So the claim is plausible there, but the PROOF covers [H-odd] only. Open: spill regime. A proof route is a removal-monotonicity argument ("F_true = min over u-subsets U of the model cost, so removing a role/hub never lowers F"), not done here.
3. Not claimed: L5 A-port counts (6,009/5,879 failing layouts) are r2.py facts; only the minimal witness above is in Lean. Hubs h >= 5 with centre merging, trees, multi-centre remain outside (as in R2 sec 3).
