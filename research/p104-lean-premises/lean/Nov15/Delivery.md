## 1. TWO-STOP (D1 sec. 2)
Algebra (`single_contact_null`, `two_contacts_needed`, `const_rows_null`, `two_contacts_suffice`): in T2's setting (t = y starts with e_k-coefficient 0 and ends with 0), a courier with token k delivers net 0 through a single contact, and through any number of contacts whose rows are all equal; delivery of a nonzero net needs >= 2 contacts with DIFFERENT courier rows (so a pickup/shed ADD happens between two meetings with t). Tight: contacts (1, r1), (-1, r2) with r1 = (1,0), r2 = (1,1) deliver (0,-1) (non-vacuity over Q). This is D1's (a)-(d) minus the scale caveat: with SCALEs of t the raw "sum of a = 0" is false (`TokenCancel.T2_literal_false`); the lemmas use effective coefficients.
Price (`three_hop_cost`, `ctype_cost`, `unit_hops_cost`, `fL_three_gt`): >= 2 stops means birth -> s1 -> s2 -> end, three hops. If each hop is genuine (gap >= 1) and the route climbs by the gap total d = e - b, then D0 = f(d) - sum f(g_i) >= f(d) - f(d-2) >= f(3) (proof: convexity of x ln x, `inc`; f(1) = 0; `two_gaps`, `three_gaps`). The C-type (1, 7, 1) route pays EXACTLY f(9) - f(7) (`ctype_cost` with n = 6; 6.154 numeric [C]); (1,1,1) pays f(3) = 3 ln 3 > 3 (3.2958 numeric [C]; Lean proves only > 3).
**WORDING FIX (paper false as written).** D1: "K-cost >= f(d) - max over three-way splits of sum f, which is >= f(3) = 3.30". The first inequality is fine, but the "max over three-way splits" is f(d) (split (d,0,0)) = 0 cost, so "which is >= f(3)" does not follow; it needs three GENUINE hops (all gaps >= 1; birth and end not at a stop chart). Lean counterexample `zero_gap_counterexample`: courier 0 -> 8 -> 9 -> 9 (gaps 8, 1, 0, d = 9), D0 = f(9) - f(8) = 3.139 < f(3) = 3.296 (5 ln 3 < 8 ln 2, i.e. 243 < 256). Corrected: "with three genuine hops D0 >= f(d) - f(d-2) >= f(3); with birth or end on a stop only f(d) - f(d-1) (one genuine hop: 0)". The 3.3 D0 floor per delivery therefore holds for {0}-born V-enders-type couriers, not for any courier whose birth/end chart is a stop. Not formalised: that the courier cannot be born/ended on the pickup/delivery chart in the real word (a verifier fact, not algebra).

## 2. ENTRY RANK and DIRECT-READ CAPACITY (D1 sec. 2, D3 sec. 1)
* `direct_read_capacity`: single owned MOVE A -> L (L <= A); ports a with u_b in A (direct X reads), phi_a vanishing on L, identity Gram block (orthonormal group) => |G| <= dim A - dim L. TRUE as written (this is D1's "|G| <= dim A - dim L"); via Annihilator with the one-hop lineage `oneHop`.
* `entry_rank_multihop` (= `Annihilator.sparse_serves_le`): any number of hops, |G| <= descending owned rank. D3's correction of D1 ("multi-hop for the 48" mis-scoped) is confirmed.
* `dense_needed`: if sparse groups' ranks total <= R, served ports <= R, so N - R ports (>= 48 for N = 104, R = 56 [R = 56 is Theorem K + C d3p, not proved here]) need dense entries.
* NOT formalised: D1's separate counting statement ENTRY RANK "only 20 owned MOVEs enter any Y world, so <= 20 ports junk-free" (a [C] count 2-6 per port given OWN-Y); the capacity lemma above is the proved content and is stronger in kind (rank, not MOVE count).

## 3. TIME-ORDER (D1 sec. 2)
`never_meet_after_read`, `direct_after_read_impossible`, `carrier_before_read`. Charts of public registers ascend (`Monotone`); Y_a's worlds are killed by phi = (. u_a) with phi u_a != 0 (orthonormal: 1). If X_b sits at a chart containing u_a at time r (the owned read), then X_b is never at Y_a's chart at any t >= r. A carrier that picks x_b up from X_b at time p and meets Y_a at j >= p has u_a not in X_b's chart at p, hence p < r strictly: it picked up BEFORE the read. D1 TRUE as written; the proof also shows the same for any carrier (not only X_b itself), because carriers ascend too. Hypotheses made explicit: monotone charts of X_b and the carrier; chart equality = co-presence.
