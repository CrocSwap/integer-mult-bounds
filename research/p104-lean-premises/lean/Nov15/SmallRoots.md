## What `IsRoot` states (one field per rc.py `req`, rc.py = small-caller/rc.py; AUDIT1 (1)-(2) checked rc.py against root_check_h.py)
shape (N = n+2 rows of length n); isotropy y_k.x_k = 0; nonzero; product T_{N-1}..T_0 = -I (T = I - 2 x y^T, applied by `applyUnit`, rc.py "W = [[W[i][j] - 2*X[k][i]*d[j]"); stage units consecutive pairs, ordered and disjoint; units inside their coordinate mask; mask commutes with the prefix product before (pre[u0]) and after (pre[u0+2]); symbolic endpoint M(D) = -diag(prod D_i^[r in mask_i]); stage pair (alpha,beta) = (y_p.x_q, y_q.x_p) equals the declared pair; rank G = n, rank X = n, rank Y = n (certified by an n x n minor with exact inverse, `rankCert`); Gram digraph strongly connected (rc.py enforces it; AUDIT1 notes it is the MRCHECK author's line, not SPEC; included because rc.py has it).

## Scope and honest gaps
- ALGEBRAIC CORE ONLY (AUDIT1 (3)): abstract masks, n = 2k + 2, not an emitted caller (no frame lowering, no events, no 96 A + 8 B port assembly, no header/address bindings, no verifier run). "Realisable" holds at root level only.
- Entries are rational, NOT dyadic (dyadic is a verifier line, not SPEC; #6931/#6932 precedent); hosted t is not in {0,-1} by design (A: t = 0 pair (0,0); B: (-1, 1/2) i.e. t = -1/2); no 18-stage condition (k = 2, 4 stages here).
- B thin units are QUERY-type isotropic transvections; the model prices B sign units as IDLE_ODD, so the 1|1 B price stays unestablished (AUDIT1 (5)). Not addressed here.
- `symbolic` is checked at the 2^L corners D in {0,1}^L (L = 2 for 1|1, 4 for 2|2), not as a polynomial identity. Equivalence with rc.py's symbolic check uses that M(D) is affine in each D_i (D_i scales the mask rows once, after stage i), so a function affine in each variable is determined by its corner values; that affinity lemma is NOT formalised. Corners are a necessary condition and, by the affinity remark, equivalent.
- `rank G = n` is the lower bound (an n x n minor is invertible); the upper bound is automatic since G = Y X^T factors through n dimensions (not formalised). Same for rank X, rank Y (sizes N x n).
- Also not proved (AUDIT1 last line): L0/L1/L2 reduction lemmas of R1 (only the explicit roots are checked, which is all that is needed).
- Negative controls run: pref at 7 units != -I, mismatched stage/mask data and a wrong prefix index make the corresponding `decide +kernel` fail.
