# FloorCert: the class-K LP certificate (780 stops) checked in Lean. No sorry, kernel `decide` only
Files: FloorCertDefs.lean (core only), FloorCertData.lean (generated), FloorCertCheck.lean (kernel checks), FloorCert.lean (bridge + floor). Exporter: floorcert/export_cert.py (py312np); row/column names in floorcert/floorcert_index.txt.
Axioms: the four checks in FloorCertCheck use **no axioms at all**; every theorem in FloorCert uses [propext, Classical.choice, Quot.sound]. No `native_decide`, so no `Lean.ofReduceBool`.

## Size
- rslp.py's full LP: 5,074 rows × 32,584 columns, 303,183 nonzeros. The exporter re-checks the full certificate exactly in Fractions (y ≥ 0, yᵀA ≤ c, bᵀy = 780) before exporting.
- Exported: the **support sub-LP**, i.e. the rows with positive dual. That is 892 rows (284 commodity u, 512 λ, 51 β, 45 α; every γ dual is 0) × 18,868 columns (the columns meeting a kept row), 31,249 nonzeros.
- Integer data: y = Y/8 with Y ∈ ℤ, kept in a Braun tree for log-depth kernel lookup.
- This is sound as a relaxation. Dropping rows weakens what the native must satisfy. Dropped columns meet no kept row and have cost ≥ 0, so the objective over the kept columns is ≤ the full objective.
- No α/β row is used with an empty sum (exporter flag list empty).
- Cost: Data 90 s / 2.1 GB; Check 20 s / 2.4 GB; FloorCert 8 s / 2.3 GB. A negative control (bᵀy = 781) is rejected by the kernel.

## Theorems
- FloorCertCheck: `len_ok`, `Y_nonneg_ok`, `bDot_ok` (Σ Y_i b_i = 780·8), `cols_ok` (every column: row indices < 892 and Σ Y_i A_ij ≤ 8 c_j). All by `decide +kernel`.
- FloorCert, over any ordered field 𝕜:
  - definitions A, b, c, y;
  - `y_nonneg`, `yA_le`, `yb_eq` (bᵀy = 780), via the generic `sum_sparse` / `bDot_eq` bridges;
  - `lp_floor`: Floor.weak_duality gives 780 ≤ cᵀx;
  - `stops_ge_780`: 780 ≤ #stays when cᵀx ≤ #stays;
  - `cost_ge_780`: FloorGlue.global_floor_of_certificate gives cost ≥ 780κ;
  - `cost_ge_real`: κ = 2 ln 2, i.e. ≈ 1,081.3096 D0/call.

## Native feasibility in Lean (NOTE: the NativeFeas files are NOT part of this package; this section is kept for context only)
Files: NativeFeasData.lean (generated by floorcert/export_native.py), NativeFeasCheck.lean (kernel checks, core only), NativeFeas.lean (bridge).
- The native #7623's point x, by rsnative.py's map: y_c = hd(c) on Nat; each native first hop s -> c (helper move whose rho-row has psi != 0
  for a certified commodity of source s) sets z_{s,c} = 1, and a_{s,c} = 1 when it serves a commodity that is type A at c; a hop into a
  non-Nat chart c sets the fresh minimal head s + v, with v the least vector of span c \ span s. That head covers every commodity (t, s)
  with c <= t, so one head per (s, c) suffices, and distinct heads are counted once.
- export_native.py checks the FULL LP exactly first (4,915 rslp rows; the 159 alpha/beta rows that export_cert also lists with an empty sum
  read y_c >= -slr_c / y_c >= needR_c and hold since hd >= L): 0 violated. Full objective **1,999** = 1,840 (hd on Nat) + 159 distinct fresh
  heads. RANKSTEINER's 2,037 counted fresh heads per (s, c) hop (197); both are <= 3,432 paid stops. On the 18,868 support columns x has
  724 nonzeros and cᵀx = **1,964**.

  `rows_ok` (every b_i <= (A·x)_i; A·x accumulated column by column into a Braun tree, `ITree.upd`). The first two use no axioms; the

  `floor_le_native`: 780 <= cᵀxN <= 3,432, i.e. lp_floor applied to the native's own point. 15 s, 2.3 GB. Axioms [propext, Classical.choice, Quot.sound].

  diffs); R0(b) holds mod q at all 600 targets; all 2,850 psi witnesses re-verified exactly on the independent replay; all 284 exported
