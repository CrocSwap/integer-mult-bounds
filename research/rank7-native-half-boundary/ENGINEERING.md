# Implementation and verification boundaries

The exit predicate is an exact source-bound local native-format theorem with
attaining grid/width failures and an actual aligned half-ADD check. It does not
require or imply a new supplier. Build the lever shaped the rerunnable sparse
operator and prefix check. Prove it works required fresh provider reconstruction,
every-column integer/Fraction comparisons, literal Boolean execution and semantic
failure controls. Power of Ten shaped the bounded inputs and explicit contracts.

All new code is nonrecursive. Native streams are bounded by 30,000 events,
prefix rows by 4,096 atoms and free words by 256 symbols. There are 632 ordinary
prefix registers. Native local circuits have at most 20 gates, fields have
512 complex coordinates, Gaussian rows have at most 16 complex terms, and
real rows have at most 32 terms. The largest final rows have 20 terms. Input
precision is bounded to 3..128. Maximum published precision is 64; tests also
check 128. Explicit exceptions remain active under optimization. New functions
fit within 60 physical lines. No dynamic source evaluation is introduced.

Rule 3 deviation: Python integers, Fractions, lists and dictionaries allocate
during replay. Replacing exact arithmetic with fixed storage would expand this
scoped mathematical checker beyond its purpose. The bounds above constrain
live data. Each authenticated frozen input is at most 8 MB; each native subprocess
has a 90-second timeout and checked exit status. Registered commands have a
600-second maximum, execute sequentially and clean their private temporary tree.
Explicit --work retains outputs for diagnosis and refuses existing paths.
Follow-up for untrusted large inputs: fixed-capacity arithmetic and enforced
bit-length/resource-exhaustion controls before widening any capacity.

Rule 10 boundary: new Python is checked with Ruff E,F,I,UP,B,SIM,C4,PIE,RUF,
source compilation and warnings-as-errors in normal and optimized execution.
Frozen historical native code is source-authenticated and executed without
optimization, rather than reformatted or silenced. Its helper imports, runtime
allocation and internal assertions remain inherited. The exact Clifford kernel
is reused and credited; the new Fraction evaluation is an internal second
implementation of its operator semantics, not a separate formal proof.

Internal read-only review found two implementation mistakes before publication.
The prefix check initially discarded other-register warp histories; an injected
four-event dependency showed false acceptance. The final prefix checker retains
all reduced words and rejects that control. D-phase evaluation initially mutated
earlier trace observations; it now returns fresh rows. A regression compares
each source trace endpoint with a fresh prefix evaluation. The final receipt is
regenerated after both corrections. These changes do not alter frozen inputs.

Canonical main d8e0f83f and priority revision 6 are the scientific baseline.
No full selected replay, Lean, Docker or outer-chain replay is relevant to the
new local theorem. The remaining physical and analytic obligations are explicit
in PROOF.md and TASK.json.
