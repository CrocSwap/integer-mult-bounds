# An exact QQ16 B1 prefix inverse before child 11795

The literal B_1_2 prefix before child11795 is a bijection on its **704 ordinary fields**, with private fields zero at entry and exit, provided its completed native and cover maps are exact invertible maps on their declared field spaces. The source contains 32 private CLEARs, so bijectivity does not follow merely by reversing every event. The checked reason is that the CLEARs enclose **16 controlled shears** whose read and written ordinary fields are disjoint.

This supplies a structural reachability lemma for [PR3258's local rounded-child question][prior]. Every ordinary state at this B1 cut has a unique unrestricted exact-prefix preimage. It does not prove that the preimage has a particular caller grid, fits a finite precision, or belongs to the output image of F0.

A compatible local rounded collision therefore lifts through this exact prefix. The native application still requires binding the predecessor's 512-coordinate local implementation to the prefix's full cut space. No complete native producer collision, fully rounded-prefix failure, borrowed-helper restoration failure, paid consumer, supplier or new kappa is established.

## Exact boundary and theorem

Let V denote an admitted complex field space, including whatever owner, payload and spectator indices the caller requires. Distinct ordinary roles contain independent arbitrary members of V. Frames may give different coordinate descriptions of V. Their conversions must be exact linear isomorphisms. The cover maps are whole-field bijections, not free address reads. This theorem does not replace or independently prove those inherited native/cover contracts.

Let P execute exactly B_1_2 events `[0,11795)`. All eight private fields start zero. The next events are literally

```
11795: climb A, L470, frame0 -> frame5, rank1
11796: L524 -= L470/2, frame5
```

**Conditional prefix theorem.** Under the stated exact-map contracts, P has the form

```
(x, private=0) -> (P_ordinary x, private=0),
```

where `P_ordinary` is a bijection on `V^704`. Its inverse is constructive and requires no additional source-dependent observation.

This is an unrestricted exact-state statement. Inverting P may require additional arithmetic precision, routing, storage and work. Those costs are not bounded here. The inverse is a proof construction, not a proposed cheap restoration routine.

### Why the erased private values do not obstruct this inverse

Each of the 16 private epochs starts and ends by clearing the same C register. Between them, the source first gathers a linear expression of ordinary control fields into C, possibly applies a completed native map to C, then adds multiples of C to ordinary destination fields. There are no other operations in the epoch. No control field is a destination.

Thus one epoch acts on ordinary state as

```
controls unchanged,
destinations += A(controls),
all other ordinary fields unchanged,
private returns to zero.
```

It is invertible by recomputing the same private expression from the unchanged controls and subtracting the deliveries. The private expression need not be retained, and its internal map need not itself be inverted. This argument uses the actual disjoint read/write sets, not a claim that CLEAR is reversible.

Outside the epochs, the source has only ADDs on distinct ordinary fields, nonzero SCALEs, phase labels and the declared invertible completed maps. Negate an ADD coefficient, invert a SCALE coefficient, and invert a completed map to reverse these events. Reverse the order of all resulting units. Composition proves the theorem. The frame directions reverse along with the maps.

The exact source prefix has 11,795 events and compiles to 11,143 units after its private epochs are grouped. The first eight epochs each have five controls, one destination and one private native map. The last eight have 22 controls each, between 47 and 55 destinations, and no private native map. Their exact ranges and all role sets are in `RESULT.json`. The final private clear is at10566, before the named child cut.

## What follows for the earlier local collision

PR3258 proves that the actual finite rank-one child/half-ADD reference of PR3250 has a `3^256` local-entry collision family at every precision `2 <= p <= 2046`, and a `2^256` sign family with its full count dictionary fixed. Suppose that reference is realized on a compatible subspace of V at this cut, and no other field or transcript stores the differing local entry. Place its collision family in L470, with L524 zero and every other ordinary field fixed. Call those complete cut states z_c. The prefix theorem gives distinct entry states

```
x_c = P_ordinary^(-1) z_c.
```

The named rounded pair sends every z_c to the same complete state, including its returned zero owned buffers. Therefore the hybrid map consisting of the exact prefix followed by that rounded pair is noninjective on these x_c. A deterministic suffix with no retained extra information cannot separate states which have already coalesced.

This is a conditional lift, not a new native embedding theorem. A 512-coordinate local kernel is not the complete 73-axis payload or full owner cover. This package does not identify those spaces or execute the actual full native prefix numerically. It also does not show that x_c are p-bit values at the B1 entrance, that a fully rounded prefix reaches z_c, or that x_c arise from the preceding F0 stage. Those are distinct remaining obligations.

The executable checks a noncommuting exact GL4 substitution for every opaque completed map. In that deliberately smaller algebraic model, nine full-state preimages round-trip through the literal prefix and three distinct complete entries coalesce at the pair for each of p=2,8,53. That is an implementation check of the constructive inverse, not a replacement for the native premises or a full-payload experiment.
