## Why the planned paid-phase enumeration was stopped

[PR4690](https://github.com/CrocSwap/integer-mult-bounds/pull/4690) already
reports bounded common-form searches, including all 511 nonzero rank-one
ambient forms and 18 compound forms. More decisively, PR4696 proves a general
fixed-path rank-debt inequality rather than merely searching those forms.
Its exact proof and verifier are preserved byte-for-byte under `upstream/`,
with original commit/path/Git blob/SHA provenance in `UPSTREAM.json`.

`rank_debt_audit.py` first runs the exact pinned upstream verifier with isolated,
optimized global Python 3.14. It reproduces the committed result and checks
that all upstream source/input/result bytes remain unchanged. This includes
512 small symmetric-form rank triangles, rational concavity controls, four
actual source mutation rejections and a change of every frame basis. Those
upstream tests retain their original authorship.

The same script independently reconstructs both physical words using its own
binary Gaussian membership tests and Gauss-Jordan inversion, rather than
calling the upstream `audit` function. On each orientation it checks:

- All 632 persistent path ranks telescope exactly.
- All 408 helper endpoints are positive/nested, and every composed logical
  warp fixes its entrance space pointwise.
- Helper paid rank mass is 3,471 across 2,208 positive helper paid jobs; each
  old step is bounded by that helper's old endpoint rank.
- Without making **any** block cut at an inert adapter marker, helper blocks
  contain zero or one old paid call: 19,817 and 2,208 blocks respectively.
- The 3,538 actual climb/warp/center graph edges are distinct physical owner
  occurrences, and the full paid profile includes all eight center jobs.

All 448 adapter markers occur on main owners 0 through 223. None belongs to a
helper. Thus omitting their textual freezes/cuts changes no helper block or
owner-wise debt hypothesis. This verifies that the proposed actual-graph
variation does not provide an escape from the new cost theorem.

For a helper with old rank `h>0`, each old contact block rank satisfies
`r_j<=h`. Restriction and telescoping bound its added endpoint rank `g` by
`sum(delta_j)`. Concavity gives

```
sum((r_j+delta_j)^t-r_j^t) >= (h+sum(delta_j))^t-h^t
                             >= (h+g)^t-h^t.
```

Those paid occurrences have distinct field owners, so summing the inequality
does not charge one child to multiple independent helpers. Added main/center
costs cannot improve the moment; fixed main endpoints supply no extra reward.
The phase rank formulas and the analytic theorem remain mathematical premises
of this audit, rather than a new Lean formalization. This source audit supplies
no native amplitude, absolute-phase, compiler or multiplication theorem replay.
