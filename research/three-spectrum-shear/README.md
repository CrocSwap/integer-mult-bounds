# Three values already force six same-phase calls

This contribution is produced by Nick Petalas. New work is Apache-2.0.
Independent human and formal proof-kernel review are unclaimed.

For a phase operator C with spectrum {1,i,-1}, three independent transfers
`y_j += (C-I)x_j` require exactly **six C/C^-1 calls**, even with arbitrary
constant invertible complex role mixing and any finite number of restored
dirty helpers. Equivalently, the complete map `I+(z-1)N` for any rank-three
square-zero N has minimum six in this alphabet.

This is a scoped algebraic proof with exact finite corroboration. It answers
Open next question 1 in Richard Hoekstra's [PR1318](https://github.com/CrocSwap/integer-mult-bounds/pull/1318),
which proves the four-value floor and leaves the three-value case open.
The new first/last-row argument excludes four independent phase directions
using only i and -1. The inherited target-image loop method needs those same
two active values. [PROOF.md](PROOF.md) gives the complete argument and credits
the inherited normalization, span split and canonical loops. No predecessor
verifier is imported or replayed. No literature-priority claim is made.

Deleting the -i character therefore does not create the proposed four-call
shortcut. Six direct calls attain the bound with all source, target and helper
columns handled as arbitrary dirty inputs. This does not change a selected
supplier, physical tariff or kappa. Extra character-dependent gates, different
phase functions and clean-input contracts are outside the theorem.

## Reproduce

From the repository root, using CPython 3.12 and its standard library:

```sh
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -W error -B research/three-spectrum-shear/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -W error -O -B research/three-spectrum-shear/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/research_package.py --package research/three-spectrum-shear
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/check_research_commit.py --package research/three-spectrum-shear --check-source-history
```

Other machines can substitute their CPython 3.12 interpreter. Expected direct
output is `PASS_THREE_SPECTRUM_SHEAR minimum=6 loops=2 collapse_cases=81 upper_samples=6 controls=9 no_new_kappa`.

The checker uses exact Q(i) arithmetic. It constructs both four-call canonical
loops on all basis inputs, imposes equality at i and -1 by exact elimination,
and obtains constant-transfer image ranks one and two. It tests the new pair
collapse on 81 explicit rational cases. Six literal eight-role upper endpoints
include two restored dirty spectator roles. The nine controls cover six omitted
calls, the single-active-value boundary, a nonidempotent factor and zero phase.
These are finite checks of the written proof's core, not enumeration of all
complex projectors or all circuits. The all-dimension lower bound is the proof.

`RESULT.json` is generated by the verifier and binds its mathematical fields to
the package and inherited-input hashes. To regenerate without overwriting it:

```sh
python3.12 -W error -B research/three-spectrum-shear/verify.py --write /tmp/three-spectrum-result.json
python3.12 -W error -B research/three-spectrum-shear/verify.py --certificate /tmp/three-spectrum-result.json
```

Source pin availability, metadata validation and passing CI are distinct from
scientific approval. No native phase/compiler, finite-precision, fixed-tape,
physical hosting, supplier-admission, outer theorem or Lean replay is run.

## Verification implementation limits

Power-of-Ten rules 3 and 9 have narrow Python-runtime deviations in `exact.py`
and `verify.py`. Fraction objects, matrix entries, JSON parsing and Python
arithmetic dispatch allocate or dispatch dynamically. Matrix order is capped
at eight, loop alphabets and products have fixed finite bounds, and no search
queue or recursion is used. Receipt inputs are trusted committed package files,
not a service input. Inspectable direct arithmetic and exact endpoint checks
compensate for these runtime constraints. A fixed-capacity native arithmetic
engine would be a separate implementation if runtime guarantees were needed.
All functions fit within 60 physical lines. Warning-strict normal/optimized
replays are the available diagnostics; no optional linter is required.
