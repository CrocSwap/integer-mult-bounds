# Implementation and verification boundaries

The predicate is a smaller sufficient signed format than the cancellation-blind
control, with exact all-prefix grids, literal ADD alignment and attaining
smaller-format rejection controls. The workload is both PR3076 providers and
orientations reconstructed through PR3080's pinned sources. There is no word
or frame search. Three analyses compare cancellation-blind bounds, exact
reduced-word row norms and exact asymmetric endpoints. The last two tie at
77 bits. Arithmetic and receipts are deterministic, with no noise tolerance.

Build the lever shaped this into `rows.py` and a rerunnable certificate.
Prove it works required fresh source regeneration, exact prefix replay,
attaining fixtures and literal bit-ADD execution. Power of Ten shaped the
bounded inputs, enabled contracts and resource limits below.

New code has no recursion, dynamic evaluation or generated source. Event
loops are bounded by 30,000 entries. There are at most 1,024 row slots,
4,096 atoms per row, 256 symbols per reduced word and 256 numerator bits
per coefficient. Dyadic denominators are checked. Observed support maxima
are 156 forward and 148 dual. Input precision is bounded to 2..128; the
published receipt uses 64. Functions are at most 60 physical lines.
Contracts use explicit exceptions and remain enabled under `-O`.

Rule 3 deviation: Python dictionaries, integers and Fractions allocate during
replay. Fixed allocation would require replacing the runtime and exact
arithmetic beyond this package's scope. Compensating controls are authenticated,
size-bounded inputs, explicit event/row/word capacities and the registered
600-second bound. Each native child has a 90-second timeout and checked exit
status. Streams are processed sequentially. Registered temporary exports
are removed on success/failure; explicit `--work` retains diagnostics.
Before extending this to untrusted mathematical inputs, add fixed-capacity
arithmetic and resource-exhaustion tests.

The separate integer checker caps integer coefficients at 512 bits. It uses
the declared denominator as an input but independently derives the observed
depth, checks every quotient exactly and rejects the next smaller denominator.
It reproduces all prefix-ledger hashes without importing the Fraction engine.

Rule 10 boundary: Python uses Ruff diagnostics and warning-as-error normal
and optimized execution. Frozen predecessor files are not refactored. Their
frame routines, subprocess compiler and bit circuit remain inherited,
source-authenticated and exercised through real entry points. A cleanup of
historical archives would be a separate change; maximum diagnostics are not
claimed for them.

Thirteen behavioral groups cover exhaustive signed boxes, the negative signed
edge, rational cancellation, free-word order, zero buffers, unknown native
events, intermediate-only fractional depth, receipt witnesses, semantic
sign/warp failures, bounds and source corruption. Publication bytes and
registered metadata are checked separately from the mathematics.
