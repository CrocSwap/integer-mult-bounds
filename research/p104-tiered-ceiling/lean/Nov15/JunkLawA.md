## 1. Law A (JunkLawA.lean) [PROVED, abstract model]
`LawAModel K P D`: `M : Matrix (Fin P) (Fin P) K` (row t = X-part of v_t = alpha_t.arr_t), `arr : Fin D -> (Fin P -> K)` (ONE arrival vector per owned descending move), and premises as fields:
- `hspan` : every row M t lies in span(arr)  [premise: SP (public moves ascend, ADD/COPY same chart, owned INIT empty) + nested owned moves; paper JL1 s.1, NOT derived in Lean]
- `hdiag` : M t t != 0  [premise: Y_t odd part = c_t e_t, c_t != 0]
- `Ev`, `hodd` : M t s != 0, s != t => Ev t s  [premise: odd off-diagonals vanish]
- `hpart` : each t has <= 48 Ev-partners  [48-law universe; used only for `j_le : j t <= 48`]
`jc M t` = #off-diagonal nonzeros of row t; `J = sum_t j t`.
- `maisBound`: sum_t 1/(j_t+1) <= rank M, for ANY matrix with nonzero diagonal. Proof in Lean: Caro-Wei over all P! rankings (`card_mul_firstSet`: |B| * #{sigma : x first in B} = P!, by the swap bijection `card_firstSet_eq`; `sum_mais`: sum_sigma |MAIS_sigma| = P! sum 1/(j+1)), then rows of a sigma-triangular set are linearly independent (`mais_linIndep`) so |MAIS_sigma| <= rank.
- `LawAModel.rank_le`: rank M <= D. `lawA`: **sum_t 1/(j_t+1) <= D**.
- `lawA_cs`: P^2 <= D (J + P), i.e. J >= P^2/D - P. `tangent`: 1 - j/2 <= 1/(j+1) for every natural j (equality at j = 0, 1; FALSE for real j in (0,1), so the integrality of j_t is used). `lawA_lin`: **J >= 2 (P - D)**. `lawA_96`: P = 104, D <= 56 => **96 <= J** (this is J_A(56) of JL1; the linear form is sharper than P^2/D - P at D = 56: 89.1 vs 96).
- `junkSet M : Finset (N x N)` = the junk cells; `junkSet_card = J`; `junkSet_card_ge_96 : D <= 56 -> 96 <= |junkSet|`.
- Theorem S core (`single_arrival_clique`, `single_arrival_junk`): rows served by ONE arrival vector (M t = c_t a) are pairwise junk partners, so a group G carries >= |G|(|G|-1) junk cells and j_t >= |G|-1. Only this clique form is formalised; "#single <= M" and the route Gram cut (rank G[P_x,N_x] <= m_x, JC1 s.2b-c) are register-machine statements, NOT in Lean.

## 4. Scope (honest)
- Law A at D <= 56 is a statement about the own56 class (hD). The jl4 argument that "owned mass > 56 never pays" is NOT formalised; and I could not find where it enters the Lean chain: the owned surplus Omega cancels exactly in `branchC_om`, so the formal chain depends on the owned layer only through N. Consequence: for words with D > 56 the Lean results are ceiling_native_Z0 (kappa <= .0151869), and the improvement .0151869 -> .0151027 needs hD. For 56 < D < 104 the intermediate N = ceil(2(104-D)) ceilings were not built (they lie between the two).
- The N = 96 ceiling is for the class K with J^arr as Law A defines it (arrival rows with premises of s.1); words outside the Y_t odd spec are not covered.
- The rank-tight witnesses (clique blocks, JL3) show Law A cannot be improved by more than ~5-20% as a rank law; the 1936-4962 band stays the hJ conjecture (not touched).
