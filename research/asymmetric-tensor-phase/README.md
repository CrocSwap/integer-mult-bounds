# Sharp asymmetric tensor-phase recovery

For fixed unitaries A and B, unequal tensor-square and tensor-cube error
budgets have an exact, discontinuous recovery frontier. This resolves the
asymmetric-budget question left open in [#5916](https://github.com/CrocSwap/integer-mult-bounds/pull/5916),
`research/tensor-phase-stability/README.md`, Open next question 1.
**Scoped analytical theorem with exact finite corroboration. No new κ.**

Put `a=asin(e₂/2)` and `b=asin(e₃/2)`, where `e₂,e₃∈[0,2]` bound the two
absolute operator-norm defects. The sharp bound on `||A−B||` is

```text
3a+2b < π:   2 sin(min(a,2b/3)/2)
3a+2b ≥ π:   2 sin(π/3+b/3).
```

Scalar unitaries attain every value in every positive finite dimension.
The threshold includes equality. At squared budgets `(e₂²,e₃²)=(1,2)`,
the optimal squared error jumps from the limiting `2−sqrt(3)` to
`2+sqrt(3)`. The complete boundary has exact parametrization
`s=4−q², t=2+q(q²−3), optimal squared error=2+q`, for `1≤q≤2`.
The equal-budget theorem and its fifth-root threshold remain predecessor work.

[PROOF.md](PROOF.md) supplies the universal proof and all degenerate budgets.
[envelope.py](envelope.py) decides the branch for exact rational squared
budgets using sign-checked polynomial inequalities, then returns a rational
enclosure of the optimal squared error. It uses no floating-point
trigonometry. [independent.py](independent.py) uses a separately written
Sturm/gcd semialgebraic oracle, without the angle or branch formulas.

## Reproduce

From the repository root, using CPython 3.12 and the standard library:

```sh
python3 -B scripts/research_package.py --package research/asymmetric-tensor-phase
```

Expected scientific markers are `PASS_ASYMMETRIC_TENSOR_PHASE`,
`PASS_ASYMMETRIC_PHASE_STURM`, and `PASS_ASYMMETRIC_PHASE_MUTATIONS`, followed
by `PASS_REGISTERED_RESEARCH_PACKAGE`. Six commands run normal and optimized
variants of the three checkers. Direct commands are listed in
[VALIDATION.md](VALIDATION.md). Default checks write no package files.
`verify.py --output NEW_PATH` writes an exclusive-create, hash-bound receipt.
[RESULT.json](RESULT.json) is generated by that command.

## Evidence and failure coverage

- 10,201 rational angular-budget pairs and 101 exact threshold points are
  checked against generic periodic-arc intersection.
- 160 literal rational unit-circle phases and 16 dense two-by-two unitary
  pairs, including 12 noncommuting pairs, are checked exactly. All 1,344
  tensor defect Gram entries through width three agree with their explicit
  diagonalizations.
- The independent polynomial oracle checks all 289 squared-budget pairs
  on the quarter-step grid, plus 33 rational jump points and 64 one-sided
  perturbations, plus 23 adversarial near-endpoint/common-root cases with
  gaps down to `2^-160`. It isolates every feasible boundary root, including
  common/repeated-root cases, and keeps interior bracket endpoints off all
  original roots.
- Invalid budgets/precision, a falsely strict threshold, interchanged
  widths, lost absolute phase and use outside the unitary domain are
  distinguished by explicit controls. Five actual envelope mutations, an
  oracle endpoint-isolation mutation,
  two actual source corruptions, and an altered receipt reject on private
  temporary copies.

The written proof establishes the universal claim; these deterministic
finite domains corroborate the formulas and implementation. No random
search, empirical generalization or exhaustive arbitrary-unitary census is
claimed. Source bytes are authenticated; predecessor executables are not
imported. The independent checker imports the new envelope only to compare
its outputs against the independently computed feasible-set maximum.
