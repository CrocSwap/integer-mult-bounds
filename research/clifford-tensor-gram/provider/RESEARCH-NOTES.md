## Experiments and corrections

1. The source has 21,449 events in each direction, 632 persistent roles and
   one owned role. The 5,710 paid class records cover 6,596 instances. Only
   checking a single native warp would not cover this boundary.
2. The first importer required each adapter marker's frame to be the current
   frame. This rejected 82 source exit markers. Source inspection showed that
   these adapters are identities. The importer now proves identity for a
   moved marker. It still rejects a nonidentity adapter at a wrong frame.
3. The first owned-lifetime tracker marked COPY but not ADD into a cleared
   owned register as live. The backward source accumulates its center by
   ADD. The tracker was corrected before any complete-provider claim.
4. The native inverse circuit returns tuple gates. The first conjugation
   helper combined a tuple with a list. This was a representation error,
   not a mathematical failure. The helper now makes the new gate list
   explicitly. Both orientations are replayed.
5. All 5,710 paid recipes then passed the new phase-exact Gram test. The
   rank-one normalized traces were zero or `(1+i)/2^j` and its conjugate,
   with j from 1 to 4. The proof uses the more general checked bounds
   `Re(tau)<=1/2` and `|tau|^2<=1/2`.
6. The initial fusion scan required a common middle frame. It found 1,341
   pairs per direction and a single-term off-diagonal contact for every
   pair. The two-sided cut formula removed that unnecessary restriction.
   The second census covers all 1,363 adjacent rank-one pairs per direction,
   including 22 with an intervening change of middle frame. It excludes
   both endpoint placements for each pair: 5,452 replacements in total.
   The same proof then applies to all 2,658 adjacent pairs at all ranks.
   A final extension removes adjacency as well: all 7,582 pairs on one
   persistent role per direction have a certificate. The final result
   excludes 30,328 endpoint placements. Each extension changes the search
   domain explicitly; it does not reuse a smaller-domain receipt as proof.
7. The complete physical programs pass the existing compact verifier. A
   separate sparse expansion measures peak total support 22,331 forward
   and 12,930 backward. Support growth is manageable for this source. No
   general polynomial support bound follows.
8. The proof is stronger than a width-one rejection: each saved contact
   defect has normalized squared norm at least q^2 at every positive
   width. The full-provider norm need not have that bound, because its
   prefix and suffix can be nonunitary. Invertibility transfers nonzero
   defect, not a condition-number estimate.
9. The final proof audit checks the positions of all 224 nonidentity main
   adapters in each direction. Each entrance precedes all uses of its role;
   each exit follows all uses. This check is part of the importer. It makes
   the interval's logical-frame interpretation explicit. All receipts keep
   the same mathematical values.
   A separate negative check moved role 112's nonidentity exit adapter from
   event 15,723 to event 14,298, before its last scalar contact. The audit
   rejected it with `Nonidentity adapters surround every use of their role`.
10. The first hosted replay on Linux / CPython 3.12.15 passed the four earlier
    checks, all native recipe classes and both complete provider endpoints.
    Its 240-second provider limit then expired during the remaining checks.
    No mathematical failure was reported. The manifest now assigns 90 seconds
    to each earlier check and 420 seconds to each provider check. The total
    stays 1,200 seconds. Source code, proof and scientific receipts are
    unchanged by this budget correction.

No promising fusion survived the exact endpoint test. The source remains
unchanged. The hypothetical invoice delta is not an achieved saving, so a
new compiler or outer arithmetic run is not warranted by this experiment.
