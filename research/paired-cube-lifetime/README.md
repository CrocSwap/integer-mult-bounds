## Reproduce

Python 3.11 or later, standard library only, with assertions enabled:

```sh
python3 -B research/paired-cube-lifetime/verify.py
```

The command checks source hashes, regenerates the bit graph and matching in a
temporary directory, rebuilds both physical inventories, and compares the
complete certificate. It performs no search and makes no source changes.
For intentional development, `--write` regenerates the certificate and
`--refresh-sources --write` explicitly updates its source pins first.
