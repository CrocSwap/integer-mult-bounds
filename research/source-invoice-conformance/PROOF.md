# Source-to-invoice conformance argument

## Claim and trust boundary

The checker accepts a literal h9/v112 native word in the retained original or
owned-relation schema and a literal complex p16/a7 caller. It recomputes their
symbolic endpoint/ownership protocol and recursive invoice. Its conclusion is
that the extracted paid and productive target counts agree with a claim bound
to those exact sources. It is not a physical supplier or funding theorem.

In particular, the h9 frame tariff and mixed-target Gaussian interpretation
are inherited interfaces. Caller stage labels denote independent formal Laurent
variables. The input does not contain a physical coordinate/tape embedding
that would establish those variables' realization at every size. The checker
therefore cannot validate a reused-coordinate realization merely by checking
the formal fresh-stage identity. Absolute phases, precision/tape lowering,
ordinary-work funding, the recursive compiler and analytic recovery remain
explicit unchecked obligations in every output.

The contribution is a reusable independent source extractor and diagnostic
gate. Its calibrations are known results, not new discoveries or scientific
admission of pending work. It imports no author replay, pricing, relation
witness, declared histogram or PASS receipt to determine the invoice.

## Native rows, frames and ownership

At entry, each persistent L field and declared owned C field is an independent
formal variable. Owned L helpers likewise start arbitrary; they are not silently
initialized to zero. Main inputs may not be declared owned. The legacy original
schema admits only C0 as owned; successor schemas require explicit ownership.

Each row is a finite rational map from (entry variable, reduced signed native
operator word) to its coefficient. Scalar ADD and SCALE implement exact rational
linear operations. CLEAR is allowed only on owned inputs. COPY requires a
cleared owned destination. At every scalar action, source and destination
frames must match the event's declared frame. Dyadic coefficient domains and
the inherited abstract real-scalar allowance are checked and recorded.

A native warp prefixes its signed operator symbol and cancels an immediately
opposite prefix. Left multiplication in a free group is injective, so this
dictionary transformation cannot silently combine distinct keys. Backward
execution uses its own formal alphabet under the retained primitive-wise
conjugation ABI; it is not inferred by reversing or taking an adjoint of the
forward program. Exact sparse propagation checks all independent entry columns
simultaneously. No test input vector substitutes for this identity.

Binary frame bases are validated for independence by complete span generation.
Every declared binary G map is checked invertible. At each warp occurrence,
its actual signed map must carry the complete current frame subspace exactly
onto the declared output frame subspace. A discrepancy rejects as an unpriced
native residual. This checks the G_columns representation supplied by the word;
it does not derive a unitary's absolute phase or independently authenticate a
different physical implementation of those columns.

For every climb or centre, actual old/new frame subspaces must be strictly
nested, and the charged rank is recomputed as the difference of their basis
dimensions. The record's rank must agree. Paid events get source orientation,
event index, role, old frame, new frame and independently derived rank.
The recursive transport changes the frame in this retained symbolic protocol;
its physical Gaussian implementation remains an inherited tariff obligation.

An uncharged zero-retag is allowed only when the entire current row is exactly
zero, including every arbitrary owned entry column. The final frame vector must
match the source return contract. Every borrowed helper returns its independent
identity row, each main row returns the prescribed signed shear, and all owned
rows return zero. Entry/exit adapter markers must occur exactly once for each
main input and agree with its endpoint frames. Phase-section markers are checked
as annotations; they are not a native phase proof.

For each helper i, its productive rank is derived from its actual start/final
frames. It earns one target only if borrowed, strictly ascending and returned
as an independent identity. Owned helpers earn none even if their frame labels
match borrowed helpers. Their surrendered target ranks are retained explicitly
in the audit. Thus the credit rule follows the checked endpoint/ownership ABI,
not a declared helper histogram or a count of physical output fields.

The fixed caller tariff also requires its native main endpoint contract. Ports
must be distinct nonzero odd-parity h-bit vectors p_i. The first main bank must
start on span(p_i) and end at the full h-space; the second must start at zero
and end on the p_i-orthogonal hyperplane. These exact subspaces are checked,
not merely their net dimensions. A further paid main climb and updated adapter
cannot silently inherit the old rank1+8-times-stages target interpretation.

## Caller identity and recursive composition

For a caller with 2p rows and 2p+1 stages, use one Laurent exponent for A and
one for every stage R_j. Execute each left/right scalar boundary program on
an identity matrix over exact rationals; require agreement with its separately
declared matrix. Initialize the Laurent rows from the computed right matrix.

LOCAL and QUERY_SHEAR apply their oriented elementary A shear. LOCAL then
multiplies both rows by its R_j. IDLE multiplies both selected rows by precisely
the listed distinct stage product. ADD, SWAP and SIGNED_SWAP act literally.
Every stage must occur exactly once as LOCAL or QUERY_SHEAR. Finally apply the
computed left boundary matrix. Require zero off-diagonal entries and exactly
one coefficient-one monomial in every diagonal cell. Its exponents must have
A exponent ±1 and every R exponent in {0,1}; compare this derived diagonal with
the declaration only after computing it.

Induction on each source instruction proves that these sparse Laurent rows are
the exact formal caller matrix. The complete coefficient identity is finite
and exact; it makes no claim that a proposed physical caller realizes fresh
independent stages or commutes in the required way.

For the explicitly supported p16/a7 h9/v112 tariff:

* Each LOCAL contributes its actual oriented native paid events and credited
  helper targets once. Its source caller event ID is retained.
* Each QUERY_SHEAR contributes v=112 rank-one calls.
* Each IDLE with t distinct listed stages contributes 2v=224 calls of rank 8t.
* Each derived main diagonal contributes v=112 targets of rank 1+8 times the
  number of R exponents, using the inherited Gaussian-product interpretation.

These are the retained caller's tariff/ownership rules, not newly proved
physical implementations. A different ABI must use a reviewed adapter rather
than inherit these labels. Ambient rank, pairs, prefix count, native dimensions
and canonical endpoint shapes are checked before a result gets this contract.

Every recursive charge appears in one disjoint category: an actual local event
at an actual LOCAL call site, an outer query, or an outer idle. Every target is
a credited local helper or a derived main target. Local events are stored once
per orientation with their complete call-site ID list. Expanding this factored
ledger yields precisely the same multiset as enumerating each call separately.
Summing ranks/counts is therefore a complete recursive census of this symbolic
protocol. Ordinary scalar, boundary, native-map and adapter records remain in
the audit and require their separate physical/precision/funding evidence.

## Claim binding and diagnostics

The emitted preflight object includes both paid and target histograms. A checked
claim must contain the same contract and both canonical-JSON source hashes.
It cannot transfer between different recipes merely because their histograms
match. All source JSON is data, never executable code. Duplicate keys, floating
point/nonfinite values, noncanonical rank keys, Boolean counts and unsupported
schemas/operations reject. Rational strings accept bounded integer/ratio syntax,
not exponent notation. Explicit input/table/term bounds limit this implementation's
supported domain; these are tool limits, not mathematical impossibility claims.

Canonical hashes identify compact sorted-key JSON, excluding trailing newlines.
Raw gzip/decompressed byte hashes serve a separate export-provenance role.
The audit additionally names the native/caller/CLI code hashes. The complete
recursive-ledger hash covers local groups, outer queries/idles and main targets.
These hashes identify what was checked; reviewer trust in the code and the
unchecked scientific obligations are not derived from a hash comparison.

New output files are explicit opt-ins and refuse overwrite. Extraction without
an expected claim is labeled EXTRACTED_RECURSIVE_INVOICE; a successful expected
claim match is labeled PASS_SOURCE_INVOICE_CONFORMANCE. Neither label grants
funding, admission, publication or a selected-frontier transition.

## Corroboration and limits

The three source calibrations compare independently extracted invoices with
the separately retained producer claim fields. Original selected-word input
has 64404 paid / 10928 productive; both owned successors have 64148/10800.
The unchanged caller has 2 forward and 16 backward LOCAL calls. Eight owned
backward helper inputs thus surrender 128 H9 targets. Omitting that debit is
detected per rank even if the paid side is unchanged.

The two successors have the same recursive invoice but different prepared
programs, owned pivots, scalar allowances and canonical source hashes. Their
backward scalar allowances 158744 and 158776 differ by 32. The stale-source
control rejects transferring one claim to the other. This is an executable
distinction, not an assumption that same histograms transfer physical evidence.

The control suite changes actual programs, source frames, maps, ownership,
boundary programs, orientations, idles and diagonal declarations. Other controls
change invoice bins with equal rank mass, omit queries/idles/target debits,
or introduce unknown operations and malformed input. Poisoning author profile
annotations leaves the computed counts unchanged, showing that extraction does
not merely validate the hash of a declared invoice. No predecessor pricing
engine, compiler, native phase suite, selected cold replay, Lean or Docker
is executed by this package.

This written argument establishes the finite interpreter's symbolic protocol
and census. It does not replace a production all-size embedding, absolute phase,
precision/storage/movement proof or the complete multiplication theorem.
