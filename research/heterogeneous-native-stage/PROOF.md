# Relative rejection of the returned heterogeneous stage

This is a price theorem for one returned invoice, conditional on the declared
changed endpoint ranks. It is not a theorem that every native realization
with those endpoints has that invoice. Numerical optimization supplies no
exact lower bound on the native cost.

Use the pinned p16 controller and the actual round-three native profile.
At 60 specified ports, replace the native main fresh-axis dimension eight
by seven, retaining each central line. All other 52 ports retain dimension
eight. The returned local paid profile is the old profile plus 120 rank-one
calls, with the same 408 independent helper targets. This is exactly the
source word with paid terminal chart changes and no internal contact moves.
The optional binary model did not discover a better invoice.

For any subset A of the 18 full native stages, the new controller main rank
at an affected port is its old rank minus the number of stages in A present
in its diagonal monomial. The new idle rank is similarly its old rank minus
the number in its idle interval. Every source full call retains all its
original helper jobs; each selected stage adds 120 rank-one paid calls.
The physical interpretation is granted for this optimistic price screen;
signed native synthesis and Gaussian-normalizer admission are not established.

For each full stage s, let M_s count diagonal monomials containing s, and
I_s count paid IDLE events containing s. The literal source list satisfies

    M_s - 2 I_s = 2,    0 <= I_s <= 8.

These are checked independently for each of the 18 full stages. The factor
two counts both owners of each idle pair. Every affected main and idle rank
stays in [1,145] after any subset is reduced: an original eight-axis block
only loses one axis, and the main central factor is retained.

Let 0 <= C <= 17/5000 and f(r)=r^(1-C). On [1,145],

    97/100 < f'(r) <= 1.

Indeed log(145)<5 follows from the degree-12 positive Taylor polynomial for
exp(5). The bound exp(-x)>=1-x then gives

    f'(r) >= (1-C) exp(-5C)
           >= (4983/5000)(983/1000)
           = 4898289/5000000 > 97/100.

The mean value bound applies to every lost axis even when several selected
stages share a target or idle. Writing alpha=97/100, the change in complete
target-minus-paid moment is at most

    -60 alpha sum_(s in A) M_s
    +120 sum_(s in A) I_s -120 |A|
    = -120 ((1+alpha)|A|-(1-alpha)sum_(s in A) I_s)
    <= -120 ((1+alpha)-8(1-alpha))|A|
    = -(1038/5)|A|.

Thus every nonempty subset of these returned local invoices strictly
worsens the complete source p16 margin throughout the stated saving range.
This includes all 262143 nonempty subsets without a mask search. For each
single-stage replacement, exact outward moment intervals at C=.00302177585
give a negative complete margin between approximately -237.853 and -237.771;
all 18 replacements together give approximately -4281.04033. The original
margin at that price is approximately .00000513644. These decimals are
orientation only; RESULT.json retains the exact rational bounds.

The calculation does not exclude a different native paid/helper profile,
another endpoint contract, another controller or a saving outside the
specified interval. In particular, proving the optional solver model has
this optimal invoice is outside this result. The next construction must
remove enough paid work to fund the lost target ranks; changing the output
rank labels alone cannot improve the price.
