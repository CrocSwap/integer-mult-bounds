# Paid offline arithmetic and explicit thin metadata

For each fixed input length parameter p, one original axis has r = 2^O(p^(1−epsilon)) positions. A complete group key has K = O(p^(beta+1−epsilon) + p^beta log p) = o(p). Enumerating the actual coefficient, phase, membership and address functions over their local keys costs poly(p) 2^O(K), after the one-axis catalogues have been built in poly(r,p) operations. Both are n^o(1). These are explicit algebraic functions, not TM transition tables.

Original global Gaussian coefficients may require Cp + O(p² log p) offline precision. No such number is a unit-cost scalar. limb_setup.py supplies signed arithmetic with 15-bit limbs, schoolbook multiplication and binary long division; elementary raw products stay below 32 bits. Polynomial-sized rational coefficient preparation and exact elimination therefore have polynomial native cost. Rational exp/root series at specified precision also have polynomial construction time with certified remainder formulas retained from the sources. This is a sufficient asymptotic construction, not a claim that the full source coefficient constructor was emitted in this packet.

Online only the source-conditioned O(p)-bit coefficients are retained, with guards for polynomial error amplification and the actual circuit suffix norms. Complete word-key projection is a Benes masked-shift network of O(log p) depth. Local tensor-circuit route width is the dyadic microbox L = p^128, so local routing also costs O(log p) stages; full original-axis width must not replace that local width. Coarse labels are spectators in those local routes while complete H calls still cover all coarse labels.

sparse_membership.py checks an explicit table-driven set-bit scatter on finite examples. Its width cap is a test limit, not the asymptotic theorem: enumeration over all K-bit keys is paid as above. No Python dictionary lookup, arbitrary-width arithmetic or oracle is silently designated as one native instruction in the proof.
