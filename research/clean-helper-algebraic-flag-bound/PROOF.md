# Clean helpers with algebraic target flags

Prepared for **@CubeJerry** with substantial OpenAI Codex assistance.
Apache-2.0. This is a scoped written proof, not proof-kernel verification.

## 1. Result and exact model

Fix integers `m >= 1`, `t >= 1`, `r >= 0`, and set `n=t+r`. Let

\[
 R_{\mathbb Q}=\mathbb F_2[(M_m(\mathbb Q),+)],\qquad
 [A][B]=[A+B],\qquad 1=[0].
\]

An exact word of `k` paid calls has the form

\[
 \prod_{j=1}^{k}\left(I_n+([A_j]-1)x_jy_j^T\right)
  =\operatorname{diag}([C_1],\ldots,[C_t],1,\ldots,1),                 \tag{1}
\]

where `rank_Q(A_j)=1`, `x_j,y_j` are binary `n`-vectors,
`y_j^T x_j=1` in `F_2`, and each `C_s` is an invertible rational
`m`-by-`m` matrix. The last `r` output exponents are exactly zero. All
registers are part of the matrix identity: helper outputs must return to
identity on arbitrary inputs. There are no interposed free address maps.
The paid-frame span is `S=span_Q{A_j}`.

**Theorem (algebraic-flag extension).** If `dim_Q S <= m+1` and the
relative matrices

\[
 T_s=C_1^{-1}C_s\quad (1\le s\le t)
\]

have a common complete invariant flag over `Qbar`, then `k >= mt`.
Equivalently, the relatives can be simultaneously triangularized over some
finite extension of `Q`. A common *rational* flag is not required.

**Corollary 1 (arbitrary two targets).** For `t=2`, arbitrary invertible
rational targets and any number of clean helpers require `k >= 2m`
whenever `dim_Q S <= m+1`. No flag hypothesis on the target pair is needed.

**Corollary 2 (commuting relatives).** The bound `k >= mt` holds if the
relative matrices commute pairwise. In particular it holds when all data
targets lie in a rational matrix pencil `span_Q{C_1,C_2}` and are invertible.

The new step is the address-field extension and its consequences. The
rank inequality, normalization, support split, and zero-helper flag count
come from the predecessors credited in Section 9. Sections 2–5 give the
complete needed argument so the claim can be reviewed without treating a
predecessor's finite tests as a proof. This result does not cover every
nontriangularizable target family; Section 8 exhibits that boundary inside
the same small-span model.

## 2. Why an address-field extension is valid

Let `K/Q` be a finite field extension containing the entries of a common
flag basis. Such a finite extension exists because there are finitely
many basis entries and they are algebraic. We enlarge the *address field*
from `Q` to `K` and keep the coefficient field of the group algebra equal
to `F_2`:

\[
 R_{\mathbb Q}\hookrightarrow R_K=\mathbb F_2[(M_m(K),+)].           \tag{2}
\]

This is induced by an injective additive-group map and is injective on
formal sums. It is not an extension of the binary coefficient field by
`K`. Equality (1) therefore remains valid, with the same scalar vectors
and the same number of paid calls. Rational matrix rank and rational
linear independence are preserved under field extension, so

\[
 \operatorname{rank}_K A_j=1,\qquad
 \dim_K\operatorname{span}_K\{A_j\}=\dim_{\mathbb Q}S.             \tag{3}
\]

For any fixed invertible `P,Q` over `K`, the map `A -> PAQ` is an
invertible additive map on `M_m(K)`. It induces a group-algebra
automorphism, preserves address rank, and sends the zero helper exponents
to zero. These changes of coordinates are proof operations on (1); they
do not grant a new physical primitive or insert free address maps into
the original rational word. Relative targets change by conjugation:

\[
 (PC_1Q)^{-1}(PC_sQ)=Q^{-1}T_sQ.                                  \tag{4}
\]

Every additive `K`-linear projection of address matrices likewise
induces a group-algebra homomorphism. The homomorphism need not be
injective: precisely the calls with zero projected frame become identity.

**Domain fact.** In each rank argument, use only the additive subgroup
`G` generated by the finitely many projected exponents. It is finitely
generated and torsion-free, because `K` has characteristic zero.
Consequently `G` is isomorphic to `Z^d` for some finite `d`, and

\[
 \mathbb F_2[G]\cong\mathbb F_2[z_1^{\pm1},\ldots,z_d^{\pm1}]
\]

is an integral domain. Ranks can be taken over its fraction field. For an
exponent `a`, the element `[a]-1` is nonzero exactly when `a != 0`.
Multiplicative algebraic relations in `K` are irrelevant to its additive
exponent group. For example, in `K=Q(i)`, `[i]^2=[2i]`, not `[0]`.
Rational denominators and algebraic coordinates are never reduced
modulo two.

**Rank tool.** For nonzero coefficients `a_j` in this domain, put
`X=(x_1 ... x_e)` and `Y=(y_1 ... y_e)`. Expansion of the ordered product
gives

\[
 \prod_{j=1}^{e}(I+a_jx_jy_j^T)=I+XHY^T,                          \tag{5}
\]

where `H` is upper triangular with diagonal `a_1,...,a_e`: a product
term starts with some column `x_p`, ends with some row `y_q^T`, and has
`p <= q`; its length-one term for `p=q` is `a_p`. Thus `H` is invertible
over the fraction field. If the product is identity, the Sylvester rank
inequality gives

\[
 \operatorname{rank}X+\operatorname{rank}Y\le e.                  \tag{6}
\]

For any product, (5) also bounds the rank of its difference from identity
by each of `rank X` and `rank Y`. The ranks of these binary matrices are
the same over `F_2` and over the fraction field. This proves all the rank
facts used below, including for algebraic projected exponents.

## 3. The zero-helper two-dimensional count over K

Consider a projected identity with `t` invertible lower-triangular
2-by-2 data exponents and zero helper exponents. Let `E` be the number of
nonzero rank-one frames in this block. Let `U` count frames with nonzero
upper-right entry, and let `rho_X,rho_Y` be the binary column and row
ranks of their scalar vectors.

Project onto the upper-right entry. Every target exponent becomes zero,
so the product is identity. Exactly the `U` frames survive. By (6),

\[
 \rho_X+\rho_Y\le U.                                             \tag{7}
\]

For `i=1,2`, let `l_i` count the frames outside that set whose `i`th
diagonal entry is nonzero. Under diagonal-entry projection, the target
minus identity has rank exactly `t`: all `t` data entries are nonzero
formal monomials minus one, and all helper entries are zero. The upper
frames contribute scalar spans of ranks at most `rho_X,rho_Y`; each of
the other `l_i` surviving frames adds at most one to each span. Therefore

\[
 t\le\rho_X+l_i,\qquad t\le\rho_Y+l_i\quad (i=1,2).               \tag{8}
\]

For a lower-triangular rank-one 2-by-2 frame, the product of its diagonal
entries is its determinant and is zero. It has at most one nonzero
diagonal entry. Hence `l_1+l_2 <= E-U`. Adding all four inequalities (8)
and using (7),

\[
 4t\le2(\rho_X+\rho_Y+l_1+l_2)\le2E,\qquad E\ge2t.              \tag{9}
\]

The clean helpers enter through their zero output exponents. No argument
regards a helper's zero address block as an invertible target block.

## 4. Small-span normalization and the non-two-support cases

Every `C_s` lies in `S`: in the expanded diagonal entry of (1), its
surviving formal symbol is a subset sum of paid frames. Work over `K` and
choose a basis of the frame span from paid rank-one matrices,
`B_j=u_jv_j^T`, `j=1,...,d`. Since the span contains an invertible target,
Cauchy–Binet gives a set of `m` indices for which both corresponding
column matrices `(u_j)` and `(v_j)` are invertible. More explicitly,

\[
 \det\Bigl(\sum_j c_jB_j\Bigr)
  =\sum_{|J|=m}\Bigl(\prod_{j\in J}c_j\Bigr)\det U_J\det V_J,
\]

and this polynomial has a nonzero value at an invertible target. In
particular `d >= m`. This uses the rank-one-generated premise; an
arbitrary one-dimensional matrix space can contain an invertible matrix.
Common left and right coordinate changes make the chosen `m` frames
`E_11,...,E_mm`.

If `d=m`, all paid rank-one frames lie on those diagonal lines. Every
data target has a nonzero coordinate on each line. Projection onto a
line's coefficient has target-minus-identity rank `t`, so the line needs
at least `t` calls. The `m` call sets are disjoint and `k >= mt`.

Otherwise `d=m+1`, and the normalized span is

\[
 S_K=\{D+cB:D\text{ diagonal},\ c\in K\},\qquad B=uv^T.
\]

Write `J=supp(u) intersect supp(v)`. The following two cases do not need
any flag hypothesis on the targets.

**If `|J| >= 3`:** for distinct `i,p,q`, the minor of `D+cB` on rows
`{i,p}` and columns `{i,q}` equals `D_ii c u_p v_q`. A rank-one matrix
with `c != 0` has, for each `i`, distinct `p,q` in `J` other than `i`,
so `D_ii=0`. Every rank-one frame therefore lies on one of the independent
lines generated by `E_11,...,E_mm,B`. For each line, coefficient
projection bounds its call count below by the number of data targets
with nonzero coefficient on that line. Summing gives at least `mt`,
because any rank-`m` target needs at least `m` nonzero coordinates in a
rank-one basis. Zero helper exponents contribute no negative rank.

**If `|J| <= 1`:** put an arc `i -> q`, `i != q`, when `u_i v_q != 0`.
Every vertex on a directed cycle must be in both supports, so there is
no cycle. A permutation makes the entire space triangular. All data
targets have every diagonal entry nonzero. A triangular rank-one frame
has at most one nonzero diagonal entry: its principal 2-by-2 minor on
any two distinct nonzero diagonal entries would be nonzero. Projection
onto each diagonal entry again gives `t` calls in disjoint call sets.

## 5. The remaining two-support case

Suppose `|J|=2`. In the same directed graph, every directed cycle lies
in `J`; the two vertices of `J` have arcs in both directions. Thus the
strong components are one component of size two and `m-2` singletons.
After a permutation, the whole space is block upper triangular with
these diagonal block sizes.

A rank-one frame has at most one nonzero diagonal block. Indeed, write
it as `xy^T`; two nonzero diagonal blocks would make the corresponding
later row component of `x` and earlier column component of `y` nonzero,
forcing a nonzero block strictly below the diagonal. Assign a call to
its nonzero diagonal block, if one exists; calls with all diagonal
blocks zero are unassigned. These assignments are disjoint. Each target
has invertible diagonal blocks because it is block triangular and
invertible. Helper blocks remain zero.

The block filtration is invariant for every normalized target and for
its inverse when that inverse is used. Hence it is invariant for all
the normalized relative matrices. By (4) these relatives also have a
common complete flag over `K`. A common complete flag passes to an
invariant subquotient: for `U subset V` invariant, use
`((F_j intersect V)+U)/U`, delete repetitions, and note that each
successive dimension increases by at most one. This is a complete
common flag on `V/U`.

Consequently the relative matrices on the two-block have a common
invariant line. Write its data blocks as `B_s`. The relatives on that
subquotient are `B_1^{-1}B_s`. Choose a basis matrix `V` whose last
column spans the common line. Then

\[
 V^{-1}B_1^{-1}B_sV
\]

is lower triangular for every `s`. Apply the fixed left-right block
change `A -> V^{-1}B_1^{-1}AV` to the projected identity. It preserves
rank one and zero helpers. Section 3 gives at least `2t` calls assigned
to the two-block. Each one-block needs at least `t` calls by its scalar
projection. Summing the disjoint call assignments proves

\[
 k\ge 2t+(m-2)t=mt.
\]

This completes the theorem in all cases.

## 6. Consequences for two targets and commuting families

A single matrix over an algebraically closed field has a complete
invariant flag: take an eigenvector, pass to the quotient, and continue
by induction. Thus `I` and `C_1^{-1}C_2` always have a common complete
flag over `Qbar`, proving Corollary 1. A sharper field-size observation
is available: carry out the rank-one normalization and support split
over `Q` first. The only case that needs an extension is then the single
rational two-block of Section 5. A splitting field of that block
relative's quadratic characteristic polynomial has degree at most two
over `Q` and supplies its invariant line. Thus a quadratic extension
suffices for the entire two-target argument, even when `m > 2`. This
resolves both real and non-real irreducible quadratic cases.
No assumption of diagonalizability is needed; a repeated-root Jordan
block has its eigenline and still gives a triangular form.

A finite commuting family over an algebraically closed field has a
common eigenvector. To see this, take an eigenspace of one matrix; all
commuting matrices preserve it. Successively restrict to eigenspaces
of the remaining matrices within that nonzero space. Passing to the
quotient by the resulting common eigenline preserves commutativity,
so induction gives a common complete flag. This proves Corollary 2.
For a pencil, `C_s=a_s C_1+b_s C_2` implies
`C_1^{-1}C_s=a_s I+b_s(C_1^{-1}C_2)`, so the relatives commute.

These corollaries do not make any claim that a short word with span
`m+1` exists for every prescribed target family. They are lower bounds
for words meeting that span condition.

## 7. Sharp examples that have no rational flag

Let

\[
 C=\begin{pmatrix}1&0\\0&-1\end{pmatrix},\quad
 D=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad
 J=\begin{pmatrix}1&1\\1&1\end{pmatrix},\quad
 H=\begin{pmatrix}1&-1\\-1&1\end{pmatrix}.
\]

Then `C^{-1}D=[[0,1],[-1,0]]` has characteristic polynomial `z^2+1`.
It has no rational eigenvalue and hence no rational invariant line.
The target pair is therefore outside the rational-flag hypothesis.
Four legal rational calls attain the new bound: use frames
`E_11,-E_22` on the first data register and `J/2,-H/2` on the second,
with coordinate scalar projectors. Their sums are `C,D`, respectively;
their common rational span is the three-dimensional symmetric matrix
space. Any number of clean helper registers can be left untouched.

Over `Q(i)`, the proof's address changes can be made explicit:

\[
 P=\begin{pmatrix}1/2&i/2\\1/2&-i/2\end{pmatrix},\qquad
 Q=\begin{pmatrix}1&1\\i&-i\end{pmatrix}.
\]

Direct multiplication gives `PCQ=I`, `PDQ=diag(i,-i)`. The upper-right
projections of the four transformed frames are `1/2,-1/2,1/2,-1/2`.
Their projected product is identity. This is the cancellation that is
not available in rational target-flag coordinates but is valid over the
extended additive exponent group.

There are sharp examples for every `m >= 2`, `t >= 2`, and `r >= 0`
with no common rational target flag. In the two-block choose targets
`a_s C+b_s D`, with rational `(a_s,b_s) != (0,0)`, taking the first
two targets to be `C,D`.
Each has determinant `-a_s^2-b_s^2 != 0`, and all relative matrices
split in the above `Q(i)` coordinates. Each two-block target is a sum
of two rational rank-one symmetric matrices: if `a != 0`, use

\[
 \begin{pmatrix}a&b\\b&b^2/a\end{pmatrix}
 +\begin{pmatrix}0&0\\0&-(a^2+b^2)/a\end{pmatrix};
\]

if `a=0`, use `(b/2)J-(b/2)H`. Append `m-2` nonzero diagonal entries
to every data target and use one coordinate frame for each. This gives
exactly `mt` calls, with paid-frame span at most `3+(m-2)=m+1` and all
helpers unchanged. The absence of a complete rational flag follows
already from the irreducible quadratic factor in the relative matrix
of the included `C,D` pair. For `m=1` or `t=1`, ordinary diagonal
examples attain the same bound.

## 8. A genuine remaining no-algebraic-flag case

The matrices

\[
 C_1=I_2,\qquad C_2=\operatorname{diag}(1,2),\qquad
 C_3=\begin{pmatrix}2&1\\1&2\end{pmatrix}
\]

are invertible and lie in the rank-one-generated space `Sym_2(Q)`.
Their nontrivial relatives are `C_2,C_3`, with commutator

\[
 C_2C_3-C_3C_2=\begin{pmatrix}0&-1\\1&0\end{pmatrix},
 \qquad\det(C_2C_3-C_3C_2)=1.
\]

If they had a common invariant line over any extension of `Q`, their
restrictions to that line would be scalars and the commutator would
annihilate the line. Its nonzero determinant rules this out. Thus even
an algebraic address extension cannot supply the flag used in Section 3.

This case is not excluded by feasibility or the low-span premise. A
legal six-call direct word uses `E_11,E_22` for `C_1`, `E_11,2E_22` for
`C_2`, and

\[
 \begin{pmatrix}2&1\\1&1/2\end{pmatrix},\quad (3/2)E_{22}
\]

for `C_3`. All frames have rank one, their span has dimension three,
and arbitrary clean helpers may be retained. The executable verifies
this word and the invertible commutator. It is a rejection control for
an overbroad claim, not a counterexample to the conjectured six-call
lower bound. Whether a five-call word exists with arbitrary clean
helpers for such a nontriangularizable triple is left open here.

## 9. Sources, verification, and limits

The exact source commits and file hashes are in [SOURCES.json](SOURCES.json).
The immediate predecessor is Nick Petalas's
[PR #6698](https://github.com/CrocSwap/integer-mult-bounds/pull/6698),
head `e7b08ac9ef4ea5b5517d9d325ae6aeae445d3f91`, which proves the
zero-helper count under a common rational flag and explicitly asks for
the irreducible-quadratic two-target case. This note extends that premise.

Eumemic's PR #288 supplies the scalar-idempotent model; Ali Romman's
PR #468 supplies the triangular product factorization, coordinate
normalization, projections and two-dimensional flag count. Nick
Petalas's PR #5988 supplies the all-dimensional support split.
Unpaidmoon's PR #6338 supplies the clean-helper question and the
non-two-support cases. The source text's direct decomposition should
not be read as promising span `m` for every prescribed target family;
our sharpness statements use the explicit families above.

[verify.py](verify.py) uses exact rational arithmetic for Gaussian
rational coordinates and exact binary formal-group-algebra products.
It checks sharp irreducible-quadratic pairs, a commuting pencil family,
helper cancellation and missing-cleanup controls, address-field rank
preservation, the nontriangularizable triple, and a repeated-eigenvalue
Jordan control. These finite checks corroborate named steps; the
universal lower bound is the written argument above.

There is no claimed native implementation, caller or precision bill,
supplier admission, change to the selected kappa, complete integer
multiplication theorem, independent human review, or formal proof-kernel
verification. Frame span above `m+1`, interposed free address maps,
arbitrary dirty helper outputs, and the two-support case with no common
algebraic target flag remain outside the theorem.
