verify_tensor.py checks all 224 binary isometric embeddings of the
punctured E8 native-word interface into dimension 17, the eight-dimensional
spectator complements, rank-eight center descents, and the exact signed
port transport to the inherited Hamming prototype. Its source hash and
checkout-relative path are recorded in NATIVE-TENSOR-LIFT.json.

This is a complete common-frame lift conditional on the inherited native
scalar word and paid endpoint-normalization interface. The native word
itself is not replayed here. The construction does not establish an
improved exponent; the separate endpoint-cost package prices it.

The frozen clique fixture verifies a selected family of 135 orthogonal
eight-root cliques partitioning every orthogonal edge exactly once. It
gives a dyadic matrix identity, not a free circuit for that identity.

Run replay.py with a fresh output directory outside the checkout. NumPy
is required. The replay writes its complete regenerated receipt only to
that directory and compares parsed JSON with the frozen receipt. No Z3
installation is needed for verification. cliques.py is the optional
discovery program: it requires z3-solver and writes a possibly different
valid cover to a fresh external output directory. Its solve is bounded
at 45 seconds; discovery output is not the frozen verification source.

Prepared by DominikScholz with OpenAI GPT-6 Astra assistance in T3 Code. The inherited
Hamming-coordinate prototype comes from research/frame-sa504 and retains
the community provenance cited by the enclosing package.

Verification from the repository root (Python 3.11+ with NumPy):

  python3 -B research/niemeier-lattices/workbench/continuation/tensor-routes/replay.py /tmp/niemeier-tensor-normal
  python3 -B -I -O research/niemeier-lattices/workbench/continuation/tensor-routes/replay.py /tmp/niemeier-tensor-optimized

Both output directories must be new and outside the checkout. The -I -O
invocation propagates isolation and disabled assertions to every child.
The certificate replay takes approximately 0.1 seconds on the packaging
machine. No native supplier replay is implied by this runtime.
