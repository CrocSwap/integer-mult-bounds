# Changed entry frames

The frozen J builder previously overwrote hyperplane variants in its output
filenames. This experiment assigns a distinct name to every variant and screens
all 31 rank-four hyperplanes of the first-write rank-five cap for the 32 listed
hostees, with host 277 and the base orientation: **992 words**.

The search used the frozen builder and certified integer-surrogate frame solver
at `0.001717794984118634663827`. Every resulting word had a necessary direct
recovery rank of nine. The independent standard-library replay here reconstructs
the relevant frame/scalar edits and all **368,218** insertion-slot tests. It
reproduces every histogram without importing the builder or frame optimizer.

The induction is simple: each framed gate contains the current frame of every
operand; register chains are nested until a warp. An equality pin forces its
whole subspace at the preceding gate. Joining these lower frames therefore
remains a necessary condition under every refit. Warp events reset the lower
frame to their pinned output frame. The exact backward substitution represents
the pre-hosting value in the current registers. A contiguous sequence of adds
into one restored host must finish at a frame containing every participating
source's lower frame. Each tested slot requires rank nine.

`verify.py` also independently derives the base word's first-write caps and
checks every original literal frame lies between its computed lower and upper
bounds. `PINS.json` binds the consumed base word from J's branch at
`dfbc5ba121d5d23381393f178be8d4ba25ebfa4d` and the expected finite domain/results.
The package-level manifest binds all verifier and evidence bytes before replay.

Scope: the 32 explicit hostees, host 277, base orientation, unchanged scalar
graph and direct contiguous recovery. This does not exclude different hosts,
staged undo, changed source bases, new scalar circuits or different consumers.
The original experiment's frame certificates are not a native/owner admission.
