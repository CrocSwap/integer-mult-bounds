# Validation contract

verify.py is the offline entry point. A successful fresh run produces RESULT.json, per-stage logs, literal forward/backward scalar templates, a global owner/bank/phase template, the explicit bank assignment and final rational pricing receipt outside the source folder.

Checks include full1023-column complex replay in both orientations;1782 global F2 columns for the changed bit composition; arbitrary dirty helpers; private erasures; exact common frames; signed response equality; canonical Gaussian phases; two rank8 endpoint adapters;25056 bank assignments and actual inverse routes;1152 possible stage/replica/pair owner-injection checks; literal coefficient expansion; physical stock, row, routing, precision and finite-cost invoices; two exact moment engines with fallback and adjacent-grid exclusion; all47 strict outer constraints.

Negative controls omit required recovery/cancellation, omit bit bridge calls, alter record/witness inputs, overlap target pairs, omit endpoint/owner ingredients, or use a false route inverse. They establish sensitivity to these concrete faults, not completeness against all implementation bugs. No Lean kernel certification is claimed.

The independent bank and scalar reviews were written separately from their constructors. Their exact receipts bind their input hashes. SHA256 checks establish reproducibility, not mathematical correctness. The package manifest covers all supplied files except itself. Timings and local output paths are deliberately not part of the claimed result.
