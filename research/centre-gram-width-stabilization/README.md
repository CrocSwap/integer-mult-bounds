# The doubled centre Gram stabilizes by tensor width ten

**Scoped written proof with a finite certificate. No κ, no supplier admission.**

The pinned one-slot doubled centre Gram `A_1` of
[`research/exact-one-slot-gram`](../exact-one-slot-gram/README.md) has a family
`A_lambda = (1/4) sum_q r_q r_q^T tensor Gamma_q^tensor(lambda)` of higher
tensor widths. Open question 1 of that package asks for the exact minimal
polynomial at `lambda > 1`, "or is there a uniform upper-degree bound?"
Nick Petalas's merged [#6302](https://github.com/CrocSwap/integer-mult-bounds/pull/6302)
already proves a uniform degree bound `2^93` and eventual stabilization, without
a stabilization width. This package sharpens the degree bound to `2^47`, computes
the actual generated-group order, and proves stabilization by width ten.

**Theorem** (written proof in [PROOF.md](PROOF.md)). Let `G` be the group
generated by the 112 involutions `Gamma_q`, acting on the 2^18 Pauli labels by
signed permutations.

1. `G` is a finite 2-group of order exactly `2^44`: its image on labels has order
   `2^36` and its kernel has order `2^8`.
2. One real polynomial `mu` with simple real roots and degree at most
   `8|G| = 2^47` annihilates `A_lambda` for **every** `lambda >= 0`.
3. The degree `d_lambda` of the minimal polynomial of `A_lambda` is nondecreasing.
4. For every `lambda >= 10` the minimal polynomial of `A_lambda` equals `mu`.

Thus `881 = d_1 < 1093 <= d_2 <= ... <= d_10 = d_11 = ... = deg mu <= 2^47`
(881 is Krzysztof Wojt's theorem and 1093 is Ali Romman's bound, both cited).
The bound `2^47` is not a useful estimate. It shows only that the degree is
finite and independent of the width, and that the stable polynomial is the
minimal polynomial of one operator in the regular representation of `G`.

**Method.** Every `A_lambda` is the image of one fixed element
`x = sum_q (r_q r_q^T/4) tensor [Gamma_q]` of `M_8(R) tensor R[G]` under
`id tensor rho^tensor(lambda)`. That gives the universal annihilator. The common
fixed vector `I/sqrt 512` embeds `A_lambda` in `A_(lambda+1)`, which gives
monotonicity. For stabilization, every element of `G` has trace 0 or `2^(18-r)`
with `r <= 9` (the sign function is additive on the fixed labels), so the
character of `V` takes at most 11 values, and the classical Burnside-Brauer
theorem puts every irreducible of `G` inside `V^tensor(10)`.

## Claim types, kept distinct

- **Scoped written proof:** parts 2, 3 and 4, given the Bell identity (derived in
  PROOF.md section 3) and the Burnside-Brauer theorem (cited, not re-proved).
- **Finite certificate:** `d_A = 36`, `d_K = 8`, hence `|G| = 2^44`; the Bell
  identity checked exactly as integer 512-by-512 matrices on all 112 labels and
  1,792 pairs; the trace lemma and the order formula on two exactly enumerated
  groups; four rejecting controls.
- **Not claimed:** the value of `deg mu`, the values `d_2, ..., d_9`, any
  improvement of the bound 1093, a complete multiplication theorem, or any
  property of a physical decoder.

## Reproduce

From the repository root, standard library only:

```sh
python3.12 -I -W error -B research/centre-gram-width-stabilization/verify.py
python3.12 -I -O -W error -B research/centre-gram-width-stabilization/verify.py
python3.12 -B scripts/research_package.py --package research/centre-gram-width-stabilization
```

Each run takes a few seconds. The marker is
`PASS_CENTRE_GRAM_WIDTH_STABILIZATION`. The printed JSON lists `d_A`, `d_K`, the
group order, the number of possible trace values and the two toy groups. The
pinned query is `INTERFACE.json` with SHA256
`5c6c51fbffc07a683e922f17532fd90262ae9e23cc3560a696002073dd234ef3`.

## Limitations

- The stabilization width 10 is an upper bound from counting possible trace
  values. The true width may be smaller.
- The proof gives no information about which irreducibles of `G` occur in
  `V tensor V`, so it does not determine `d_2`.
- `mu` depends on the matrix `R`; the existence and the degree bound use only the
  112 labels. The theorem holds for any real 8-by-112 matrix in place of `R`.
- No independent human or proof-kernel review is claimed.

## Open next questions

1. **Which irreducibles of `G` occur at widths 2 through 9, and what are `d_2`,
   ..., `d_9`?** This is the unequal outer-label question left open by
   `research/equal-bell-two-slot-spectrum`, restated as a finite
   representation-theory problem. First step: use the exact normal series
   `K` (dimension 8) by `A` (dimension 36), compute the orbits of `A` on the 256
   characters of `K`, and list the stabilizers. Blocker: the projective
   irreducibles over the stabilizers can be large, and each needs the exact
   spectrum of an operator of size `8 dim(pi)`.
2. **Can the stabilization width be lowered from 10?** First step: find which
   ranks of `M_S = sum over S of q q^T` occur in the 36-dimensional span, and
   which trace values `2^(18-r)` occur on `G`; each value that never occurs lowers
   the Burnside-Brauer width. Blocker: the span has `2^36` elements, so this needs
   an orbit or invariant argument rather than enumeration.
3. **Can `deg mu` be bounded far below `2^47`, or lower-bounded above 1093?** First
   step: build one small irreducible of `G` from a character of `K` with a large
   stabilizer and compute the exact spectrum of its `x_pi`, to find eigenvalues
   outside the 1093 already known. Blocker: the size of `pi` and the cost of an
   exact characteristic polynomial.

## Verifier constraints

The verifier reads the fixed source files and writes nothing. It uses no
recursion, subprocesses or network access. The actual calculation has 112
generators, at most 6,292 relation and commutator words, and an 18-dimensional
kernel module. Its closure queue processes at most `6292 + 18*112` vectors.
Full group enumeration is restricted to the two toy fixtures, with at most
2,048 signed permutations on at most 256 labels. All functions are below
60 lines. Explicit exceptions preserve acceptance checks under `-O`.

Power-of-ten rule 3 deviation: CPython allocates integers and containers during
checking; the fixed domains above bound their live sizes. Rule 9 deviation:
the rejection helper invokes two fixed local lambdas. Both registered modes
use `-W error`. No independent static analyzer or proof-kernel check is claimed.
