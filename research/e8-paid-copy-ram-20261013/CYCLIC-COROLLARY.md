# A source-bound cyclic-Fourier transfer from the accepted tensor-E8 provider

**The exact-RAM cyclic transfer can be instantiated.** The accepted depth-one
tensor-E8 Gaussian kernel provider meets the actual positive-kernel interface
of the pinned exact-DFT source. With that source's specified-root and field
operation hypotheses, it yields a deterministic exact cyclic DFT at every
length N in

```
O(N*(log N)^(14999/15000)*(loglog N)^(45001/15000))
  = O(N*(log N)^(1-1/30000)) eventually.
```

All scalar preparation, scheduling, sector packing and integer indexing are
charged in this RAM statement. One explicitly specified canonical root of
order D_*<1024N^3 suffices. This proof supplies the transfer missing from the
recovered E8 package; it does not rewrite that package's earlier scope verdict.
No finite-alphabet multitape or integer-multiplication bound follows.

There is also a precise counterexample to omitting the root hypothesis:
the original root-free E8 Q(i)-constant machine cannot compute F_3 even on
x=(0,1,0). The source's supplied-root interface is an essential repair,
not something generated by the Gaussian–Walsh program.

## The fully instantiated theorem

Use the following RAM:

1. Exact complex cells with unit-cost field addition, subtraction,
   multiplication and division by a proved nonzero value, and charged
   indexed reads/writes. Division is needed in scalar preparation and is
   explicitly admitted by the pinned exact-DFT model. The original E8
   provider uses a subset of these operations.
2. A fixed number of O(log(N+2))-bit integer words per register, with the
   source's unit-cost arithmetic, quotient/remainder, comparison and
   indexing. Arrays, scratch initialization, copies, clears and traversal
   are charged. Constants are absolute after choosing depth one.
3. The canonical root zeta_(D_*)=exp(2*pi*i/D_*) is supplied as one exact
   complex input, or returned by the model's specified-root operation.
   The order D_* is computed below and is polynomially bounded in N.
   No other root oracle or arbitrary algebraic-number operation is used.
4. Complex coefficients and intermediate magnitudes are unrestricted.
   There is no binary precision or numerical-stability premise disguised
   as unit-cost exact arithmetic.

For every N>=1 and every x in C^N, one deterministic program computes the
unnormalized positive-exponent F_N x exactly within the bound at the start.
The program is input-linear: the chirp operand is fixed and its preparation
is paid. Three forward transforms, pointwise products and reversal/scaling
also give full convolution of two length-N complex vectors in the same
asymptotic bound, with one supplied root of order below 8192N^3. That latter
algorithm is bilinear, since its pointwise products multiply two variable
operands. These are exact arithmetic/RAM statements.

The tensor provider is completely fixed at architecture depth one:

## Proof: the exact-width local interface

The local compiler must preserve width; padding each Fourier axis would
multiply the total tensor dimension. The source actually proves a polynomially
preparable word on **exactly r coordinates** for every F_r(u), primitive u.
It uses O(1+log^4 r) synchronized monomial or ordered-pair C slots. This is
the required interface, rather than a generic analogy between WHT and DFT.

For H_j=product_(s=1)^j(1-u^s), H_0=1, the Newton matrix has

```
N_ik=(-1)^k*u^(k(k-1)/2)*H_i/H_(i-k)   for i>=k,
F_r=N*diag(N_00,...,N_(r-1,r-1))^(-1)*N^T.
```

No denominator H_j vanishes for j<r. N is a diagonally gauged lower
triangular Toeplitz matrix and its transpose; these are the actual source
operators. This step does not use PR628's cyclic inverse or confuse it with
the triangular inverse.

The source compiles a triangular Toeplitz block by recursively applying its
two diagonal blocks and a cross shear E=B*T_p^-1. Reciprocal coefficients
g_j are prepared by a finite recurrence dividing only by the nonzero
Toeplitz diagonal h_0. In the cross block,

```
E_ij=sum_(nu=j)^(p-1) h_(i-nu)*g_(nu-j),
E_ij-E_(i-1,j-1)=-h_(i-p)*g_(p-j).
```

A rectangular chunk's shift displacement is thus three explicitly formed
outer products: the displayed interior product plus a first-row and a
first-column correction. Nilpotent telescoping reconstructs the chunk from
two fixed-vector convolutions per term. Ordinary small binary FFTs supply
bounded-fan-out, O((a+e)log(a+e)) gate DAGs of O(log(a+e)) depth. This is
local preparation at polynomially small widths, so there is no circular use
of the desired global cyclic transform algorithm.

The dirty-coordinate replay lemma realizes each such linear DAG using
existing arbitrary coordinates: a forward sweep creates Uz+Tx, output
reads add Mx+FUz, inverse shears restore z, and a second source-free
forward/output/inverse sweep subtracts FUz. Direct-source output reads
are included only in the first output round. Hence every borrowed value,
including correlated values, is restored. Bounded-degree coloring gives
O(depth) pair layers. The source measures each printed DAG and chooses
chunks satisfying g+a+e<=parent width. A sufficiently large chunk of order
r/log r fits; bounded small widths use the explicit direct fallback.
Serial O(log^2 r) chunk pairs and balanced recursion give O(log^4 r)
layers. The measured fit search, scalar DAGs and integer coloring/scans
all use r^O(1) preparation, with an absolute exponent.

The special positive C is sufficient without invoking abstract Zariski
generation. Write a0=(1+i)/2, H'=[[1,1],[1,-1]], S=diag(1,i).
Direct multiplication gives H'=a0^-1*S*C*S and

```
H'*diag(2,1)*H'*diag(-3,1)*H' = [[-8,-10],[0,-6]].
```

Diagonal conjugation by diag(4t/5,1) and normalization produce the upper
shear of nonzero coefficient t using exactly three forward C calls.
For any prepared coefficient mu, including zero, put
s=1+mu*conjugate(mu), t1=s, t2=mu-s. Both are nonzero because
1+|mu|^2>|mu|. Their two shears give the desired coefficient with a
fixed **six-C** slot pattern. An update target+=mu*source uses ordered
pair (target,source). No complex zero decision is required.

The conjugate is obtained by reevaluating the coefficient's arithmetic DAG
with each supplied root inverted and i replaced by -i; rational literals
are real. No conjugation of variable data is performed. The scalar
programs retain shared subexpressions and every divisor has a nonzero
proof. The ordinary small-FFT auxiliary root has order
2^ceil(log2(4r))<8r. This proves the full local preparation/root interface
used by the transfer, not merely an existence factorization.

## Proof: synchronized sectors and their actual address cost

Compile each Fourier axis into the common O(log^4 r_max) slot pattern.
At a monomial slot, a mixed-radix prefix traversal maintains the original
address, permuted address and cumulative scalar. The number of digit
prefixes is less than twice the full array size R, since every radix is
at least two. Therefore scalar products and indexed array movement cost
O(R), rather than O(R) separately for every axis.

For a simultaneous pair slot, a sector chooses one local ordered pair or
singleton on each axis. Let q_j be its width, p_j the cumulative coordinate
width of preceding blocks, t_j its within-block digit, and
tau_j=product_(i>j)r_i. The pinned source's packing address is

```
sector start S=sum_j (product_(i<j)q_i)*p_j*tau_j,
within-sector offset o in radices q_j,
packed address S+o.
```

Maintain S,Q,o,I during one digit-prefix traversal, updating
S+=Q*p_j*tau_j, Q*=q_j, o=o*q_j+t_j, I=I*r_j+a_j.
No complete tuple is recomputed per entry. Block-prefix traversal likewise
lists sector starts, widths and pair counts in O(R); even an axis with only
one block is covered by the digit-prefix bound. Pairs need not be consecutive
in the original axis. All computed addresses stay below R and use O(log R)
bits. Packing, unpacking and width-one identity sectors are charged.

A width-2^k sector carries exactly C tensor k. Calling the accepted
provider costs O(2^k(k+1)^alpha). Since k<=ell and widths sum to R,
the total cost of a pair slot is O(R(ell+1)^alpha), with O(R) packing
work. Sequential sector calls reuse private workspace; their peak workspace
is O(R). Tensor multiplication of the local slot words proves the whole
operator, even when one axis changes another word's currently borrowed
coordinates: each local word is correct on arbitrary inputs, and products
of tensor factors obey the exact tensor-product identity.

Thus the source synchronization proposition is valid with the new alpha:

```
tensor_j F_(r_j):
 O(R*(ell+1)^alpha*(1+log r_max)^4)
 +poly(ell,r_max,log(R+2)).
```

The polynomial covers actual compiler/root/table preparation only;
full-array scalar products are already charged in the prefix traversal.
The original network-specific theta is not an additional requirement.

## Proof: all lengths, one root, and no free fixed convolution

For the requested N, take the longest initial product R_ell of odd primes
not exceeding 2N. Let e be the least nonnegative exponent such that
L=R_ell*2^e>=2N. Then 2N<=L<4N, 2^e<2*r_(ell+1), and
e=O(log(ell+2)). The source's elementary central-binomial estimate
supplies r_j=O((j+1)^2); factorial lower bounds give
log R_ell=Theta(ell log(ell+2)). Hence
ell=Theta(log N/loglog N), and all odd local widths and the residual
power of two are polynomial in log N. Trial division/product construction
is also polynomial in log N with O(log N)-bit integers.

For each coprime factor q of L choose d_q=(L/q)^-1 mod q and
E_q=(L/q)*d_q. The idempotents E_q give the exact CRT identity

```
zeta_L^(jk)=product_q zeta_q^(d_q*j_q*k_q).
```

Multiplication of the local output digit by d_q is a permutation. The
CRT array permutations use local tables and one accumulated-sum prefix
traversal, so their charged cost is O(L). No per-entry scan through all
factors or uncharged group-index lookup is used.

Synchronize the odd-prime axes and apply the ordinary radix-two transform
to the remaining small power-of-two axis. The cost of F_L and its inverse
is

```
O(L*(ell+1)^alpha*(1+log(ell+2))^4 + L*(1+e))
 +poly(log(N+2))+O(1).
```

The inverse is L^-1*J*F_L, J negating indices modulo L, so it needs no
new negative-kernel provider. Normalization and reversal are charged.

With eta=zeta_(2N), the positive-exponent chirp identity is
zeta_N^(jk)=eta^(k^2)*eta^(-(k-j)^2)*eta^(j^2). Prepare the length-L
input vector eta^(j^2)x_j and the fixed kernel eta^(-u^2) at residues
u=-(N-1),...,N-1. These residues are distinct, so the relevant convolution
has no alias. Three length-L transforms, their pointwise multiplication
and final chirp scaling produce F_N x. In particular, transforming the
fixed kernel is charged as a whole transform; it is not supplied as a
precomputed oracle. Successive chirp ratios generate the scalar tables
in O(N) work.

Set, exactly as in the source,

```
D_*=(2N)*L*2^ceil(log2(16L)) <64*N*L^2 <1024*N^3.
```

This order is divisible by 2N, every working factor order, and every
power-of-two auxiliary order required by the small compilers. Extract
their canonical roots by binary powering the one supplied zeta_(D_*).
Extraction and all local coefficient/schedule preparation are polynomial
in log N. Integer root orders, products, array addresses and chirp index
squares are polynomially bounded in N; fixed architecture tables add
absolute constants. A fixed number of O(log(N+2))-bit words suffices.
The direct formula handles the finite initial range without asymptotic
assumptions about ell. The algorithm is deterministic and halts at all N.

The resulting estimate is O(N*ell^alpha*(log ell)^4), plus negligible
polylogarithmic setup. Substitution of ell gives
O(N*(log N)^alpha*(loglog N)^(4-alpha)). With alpha=14999/15000,
4-alpha=45001/15000. Any saving eta0<1/15000 absorbs the fixed
loglog power eventually. Choosing eta0=1/30000 yields the displayed
simple bound. This is a fixed architecture, absolute-constant theorem;
it does not claim a bound uniform while architecture depth grows with N.

For two-input convolution, use length 2N-1 with zero padding. Three
transforms, general pointwise products, reversal and scaling produce the
full convolution. Reuse the one specified root for that length; its order
is below 1024(2N-1)^3<8192N^3. This establishes the convolution corollary
in the same exact-RAM model, without converting it to integer bit work.

## The exact root-free obstruction and repair

Every constant and operation in the original recovered E8 algorithm lies
in Q(i): rational roots/coefficients, the Gaussian kernel, Z4 phases,
addition and multiplication. Even granting division leaves a field
operation computation on Q(i) inputs inside Q(i). Integer address
computation cannot introduce a new complex algebraic constant.

At N=3, x=(0,1,0) has entries in Q(i), but F_3 x=(1,zeta_3,zeta_3^2).
Here zeta_3=(-1+i*sqrt(3))/2 is not in Q(i), since sqrt(3) is irrational.
For completeness, a rational square root a/b in lowest terms would imply
a^2=3b^2, forcing both a and b divisible by three. Therefore a root-free
Q(i)-constant version cannot compute this target exactly. This is a
source-specific constant-field counterexample, not a lower bound for RAM
algorithms granted the source's canonical root.

The repair is precisely the model hypothesis instantiated above: supply
zeta_(D_*) and allow the source's paid exact field preparation. Roots of
arbitrary order are not inferred from C_1 or WHT identities. The theorem
uses no hidden approximate root finder, zero decision, algebraic search
or arbitrary-coefficient oracle.
