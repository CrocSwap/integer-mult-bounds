# Warm-donor synthesis with transported endpoint repair

This is a sufficient constructive extension, not an achieved kappa bound. The one/two-donor screen on the new public354 word returned no match; an arbitrary-basis screen is separate.

Assume the target subsystem is terminal: target values are never read into sources/helpers or copied non-target centers. This syntactic condition is checked on the actual word. At a cut c, a cold pivot p contains exactly its initial dirty value hp and its initial zero-frame READs have finished. Let Qp be those READs' final target response, transported through the actual target suffix. A warmed donor d may already hold clean source data and arbitrary dirt. Its response Fd(c) is the exact suffix target response to adding one independent unit to its value at c.

If explicit integers alpha satisfy Qp=sum alpha Fd(c), delete only p's READs and inject d+=alpha hp at c. The signed target map is unchanged, by linearity; existing donor contents need not be zero.

To close every other output, propagate the injected unit vector through the literal suffix, obtaining endpoint change N. Require source-output entries N_X=0; require N_p=0; require the original pivot endpoint is exactly hp as a row on every initial scalar input; and require every helper with N_r !=0, together with p, has final FULL frame. Append r-=N_r*p at FULL for every such helper. The pivot value remains hp throughout these tail repairs because N_p=0. The target perturbation has already canceled the removed READs; the helper perturbation is canceled entrywise. Hence the entire modified signed scalar map agrees with the original, on arbitrary initial inputs. No uncomputed endpoint inverse or unspecified oracle is assumed: N and the pivot endpoint row are explicit exact forward/backward simulations.

For geometric permission, all setup donors have actual current frame E at c, E is nondegenerate and contained in p's first frame, and c precedes p's first physical MOVE. Give p entrance E and change its first jump from 0->Fp into E->Fp. Its clean-source value is zero at the setup, so all new operand source spans remain in E. Donor movements are unchanged. Setup coefficients and all transported FULL tail repairs are unit-expanded and charged; the pivot loses one rank-k child when E=Fp, or its first child rank decreases by k=dim E. Endpoint residual stock decreases consistently by k and must be recomputed with actual bank tiling.

For multiple simultaneous families, separate target equations are insufficient by themselves: later pivot values and endpoint references can acquire cross terms. Require pairwise disjoint selected pivots/donors and zero transported perturbation on every other selected pivot endpoint; also check the actual emitted full map independently. This is an explicit interaction condition, never a free assertion that independently priced gains add.

This opens a representation absent from the earlier cold-only kernel witness: dynamic donor columns plus concrete transported endpoint repair. It does not claim the existence of a productive warm family on today's word, nor historical first-ever conjugation in mathematics.
