## Sufficient construction

Fix a signed linear scalar word and a common cut. A cold helper has its original zero entrance, has only compensated initial helper-to-target READs before the cut, has its last READ before the cut, and has its first physical MOVE and first non-READ use after the cut. Select disjoint pivot and donor helpers meeting these conditions.

For helper r, let T_r be the exact initial-helper-to-final-target response of the original word. Let Q_r be its initial READ contribution transported through every subsequent signed target operation. The actual suffix response available at the cut is F_r=T_r-Q_r. Raw READ incidence sums are not assumed to equal Q_r.

Supply explicit bounded integer rows satisfying Q_p=sum_d alpha[p,d]F_d for each pivot p. Delete the pivot's initial READs. At the cut perform helper_d += alpha[p,d]helper_p. Donor and pivot sets are disjoint, so every pivot still contains its unchanged dirty input. The removed target contribution is -Q_p times that input and the setup contributes sum_d alpha[p,d]F_d times the same input. The two cancel. All original source and signed target maps are preserved on every initial scalar input. This is a sufficient proof, not an assumed recovery oracle.

Give every pivot a registered nondegenerate common entrance cap E contained in its original first frame F_p. Each distinct donor moves0-to-E once, receives all setup ADDs there, then follows E-to-F_d in place of its original0-to-F_d MOVE. All original later scalar gates remain. The pivot's first MOVE similarly becomes E-to-F_p. Cold interval checks and E contained in each F_r give literal setup permissions and nested paths. Helper endpoints, COPY lifetimes, arbitrary physical dirt, geometry, source spans, bank completion and exact supplier pricing are independently rechecked on the changed word; target-response algebra alone does not prove these additional contracts.

For cap rank e, each pivot changes its local child invoice by +child(f_p-e)-child(f_p). Each distinct donor changes it by +child(e)+child(f_d-e)-child(f_d). Rank-zero children are omitted. Integer coefficient alpha is realized as abs(alpha) signed unit ADDs at the same cap; every ADD is charged. Even coefficients do not require extra recursive children, because no operand frame changes between their repeated ADDs.
