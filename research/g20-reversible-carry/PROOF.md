# Exact inverse histories for the current G20 carry producer

The source is PR6503's 23 quotient machines, derived from PR6474's carry
invariant. Their original endpoint and minimum-state proofs remain predecessor
work. This result supplies a reversible transition record and a complete
forward/copy/reverse protocol at an explicit logical table interface.

## Sharp history for a fixed quotient transition

Fix a model and a known input letter a. Its retained transition is f_a:S->S.
For each target t, list f_a inverse(t) in increasing source-state order. Store
j, the index of s in that list. The pair (f_a(s),j) determines s exactly.

Let H_a=max_t |f_a inverse(t)|. The minimum fixed history width for this
transition contract is ceil(log2 H_a). The construction attains it. To prove
necessity, hold a and t fixed at a largest fiber. A reversible extension that
retains this literal target-state register, leaves the input unchanged and
starts with fixed auxiliary data must distinguish all H_a predecessors in its
history. Fewer than H_a history values cannot do so. This is elementary
injectivity, not a new information theorem.

The checker visits all 304,894 source edges. It checks the target, history
range, pairwise injectivity, literal inverse lookup and a largest-fiber witness
for every letter. It checks both inequalities that define the minimum width.
The largest fiber has 20 states. Five history bits are necessary and sufficient
for the worst quotient transition. Many letters need fewer. This does not prove
a minimum for the full canonical-input packet machine: other registers and
valid-prefix restrictions can carry information about its quotient state.

INVERSE.bin stores one byte per forward history rank, 16-bit prefix offsets,
and 16-bit predecessor labels. INVERSE.json records widths and largest-fiber
witnesses. Storage is paid explicitly; a 5-bit history does not make an 8-bit
rank-table entry free. Exact regenerated bytes must match both artifacts.

## The complete producer

The eight input comparisons have c_i in {-1,0}, initially zero, and update
c_i'=floor((c_i+x_i_bit-q_bit)/2). Represent c_i by v_i=c_i+1. If the two
input bits agree, v_i'=v_i and no history is needed. Otherwise v_i' is the
known input bit x_i_bit, and one saved bit v_i restores the old comparison.
The implementation packs only these collapsed comparison bits after the
known-letter quotient history. The separate bounds give 5+8=13 bits, but this maximum cannot occur in the
released columns. The exhaustive 729-column by 512-row certificate binds the
aggregate letter to the comparison bits and gives at most 12 bits per row.
A witnessed row has 13 quotient predecessors and eight collapsed comparisons.
On the unrestricted product of the quotient and comparison state spaces, that
row has 13 times 256 = 3328 predecessors for one target. Since 2048<3328<=4096,
12 bits are necessary and sufficient for this full product-state row contract.
Reachable canonical prefixes can correlate those states; this is not a global
minimum-history result for the initialized packet producer.

The first two rows update N modulo d by addition modulo d, where d is 1 or 4.
The second radix bit is copied by XOR. These operations have direct inverses
and need no overwritten-state history. The source formula computes the carry
from the final quotient, this residue and q modulo 4. It retains the original
five-bit packet for every valid canonical input.

A sixth output bit reports validity: the input is nonempty, its first and last
radix bits are one, and every final comparison is -1. Output is XORed into a
six-bit dirty target. Invalid canonical inputs still follow the return protocol;
their packet bits are unspecified and their validity bit is zero. Ill-typed
host objects are outside the bit-stream contract and are rejected.

After output copy, read the same immutable rows in reverse order. Undo the
residue updates and radix copy. Restore each collapsed comparison from its
saved bit. Use the target state and quotient history to read the old state.
Check the literal forward edge and its history again. XOR the reconstructed
history value into its record. Every record becomes zero; nothing is discarded.
The final state and comparisons equal their prepared constants. XORing those
constants out leaves zero. The diagnostic history counter is decremented by
the same known widths and also returns to zero. The packet and input rows stay
unchanged. Determinism and the per-edge inverse proof give this result for any
finite well-typed stream, including invalid canonical inputs.

This is an injective logical protocol on clean work registers and arbitrary
dirty outputs. It is not yet a Boolean gate network or a tape implementation.
A physical implementation must lower the table queries and arithmetic and
must preserve the source rows through the reverse pass.

## Exact ledger and scope

For L rows, there are 2L row accesses and 7L+1 logical table queries. A forward
row reads its target and history rank. A return row reads two prefix offsets,
a predecessor label, the forward target and its rank. Output reads one entry.
For a w-bit quotient-state index, table reads total (2w+64)L+5 bits, at most
88L+5. Constant preparation and return cost 2(popcount(start)+8) bit flips.
These counts exclude arithmetic gates, address computation, physical head
travel and table implementation. They are not a complete ordinary-work tariff.

The retained forward table has 464,866 bytes. The inverse table adds 1,525,010
bytes and its descriptor/witness file adds 17,093 bytes. The old forward metadata
is also retained. These fixed bytes cannot be treated as free physical storage.
The old producer's 26-bit state count is cited context, not a bound on Python
heap allocation or the whole restored implementation. History uses at most 12L
logical bits. Input storage, row cursor, lookup scratch and audit counters must
also be charged in a concrete implementation. No overall physical-space optimum
or runtime improvement is claimed.

The new output has a validity bit as well as the old packet. This is an explicit
interface extension. There is no automatic consumer substitution. If a later
consumer changes the source low digits, the return pass cannot silently use
those changed rows. Post-consumer packet retirement needs its own source or
recovery contract. No selected-frontier or kappa change follows from this result.

## Evidence and credit

The exact source catalogue contains 444 routes and 3,552 columns, with 729
distinct columns. Each distinct column is tested at five radices against an
independent modular-inverse oracle. All 49,449 active q=3 inputs, all 373,248 source-row patterns, all 64 dirty
outputs for every model, invalid canonical inputs and 23 4,097-bit cases run
through full restoration. Source corruption, inverse payload corruption,
missing/oversized history, wrong input rows and impossible fiber ranks reject.
Normal and optimized checks use explicit exceptions.

Reversible embeddings, predecessor ranking and compute/copy/uncompute are
classical. PR6474, PR6503, the fused G20 construction and their full retained
lineage keep their scientific credit. Ali Romman supplies this protocol, exact
finite certificate and source binding with substantial OpenAI Codex assistance.
Apache-2.0. This is author-checked evidence, not independent human acceptance
or discharge of any of the five framework assumptions.
