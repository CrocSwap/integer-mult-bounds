# A completed selected complex layer

We propose a written all-size construction for the selected R480/T16 complex
layer, with time `O(V d^(599/600))` on the stated spaced-axis/long-record
domain. We close the recursive complex-child, row/work and common-grid
precision contracts. We use the pending completed ordinary-interchange
construction in PR2234 and the compact monomial implementation in PR2250.

[PROOF.md](PROOF.md) gives the algorithm and its quantified conditions.
It applies the common-label argument to both the literal local word and
the global nine-stage controller. It retains all phase translations,
including 6,822 cases whose idle child has no positive-rank remainder.
The height induction uses completed child endpoints and one root precision
grid, with no rounding at child returns.

We leave the selected frontier unchanged. The rate is a coarse layer rate,
not a new optimized supplier root or an integer multiplication exponent.
The ordinary-callee and adapter predecessors remain under review.
