## Universal argument reviewed

For a productive role with rank k, an occurrence at paid path p, dilation
rho and target profile alpha has actual job rank s=rho*c(alpha)*k.
Substituting that expression into the inherited parent-fit condition gives
the exact nonroot freshness test A*s>N*r_last. Substituting into the unit-fit
condition gives A*s<=N*k. Both substitutions use positive divisors; equality
is admitted as parent fit and therefore is not fresh. The role's bare k,
the profile degree and the source-row index cannot replace s.

At fixed state and s, the required target word product is s/(rho*k).
The weighted product table counts all ordered native role words with that
product. Multiplicative collisions add counts, and W_k retains distinct
productive role names. Thus the local formula counts exactly the eligible
source occurrences. There is no loss of profile or role identity when those
statistics share a count table; ranking later scans the separate ordered
profile intervals. The subtree recurrence adds each actual paid child's
source interval; equal paid ranks are multiplied by their occurrence count.
The last paid rank remains in the state and freshness test.

The candidate rank set is complete: an actual source product combines h
paid factors with G-h+1 target factors, the latter degree being positive.
Stars and bars gives the displayed Q0 bound including its omitted zero-target
term. At the root, k_min^(G+1)>N/A. At nonroots freshness and r_last>=1 give
the same strict lower band; fit and k<=A give s<=N. Neither filtering step
drops a source. Constructing and charging zero-count candidate DPs is explicit.

The restricted order is exactly the inherited source order filtered by s:
actual paid-path preorder, then profile, unit ordinal and native role-list
order. The local blocks and actual child intervals form disjoint half-open
intervals. Ranking adds preceding intervals; unranking selects the unique
containing interval and decreases the remaining subtree depth. This proves
the inverse maps without treating equal products or rank statistics as equal
physical occurrences.

For replica b, original source u, bucket ordinal r_s(u) and bucket count S_s,
the grouped ordinal is x=b*S_s+r_s(u). Its image is [0,a*S_s). If s<N,
divmod(x,B_(N-s)) is a bijection onto whole invocation/slot rectangles exactly
when B_(N-s) divides a*S_s. If s=N, the separately typed NoComplement port
carries x and invokes no smaller program. Reversing these formulas restores
b and the unique bucket source before applying the old source-row codec.
Namespace, true source rank, paid path, unit ordinal, native role and replica
remain distinguishable. Owned banks and matched interior targets are outside
the fresh productive source domain.

The source note's initial complement phase authorizes grouping these sources
before flow execution. The package correctly leaves chronological exit
batches separate and does not infer a sufficient complete replication factor
from complements alone. The prior gcd/LCM formulas in #4507 and
`symbolic-integer-batch-width/PROOF.md` are explicitly credited and not claimed
as new. Likewise, rank equality does not supply coordinate adapters, transport,
restoration or an actual smaller native program.

## Deterministic metadata and space audit

New product-count and state tables use sorted keys and deterministic binary
search. Equal product contributions are aggregated by addition; there is no
growing data-dependent hash table in the new count DP. The unchanged codec's
hash operations are confined to the supplied finite specification, whose
worst-case quadratic cost is charged by S_bit. The source-index dependency
is the repaired deterministic package previously reviewed in this run.

The product table stores through degree G+1 and allows d times the previous
degree's contributions before sorting. The candidate count Q0 charges all
remaining zero and positive bucket candidates. An active bucket's local and
subtree tables occupy O(R) records. Replacement can briefly double that
constant, which does not change the displayed O-space envelope; retaining
all queried buckets is expressly outside the claim.

The bit bound includes the complete supplied library widths and replication
factor. Subtree counts, replicated indices, candidate products and lookup
keys fit its declared O(B) envelope. Indexed metadata and a conservative
serialized full-scan/insertion simulation are separately priced. The latter
charges travel and rewriting and is a companion construction, not a claim
that the Python interpreter is a fixed-tape dispatcher. Actual payload work,
library generation and expanded native program size remain outside this
metadata theorem and are named as such.

No author freshness inequality supplies that expected classification. Word
