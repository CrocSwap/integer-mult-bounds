# Oracle first-run independence and exposure

Status: independently authored execution model, with deliberately shared
authenticated original construction. This is source-aware AI work, not an
unexposed discovery, independent end-to-end construction or human acceptance.

I authored `ORACLE/oracle.py` from the common immutable instruction, fixture,
observation and certificate contract. Before both sealed firsts completed, I
did not read a peer engine, peer output, original source checker/observer or
source expected-output function, and did not execute/import/compile either my
engine or a source fixture. Earlier session04 written work had exposed the
original recursive constructor text, proof/contract and retained initializer
excerpt. That source awareness is retained, not described as blindness to the
underlying construction. The full source checker remained inert and its raw
bytes were authenticated without reading or executing its expected/observer
implementation.

The oracle uses dense physical byte arrays and separate visited-position
bitmaps, with its own literal branch/write/unit-move/goto/HALT/reject
dispatcher. Its expected endpoint follows each original root index iteratively:
split the index as `(a, low, r)`; an internal low outside `{0,1}` gives no
flip; otherwise replace the index by `a*R+r`, set `A <- A/(L*H)` and
`R <- H*R`, and continue to the leaf, which flips exactly low0. This does not
recursively transform any expected bit vector. Expected data never select a
runtime branch, head or tape. Actual whole parent payload/control/phase
objects, observed grant bit lists, protected changed output, all final cells
and heads, and persistent visits are independently collected and checked.

Both engines intentionally share the five authenticated original constructor
files and the original table. The oracle authenticates all 14 source objects
by raw size, SHA256 and Git blob, then imports the original constructor and
calls `R.build(4,3,1)` once. It compares the complete normalized constructed
program and metadata with the retained table before interpreting instructions.
No source Machine/Tape instance, source step/run or source checker/expected
function is invoked. Shared constructor and common contract defects therefore
remain shared dependencies; agreement cannot certify them independently.
