# Movers miss the 8-dimensional dihedral summand

This is an exhaustive finite census, together with an exact rank computation
over `Q`, for one subspace of the historical one-slot doubled centre block at
Bell label `c=1`. It is not a characteristic polynomial, not an annihilator of
the full one-slot operator, and not a multiplication bound.

The selected conditional kappa stays `781451/250000000`.

## Operators and the group

The input is the 8-by-112 query retained by
`research/centre-polynomial-cache-limits/`. Its columns lie in `{-1,0,1}^8`,
each has weight 4, and `R R^T = 56 I_8`. The 112 port labels are distinct odd
vectors in `F_2^9`.

A signed coordinate permutation acts by `(S v)_k = eps[k] v[inv[k]]` and by
the linear port map `T` that carries each port to the port of its image
column. On `R^8 ⊗ R[F_2^9]`, of dimension 4096, the operator is `S ⊗ U_T`.
Both factors are monomial with nonzero entries `±1`, so the operator is
orthogonal for the standard Euclidean product. Its trace is

    tr(S) · 2^{nullity(T - I)}.

Let `W` be the hyperoctahedral group of signed permutations of the eight
coordinates, of order `8! · 2^8 = 10321920`. Let `A` be the subset that sends
every query column to a scalar multiple of a query column. The 13 signed
permutations used as generators in `research/exact-one-slot-gram/` lie in
`A`. Their generated subgroup has order `344064`. The left cosets of this
subgroup in `W` number 30, and `344064 · 30 = 10321920`. Exactly one coset
preserves the column lines, namely the subgroup itself. Therefore the
subgroup is all of `A`.

The stabilizer `A(c=1) = {s ∈ A : T_s(1) = 1}` has order 3072. These are
exactly the signed coordinate permutations that preserve sector `c=1`. The
completeness argument is this coset decomposition, not a search that stopped
early.

## The 216-space and the 8-dimensional summand

Let `H` be the group of coordinate sign patterns in `A(c=1)` with positive
sign on coordinate 0. It has order 16. PR #6944 fixes the commuting
involutions

| name | permutation | output signs |
|---|---|---|
| `g` | `(1 2)(5 6)` | minus on coordinates 4 and 7 |
| `t` | `(1 5)(2 6)` | minus on coordinates 3 and 7 |

The trivial character of `H` has dimension 864. The joint `(+1,+1)` dimension

    (tr_V(1) + tr_V(g) + tr_V(t) + tr_V(gt)) / 4

equals 216. The same 216 is the dimension of the lattice of vectors fixed by
`H`, by `g`, and by `t`. The verifier rebuilds that lattice and checks that
it equals the published basis in
`research/a1-joint-216-charpoly/evidence/basis.json`. Call this space `E`.

PR #7008 produces a dihedral image of order 12 on `E`, generated by

| name | `inv` | output signs |
|---|---|---|
| `r` | `(0, 1, 6, 7, 3, 2, 5, 4)` | minus on coordinates 0 and 7 |
| `u` | `(0, 1, 2, 3, 7, 6, 5, 4)` | all positive |

Here `(S v)_k = eps[k] v[inv[k]]`. The element `r` has order 6 and `u`
inverts `r`. Both preserve sector 1 and preserve `E`. Let `ψ` be the linear
character `ψ(r^k) = (-1)^k` and `ψ(r^k u) = (-1)^{k+1}`. The corresponding
central projector is

    P = (1/12) ∑_{g ∈ ⟨r,u⟩} ψ(g) g.

The verifier builds `12P` on the published basis of `E`, checks
`(12P)^2 = 12 · (12P)`, and finds trace 96, so `P` is a projector of rank 8.
An explicit basis of the image `V` is

    w_i = e_{a_i} - e_{b_i} + e_{c_i},

with joint-basis indices

| i | a | b | c |
|---|---:|---:|---:|
| 0 | 104 | 120 | 142 |
| 1 | 105 | 121 | 143 |
| 2 | 106 | 122 | 140 |
| 3 | 107 | 123 | 141 |
| 4 | 116 | 124 | 134 |
| 5 | 117 | 125 | 135 |
| 6 | 118 | 126 | 132 |
| 7 | 119 | 127 | 133 |

Each `w_i` is fixed by `12P`. The eight vectors are linearly independent, so
they are a basis of `V`. Both `r` and `u` act on this basis by `-I`. The
Gram matrix in the standard Euclidean product is `48 I_8`, so the form is
positive definite on `V` and the basis is orthogonal.

This note does not recompute the characteristic polynomial of `A_1` on `V`.
Reducibility of `V` under `A_1` remains the statement proved by PR #7023.

## Census

An element `s ∈ A(c=1)` preserves `E` when `s` sends every vector of the
published basis into `E`. The verifier tests all 3072 elements.

| set | order |
|---|---:|
| `A(c=1)` | 3072 |
| elements with `sE = E` | 768 |
| elements that move `E` | 2304 |

On each of the 768 preservers, the matrix of `s` in the basis `(w_i)` is
`+I` for 384 elements and `-I` for 384 elements. In particular every
preserver preserves `V` and acts by a scalar. PR #7022 already places every
preserver outside the normalizer of `{1,g,t,gt}` among these 768 elements, so
those elements are scalar on `V` as well. This census does not recompute that
normalizer. The scalar count is a control: the membership test accepts the
action that PR #7008 predicts from the linear character, and it is not the
statement about movers.

For each of the 2304 movers the same test gives two facts.

1. Every image `s(w_i)` is orthogonal to every basis vector `w_j`. Therefore
   `s(V) ⊥ V`. Since the Gram matrix is `48 I_8`, `V` is not orthogonal to
   itself, so `s(V) ≠ V`.

2. Write `ρ` for the quotient map `Q^{4096} → Q^{4096}/E` along the
   orthogonal complement of `E`. The eight vectors `ρ(s(w_i))` are linearly
   independent over `Q`. Therefore `ρ ∘ s` is injective on `V`, and

   `s(V) ∩ E = {0}`.

Either fact implies that `s` does not preserve `V`. The second is stronger:
the whole image misses `E`, not only the individual basis vectors. A linear
combination of the eight images cannot land back in `E`.

Thus no element of `A(c=1)` that moves `E` preserves `V`. A fortiori, none
preserves `V` and acts non-scalarly on it.

## One explicit mover

Let `m` be the signed permutation with `inv = (3, 1, 2, 0, 4, 6, 5, 7)` and
every output sign positive. The coordinate map `k ↦ inv[k]` is the
permutation `(0 3)(5 6)`. It lies in `A(c=1)`, it does not preserve `E`, all
eight images `m(w_i)` miss `E`, and those images remain linearly independent
modulo `E`. Repeating one residual drops that rank from 8 to 7, so the rank
test can see a dependence.

Two preservers are recorded as controls, with the same basis of `V`. The
normalizer element `u` acts by `-I`. The coordinate-1 sign `h` is orthogonal
and has compressed trace 216 on `E`. For an orthonormal basis `(u_j)` of `E`,
that trace is `∑ ⟨h u_j, u_j⟩`, and Cauchy-Schwarz gives `h u_j = u_j`, so
`h|_E = I`. The product `u h` is the witness of PR #7022. It has compressed
trace 72 on `E`, so it is non-scalar on `E`, and it acts by `-I` on `V`. A
non-scalar action on `E` is not a non-scalar action on `V`.

## What this does not say

The census is restricted to `A(c=1)` and to this one subspace `V`. It does
not claim that an element of `A` outside the `c=1` stabilizer fails to
preserve `V`. It does not identify which character space contains `m(V)`. It
does not treat the 80-dimensional or 128-dimensional dihedral components, and
it does not use the different 8-dimensional joint space of the nontrivial
sign character studied in PR #7019.

No characteristic polynomial is computed. The degree-881 one-slot annihilator
is untouched. The selected conditional kappa stays `781451/250000000`.
