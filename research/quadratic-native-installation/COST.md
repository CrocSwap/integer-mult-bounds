## Intrinsic compiler change

For n coordinates and L input gates there are at most L path variables. The current address uses n affine bit masks. Binary row reduction uses at most n pivot rows and L columns. The phase table contains at most L mod-four coefficients and L² edge bits. Each application of a diagonal visits at most n(n+1)/2 terms. Each quadratic substitution visits at most L variable positions and changes O(L)-bit rows. At most L sum eliminations occur. Thus the producer uses polynomial bit operations and polynomial space in n and L, including every permutation, constraint, path prefactor, temporary, comparison and release. Explicit dense global-phase matching previously visited a 2^n-entry state repeatedly.

For the actual nine-coordinate graph the producer made 12,092 exact matrix-element queries and checked 9,121 signed monomials. Its longest query has 32 gates, at most 18 path choices and at most nine free bits after address constraints. It also computed each composed child phase and its tableau. The independent dense state interpreter is an optional verification expense. Production includes its own complete tableau and phase comparisons and the old canonical digest.
