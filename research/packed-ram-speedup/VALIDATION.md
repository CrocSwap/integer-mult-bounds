# Validation scope

The registered check authenticates all packaged bytes, then runs four exact finite components and one composed multiplication fixture under isolated optimized Python. It does not invoke Lean and does not verify a complete multiplication theorem or an improved TM kappa.

- The macro model builds every local transition-table row, checks full affected tape ranges after each macro against a separate signed-coordinate TM reference, retains nonhalting prefixes and checks table/address rejection controls. Uniform parameter tests are separate from tiny finite simulation fixtures.
- The codec checks genuine bit spreading/gathering through generated tables; it includes MSB/LSB direction, partial chunks, zero, leading zeros, cap boundaries, dirty post-terminator data and corrupted decoder rows.
- The finite composed fixture executes one fixed 144-state single-tape machine that multiplies all 16 pairs of 2-bit operands. Python multiplication appears in its fixed truth-table constructor and independent oracle, not in runtime RAM operations. This does not provide an all-length multiplier. One extra invocation of the generic supplied-machine runner recomputes all parameters and setup for a fresh input, rather than reusing the fixture table.
- The short-product supplement checks radix reconstruction, low/high products and a carry mutation. It does not remove arbitrary division or instantiate an entire richer-RAM multiplier by assumption.

The universal claims have informal proofs and independent agent review. The operational model's counters record displayed arithmetic/memory primitives and annotated control, not every instruction of a fully emitted RamStd program. The proof pays a fixed factor for finite control lowering. No microbenchmark is used as an asymptotic proof.

New TM profile candidates were tested before scoring. Generalizing a single geodesic contact to arbitrary Clifford labels did not supply a changed paid graph. Deferring a helper's initial correction also required additional prefix contacts and output Fourier compensation; no entrance-only saving was admitted. A further chronological X/Y shared-qubit scan tested 7,140 two/three-stage gauge assignments under the noncommuting-stage certificate; none improved the complete profile. These are bounded local observations, not a universal no-improvement theorem.

The historical key-budget ResearchRoute ledger is scoped only to its numerical table-size sublemma. An observed finite experiment there is not a kernel proof or an audit of this complete informal construction. No new Lean theorem is claimed by this package.

The frozen base is f9f85c1e4fa1e955ff39f10fca447e3e2a4e4adc. Public source pins and overlap are in SOURCES.json and OVERLAP-SOURCES.json. Component checks run without downloading those reference documents; all executable inputs are local and byte-bound. No selected-frontier cold replay is required because no selected source or parameter is changed. Hosted CI and a Linux runtime replay remain unrun unless separately documented.
