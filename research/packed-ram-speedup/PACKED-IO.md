# Packed binary IO without a linear bit-by-bit RAM bottleneck

Prepared by Dugongue with substantial OpenAI Codex assistance. Apache-2.0.
This is a constructive bounded-word algorithm and an informal universal proof,
with finite operational-model checks. It is not an emitted RamStd program,
a fresh Lean theorem, or an improved multitape-TM exponent.

## Protocol and sufficient theorem

Fix c>=2, a power of two, and r>=1, also a power of two. The simulated tape
alphabet uses blank symbol 0 and logical bit codes 1,2. Other symbols may exist
internally, but an output binary prefix contains only 1 and 2 before its first
blank. Let beta=2^r. An n-bit operand arrives in exactly ceil(n/r) little-endian
base-beta digit words; the final digit's unused high bits must be zero. The
length header n, table arenas, input/output arrays and all pointers fit in
bounded w-bit words. Require 2cr+8<w and enough arena space for the tables plus
the actual buffers. The table-address envelope itself is O(2^(cr)) words; this
is an explicit memory requirement, not a zero-cost table oracle.

There are generated tables and one uniform additive/Boolean algorithm with:

- setup at most 100 r 2^(cr) charged word operations;
- input expansion at most 100(ceil(n/r)+1) charged operations, producing either
  LSB-first or the usual MSB-first binary symbol stream in packed c-bit cells;
- output conversion at most 160(ceil(m/r)+1) charged operations, reading a
  usual MSB-first coded binary prefix of at most m cells until blank or the
  m-cell cap, and emitting exactly ceil(m/r) little-endian beta digits with
  all unused high bits zero.

Input/output setup, table indexing, chunk reversals, partial chunks and high
zero padding are all included. Each external input digit is read O(1) times,
and each external output digit is written once. No external bit-per-word stream
is introduced. Every variable scaling by c or r is a shift because those
parameters are powers of two. Multiplication and division instructions are not
used. The constants above are operational-model envelopes, not certified exact
RamStd instruction counts; the finite loop bodies admit constant-size lowering.

## Table construction

For every 0<=x<2^r, enumerate its r logical bits and generate

    E[x]  = sum_j (1 + bit_j(x)) << (cj),
    Er[x] = sum_j (1 + bit_(r-1-j)(x)) << (cj).

The displayed sums describe the object. The constructor uses a bounded loop,
bit tests, shifts and OR, never a multiplication instruction. For every
0<=y<2^(cr), enumerate its c-bit cells from low to high. Stop at the first blank.
Reject a cell outside {1,2} only if it occurs before that blank. Record
(length, value, valid), where value is the ordinary integer represented by the
MSB-first logical prefix seen. Its recurrence is value <- (value<<1) OR (cell-1).
Consequently its little-endian bits are exactly the reverse of that prefix.
Use a fixed power-of-two row stride for these metadata triples.

Enumeration takes O(r 2^(cr)) operations and O(2^(cr)) words. Invalid table
keys have defined entries and do not require a promise that every row is valid.
Only entries reached by actual valid input/output data must have valid=true.
All table keys and outputs use at most cr+O(1) bits, so the stated word width
and a disjoint arena prevent address/value wrap. Setup is recomputed from r,c;
it is neither supplied as advice nor generated by an unpriced root/bit oracle.

## Input correctness

For LSB-first TM input, traverse input digits from low to high and use E[x].
For the highest partial digit of ell bits, retain only its low c*ell encoded
bits so that unused tape cells remain genuinely blank, rather than coded
logical zero.

For MSB-first input, traverse digits from high to low and use Er[x]. The highest
partial digit has ell bits, so shift Er[x] right by c(r-ell): this removes its
coded leading zero fields and retains exactly bits ell-1,...,0. Every remaining
digit has r bits and needs no adjustment. No unbounded bit reversal is assumed.

Append each at-most-r-cell result to a reservoir holding fewer than r cells.
If at least r cells are present, flush the low r to the packed output stream
and shift the residual down. At most one flush is needed per append. The
invariant is that flushed fields followed by the reservoir are exactly the
processed logical prefix, in the selected bit order. At the end, emit any
remaining fields with zero high padding. This proves both bit orders and
ensures that after the n input symbols every uninitialized tape cell is blank.
At every step the reservoir contains fewer than 2r cells, hence fewer than
2cr bits. The supplied width bound pays for every intermediate shift.

The packed simulated-tape representation may hold 4r cells per RAM word, as
in the companion tabulation backend. Each produced r-cell chunk is inserted
by at most two masked word writes at an arbitrary starting alignment; this is
O(1) actual word work. An origin aligned to 4r simplifies it to one word per
chunk plus retention of the other subchunks. No per-symbol initialization is
needed. The overwritten fields represent input symbols; neighboring initially
blank fields and all other tapes remain unchanged.

## Output correctness and termination

Read the simulated tape in r-cell chunks, masking the last chunk to the m-cell
cap. Lookup its decoder entry. Stop immediately after the first blank or after
m payload cells; later chunks are not read. Retain its at-most-r-bit value and
its actual prefix length. Valid earlier chunks have length r, and only the
last can have a shorter payload. The all-blank output prefix represents zero.
If the output has m bits, its terminator may lie beyond the scanned cap and
need not be read. An absent stream that supplies neither enough payload nor a
terminator is a malformed protocol and rejects.

Traverse the retained chunk descriptors in reverse order. For each descriptor,
append its value and length to a binary reservoir. Its low-to-high bits are
the reversal of that chunk's original MSB prefix. Reversing the chunk order
therefore reverses the entire original bit prefix, including partial chunks
and leading logical zeros. The same reservoir invariant as for input proves
that the emitted low-to-high digit bits represent exactly the original integer.
Append zero digits until exactly ceil(m/r) output words exist, and mask any
unused high bits in the final output word. This is padding at the high end of
an LSB encoding, so it preserves the value. Appending zeros to the original MSB
word would not preserve it and is not used.

Descriptor storage, its reverse traversal and the final padding use
O(ceil(m/r)) words and operations. Zero cap emits no word and reads no tape
chunk. Dirty symbols after the first terminator are irrelevant. The decoder
rejects invalid symbols before it, rather than silently treating a marker as
a logical bit. A distinct fixed end marker can be added to the decoder's
termination test at constant cost; the checked version specifically uses 0.

## Combination with the full local-configuration table

For a fixed k-tape machine and polynomial running-time envelope, choose the
common epoch/chunk r=Theta(log(n+2)) small enough that

    Q * 2^(kc(2r+1)) <= (n+2)^epsilon

for one fixed 0<epsilon<1. Rounding r down to a power of two changes only its
constant factor. The codec's 2^(cr) rows are dominated by this complete machine
configuration table (up to fixed constants). Their setup costs are therefore
O(n^epsilon polylog n), and their active IO costs are O(n/log n).

A complete r-step macro simulation costing O(1) word operations per epoch
then combines with these codecs to give

    O(T(n)/log(n+2) + n/log(n+2) + n^epsilon polylog n)

bounded-word RAM operations on the packed protocol. For a complete conditional
multitape multiplication theorem T(n)=O(n log^(1-kappa)(n+2)), 0<kappa<1, this
is O(n/log^kappa(n+2)) word operations. The former bit-per-word wrapper's O(n)
term is genuinely removed: the implementation consumes and produces
Theta(n/log n) digit words instead. This is a model-relative consequence with
inherited hypotheses; it is not an improvement to the multitape κ or a claim
of novelty for classical tabulation. It depends on the companion simulator's
fully paid table and macro correctness, which are not proved by codec tests.

## Evidence and provenance

`python3 -I -O -B packed_codec.py` checks 4,277 cases across r=1,2,4,8 and c=2,4
(where finite table sizes permit), both bit orders, partial chunks, leading
zeros, capped full outputs, zero outputs, and dirty post-terminator cells.
Seven actual decoder-entry mutations produce an incorrect represented integer
and are detected; invalid pre-terminator symbols reject. The tests compare
ordinary integer values and literal symbol streams independently of the tables.

This extends the prior Word RAM deliverable's explicit restricted-RamStd model,
packed-tape access and fixed-length LSB output contract. It retains their
Problem 1.8 machine/compiler provenance. The uniform local-configuration
simulation and its main proof are separate root-owned work. No canonical Lean
module, shared DAG, selected frontier or prior research source was changed.
