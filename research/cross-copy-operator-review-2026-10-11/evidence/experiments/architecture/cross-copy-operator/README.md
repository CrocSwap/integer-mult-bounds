# Scoped cross-copy operator obstruction

Source: higherbeing/Sreekanth Nair + Claude PR448, head `9b966d8188e1cadd00aa834078ee6a8742a9d9b4`; exact cached source hashes in PINS.json. This tests transfer to the unchanged signed95 helper interface, not every possible strengthened compiler interface.

The inherited bit operator D_U swaps the two doubled address components in U. A physical stream holds an arbitrary array of values indexed by those addresses. Address subspaces of one stream are tensor-coordinate directions of that array. Distinct physical streams instead carry a direct sum of arrays. These are different representations.

For two nonempty pieces of widths a,b, the old complete helper residual together with one untouched stream has trace N+N/q^(a+b). Two independent physical stream residuals have trace N/q^a+N/q^b. Their difference is N(1-q^-a)(1-q^-b)>0. Thus no permutation selector, nor any invertible linear value selector, conjugates the old operator to the proposed split operator. The old construction and its reflection/inverse are involutions. check.py enumerates every signed integer basis column in an actual odd-field q=3,m=2 example (162 columns). Its larger binary-coordinate example is explicitly a model, not an admitted odd-field supplier. The exact general formula applies all odd fields without exponential enumeration.

The same-family identity D_P1 D_P2=D_(P1+P2) remains correct. The failure is using it to infer a cross-family ownership map without an additional value representation. Charging a third route factor does not define or repair this missing map.

Minimum new proof interface: an explicit value embedding/extraction for a virtual helper across multiple families, lowering every local ADD/COPY/READ/MOVE operand through that embedding, arbitrary correlated dirt and full inverse/endpoint verification, and the resulting actual primitive calls, work stock, restoration, prefix and selector invoice. A redesigned local supplier could establish such a contract; this receipt does not exclude it. No improved supplier or score is admitted here. The cross-copy inventory and its moment improvements remain conditional.

## Intermediate and lowering gates

`flags.py` tests an aligned two-axis partial flag model over q=3. The logical pair has a nine-dimensional joint (minus,minus) character space; the independent physical-family pair has none. Therefore no injective fixed encoding simultaneously intertwines both partial factors, even though the terminal product alone admits the earlier restricted encoding. This is an exact model gate, not an assertion that every actual signed95 path has that alignment. Actual helper chains and proposed split axes need individual verification.

The constructive subset embedding also sends the logical constant array to nonconstant physical masks (63 of81 addresses in one family,18 of81 in the other). Pointwise streamwise scalar ADD/COPY/scales and arbitrary bijective address permutations preserve the subspace of constant arrays on each family. Starting zero ancillas cannot supply these masks. Consequently this particular embedding has no synthesis using only those primitives, regardless of repeated unit counts. Nonconstant ancilla templates or masked read/write would be an additional interface. A different encoding remains open; a time-dependent encoding additionally requires lowering its transitions and spectator restoration through the actual source grammar.

No actual full local-word virtual-helper redesign or competitive paid profile has yet been established. The previous signed95 source word and all frozen publication packages remain unchanged.

`ACTUAL-FIRST-LAST.json` binds a stronger scoped gate to lattice's actual helper240 split placement. Its first frame is the e0 line, its final local frame is full rank8, and its selected split is7+1. For a fixed encoding and a carrierwise aligned first line, the logical joint(first minus, terminal plus) dimension exceeds the available physical dimension whether the first line occupies the width7 or width1 carrier. The exact general gap is `N(q−1)(q^−a−q^−8)/4`; the q3,m8 gaps are6561 and7171173. Mixing the line between carriers instead requires an explicit intermediate cross-family MOVE lowering. This gate does not forbid time-dependent encodings or separately paid richer operators.

More generally a coordinate-value subset encoding occupying both families maps the logical constant array to partial value masks. It therefore cannot be synthesized from the stated constant-preserving grammar with zero ancillas. Occupying just one full family avoids masks but cannot realize the width8 terminal operator as its width7 or width1 carrier: the terminal traces differ. Noncoordinate linear value encodings are not covered by this subset argument.
