Cao Yifan; substantial OpenAI Codex assistance. Apache-2.0.

The current conditional PR4610 claim remains **kappa=0.0030217758**.
This note credits newly inspected concurrent work and prevents the bounded
one-edge certificate from being mistaken for a general frontier result.

[Cinna Davis's PR4696](https://github.com/CrocSwap/integer-mult-bounds/pull/4696),
at `def829364e8e53a74eac7997b49b5366afd5bc29`, already supplies a stronger
written cost argument for paid symmetric-form changes on the retained graph.
Its [proof](https://github.com/1337isnot1337/integer-mult-bounds/blob/def829364e8e53a74eac7997b49b5366afd5bc29/research/phase-rank-debt/PROOF.md)
bounds each helper's phase-rank gain by its own added paid ranks. It checks
monotone owner paths, pointwise fixing of the transported entrance, and at
most one original positive paid call per block between scalar contacts.
Concavity then prices that debt at least as highly as the helper reward.
It permits compatible owned phases and increased paid ranks; fixed
subspaces, chronology, maps and the single-owner contact alphabet remain
material premises. Its native rank grammar is inherited, and its finite
source checks are not a formal kernel verification.

The one-edge package published with this note is an independent, narrower
finite kernel classification with scoped Lean analytic lemmas. It does not
replace or claim priority over PR4696's broader argument. Relaxing a textual
adapter-marker freeze alone does not escape that rank-debt reasoning if
the same actual helper path and whole-job invoice remain. A separate audit
is checking its exact source premises and formalizing the general analytic
debt inequality. No completed result from that ongoing audit is assumed here.

[PR4690](https://github.com/CrocSwap/integer-mult-bounds/pull/4690), at
`ddb7ead76479b1e281b485a78b65ce21cc7de8d7`, supplies charged non-nested,
common symmetric-phase and common Pauli-axis search models. Its reported
511 rank-one forms, 18 compound forms and 255 Pauli axes give bounded
negative solver evidence, not a universal ceiling. We stopped the overlapping
fixed-ambient phase sweep after inspecting this work.

The remaining active-mask construction instead chooses actual chart-dependent
axes `K_U X_v K_U^-1` independently at shared scalar components. For an odd
active mask, the Fourier rowspace changes and the frame rank can decrease.
This leaves PR4696's fixed-subspace formula and differs from PR4690's single
common ambient-axis switch. Every actual relative, formerly free warp,
independent helper endpoint, owned stream and complete moment must still
be paid. A bounded unsuccessful palette is not a theorem about all such
gauges, and this note reports no higher kappa or admitted new supplier.
