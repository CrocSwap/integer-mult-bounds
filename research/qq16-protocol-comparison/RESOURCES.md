# Shared primitive inventory, controller roles and visited storage

Chris R with OpenAI Codex assistance. The physical controller, Count, primitive
and native implementation are inherited from Jose Manuel's #3385. Sagar
Thakrar's #3464 supplies compatible parent-restoration semantics; Tekalign's
#3380 supplies the motivating finite-role-exchange method. Central manifests
pin the actual sources. These predecessors do not establish this package's new
complete protocol comparison.

## Selected mechanism and external contract

A runs the original selected Machine inside the unchanged RootLayer. Primary B
uses two **controller banks** with one physical scalar/leaf/monomial bundle,
including one Ordinary native engine. One controller retains the parent state;
the original controller executes the external child and all descendants with
the original embedded protocol. B* adds completed-child output adoption. C/D
retain the frozen #4166 installation with its separate inventories. The external
RootLayer borrowed inputs and public output identities remain the same.

The shared-bundle route resolves a precise issue with the first separate-engine
candidate. PhysicalArena.available preserves its free-slot order after erasure;
fresh and used native engines can therefore encode different finite slot IDs.
Closed tape bodies alone would not establish their literal execution relation.
That separate-engine comparison is **deferred**, not disproved. Primary B uses
the identical primitive objects for the same ordered primitive operations, so
no fresh-versus-used allocator identification is required.

Only root child boundaries are changed. The original child controller retains
its complete source binding and original descendants. The result does not claim
an all-node recursive replacement or a new multiplication exponent.

## Why shared ownership is exclusive

The external call borrows the parent's completed owned capsule. Before entry,
source prepare_child copies the target payload and fourteen encoded descriptors
and writes the bounded return header. These are paid work. The parent current
bank, gathered packets, private roles, capsule, header and descriptors all remain
live in its own **distinct controller inventory**.

At enter_child the parent's OuterScope manager is absent, its own scratch pool
is empty and source primitive_boundary checks closed scalar, leaf and monomial
engines with consumed outputs and closed Compact/ordinary backend. Only then may
the dedicated child Machine borrow the shared primitive bundle. The parent's
primitive wrapper runs never overlap the child controller's runs. The child
uses its own controller Count pool and suspended state. On return all shared
primitives are again closed before the parent resumes. No borrowed scratch lease
crosses this boundary and neither controller is re-entered while active.

Both controllers' scalar, leaf and monomial fields name the **same objects**.
Inside those objects, all ordinary arenas, templates, free-slot order, finite
selectors, runtime roles, scratch pools and dictionary-codec state are therefore
literally the same resources. Source scalar/monomial selection is performed at
its normal instruction boundary. The unchanged temporal order of primitive
invocations gives the same evolving internal state, including any allocator
history. The protocol context lemma separately matches controller root flags,
headers, parking and returned packets; sharing does not by itself prove those
controller traces equal.

This is a new exclusive sequential-lending proof. It is narrower than permitting
arbitrary engines to share native scratch while suspended. In particular, an
active scalar/monomial invocation, an escaped lease, a live native output or a
parent allocator manager invalidates the call boundary. Successful completion
and original primitive admission/closure remain inherited premises.

## Added-controller startup and terminal bill

The emulator's Tape constructor installs LEFT at head0 and starts at head1
without meter increments. The physical allowance nevertheless pays at most
three actions per newly created tape for marker placement/head setup. Only the
BankPackets constructor performs further Tape operations: it calls erase_marker
on its 704 packets, output and sixteen pool tapes, costing five actions each.
All other new controller fields and its Count pool/parking ports have marker-only
initial state; FiniteFields construction fixes bounded source labels in control.
Thus fresh construction is bounded by `3J + 5*(704+1+16) < 8J` actions.

The shared primitive bundle and Ordinary constructor are common to A/B and are
created once. Their initialization is retained in both comparisons and is not
charged again as an extra engine. In particular, the source Compact constructor
really calls native.finish(False), scanning native pools and arenas; that cost
is common rather than assumed zero.

Complete call bills already contain successful body cleanup, returned payload
publication and capsule/header retirement. They must not be charged a second
time as terminal disposal. At actual last use `retire_empty_roles` walks the
precompiled extra-controller tuple and erases its remaining empty origin
markers. Each role costs at most five actions: read blank, move left, read
marker, optionally erase it, move right. The shared primitive/codecs are **not**
retired by this sweep. The source completed-return proof supplies the dense
empty-body/canonical-head invariant; a first-symbol check alone would not prove
that no hidden suffix exists. Terminal retirement prevents further reuse of the
additional controller.

Including fresh construction, final marker sweep and fixed boundary checks
(such as the adapter's additional outer-entry protected-output read), the
conservative bound used in the whole-root ledger is

```
E_extra_IO <= 64J + 1024 = 66,496 tape actions.
```

`startup_retirement_bound(q)` retains its integration API but now returns this
controller-only quantity. Fixed source compilation and host allocation wall time
are outside this read/write/unit-move tariff. The bound is charged once through
actual last use, not for each child. High-water backing survives retirement.

## Empty bodies and numerical representation

The extra controller's successful source return transfers its current bank to
protected output, clears every parked role and verifies an empty stack. Every
completed external child consumes its capsule/header. After the outer caller
consumes the fixed protected output all controller bodies are empty. There is
no persistent q/modulus/program payload in the extra controller; these remain
in the common source control and native implementation.

For completeness, the shared native's successful closure still follows the
actual inherited chain: Ordinary.fitted ExitStack frees modulus/remainder/index
maximum/size/depth and clears unit program/directory bodies; MacroMachine's
close_frame closes geometry/context/ring, frees its numerical words and clears
all roles. Arena.free calls Word.erase through RIGHT; PhysicalArena.erase_owned
also erases every initialized template. Ordinary.finish erases all six arenas,
its pools and dictionary-codec marker. Scalar/leaf/monomial/Compact/Binary return
only their protected output and close scratch; the consuming source call clears
that output. The differing finite allocator order noted above remains on the
same shared object, so it is preserved rather than presumed canonical.

No numerical payload operation changes under the pure protocol transformation.
Copies, parking/restoration and proved finite-role exchange preserve symbols.
Actual widths, q_s, H_b, H_g, rows, coefficients and spectators are unchanged.
Given the controller-context correspondence and original native contract, the
source range/grid induction therefore transfers, including correlated and dirty
payloads. A truncating return, changed descriptor, omitted spectator or different
native endpoint would invalidate this implication. Reduced executions do not
instantiate production O73 parameters.

## Completed-child output adoption

The optional child-return transfer site is new. It does not import #3380's
22V+13 or #4166's whole-bank 11B+4 into its invoice. Its matched action bill is
proved in the protocol component, including old-target erasure and head checks.

Let t be the saved target, P its old physical packet and Q the completed child
protected output. After all shared primitives close, physically erase P's old
body and owned marker. Bind parent target t to Q and child.output to empty P.
Update parent.bank.packets (or parent.private for a private target), parent.parked
and parent.parking.roles in identical constructor logical order. Preserve parent
public output, capsule, descriptors, group, current bank and saved PC. Then
perform the same exact continuation validation and capsule/header cleanup.

The source's full alias list is explicit: packet(t) resolves bank.packets or
private; parked and parking.roles retain the same roles; bank.selection stores
slot numbers; group.code/keys contain immutable logical selectors; bank.source
is the unchanged current bank. The shared primitives are closed and hold no live
borrowed target. The child's output field is the sole protected-return binding.
Public RootLayer/parent ports are separate. Raw target/output references must
not escape the fixed compiled boundary; this is not a general revocable Python
handle API.

Subsequent scatter reads the updated logical target. On later child entry,
Parking serializes logical roles in the unchanged order. Ancestor frames contain
body symbols and delimiters, not physical references. Thus #3464's restoration
induction extends under the finite role permutation, preserving ancestor values
and continuations. Private targets are included, as required by original centre
calls. B* does not allocate another tape or borrow active native storage.

`binding_tuple` and `check_child_exchange` audit the relevant alias tables.
`adoption_controls` uses actual Tape operations at explicitly synthetic fixed
cuts: bank/private exchanges succeed; stale parked order, stale parking.roles,
public-output alias, wrong result head and wrong target head reject. Reached
continuous fixtures separately test real source calls, generations, both bridge
legs and terminal cleanup. These guard fixtures alone are not a caller theorem.

## Visited backing and scope

For physical role r over executions j, retain

```
H_total = sum_r max_j H(r,j).
```

Erasure does not reclaim visited cells. Role exchange can spread historic maxima
across roles: extent pairs (10,3), then (3,10), require20 cells, although each
active pair totals13. `visited_bound` keeps this rejection example.

At selected root geometry let V be complete bank bits and L=14336*Gamma. Each
gathered owner packet and capsule has V/L bits; its active width changes its
complementary after field, preserving complete row/address extent. The extra
controller retains V plus at most712 local packet/private bodies, a capsule,
protected output, descriptors and its controller backing. The original child
controller still satisfies its source recursive bound. The primitive bundle's
historical backing is common and used sequentially; it is counted once, not
once per controller or call. Parent packet storage and child controller storage
remain physically distinct. Per-role historical maxima, including adoption,
remain bounded by the largest admitted packet geometry with the source
long-record/native premises. This establishes an O_q(V)+F_q-type space domain
with an increased fixed controller constant; it does not assert a space saving.

A's source parked-branch bound is
`4(1+712/L)V/(1-1/L)`, plus its separately named root/capsule/return work.
B retains the live parent while using the original child controller and shared
primitive. Subtracting these space upper bounds does not prove a time difference.
The signed time result comes from the protocol action/context lemma and the
whole-root occurrence sum, including the later suffix.

supplies logical restoration under its premises; #3380 supplies the finite-role

and meaningful symbols, and the dictionary-codec heads/data. It excludes object
identities, meters and historical trailing blank backing. Comparing these
snapshots at reached prepared/returned cuts tests the new sharing invariant;
it does not turn a host digest into a runtime cost or production execution.

Publication requires the integrated controller-context proof, the complete
whole-root ledger and adversarial review. This resource component alone does
not establish QQ16 affordability, all-node substitution or a new exponent.
