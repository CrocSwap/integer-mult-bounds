# Exact complex child-call comparison

Prepared with OpenAI assistance. Apache-2.0. The machine and codec are Jose
Manuel's #3385 physical complex controller. Sagar Thakrar's #3464 establishes
compatible semantic parent restoration; its frame length is not used as an
action tariff. The external-call boundary starts from #4166. The constructive variant here
changes its engine allocation: caller and external controller share one
exclusively leased, closed scalar/leaf/monomial bundle. This section derives
the resulting same-boundary protocol comparison and credits no QQ16 arithmetic
improvement. The separately allocated #4166 backend requires a further
allocator-context equivalence argument and is not silently substituted for this
new shared-bundle variant.

## Domain and typed boundary

Fix the authenticated original `Machine`, selected binding and physical native
backend. At entry, `prepare_child(target,rank)` has completed: parent mode is an
active gathered group, saved header names the exact next PC/target/rank, each
parked role has canonical body head and LEFT marker, child capsule contains the
complete copied payload and fourteen Count descriptors, and parent allocation
scope is uninstalled. Width contracts strictly, row stock is sufficient, and
all source arithmetic/hosting hypotheses hold. The allowed resource difference is one **separate original-binding controller**
with its own current/input/derived roles, capsule, output, bank, private roles,
Count scratch pool and parking stack. Its scalar, leaf and monomial engines
are the same physical bundle as the caller's, assigned before execution. The
bundle includes the underlying ordinary native machinery and retains its
allocator history. The two controllers have exclusive sequential access: the
caller has exited its allocation scope and `primitive_boundary` establishes
closed engines before the external controller starts. No active Machine is
re-entered and no active primitive is borrowed. The new controller's fresh bank
packet markers may be erased; previous high-water backing remains allocated.
This shared-bundle protocol-only candidate is denoted B below; the independent
engine version of B suggested by #4166 remains a separate comparison.

At exit the child result occupies the original caller's required target packet;
all other parent bodies, heads and bindings have their original values; saved
header/capsule bodies are empty; PC is the saved successor; group/selection is
restored, and all child scratch is closed. Public root input/output identity
is unchanged. Source `prepare_child` can be included in both boundaries:
its Count arithmetic, copied descriptors/payload and header construction are
**the identical literal subtrace** in A and B, not two unrelated upper bounds.
The formula below starts immediately after this shared preparation.

Let `r` be the number of parked parent roles, `S` the sum of their dense body
lengths **including the saved header**, `C` the sum of the fifteen capsule body
lengths, and `h` the finite header length. Numerical lengths are proof variables
and checker observations; execution does not decode them into host integers.
`q` is the input/output target packet extent. Counts, prefixes, row stock,
spectators, coefficients, spacing, compact fields and stored component width
are retained in these actual lengths. No logical-width substitution is used.

## Actual read/write/unit-move formulas

Write an action triple as `(R,W,M)`; each primitive read, write and unit head
move is counted once. All entries below start at canonical body heads, except
a rewind whose starting offset is explicitly given. Dense lengths may be zero.

| Source operation | Exact `(R,W,M)` |
| --- | --- |
| `rewind`, starting `n` cells after origin | `(n+1,0,n+2)` |
| `clear` of length `n` | `(2n+3,n,2n+4)` |
| preserved copy `n` into old target `m` | `(5n+2m+7,n+m,4n+2m+10)` |
| owned transfer `n` into old target `m` | `(5n+2m+7,2n+m,4n+2m+10)` |
| `origin`, marker absent flag `a` | `(2,a,2)` |
| `erase_marker` | `(2,1,2)` |
| `Parking.empty` | `(3,0,2)` |
| finite header write `h` | `(2h+2,h,2h+2)` |
| finite header read `h` | `(2h+3,0,2h+4)` |
| `park` of `r` roles, body sum `S` | `(3S+3r+2,5S+r+1,6S+5r+1)` |
| `restore` of the same frame | `(15S+5r+5,13S+r+1,14S+7r+1)` |

For example each restored symbol incurs four stack reads, four reverse-port
append checks, four reverse-digit reads, a reverse-loop read, a destination
append check and a rewind read. Role delimiters, final failed loop tests,
empty-role reversals and both canonical-port checks supply the constants.
Thus park plus restore costs `56S+22r+11` total actions. The four-bit frame's
length `4S+r+1` is an entirely different quantity.

`protocol.verify_primitives` meters the actual imported source operations over
empty/nonempty dirty targets, all twelve allowed body symbols, and stack frames
with and without an older ancestor frame. It does not fit coefficients to
benchmark timings. The formulas follow the displayed loops; the tests can
reject missing loop/append reads and wrong canonical heads.

## Literal child-context correspondence

The external child executes the **original binding**, not the altered QQ16
binding. Immediately after the fifteen capsule transfers/copies, its active
current/input roles equal the embedded child's roles; derived/header bodies
are empty. The active scope, finite PC, group and bank selection correspond. The
primitive bundle is physically shared and has exactly the same state and
invocation history as A at the matched cut. Payloads may be nonconstant,
correlated and dirty; the correspondence compares complete symbol strings.

There are three controlled differences.

1. The top child has `root=False` embedded and `root=True` externally. The only
   executable tests/uses of this flag in the source are the saved header bit,
   child entry assigning false, terminal return branch, and public run entry
   assigning true. The differing top-root bit can therefore appear in headers
   saved for immediate descendants. Both encodings have the same finite width;
   binary symbol 0 versus 1 takes exactly the same read/write/move sequence.
   Restoration reinstates the corresponding flag. All deeper descendants have
   equal root flags. The top child's **terminal return branch is excluded**
   from the cancelled subtrace and priced below.
2. The embedded stack has the parent frame (and any older frames) beneath the
   child; the external stack starts empty. Parking appends at its current end;
   it never rewinds to the global stack origin. A descendant restoration stops
   at a preceding ROLE_END/FRAME_END or LEFT with exactly the same branch and
   movement. Translating stack head coordinates by the ancestor-prefix length
   therefore preserves every descendant action. The boundary delimiter's
   value differs only in a membership test admitting both alternatives.
   `Parking.empty` is only taken at the top external return, which is charged.
3. Initial absent owned markers can differ. The embedded parked roles are all
   armed by preparation/gather. A newly constructed external bank has erased
   packet markers. Each is armed once, by its first gather or by terminal
   `return_node`; this adds one write and no read/move difference. Machine
   output is similarly armed at its first return. Thereafter the marker states
   agree throughout the child computation. Let `epsilon` be this signed initial
   marker debt for parked roles plus output. A fresh backend has at most
   `slots+1`; after a completed external run all parked markers are LEFT and
   caller output consumption erases just the output marker. The shared primitive bundle is literally the same engine state, including
   ordinary arena free-slot order, finite selectors, encoded slot IDs and
   numerical backing. Each next scalar, leaf or monomial invocation is the same
   source instruction on the same bundle; equal arguments and equal state
   therefore imply equal actions and next state. Its successful closure is
   required before switching controller users. Independent Count pools choose
   the first free lease deterministically; their slot labels remain finite
   controller data and do not alter encoded Count bodies. All corresponding
   Count tapes are empty at the same lease boundaries. High-water backing is
   retained in the resource bill. Native completion remains a source premise.

Induction on the dispatched source instruction now pairs all node/body work,
including child constructors, descendant preparation, complete descendant calls
and their returns. It does **not** infer cancellation from rank, width or final
values. Counts and numerical byte strings are identical at every paired
operation; marker debt is the only unmatched body write. The induction applies
at every admitted finite depth, conditional on source completion. Ancestor
stack storage still exists physically in A; translating a head for a proof
does not reclaim its backing. Repeated invocations of the external controller must satisfy the same
closed-state and exclusive-lease contract. The shared engine sequence continues
through parent primitives between calls, so the induction is global across the
whole root and does not reset native allocator state at child boundaries.

## Complete boundary difference

Original A performs a primitive check; arms `r` already-armed parent roles;
parks the parent; transfers all fifteen capsules into now-empty active roles;
runs C; protects its result and clears active roles; restores the parent;
reads and clears the header; and transfers the result into the restored target.

External B performs the same primitive check; reads the same header; enters
`Machine.run` (including output check and empty-stack check); copies the fifteen
capsules; runs C; protects its result and clears active roles; checks its root
stack is empty; rewinds its borrowed capsule payload; transfers the result to
the unchanged target; erases its output marker; clears fifteen capsule bodies
and clears the parent header. All native descendants are already inside this
complete C run and are not added again.

The two header reads/clears and the complete target transfer cancel literally.
The child return prefix and active-role clearing cancel under the context
lemma. Capsule copy versus transfer saves `C` writes, exactly offset by later
capsule cleanup's `C` writes. With `k=15`, the resulting **B minus A** is

```
R = 2C + 3k + 3 - 18S - 10r
W =                  -18S -  2r - 1 + epsilon
M = 2C + 4k + 6 - 20S - 14r
R+W+M = 4C + 113 - 56S - 26r + epsilon.
```

Scratch-pool boundary checks are present in both compared traces; their many
Tape reads/moves cancel under the closed-state correspondence. They are not
silently replaced by a zero-cost assertion. Finite Python control represents
fixed compiled control; if a separate transition tariff is desired, retain its
per-call difference explicitly. The reported primitive action claim is exactly
in the repository Tape-meter units. The construction adapter's extra once-per-
root closed-output check and complete added controller construction/disposal are
outside this per-occurrence difference and appear in the whole-root ledger.

This is an exact signed difference, not subtraction of upper bounds. It also
covers direct children: the body induction has no descendant case, and the
marker potential is paid at terminal return. No empty-role calibration is
called a reachable source payload witness.

## Why the source geometry controls the sign

For an admitted source node, `C <= S`. Inject the capsule payload into its
parent target packet; the eleven unchanged Count descriptors into their parent
roles; child rows into derived `unused`; child width into parent `width`; and
child `after` into derived `row_bits`. These target roles are distinct.
Canonical nonnegative binary Count lengths are monotone in their values.
The width inequality is strict contraction. For the last injection, put

```
b = 3*compact_bits + front + before + width*spacing + after + back.
```

The child-after value is at most `b`, while
`row_bits = 2^(b+1)*coefficients*component_bits >= b` under the positive source
conditions. This argument retains spectators, full stored width and row stock.
Consequently `B-A <= -52S-26r+113+epsilon` in total actions. More strongly,
the coordinate bounds are `delta_R <= -16S-10r+48`,
`delta_W = -18S-2r-1+epsilon`, and `delta_M <= -18S-14r+66`.
For the source inventory `r >= 20` and `epsilon <= slots+1 <= r-19`,
each coordinate is strictly negative; positive fixed weighting of the three
primitive actions preserves this per-call sign. The complete root
statement sums the actual occurrence lengths, plus the fixed-controller setup,
cleanup and any separately stated control costs. It is a generic protocol gain;
it cannot be credited a second time to QQ16 recovery.

## Additional compatible ownership return

At a completed external child return, a finite internal packet role may adopt
its completed output if every binding is updated and the old target becomes
the backend's empty output role. Clearing/erasing the old target replaces the
transfer/erase path; fixed public output ports are not exchanged. With the
implemented two LEFT-origin checks charged, the exact extra saving is

```
(5q+2, 2q, 4q+2), total 11q+4,
```

before separate finite rebinding control. Without those checks the algebraic
site would save `11q+10`; that is not the implemented tariff. This adapts
Tekalign's ownership-exchange method, and applies fairly to protocol-only B
and compatible C/D variants. It is neither #3380's `22V+13` nor #4166's already
credited whole-bank publication `11B_bank+4-c_R`.

## Independent-engine obstruction and suffix limitations

The initial separate-native cancellation proposal was withdrawn during assisted
review. `PhysicalArena.available` preserves its free-slot order across ordinary
finish/rearm. Native parking encodes physical slot IDs. Thus equal closed tape
bodies, widths and final values do not establish the same literal native trace.
An equivariance proof under arena-slot permutations may resolve this issue, but
is not assumed here and is not refuted by this observation. The shared-bundle
construction removes that proof obligation by preserving the actual complete
primitive state and history. In particular the shared-bundle theorem cannot
assign a zero context correction to published #4166 D without a new argument.

## Conditional suffix tariff

For two external-copy callers whose complete suffix packets, descriptors and
full child states (including allocator history or a proved equivariance) are paired, a header-width change of `delta_h` costs exactly
`14*delta_h` actions per call (header write, read and clear). In particular the
original-versus-expanded binding's two extra header bits cost 28 actions for
each paired suffix occurrence. This requires the #4166 whole-bank reconnection, literal source-occurrence
pairing, and the full child-state relation. The first two alone do not establish
the third for #4166's independent engine. It is not a rank-histogram inference.
Other changed binding inventories, finite predicates and final cleanup remain
in the whole-root ledger. A matched external C call already contains all its own per-call packet and
descriptor construction, copies and descendants. The one-time controller
constructor and final disposal remain separate.
