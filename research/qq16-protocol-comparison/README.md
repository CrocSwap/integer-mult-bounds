# A fair physical protocol baseline after QQ16 caller installation

This package constructs an original-arithmetic external child protocol which
avoids top-parent serialization **without another numerical engine**. A separate
controller bank borrows the original closed scalar/leaf/monomial/Ordinary bundle
sequentially. This preserves the literal primitive invocation and allocator
history of embedded recursion. It adds1,023 fixed tapes, with complete added
controller initialization and terminal retirement bounded by66,496 tape actions.

The result changes the comparison after #4166: avoided parent parking is a
**generic protocol benefit**, available without QQ16 acquisition, decoding or
service. It cannot be credited exclusively to recovery. The package supplies a
source-bound complete-root action comparison and a new guarded protected-child
return mechanism. It does not establish that QQ16 improves over this baseline,
Turing-step dominance, a practical runtime speedup, or a new multiplication
exponent. The selected κ remains836330098538459/500000000000000000.

## What the comparison does and does not decide

The exact identity T_D−T_A=(T_B−T_A)+(T_D−T_B) separates generic protocol work
from recovery. The literal census identifies503674Γ retained calls with matching
payloads under #4166's semantic refinement and6972Γ changed-core calls. The
expanded header adds14,102,872Γ actions on that matching-payload subset,
including13,806,716Γ in the later suffix. This is a header component only.

An actual obstruction to a *proposed proof* was found: separate closed numerical
engines retain free-slot ordering, and slot identities occur in encoded words.
Closed flags alone do not cancel their complete traces. Shared primitives solve
that problem constructively for B. No impossibility or losing-runtime theorem
for independent engines is inferred. Frozen D retains a signed nonheader context
residual, the changed-core differences,336Γ service calls,32Γ added producer
calls,16Γ removed centres and the complete nonchild difference. Unknowns are
explicit, not zero. The isolated368C1 versus16C8 screen remains an inherited
component result and supplies no total-runtime sign.
