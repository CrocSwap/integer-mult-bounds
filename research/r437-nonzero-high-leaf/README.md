## Chart and independent output derivation

Let P be the exact source preparation modulo 9. For active index i=0,1 and
inactive j=i+2, use the invertible 2×2 header block `[[1,1],[p_i−1,p_i]]`, determinant
one. Elsewhere use the identity. Set chart=header·P⁻¹. All chosen p_i are 2 modulo
3, so these charts share one actual compiler-resolved GOOD low class. Their
canonical high digits `(chart−low)/3` lie in {0,1,2} and are nonzero. The independent
oracle constructs the rank-two projector header[:,0:2]·header⁻¹[0:2,:] and checks
its actual leading pivots. A diagonal scaling alone would leave this projector
unchanged, so it would not be a discriminating high-field fixture.

Ancestor pivots are [2,5]. For child coordinates 0 and 1 the ancestor's
floor(2048/64)=32 gives pivot0. Root unit2 therefore contributes 4, while the
current 64→2 step contributes p_i. Current pivots [2,5] and [8,2] yield [8,2]
and [5,8]. The three ADDs request λ, −λ⁻¹, λ, each once per split and merge.
Runtime `Word.inspect` is disabled; the observer saves the original method to
compare outputs and never returns decoded data to the algorithm.

For one paired coordinate, the literal eight primitives have pullback matrix
`S A(λ) S A(−λ⁻¹) S A(λ) S D = [[0,λ],[λ⁻¹,0]]`, where
`A(c)=[[1,0],[−c,1]]` and `D=diag(1,−1)`. For coordinates `(x0,x1,y0,y1)` the
independent permutation is `(λ0*y1, λ1*y0, λ1⁻¹*x1, λ0⁻¹*x0) mod9`.
The verifier enumerates all 9⁴ coordinates per fiber, checks bijectivity, and
compares every output bit. Reusing prefix0 weights for prefix1 and exchanging
weights with their inverses both change the dirty expected output.

## Exact finite restriction and intertwining

The production `directory.Odometer.advance` increments the last matrix entry
first. Thus `n(H)=Σ H[k]3^(4095−k)` is the high index. The verifier constructs and
decodes the two distinct indices and checks every local coordinate's global
offset `E_i(j)=n(H_i)*9⁴+j` within this fixed old-prefix and low-class
block. This is a global high-cube offset for that block, not an asserted offset
through all old prefixes, low classes or full-parent spectator coordinates. It checks `floor(E_i(j)/9⁴)=n(H_i)` and
`E_i(j)%9⁴=j`, and that the independent permutation stays in that same fiber.

This indexing alone is not the separability argument. In authenticated
`packet_engine.run_generator`, each primitive resets an output tape, loops over
complete prefixes, calls `read_prefix`, copies exactly one `shape.fibre`, executes
the primitive on that local tape, and appends its return. No primitive reads a
neighboring prefix's payload. Coefficients read the current complete prefix plus
the same borrowed Program. `episode.xor_packet` loops old prefixes, then
`context.highs`, then exactly `fibre` bits and performs pointwise XOR. Therefore
for each fixed full prefix, projection π_i commutes with each primitive and the
XOR consumer; induction over the finite trace gives π_i T = T_i π_i. Embedding
commutes on the selected support, with all other fibers left to their own T_j.
No claim is made that full T is identity on omitted fibers.

The explicit adapter sets prefix count and the consumer's `context.highs` to 2,
and supplies precisely those two complete prefixes in matching payload order.
It replaces infeasible independent copies only. It does not replace a numeric
primitive or callback. Full `3^4096` enumeration, full parent spectator expansion,
GL64 gather and physical field generation are unexecuted. The two represented
prefixes have different dirty data and weights; source and target bytes/heads
must remain unchanged. This is not an inference from one repeated fiber.
