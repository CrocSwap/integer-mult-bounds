# Generated binary compiler route ledger

This appendix supplies elementary dyadic words and explicit count recurrences for the selected compiler's actual carried-basis grammar. It extends the completed 513-entry finite route catalogue to generated products, tensors, direct sums, complete placements, positive image splits, matchers and guarded sectors. The original coupled-port bases and shared routes are preserved.

Read [PROOF.md](PROOF.md) for the theorem, source-to-constructor map and exact limitations. The proof is frozen at SHA256 `8c9d8e631325f6b67e8a0863eda8602ff51095d3488c95de5e714d1cd4100a6d`. The author verification is complete; separate peer review is attached at integration rather than inferred from the author's pass.

The seed dependency is explicit: 636 raw complete frames, eight rank-reference complete bases and 111 original port bases receive genuine Euclidean words. The 513 relative matcher words then supply all 513 normalized complete bases. Generated nodes need no new pivot search or matrix-rank decision. Their linear word coefficients remain within 94 addition coefficients and 15 scale coefficients; low-controlled carry coefficients are a separate obligation.

For a dimension-N route with t swaps, a additions, u earlier-target additions, d fixed scales and h signed scaling atoms, the directed bill is `N(t+2u)` ordinary swaps, `Na+N^2` shifts/translations and `Nd` fixed scales, or `Nh` signed atoms. Both directions are charged. The guard `L_E(S)` has recurrence `2n c(B_E)+rank(E)c(S)`. These are the counts of the constructed words; the earlier generic cubic counts and the finite eight-dimensional maxima are not substituted.

## Evidence

Strict normal and optimized executions agree byte for byte. The independent data interpreter imports neither the factorization engine nor the producer. It checks 755 source seed words plus three controls, 513 derived bases, 25 constructor fixtures, 150 full prime-power route cases and 16,038 high-coordinate checks. All 111 port bases, 1,998 port-stage symbol ledgers and 4,218 caller-target ledgers are included. A literal pinned compiler trace with a normalized mock callback checks complete placements and nested returns; it is not a new native or erasure theorem.

`EVIDENCE.json`, `EVIDENCE-OPTIMIZED.json` and `RECEIPT.json` are frozen. Reproduce without rewriting them:

```sh
python3 -W error -I -B verify.py
python3 -W error -I -O -B verify.py
```

The deterministic stdout is the receipt. An optional `--output /tmp/filename.json` writes a separate copy. `build.py` is the explicit certificate producer; it regenerates the emitted data and is not run by ordinary verification. `factor_words.py` contains the lazy word constructors. Normal package replay uses only Python's standard library.
