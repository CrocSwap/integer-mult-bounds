# Design and acceptance plan: actual phase-recursive interfaces

Cao Yifan; substantial OpenAI Codex assistance. Apache-2.0.

The target is a complete arbitrary-input recursive supplier that improves the
conditional PR4610 value `kappa=0.0030217758`. The retained round6 pair algebra
and layout audit are frozen inputs. Root owns the live PR/comment/rigidity
metadata. This package does not resume the user's mistaken PR4160 reference.

## First discriminating question

`S(X_(q tensor ones_f))` is one global Clifford transvection on f columns.
It is not the tensor product of f single-column S gates. A fixed number may
change symplectic rank only by a constant, so treating it as cancellation of
one f-column Gaussian direction may be invalid. Establish the exact bound,
including arbitrary intervening monomial owner routes and conjugations,
before giving a recursive target any credit.

## Candidate new job types

1. **One global translation phase:** arbitrary coefficient array, fixed q,
   selected column group J, compute `S(X_(q tensor 1_J))`. Its complete
   compact movement cost is inherited from the layout audit; no independent
   Gaussian helper credit is attached.
2. **Grouped phase encoding:** a disjoint partition of columns, each block
   retaining its explicit global-Pauli encoding at input and output. A child
   may use an already encoded batch only if its actual endpoint preserves
   that same encoding and all helper inputs remain arbitrary. All initial
   stock, terminal conversion, block partitions, owned streams, precision,
   and recursive width changes are part of the type.
3. **Recursive split/merge phase:** attempt to factor the desired tensor
   gauge through two subgroups plus a global phase and a funded interaction.
   Derive its exact Pauli/Laurent identity first. Any missing controlled
   interaction remains a paid job; its endpoint is not relabelled as a query.

## Work order and acceptance

* Prove or refute the fixed-count rank barrier in the actual symplectic
  address model, then test the first nontrivial block split on arbitrary
  inputs at f=2 and f=4.
* If a recursive split identity exists, specify producer/consumer types and
  a recurrence with every interaction, encoder/decoder, helper and owned
  stream charged. Map the recurrence to the inherited tape exponent.
* Only a complete positive invoice may feed the exact kappa calculation.
  Verify any positive finite endpoint by the actual native interpreter and
  prove the new reusable algebra/inequalities in Lean.
* A scoped negative result is acceptable. Finite examples are distinguished
  from the all-f identity, machine admission and full conditional theorem.

No staging, commits, publishing, or external posts are performed by this
subtask. No construction is admitted solely from Gaussian/Walsh similarity.
