# A productive controller without idle transforms: a formal border and its costs

Deleting every whole-idle transform from the query-thinned controller produces
an explicitly triangular endpoint for **every pair count p**. A scalar
conjugation by powers of an auxiliary parameter makes its independent monomial
outputs the constant term of a degree-(p-1) polynomial. This changes the endpoint
interface rather than optimizing a fixed native invoice.

The result is a **formal border construction, with scoped recovery and budget
obstructions**. It is not an exact admitted supplier, a new kappa, or a selected
frontier update. Its separate finite complex approximation lemma identifies
sufficient numerical hypotheses; it does not complete the recursive caller.

## Why this question, and what happened

The donor requested an ambitious, risky avenue and at least five minutes of
strategic selection. Between the refreshed guidance read at 09:59:29 UTC and
selection at 10:05 UTC on October 22, 2026, we compared quotient repair
[#4596](https://github.com/CrocSwap/integer-mult-bounds/pull/4596), native caller
integration [#4554](https://github.com/CrocSwap/integer-mult-bounds/pull/4554),
compiler widths [#4586](https://github.com/CrocSwap/integer-mult-bounds/pull/4586),
and a changed controller interface. The live
[#4602](https://github.com/CrocSwap/integer-mult-bounds/pull/4602) handoff identifies
whole-idle transforms as 56–59% of the paid moment. Removing that work on both
suppliers was a plausible structural route toward the declared kappa>.01 target.

The exact algebra succeeded. The full budget rejected that target: removing
idles also removes their credited output ranks. Even granting recovery free,
a determinant/Jensen bound excludes supplier saving C>=.006 complex and
C>=.007 BIT for every positive p in the stated fixed-inventory model. We have
stopped that target rather than relabeling a smaller formal gain as success.

Two natural recovery routes also fail. Repeating the whole controller K>=2
times loses every concave moment, even when each evaluation earns all its
fresh independent helper outputs. A copied-input decoder needs p-1 new query
jobs per port to correct the X block, and that bill already loses before the
Y block is corrected. Neither result excludes shared internal queries,
cross-port constructions, different native words, or other output contracts.

## Full boundary and expansion decision

Inputs are the existing arbitrary main fields plus separate arbitrary helpers
for every full native call. Scalar parameter wrappers act only on mains.
The formal constant term gives separate target operators; at a nonzero
parameter the main outputs are coupled. Owned copies and centers earn no
productive credit. Helper restoration and main ownership follow the source
contract; exact recovery must preserve them.

| Obligation | Status |
|---|---|
| Retained full native calls, thin queries, helpers and changed main ranks | Explicitly counted; source native/physical contracts inherited |
| Whole-idle calls | Deleted from both paid work and corresponding target rank credit |
| Formal endpoint and singular scalar wrappers | Proved algebraically; inverse parameter powers prevent evaluation at zero |
| Repeated evaluations with fresh helpers | Constructed at the linear-operator level under copying/combination assumptions; optimistic paid budget fails |
| Per-port copied-input X correction | Exact logical construction and rank bound; full added-query budget fails |
| Shared-work exactification, all-column physical scalar implementation, legal amplification | Unknown; not priced as zero in an admitted construction |
| Global approximation and recursive precision | Finite sufficient lemma only; actual caller and runtime obligations remain |
| BIT scalar extension and return to ordinary BIT | Unknown; complex small-parameter rounding does not supply it |

Decision: retain the new formal interface and the negative full-cost decisions;
stop fixed-inventory attempts at the original .01 target. Do not expand into
more pair counts or scalar-weight searches. A further construction round must
change a costed native/query/output premise or close the recovery contract.

## Reproduction

From the repository root, Python 3.12 and standard library only:

```sh
python3.12 -B scripts/research_package.py --package research/controller-border-interface
python3.12 -I -O -B research/controller-border-interface/verify.py
```

The verifier authenticates three live inputs, compares every Laurent coefficient
for p=1..8, checks exact budget certificates valid for all p, and runs a separate
rational event implementation at p2/p3. Controls include incorrect orientation,
reversed parameter weights, lost decoder queries, duplicated main credit,
omitted thin-query charges, polynomial degree growth and underfunded precision.
The exact receipt is regenerated only with the explicit authoring `--write`
option. [VALIDATION.md](VALIDATION.md) records actual execution and export checks.
No complete native, selected cold replay, Lean or historical suite is claimed.
