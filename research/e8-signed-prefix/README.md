## Reproduce

Use Python 3.11 or later, NumPy, SymPy, mpmath, a C++17 compiler, and Boost headers. Install `requirements.txt`, then from any directory:

```sh
python -B verify.py /absolute/path/to/a-new-output-directory
```

The output directory must be new and outside this package. Set `CXX` if the compiler is not `g++`; set `BOOST_INCLUDE` if Boost is outside its default include paths. Do not use Python `-O`. Verification is offline and runs this changed composition; it does not fetch or run public PR verification pipelines. All source dependencies are bundled.

`verify.py` checks the manifest, rebuilds the R781 baseline and signed word, audits dirty columns and private restoration in both orientations, audits exact Gaussian phases and the global finite template, certifies the paid moments by two exact engines, checks the bit component, then evaluates the 47 outer inequalities. Final results appear in the output directory. No discovery search is needed to reproduce the fixed witness.
