# One clean core in the original complex frames

This package gives an exact local construction and its original-owner
binding at every positive tensor width. One raw core, with the stated
physical ADDs and signs, restores all 480 arbitrary helper contents.
No helper input enters a data output. The eight selected helpers keep
their original complete physical `F9` jobs; the other 472 helper jobs
are unchanged. No field, native child, address map, or phase map is added.

The data kernels are

```text
D_plus  = I-KR+KRQ,
D_minus = I-KR+KRQ^-1,
F(x,y)  = (x,y+D_plus x),
B(x,y)  = (x-D_minus y,y).
```

The products have their displayed order. `D_plus` and `D_minus` are
distinct on the actual native operator at every positive width. They
are not a reciprocal pair supplied by this theorem. The global changed
data word still has to satisfy `E=W^-1` at the original terminal.
This package does not prove that condition or improve complete kappa.

[PROOF.md](PROOF.md) gives the ordered construction, whole-helper
substitution, and terminal condition. [DIRECT-SOURCES.json](DIRECT-SOURCES.json)
identifies the complete original proof and the three separate reviews.
[SOURCES.json](SOURCES.json) pins all retained inputs. The old source
note lists physical and owner reviews as future work; the later reviews
retained here complete those local obligations within their stated scope.

## Replay

Use Python 3.11 or later with its standard library. Run one process
with at least 3 GiB free. The output directory must not exist.

```text
python3 -I -B replay.py --out /tmp/original-clean-source-replay
```

This runs three decisive checks normally and with `python -O`:

1. All 704 formal input columns in the free ordered port algebra,
   with every helper row and each stated negative control.
2. Literal physical prefix/core/suffix binding, retained native event
   order, exact helper endpoints, and native phase witnesses.
3. Original owner and helper-job binding, unchanged phase schedule,
   retained complete profile, and the ordered terminal condition.

All six receipts must equal the frozen receipts byte for byte. The
final output is:

```text
PASS_ORIGINAL_CLEAN_SOURCE_INTERFACE
```

The replay uses temporary copies. It keeps source files unchanged.
Two checkers read five exact archive members from local files instead
of opening the large selected archive. Every member hash and every
mathematical check remains. The full original archive hash was checked
at extraction. The original scripts, portable scripts, and exact diffs
are recorded in [PORTABLE-ADAPTATIONS.json](PORTABLE-ADAPTATIONS.json).

The raw native kernel proof, its dense phase compiler, and the old
complete owner-axis history are pinned inherited premises. They are
not rerun by this command. A successful replay does not prove the
global data controller, finite precision, recursive invoice, parser
admission, integer recovery, or a complete multiplication theorem.
