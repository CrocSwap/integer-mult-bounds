# Independent review of the sign-metric capture annex

The annex passes for its stated matrix and reader claims. It gives a
24-exception response with correction rank 16, a whole selected-reader
obstruction, and a 32-FULL/16-centre Gaussian-dyadic unit construction.
The minimum of 32 applies only to the stated blockwise class. A separate
option retains the first response and expands the read set to 32 fields.
No native word, complete invoice, or complete kappa improvement follows.

This is a fresh review by a separate OpenAI Codex agent. It does not
claim independent human review or a formal-kernel proof. The accepted
main encoder package and its earlier review remain unchanged.

The [annex README](../../../centre-metric-encoders/annexes/sign-metric-capture/README.md)
states the adopted claims. The
[first proof](../../../centre-metric-encoders/annexes/sign-metric-capture/frozen/root/SIGN-METRIC-INVOLUTIONS-20261020.md)
uses S=I-ww*D with w*Dw=2. Direct multiplication proves the involution
and sign-metric identities. Its correction has rank one in each of the
sixteen disjoint mode blocks. The exact physical pair code commutes
with D, and its Gram matrix has constant scale on each invariant size
component. This proves the corresponding identities for A=H^-1 S H.
The full response A is a unit of rank 112. Its correction A-I has
rank 16, its determinant is one, and its trace is 80.

The 24 exceptional diagonal coordinates have the stated pair closure.
The ordinary physical principal block and row support are preserved.
All 24 selected columns change within ordinary rows. The construction
therefore cannot inherit a theorem restricted to selected-row changes.
For diagonal unitary Z commuting with D, the ordered identity is
D(ZA)*D=(ZA)^-1. This proof does not commute A past Z. Intervening
progress, code boundaries, signs, and final phases remain obligations.

The [reader addendum](../../../centre-metric-encoders/annexes/sign-metric-capture/frozen/lanes/oblique-native-20261017/sign-metric-review-20261020/READER-ADDENDUM.md)
proves a whole-reader obstruction, not only a failed square minor.
Each of eight small rows has a single selected coefficient with norm
five. The ring map to F5 with i mapped to three kills those rows.
A right inverse over Z[i,1/2] would reduce to an impossible right
inverse of that rank-deficient matrix. The claim concerns arbitrary
normalization from those 24 columns. It does not exclude code-image
division, other columns, or a different representation.

The [unit-capture proof](../../../centre-metric-encoders/annexes/sign-metric-capture/frozen/root/SIGN-METRIC-UNIT-CAPTURE-20261020.md)
uses two selected entries of norm two in each small block. Their reader
coefficients are Gaussian-dyadic units. The actual original centre
pivots give a unit minor after the pair code. Thus L=V_P^-1 V satisfies
L_P=I and LA=-L. The row code C has C_P=L and identity ordinary rows.
Its difference from the identity has only centre rows and noncentre
columns, so its square is zero. Both inverse orders hold on arbitrary
arrays, with no clean-input promise.

The actual C fails C*DC=D. The sign-only adjoint conversion for ZA
therefore does not pass to ZCA. The complete caller must use the actual
coded response. The unchanged-response option in the
[unit review](../../../centre-metric-encoders/annexes/sign-metric-capture/frozen/lanes/oblique-native-20261017/sign-metric-unit-review-20261020/REVIEW.md)
has a different small centre set. Its exact unit minor requires the
expanded 32-field read set; it does not remove the original obstruction.

The blockwise minimum is valid with all stated hypotheses. A rank-one
sign-metric reflection with one exceptional diagonal coordinate in a
k-mode block requires Gaussian rational norm k-3. The norm-three
descent excludes one exception for a six-mode block. Zero exceptions
contradict its trace. An eight-mode block can use one exception, but
its sole FULL reader coefficient then has norm five and is not a unit.
For arbitrary blockwise normalization, a second FULL field is required.
The two fields per block give 32 in total, and the construction attains
this count. The argument requires independent rank-one blocks, a
diagonal sign metric, and every exception and reader pivot in the FULL
set. The actual pair-closed representation preserves that split.
Coupled blocks, higher rank, other frames, other representations,
code-image division, and general native algorithms are outside it.
