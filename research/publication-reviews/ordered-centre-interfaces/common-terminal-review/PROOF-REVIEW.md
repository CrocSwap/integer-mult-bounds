applies `Q`, then `F E^-1 F^-1`, then `Q`. This gives `F Q x`.

therefore returns `(F Q x,F y)`. The argument uses commutation of `F`
with payload line transforms. It requires no commutation of `E` with
the port-dependent `Q`.

## Sharpness and cost class

For any admitted orthogonal extension with `Lq=v` and `q^T v=0`, set
`w=L^-1 q`. Then `q^T w=(Lq)^T q=0`. Both vectors have norm one, so
they are distinct and independent. The terminal Fourier block
`q q^T+w w^T` has rank two. Monomial Clifford maps preserve this rank.
For a product, `B=A_left B_right+B_left D_right`, so rank is at most
the sum of the factor ranks. Thus a standalone one-field Clifford
terminal needs total native rank at least two. The emitted child
attains the bound.

This lower bound does not cover a circuit that mixes fields, fuses an
earlier native call, changes the first line cut, or gives the logical
response a nontrivial payload action. In particular, it is not a
general terminal or multiplication lower bound.

For four pairs and 112 ports, the inventory is 448 rank-two children,
native rank mass 896, 896 child wrapper maps, and 448 FULL source maps.
There are 1,344 monomial maps in total. Removing the old 448 line-square
maps gives 896 additional maps. The 448 signed exchanges retain their
1,344 unit complex ADDs and 10,752 real primitives. These are counts,
not a complete finite execution price.

The native-moment conclusion has a further premise: the complete
productive path and idle ledger must have rank `2mn(D-1)` before the
terminal. With this premise, the terminal gives total rank `2mnD`.
For `r<=D` and `b>0`, `r^(1-b)>=r D^-b`. Repartitioning the same rank
cannot give a positive native saving. This review does not verify the
full hosted path ledger. This dimension-73 common-response terminal is
distinct from the two dimension-25 one-pair terminals in the parent
