## Scope and proof review

The complete source proofs and their retained independent reviews were read.
The seven replay checkers and the code used for their mathematical checks
were read. The review also covered the common-grid and fixed-odd scan
dependency, the whole-state type proof, the actual D25 join proof, its
retained-reader query proof, and the inherited local native phase review.
The [proof index](../../centre-code-services/PROOFS.md) links these
sources. The following distinctions are required for acceptance.

**Moving entry.** The four ordered updates implement
`((I-JD)a+Jz, Da)` when `DJ=I`. Direct substitution proves both the
arbitrary-input endpoint and the involution. One use stores the old centre
bank in the data. It does not erase or restore that bank. The actual entry
is the conjugate by `L=Q^2`, so both translation passes are required.
The separate bank contains 30 or 16 fields. The square code on 112 data
fields is a different storage contract and has its own inverse.

The rank-30 square section uses an actual unit minor with determinant
`-1/256` and integral inverse. The sum-code claim requires dyadic `U`, `V`,
and `U_P^-1`; the minor hypothesis alone does not suffice. The frozen root
text is read with its explicit proof addendum. The new README states the
full qualification. For the older fixed reader, `QU` is a section of
`T^-1 VQ`, not of `VQ`.

**Transport.** The four code types retain their operator order. Every
advance needs the stated commutation premises. A routed advance must
satisfy the actual matrix relation or a proved connecting operator.
Nominal frame names do not imply this. The encoded exit requires the
ordered raw decode `Q C^-1 Q`, and the physical cross-bank calls retain
their odd phase. The four-step cycle is not an admitted interleaved caller
and does not remove the final code at an odd cut.

**Fixed-reader phase inverse.** The checker verifies both product orders
of the supplied exact inverse certificate on all 512 characters. The
translation group and XOR character argument extend the identity to every
positive tensor width; this is not an extrapolation from width samples.
The physical inverse has 2712 terms, common denominator 120, and exact
infinity norm `88/5`. Explicit coefficients require both odd factors 3
and 5. The additive reader service retains an arbitrary centre baseline
through its paid multiply/add/divide word. The complete swap costs 208028
old dyadic real primitives, 12072 translation calls, and 60 real scans in
each direction at 15. It still has the fixed-reader terminal mismatch.
The review checks a certificate, not a second inverse-finding algorithm.

**Constant and rank-16 code services.** The actual `B` and `H` matrices,
both inverse orders, scalar words, prices, and prefix bounds agree. The
rank-16 scalar centre action works under independent linear field frames;
it does not supply or admit those fields. The whole-bank response code
has eigenvalues `1` on 96 dimensions, `-5` on eight, and `-7` on eight.
Its two exact words each use 3420 old real scalar primitives plus 32
real fixed-odd scans. This response code is distinct from the unitary
`C16` packing in the encoder package.

The signed scan proof gives exact division only on its declared integer
domain. The checks cover the finite carry state and sign rules, valid-image
decoding, and generic-grid requirements. Odd scan costs do not include
unpriced descriptor work. A valid code image and an arbitrary rational
input are different contracts.

**Rank-30 rational capture.** The code image has exact quotient
`(R0/3R0)^11 direct-sum (R0/5R0)^11`, where `R0=Z[i,1/2]`.
The syndromes, explicit right inverses, and Chinese remainder argument
prove the image test. The argument correctly treats `R0/5R0` as a split
ring, not as `F25`. The complete matrix test includes helper and address
columns. The data-ADD and helper-ADD failures demonstrate why a middle
operation needs an image-preservation proof.

The literal capture and inverse each use 2910 old real scalar units and
44 real odd scans. Their complete action chains use 6090 old units plus
22 real multiplications and 22 real divisions at each of 3 and 5. The
checks cover all 640 arbitrary input columns and keep 528 outside roles
fixed. Valid code chains have exact divisions without an odd root scale.
These common-frame scalar words do not establish physical native capture.

**Conditional type theorem.** The whole-state endpoint is
`C_out A C_in^-1` with a dyadic semantic `A`. Equal adjacent types cancel
in order, without a commutation assumption. The theorem requires a bound
at each decoded child entry and within each local prefix. Under those
premises it gives odd height at most `(D+1) ell_p+c_p`. The root needs an
identity type or paid encoding. Exact final unscaling needs a dyadic
physical endpoint, and a raw result needs removal of the final code.
The finite noncommuting-code example and failed mismatched-code control
support these distinctions; they do not discharge a complete caller's
premises.

**Six D25 forward joins.** The checks cover two providers and the three
pairs `(s,t)=(0,1),(0,2),(1,2)`, on all 640 input columns. The retained
reader index is `s`; the physical entry level is `t-1`. In particular,
pair `(0,2)` starts at physical level one. The bank baseline is arbitrary.
The exact content relation, DATA phases, route involutions, and complete
regular-cover barrier support the joined service. A query after each
single body would need a separate source-availability proof.

The service has 17624 scalar primitives, rank mass 1792, and 5776
monomial map calls. The join introduces no new field or odd division.
The inherited 416-role helper supply and restoration contract remain
premises; the DATA partition does not construct that host. The replay
checks all 35 consumed phase-source hashes and the new phase equations.
It does not rerun the inherited 4194304-coefficient spatial interpreter.
An abstract inverse-adjoint identity does not supply a literal complete
backward native service. No such service is claimed in this package.

phase-inverse summary now states positive tensor width. A copied source
receipt now names the actual retained common-grid path under `notices/`.
The corrected receipt and its manifest were checked. Neither change
alters a frozen source or a replay input. No repair or new research was
needed to support the accepted claims.

spatial phase suite, a complete recursive supplier, the selected-frontier
replay, or Lean. Native-child precision, helper hosting, finite map prices,
productive interleaving, final code removal, and full caller restoration
remain the explicit obligations stated in the package. The historical
sources are not transplanted into the current selected construction.
Publication, GitHub link checks, and rendered PR checks are separate work.

The final source and notice scope is sufficient for this package. No
unresolved dependency gap was found within the seven selected checks.
