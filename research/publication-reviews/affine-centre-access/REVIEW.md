## Proof assessment

The common-form argument proves
`dim L <= r+n floor((lambda-r)/2)` and hence the stated sharp bound
for `n>=2`. The pair construction attains it at every positive width.
The equality classification correctly requires a third row. Its
`n=2, lambda=2` diagonal example explains why that restriction is
needed. The fixed-residue cover retains the domain condition
`W_0 subset omega^perp` and the separate `n>=3` qualification in
the cover amendment.

The signed Haar code retains both outputs of every two-point map.
Only the active output is refined; every detail is available for the
inverse. The identity `B^-1 E B=P Pi P^-1` therefore gives the claimed
shear on arbitrary source and target values. The source restores, and
the target retains its arbitrary complement. The alternative source-copy
construction clears only owned copies. Neither construction assumes
that an arbitrary borrowed signal is zero.

The code and inverse use a geometric sum of active record volumes.
The address maps have a separate paid compact-control bound. The
stated `O(V((e log p)^tau+1))` result uses complete guarded records,
fixed native dimension, and the pinned fixed-tape primitives. It is
an asymptotic local bound, not an explicit finite machine invoice.

At odd width the code retains one physical leaf bit. Its signed
translation formula gives the stated `C_u` leaf action and the
ordered frame correction `O_t O_s^-1`. The total tensor phase
convention in the amendment is necessary and is included in the
proof map. An additional outer address map is not discarded.

The quarter turn uses the ordered leaf map `(-D^-1 b,D a)`. With
`LJ=I` and `JL=Pi`, block multiplication gives fourth power identity.
Both arbitrary complements remain unchanged. For different odd-width
frames, the direct saved-operand two-point map supplies the stated
precision bound; the proof does not infer it from separately rounded
kernels.

The fractional-bit and magnitude-bit bounds apply to the stated exact
dyadic-grid words with saved local operands. No internal rounding is
used. The bare inverse code on unrelated encoded coordinates has a
larger norm, and the independent stream review checks this distinction.
Recursive use remains conditional on a valid dependency-path envelope
for the changed controller. Zero added native children alone is not
used to establish that envelope.

For the literal Haar-tree limit, every nonconstant affine binary test
adds one codimension. Branch-specific affine chart changes preserve
this fact. The double count
`T=sum_v |A_v|=sum_l |A_l| depth_l` includes accepted leaves, rejected
leaves, and retained details. Thus `T>=k|S|`. The fixed-record-width
premise gives `Omega(k delta V)`. The exact positive limiting density
then gives `Omega(lambda V)` at fixed `n` in this class. The proof
does not cover general linear circuits, non-affine blocks, overlapping
cancellation, productive native children, or a query that does not
form the full projector.

The density formula and the exact `n=73` threshold use rational
arithmetic. The independent recurrence, closed alternating-form count,
dual spectrum, and literal small walks agree. The value `2^-2700`
and width 152 are scoped to the sufficient all-odd sector. They are
not promoted to an actual-supplier maximality or useful finite-budget
lower bound.
