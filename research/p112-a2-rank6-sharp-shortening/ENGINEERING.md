# Verification boundaries

Separate Before Serializing Shared State gave this result its own worktree,
branch, package, status and cache. The common OS-released Git lock covers only
short shared metadata operations. No sibling artifact is mutated.

Prove It Works changed the boundary check from a counting equality to a literal
thirty-coordinate cut, exact piece coefficients, binary ranks six and rational
intersection rank two. A separate checker reconstructs the lattice and labels,
checks the closure inventory through distinct ambient restrictions, and proves
the same rational ranks by exact identities plus modular lower bounds.

Power of Ten review covers all three new Python entry points. Control flow has
no recursion. Every loop iterates a fixed finite collection, with largest
bounds 788,035 inherited six-spaces, 390,625 independent lattice candidates,
80,730 five-label subsets per class, 2,667 five-spaces per class, 1,120 planes,
512 binary vectors, 120 roots or 112 matrix rows. Registered commands time out
at 120 seconds. Functions are below sixty physical lines after formatting.
Explicit ValueError contracts remain active under optimization. Source hashes
are checked before loading the sole executable dependency by absolute path.
No dynamic evaluation, generated source, callbacks or shared mutable state is
introduced. Source imports use Python's required loader interface.

Python requires dynamic allocation, a deviation from fixed steady-state
allocation. Live collections are bounded by the inventories above. The
independent generated-five-space set has at most 80,730 entries of at most
32 nine-bit values per class and is released before the next class. The
inherited flat census uses fixed 113-entry histograms and 512 kernel masks.
No process, network, native build or heavy replay is launched by the verifier.
The inherited geometry remains unchanged; its legacy dynamic allocations and
iterator loops are constrained by these fixed nine-bit dimensions.

The optional receipt writer creates a new external file exclusively and checks
the returned byte count. Compilation with warnings as errors and Ruff's
E,F,I,B,UP,PLE,PLW,RUF checks run on each changed Python file. Project-wide lint
configuration is outside this isolated research package.

The independent checker does not reprove six-flat capacity, chamber
classification or reflection transitivity. The primary checks their finite
premises. Neither executable formalizes the Weyl-chamber theorem or the
characteristic-zero lifting argument. The selected cold replay is unrun
because the selected construction is unchanged.
