# Mixed BIT fallback descriptors and stream adapters

We complete the mixed fallback transcript beyond PR2188's diagonal-pair
descriptors. Each shear uses its intermediate original-row permutation;
we retain that snapshot when reversing elimination and bind the coefficient
to the actual physical target orientation. We execute the resulting ADDs
through PR2171's sequential routine and pass generated descriptors to the
remaining weighted children.

We prove the composed fallback endpoint conditional on completed children
and their workspace contracts. We retain the 98,682-child allowance and
claim no new supplier exponent. [PROOF.md](PROOF.md) states the domain,
preparation estimate, child contract and selected parking application.

## Concrete changes

For the selected rank-42 residual, an upper shear has logical coefficients
`[21,21,16]` modulo25. Its middle lower ADD targets a reversed tail field,
so physical execution needs `[16,21,21]`. We test the resulting record
movement and reject the original-target orientation.

A second selected path has both good and fallback ancestors. Its current
ADD needs coefficient `9`, obtained as `-1/11 mod25`; reading only the low
ancestor residues gives `24`. We run both descriptors through the physical
ADD and compare their payloads. The evaluator receives full exposed headers
and has no unused-row argument.

For row swaps we keep an unweighted swap and update the moving row labels.
For shears we use the permutation at that step; for diagonal pairs we use
the final permutation. A complete Z/9 example shows why the distinction
matters: the wrong rule leaves an uncleared entry equal to 5.

## Evidence and reproduction

From the repository root, use Python 3.12 and its standard library:

```sh
python3.12 scripts/research_package.py --package research/selected-bit-fallback-streams
```

The registered commands authenticate local and vendored sources, run the
checks normally and with `-O`, and compare [RESULT.json](RESULT.json).

We check eight complete 128-coordinate operators across four selected
fixtures, retaining all 16,256 shear slots per fixture. We also execute:

- A complete four-atom address program over Z/9 across three parent headers,
  with unused and gap fields: 1,338,444 payload bits, twelve ADD passes and
  nineteen width-one completed-child calls.
- A complete eight-atom program over Z/3: 85,293 bits, twenty-four ADD passes
  and thirty-one completed-child calls, including twelve reversal children.
- Two selected two-operand physical fixtures, 32,500 bits each, and a
  sequential fixed-sign pass on 669,222 bits.

The complete programs use exact, charged F_a oracles for recursive children.
We implement the ADD/sign adapters as sequential tape passes; we do not
claim that the oracle's random-access permutation model implements a child.
We record each child's width and full logical volume. We compare payloads
against direct address-matrix actions independent of the emitted factors.

The controls reject final-permutation substitution, lost physical orientation,
low-only mixed ancestry and one missing reversal child. Zero and nonzero
nonunit coefficients occur in the complete Z/9 payload program.
