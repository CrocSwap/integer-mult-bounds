## Reproduce

Python 3.11+, a C++ compiler, and Boost headers are needed for a fresh native replay. No optimization solver runs during verification. The output directory must be new and outside the repository.

```sh
python -B research/k8-three-demotions/verify.py \
  --base "$BASE" \
  --work /tmp/k8-three-demotions-fresh
```

`BASE` is the original R480 k8 + seven-slot raw word identified in `../k8-eight-ends/RECIPE.json`. This command rebuilds the preceding T16 witness, the changed word, its native artifacts, and strict global admission. Set `CPLUS_INCLUDE_PATH` for Boost if needed.

To reuse explicitly supplied completed replays, use `--parent-from /path/to/k8-eight-ends-t16-replay` and `--native-from /path/to/new-native-replay`; `--base` is then unnecessary. The former must be a completed `../k8-eight-ends-t16/verify.py` run. The latter must contain the five completed native stages for this exact new word. The verifier checks the word and semantic artifact identities, every consumed parent file, and reruns the independent local audit, semantic controls, and complete global admission.

All admission engines are byte-identical to the PR1074 sources already pinned in `../k8-eight-ends-t16`. The new driver binds the changed local provider to the same pinned T16 geometry and checks every original geometry field. The unchanged independent T16 checker reconstructs actual source-event windows and recounts the new word's recursive profile. No admission condition is removed.

## Search and limitations

The search tested 306 codimension-one entrance subspaces: 186 reductions from dimension five to four and 120 from four to three. The latter performed worse in the floating packing screen. Individual favorable five-to-four reductions compose profitably through three groups; adding all six performs worse. Only the frozen three-group composition is fully admitted here.

Producer-side elimination was also attempted on 19 target-only helpers. Two fall outside the B-only rewrite's preconditions. The other 17 failed frame feasibility, including a search of 61,674 constant-value delivery placements/orderings. These are scoped negative results, not a general lower bound on helper count.

The new word has its own exact fixed-family all-replica grid upper bound, **0.001675129371412064**. That bound does not cover mixtures of different local words or further interface changes. Such changes remain a route to additional gains. See `SEARCH.json`, `PROOF.md`, and `NOTICE.md`.
