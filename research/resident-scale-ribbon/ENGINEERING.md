# Verification and implementation bounds

Playbook: autonomous local run. Exit predicate: one original, verified resident
SCALE transition saving, packaged for independent review. Stop after that step.
Build the Lever led to a retained physical compiler and deterministic verifier.
Prove It Works led to literal metered execution and full endpoint comparisons.

The new call graph is acyclic. Compiler loops are bounded by W <= 64, D <= 64,
at most 24320 gates and 220000 emitted instructions. Each unit seek has a bound
from the fixed tape capacity. Tape storage is allocated once at construction,
with at most 131072 bits per tape. Transfer length is at most 8192 bits. The
scientific suite has 129 basis columns, 1364 legal pairs, 252 bounded
width/dimension cases and 24 full physical comparisons. The seven expected
rejections and three semantic controls have explicit finite domains.

Rule 3, managed allocation deviation. Python lists, tuples and arbitrary-size
integers allocate during compilation and execution. Directly forbidding that
allocation conflicts with the supplied CPython replay interface. Scope is this
fixed finite compiler/verifier only. Explicit width/dimension, route and tape
capacities bound live payloads; one comparison fixture runs at a time. The
largest full owner fixture is 99072 bits. The runtime's internal allocations
are not separately instrumented. A lower-level fixed-storage executor is a
separate integration step, required before a uniform physical runtime claim.

Rules 8/9, authenticated source loading deviation. The comparison compiler is
loaded from one hash-checked retained Python file by importlib. Its only
invoked scientific path is compile_route on the single 380-gate SCALE 2
circuit and its fixed certificate. There is no arbitrary module selection,
network fetch or predecessor whole-word replay. Its original code is frozen.
Source compiler loops operate on the fixed authenticated row, width 64 and
finite heads. Replacing this adapter is unnecessary for the new construction;
an eventual standalone lower-level implementation can consume its literal
instruction output instead.

New functions remain below sixty physical lines. Runtime guards validate
compiler capacities, tape boundaries, legal instructions and restored finite
control. The gate-count assertion is supplementary; every scientific check
and contract uses optimization-preserved exceptions. New code is warning-strict
and syntax-checked, and the complete verifier also runs under optimized Python.
No repository Python linter is installed in the available environment. Shared
diagnostics configuration and immutable source files are unchanged.

The tariff counts logical tape reads, writes and unit moves. A read/XOR is one
read, and a conditional flip is a read plus write under the same finite-control
model as the predecessor. Python compilation, fixture construction, snapshots,
metadata hashing and host interpreter overhead are outside this operation bill.
The result is not a wall-clock measurement or an encoded-D machine compiler.
