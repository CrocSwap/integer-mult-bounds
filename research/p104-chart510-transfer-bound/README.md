# The chart-510 transfer bound and a restricted two-MOVE rewrite

**Five rank-one MOVEs are optimal for the chart-510 block on arbitrary inputs with the specified exterior traffic.** This permits new intermediate projectors, free local recoding and both chart-1 deliveries delayed to their first actual readers. The optimum requires the original hub. The proof follows the clock 8105 nomination in the upstream handoff. [Proof](PROOF.md) · [Historical spaces and geometry](HISTORY.md) · [Prior investigation](https://github.com/CrocSwap/integer-mult-bounds/discussions/7111#discussioncomment-19799234)

**Two MOVEs can be removed exactly on a codimension-two subspace.** A concrete rewrite redelivers the two chart-1 exports using fields already held there. It keeps all 3,433 private clears, adds 30 cochart ADDs and needs two specified helper XORs to vanish. In the unrestricted 630-input map the new rank is 628. On constant fields in the actual 36-call order, rewriting any *m* local calls changes the rank from 18,906 to 18,906 − 2*m*. The separate direct-sum theorem establishes a 5*m* minimum for any number of clean independent instances. A final decoder can repair the loss with exactly two side bits per rewritten call on constants. For one invocation, exactly 60 pairs of original helpers can supply the two observations.
