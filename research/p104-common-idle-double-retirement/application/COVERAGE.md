## Exact independent field-map construction

field(role,p) has integer slot104*role+p, giving0..3639. List the563 native
helper roles in increasing raw-role order; helper(stage,hindex) uses
3640+563*(stage−1)+hindex. All helpers end before slot13774 and every stage
gets fresh independent originals. The29 owned labels for stage s use
13774+29*(s−1)+label_index. Query streams use14296+p. Every actual native
public field map is checked injective; the complete map payload hash is in
APPLICATION.json. No owned bank or copied query receives a target.

These constants are compatible with the existing finite W+O envelope, but
do not certify a production tape allocation. The module intentionally leaves
that inherited application boundary visible.
