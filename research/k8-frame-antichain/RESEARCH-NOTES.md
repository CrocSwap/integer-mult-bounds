# Research record

The assigned route was new mutable-source and leaver circuits beyond the
eight k8 cells. The initial candidates were overlap between residual
faces, joint source/target restoration, and a lower bound for a larger
rational circuit class. The owner-packing lane kept the seven-slot word
fixed and owned its T16/T37 work. No owner search was repeated here.

The current word was rebuilt before the local experiment. The archived
PR1005 `evidence/local` files describe an older 492-helper word, so they
were not used as the k8 input. The unchanged k8 scalar chain and the
seven-slot recipe reproduced all their content pins. The final native
word, ledgers, endpoint replay, adapters, and 2,896 exact phase edges
passed. This shared rebuild supplied the separate owner-packing lane.

The first overlap analysis used the actual surviving faces and exposed
leavers. It gave the 168-frame antichain and the sharp 224-helper bound.
The bound was not treated as a result about the whole 480-helper word.

The next attempt moved each group of four cold helpers into target
registers and restored it before B. Exact arbitrary-input replay showed
that the low scalar tails restore all four rows at that point. The
native endpoint frames then blocked every one of the eight complete
blocks at every target. The proposed four-helper, width-16 deletion was
therefore not a valid cost saving. No verifier guard was removed.

The initial idea that a complementary rational root block could host
the binary frame was false. The binary Gram relation includes a constant
one. The complete binary cap check replaced that incorrect assumption.

The next check split a block between two target caps. Complete mask and
rational-rank enumeration gave a minimum of six carriers in that class.
A four-cap construction with four independent face rows then disproved
an unrestricted six-carrier claim. The package retains this exact escape
witness. It does not attach a new kappa to an unbuilt circuit.

Private query descents also need a separate interface. The antichain
argument cannot be applied to a register after a source query descends
below its clean support hull. The cost screen in `PROOF.md` therefore
applies only to descent between local formation jobs with the other
invoice charges fixed. The broader charged-query route remains open.

The archived candidate500 screen already prices a different full-block
coordinate route. Its changed word, query frames, and owner obligations
cannot be copied onto k8 as additive savings. No previously closed
candidate500 search was rerun. PR899 was read as a predecessor with a
fixed-operation-multiset hypothesis. PR1103 uses another recursive
output-borrowing interface. PR1105 gives a separate scalar cleanup
obstruction for target feedback. Neither is claimed as a dependency
that admits mixed-cap borrowing here.

The stopping decision was to complete the exact obstruction and expose
its escape boundary. A native mixed-cap construction would need new
arbitrary-dirt scalar maps and frame/phase paths. The present evidence
does not supply those maps. It would be false to call this a proved
impossibility for all mutable-source circuits.

Coverage is deterministic: all 14 packet programs, all 192 specified
value demands at 168 frames, all pairs of those frames, all 896 cold
block/target pairs, all 896 center/target pairs, all 15 target masks and
seven complementary partitions per cold block, and all 704 arbitrary
input columns in each cold-tail replay. No random seed or numerical
solver is used. The universal circuit statement follows from the written
first-formation proof, not from enumeration of finite programs.

The final overlap refresh reached PR1128. PR1126 proves a distinct
positive-lift ADD minimum for the cell cores. PR1124 changes the local
word with an eighth slot and new helper endpoints. This package neither
duplicates the former theorem nor excludes the latter construction.
