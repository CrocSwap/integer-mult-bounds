# Chronological numerical fields on delayed-cover fibres

The delayed-cover shape machine and the existing numerical directory enumerate
high matrices in opposite factor orders. Pairing their equal ordinals can compute
the right formula on the wrong payload fibre. This package supplies a literal
fixed-tape bridge and a numerical counterexample to that proposed composition;
neither predecessor's stated theorem is refuted. **No new κ.**

## Result

For fixed q, dimension N and source-code width Q, one thirteen-tape instruction
table produces every chronological raw-field prefix in the actual whole-high
body order. Width, field count, fibre length and row multiplicity are runtime
data. The producer computes its high-digit radix and word extent, retains all
original global slots, preserves borrowed bytes/heads, and erases owned work at
reusable origins. No decoded address, host callback, host recursion or per-depth
tape allocation supplies these operations.

[PROOF.md](PROOF.md) gives the all-size induction, full transition bill, exact
visited-backing count and sufficient conditions for O(V) added work. The general
invoice retains the prefix-length factor: arbitrary shape depth is not silently
assigned the numerical caller's root coupling.

The bridge is statically inserted into #6719's actual natural-root table. Actual
CALL/RETURN phase bits produce and retire chronological labels. The original
width/body packets and current leaf bank are wired directly to the producer.
At depth two, q3/w2/N1, the joined table has **32,748 instructions and 37 tapes**,
executes all four leaves and **108 complete prefixes**, and adds **90,180
transitions** to the original 1,449,116. Every original tape has exactly its old
completed state; all added roles are erased. Added visited backing is **109
cells**: 107 on new roles and two previously unvisited borrowed header markers.
This table still has the source's
bit-complement leaf, not a numerical BIT leaf.

Separately, physically emitted records feed the unchanged 64D `Callback.weight`.
A legal synthetic rank-one vocabulary, two Good ancestors and a current field
