## Reproduce

From a checkout containing the pinned sibling packages:

```sh
PYTHONDONTWRITEBYTECODE=1 python -B research/e8-prefix-helper-composition/verify.py /tmp/e8-prefix-helper-fresh
```

The output directory must not exist. The default first executes the complete
fresh `e8-bit-signed-validation` recipe, including every frozen ancestor replay.
It then reconstructs the prefix candidate from source, replays all complex
admission stages and recomputes the exact composition. Python 3.12 or 3.13,
the ancestors' pinned Python requirements, GNU g++ and Boost headers are needed.
The inherited shell recipe requires paths without whitespace. Use `--help` for
explicit dependency paths. A local complete run generally takes several minutes;
no network access, cloud service or paid API is used by this package.

`SOURCE.json` pins every dependency manifest, original prefix algorithm and
selection. The two readable source carriers use LF line endings for repository
transport. Before execution, the verifier reconstructs exact original CRLF bytes
only inside its fresh output directory, requires the original PR390 hashes
(including terminal newline state), then executes/parses those reconstructed
files. `PREFIX-SOURCE.json` records both carrier and original hashes; the carriers
are not described as byte-identical upstream files. `EXPECTED.json` pins the deterministic candidate, source differences,
interface and assembly results. `MANIFEST.sha256` covers the complete flat package.
Generated logs and receipts live only in the chosen output directory. The replay
copies its inputs and records every derived edit. Its fixed gzip transport and
native payload hashes retain the reviewed cross-platform portability repair.
