## A universal finite certificate

The exact row evaluator `verify_buffers.py` represents a row by a finite dictionary

    (independent_input_role, reduced_signed_generator_word) -> rational_coefficient.

Its `warp` operation left-prepends the actual shared operator symbol, cancelling only an immediately adjacent inverse symbol. Its `add`, SCALE, COPY and owned CLEAR rules perform exact rational linear algebra on these dictionaries. Distinct backward operator symbols are also represented formally. It assumes no finite matrix identities among different generators. The second evaluator `native_extensions.literal_replay` invokes those same free-word arithmetic primitives while separately checking every physical frame incidence and all owned-buffer conventions.

Thus a successful endpoint comparison is a finite coefficient-wise identity over the rational free group algebra Q[F_72], with distinct independent field labels. It is stronger than numerical agreement of 512-dimensional matrices. In particular the expected helper rows contain only their own input label and the empty word, while main rows contain the stated elementary shear and no unwanted helper input labels. The owned C row is identically zero. Those exact zero coefficients must remain explicit acceptance checks.

## Evaluation theorem

Assign any invertible operator K_j on a vector space A to each positive generator j and K_j^-1 to its negative occurrence. There is a unique rational algebra homomorphism

    ev : Q[F_72] -> End_Q(A)

sending a reduced word to the ordered product of its assigned operators. Adjacent inverse cancellation is valid because each K_j is invertible. Exact addition, scalar multiplication and multiplication are preserved by linear extension. Consequently every formal endpoint identity remains true under this assignment, on every arbitrary independent input field.

This handles sums correctly. It does NOT assert that tensor powers preserve addition. Instead it first proves a free-group-algebra identity, then evaluates each generator by K_j^(tensor f). Evaluation is an algebra homomorphism for every f separately, including f>1.

## Physical frame restoration

At a native warp, the physical operator C_new K_j C_old^-1 realizes logical multiplication by K_j. Scalar ADD/COPY operations use a common frame for their operands and therefore enact the exact field-level rational operations. Owned CLEAR produces zero at any declared frame. Exact monomial/Clifford normalizers must implement those stated physical operators, with their absolute phases, rather than only their projective tableaux.

Therefore the successful formal endpoint identity yields the actual physical endpoint C_final S C_start^-1, where S is the stated elementary main shear and independent helper identity.
