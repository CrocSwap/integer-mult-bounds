# A repaired native quotient with an exact typed seven-axis interface

Prepared for Dugongue with substantial OpenAI Codex assistance; Apache-2.0.

This package constructs a usable local supplier from the kernel-153 complex quotient: one consistent replacement for each of its 72 shared native address maps, exact monomial realizations of every actual warp, and explicit monomial wrappers giving the complete two-bank main operator. It proves the arbitrary-input identity at every fiber width by evaluation of an exact free-group-algebra certificate. It establishes no new multiplication exponent or improved kappa.

The main theorem is constructive. There are 56 main pairs of type A, `diag(D,D) S_y(Q^-1)`, and 56 of type B, `diag(D,QD) S_y(Q^-1)`, where D is a seven-axis Gaussian and Q is a separate one-axis central Gaussian. The extra Q in type B acts on physical Y. The backward word realizes the corresponding inverse transpose. The 408 helpers remain arbitrary independent inputs, with target census `{3:2,6:7,7:47,8:139,9:213}`; the complete local paid census is `{1:2177,2:424,3:389,4:147,5:50,8:8}`.

[FREE-GROUP-LIFT-REVIEW.md](FREE-GROUP-LIFT-REVIEW.md) independently checks the crucial universal evaluation argument. This is a sufficient local operator theorem: it does not ask a future worker to invent the maps or recover an unspecified endpoint.

The repaired native maps, typed interfaces and universal evaluation proof are new artifacts relative to those frozen source submissions; no general novelty priority is claimed for the classical symplectic or group-algebra facts used.

## Proof and verification

The retained logical interpreter works over the free group algebra on 72 named generators with exact rational coefficients. Both orientations reduce every one of 632 final input-field rows to its specified endpoint with no nonempty generator words left. Evaluation in any invertible matrix representation preserves this finite formal identity. It therefore applies to tensor-power address maps at every width. This argument evaluates a formal algebra identity; it does not assume tensor powers preserve sums.

The independent Clifford lowering checks every one of 180 warp classes in both orientations, including absolute phase. It also checks all 448 main input/output monomial wrappers and 336 block-operator identities using tableaux and exact zero states. The all-width interface follows by tensoring each address-operator block identity separately. All scalar contacts, eight paid centers, helper repadding and monomial wrappers remain part of the real construction. A later consumer must charge the fixed native work of these wrappers; they are not zero-cost machine instructions.

Reproduce with Python 3.12 or later, using only its standard library, on Windows or Linux:

```sh
python3 -I -O -B research/native-quotient-interface/verify.py
```

The verifier authenticates every file, copies the package into a temporary directory, runs assertion-enabled isolated reconstruction subprocesses, compares regenerated mathematical payloads, and rejects independent source and artifact mutations. It does not require Git, SciPy, a GPU, Lean, the author's drives or a network connection. `-O` does not disable the retained source assertions because the child processes explicitly run without optimization. Fresh execution timings are not compared to frozen timing fields. An exact Laurent-polynomial check verifies the raw backward inverse transposes and their explicit even-power monomial conjugations, and rejects both formulas with the conjugation omitted.

The supplementary [phase-form grammar](PHASE-FORM-GRAMMAR.md) proves an exact symmetric-form extension of subspace-only chart search, with a complete relative-rank formula and explicit Clifford realization. [PHASE-CUT.md](PHASE-CUT.md) gives sufficient binary minimum-cut models including the real rank-one/rank-two costs of formerly free warps. Its finite check exhausts all 153 Lagrangians in dimensions 1 through 3 and all 18,459 ordered pairs, with sampled exact phase lowering. The proof, rather than these small cases, establishes the general formula.

## Bound status and practical use

The old retained controller does not become profitable merely by inserting these two port types. Exact central parity accounting must cover chronological local calls, both scalar boundary programs, query shears, ordinary additions and final productive rank. The tested full parity model did not improve the invoice. Bounded phase searches also found no profitable certificate. These failures are search observations, not universal impossibility theorems and not the research result.

There is no new best kappa in this package. PR #4635's conditional native Word RAM value remains a separate predecessor result with its own assumptions; this package does not re-audit or promote it. The independent arithmetic audit #4641 confirms that its numerical increase comes from #4610's paid profile, while the native transfer adds no numerical gain and provider admission remains separate. A useful next implementation can consume the supplied actual typed operator, or use the phase grammar, without repeating the map reconstruction or mistaking a changed frame for the old ABI. Nothing here uses a Turing-machine simulator or an unbounded-word arithmetic primitive.
