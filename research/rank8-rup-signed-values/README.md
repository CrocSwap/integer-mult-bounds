# Complete rank-eight replay with direct signed-literal values

The complete PR1212 P112 primary command takes **32.78% less median wall time**
locally, from 14.881683875 s to 10.003980833 s. P120 takes 26.16% less time,
from 6.822026333 s to 5.037459500 s. Each comparison uses five alternating
fresh-process runs per side, with identical complete stdout and certificate
objects, zero errors and disjoint observed timing ranges.

Claim type: scoped implementation-equivalence proof, exact finite conformance
and local performance evidence. The new contribution was produced by Nick
Petalas. No new decoder theorem or kappa is claimed. This package does not
audit or re-establish the predecessor's mathematical result.

## Change and evidence

An opt-in adapter stores both signs of each ternary assignment. It replaces the
205,432,164 literal-value helper calls in the profiled complete P112 run with
direct list indexing. Clause visits, the propagation queue, trail resets,
proof parsing, all scientific checks and every rejection control remain in
the same order. The old and new state representations are related by
`s[v]=a[v]` and `s[-v]=-a[v]`. [PROOF.md](PROOF.md) proves exact trace
equivalence by induction and records resource limits.

[BENCHMARK.json](BENCHMARK.json) is generated by the measurement driver. It
contains every sample, environment, source hashes and check counts. Measured
on CPython 3.12.15, macOS 27.0.1 arm64, with 18 logical CPUs and load averages
1.92/2.07/1.85 before profiling. Other contributions could run on the host;
alternation limits the effect of shared-host drift. No timing threshold is
an acceptance gate in CI.

The separately profiled complete P112 run spent 37.382 of 43.688 profiled
seconds inside RUP calls. The value helper accounted for 16.708 cumulative
seconds. These instrumented durations identify the limiter and are not the
before/after timing samples. The measured reduction is below the fraction
of the path affected by the change. Both sides use the same interpreter,
flags, exact fixtures, proof data, process start and validation path.

Local correctness evidence includes 12,030 signed-literal reads over every
ternary state through six variables; 9,282 exact original/transformed RUP
parser, decision and checked-count cases; and 11 source-admission controls.
The two complete CLIs retain all 61/41 check lines and replay all eight proof
files across the pair. Registered commands compare every stdout byte and
certificate field, not just a summary digest. The generated stdout receipt
binds the package files by SHA256. No handwritten receipt is used.

## Reproduce

From the repository root with CPython 3.12 and the standard library only.
The local interpreter is shown exactly; another CPython 3.12 path can replace it.
Choose a new external scratch directory for generated files.

```sh
export TMPDIR=/absolute/path/to/existing/scratch
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/research_package.py --package research/rank8-rup-signed-values
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -W error -B research/rank8-rup-signed-values/verify.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -B research/rank8-rup-signed-values/adapter.py
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -B research/rank8-rup-signed-values/adapter.py --live P120
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -I -W error -B research/rank8-rup-signed-values/benchmark.py --output-dir "$TMPDIR/new-benchmark"
/Users/nick/git/integer-mult-bounds/.venv/bin/python3.12 -B scripts/check_research_commit.py --package research/rank8-rup-signed-values --check-source-history
```

All four registered checks passed locally in 0.100 s, 0.114 s, 24.500 s and
11.582 s. [CHECKS.json](CHECKS.json) contains the generated timing record.
The registered runner emits `PASS_REGISTERED_RESEARCH_PACKAGE`. The new checker
emits `PASS_RANK8_RUP_SIGNED_VALUES`; the adapter retains the original
`PASS_COMPLEX_RANK8_DECODER_RIGIDITY` output. Benchmark output directories must
not already exist. The adapter reads the nine live files in SOURCES.json and
rejects source or proof changes before loading the predecessor. VERIFY.json
declares each file for CI invalidation. This is opt-in and changes no default
entry point or frozen predecessor bytes.

## Scope and limits

The signed table adds `n` list slots, at most 32,256 slot bytes on the measured
64-bit interpreter. It trades these additional writes and slots for fewer
Python calls. The only optimized artifact is the complete fixed PR1212 primary
CLI. Local wall-time results do not promise the same speedup on another host.
No decoder construction, physical supplier, new kappa or selected-frontier
change follows from this implementation improvement.

Selected cold replay, default adoption, end-to-end Linux workflow timing,
Lean, Docker, independent human review and formal proof-kernel review are
unrun. All five selected framework assumptions remain. SOURCES.json pins the
historical card and selected record at canonical main
`7c49fe32c55de02c2c873655c804b16e4c3fef0a`; those files are provenance rather
than live scientific dependencies. The replay-runtime card is refined to
this measured implementation task. Build the Lever determined the reusable
adapter and benchmark; Prove It Works determined complete CLI/certificate
comparison rather than a helper-only timing. One hypothesis was kept; none
was rejected or extended after the first measured improvement.

Live open PRs, handoffs, main/merged RUP and rigidity searches, this account's
recent submissions and local reservations were checked. The overlap helper
covered 539 open PRs and 6,564 Discussion records with complete pagination,
but only 133 of 8,917 main README paths in this sparse checkout. Direct main
README searches supplemented that cache. Arbitrary diffs and unpublished work
remain limits. [Advance claim](https://github.com/CrocSwap/integer-mult-bounds/discussions/1166#discussioncomment-19372279).
