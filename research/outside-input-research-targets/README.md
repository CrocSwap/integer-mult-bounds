These ten proposed research results target those recurring boundaries. The ranking emphasizes reuse across searches. New prose and probe code: Apache-2.0, with substantial OpenAI Codex assistance.

1. **An encoded-output supplier with an internally produced observer and bounded history.**

   **Target result:** a literal changed provider/caller that produces the current-version observation it needs, consumes encoded rather than immediately decoded outputs, closes at least two recursive generations, and returns every borrowed response and owned field correctly. The complete signed invoice must improve an explicit saving point. A small exact reusable composition theorem should accompany the first instance, stating which downstream observations suffice and how deferred restoration is charged.

   **Outside input:** minimal realization and observability distinguish an internal state from what a consumer must observe. [Kalman's original realization paper](https://people.duke.edu/~hpgavin/SystemID/References/Kalman-JSIAM-1963.pdf) provides that distinction; it provides no native supplier or restoration discount. Locality-aware index coding similarly treats the cost of obtaining the demanded observations rather than assuming access to the entire codeword: [Natarajan, Krishnan, Lalitha and Dau](https://arxiv.org/abs/1910.08745).

   **Why many searches would use it:** it changes the endpoint requirement that currently forces repeated decoding and restoration. This could unlock whole families, whereas another inverse formula would not.

   **Existing work and first gate:** build on [PR5419's 25-paper synthesis](https://github.com/CrocSwap/integer-mult-bounds/pull/5419), [Dugongue](https://github.com/Dugongue)'s completion and [Dillon](https://github.com/dillona)'s coupled provider. The newly read [PR5427](https://github.com/CrocSwap/integer-mult-bounds/pull/5427) reports that `ZQY` and reusable paid responses are absent in the frozen words within its declared free-word grammar. Thus the next experiment must change the producer, paid observation or contract. Start at one actual FULL/thin-query cut; retain all independent original modes and both source versions. Stop if the needed observation has no legal producer or its complete cost exhausts the allowance. The existing Global120 point budget [PR5424](https://github.com/CrocSwap/integer-mult-bounds/pull/5424) is an optimistic bound, not earned outputs.

   **Assessment:** strongest direct complex-side opportunity, with substantial construction risk. It is active predecessor work to extend or independently test, not a newly discovered vacant assignment.

2. **A restoration-aware time–space–query frontier for dirty linear programs.**

   **Target result:** for a useful stated class of source-versioned linear programs, compute a Pareto frontier of paid query moment, peak live state, ordinary operations and precision growth. Emit an attaining program plus a separately checkable lower bound. Distinguish reusable borrowed dirt from owned state that may be erased. The goal is an optimality result beyond a stationary single-oracle fanout grammar, allowing changing sources and legal recomputation.

   **Outside input:** reversible pebbling supplies the compute/uncompute view; I/O pebbling charges obtaining data. [Parent, Roetteler and Svore](https://arxiv.org/abs/1510.00377) demonstrate dependency-aware reversible compilation, and [Hong–Kung](https://www.eecs.harvard.edu/~htk/publication/1981-stoc-hong-kung.pdf) supply a model for data movement. Neither model automatically charges the repository's native frames or recursive oracle tariffs.

   **Why many searches would use it:** useful memory is repeatedly mistaken for free memory, and a shorter local word can create an expensive global return. A frontier would let each candidate choose a feasible space/price tradeoff before implementing a complete caller.

   **Existing work and first gate:** preserve the exact stationary result in [dirty-fanout-cut-certificate](../dirty-fanout-cut-certificate/README.md) and the scoped 112-call bound in [PR5425](https://github.com/CrocSwap/integer-mult-bounds/pull/5425). Start with two actual contacts and a small finite scratch limit, using exact shortest-path synthesis and independent cut lower bounds. Require an example whose source changes between contacts; otherwise this merely repeats stationary fanout. An exponential finite search is acceptable for the first bounded result; no generic polynomial algorithm is assumed.

   **Assessment:** high reuse value even if it yields a scoped negative theorem rather than a new κ.

3. **A physically admissible vector index code with a genuine block advantage.**

   **Target result:** a rational or binary block decoder that improves the complete cost over the best scalar implementation for a **changed, explicitly named** mask, with arbitrary payload columns, legal native frame transport, volume proportional to the actual payload, and full restoration. A block fitting matrix alone is the algebraic certificate; the sought research result includes the physical realization and its favorable invoice.

   **Outside input:** [Bukh and Cox's fractional Haemers framework](https://arxiv.org/abs/1802.00476), crediting Blasiak, searches rank per block dimension rather than scalar minrank. [Vector network coding](https://arxiv.org/abs/1512.06352) gives independent motivation for non-scalar linear actions. Neither guarantees a useful repository instance.

   **Why many searches would use it:** successful block actions could escape scalar or commuting-projection restrictions and provide a reusable decoder backend for new geometries.

   **Existing work and first gate:** [paired-plane-block-rank](../paired-plane-block-rank/README.md) already proves `49d` for every field/block size on its fixed mask; enlarging d there does not help. Odd cycles, unequal payloads and the seven-vertex theta mask have additional completed capacity results. Change the actual mask or source side information and pin it. Test d=2 first with exact noncommuting blocks and a complete volume ledger. Reject dense embeddings requiring a child of volume N² to represent O(N) original data; a sparse service would require a new proved ABI.

   **Assessment:** high structural upside; physical realization is the principal risk, not finding a low-rank numerical matrix.

4. **A decoder factorization theory that minimizes paid cost, including overcomplete factors.**

   **Target result:** characterize or construct `M = Σ_j u_j v_j^T` minimizing the **actual sum of binary pairing ranks and endpoint costs**, with signed target losses, rather than minimizing only `rank(M)` or the number of summands. Produce a reusable optimizer and a scoped lower certificate, then one changed geometry whose complete caller passes.

   **Outside input:** [Beniamini, Cheng, Holtz, Karstadt and Schwartz](https://arxiv.org/abs/2008.03759) study sparsifying operators of fast bilinear algorithms. This motivates searching bases and factors jointly, while their arithmetic objective must be replaced by the repository's paid frame/decoder objective. [Higher-point coding bounds](https://arxiv.org/abs/1812.06045) suggest symmetry-reduced exclusion screens for suitable geometric subclasses. PSD assumptions apply only to the declared real Gram subclass; general fitting matrices can be indefinite or nonsymmetric.

   **Why many searches would use it:** a rank-minimal factor need not have the cheapest support pattern. The October 24 product-plane discussion already reports an overcomplete pairing tariff **15,232** versus **15,552** for its tested rank-minimal factor, followed by a failed serial native cost screen. This is motivation, not an admitted improvement.

   **Existing work and first gate:** retain [line-system-saturation](../line-system-saturation/README.md), existing lattice/polynomial kernels and the [product-plane handoff](https://github.com/CrocSwap/integer-mult-bounds/discussions/1587). Calibrate the optimizer against that exact pair of factorizations; then price a changed native realization. Stop if the optimistic **complete** moment already fails. Another rank count, new shell size or better scalar factor alone is not the target result.

   **Assessment:** a strong route for importing geometry and algebra while learning from an already discriminating local example.

5. **A fully charged supplier with genuinely different recursive representation types.**

   **Target result:** an actual two- or three-type recursive construction, such as plain, encoded and history-bearing states, with real child-size lists, complete conversion/return charges and a positive rational vector satisfying `M(C)v < v`. It must improve the admitted result relative to the best applicable one-type implementation and survive the outer reduction.

   **Outside input:** positive-matrix/Lyapunov certificates price different states differently; type weights can make a full cycle contract even when one row sum exceeds one. This is established mathematics, and the repository **already has** A051–A056 in [kappa-action-theory](../kappa-action-theory/volumes/04-analytic.md). The open result is a physical instantiation, not another proof of Perron–Frobenius theory.

   **Why many searches would use it:** it removes the demand that every locally useful representation immediately convert back to one universal format. Several individually losing interfaces could participate in a favorable, correctly priced cycle.

   **Existing work and first gate:** [idea-a-spectral-radius-screen](../idea-a-spectral-radius-screen/README.md) explains why the tested 3|7 macro is only a finite scheduling saving, not a multitype supplier. [phase-accumulator-tensor-closure](../phase-accumulator-tensor-closure/README.md) already supplies a real two-operation, two-level closure whose optimistic bill is critical before wrappers. A successor must change that bill or use another real representation pair. Derive the transition matrix from emitted jobs and include all adapters. Stop if the two proposed types differ only in labels, or if the necessary contraction fails. Never average independently computed seed exponents; [scale-dependent-seed-moment-audit](../scale-dependent-seed-moment-audit/README.md) supplies a counterexample.

   **Assessment:** high upside and high usefulness, conditional on finding real cross-type transitions.

6. **An optimal relation-selection theorem for productive BIT helpers.**

   **Target result:** select a legal subspace of helper relations that makes expensive recursive operands zero or dependent, while preserving independent productive inputs and explicitly debiting every lost target. Optimize the complete signed moment, with per-port frame and ownership constraints. Return the actual reverse word and a certificate of the selected relation space, preferably with a sharp optimum for a useful family.

   **Outside input:** [Wei's generalized Hamming weights](https://ieeexplore.ieee.org/abstract/document/133259/) organize the support obtainable by subspaces of a linear code. Shortening, relative support weights and matroid representations suggest a systematic replacement for independent zero-operand guesses. The repository adaptation has weighted, chronological and physical constraints, so ordinary code weights alone do not solve it.

   **Why many searches would use it:** BIT improvements are necessary for a sustained move past the selected admitted .0034 input, and this turns a successful local idea into a search primitive for many words.

   **Existing work and first gate:** [Ali Romman](https://github.com/aliromman)'s pending [PR5421](https://github.com/CrocSwap/integer-mult-bounds/pull/5421) already claims nine owned relations and ordinary BIT saving **0.0034441226396**, admitting .00344412; it is not a complete new multiplication κ. Preserve that credit and use its nine-relation witness as a positive control. Enumerate legal relation spaces on one bounded connected block, separately over F2 and Q as appropriate. Require the saved paid calls and all lost productive directions in the same invoice. A duplicated input basis or a helper set to zero without its target debit is a rejection, not a win.

   **Assessment:** especially useful companion to complex-side exploration; the recent witness makes the first calibration concrete.

7. **A precision composition theorem for approximate recursive suppliers with dirty state.**

   **Target result:** given a typed word, derive internal magnitude bounds, correlated error propagation, rounding points, required bits and storage, and the resulting recursive cost. Include source encoding, borrowed dirt, the consumer and final exact recovery. The useful theorem would state when an approximate, encoded or degenerate local algorithm retains a favorable exponent after these costs.

   **Outside input:** [Demmel, Dumitriu, Holtz and Kleinberg](https://arxiv.org/abs/math/0603207) analyze stable recursive matrix multiplication. The much newer [arbitrary-precision approximate matrix multiplication paper](https://arxiv.org/abs/2610.13905) is another lead, not a checked transplant. Those theorems do not establish stability or cost of this Gaussian/native supplier.

   **Why many searches would use it:** it makes approximate or alternative-basis ideas testable and could replace repeated ad hoc guard arguments with a reusable sufficient criterion. It can also reject a numerically impressive circuit before a large implementation.

   **Existing work and first gate:** [PR5419](https://github.com/CrocSwap/integer-mult-bounds/pull/5419) already covers gauge optimization and warns that the non-nilpotent `ZW=14I` cycle cannot simply be made small by similarity. Do not repeat a condition-number-only scan. Start from one real producer and propagate the **actual correlated** defects through one consumer and then a second generation. Test independent dirty inputs and explicit rounding; compare the complete precision-weighted invoice. Stop if the required precision consumes the saving or the recovery hypothesis is unproved.

   **Assessment:** broad reuse and a possible gateway to a genuinely new regime, with no generic promise that border-rank ideas transfer.

8. **Small symbolic certificates of native identities valid at every column width.**

   **Target result:** a decidable, explicitly restricted operator language with a sound map to the native phase/address operators at every positive column multiplicity. Emit compact identity certificates that a small checker can verify, including spectators, inverse orientation, phases and ownership adapters. A proof for the selected operator class could discharge a meaningful part of the `native_all_columns` assumption.

   **Outside input:** [Garg, Gurvits, Oliveira and Wigderson](https://arxiv.org/abs/1511.03730) give algorithms for noncommutative symbolic invertibility and rational identities. That motivates exact symbolic reasoning, but free-skew-field identities and concrete native representations have different hypotheses. The representation/lifting theorem is essential.

   **Why many searches would use it:** every new word needs reliable all-width validation. A compact proof interface would make searches safer and reduce the cost of independently reviewing their outputs.

   **Existing work and first gate:** [Discussion 5354](https://github.com/CrocSwap/integer-mult-bounds/discussions/5354) already reports four-width sufficiency in its affine-quadratic class, and [PR5270](https://github.com/CrocSwap/integer-mult-bounds/pull/5270) proposes a p19 lifting argument. The next result must cover a named operation or composition missing from those classes. Test exponent two, reversed noncommuting factors, phase/spectator mutations and a word that passes small-width evaluation while failing the proposed symbolic rule. A random small-bank replay is a control, not the all-width proof.

   **Assessment:** one of the strongest infrastructure targets; it improves confidence rather than automatically increasing κ.

9. **A contract-aware superoptimizer that extracts paid-profile improvements.**

   **Target result:** equality saturation or counterexample-guided synthesis over typed noncommuting words, with shared-DAG extraction and an objective containing the full signed recursive invoice, retained targets, ownership, frame transitions and precision. Emit a literal replacement and a checkable equivalence proof. A useful first publication would find one improvement missed by commuting-only rewrites and explain the new rule's exact domain.

   **Outside input:** [Willsey and colleagues' egg](https://arxiv.org/abs/2004.03082) supplies the equality-saturation architecture. Its standard expression costs do not automatically model shared histories, whole-program restoration or nonlinear moment objectives; those are the research work.

   **Why many searches would use it:** it expands the search from seed changes and adjacent swaps to coordinated graph changes, with a common output format for independent validation.

   **Existing work and first gate:** [paired-swap-normal45](../paired-swap-normal45/README.md) already investigated bounded commuting rewrites, and [projection-cut-toolkit](../projection-cut-toolkit/README.md) gives exact joint frame optimization for its fixed graph. Reuse both rather than relabeling them. Start with a small paid neighborhood where a noncommuting identity changes the graph. Optimize the paid profile before ordinary instruction count. Stop if every extracted word retains the same signed invoice; scalar savings alone do not meet this target.

   **Assessment:** high tool reuse; the central risk is a cost model that rewards an illegal or economically neutral rewrite.

10. **A uniform fixed-tape implementation theorem for mixed-target compilation.**

   **Target result:** turn a finite typed, fully priced template into a uniform implementation with constructive completion/splitting, real normalizer generation, owner allocation/erasure, sequential movement, bounded precision and explicit coefficients in the recurrences. Prove the exact sufficient hypotheses, and instantiate them on the selected template or a changed one. This should discharge a specified portion of the selected `compiler`, `owned_erasure` and `precision_tape` premises; analytic recovery remains a separate theorem.

   **Outside input:** uniform circuit compilation, reversible dependency scheduling and communication-cost models suggest the proof structure. [Hong–Kung](https://www.eecs.harvard.edu/~htk/publication/1981-stoc-hong-kung.pdf) is useful for exposing movement obligations, not for proving linear-tape access or granting random lookup. A RAM or I/O upper bound is not a fixed-tape Turing-machine upper bound.

   **Why many searches would use it:** an explicit sufficient interface would let future constructors know exactly what must be supplied and prevent a large class of finite-certificate-to-all-size gaps. Removing an inherited assumption could be more significant than a tiny conditional exponent increase.

   **Existing work and first gate:** this extends the pinned mixed-target and compact-control work, not a claim that no compiler proof exists. [PR4192](https://github.com/CrocSwap/integer-mult-bounds/pull/4192) already audits Beneš compilation with sequential arena scans, and [PR4100](https://github.com/CrocSwap/integer-mult-bounds/pull/4100) has separately tracked unconditional CRT/native/precision/tape claims. Choose one uncovered lemma and its actual caller before expanding. Begin with one chronological completion/splitting pass, including metadata generation, head returns and all source reads. If its cost cannot be absorbed under the declared recurrence, deliver that scoped gap. Do not relaunch the entire historical proof/replay stack.

   **Assessment:** strongest foundational target in this list; slower to complete, but potentially useful to every future construction.

The second probe is exact row-space algebra. For independent latent coordinates z, already available answers `Sz` and demanded answers `Hz`,

`d = rank([S; H]) − rank(S)`

is the dimension of the missing scalar linear information. Each new scalar linear answer supplies at most one dimension, so d is a lower bound. Arbitrary unconstrained linear queries could attain it; native queries, legal coefficients, source versions, acquisition cost and restoration can make the actual cost larger. Raw untransformed inputs must not be listed as free transformed responses. The probe is deliberately not a group-algebra or all-width verifier.

Synthetic controls need **4** answers with no side information but **2** after two correlated answers are legally available. Two new independent source-version defects still need **2** answers even when all four old outputs are retained. A characteristic control gives rank **2 over Q** and **1 over F2**, preventing a silent cross-field substitution. An even-denominator F2 input rejects. All controls use explicit checks retained under `-O`.

To screen a new scalar cut, provide a JSON file with `width`, `field` (`Q` or `F2`), `available` and `demanded` row arrays, using integers or rational strings, and pass `--cut /absolute/path/to/cut.json`. The output includes an independent demand-row basis for the quotient. Exact row counts do not establish a legal observer or recursive saving.
