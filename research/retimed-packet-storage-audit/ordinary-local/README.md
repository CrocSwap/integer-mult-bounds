Python 3.12, standard library only. From this directory:

```sh
python3 -I -B check.py
python3 -I -O -B check.py
```

`EVIDENCE.json`. `REPLAY-RECEIPT.json` records strict normal/optimized parity.
The checker uses explicit exceptions rather than removable assertions.
