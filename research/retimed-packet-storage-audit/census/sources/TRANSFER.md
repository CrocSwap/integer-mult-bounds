## Scale bands and data

Let N=2^H, H>=1,024 (binary H>=5,610), L=32768 and A=134 or 1,224 on the binary and numerical sides respectively. Set U=2 floor(N/(2048A)), V=N^6, K=N^82 and R=N^2. The number m[e] of native copies at each time is the upward-rounded integral of V x^(-1-t) over [e,e+2), using an upper enclosure. At a paid j, for each target i, send the fraction pi[j,i] with y=x r[j]/k[i]. If L<=y<U, bind a real native input at y to the actual parent job. If y<L, execute its axes with the paid elementary service. If x>U but y is in the band, issue an external occurrence at y. There are no upward interior transfers. In each child port fill every unassigned input of a native unit with its own blank zero field, then run and retire it. This is essential because the normalized transport can leave unused target capacity in the interior. It gives no credit for the dummy inputs.

## Chronological scheduling

Let level(e)=floor(log_(6/5)(e/L)), computed by comparing powers of 5 and 6, and D[e]=D0^level(e), with D0=2^19 for binary and 2^20 for the two-scale Gaussian word. Start all m[e] true raw units of each band at each integer birth b from 0 to K-1. At t0=b+jD[e] issue paid ordinal j, starting at j=0. Close a unit at b+Q D[e], where Q is the actual paid count. For a positive edge e to d, d<=4(e+2)/5 <5e/6. Thus D[d]<=D[e]/D0. At time t0 the child at d receives real jobs from parent births t0-jD[e]. Its last paid cut and return precede the next parent cut, independent of which other j values feed the same child. Missing negative births supply private zeros. For t0>=K, any parent with a later cutoff executes its whole loan locally. Since (6/5)^77>2^20, D[e]≤(e/L)^77. The full lifetime Q D[e]+1 is less than N^77 because e≤N/(1024A) and Q≤2^20. The separate inequality (6/5)^4>2 bounds the number of dependency levels by 4H+1.

At each integer time close all due units first. Open and issue in order of decreasing e, including the first issue of a newly opened child. Different e on one delay level cannot lend to each other. Only a live parent creates a loan. Issue the suffix on that parent before passing its prefix. Consume the prefix once, on that same tick. A fresh zero has a new owner, and external occurrences have disjoint live fields. By induction on these operations, all concurrently lent owners are disjoint until return. This also follows by giving each complete root field a unique custody token and moving that token only to the current one child at its cut. Internal aliases of the physical raw emitter, such as its idle register, stay locked in that suspended context. Other fields with different true jobs cannot use the underlying physical storage before it returns. The last close and the final empty-pending check dispose of all temporary jobs. Each active `Plan.events` emits its own open, issue and close records as the physical decoder needs them. A recursive paid call retains its parent’s iterator and live fields until it returns.
