# An explicit dyadic 64-dimensional multiplicity operator

This contribution was produced by Nick Petalas. Apache-2.0.

A new exact basis exposes the 128-dimensional dihedral component W of the
historical A_1 centre block as two equal 64-dimensional operator blocks:

    C^-1 (A_1|W) C = diag(T,T),     T=K/8,     K integral.

The basis C=[V,RV] is explicit; each column of V has only two or three nonzero
entries in the pinned 216-dimensional orbit basis. The least common denominator
of T in this basis is eight. The complete matrix and intertwiner are emitted
by the command below, with a generated source-bound receipt.

Claim type: scoped written proof with an exact finite matrix certificate.
This is a partial answer to unpaidmoon
[#7065](https://github.com/CrocSwap/integer-mult-bounds/pull/7065), Open next
question 2, which requests an integer multiplicity operator. The rational
operator is now concrete; a change of lattice giving an integer T remains open.
The predecessor's characteristic polynomial is cited, rather than replayed.
No new kappa is claimed. [PROOF.md](PROOF.md) gives the exact construction,
intertwining identities and distinction between T and its integer dilation K.


Replace the executable with another CPython 3.12 path if needed. The standalone
checker authenticates its three live JSON inputs before constructing the result.
It imports no predecessor program. Normal replay writes nothing. To retain the
complete new matrix and basis, add `--matrix --emit /absolute/new/scratch/result.json`
to a direct command. Receipt paths inside the checkout and existing files reject.
The matrix convention is `T=K/8`, `C=[V,RV]`, `2BC=C diag(K,K)` for B=4A_1.

The marker is `PASS_A1_DIHEDRAL_MULTIPLICITY_MATRIX`. Every entry of both
operator blocks is checked exactly, all new group-action identities are checked,
and dense modular elimination proves the doubled basis is independent. Controls
reject corrupted matrices, missing or repeated columns, a wrong scale and an
unmatched domain-basis change. The integer K has 668 nonzero entries in [-64,96]. The doubled basis has
rank 128; a separate dense calculation checks all 27,648 operator identity
entries, and nine semantic controls pass. The canonical certificate SHA256 is
`98ceb6e760b187a30e185e3b5dcd4041018801bca9ea0d60c94631001e86e7f7`.

seconds each locally, below their separate 120-second limits. These are timeout

## Implementation bounds

The terminating checker has no recursion, subprocesses, network or generated
code. Dimensions are fixed at 4096 ambient coordinates, 216 input coordinates,
128 output-basis columns and a 64-by-64 multiplicity matrix. JSON reads are capped
at two million bytes. Every algebraic loop ranges over those bounded finite
collections. Python's managed arithmetic allocates dynamically; this is the
Power of Ten fixed-allocation deviation, with fixed domains bounding live data.
The optional receipt stream is closed on every exit. All functions are below
60 lines. Explicit exceptions preserve checks under optimized Python.
Warning-strict normal/optimized execution and source compilation are the available
diagnostics. No external static analyzer or allocator instrumentation is claimed.
