# Exact exponent arithmetic

Run offline with standard Python 3:

```sh
python3 run.py
```

The command checks pinned capsule inputs, reads both original and retimed words, derives the full paid profile from their common local change, verifies its root with two different rational interval engines, and checks all 63 strict transfer inequalities and 17 rejection controls plus the independent balance derivation. Output goes to a fresh temporary directory, or use `--out NEW_DIRECTORY` for a fresh directory outside this package.

The accepted endpoint is `0.001730394391813963415120 - 10^-46 - 10^-70`. The upper bracket is `0.001730394391813963415121`. The profile moment is divided by `474880 * 73^(1-b)`; its strict monotonicity follows because all positive ranks are below 73.

`vendor-repo/` holds exact copies from canonical main at `20ecf2891d80b5acf18d980b2164fb44ea7faa90`; `t530/` holds exact predecessor PR #3626 inputs at `659fd5e7064d9466b668d7188cbb013b333a415a`. `t530/CREDITS.md` preserves attribution. The two local suppliers originate in Ross Richardson's #3605. All original source notices are retained.

`verify_outer.py` applies the same authenticated dimension generalization already used by #3626: from a fixed replica count to `W = 896*T`. It checks exact before/after hashes. It does not remove an inequality or control. The new inputs are the retimed profile and resulting endpoint.

`recorded/` contains the actual results obtained during this research. Those are stored evidence; running the command produces fresh evidence. Arithmetic alone does not establish operator correctness, physical allocation or full release. See the sibling local, owner and full admission packages. All inherited all-size/compiler, hosting, precision/recovery and analytic/BIT premises remain conditional.
