# Selected reader normalization is a separate obligation

This addendum does not change the frozen matrix review. The response,
sign metric, involution, rank, and support conclusions remain valid.
The root identified a further interface condition after that freeze.

Let R=Z[i,1/2], and restrict the physical reader V in the frozen
factorization A=I+UV to the 24 selected columns. Each small-block
reader row has exactly one nonzero entry in those columns. That
entry is a sign times 1-2i. Its norm is 5, so it is not a unit of R.

This is not only a failure of one chosen square minor. There is a
ring map R -> F5 that sends i to 3 and 1/2 to 3. It sends 1-2i to
zero. Under this map, eight rows of the entire selected reader
V_P become zero. Thus no matrix X over R can satisfy V_P X=I16.

The old normalized selected-row centre interface therefore cannot
be inherited as an arbitrary Gaussian dyadic right inverse of V_P.
One must supply a different representation, more source columns,
or a proved division on the actual code image. Division on that
image is not excluded by this argument. The argument does not
prove a native obstruction for the 24-port response.

For comparison, a size-eight block with two negative metric entries,
each of whose w entries is 1+i, has metric norm 6-2-2=2.
Its selected reader entries 1-i are Gaussian dyadic units, with
inverse (1+i)/2. This explains the root's proposed 32-selected-port
variant. This addendum does not bind that variant to the actual
pair geometry or give it a native word.

`check_reader_addendum.py` checks the eight actual restricted rows
and the finite-field certificate from the preserved payload.
It does not import the response producer.

The root supplied this interface finding. This independent
addendum strengthens it from a square-minor issue to failure of
a right inverse on all 24 selected columns. AI assistance was
used. No PR or publication is authorized.
