## The general local interface

Let \(P\) be the coordinate projection onto the sixteen selected
fields, and let \(R=I-P\). Let \(A\) be an invertible code. The forward
content map is

\[
 F_A=
 \begin{pmatrix}RA&-P\\A&R\end{pmatrix}.
\]

For \(x=(a,u)\) and \(y=(z,v)\), put \(w=Ax\). Then

\[
 X'=(-z,w_R),\qquad Y'=(w_P,v+w_R).
\]

Both banks are arbitrary. In particular, the word preserves \(z\) as
\(-z\). It uses no zero work field.

To invert the map, first recover
\(w=RX'+PY'\). Then
\(x=A^{-1}w\) and \(y=-X'+RY'\). Thus

\[
 F_A^{-1}=
 \begin{pmatrix}A^{-1}R&A^{-1}P\\-I&R\end{pmatrix},
 \qquad
 F_A^{-T}=
 \begin{pmatrix}RA^{-T}&-I\\PA^{-T}&R\end{pmatrix}.
\]

Let \(S\) exchange the two banks on the selected ports. The map
\(S F_A^{-T}S\) sends

\[
 (a,u;z,v)\longmapsto
 \bigl((A^{-T}(z,u))_P,\,
       (A^{-T}(z,u))_R-v;\,-a,v\bigr).
\]

The checker derives this formula directly and compares it with the
complete literal word. It also checks both inverse orders.

For \(A=\bar C^T\), the mixed-source code in this raw selected dual is
exactly \(\bar C^{-1}\). This is an admitted local interface. It does
not imply that codes from different routed stages cancel.

## The full metric conversion

Suppose \(K,G\) are invertible diagonal real matrices and

\[
 AKA^T=G,\qquad J=K^{-1}.
\]

Then \(A^{-T}=G^{-1}AK\). Since \(G\) commutes with \(P\) and \(R\),

\[
 \operatorname{diag}(G,G)F_A^{-T}
 \operatorname{diag}(J,G^{-1})
 =
 \begin{pmatrix}RA&-I\\PA&R\end{pmatrix}.
\]

Conjugation by \(S\) gives the preceding selected-dual formula with
\(A\) in place of \(A^{-T}\). No commutation of \(A\) with \(P\) is
used. No positivity assumption on \(K\) or \(G\) is used.

The actual metrics are signed powers of two. Each scale acts on one
field, so it commutes with that field's complex spatial frame. This
remains true when the two banks have different frames. The checker
binds every scale to the field after the selected-bank relabeling.

Both input banks require a metric. Removing the input scales on the
target bank changes the full map. The negative control confirms this
on arbitrary inputs. The conversion is not a one-bank code identity
with target baselines suppressed.

For the transpose family, the code identity is
\(\bar C^T\bar G^{-1}\bar C=K^{-1}\). The input and output metrics
are therefore exchanged in the precise order given by this identity.
The checker does not reuse the original code's scales for that family.
