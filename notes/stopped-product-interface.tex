\subsection{Paid atom adapters and remainders}
Expand each fixed lower-triangular formal factor into unit scalings and
additions from earlier to later formal fields. Execute intrabank targets
in descending formal-field order, so earlier controls still have their
required original values. Every atom update reads only physically earlier
controls. In a cross-bank shear the update is
\[
 D_{i,t}\leftarrow D_{i,t}+k_{ij}H_{j,f-1-t}.
\]
Even with the reversed source index, the source lies in the earlier head
bank. The retained ordered-affine streaming primitive applies to each
ordinary width-$w$ atom update, costing $O(V)$ per pass.
There are $O(f)$ passes per fixed matrix and thus $O(Vn)$ per finite
node. The reversed control is an indexed earlier atom, not a reversed
field operation. Atom loops use binary descriptors on a fixed tape set;
all inactive digits remain complete spectators. The inherited parking
schedule never scans through parked ancestors, and polynomial descriptor
work is absorbed by the complete stream volume.

For $n=m_bf+\delta$, $0\le\delta<m_b$, pair the first $\delta$
head atoms with the last $\delta$ tail atoms in reverse order. Each pair
uses the retained ordinary width-$w$ interchange. The remaining two
contiguous $m_bf$-atom intervals receive the finite construction.
When $n<m_b$, at most $m_b$ such ordinary calls complete $F_n$.
Both cases cost $O(Vw^{1-a_{\rm old}})$ in addition to the node adapters,
where $a_{\rm old}=384599/10^{10}$. A radix-$q$ atom can be padded to
the next binary power and treated by that ordinary interface, with
volume factor below four and binary width $O(w)$, so the old leaf
algorithm need not use the same address prime.

\subsection{Stopped recurrence}
Let $T(n,w)$ denote time normalized by logical volume. The complete
recursive list, including copied streams, yields
\[
\begin{aligned}
 T(n,w)&\le\sum_r\frac{n_r}{W_b}
       T(r\lfloor n/m_b\rfloor,w)+C n+Cw^{1-a_{\rm old}}
                         &&(n\ge m_b),\\
 T(n,w)&\le Cw^{1-a_{\rm old}}&&(1\le n<m_b).
\end{aligned}
\]
The constant includes finite scalar gates, split/merge, parking, all
adapter passes and remainders at every node. Choose constants $A,B$
using the positive gaps $1-\mu_1$ and $1-\mu_{\tau_*}$.
Strong induction, with child widths at most $(r/m_b)n$, gives
\[
 T(n,w)\le An+Bn^{\tau_*}w^{1-a_{\rm old}}.
\]
Indeed the linear child terms use at most $\mu_1 An$, leaving the
linear toll, and the other child terms use at most
$\mu_{\tau_*}Bn^{\tau_*}w^{1-a_{\rm old}}$, leaving the peeled-atom
toll since $n^{\tau_*}\ge1$. Enlarge $B$ for the bounded base cases.
All constants are independent of both $n$ and $w$.

\subsection{Outer ordinary wrapper and arbitrary widths}
Write $C=C_n$. The map $F_n(H,D)=(CD,CH)$ obeys
$F_nLF_n(H,D)=(H+D,D)$ for $L(H,D)=(H,D+H)$.
Accordingly the chronological sequence
\[
 D\leftarrow D-H;\quad F_n;\quad D\leftarrow D+H;\quad
 F_n;\quad D\leftarrow H-D
\]
is exactly $(H,D)\mapsto(D,H)$. The three lower updates cost $O(Vn)$
in the atom model. Both calls reuse their restored row reserve.
This is a constant outside the entire recursion, so it does not multiply
any recursive child count or characteristic.

For a radix-$q$ width $e$ choose $\theta=1/1000$,
$w=\lceil e^\theta\rceil$ and $n=\lfloor e/w\rfloor$.
Apply the ordinary wrapper to the atom body and the old ordinary
algorithm to the fewer than $w$ residual digits. For large $e$ the cost is
\[
 O\!\left(V\left[e^{1-\theta}+
 e^{(1-\theta)(1-a_*)+\theta(1-a_{\rm old})}\right]\right).
\]
The remainder is bounded by the second term. Thus the ordinary saving is
\[
 a_b=(1-\theta)a_*+\theta a_{\rm old}
     =\frac{803380799}{10^{13}}=0.0000803380799.
\]
Since $\theta>a_b$, the paid adapter term is strictly lower order.
All bounded widths use the old interface. Numerical padding of a binary
chunk range to the least suitable radix-$q$ range has volume factor
below $q^2$; it preserves numerical order and is removed after the
completed ordinary wrapper, whose endpoint is ordinary interchange.

If external rows are unavailable, use the inherited ordinary high-digit
borrowing construction from \path{notes/batched-bit-rows.tex}.
Borrow $O(\log e)$ high digits, exchange and join them into a preceding
row field, pad that field once, act on the body, and separate the high
parts. It applies literally to the completed ordinary wrapper; no claim
about borrowed high positions is made for an unwrapped reversed call.
Single-digit moves cost $O(V\log e)$, and small widths use the old
algorithm. Atom indices and rational coefficients are finitely specified;
the algorithm uses the same fixed tape set and complete spectator ranges.
