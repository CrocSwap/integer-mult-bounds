\begin{abstract}
PR29 (Zhihao Chen) builds the two-stage partial-swap construction at
factor dimensions $(55,53)$, and PR31 (Rohan Arun) exposes two contiguous
blocks in its data null-corner. Both constructions are parametric in
$(a,b)$ with $a=b+2$. At $(a,b)=(47,45)$ we rebuild both producers with the
exact label audit and regenerate the common-basis prescriptions. We also
regenerate PR31's weight-independent zero-minor certificates, now 1569 of
them, and its exact rational pivot witness. The data profile becomes
$11$ singletons $+[43,37,1933]$. The bit saving is $1638156876/10^{14}$.
With the unchanged PR21 complex circuit, the PR23 semantic/bulk transfer
and the stopped-leaf parameter $\beta=1/20$ and headroom $h=10^{-12}$, the conditional final saving is
$\kappa=1638103206/10^{14}=1.638103206\times10^{-5}>2^{-16}$. This is not a formal
verification or a practical multiplication implementation.
\end{abstract}

\section{Data corner}
Set $d=a+b-1=91$. The inherited prescriptions restricted to the first $d$
rows and last $d$ columns are
\[
R=[0,\ldots,46;1,\ldots,44],\qquad C=[2,\ldots,45;0,\ldots,46].
\]
The row residue is $\beta_i=i\bmod45$. The column residue is
$\gamma_j=(m-d+j)\bmod45=(j+44)\bmod45$, since $(m-d)\bmod b=44=b-1$, as at
PR31's dimensions. Exactly as in PR31, on the nonzero-coordinate open set
the null corner of $(I-p\xi)\otimes(I-v\nu)$ is diagonally equivalent to
\[
 M_{ij}=x_{R_i}\mathbf 1_{R_i=C_j}+y_{\beta_i}\mathbf 1_{\beta_i=\gamma_j}-1
 =\bigl(F\operatorname{diag}(x_0,\ldots,x_{46},y_0,\ldots,y_{44},-1)G^T\bigr)_{ij}.
\]
Here $f_i$ has ones at $R_i$, $\beta_i$ and the constant, and $g_j$ has ones
at $C_j$, $\gamma_j$ and the constant.

\begin{lemma}[PR31]
Let $U,V$ have $e$ rows, let $D$ be diagonal, and let the coefficient set
split as $E=X\sqcup Y$. Then
$\operatorname{rank}(UDV^T)\le\operatorname{rank}U_X+\operatorname{rank}V_Y$.
\end{lemma}
If this bound is below $e$, the minor vanishes identically in all weights.

The claimed rightmost-pivot sequence is
\[
\begin{gathered}
(0,90);\quad(i,i+46),\ 1\le i\le43;\\
(44,46),(45,45),(46,44),(47,43),(48,42),(49,41);\\
(i,i-46),\ 50\le i\le86;\quad(87,3),(88,2),(89,1),(90,0).
\end{gathered}
\]
For each claimed pivot and each still-available column to its right, the
certificate gives a partition $X\sqcup Y$ of the $93$ coefficient
coordinates. Its two integer ranks sum to less than the augmented minor
size. There are $43\cdot42/2+37\cdot36/2=1569$ such minors. All $3138$
ranks are checked by integer elimination, independently of the
matroid-intersection search that found the partitions.

The exact normalized witness is
\[
p_r=v_t=1,\qquad \xi_r=\frac{(r+1)^2}{\sum_{s=1}^{47}s^2},\qquad
\nu_t=\frac{(t+1)^3}{\sum_{s=1}^{45}s^3}.
\]
It is reconstructed over $\mathbb Q$. Rightmost-nonzero elimination
reproduces the $91$ stored pivot values, all nonzero, with run lengths
$1,43,1,1,1,1,1,1,37,1,1,1,1$. The PR29/PR31 finite-product argument places
these minors, the auxiliary and local minors and the basis determinants in
the same irreducible free $\mathrm{GL}_{47}\times\mathrm{GL}_{45}$ family. A
single common rational basis therefore satisfies all of them, and the
address prime is chosen afterwards.

\section{Exact moment and assembly}
The rational logarithm enclosure and $e^u\le1+u+u^2/[2(1-u/3)]$ certify
$a_b=1638156876/10^{14}$; the next grid point $1638156877/10^{14}$ fails the
same enclosure.

\paragraph{Row stock.} The bit halving degree is $16$ and the wire
exponent $34$. The coefficient is $16\cdot34+544\cdot41=22848$, and
$47000>(51/25)\,22848$, so the stock is unchanged.

\paragraph{Stopped leaves.} PR23's stopped complex tree charges leaves at
$e<d^\beta$ with exponent $\sigma+\beta(1-\sigma)$; this is the only place
$\beta$ enters. The requirement $(1-\beta)a_c>a_b$ fails at PR29's
$\beta=1/10$ ($16.2\times10^{-6}<a_b$). We take $\beta=1/20$, which gives
$(1-\beta)a_c=17.1\times10^{-6}>a_b$. PR21 already used $\beta=1/1000$, so
smaller $\beta$ is admissible in this framework; it changes only the
explicit stopped-leaf cutoff, which becomes $357$ bits and stays far below
the common eventual cutoff.

\paragraph{Assembly.} With $h=10^{-12}$ and
\[
q=a_b(1-2h),\quad c=q(1+h),\quad \epsilon=\frac{1-h}{1+c+q},\quad
G=\epsilon q,
\]
together with PR23's remaining definitions, all $47$ strict constraints
and seven margins hold. The minimum margin is $G$, and
$G-1638103206/10^{14}>5.9\times10^{-15}$. The next $\kappa$ grid point fails.

\paragraph{Negative controls.} The following are all rejected:
\begin{itemize}
\item the old guard and old exposures;
\item $\beta=1/10$;
\item a corrupted identity certificate;
\item omitting the data blocks, which lowers the certified saving.
\end{itemize}
