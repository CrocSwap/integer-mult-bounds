# Equal-frame fusion of the direct ternary producer

This is a compiler refinement of the certified [direct intersection-two
producer](ternary-targets.md), which follows Zhihao Chen's F3 five-set
construction in [PR #7](https://github.com/CrocSwap/integer-mult-bounds/pull/7).
It retains the existing rational source/dual frame assignment, including the
64 delayed source nodes. These working notes cover the compiler checks;
assembly arithmetic is checked separately.

At h=28, the exact role count decreases from **10,365,877 to 10,356,672**:
9,205 roles saved, with the per-invocation center loss unchanged at 9,828.
The source-span pass takes about 28 seconds on the development machine; its
boundary-rank pass takes about two seconds. Building the full exact producer
also requires the upstream checker's several GB of working memory.

| Rational dual-target span; source nodes separate | 6,004,464 | 16,401,145 | 6,133,548 | 10,365,877 |
| Rational source spans and rational dual-target spans | 5,296,637 | 15,710,636 | 5,452,244 | 10,356,672 |

The first two passes give no role saving. The final pass merges 707,827 source
nodes into other classes: 521,352 with a common source pair and 186,475 with a
common source triple. Source and dual labels are never identified with each
other. The 5,355,755 source nodes occupy 4,647,928 rational-span classes; the
649,983 distinct dual target families occupy 648,709 rational-span classes.

## Exact equality of rational frames

Every source or target span is generated by original 0/1 five-set indicators
in Q^28. Hadamard's inequality bounds every square minor by 5^14, less than
the prime p=2^61-1. Reduction modulo p therefore preserves the rank of every
such matrix. For two row spaces, it preserves the ranks of A, B and their
stacked matrix [A;B]. Equality of their canonical modular row spaces is
equivalent to equality of the rational spaces. Hashes only select dictionary
buckets: every match compares the complete canonical tuple.

The common intersection and union of a family are intrinsic to its row space.
A point is in the union precisely when its coordinate functional is nonzero
on the space. It is in the common intersection precisely when its coordinate
functional equals one fifth of the coordinate sum on the space. Families with
different signatures cannot have equal spans, so singleton signature buckets
need no elimination. If the union has d points and the common intersection has
k points, the span has dimension at most d-k when d>k, and dimension one when
d=k. Enumeration can stop as soon as this bound is attained; otherwise it
continues through every original indicator. This avoids storing a dense
matrix at every node.

Source-frame classes use the actual source spans. Dual-frame classes use
equality of target spans, equivalent to equality of their orthogonal
complements because the ambient form is nondegenerate. Thus every assigned
frame is already covered by the upstream nondegeneracy audit.

## Boundary compiler and role count

The [common-frame compiler](ternary-reuse.md) replaces a region with p distinct
incoming values and q outgoing uses by an invertible gate occupying p+q-r
roles, where r is the rank over F3 of its q-by-p boundary map M. Choose r
independent output rows and r pivot input columns. Compute those independent
outputs into the pivot input slots, preserve the other inputs, and add the
remaining outputs into q-r fresh dirty slots. The selected square matrix is
invertible, so the entire operation is invertible for arbitrary scratch data.
The existing transparent wrapper cancels the dirty contributions.

One incoming port supplies every use of that value inside the region. An
outgoing port is one distinct `(value, successor region)` delivery, plus one
port for each designated output use. Repeated outgoing copies have repeated
matrix rows and still consume separate ports. Different successor regions
require separate deliveries. Starting with v=98,280 input roles gives

    R = v + sum(q_region - rank_F3(M_region)).

The counter independently builds the boundary maps from the exact producer
DAG. Its packed elimination operates over F3, not over Q or modulo the
61-bit prime. It checks that the original cancellation-free additions induce
disjoint formal incoming supports before forming each 0/1 boundary row.

Each source-region edge increases source spans by inclusion. Each dual-region
edge increases target orthogonal complements by inclusion. Contracting all
equal spans inside either region cannot create a cycle: inclusion around a
cycle would force all frames to be equal. The source region is ancestor-closed,
so there is no edge from a dual region back to a source region. The combined
quotient is acyclic. Every fused gate has one previously certified
nondegenerate frame. All boundary inclusions, their complementary reversed
orientations, and center endpoints remain valid, so no new decreasing edge
is introduced.

## Reproduction and scope

From the repository root, run:

```sh
python3 scripts/experiments/ternary_span_fusion.py --workdir /tmp/ternary-span-fusion
python3 -m unittest discover -s tests -p test_ternary_boundary_fusion.py -v
```

The [driver](../../scripts/experiments/ternary_span_fusion.py) rebuilds the exact producer,
audits all rational frames, exports
the cut, computes both source and dual classes, and reruns all boundary-rank
counts. It writes the [fusion certificate](../../certificates/ternary-span-fusion.json).
A retained DAG can
be reused with `--dag PATH --producer-certificate PATH`; the driver checks its
hash against the producer certificate and requires every producer proof-file
hash to match the current source. It never accepts a fingerprint-only DAG.

The focused tests compare canonical modular target classes with independent
Fraction elimination, compare C++ boundary counts with independent Python
boundary matrices for the full h=8 direct producer, and check a four-output
boundary whose rank is four over Q but three over F3, including duplicate
designated output deliveries. The compiler's separate existing tests cover
physical frame sequences and arbitrary dirty scratch on small networks.

The result is an exact finite producer-width improvement using the written
common-frame compiler argument. It is not a formal proof checker. The
[assembly checker](../../scripts/ternary_fused_network.py) separately determines
which multiplication exponent the reduced role count supports.
