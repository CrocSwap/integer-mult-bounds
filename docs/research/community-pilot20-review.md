## Evidence and efficiency

The 14 passing scoped commands consumed **129.9 aggregate process-seconds** with four workers. This is test runtime, not elapsed reviewer time. No full supplier rebuild was started. METRICS.json records **12.3 minutes** from frozen selection through publication and disposition comments. This includes packet tooling and review work, not just execution. Token telemetry is unavailable, and there is no matched control batch: no numerical token-saving or speedup claim is made.

The unchanged selected supplier is reused only as historical context/pinned inputs. These scoped checks do not re-establish its theorem. #671 compares 103 identical predecessor files and identifies nine changed files; missing local provider payload prevents blanket reuse of #664 logs. Keeping a minimal authenticated artifact bundle is the next cache improvement.

#684 initially failed because our reduced fixture omitted transitive generator modules. Restoring its exact-head scripts, notes and upstream files fixed the fixture; the unchanged command passed. #686 reached a missing Boost header; no test or source pin was bypassed. Both initial logs remain in checks/.

Original package commands are baseline-sensitive. #670, #677, #683 and #684 contain historical context/source pins that differ from current main. The scoped runs use exact-head fixtures; a root command against a later selected record may require the documented pinned checkout. No historical pin or selected certificate was rewritten to manufacture a pass.

Written arguments were reviewed at the scopes listed above. Finite tests, scoped proofs, search failures and a complete multiplication theorem remain distinct. #682 does not validate all of #647; #689 does not approve all of pending #673.

## Reuse for the next batch

1. Fetch metadata once and pin current heads. Run `scripts/pr_review_packet.py --baseline COMMIT --output NEW_DIRECTORY metadata/*.json` against the local fetched Git objects.
2. Group packages by shared dependency; inspect full diffs and the new reasoning. Blob equality alone is not scientific equivalence.
3. Run only the necessary changed-package checks, with bounded first-pass runtime and complete logs outside the conversation. Authenticate input/verifier/environment scope before reusing receipts.
4. Publish source, attribution and scoped evidence in one integration batch. Check live heads before mutation; leave explicit unresolved items open.

The packet generator is offline and read-only. Its test covers truncated metadata, deletion, mode-only change and identity at the integration baseline. It never executes contributor code, approves a PR or closes one.
