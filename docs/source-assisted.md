The wrapper checks the curated source manifest and immutable parent bindings,
extracts the compressed immutable reference and flow in a temporary directory, regenerates the new
complex maps and bit boundary/templates, verifies matching prefixes, and checks
all exact assembly fields. It also emits the new globally allocated complex
scalar transcript and replays arbitrary dirty probes with negative controls.
Generated caches, transcripts and logs remain outside tracked sources. To retain
them, use `scripts/source_assisted_verify.py --work ABSOLUTE_NEW_DIRECTORY`.

For recorded profiles and exact arithmetic alone, use
`make source-assisted-arithmetic`. This command does not regenerate construction
or replay the new transcript. Python assertions must remain enabled.

The globally renumbered bit elementary transcript and its new arbitrary-dirty replay have not been exported. The independent complex scalar transcript is a separate integration check; scalar replay does not materialize physical Clifford/frame transports or prove the inherited all-size interfaces.
