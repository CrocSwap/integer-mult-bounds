## Reproduction

```sh
make skip-clones-verify
```

`producer.py` rebuilds PR53 and the pinned clone jobs, verifies every exact
scalar output, expands all global supports, checks every actual matched
use before C++ profiling, recomputes the fixed profiles under exact CRT
bounds, and checks the complete physical word on every dirty basis vector
in both orientations. Saved finite records must exactly match fresh replay.

`witness.py` verifies source pins, strict integer counts, the complete child
list and exact moment, all 47 strict assembly conditions and seven margins,
eventual cutoffs, next-grid rejection, and lower moments excluding prior
networks including PR53. `make verify` retains historical PR53 and copied/fixed
checks as well as this new target. Integrated run receipts are recorded
separately; copied discovery output is not a completed repository replay.

`clone-jobs-h.json` pins each preceding carrier matching, every whole-chain
edit, and the source/output graph hashes. The strict parser rejects floating
JSON numbers, duplicate keys, booleans used as indices, and malformed fields.
Replay rejects incomplete chains, colliding or used provider capacities,
wrong chronology, changed core/cover envelopes, and false source partitions.
`parameters.json` stores exact numerator/denominator pairs plus the grid.
Verification never refreshes the source manifest. Maintainers explicitly
freeze reviewed files with `pin_sources.py`; certificates and run receipts
are derived outputs and excluded from that manifest.
