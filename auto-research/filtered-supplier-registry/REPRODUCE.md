# Reproduction and transport

Run `python -B verify.py --work /absolute/path/to/new-output` with Python3.11+
and NumPy installed. The retained exact phase engine uses NumPy integer arrays;
it does not price the final bound with floating point. A normal replay takes
about a minute on the tested machine. No network, compiler, optimizer or GPU
is required for reproduction. The discovery MIP/native search is not a premise.

The root verifier checks every manifest entry before creating outputs, then
copies its source to an output-local LF-normalized tree. It reconstructs the
selected source, applies the exact observational rewrite, and freshly checks
both variants' local words, changed phases, wrappers, emitted programs and
arbitrary dirty columns. Pinned unchanged phase edges/controller/bit artifacts
are explicit inherited dependencies, not newly re-proved public submissions.

Every helper is tied to the actual selected variant, source frame, full chart,
whole owner, legal interval and paid remainder. The scalar/Horner recount uses
the actual per-call program and a conservative common registry bound. Both
moment engines certify adjacent rational endpoints; all47 outer constraints
and negative controls are required. The final template must match EXPECTED.

Text may arrive as LF or CRLF; only line endings are normalized for hashes.
Generated gzip pins level9, timestamp0 and OS byte255. Root manifest, expected
result and every input are mandatory. Optimized Python(-O) is rejected.
The package was tested on Windows Python3.11 with NumPy2.4.6; no unexecuted
Linux/macOS/Python3.14 test is claimed.

Upload all batches to the root of ONE fresh branch. Each batch contains a
research folder; upload that folder, not the batch folder. All batches must
be committed before opening one PR. Files are split to at most40 per batch,
under2MB each, with no hidden files. The combined upload is checked byte-for-byte.

Registry bindings for CLIFFORD-REVIEW.json use canonical sorted JSON with only
the top-level runtime `seconds` field omitted. All mathematical receipt fields,
including source/recipe/compiler hashes, equality counts and global-phase flags,
remain bound. Other registry entries are raw-byte SHA-256. HOSTED source_artifacts
also retain the actual per-run raw receipt hash. This avoids putting wall-clock
timing in the mathematical template identity; no proof check is removed.
